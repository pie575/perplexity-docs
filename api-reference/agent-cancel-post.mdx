---
title: "Cancel Agent Response"
description: "Requests cancellation of response `{id}`. Acts on durable state,
  so it works for background runs that outlive the client connection.
  Cancellation is asynchronous: a `200` acknowledges the request (`status:
  cancelling`) and the run stops shortly after - poll `GET /v1/agent/{id}` for
  its terminal status. Cancelling a run that is already terminal returns `400`.
  Ownership is enforced server side; a cross-tenant or unknown id surfaces as
  `404`."
openapi: "/openapi/openapi.json POST /v1/agent/{id}/cancel"
---
