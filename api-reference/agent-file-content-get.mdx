---
title: "Download Agent Response File"
description: "Download the raw bytes of a file the response delivered with the
  `share_file` tool. The `file_id` comes from the file list endpoint and is
  distinct from the response `id`. The response streams raw bytes, not JSON,
  with a `Content-Type` matching the file and a `Content-Disposition:
  attachment` header carrying the original filename."
openapi: "/openapi/openapi.json GET /v1/agent/{id}/files/{file_id}/content"
---
