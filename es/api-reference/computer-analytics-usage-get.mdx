---
title: "Analítica de uso"
description: "Devuelve la analítica de uso de Perplexity de tu organización como
  una serie temporal agrupada en intervalos para un único conjunto de datos.
  Requiere una API key de analítica de organización, generada por un
  administrador de la organización desde Configuración → Organización → Computer
  en la aplicación web de Perplexity. Solo se devuelven los intervalos completos
  de la cuadrícula UTC: start_time se ajusta hacia abajo hasta el inicio de su
  intervalo y el intervalo en curso nunca se incluye. Cada conjunto de datos
  cuenta algo distinto: créditos en credit_usage, consultas en query_volume,
  miembros activos únicos en daily_active_users y número de hilos en el resto.
  Los intervalos de daily_active_users no son aditivos: un miembro activo
  durante varios días se cuenta una vez por cada día, por lo que su suma no
  equivale al número de miembros activos del periodo."
openapi: "/es/openapi/openapi.json GET /v1/analytics/computer/usage"
