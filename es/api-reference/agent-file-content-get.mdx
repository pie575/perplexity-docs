---
title: "Descargar archivo de respuesta del agente"
description: "Descarga los bytes sin procesar de un archivo entregado por la
  respuesta mediante la herramienta `share_file`. El `file_id` se obtiene del
  endpoint de listado de archivos y es distinto del `id` de la respuesta. La
  respuesta devuelve bytes sin procesar, no JSON, con un `Content-Type` acorde
  al archivo y una cabecera `Content-Disposition: attachment` que incluye el
  nombre original del archivo."
openapi: "/es/openapi/openapi.json GET /v1/agent/{id}/files/{file_id}/content"
---
