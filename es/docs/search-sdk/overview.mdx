<div id="search-as-code">
  ## La búsqueda como código
</div>

La búsqueda tradicional trata la recuperación como un monolito: un modelo emite una consulta, el motor de búsqueda ejecuta una canalización predefinida y el modelo consume los resultados ya procesados. Ese contrato se rompe cuando los agentes abordan tareas complejas y abiertas: genera un contexto poco preciso, desaprovecha el conocimiento de dominio del modelo y fuerza un trabajo naturalmente paralelo a través de una interfaz serial.

[Search as Code](https://research.perplexity.ai/articles/rethinking-search-as-code-generation) es la respuesta de Perplexity: exponer la pila de búsqueda como primitivas componibles que los agentes orquestan mediante código generado. El agente controla directamente la recuperación, el ranking, el filtrado, la distribución en paralelo y el renderizado; mantiene el estado intermedio en el entorno de ejecución en lugar del contexto del modelo y consume solo la información que importa.

El Perplexity Search SDK lleva este enfoque a tus propios agentes y aplicaciones. Ofrece como primitivas de Python los resultados web clasificados en tiempo real y los fragmentos de página relevantes para la consulta que proporciona la [Search API](/es/docs/search/quickstart), con concurrencia, procedencia y puntos de control integrados para flujos de trabajo con uso intensivo de recuperación.

<div id="built-for-agents">
  ## Diseñado para agentes
</div>

El SDK adopta un enfoque agents-first: está pensado para que lo utilicen agentes de programación, no para aprenderlo leyendo documentación en prosa. La referencia de uso canónica es la Agent Skill del SDK, que cubre la instalación, la autenticación, el conjunto completo de métodos, los patrones de flujo de trabajo y los problemas habituales:

<Card title="Agent Skill de pplx-search-sdk" icon="github" horizontal="true" arrow="true" href="https://github.com/perplexityai/api-platform-developers/tree/main/skills/pplx-search-sdk">
  Instala esta skill en tu agente de programación y deja que sea él quien escriba la integración.
</Card>

El código fuente está en [perplexityai/perplexity-search-sdk](https://github.com/perplexityai/perplexity-search-sdk), y el paquete se publica en PyPI como [pplx-srch-sdk](https://pypi.org/project/pplx-srch-sdk/).

  ## Productos relacionados
