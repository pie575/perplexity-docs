<div id="overview">
  ## Descripción general
</div>

La Embeddings API de Perplexity genera embeddings de texto de alta calidad para búsqueda semántica y recuperación. Elige entre **embeddings estándar**, para textos independientes, o **embeddings contextualizados**, para fragmentos de documentos que comparten contexto.

<Info>
  Recomendamos usar nuestros [SDK oficiales](/es/docs/sdk/overview) para interactuar con la Embeddings API de forma más cómoda y con seguridad de tipos.
</Info>

  Precios de pago por uso en todas las APIs. No se requiere suscripción.
</Card>

<div id="available-models">
  ## Modelos disponibles
</div>

|            Modelo            | Dimensiones | Contexto | MRL | Cuantización | Precio ($/1M tokens) |
| :--------------------------: | :---------: | :------: | :-: | :----------: | :------------------: |
|     `pplx-embed-v1-0.6b`     |     1024    |    32K   |  Sí |  INT8/BINARY |        $0.004        |
|      `pplx-embed-v1-4b`      |     2560    |    32K   |  Sí |  INT8/BINARY |         $0.03        |
| `pplx-embed-context-v1-0.6b` |     1024    |    32K   |  Sí |  INT8/BINARY |        $0.008        |
|  `pplx-embed-context-v1-4b`  |     2560    |    32K   |  Sí |  INT8/BINARY |         $0.05        |

Todos los modelos usan mean pooling y no requieren ningún prefijo de instrucción: puedes generar embeddings de texto directamente, sin ingeniería de prompts.

<Warning>
  Los embeddings de Perplexity **no están normalizados**. Compara siempre los embeddings `base64_int8` mediante **similitud del coseno** (no con producto interno ni distancia L2). Compara los embeddings `base64_binary` mediante **distancia de Hamming**. Consulta [Buenas prácticas](/es/docs/embeddings/best-practices) para más detalles y funciones auxiliares de normalización.
</Warning>

<Tip>
  **Cuándo usar cada uno:**

  * **Embeddings estándar** (`pplx-embed-v1-*`): textos independientes, consultas de búsqueda, oraciones sueltas
  * **Embeddings contextualizados** (`pplx-embed-context-v1-*`): fragmentos de documentos que se benefician de un contexto compartido (por ejemplo, párrafos de un mismo artículo)
</Tip>
