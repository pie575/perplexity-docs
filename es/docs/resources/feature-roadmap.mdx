<div id="upcoming-and-in-progress">
  ## Próximamente y en curso
</div>

<AccordionGroup>
  <Accordion title="API de sandbox" description="Entornos aislados para ejecutar Python y Bash">
    Estamos presentando una Sandbox API con entornos aislados para ejecutar código Python y Bash. Cada sandbox se ejecuta en su propio contenedor con recursos dedicados y admite operaciones con archivos, procesos en segundo plano y persistencia del estado mediante pausa/reanudación.

    * **Contenedores dedicados por sandbox** para un aislamiento más sólido
    * **Ejecución de Python y Bash** con soporte de archivos y procesos
    * **Persistencia del estado con pausa/reanudación** para flujos de trabajo iterativos
  </Accordion>

  <Accordion title="Mejora del rendimiento de Chat Completions" description="Menor latencia en los endpoints actuales">
    Estamos desplegando mejoras de rendimiento sin romper la compatibilidad.

    * **Mismos contratos de endpoints**, con retrocompatibilidad
    * **Mejoras de latencia** en los patrones de solicitud más habituales
    * **Despliegue automático**, sin necesidad de migración para la mayoría de los usuarios
  </Accordion>

  <Accordion title="Capacidades para cargar vídeos" description="Procesamiento multimodal de vídeo">
    Estamos ampliando la compatibilidad multimodal para incluir la carga directa de videos.

    * **Análisis del contenido de video** en los archivos cargados
    * **Razonamiento a nivel de fotograma** para obtener información sobre momentos concretos
    * **Comprensión visual de escenas** en contenidos multimedia más extensos
    * **Recuperación multimodal** en contextos de texto, imagen y video
  </Accordion>

  <Accordion title="Búsqueda de archivos y conectores" description="Acceso ampliado a los datos">
    Estamos trabajando para ampliar el acceso a archivos y fuentes de datos de las organizaciones que usan la API.

    * **Búsqueda en repositorios y conectores** sobre los datos de la organización
    * **Compatibilidad con múltiples formatos** de documento habituales
    * **Integración con fuentes de datos externas** para flujos de trabajo empresariales
  </Accordion>

  <Accordion title="Compatibilidad con webhooks para la API asíncrona" description="Notificaciones de finalización basadas en eventos">
    Tenemos previsto añadir callbacks mediante webhooks para flujos de trabajo asíncronos, de modo que los trabajos de larga duración puedan notificar automáticamente a tus sistemas.

    * **Webhooks de finalización de trabajos** para solicitudes asíncronas
    * **Webhooks de fallos** con semántica de entrega segura ante reintentos
    * **Verificación de firmas** para gestionar los callbacks de forma segura
  </Accordion>

  <Accordion title="Ampliación de modelos y SDK" description="Nuevas funcionalidades de los modelos y mejoras de usabilidad en los SDK">
    Seguiremos ampliando la cobertura de modelos y mejorando la ergonomía de los SDK.

    * **Nuevos lanzamientos de modelos** y mayor claridad sobre su ciclo de vida
    * **Mejoras de usabilidad en los SDK** de Python y TypeScript
    * **Más ejemplos listos para producción** de patrones de integración habituales
  </Accordion>

  <Accordion title="Gestión del contexto y memoria" description="Mejor gestión del contexto entre llamadas">
    Estamos abordando los límites de persistencia del contexto mejorando los flujos de trabajo orientados a la memoria.

    * **Gestión de estado con reconocimiento de sesión**
    * **Menor necesidad de unir el contexto manualmente** entre solicitudes
    * **Mayor control sobre flujos de trabajo conversacionales de larga duración**
  </Accordion>

  <Accordion title="Mejor manejo de errores" description="Resolución de problemas y recuperación más claras">
    Estamos mejorando la forma en que se notifican y diagnostican los errores en todas las API.

    * **Mensajes de error más útiles y accionables**
    * **Mejores guías de resolución en la documentación**
    * **Recomendaciones más claras sobre reintentos y backoff**
  </Accordion>

  <Accordion title="API de voz a voz" description="Interacciones de audio en tiempo real">
    Estamos desarrollando capacidades de interacción nativas por voz para experiencias en tiempo real.

    * **Entrada de voz directa y salida de audio en streaming**
    * **Compatibilidad con múltiples idiomas**
    * **Ciclos de conversación de baja latencia**
  </Accordion>

  <Accordion title="Consola de API exclusiva" description="Consola para desarrolladores independiente de la aplicación Perplexity">
    Estamos creando una consola de API dedicada: una interfaz independiente para desarrolladores, separada del sitio web de Perplexity. Será el centro principal para la gestión de API keys, la visibilidad del uso y los controles de equipo.

    * **Independiente de la aplicación de Perplexity**: creada específicamente para desarrolladores de API
    * **Gestión de API keys** con permisos granulares y rotación
    * **Visibilidad del uso y los costos** a nivel de key y de equipo
    * **Controles de organización** para el acceso y la colaboración del equipo
  </Accordion>

  <Accordion title="Panel de analíticas para desarrolladores" description="Información sobre el uso operativo">
    Estamos ampliando la visibilidad analítica para los equipos de API.

    * **Análisis de consultas y latencia**
    * **Monitoreo de tendencias de errores**
    * **Previsión de costos y uso**
  </Accordion>

  <Accordion title="Integración de herramientas financieras" description="Datos y análisis financieros">
    Estamos ampliando las capacidades de investigación financiera con un acceso estructurado más completo.

    * **Flujos de trabajo de mercado y de presentaciones regulatorias**
    * **Mejores controles para la recuperación de datos financieros**
    * **Más ejemplos de extremo a extremo para casos de uso de analistas**
  </Accordion>

  <Accordion title="Revisión integral de la documentación" description="Documentación y guías de mayor calidad">
    Las mejoras en la documentación siguen en curso.

    * **Guías más claras para elegir la API adecuada**
    * **Guías de implementación con recomendaciones más concretas**
    * **Ejemplos más fieles y orientados a producción**
  </Accordion>

  <Accordion title="Funciones de Labs a través de la API" description="Funciones experimentales">
    Tenemos previsto incorporar algunas funcionalidades experimentales a las versiones preliminares para desarrolladores.

    * **Canales de acceso anticipado a funcionalidades**
    * **Integraciones prototipo para recabar comentarios**
    * **Ciclos de retroalimentación más ágiles con desarrolladores para planificar la hoja de ruta**
  </Accordion>
</AccordionGroup>
