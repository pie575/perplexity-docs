La Perplexity API Platform está disponible como producto SaaS en AWS Marketplace. Los créditos de API se compran desde tu cuenta de AWS: se aplican a tu saldo de Perplexity API y sirven para todas las APIs (Router, Agent, Search, Sonar y Embeddings).

<Note>
  Esta ficha corresponde a la **API Platform** (Router API, Agent API, Search API, Sonar y Embeddings). Es un producto distinto de **Enterprise Pro**, que no incluye acceso a la API.
</Note>

<div id="why-subscribe-through-aws-marketplace">
  ## ¿Por qué suscribirse a través de AWS Marketplace?
</div>

Comprar a través de AWS Marketplace ofrece varias ventajas frente a la facturación directa:

* **Facturación consolidada de AWS**: los cargos aparecen en tu factura de AWS existente junto con los demás servicios de AWS, lo que simplifica los flujos de trabajo financieros y contables
* **Compras empresariales**: cumple los requisitos de adquisición de las organizaciones que exigen que las compras se realicen a través de AWS Marketplace; no hace falta establecer una relación con un proveedor aparte
* **Elegible para EDP**: las compras cuentan para tus compromisos del AWS Enterprise Discount Program (EDP)
* **Gestión de proveedores simplificada**: no hay que mantener un contrato ni un método de pago aparte; AWS se encarga de la facturación

<div id="pricing">
  ## Precios
</div>

La Perplexity API Platform en AWS Marketplace está disponible como **contrato de 1 mes** con créditos de la plataforma de API:

| Plan                                 |   Créditos   | Contrato |
| ------------------------------------ | :----------: | :------: |
| **Créditos de la plataforma de API** | Desde $1.000 |   1 mes  |

Los créditos están denominados 1:1 con el USD: 1 crédito = $1. Los créditos se abonan al saldo de tu cuenta y se van consumiendo a medida que realizas solicitudes a la API.

<Note>
  Todos los productos de la Perplexity API — Router API, Agent API, Search API, Sonar y Embeddings — consumen del mismo fondo compartido de créditos. No necesitas presupuestos separados por producto.

  Para conocer los precios por solicitud y por token, consulta la <u>[página de Precios](/es/docs/getting-started/pricing)</u>.
</Note>

<div id="how-to-subscribe">
  ## Cómo suscribirse
</div>

<Tip>
  Los créditos no caducan: el **contrato de 1 mes** se refiere al ciclo de facturación, no a un plazo de uso, por lo que los créditos no utilizados permanecen en tu saldo.
</Tip>

1. Visita la <u>[ficha de Perplexity API Platform](https://aws.amazon.com/marketplace/pp/prodview-fslss6gnscauq)</u> en AWS Marketplace
2. Haz clic en **View purchase options**
3. Elige el importe de créditos y haz clic en **Create contract**
4. Confirma la compra: AWS procesará la suscripción y te lo notificará por correo electrónico

<div id="getting-started-after-subscribing">
  ## Primeros pasos tras suscribirte
</div>

Una vez confirmada tu suscripción en AWS Marketplace:

1. **Inicia sesión o crea una cuenta** — ve a <u>[console.perplexity.ai](https://console.perplexity.ai)</u> e inicia sesión con tu cuenta de Perplexity (o crea una si aún no tienes)
2. **Vincula tu suscripción** — sigue las indicaciones de la consola para conectar tu compra de AWS Marketplace con tu cuenta de Perplexity; así los créditos adquiridos quedan asociados a tu proyecto
3. **Configura tu proyecto** — tus créditos están vinculados a un proyecto (el espacio de trabajo de tu organización en el API Portal). La persona que completa la configuración pasa a ser Admin, con acceso completo a la facturación, las API keys y las invitaciones de miembros. Otras personas pueden unirse como Admins (acceso completo) o Members (solo lectura). Consulta <u>[Proyectos y facturación](/es/docs/getting-started/projects)</u>.
4. **Genera una API key** — ve a API Keys en la consola para crear una clave para tu proyecto. Consulta <u>[Gestión de API keys](/es/docs/admin/api-key-management)</u>.
5. **Empieza a hacer solicitudes** — los créditos se aplican al saldo de tu proyecto y se comparten entre todos los productos (Router API, Agent API, Search API, Sonar, Embeddings). Puedes consultar el saldo restante y el uso en la consola en cualquier momento.

<div id="refund-policy">
  ## Política de reembolsos
</div>

Si necesitas cancelar tu suscripción, puedes solicitar un reembolso **dentro de los 14 días posteriores a la compra**, siempre que **no hayas utilizado ningún crédito**. Para solicitarlo, escribe a <u>[aws-api@perplexity.ai](mailto:aws-api@perplexity.ai)</u> indicando el ID de tu pedido de AWS Marketplace.

<Warning>
  No se ofrecen reembolsos una vez que se haya consumido algún crédito ni después de que haya transcurrido el plazo de 14 días.
</Warning>

<div id="support">

Si tienes preguntas sobre tu suscripción de AWS Marketplace, la facturación o el uso de la API, ponte en contacto con el equipo de Perplexity API:

**Correo electrónico:** <u>[support@clazar.io](mailto:support@clazar.io)</u>

Cuando nos escribas, incluye el ID de pedido de AWS Marketplace o el correo electrónico de tu cuenta para que podamos localizar tu suscripción rápidamente.
