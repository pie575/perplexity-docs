<div id="data-privacy-retention">
  ## Privacidad y retención de datos
</div>

<div id="zero-data-retention-policy">
  ### Política de cero retención de datos
</div>

Perplexity mantiene una estricta **política de cero retención de datos** para la API de Chat Completions. No conservamos los datos enviados a través de la API de Chat Completions ni utilizamos los datos de los clientes para entrenar nuestros modelos ni para ningún otro fin que no sea procesar la solicitud en curso.

<div id="data-we-collect">
  ### Datos que recopilamos
</div>

Los únicos datos que recopilamos a través de la API de Chat Completions son las métricas facturables esenciales necesarias para el funcionamiento del servicio:

* Cantidad de tokens procesados
* Modelo utilizado en cada solicitud
* Marca de tiempo y duración de la solicitud
* Identificación de la API key (con fines de facturación)

Estos metadatos de facturación no incluyen ningún contenido de tus prompts ni de las respuestas, ni ningún otro dato de usuario.
