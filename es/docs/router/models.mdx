<div id="overview">
  ## Descripción general
</div>

Todos los modelos que figuran a continuación están disponibles en ambos endpoints de Router — [Chat Completions](/es/api-reference/gateway-chat-completions-post) y [Messages](/es/api-reference/gateway-messages-post) — bajo el mismo id `creator/model-name`. Los precios se indican en USD por millón de tokens, y la facturación se realiza según las tarifas del modelo solicitado, independientemente de cómo se atienda la solicitud.

Para consultar el catálogo en tiempo real, usa [`GET /models`](/es/api-reference/gateway-models-get); las tablas siguientes muestran el catálogo actual.

<Note>
  La entrada almacenada en caché se factura por separado de la entrada nueva: las lecturas de caché se facturan a la tarifa reducida de cada modelo que se indica en la columna «lectura de caché», y las escrituras de caché, a la tarifa indicada (o a la tarifa de entrada cuando no se especifica una tarifa de escritura propia). Los tokens de razonamiento se facturan a la tarifa de salida.
</Note>

<div id="listing-models-programmatically">
  ## Listar modelos mediante código
</div>

```bash theme={null}
curl 'https://api.perplexity.ai/router/v1/models' \
  -H "Authorization: Bearer $PERPLEXITY_API_KEY" | jq
```

La respuesta enumera todos los modelos disponibles ordenados por id, incluidos los precios base por token de cada uno. Solicitar un modelo que no esté en el catálogo devuelve un `400` que indica el nombre del modelo no válido: el catálogo también funciona como lista de permitidos.
