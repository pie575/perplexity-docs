<div id="overview">
  ## Descripción general
</div>

Los SDK de Perplexity ofrecen un manejo de errores robusto, con tipos de excepción específicos para distintos escenarios de error. Esta guía explica cómo capturar y gestionar de forma adecuada los errores más comunes de la API.

<div id="common-error-types">
  ## Tipos de error comunes
</div>

Los SDK proporcionan tipos de excepción específicos para distintos escenarios de error:

* **APIConnectionError**: problemas de conexión de red
* **RateLimitError**: límite de solicitudes de la API superado
* **APIStatusError**: errores de estado HTTP (4xx, 5xx)
* **AuthenticationError**: API key no válida o problemas de autenticación
* **ValidationError**: parámetros de solicitud no válidos

<div id="basic-error-handling">
  ## Manejo básico de errores
</div>

Gestiona los errores comunes de la API con bloques try-catch:

<CodeGroup>
  ```python Python theme={null}
  import perplexity
  from perplexity import Perplexity

  client = Perplexity()

  try:
      search = client.search.create(query="OpenAI o-series reasoning model benchmarks")
      print(search.results)
  except perplexity.APIConnectionError as e:
      print("Falló la conexión de red")
      print(e.__cause__)
  except perplexity.RateLimitError as e:
      print("Límite de solicitudes superado; vuelve a intentarlo más tarde")
  except perplexity.APIStatusError as e:
      print(f"Error de la API: {e.status_code}")
      print(e.response)
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  try {
      const search = await client.search.create({ query: "OpenAI o-series reasoning model benchmarks" });
      console.log(search.results);
  } catch (error: any) {
      if (error.constructor.name === 'APIConnectionError') {
          console.log("Falló la conexión de red");
          console.log(error.cause);
      } else if (error.constructor.name === 'RateLimitError') {
          console.log("Límite de solicitudes superado; vuelve a intentarlo más tarde");
      } else if (error.constructor.name === 'APIStatusError') {
          console.log(`Error de la API: ${error.status}`);
          console.log(error.response);
      }
  }
  ```

<div id="exponential-backoff-for-rate-limits">
  ### Backoff exponencial para límites de solicitudes
</div>

Implementa una lógica de reintentos inteligente para los errores de límite de solicitudes:

<CodeGroup>
  ```python Python theme={null}
  import time
  import random
  import perplexity
  from perplexity import Perplexity

  def search_with_retry(client, query, max_retries=3):
      for attempt in range(max_retries):
          try:
              return client.search.create(query=query)
          except perplexity.RateLimitError:
              if attempt == max_retries - 1:
                  raise  # Volver a lanzar en el último intento
              
              # Backoff exponencial con jitter
              delay = (2 ** attempt) + random.uniform(0, 1)
              print(f"Rate limited. Retrying in {delay:.2f} seconds...")
              time.sleep(delay)
          except perplexity.APIConnectionError:
              if attempt == max_retries - 1:
                  raise
              
              # Espera más corta para errores de conexión
              delay = 1 + random.uniform(0, 1)
              print(f"Connection error. Retrying in {delay:.2f} seconds...")
              time.sleep(delay)

  # Uso
  client = Perplexity()
  result = search_with_retry(client, "artificial intelligence")
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  async function searchWithRetry(
      client: Perplexity, 
      query: string, 
      maxRetries: number = 3
  ) {
      for (let attempt = 0; attempt < maxRetries; attempt++) {
          try {
              return await client.search.create({ query });
          } catch (error: any) {
              if (attempt === maxRetries - 1) {
                  throw error; // Volver a lanzar en el último intento
              }

              if (error.constructor.name === 'RateLimitError') {
                  // Backoff exponencial con jitter
                  const delay = (2 ** attempt + Math.random()) * 1000;
                  console.log(`Rate limited. Retrying in ${delay}ms...`);
                  await new Promise(resolve => setTimeout(resolve, delay));
              } else if (error.constructor.name === 'APIConnectionError') {
                  // Espera más corta para errores de conexión
                  const delay = (1 + Math.random()) * 1000;
                  console.log(`Connection error. Retrying in ${delay}ms...`);
                  await new Promise(resolve => setTimeout(resolve, delay));
              } else {
                  throw error; // No reintentar otros errores
              }
          }
      }
  }

  // Uso
  const client = new Perplexity();
  const result = await searchWithRetry(client, "artificial intelligence");
  ```

  ### Contexto de errores y depuración

Extrae información detallada de los errores para depurarlos:

<CodeGroup>
  ```python Python theme={null}
  import perplexity
  from perplexity import Perplexity

  client = Perplexity()

  try:
      response = client.responses.create(
          preset="low",
          input="Explain how the 10-year US Treasury yield is determined and how it influences mortgage rates."
      )
  except perplexity.APIStatusError as e:
      print(f"Status Code: {e.status_code}")
      print(f"Error Type: {e.type}")
      print(f"Error Message: {e.message}")
      
      # Accede a la respuesta sin procesar para una depuración detallada
      if hasattr(e, 'response'):
          print(f"Raw Response: {e.response.text}")
          print(f"Request ID: {e.response.headers.get('X-Request-ID')}")
          
  except perplexity.ValidationError as e:
      print(f"Validation Error: {e}")
      # Gestiona los errores de validación de parámetros
      
  except Exception as e:
      print(f"Unexpected error: {type(e).__name__}: {e}")
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  try {
      const response = await client.responses.create({
          preset: "low",
          input: "Explain how the 10-year US Treasury yield is determined and how it influences mortgage rates."
      });
  } catch (error: any) {
      if (error.constructor.name === 'APIStatusError') {
          console.log(`Status Code: ${error.status}`);
          console.log(`Error Type: ${error.type}`);
          console.log(`Error Message: ${error.message}`);
          
          // Accede a la respuesta sin procesar para una depuración detallada
          if (error.response) {
              console.log(`Raw Response: ${await error.response.text()}`);
              console.log(`Request ID: ${error.response.headers.get('X-Request-ID')}`);
          }
      } else if (error.constructor.name === 'ValidationError') {
          console.log(`Validation Error: ${error.message}`);
          // Gestiona los errores de validación de parámetros
      } else {
          console.log(`Unexpected error: ${error.constructor.name}: ${error.message}`);
      }
  }
  ```

<div id="graceful-degradation">
  ### Degradación controlada
</div>

Implementa mecanismos de respaldo cuando fallen las llamadas a la API:

<CodeGroup>
  ```python Python theme={null}
  import perplexity
  from perplexity import Perplexity

  def get_ai_response(query, fallback_response="Lo siento, no estoy disponible temporalmente."):
      client = Perplexity()
      
      try:
          response = client.responses.create(
              preset="low",
              input=query
          )
          return response.output_text
          
      except perplexity.RateLimitError:
          return fallback_response
              
      except perplexity.APIConnectionError:
          # Problemas de red: devuelve la respuesta en caché o la de respaldo
          return fallback_response
          
      except Exception as e:
          print(f"Unexpected error: {e}")
          return fallback_response

  # Uso
  response = get_ai_response("What is machine learning?")
  print(response)
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  async function getAIResponse(
      query: string, 
      fallbackResponse: string = "Lo siento, no estoy disponible temporalmente."
  ): Promise<string> {
      const client = new Perplexity();
      
      try {
          const response = await client.responses.create({
              preset: "low",
              input: query
          });
          return response.output_text ?? fallbackResponse;
          
      } catch (error: any) {
          if (error.constructor.name === 'RateLimitError') {
              return fallbackResponse;
          } else if (error.constructor.name === 'APIConnectionError') {
              // Problemas de red: devuelve la respuesta en caché o la de respaldo
              return fallbackResponse;
          } else {
              console.log(`Unexpected error: ${error.message}`);
              return fallbackResponse;
          }
      }
  }

  // Uso
  const response = await getAIResponse("What is machine learning?");
  console.log(response);
  ```
</CodeGroup>

  ## Buenas prácticas

<Steps>
  <Step title="Gestione siempre los límites de tasa">
    La limitación de velocidad (rate limiting) es habitual al usar APIs. Implementa siempre una lógica de reintentos con retroceso exponencial.

    <Warning>
      No implementes bucles de reintento agresivos sin esperas: esto puede empeorar la limitación de velocidad.
    </Warning>
  </Step>

  <Step title="Registra los errores para su monitorización">
    Incluye un registro (logging) adecuado para monitorear los patrones de error y el estado de la API.

    <CodeGroup>
      ```python Python theme={null}
      import logging
      import perplexity
      from perplexity import Perplexity

      logging.basicConfig(level=logging.INFO)
      logger = logging.getLogger(__name__)

      client = Perplexity()

      try:
          result = client.search.create(query="discovery of penicillin by Alexander Fleming")
      except perplexity.APIStatusError as e:
          logger.error(f"API Error {e.status_code}: {e.message}", 
                      extra={'request_id': e.response.headers.get('X-Request-ID')})
      ```

      ```typescript TypeScript theme={null}
      import Perplexity from '@perplexity-ai/perplexity_ai';

      const client = new Perplexity();

      try {
          const result = await client.search.create({ query: "discovery of penicillin by Alexander Fleming" });
      } catch (error: any) {
          console.error(`API Error ${error.status}: ${error.message}`, {
              requestId: error.response?.headers.get('X-Request-ID')
          });
      }
      ```
