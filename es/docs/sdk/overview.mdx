<div id="overview">
  ## Descripción general
</div>

Los SDK oficiales de Perplexity facilitan el acceso a las APIs de Perplexity desde aplicaciones en Python 3.8+ y Node.js. Ambos SDK incluyen definiciones de tipos para todos los parámetros de solicitud y los campos de respuesta, además de clientes síncronos y asíncronos.

Accede a cuatro APIs: **Agent API**, para modelos de terceros con herramientas de búsqueda web y presets; **Search**, para resultados de búsqueda web ordenados por relevancia; **Sonar**, para respuestas de IA fundamentadas en la web; y **Embeddings**, para generar embeddings de texto.

<div id="installation">
  ## Instalación
</div>

Instala el SDK del lenguaje que prefieras:

<CodeGroup>
  ```bash Python theme={null}
  pip install perplexityai
  ```

  ```bash TypeScript theme={null}
  npm install @perplexity-ai/perplexity_ai
  ```
</CodeGroup>

<div id="authentication">
  ## Autenticación
</div>

<Card title="Obtén tu API key de Perplexity" icon="key" arrow="True" horizontal="True" iconType="solid" cta="Haz clic aquí" href="https://console.perplexity.ai/project/keys">
  Genera una nueva clave en la página **API Keys** de la API Console.
</Card>

Una vez generada la clave, defínela como variable de entorno en tu terminal:

<Tabs>
  <Tab title="Windows">
    ```bash theme={null}
    setx PERPLEXITY_API_KEY "your_api_key_here"
    ```
  </Tab>

  <Tab title="MacOS/Linux">
    ```bash theme={null}
    export PERPLEXITY_API_KEY="your_api_key_here"
    ```
  </Tab>
</Tabs>

<div id="using-environment-variables">
  ### Uso de variables de entorno
</div>

Puedes usar la variable de entorno directamente:

<CodeGroup>
  ```python Python theme={null}
  import os
  from perplexity import Perplexity

  client = Perplexity() # Usa automáticamente PERPLEXITY_API_KEY
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity({
    apiKey: process.env['PERPLEXITY_API_KEY'], // Este es el valor predeterminado y puede omitirse
  });
  ```
</CodeGroup>

O usa [python-dotenv](https://pypi.org/project/python-dotenv/) (Python) o [dotenv](https://www.npmjs.com/package/dotenv) (Node.js) para cargar la variable de entorno desde un archivo `.env`:

<CodeGroup>
  ```python Python theme={null}
  import os
  from dotenv import load_dotenv
  from perplexity import Perplexity

  load_dotenv()

  client = Perplexity() # Usa PERPLEXITY_API_KEY del archivo .env
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';
  import dotenv from 'dotenv';

  dotenv.config();

  const client = new Perplexity(); // Usa PERPLEXITY_API_KEY del archivo .env
  ```
</CodeGroup>
