<div id="what-is-a-project">
  ## ¿Qué es un proyecto?
</div>

Un **proyecto** es el espacio de trabajo de tu organización en el Portal de la Perplexity API. Te permite:

* **Gestionar la facturación** y los métodos de pago del uso de la API
* **Crear y controlar API keys** para acceder a la Perplexity API
* **Invitar a miembros del equipo** y controlar sus permisos (opcional)
* **Supervisar el uso y los costos** de todas tus API keys

<div id="prerequisites">
  ## Requisitos previos
</div>

Antes de comenzar, asegúrate de contar con:

* Una cuenta de Perplexity (regístrate en [perplexity.ai](https://perplexity.ai))
* **Permisos de administrador** para la facturación y la gestión de API keys
* Una **tarjeta de crédito** lista para configurar el pago (al principio no se te cobrará nada)

<Note>
  Si te unes a un equipo existente, necesitarás una invitación de un administrador. Ponte en contacto con el responsable de tu equipo para obtener acceso.
</Note>

<div id="accessing-the-api-portal">
  ## Acceso al Portal de la Perplexity API
</div>

Ve a [console.perplexity.ai](https://console.perplexity.ai) para acceder a tu proyecto. La barra lateral izquierda se divide en dos secciones:

* **Project**: Settings, Members, Facturación, API keys, Files
* **API Playground**: Search API, Agent API

<div id="billing-and-payment-methods">
  ## Facturación y métodos de pago
</div>

<div id="how-billing-works">
  ### Cómo funciona la facturación
</div>

La Perplexity API utiliza un **sistema de facturación basado en créditos**:

* Los **créditos** se compran por adelantado y se usan para las llamadas a la API
* **Cada modelo** consume una cantidad distinta de créditos por solicitud
* **El uso se cobra** según los tokens procesados y las consultas de búsqueda realizadas
* Se puede habilitar la **recarga automática** para evitar interrupciones del servicio

<Info>
  Consulta nuestra [página de precios](./pricing) para obtener información detallada de costos por modelo y tipo de uso.
</Info>

<div id="setting-up-payment">
  ### Configurar el pago
</div>

<Card title="Acceder al panel de facturación" icon="credit-card" arrow="True" horizontal="True" iconType="solid" cta="Ir a Facturación" href="https://console.perplexity.ai/project/billing">
  Ve directamente al panel de facturación de la API para gestionar métodos de pago, consultar el uso y ajustar la configuración de facturación.
</Card>

<Steps>
  <Step title="Ir a Facturación">
    Haz clic en **Facturación** en la barra lateral izquierda. Esta página muestra tu saldo de créditos, el método de pago, el gráfico de uso y el desglose de facturación.

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_billing.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=6d6e71d28dcf4d39faa4fc8b14c6ad48" alt="Panel de facturación de la API" />
    </Frame>
  </Step>

  <Step title="Añadir un método de pago">
    Haz clic en **Add payment method** e introduce los datos de tu tarjeta de crédito. El pago se gestiona a través de Stripe; también puedes hacer clic en **Manage ↗** para acceder directamente al portal de Stripe.

    <Note>
      Añadir un método de pago no generará ningún cargo en tu tarjeta de crédito. Solo se guarda la información de pago para el uso futuro de la API.
    </Note>
  </Step>

  <Step title="Configurar la recarga automática (recomendado)">
    Activa la recarga automática de créditos haciendo clic en **Change preferences**, junto a **Auto reload**.

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_topup.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=3aa16c75b424292781b61005b1ab32df" alt="Panel de facturación de la API" />
    </Frame>

    <Warning>
      Si te quedas sin créditos, tus API keys se bloquearán hasta que recargues tu saldo. La recarga automática evita esto añadiendo créditos en cuanto tu saldo cae por debajo de un umbral determinado.
    </Warning>
  </Step>
</Steps>

<div id="credit-balance">
  ### Saldo de créditos
</div>

La página de Facturación muestra de forma destacada tu **saldo de créditos restante** en la parte superior. Puedes comprar créditos adicionales en cualquier momento mediante el enlace **Buy more credits**.

Aquí también se muestra tu **nivel de uso** actual: haz clic en **Learn more ↗** para conocer los umbrales y beneficios de cada nivel.

<div id="managing-api-keys">
  ## Gestión de API keys
</div>

<div id="what-are-api-keys">
  ### ¿Qué son las API keys?
</div>

Las API keys son tus credenciales para acceder a la Perplexity API. Cada key:

* **Autentica tus solicitudes** a la Perplexity API
* **Registra el uso** con fines de atribución
* **Se puede revocar** por motivos de seguridad
* **Debe mantenerse segura** y no compartirse nunca públicamente

<Info>
  Debes incluir tu API key en el encabezado Authorization de cada solicitud a la API: `Authorization: Bearer $PERPLEXITY_API_KEY`
</Info>

<div id="creating-an-api-key">
  ### Crear una API key
</div>

<Steps>
  <Step title="Ir a API keys">
    Haz clic en **API keys** en la barra lateral izquierda.

    <Frame>

    </Frame>
  </Step>

  <Step title="Generar una nueva key">
    Haz clic en **+ Generate API Key** para crear una nueva API key.

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_api_keys_new.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=ca3c652417faa90238d299ddc72b0249" alt="API Keys" />
    </Frame>
  </Step>
</Steps>

<Warning>
  Las API keys son credenciales sensibles. Nunca las expongas en código del lado del cliente ni las compartas en repositorios públicos.
</Warning>

<div id="adding-and-managing-members">
  ## Agregar y administrar miembros
</div>

Los administradores pueden invitar a miembros del equipo a la organización con roles específicos: **Admin** o **Member**.

<div id="adding-a-member">
  ### Añadir un miembro
</div>

<Steps>
  <Step title="Ir a Members">
    Haz clic en **Members** en la barra lateral izquierda. Esta página muestra los miembros actuales de tu equipo y sus roles.
  </Step>

  <Frame>
    <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_members.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=78f439f1a1567dc49c7ff06c4033b3af" alt="Members" />
  </Frame>

  <Step title="Iniciar la invitación del miembro">
    Haz clic en **+ Add Member**. Introduce la dirección de correo electrónico del usuario y haz clic en **Invite**.

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_add_member.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=c4fab8e720fb1db15206846289399a3a" alt="Add Member" />
    </Frame>
  </Step>

  <Step title="El miembro recibe la invitación">
    El usuario invitado recibirá un correo electrónico con un enlace para unirse a tu proyecto.

    <Check>
      Cuando la acepte, aparecerá en tu lista de miembros con el rol que le hayas asignado.
    </Check>
  </Step>
</Steps>

<div id="filtering-members-by-role">
  ### Filtrar miembros por rol
</div>

Usa el menú desplegable para filtrar por rol la lista de miembros de tu equipo.

<div id="roles">
  ### Roles
</div>

* **Admin**: acceso total para invitar o eliminar miembros, gestionar la facturación y consultar los datos de uso.
* **Member**: puede consultar el uso y los límites de la cuenta, pero no puede modificar la configuración.

<Warning>
  Solo los administradores pueden modificar la facturación y los permisos de los miembros.
</Warning>

<div id="viewing-usage-metrics">
  ## Visualización de métricas de uso
</div>

Todos los miembros pueden monitorear el uso de la API directamente desde la página **Facturación** de la consola.

<Frame>
  <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_usage_metrics.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=80e6246097068cf8854370c98a9de338" alt="Usage Metrics" />
</Frame>

El gráfico **Usage** permite hacer seguimiento de la actividad a lo largo del tiempo con los siguientes filtros:

* **Selector de métrica**: elige entre Chat Completions API Requests, Input Tokens, Output Tokens, Citation Tokens, Reasoning Tokens, Deep Research Requests Count, Search API Requests Count o Pro Search API Requests Count
* **Rango de tiempo**: filtra por Last 7 Days, Last 30 Days o un rango personalizado

Debajo del gráfico, la tabla **Billing breakdown** muestra un desglose por modelo de la cantidad de uso, la tarifa y el costo, lo que ofrece una visión clara del gasto por producto.

<Check>
  Las métricas de uso te ayudan a monitorear la actividad de la API y a optimizar costos o rendimiento.
</Check>

</div>

Debajo del gráfico de uso y del desglose de facturación en la página **Facturación**, encontrarás tu **Invoice history**: un registro de todas las facturas anteriores con su fecha, estado y costo.

  <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_invoices.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=4df3bb3d07fef0c321d8b82272651c14" alt="Invoice History" />
