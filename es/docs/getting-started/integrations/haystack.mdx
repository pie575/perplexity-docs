<div id="overview">
  ## Descripción general
</div>

El paquete `perplexity-haystack` ofrece componentes de Haystack para la Agent API, la Embeddings API y la Search API con fundamentación de Perplexity, de modo que puedas crear pipelines agénticos y de generación aumentada por recuperación que combinen chat, embeddings y búsqueda web en vivo.

<Info>
  **Haystack** es un framework de Python de código abierto creado por [deepset](https://deepset.ai) para desarrollar aplicaciones LLM listas para producción, incluidos pipelines RAG y flujos de trabajo agénticos. Más información en [haystack.deepset.ai](https://haystack.deepset.ai).
</Info>

La integración incluye:

* **PerplexityChatGenerator**: generación de chat mediante la [Agent API](/es/docs/agent-api/quickstart).
* **PerplexityTextEmbedder** y **PerplexityDocumentEmbedder**: embeddings mediante la [Embeddings API](/es/docs/embeddings/quickstart).
* **PerplexityWebSearch**: resultados web fundamentados y ordenados por relevancia mediante la [Search API](/es/docs/search/quickstart).

<div id="quick-start-chat-agent-api">
  ## Inicio rápido: Chat (Agent API)
</div>

`PerplexityChatGenerator` funciona con la Agent API de Perplexity y usa `openai/gpt-5.4` de forma predeterminada.

```python theme={null}
import os

from haystack.dataclasses import ChatMessage
from haystack_integrations.components.generators.perplexity import PerplexityChatGenerator

os.environ["PERPLEXITY_API_KEY"] = "your_api_key_here"

client = PerplexityChatGenerator()
response = client.run(
    messages=[ChatMessage.from_user("What are Agentic Pipelines? Be brief.")]
)

print(response["replies"])
```

<div id="selecting-a-model">
  ### Selección de un modelo
</div>

Puedes elegir cualquiera de los modelos compatibles con la Agent API mediante el parámetro `model`:

```python theme={null}
client = PerplexityChatGenerator(model="anthropic/claude-sonnet-4-6")
```

Entre los modelos compatibles se incluyen `openai/gpt-5.4` (predeterminado), `openai/gpt-5.5`, `anthropic/claude-sonnet-4-6`, `xai/grok-4.5` y `google/gemini-3-flash-preview`. Consulta la [página de modelos de la Agent API](/es/docs/agent-api/models) para ver la lista completa.

<div id="quick-start-embeddings">
  ## Inicio rápido: Embeddings
</div>

Genera el embedding de una sola consulta con `PerplexityTextEmbedder`:

```python theme={null}
import os

from haystack_integrations.components.embedders.perplexity import PerplexityTextEmbedder

os.environ["PERPLEXITY_API_KEY"] = "your_api_key_here"

embedder = PerplexityTextEmbedder()
response = embedder.run(text="What is Haystack by deepset?")

print(response["embedding"])
```

Genera embeddings de una lista de documentos con `PerplexityDocumentEmbedder`:

```python theme={null}
from haystack import Document
from haystack_integrations.components.embedders.perplexity import PerplexityDocumentEmbedder

docs = [Document(content="What is Haystack by deepset?")]
result = PerplexityDocumentEmbedder().run(documents=docs)

print(result["documents"][0].embedding)
```

Ambos generadores de embeddings usan `pplx-embed-v1-0.6b` de forma predeterminada. También está disponible el modelo más grande, `pplx-embed-v1-4b`: puedes seleccionarlo mediante el parámetro `model`.

<div id="quick-start-web-search-search-api">
  ## Inicio rápido: búsqueda web (Search API)
</div>

Usa `PerplexityWebSearch` para obtener resultados web ordenados por relevancia y fundamentados en fuentes dentro de un pipeline de Haystack:

```python theme={null}
import os

from haystack.utils import Secret
from haystack_integrations.components.websearch.perplexity import PerplexityWebSearch

os.environ["PERPLEXITY_API_KEY"] = "your_api_key_here"

websearch = PerplexityWebSearch(
    api_key=Secret.from_env_var("PERPLEXITY_API_KEY"),
    top_k=5,
)
result = websearch.run(query="What is Haystack by deepset?")

documents = result["documents"]
links = result["links"]

print(documents)
print(links)
```
