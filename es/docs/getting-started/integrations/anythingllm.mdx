<div id="overview">
  ## Descripción general
</div>

[AnythingLLM](https://anythingllm.com) es una aplicación de productividad con IA todo en uno que convierte cualquier documento, recurso o contenido en contexto para chats impulsados por LLM. Admite despliegues tanto de escritorio como autoalojados y funciona con decenas de proveedores de LLM, incluido Perplexity como proveedor en la nube de primer nivel, lo que da a cada espacio de trabajo acceso a respuestas fundamentadas en la web y con citas.

<Info>
  **AnythingLLM** lo desarrolla y mantiene Mintplex Labs. Permite configurar el LLM por espacio de trabajo, de modo que puedes usar Perplexity en un espacio de trabajo y otro proveedor distinto en otro. Más información en [anythingllm.com](https://anythingllm.com).
</Info>

<div id="setup">
  ## Configuración
</div>

<Steps>
  <Step title="Obtén tu API key">
    Genera una API key de Perplexity desde el [portal de API](https://console.perplexity.ai/project/keys).

    <Card title="Obtener API key" icon="key" href="https://console.perplexity.ai/project/keys">
      Genera tu API key de Perplexity.
    </Card>
  </Step>

  <Step title="Abre la configuración del LLM">
    En AnythingLLM, ve a **Settings → LLM Preference**.
  </Step>

  <Step title="Selecciona Perplexity AI">
    Elige **Perplexity AI** en la lista de proveedores y pega tu API key.
  </Step>

  <Step title="Elige un modelo">
    Una vez introducida la key, el menú desplegable **Chat Model Selection** se rellena automáticamente con los modelos de Perplexity disponibles. Selecciona el modelo que quieras (por ejemplo, `sonar-pro`) y guarda los cambios.
  </Step>
</Steps>

<div id="system-vs-workspace-models">
  ## Modelos de sistema frente a modelos de espacio de trabajo
</div>

AnythingLLM te permite definir el ámbito de la elección del LLM en dos niveles:

* **LLM del sistema**: el proveedor predeterminado que se usa en todos los espacios de trabajo y agentes.
* **LLM del espacio de trabajo**: una anulación específica de cada espacio de trabajo que tiene prioridad al chatear dentro de él.

Puedes combinar proveedores con total libertad. Por ejemplo, define Anthropic como predeterminado del sistema y usa Perplexity en un espacio de trabajo concreto en el que necesites fundamentación web en tiempo real para conversaciones con un gran componente de investigación.

Para anularlo en un espacio de trabajo: abre el espacio de trabajo, ve a **Workspace Settings → Chat Settings → Workspace LLM Provider** y selecciona **Perplexity AI** con el modelo que quieras.

<div id="available-models">
  ## Modelos disponibles
</div>

Todos los modelos de Perplexity compatibles con la API están disponibles para los usuarios de AnythingLLM: el menú desplegable de modelos se completa dinámicamente en cuanto se valida tu API key. Modelos recomendados:

* `sonar` — chat rápido y económico fundamentado en la web
* `sonar-pro` — razonamiento avanzado con mayor profundidad de citas
* `sonar-reasoning-pro` — razonamiento en varios pasos con búsqueda

Consulta la lista completa de [modelos y capacidades de Perplexity](/es/docs/sonar/models).

<div id="use-cases">
  ## Casos de uso
</div>

Combinar Perplexity con AnythingLLM te ofrece:

* **Respuestas web en tiempo real dentro de flujos de trabajo documentales**: tu espacio de trabajo puede responder preguntas sobre los PDF que subas y sobre la web abierta en el mismo chat.
* **Recuperación respaldada por citas**: Perplexity devuelve las URL de las fuentes, que puedes auditar junto con tu contexto de recuperación aumentada.
* **Alternativa sin RAG para temas de actualidad**: cuando los documentos no contienen la respuesta, el modelo puede recurrir automáticamente al contexto web en tiempo real.

<div id="agent-configuration">
  ## Configuración del agente
</div>

Cuando uses los [agentes de IA](https://docs.anythingllm.com/agent/setup) de AnythingLLM, puedes configurar Perplexity como el LLM del agente desde el menú **Agent Configuration** del espacio de trabajo. Esto resulta útil para agentes que necesitan combinar la investigación web con capacidades como la navegación web, las preguntas y respuestas sobre documentos o las llamadas a APIs externas.
