<div id="overview">
  ## Descripción general
</div>

[Agno](https://docs.agno.com) es un framework de Python de código abierto para crear agentes, equipos y flujos de trabajo. Conéctalo a la [Agent API](/es/docs/agent-api/quickstart) de Perplexity mediante la clase de modelo de Agno compatible con OpenAI Responses.

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
pip install agno openai
```

<div id="api-key-setup">
  ## Configuración de la API key
</div>

Define tu API key de Perplexity como variable de entorno:

```bash theme={null}
export PERPLEXITY_API_KEY="your_api_key_here"
```

<Card title="Obtener API key" icon="key" href="https://console.perplexity.ai/project/keys">
  Genera tu API key de Perplexity desde el portal de API.
</Card>

<div id="quick-start">
  ## Inicio rápido
</div>

Usa `OpenAIResponses` con la URL base de la Agent API y cualquier modelo compatible de la Agent API. Pasa un [preset](/es/docs/agent-api/presets) de investigación mediante `extra_body` para que las respuestas se fundamenten en resultados web en tiempo real:

```python theme={null}
import os

from agno.agent import Agent
from agno.models.openai import OpenAIResponses

agent = Agent(
    model=OpenAIResponses(
        id="openai/gpt-5.6-luna",
        base_url="https://api.perplexity.ai/v1",
        api_key=os.environ["PERPLEXITY_API_KEY"],
        extra_body={"preset": "medium"},
    ),
    markdown=True,
)

agent.print_response(
    "What are the latest breakthroughs in fusion energy this year?",
    stream=True,
)
```

Sustituye `id` por cualquier [modelo de la Agent API](/es/docs/agent-api/models) para enrutar modelos de terceros a través de Perplexity. La Agent API también ofrece [presets](/es/docs/agent-api/presets) respaldados por investigación y [herramientas](/es/docs/agent-api/tools) integradas adicionales.
