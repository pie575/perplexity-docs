<div id="overview">
  ## Descripción general
</div>

El `SearchToolkit` de CAMEL-AI incluye un método `search_perplexity` que encapsula la [Search API de Perplexity](/es/docs/search/quickstart) como una herramienta nativa de CAMEL. La herramienta devuelve resultados web ordenados por relevancia —título, URL, fragmento y fecha—, de modo que el `ChatAgent` que la invoca puede fundamentar sus respuestas en fuentes actualizadas y citables.

<Info>
  **CAMEL-AI** es un framework de código abierto para crear sistemas multiagente comunicativos. Más información en [camel-ai.org](https://www.camel-ai.org).
</Info>

<div id="quick-start">
  ## Inicio rápido
</div>

Registra `search_perplexity` como herramienta en un `ChatAgent`:

```python theme={null}
from camel.agents import ChatAgent
from camel.toolkits import FunctionTool, SearchToolkit

agent = ChatAgent(
    system_message=(
        "You are a helpful assistant that can use the Perplexity "
        "search engine to answer questions."
    ),
    tools=[FunctionTool(SearchToolkit().search_perplexity)],
)

response = agent.step(
    input_message="What are the latest developments in multi-agent AI systems?",
    response_format=None,
)
print(response.msgs[0].content)
```

La herramienta llama internamente a `POST https://api.perplexity.ai/search` y devuelve la respuesta sin procesar de la API para que el agente pueda elegir qué resultados citar.

<div id="configuration">
  ## Configuración
</div>

Todos los parámetros de la Search API se admiten directamente en `search_perplexity`:

```python theme={null}
from camel.toolkits import SearchToolkit

toolkit = SearchToolkit()

results = toolkit.search_perplexity(
    query="AI safety research",
    max_results=5,
    max_tokens_per_page=512,
    country="US",
    search_recency_filter="week",                         # hour | day | week | month | year
    search_domain_filter=["arxiv.org", "-medium.com"],   # anteponer '-' para excluir
    search_language_filter=["en"],
)
```

También puedes pasar una lista de consultas para realizar búsquedas por lotes, o usar `extra_params` para enviar cualquier campo adicional de la Search API que todavía no sea un argumento de primer nivel:

```python theme={null}
results = toolkit.search_perplexity(
    query=["NVIDIA earnings", "AMD earnings"],
    max_results=3,
    extra_params={
        "search_after_date_filter": "1/1/2026",
        "search_before_date_filter": "5/1/2026",
    },
)
```

<div id="response-shape">
  ## Forma de la respuesta
</div>

`search_perplexity` devuelve la respuesta sin procesar de la Search API de Perplexity como un `Dict[str, Any]`. Si la llamada tiene éxito, incluye una lista `results` junto con `id` y `server_time`:

```python theme={null}
{
    "id": "...",
    "server_time": "...",
    "results": [
        {
            "title": "...",
            "url": "...",
            "snippet": "...",
            "date": "...",          # puede estar presente
            "last_updated": "...",  # puede estar presente
        },
        # ...
    ],
}
```

En caso de fallo, la respuesta es un diccionario con una clave `error` que describe el problema (API key ausente, error HTTP o excepción en la solicitud).
