<div id="router-api-pricing">
  ## Precios de la Router API
</div>

El uso de la Router API se factura por token según las tarifas publicadas de cada modelo: no hay cargos por solicitud. Cada modelo tiene sus propias tarifas de entrada y de salida; las lecturas de caché se facturan a la tarifa reducida de lectura de caché del modelo y los tokens de razonamiento, a la tarifa de salida. La facturación siempre se aplica según las tarifas del modelo solicitado, sin importar cómo se atienda la solicitud.

Consulta [Models y precios de Router](/es/docs/router/models) para ver la tabla completa de tarifas por modelo, incluidas las tarifas de escritura en caché y los precios de contexto largo.

<div id="agent-api-pricing">
  ## Precios de la Agent API
</div>

La Agent API brinda acceso a modelos de terceros de proveedores como OpenAI, Anthropic, Google, xAI, Z.AI, Moonshot AI y NVIDIA con **precios transparentes basados en tokens**, a las tarifas directas de cada proveedor y sin recargos.

<div id="model-pricing">
  ### Precios de los modelos
</div>

Los precios de la Agent API varían según el proveedor y el modelo, y cada proveedor ofrece varios modelos con distintos precios.

<Card title="Ver los precios completos de los modelos de terceros" icon="table" href="/es/docs/agent-api/models">
  Consulta el desglose completo de precios de todos los modelos disponibles de OpenAI, Anthropic, Google, xAI, Z.AI, Moonshot AI y NVIDIA, incluidas las tarifas de caché y los enlaces a la documentación de cada proveedor, en la [página de modelos de la Agent API](/es/docs/agent-api/models).
</Card>

<div id="tool-pricing">
  ### Precios de las herramientas
</div>

Al usar herramientas con la Agent API:

| Herramienta          |         Precio         | Descripción                                                                                                                                                                                                                                                                                                                                     |
| -------------------- | :--------------------: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`web_search`**     | $0,0025 por invocación | Realiza búsquedas web para obtener información actualizada                                                                                                                                                                                                                                                                                      |
| **`fetch_url`**      | $0,0005 por invocación | Obtiene y extrae el contenido de URL específicas                                                                                                                                                                                                                                                                                                |
| **`people_search`**  |  $0,005 por invocación | Busca profesionales, empleados y personas. $5 por cada 1.000 invocaciones de la herramienta                                                                                                                                                                                                                                                     |
| **`finance_search`** |  $0,005 por invocación | Recupera datos financieros e información de mercado. $5 por cada 1.000 invocaciones de la herramienta                                                                                                                                                                                                                                           |
| **`sandbox`**        |    $0,03 por sesión    | Contenedor aislado para ejecutar código durante una solicitud de la Agent API. A efectos de facturación, una sesión abarca hasta 20 minutos de uso activo: es la ventana de facturación, no un límite de ejecución. Las consultas de búsqueda del SDK realizadas desde el sandbox se facturan a $0,0025 por solicitud (igual que `web_search`). |

<Note>
  La mayoría de los costos de las herramientas se cobran por invocación. `sandbox` se factura por sesión de contenedor —una ventana de facturación de 20 minutos por contenedor, no un límite de ejecución— más cada consulta de búsqueda del SDK realizada desde su interior. Los costos de las herramientas son independientes de los costos de tokens del modelo.
</Note>

<div id="search-api-pricing">
  ## Precios de la Search API
</div>

| API            | Precio por 1K solicitudes | Descripción                                                   |
| -------------- | :-----------------------: | ------------------------------------------------------------- |
| **Search API** |           $5.00           | Resultados de búsqueda web sin procesar con filtrado avanzado |

<Note>
  **Unidad de facturación:** la Search API cobra por cada solicitud `POST /search` correcta, no por cada consulta incluida en ella. Una solicitud correcta que contenga un arreglo de hasta cinco consultas equivale a una unidad de facturación. No se facturan las solicitudes inválidas, las rechazadas por límite de tasa ni los fallos en servicios upstream. Una respuesta correcta se factura aunque no devuelva resultados. No se aplican cargos adicionales por tokens.
</Note>

  <Tab title="Precios por solicitud">
    <div id="request-pricing-by-search-context-size">
      ## Precios por solicitud según el tamaño del contexto de búsqueda
    </div>

    El **contexto de búsqueda** determina cuánta información web se recupera. A mayor contexto, resultados más completos. La siguiente tabla muestra la tarifa por solicitud de cada modelo por cada **1000 solicitudes**.

    | Modelo                  | Contexto pequeño | Contexto medio | Contexto grande |
    | ----------------------- | :--------------: | :------------: | :-------------: |
    | **Sonar**               |        $5        |       $8       |       $12       |
    | **Sonar Pro**           |        $6        |       $10      |       $14       |
    | **Sonar Reasoning Pro** |        $6        |       $10      |       $14       |

    <Note>
      * **Low**: (predeterminado) el más rápido y económico
      * **Medium**: equilibrio entre costo y calidad
      * **High**: máxima profundidad de búsqueda, ideal para investigación

      [Más información sobre el contexto de búsqueda →](https://docs.perplexity.ai/docs/sonar/filters#context-size-control)
    </Note>
  </Tab>

  <Tab title="Precios de Pro Search">
    <div id="pro-search-pricing-pro-search-for-sonar-pro">
      ## Precios de Pro Search (Pro Search para Sonar Pro)
    </div>

    **Pro Search** amplía las capacidades de Sonar Pro con uso automatizado de herramientas y razonamiento de varios pasos. Cuando está habilitado, el modelo puede realizar múltiples búsquedas web y obtener el contenido de URL para responder consultas complejas. [Más información sobre Pro Search aquí](/es/docs/sonar/pro-search/quickstart).

    <Info>
      Pro Search requiere `stream: true` y se habilita mediante el parámetro `search_type` en `web_search_options`.
    </Info>

    <div id="search-type-options">
      ### Opciones de tipo de búsqueda
    </div>

    | Tipo de búsqueda | Descripción                                                  | Tarifa por solicitud (por 1K) |
    | ---------------- | ------------------------------------------------------------ | :---------------------------: |
    | **`fast`**       | (predeterminado) Comportamiento estándar de Sonar Pro        |         $6 / $10 / $14        |
    | **`pro`**        | Uso de herramientas en varios pasos para consultas complejas |        $14 / $18 / $22        |
    | **`auto`**       | Clasificación automática según la complejidad de la consulta |  Varía según la clasificación |

    <Note>
      Las tarifas por solicitud varían según el tamaño del contexto de búsqueda (Low / Medium / High). Los precios por token son los mismos que los de Sonar Pro estándar ($3 por 1M de entrada, $15 por 1M de salida).
    </Note>

<AccordionGroup>
  <Accordion title="Glosario de tokens y costos">
    <div id="input-tokens">
      ### Tokens de entrada
    </div>

    Cantidad de tokens del prompt o mensaje que envías a la API. Incluye:

    * Tu pregunta o instrucción
    * El contexto o los ejemplos que proporciones
    * Los mensajes de sistema y el formato

    **Ejemplo:** «What is the weather in New York?» = ~8 tokens de entrada

    <div id="output-tokens">
      ### Tokens de salida
    </div>

    Cantidad de tokens de la respuesta de la API. Incluye:

    * La respuesta o el contenido generado
    * Las explicaciones o el contexto adicional
    * Los resultados de búsqueda y las referencias

    **Ejemplo:** «The weather in New York is currently sunny with a temperature of 72°F.» = ~15 tokens de salida

    <div id="citation-tokens">
      ### Tokens de citas
    </div>

    Tokens utilizados específicamente para generar resultados de búsqueda y referencias en las respuestas. Solo aplica al modelo **Sonar Deep Research**.

    **Ejemplo:** Incluir enlaces a fuentes, números de referencia e información bibliográfica

    <div id="search-context-size-vs-context-window">
      ### Tamaño del contexto de búsqueda vs. ventana de contexto
    </div>

    El **tamaño del contexto de búsqueda** *no* es lo mismo que la **ventana de contexto**.

    * **Tamaño del contexto de búsqueda**: cuánta información web se recupera durante la búsqueda (afecta al precio de la solicitud)
    * **Ventana de contexto**: número máximo de tokens que el modelo puede procesar en una sola solicitud (afecta a los límites de tokens)

    <div id="search-queries">
      ### Consultas de búsqueda
    </div>

    Número de búsquedas individuales que realiza **Sonar Deep Research** al procesar la consulta. Es algo independiente de tu consulta inicial.

    * El modelo determina automáticamente cuántas búsquedas hacen falta
    * No puedes controlar el número exacto de consultas de búsqueda
    * El parámetro `reasoning_effort` influye en la cantidad de búsquedas realizadas
    * Solo aplica al modelo **Sonar Deep Research**

    <div id="reasoning-tokens">
      ### Tokens de razonamiento
    </div>

    Tokens utilizados para el razonamiento lógico paso a paso y la resolución de problemas. Solo aplica al modelo **Sonar Deep Research**.

    **Ejemplo:** Descomponer un problema matemático complejo en pasos secuenciales con explicaciones

    <Info>
      **Cálculo de tokens:** 1 token ≈ 4 caracteres en texto en inglés. El conteo exacto puede variar según el idioma y la complejidad del contenido.
    </Info>
  </Accordion>
</AccordionGroup>
