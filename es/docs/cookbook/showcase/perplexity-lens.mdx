**Perplexity Lens** es una potente extensión de navegador que transforma tu experiencia de navegación: aporta información basada en IA con Perplexity AI y crea un grafo de conocimiento personalizado que conecta visualmente los conceptos que encuentras en línea.

<div id="features">
  ## Funcionalidades
</div>

* **Selección inteligente de texto** con explicaciones generadas por IA sobre el texto seleccionado
* **Resumen de páginas web** para obtener vistas generales concisas e instantáneas de páginas completas
* **Información contextual con RAG** que emplea generación aumentada por recuperación para aportar contexto y significados detallados
* **Visualización de grafos de conocimiento** con grafos interactivos de D3.js que muestran las conexiones entre conceptos
* **Compartición pública** con generación de URL para compartir grafos con otras personas
* **Autenticación de usuarios** mediante Firebase para un acceso seguro
* **Almacenamiento dual** con IndexedDB local y almacenamiento en la nube de Firebase
* **Interfaz adaptable** plenamente funcional en todos los dispositivos

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js v14+ y npm v6+
* Google Chrome o un navegador compatible
* Cuenta de Firebase para la funcionalidad en la nube
* Firebase CLI (`npm install -g firebase-tools`)
* API key de Perplexity y API key de OpenAI

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clona el repositorio
git clone https://github.com/iamaayushijain/perplexity-lens.git
cd perplexity_lens

# Instala las dependencias
npm install

# Compila la extensión
npm run build
```

<div id="configuration">
  ## Configuración
</div>

Edita `src/config.ts`:

```typescript theme={null}
export const PERPLEXITY_API_KEY = 'your-perplexity-key';
export const EMBEDDING_API_KEY = 'your-openai-key';
export const FIREBASE_HOSTING_URL = 'https://your-project-id.web.app';
```

<div id="usage">
  ## Uso
</div>

1. **Cargar la extensión**: ve a `chrome://extensions/`, activa el modo de desarrollador, haz clic en «Load unpacked» y selecciona el directorio `dist/`

2. **Iniciar sesión**: haz clic en el icono de la extensión y autentícate mediante Firebase

3. **Usar las funciones**:
   * **Resaltar texto**: selecciona texto en cualquier página web para obtener información generada por IA
   * **Resumir la página**: usa la función «Summarize» para obtener un resumen general de la página web
   * **Preguntar lo que quieras**: pasa el cursor o haz clic sobre palabras o frases para ver definiciones o explicaciones
   * **Ver el grafo**: ve a la pestaña Graph para consultar tu grafo de conocimiento
   * **Explorar**: amplía, arrastra y pasa el cursor sobre los nodos del grafo interactivo
   * **Compartir**: haz clic en «Share Graph» para generar un enlace público

<div id="code-explanation">
  ## Explicación del código
</div>

* **Frontend**: React con TypeScript y TailwindCSS para una interfaz moderna y adaptable
* **Extensión de navegador**: arquitectura de extensión de Chrome con scripts de popup y de contenido
* **Integración de IA**: Perplexity AI para explicaciones y resúmenes inteligentes de texto
* **Grafo de conocimiento**: D3.js para la visualización interactiva del grafo y las conexiones entre conceptos
* **Almacenamiento**: sistema de almacenamiento dual con IndexedDB local y Firebase en la nube
* **Autenticación**: Firebase Auth para un acceso seguro de los usuarios y la gestión de datos
* **Sistema RAG**: generación aumentada por recuperación (RAG) para obtener información contextual y definiciones
