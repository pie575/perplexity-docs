**Greenify** es una aplicación móvil diseñada para fomentar prácticas sostenibles mediante el análisis de imágenes en vivo y la creación de comunidades. Los usuarios toman fotos de su espacio (balcón, borde de la carretera, sótano, etc.) y Greenify analiza automáticamente la imagen con la Sonar API de Perplexity para sugerir las plantas más adecuadas para ese lugar. La aplicación también conecta a personas afines de la zona para crear comunidades orientadas al crecimiento sostenible, económico y social.

<div id="features">
  ## Funcionalidades
</div>

* **Análisis de plantas con IA** mediante reconocimiento de imágenes y datos de ubicación para sugerir plantas adecuadas
* **Recomendaciones según la ubicación** que tienen en cuenta el clima, la luz solar y las condiciones ambientales
* **Creación de comunidad** que conecta a usuarios con intereses similares en plantas y objetivos sostenibles
* **Aplicación móvil multiplataforma** creada con Expo para iOS, Android y web
* **Integración meteorológica en tiempo real** para evaluar con precisión la idoneidad de las plantas
* **Salida JSON estructurada** con modelos de Pydantic para un manejo de datos coherente
* **Compatibilidad con modelos de RA** para mejorar la visualización de las plantas

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js 20.19.4+ y npm
* Python 3.10.0+ y pip
* Expo CLI y SDK 51+
* API key de Perplexity (Sonar Pro y Sonar Deep Research)
* Android SDK/Studio o Xcode (para compilaciones locales)
* Dispositivo móvil con cámara para capturar imágenes

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clonar el repositorio
git clone https://github.com/deepjyotipaulhere/greenify.git
cd greenify

# Instalar las dependencias del frontend
npm install

# Instalar las dependencias del backend
cd service
pip install -r requirements.txt
```

<div id="configuration">
  ## Configuración
</div>

Crea un archivo `.env` en el directorio `service`:

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key_here
```

<div id="usage">
  ## Uso
</div>

1. **Iniciar el servicio de backend**:
   ```bash theme={null}
   cd service
   python app.py
   ```

2. **Iniciar la app de frontend**:
   ```bash theme={null}
   npx expo start
   ```

3. **Acceder a la app**:
   * Instala la app Expo Go y escanea el código QR, o
   * Abre el navegador web del móvil y ve a la URL que se muestra

4. **Usar la app**:
   * Concede los permisos de cámara y ubicación
   * Toma una foto de tu espacio (balcón, jardín, etc.)
   * Recibe recomendaciones de plantas generadas por IA
   * Conecta con usuarios cercanos para crear comunidad

<div id="code-explanation">
  ## Explicación del código
</div>

* **Frontend**: React Native con Expo para el desarrollo móvil multiplataforma
* **Backend**: API en Python con Flask que gestiona el procesamiento de imágenes y la integración con la Perplexity API
* **Integración de IA**: Perplexity Sonar Pro para el análisis de imágenes y Sonar Deep Research para las recomendaciones de plantas
* **Modelos de datos**: modelos de Pydantic para la salida JSON estructurada y la validación de datos
* **Procesamiento de imágenes**: análisis de imágenes en tiempo real con contexto basado en la ubicación
* **Funcionalidades comunitarias**: emparejamiento de usuarios según las sugerencias de plantas y los intereses en sostenibilidad
* **Integración meteorológica**: datos meteorológicos en tiempo real para evaluar con precisión la idoneidad de las plantas
