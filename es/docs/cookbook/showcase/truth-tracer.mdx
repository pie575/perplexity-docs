**TruthTracer** es una plataforma integral de detección de desinformación que utiliza la Sonar API de Perplexity para realizar un análisis de afirmaciones en múltiples capas. La plataforma combina verificación de hechos, trazado de cadenas de confianza y razonamiento socrático para ofrecer resultados de verificación precisos y basados en evidencia, con puntuaciones de confianza y un detalle exhaustivo de las fuentes.

<div id="features">
  ## Funcionalidades
</div>

* **Análisis multimétodo** que combina verificación de hechos, análisis de cadena de confianza y razonamiento socrático
* **Verificación con IA** mediante los modelos Sonar, Sonar Deep Research y Sonar Reasoning Pro de Perplexity
* **Procesamiento en tiempo real** con ejecución paralela de múltiples métodos de análisis
* **Resultados basados en evidencia** que aportan fuentes, puntuaciones de confianza y razonamiento detallado
* **Arquitectura limpia** con backend en NestJS y frontend en React
* **Listo para producción** con despliegue en Docker, pruebas exhaustivas y documentación de la API
* **Puntuación de confianza configurable** con pesos y umbrales personalizables

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js 18+ y npm
* API key de Perplexity (con acceso a los modelos Sonar)
* Docker (opcional, para el despliegue)
* Git para clonar el repositorio

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clona el repositorio del backend
git clone https://github.com/anthony-okoye/truth-tracer-backend.git
cd truth-tracer-backend

# Instala las dependencias
npm install

# Clona el repositorio del frontend
git clone https://github.com/anthony-okoye/truth-tracer-front.git
cd truth-tracer-front

# Instala las dependencias del frontend
npm install
```

<div id="configuration">
  ## Configuración
</div>

Crea un archivo `.env` en el directorio del backend:

```ini theme={null}
# Obligatorio
SONAR_API_KEY=your_perplexity_api_key
SONAR_API_URL=https://api.perplexity.ai

# Configuración opcional
SONAR_TIMEOUT=30000
SONAR_MAX_RETRIES=3
CONFIDENCE_WEIGHT_FACT_CHECK=0.35
CONFIDENCE_WEIGHT_TRUST_CHAIN=0.25
CONFIDENCE_WEIGHT_SOCRATIC=0.20
```

<div id="usage">
  ## Uso
</div>

1. **Inicia el backend**:

```bash theme={null}
   cd truth-tracer-backend
   npm run start:dev
```

2. **Iniciar el frontend**:

```bash theme={null}
   cd truth-tracer-front
   npm start
```

3. **Acceder a la aplicación**: abre [http://localhost:3000](http://localhost:3000) en tu navegador

4. **Analizar afirmaciones**:
   * Escribe una afirmación en el área de texto
   * Haz clic en &quot;Analyze Claim&quot; para ejecutar la verificación de hechos, el análisis de la cadena de confianza y el razonamiento socrático
   * Consulta los resultados con las puntuaciones de confianza, las fuentes y las explicaciones detalladas

<div id="code-explanation">
  ## Explicación del código
</div>

* **Backend**: aplicación NestJS con arquitectura limpia que sigue las buenas prácticas de TypeScript
* **Integración de IA**: Sonar API de Perplexity con tres modelos especializados: Sonar para la verificación de hechos, Sonar Deep Research para el análisis de la cadena de confianza y Sonar Reasoning Pro para la evaluación lógica
* **Procesamiento en paralelo**: ejecución simultánea de los tres métodos de análisis para verificar las afirmaciones de forma eficiente
* **Saneamiento de respuestas**: parseo y validación de JSON personalizados para manejar distintos formatos de respuesta de la API
* **Puntuación de confianza**: sistema de puntuación ponderada que combina los resultados de los tres métodos de análisis
* **Frontend**: aplicación React con una interfaz intuitiva para enviar afirmaciones y una visualización detallada de los resultados
* **Pruebas**: conjunto de pruebas integral que incluye pruebas unitarias, pruebas de extremo a extremo y pruebas de análisis de afirmaciones

<div id="how-the-sonar-api-is-used">
  ## Cómo se usa la Sonar API
</div>

TruthTracer aprovecha la Sonar API de Perplexity mediante tres enfoques de análisis diferenciados:

```typescript theme={null}
// Ejecución en paralelo de varios modelos Sonar
const [factCheckResult, trustChainResult, socraticResult] = await Promise.all([
  sonarClient.chat.completions.create({
    model: "sonar",
    messages: [{ role: "user", content: factCheckPrompt }],
    max_tokens: 500
  }),
  sonarClient.chat.completions.create({
    model: "sonar-deep-research", 
    messages: [{ role: "user", content: trustChainPrompt }],
    max_tokens: 2500
  }),
  sonarClient.chat.completions.create({
    model: "sonar-reasoning-pro",
    messages: [{ role: "user", content: socraticPrompt }],
    max_tokens: 4000
  })
]);
```
