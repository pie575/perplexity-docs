**PosterLens** es una aplicación de iOS que convierte pósteres científicos estáticos en información interactiva y explorable mediante OCR e IA. Creada para el Perplexity Hackathon 2025, permite a investigadores, MSL y redactores médicos escanear pósteres y explorarlos de forma interactiva con lenguaje natural, extrayendo su significado y mostrando estudios relacionados al instante.

![PosterLens Screenshot](https://cdn.prod.website-files.com/66d49e8555a289120a81ec3e/68930ad938e072c05d1be0b9_PosterLens.png)

<div id="features">
  ## Funcionalidades
</div>

* **Escaneo de pósteres científicos** con la cámara del dispositivo y el OCR de Apple Vision
* **Preguntas y respuestas en lenguaje natural** sobre el contenido del póster, con respuestas generadas por IA
* **Integración de búsqueda semántica** mediante Perplexity Sonar Pro para encontrar estudios relacionados
* **Validación de citas** con las E-utilities de PubMed para garantizar el rigor académico
* **Preguntas de investigación autogeneradas** y líneas de investigación futuras
* **Procesamiento en el dispositivo** para mayor privacidad y rendimiento
* **Experiencia de investigación interactiva** que convierte el contenido estático en información dinámica

<div id="prerequisites">
  ## Requisitos previos
</div>

* Dispositivo con iOS 17+ y cámara
* Xcode 15+ para el desarrollo
* Cuenta de Apple Developer para la distribución en la App Store
* API key de Perplexity (Sonar Pro)
* API key de OpenAI (GPT-3.5)
* Acceso a E-utilities de PubMed


<div id="configuration">
  ## Configuración
</div>

Agrega tus API keys a la configuración del proyecto:

```swift theme={null}
// Configuración de la API
PERPLEXITY_API_KEY=your_sonar_pro_api_key
OPENAI_API_KEY=your_gpt_api_key
PUBMED_API_KEY=your_pubmed_api_key
```

<div id="usage">
  ## Uso
</div>

1. **Instálalo desde la App Store**: descarga PosterLens desde la App Store de iOS
2. **Escanea el póster**: apunta la cámara hacia un póster científico
3. **Procesamiento OCR**: Apple Vision extrae automáticamente el texto
4. **Haz preguntas**: consulta el contenido del póster en lenguaje natural
5. **Explora investigaciones relacionadas**: descubre estudios relacionados semánticamente con Sonar Pro
6. **Valida las citas**: comprueba las referencias académicas con la integración de PubMed

<div id="code-explanation">
  ## Explicación del código
</div>

* **Frontend**: aplicación nativa de iOS creada con SwiftUI para una UI/UX moderna
* **Procesamiento OCR**: framework Apple Vision para extraer texto de imágenes
* **Integración con IA**: API de Perplexity Sonar Pro para búsqueda semántica y comprensión del contexto
* **Lenguaje natural**: GPT-3.5 para preguntas y respuestas e interpretación del contenido
* **Validación académica**: E-utilities de PubMed para verificar las citas
* **Procesamiento en el dispositivo**: OCR y procesamiento locales para mayor privacidad y rendimiento
* **Mejora de la investigación**: generación automática de preguntas de investigación y líneas de investigación futuras
