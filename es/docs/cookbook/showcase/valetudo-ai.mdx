<div id="valetudo-ai">
  # Valetudo AI
</div>

**Valetudo AI** es un asistente médico con respaldo científico impulsado por la Sonar API de Perplexity. Ofrece respuestas rápidas, claras y bien citadas a preguntas de salud, y ayuda a los usuarios a filtrar la desinformación mediante filtros, análisis de imágenes y plantillas de prompts listas para usar.

Está pensado para usuarios informados —como padres, pacientes y estudiantes de medicina— que buscan información fiable.

<div id="features">
  ## Funcionalidades
</div>

* **Respuestas con citas** — extraídas de una lista curada de 10 dominios médicos de confianza
* **Filtros inteligentes** — por fecha y país, para obtener información localizada y actualizada
* **Carga de imágenes** — analiza fotos de medicamentos, afecciones o envases
* **Plantillas de prompts** — 7 categorías para consulta de síntomas, seguridad de medicamentos, investigación y más
* **Interfaz sencilla** — desarrollada con React y Tailwind CSS

<div id="how-it-uses-the-sonar-api">
  ## Cómo utiliza la Sonar API
</div>

Valetudo AI se integra con [Perplexity Sonar Pro](https://docs.perplexity.ai) y aprovecha funciones avanzadas para la búsqueda por dominios y las respuestas enriquecidas:

| Función               | Campo de la API                   | Propósito                                                        |
| --------------------- | --------------------------------- | ---------------------------------------------------------------- |
| Control de contexto   | `search_context_size: medium`     | Equilibra velocidad y profundidad en consultas médicas concretas |
| Dominios de confianza | `search_domain_filter`            | Restringe los resultados a fuentes de salud verificadas          |
| Entrada visual        | `image_url`                       | Permite consultas médicas basadas en imágenes                    |
| Filtro de actualidad  | `search_after/before_date_filter` | Ayuda a destacar hallazgos recientes y relevantes                |
| Relevancia local      | `user_location`                   | Adapta las respuestas a la región del usuario                    |
