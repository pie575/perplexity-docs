**Monday** es un compañero de aprendizaje con IA y control por voz, diseñado para tender un puente entre las consultas en lenguaje natural y el contenido educativo de alta calidad. Inspirado en JARVIS y FRIDAY de Marvel, Monday ofrece respuestas personalizadas en tres modos —básico, razonamiento y investigación profunda— e integra visualizaciones inmersivas, contenido de video seleccionado y un diseño que prioriza la accesibilidad.

<div id="features">
  ## Funcionalidades
</div>

* **Tres modos de aprendizaje**: respuestas factuales básicas, razonamiento paso a paso e investigaciones en profundidad
* **Interacción por voz** para aprender sin usar las manos, con procesamiento de lenguaje natural
* **Visualizaciones 3D de conceptos en tiempo real** con Three.js y WebXR
* **Integración de videos educativos de YouTube** seleccionados de fuentes confiables
* **Retroalimentación multimodal** que combina texto, voz (mediante ElevenLabs) y paneles espaciales
* **Diseño con realidad virtual opcional** para vivir experiencias inmersivas sin necesidad de un visor
* **Interfaz centrada en la accesibilidad** para personas con discapacidad motriz o visual

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js 18 LTS o superior
* Navegador web moderno (se recomienda Chrome, Edge o Firefox)
* Micrófono para la interacción por voz
* Opcional: visor de VR para el modo inmersivo (compatible con WebXR)
* API key de Perplexity, API key de ElevenLabs y API key de YouTube

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clona el repositorio
git clone https://github.com/srivastavanik/monday.git
cd monday
git checkout final
cd nidsmonday

# Instala las dependencias
npm install
```

```ini theme={null}
# Crea un archivo .env y configura tus API keys
PERPLEXITY_API_KEY=your_api_key
ELEVENLABS_API_KEY=your_api_key
YOUTUBE_API_KEY=your_api_key
```

```bash theme={null}
# Inicia el servidor backend
node backend-server.js

# Inicia el frontend
npm run dev
```

<div id="usage">
  ## Uso
</div>

1. Abre la aplicación en tu navegador
2. Di **«Hey Monday»** para activar el asistente
3. Haz una pregunta en uno de los tres modos:
   * **Modo básico**: «¿Qué es la fotosíntesis?»
   * **Modo de razonamiento**: «Piensa en cómo funciona el blockchain».
   * **Modo de investigación profunda**: «Investiga la historia de la mecánica cuántica».
4. Consulta las respuestas en paneles de texto flotantes, respuestas por voz y modelos 3D interactivos

<div id="code-explanation">
  ## Explicación del código
</div>

* **Frontend**: TypeScript con Three.js para visualizaciones 3D y WebXR para compatibilidad con VR
* **Backend**: Node.js con Socket.IO para el procesamiento de comandos de voz en tiempo real
* **Integración con IA**: Sonar API de Perplexity para respuestas inteligentes con extracción del razonamiento
* **Procesamiento de voz**: ElevenLabs para síntesis de voz y comprensión del lenguaje natural
* **Curación de contenido**: integración con la API de YouTube y extracción inteligente de palabras clave para vídeos educativos
* **Accesibilidad**: diseño centrado en la voz, con audio espacial y compatibilidad con respuesta háptica
