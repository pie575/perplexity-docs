**Sonar Chromium Browser** es un parche para el navegador Chromium que integra de forma nativa la Sonar API de Perplexity para ofrecer funcionalidad basada en IA directamente en el navegador. Los usuarios pueden escribir `sonar <query>` en la omnibox para obtener respuestas de IA al instante, o seleccionar un texto y hacer clic derecho en &quot;Summarize with Sonar&quot; para obtener resúmenes rápidos, lo que agiliza los flujos de trabajo de investigación y navegación.

<div id="features">
  ## Características
</div>

* **Respuestas de IA en la omnibox** con la sintaxis `sonar <query>` para obtener respuestas instantáneas
* **Resumen desde el menú contextual** del texto seleccionado, con acceso en un solo clic
* **Integración nativa con el navegador** mediante las API de omnibox y de menú contextual de Chromium
* **Compatibilidad con dos modelos**: Sonar Pro para la omnibox y Sonar para los resúmenes
* **Gestión de la entrada con debounce** para un uso eficiente de la API
* **Compilación personalizada del navegador** que ilustra patrones de integración de IA

<div id="prerequisites">
  ## Requisitos previos
</div>

* Ubuntu 22.04 (se recomienda WSL2)
* Copia local del código fuente de Chromium
* API key de Perplexity
* 16 GB o más de RAM para compilar Chromium
* Git y herramientas de compilación estándar

  ## Instalación
</div>

```bash theme={null}

# Aplica los parches al código fuente de Chromium
# Consulta el README para ver instrucciones detalladas de configuración de Chromium
```

<div id="configuration">
  ## Configuración
</div>

Actualiza las API keys en los archivos modificados:

```cpp theme={null}
// En sonar_autocomplete_provider.cc y render_view_context_menu.cc
const std::string API_KEY = "your_perplexity_api_key_here";
```

<div id="usage">
  ## Uso
</div>

1. **Compila Chromium** con los parches aplicados siguiendo las instrucciones del repositorio
2. **Inicia el navegador personalizado** con la integración de IA
3. **Usa IA en la omnibox**: escribe `sonar what is quantum tunneling?` en la barra de direcciones
4. **Usa el resumen de contexto**: selecciona el texto y haz clic derecho en «Summarize with Sonar»

<div id="code-explanation">
  ## Explicación del código
</div>

* **Integración con la omnibox**: proveedor de autocompletado personalizado conectado a la API de omnibox de Chromium
* **Menú contextual**: menú contextual de la vista de renderizado modificado para resumir texto
* **Integración de la API**: llamadas directas a la Sonar API de Perplexity con control de entrada mediante debounce
* **Selección de modelo**: Sonar Pro para las consultas desde la omnibox y Sonar para el resumen de texto
* **Arquitectura del navegador**: muestra los puntos de extensión de Chromium para funcionalidades de IA
* **Proceso de compilación**: compilación personalizada de Chromium con los parches de IA aplicados
