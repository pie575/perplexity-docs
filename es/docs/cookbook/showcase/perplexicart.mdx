**PerplexiCart** ayuda a los usuarios a tomar decisiones de compra informadas y coherentes con sus valores. Impulsado por la **Perplexity Sonar API**, analiza productos en toda la web y devuelve información estructurada con recomendaciones priorizadas, ventajas y desventajas, análisis de contrapartidas y sentimiento de los usuarios, todo ello adaptado a preferencias como ecológico, durabilidad, ética y necesidades propias de cada región.

<div id="features">
  ## Funcionalidades
</div>

* **Recomendaciones inteligentes de productos** que van más allá de la simple comparación de especificaciones
* **Alineación con valores según prioridades** (mejor relación calidad-precio, ecológico, ético, durabilidad, fabricado en India)
* **Personalización contextual** (tipo de piel, patrones de uso, región, etc.)
* **Resultados de investigación estructurados** con:
  * Resumen de la investigación y principales recomendaciones
  * Alineación con los valores y su justificación
  * Ventajas/desventajas y especificaciones clave
  * Sentimiento de los usuarios y perspectivas de la comunidad (Reddit, Quora)
  * Análisis de contrapartidas y consejos de compra
* **Fuentes transparentes** con citas para su verificación

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js 18+ y npm/yarn
* Python 3.10+ y pip
* API key de Perplexity

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clona el repositorio
git clone https://github.com/fizakhan90/perplexicart.git
cd perplexicart

# Configuración del backend (FastAPI)
cd backend
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Configuración del frontend (Next.js)
cd ../frontend
npm install
```

<div id="configuration">
  ## Configuración
</div>

Crea un archivo `.env` en el directorio del backend:

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key
```

(Opcional) Añade los ajustes específicos de tu aplicación que necesites (caché, región predeterminada, etc.).

<div id="usage">
  ## Uso
</div>

1. **Inicia el backend (FastAPI)**:
   ```bash theme={null}
   cd backend
   uvicorn main:app --reload  # adapta module:app si tu punto de entrada es distinto
   ```

2. **Inicia el frontend (Next.js)**:
   ```bash theme={null}
   cd frontend
   npm run dev
   ```

3. **Abre la aplicación**: entra en `http://localhost:3000` y busca un producto. Selecciona tu prioridad (por ejemplo, ecológico) y añade contexto opcional (tipo de piel, región).

<div id="code-explanation">
  ## Explicación del código
</div>

* **Backend (FastAPI)**: orquesta las llamadas a Sonar con ingeniería de prompts dinámica según la consulta, la prioridad seleccionada y el contexto
* **Salidas estructuradas**: impone un esquema JSON estricto mediante `response_format` para garantizar un renderizado coherente de la interfaz
* **Investigación web en tiempo real**: indica a Sonar que busque en plataformas de comercio electrónico, foros, blogs de reseñas e informes de sostenibilidad
* **Análisis semántico**: extrae la alineación con valores del usuario, la ventaja y desventaja y el sentimiento, y cita las fuentes para mayor transparencia
* **Frontend (Next.js/React)**: presenta una vista clara e intuitiva de las recomendaciones, las contrapartidas y las citas

<div id="how-the-sonar-api-is-used">
  ## Cómo se usa la Sonar API
</div>

PerplexiCart utiliza la **Sonar API de Perplexity** como núcleo de inteligencia y genera dinámicamente prompts personalizados a partir de los datos que introduce el usuario, como consultas de búsqueda, prioridades y contexto. La API realiza una investigación web exhaustiva en sitios de comercio electrónico, foros y plataformas de reseñas, y devuelve las respuestas en un formato JSON uniforme. Mediante análisis semántico, extrae información clave sobre los productos: su correspondencia con las prioridades del usuario, ventajas y desventajas y sentimiento, todo respaldado por fuentes citadas. El backend de FastAPI procesa estas respuestas estructuradas antes de entregarlas al frontend de Next.js para ofrecer una experiencia de usuario cuidada.
