**FirstPrinciples App** es una herramienta impulsada por IA que convierte tus objetivos de aprendizaje generales en hojas de ruta estructuradas y personalizadas. A través de un chat interactivo, la IA conversa contigo y te plantea preguntas específicas para concretar tus necesidades de aprendizaje antes de generar un plan detallado. La aplicación está pensada para ayudarte a aprender de forma más eficiente al ofrecerte un camino claro a seguir.

<div id="features">
  ## Funcionalidades
</div>

* **Interfaz de chat interactiva** para definir y perfeccionar los objetivos de aprendizaje mediante conversación
* **Acotación de temas con IA** mediante preguntas inteligentes y específicas para precisar los objetivos de aprendizaje
* **Gestión de sesiones** que permite mantener varias conversaciones sobre hojas de ruta de aprendizaje y hacer seguimiento del progreso
* **Indicadores visuales de progreso** que muestran cuándo se ha reunido información suficiente
* **Planes de aprendizaje personalizados** con hojas de ruta estructuradas paso a paso
* **Flujo conversacional con IA** que combina las APIs de OpenAI y Perplexity para lograr interacciones inteligentes

<div id="prerequisites">
  ## Requisitos previos
</div>

* Python 3.8+ y pip
* Node.js 16+ y npm
* Clave de API de OpenAI
* Clave de API de Perplexity

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clonar el repositorio
git clone https://github.com/william-Dic/First-Principle.git
cd First-Principle

# Configuración del backend
cd flask-server
pip install -r requirements.txt

# Configuración del frontend
cd ../client
npm install
```

<div id="configuration">
  ## Configuración
</div>

Crea un archivo `.env` en el directorio `flask-server`:

```ini theme={null}
OPENAI_API_KEY=your_openai_api_key
PERPLEXITY_API_KEY=your_perplexity_api_key
PERPLEXITY_API_KEY=your_perplexity_api_key
```

<div id="usage">
  ## Uso
</div>

1. **Iniciar el backend**:
   ```bash theme={null}
   cd flask-server
   python server.py
   ```
   El servidor se ejecuta en [http://localhost:5000](http://localhost:5000)

2. **Iniciar el frontend**:
   ```bash theme={null}
   cd client
   npm start
   ```
   El cliente se ejecuta en [http://localhost:3000](http://localhost:3000)

3. **Generar la hoja de ruta**:
   * Abre [http://localhost:3000](http://localhost:3000) en tu navegador
   * Describe qué quieres aprender en la interfaz de chat
   * Responde a las preguntas de seguimiento de la IA para afinar tus objetivos de aprendizaje
   * Recibe una hoja de ruta de aprendizaje personalizada y estructurada

<div id="code-explanation">
  ## Explicación del código
</div>

* **Frontend**: aplicación React con interfaz de chat conversacional e indicadores de progreso
* **Backend**: servidor Flask que gestiona las llamadas a la API, el estado de la sesión y el flujo de la conversación
* **Integración de IA**: combina la API de OpenAI para el flujo conversacional y la Perplexity API para el análisis inteligente de temas
* **Gestión de sesiones**: hace seguimiento del estado de la conversación y del refinamiento del objetivo de aprendizaje
* **Generación de la hoja de ruta**: crea planes de aprendizaje estructurados y prácticos a partir de la información que aporta el usuario
* **Flujo conversacional**: implementa un diálogo orientado a objetivos para delimitar las metas de aprendizaje
