**UnCovered** es una extensión de Chrome que verifica textos, imágenes, sitios web y capturas de pantalla en tiempo real, justo donde navegas. Desarrollada sobre la Sonar API de Perplexity, ofrece la verdad al instante con citas, veredictos y análisis detallado con solo un clic derecho, sin interrumpir tu navegación.

<div id="features">
  ## Funcionalidades
</div>

* **Verificación en 3 clics**: seleccionar → clic derecho → verificar (texto, imagen, enlace o captura de pantalla)
* **Modos de análisis de texto**: búsqueda rápida, verificación de datos e investigación profunda
* **Verificación de imágenes**: búsqueda inversa de imágenes y verificación multimodal de afirmaciones
* **Captura de pantalla y de fotogramas de video**: analiza elementos visuales como infografías, memes o capturas de gráficos
* **Resultados respaldados por citas**: todas las respuestas incluyen fuentes y veredictos de veracidad (verdadero/falso/sin confirmar)
* **Generador instantáneo de réplicas**: crea respuestas concisas y basadas en hechos para responder a la desinformación
* **Experiencia sin fricciones**: todo ocurre en la misma página, sin copiar y pegar ni abrir pestañas nuevas

<div id="prerequisites">
  ## Requisitos previos
</div>

* Navegador Chrome
* Node.js 16+ y npm
* Base de datos MongoDB
* Cuenta de Cloudinary para almacenar imágenes
* API key de Perplexity (con acceso a Sonar Pro y investigación profunda)
* Credenciales de Google OAuth

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clona el repositorio
git clone https://github.com/aayushsingh7/UnCovered.git
cd UnCovered

# Instala las dependencias
npm install

# Compila la extensión de Chrome
npm run build
```


<div id="usage">
  ## Uso
</div>

1. **Verificación de texto/enlaces**:
   * Selecciona texto o haz clic derecho en un enlace
   * Elige búsqueda rápida / verificación de datos / investigación profunda
   * Obtén resultados fiables con veredictos y citas

2. **Verificación de imágenes**:
   * Haz clic derecho en cualquier imagen
   * Elige entre búsqueda rápida o verificación de datos
   * Detecta desinformación y manipulación visual

3. **Análisis de capturas de pantalla/infografías**:
   * Haz clic en el icono de UnCovered en la barra de herramientas
   * Usa «Capture Screen» para analizar contenido visual

4. **Obtén una refutación instantánea**:
   * Genera automáticamente respuestas basadas en hechos para corregir la desinformación

<div id="code-explanation">
  ## Explicación del código
</div>

* **Frontend**: extensión de Chrome en JavaScript puro con integración en el menú contextual
* **Backend**: servidor Express de Node.js que gestiona las solicitudes a la API y la autenticación de usuarios
* **Integración de IA**: APIs de Perplexity Sonar Pro y investigación profunda para una verificación de datos inteligente
* **Procesamiento de imágenes**: integración con Cloudinary para el análisis de imágenes y capturas de pantalla
* **Base de datos**: MongoDB para los datos de usuario y el historial de verificaciones
* **Autenticación**: Google OAuth para una gestión segura de usuarios
* **Análisis multimodal**: compatibilidad con texto, imágenes, capturas de pantalla y fotogramas de video

<div id="technical-implementation">
  ## Implementación técnica
</div>

UnCovered utiliza la Sonar API de Perplexity en tres modos principales:

```javascript theme={null}
// Búsqueda rápida y verificación de datos con Sonar Pro
const quickResponse = await perplexityClient.chat.completions.create({
  model: "sonar-pro",
  messages: [{ role: "user", content: factCheckPrompt }]
});

// Investigación profunda para un análisis exhaustivo
const deepResponse = await perplexityClient.chat.completions.create({
  model: "sonar-deep-research", 
  messages: [{ role: "user", content: deepAnalysisPrompt }]
});
```
