**Ellipsis** es un agente de generación de pódcast de nueva generación que da vida a contenido de audio de alta calidad y con un sonido natural sobre cualquier tema con un solo clic. Ya sean noticias de última hora, explicaciones técnicas en profundidad, reseñas de películas o análisis deportivos tras un partido, Ellipsis crea episodios de pódcast inteligentes que suenan como si los hubieran producido presentadores expertos en un estudio profesional.

<div id="features">
  ## Características
</div>

* **Diálogo inteligente con múltiples interlocutores**, con varias voces y personalidades distintas
* **Cobertura temática integral**, desde arquitecturas de LLM hasta eclipses lunares
* **Motor de evaluación personalizado** que garantiza precisión factual, cumplimiento legal y calidad conversacional
* **Generación de pódcast totalmente automatizada**, con audio natural y listo para publicar
* **Actualizaciones en tiempo real por streaming** mediante Server-Sent Events (SSE)
* **Integración con Podbean** para publicar pódcast directamente
* **Detección de temas en tendencia** mediante la Perplexity API

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js v16+ y npm/yarn
* Python 3.10+ y pip
* Servidor Redis en ejecución (por defecto en el puerto 6380)
* API key de Perplexity, credenciales de Podbean

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clonar el repositorio
git clone https://github.com/dineshkannan010/Ellipsis.git
cd Ellipsis

# Configuración del backend
cd backend
python -m venv venv
source venv/bin/activate    # macOS/Linux
pip install -r requirements.txt

# Instalar paquetes nativos
pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
pip install git+https://github.com/freddyaboulton/orpheus-cpp.git
pip install huggingface_hub[hf_xet] hf_xet

# Configuración del frontend
cd ../frontend
npm install
```

<div id="configuration">
  ## Configuración
</div>

Crea `backend/.env`:

```ini theme={null}
REDIS_URL=redis://your-redis-host:6379
PERPLEXITY_API_KEY=your_key_here
PODBEAN_CLIENT_ID=...
PODBEAN_CLIENT_SECRET=...
```

Crea `frontend/.env`:

```ini theme={null}
REACT_APP_API_URL=http://your-backend-host:5000
```

<div id="usage">
  ## Uso
</div>

1. **Inicia el servidor de Redis**:
   ```bash theme={null}
   redis-server --port 6380
   ```

2. **Inicia el backend**:
   ```bash theme={null}
   cd backend
   python app.py
   ```

3. **Inicia el frontend**:
   ```bash theme={null}
   cd frontend
   npm run dev
   ```

4. **Opcional: integración con Podbean**:
   ```bash theme={null}
   cd backend/integrations/podbean_mcp
   pip install -e .
   python server.py
   python client.py server.py
   ```

5. **Genera contenido**: escribe un tema en el cuadro de texto de la página de inicio y pulsa Enter. Cambia a `ContentGenerationView` para ver en tiempo real el progreso del guion y del audio.

<div id="code-explanation">
  ## Explicación del código
</div>

* **Backend**: Python Flask con Redis pub/sub, llama.cpp y Orpheus TTS para la generación de audio
* **Frontend**: React con Vite, Tailwind CSS y Server-Sent Events para actualizaciones en tiempo real
* **Integración de IA**: Perplexity API para la generación de contenido y la detección de temas en tendencia
* **Procesamiento de audio**: TTS multilocutor con personalidades de voz diferenciadas
* **Evaluación de contenido**: pipelines integrados para verificar la exactitud de los datos y el cumplimiento legal
* **Publicación de pódcast**: integración directa con Podbean mediante un servidor MCP
