**Executive Intelligence** es una aplicación integral impulsada por Perplexity Sonar que ofrece a directivos y miembros de consejos de administración información estratégica instantánea, precisa y fiable para la toma de decisiones. Genera análisis listos para presentar al consejo, elaborados a partir de fuentes de datos en tiempo real y con la tecnología de la Sonar API de Perplexity.

<div id="features">
  ## Funcionalidades
</div>

* **Informes de inteligencia competitiva** con análisis competitivo exhaustivo, listo para presentar al consejo, y citas verificables
* **Planificación de escenarios (análisis «¿qué pasaría si?»)** para generar escenarios futuros de forma dinámica a partir de datos en tiempo real
* **Memoria del Board Pack** para guardar y organizar informes de inteligencia, análisis de escenarios e informes comparativos
* **Comparativas instantáneas y análisis frente a competidores** con comparaciones visuales de métricas clave y fuentes citadas
* **Integración de datos en tiempo real** que aprovecha la Sonar API de Perplexity para obtener inteligencia de mercado actualizada
* **Formato profesional** con informes estructurados, resúmenes ejecutivos y presentaciones listas para el consejo

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js 18+ y npm/yarn
* Git
* API key de Perplexity (Sonar Pro)

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clona el repositorio
git clone https://github.com/raishs/perplexityhackathon.git
cd perplexityhackathon

# Instala las dependencias
npm install

# Configura las variables de entorno
cp .env.example .env.local
```

<div id="configuration">
  ## Configuración
</div>

Crea el archivo `.env.local`:

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key
```

<div id="usage">
  ## Uso
</div>

1. **Iniciar el servidor de desarrollo**:
   ```bash theme={null}
   npm run dev
   ```

2. **Acceder a la aplicación**: abre [http://localhost:3000](http://localhost:3000) en tu navegador

3. **Generar inteligencia**:
   * Escribe el nombre de una empresa en el campo de entrada
   * Haz clic en «Competitive Analysis» para obtener informes completos
   * Usa «planificación de escenarios» para análisis de hipótesis
   * Accede a «comparativa» para comparativas con empresas similares
   * Guarda los informes en «Board Pack» para consultarlos más adelante

4. **Gestión del Board Pack**: usa el botón «📁 Board Pack» para ver y gestionar los informes de inteligencia guardados

<div id="code-explanation">
  ## Explicación del código
</div>

* **Frontend**: Next.js con TypeScript y React para una interfaz moderna y adaptable
* **Backend**: rutas de API de Next.js que gestionan la integración con la Sonar API de Perplexity
* **Integración de IA**: Sonar Pro de Perplexity para inteligencia competitiva en tiempo real y análisis de escenarios
* **Gestión del estado**: React Context para la memoria del consejo directivo y el almacenamiento persistente de datos
* **Procesamiento de Markdown**: utilidades personalizadas para analizar las respuestas de la IA y gestionar las citas
* **Gestión de errores**: control integral de tiempos de espera y errores en las llamadas a la API
* **Resultados profesionales**: formato estructurado para presentaciones listas para presentar al consejo, con citas de las fuentes
