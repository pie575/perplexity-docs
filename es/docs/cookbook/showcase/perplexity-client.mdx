**Perplexity Client** es una aplicación de escritorio basada en Electron que ofrece una interfaz cuidada para interactuar con la Sonar API de Perplexity. Expone parámetros avanzados de la API, como max tokens, lo que la hace ideal para desarrolladores que quieren un control preciso sobre sus interacciones con la IA sin renunciar a una interfaz atractiva e inspirada en macOS.

<div id="features">
  ## Funcionalidades
</div>

* **Múltiples modelos Sonar** con soporte para Sonar, Sonar Pro y Sonar Reasoning Pro
* **Spaces personalizados** con funcionalidad de guardado/carga para distintos casos de uso
* **Controles de parámetros de la API**, incluido el ajuste de max tokens
* **Modo de depuración de la API** que muestra las cargas útiles completas de solicitud/respuesta para diagnosticar problemas
* **Seguimiento del uso de tokens** para monitorear el consumo y los costos de la API
* **Modos de enfoque** para tareas especializadas como programación, redacción e investigación

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js v16 o superior
* npm o yarn
* Una clave de API de Perplexity

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clona el repositorio
git clone https://github.com/straight-heart/Perplexity-client-.git
cd Perplexity-client-

# Instala las dependencias
npm install

npm run dev
```

<div id="build">
  ## Compilación
</div>

Compila la aplicación para tu plataforma:

```bash theme={null}
npm run build:win    # Windows
npm run build:mac    # macOS
npm run build:linux  # Linux
```

<div id="configuration">
  ## Configuración
</div>

Las claves de API se gestionan directamente desde la aplicación:

1. Abre la aplicación y ve a Configuración (icono de engranaje)
2. En la sección **API Keys**, haz clic en **Add Key**
3. Introduce tu clave de API de Perplexity
4. La clave se almacena de forma segura y se conserva entre sesiones

Para usar prompts de sistema personalizados, utiliza la función **Spaces** para guardar distintos conjuntos de instrucciones y alternar entre ellos.

<div id="usage">
  ## Uso
</div>

1. **Iniciar**: Ejecuta `npm run dev` o usa la aplicación compilada
2. **Añadir la clave de API**: Abre Configuración y añade tu clave de API de Perplexity
3. **Seleccionar el modelo**: Usa el menú desplegable para elegir entre las variantes de Sonar
4. **Crear Spaces**: Define prompts de sistema personalizados para distintas tareas
5. **Conversar**: Empieza a chatear con respuestas en streaming en tiempo real
6. **Depurar**: Activa la depuración de la API para ver todos los detalles de las solicitudes y respuestas
7. **Controlar el uso**: Monitorea el consumo de tokens en el panel de Configuración

<div id="limitations">
  ## Limitaciones
</div>

* Solo escritorio (Windows, macOS, Linux): no hay versión móvil ni web
* Requiere conexión a internet para las llamadas a la API
* Se requiere una clave de API para su funcionamiento
