**Daily News Briefing** es un plugin de Obsidian que entrega resúmenes de noticias generados con IA directamente en tu bóveda. Mantente al día de los temas que te interesan con una recopilación y un resumen de noticias automatizados e inteligentes, gracias a la Sonar API de Perplexity para la curación de contenido.

<div id="features">
  ## Funcionalidades
</div>

* **Recopilación personalizada de noticias** según tus temas de interés y preferencias
* **Resúmenes generados por IA** de artículos de noticias mediante la Sonar API de Perplexity
* **Informes diarios automatizados** entregados directamente en tu bóveda de Obsidian
* **Programación de entrega personalizable** y opciones de formato
* **Integración fluida con Obsidian** dentro de tu flujo de trabajo de gestión del conocimiento
* **Filtrado de fuentes confiables** para garantizar calidad y fiabilidad
* **Formato Markdown** para facilitar los enlaces y la organización dentro de tu bóveda

<div id="prerequisites">
  ## Requisitos previos
</div>

* Aplicación de escritorio de Obsidian instalada
* API key de Perplexity (con acceso a la Sonar API)
* Conexión a internet para obtener artículos de noticias
* Entorno de desarrollo de Typescript (para personalizar)

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clona el repositorio
git clone https://github.com/ChenziqiAdam/Daily-News-Briefing.git
cd Daily-News-Briefing

# Instala las dependencias
npm install

# Compila el plugin
npm run build
```

<div id="configuration">
  ## Configuración
</div>

1. **Instalar el plugin**: copia el plugin compilado en la carpeta de plugins de Obsidian
2. **Habilitar el plugin**: actívalo en los ajustes de Obsidian
3. **Configurar la API**: introduce tu API key de Perplexity en los ajustes del plugin
4. **Configurar temas**: define tus temas de noticias y tus preferencias de entrega

<div id="usage">
  ## Uso
</div>

1. **Configurar intereses**: define tus temas, fuentes y programación de entrega preferidos
2. **Recopilación automatizada**: el plugin usa la Sonar API de Perplexity para reunir las noticias más recientes
3. **Resumen con IA**: los artículos se procesan y se resumen aprovechando las capacidades de Perplexity
4. **Entrega en la bóveda**: los resúmenes se formatean como notas de Markdown en tu bóveda de Obsidian
5. **Integración del conocimiento**: vincula los boletines de noticias con otras notas de tu base de conocimiento

<div id="technical-implementation">
  ## Implementación técnica
</div>

El plugin utiliza la Sonar API de Perplexity para:

```typescript theme={null}
// Recopilación de noticias con la Sonar API de Perplexity
const newsQuery = `latest news about ${topic} in the past 24 hours`;
const searchResponse = await perplexityClient.search({
  query: newsQuery,
  max_results: 5,
  include_domains: userPreferences.trustedSources || []
});

// Resumen generado con IA
const summaryPrompt = `Summarize these news articles about ${topic}`;
const summaryResponse = await perplexityClient.generate({
  prompt: summaryPrompt,
  model: "sonar-medium-online",
  max_tokens: 500
});
```
