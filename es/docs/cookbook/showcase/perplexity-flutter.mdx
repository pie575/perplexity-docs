<div id="perplexity-dart-flutter-sdks">
  # SDKs de Perplexity para Dart y Flutter
</div>

Los **SDKs de Perplexity para Dart y Flutter** ofrecen un conjunto completo de herramientas para integrar las capacidades de IA de Perplexity en aplicaciones Dart y Flutter. Creados específicamente para la comunidad de Flutter, estos paquetes incluyen un cliente ligero de la API principal y widgets de Flutter listos para usar con gestión de estado mediante BLoC.

<div id="features">
  ## Características
</div>

* Cliente de API con tipado seguro, con modelos completamente tipados y seguridad en tiempo de compilación
* Chat completions con y sin streaming, con manejo de respuestas en tiempo real
* Compatibilidad con todos los modelos de Perplexity (Sonar, Sonar Pro, Deep Research y variantes de Reasoning)
* Procesamiento de varias imágenes con soporte para base64, URI de datos y URL HTTPS
* Widgets de Flutter listos para usar, con integración de gestión de estado mediante BLoC
* Opciones de configuración avanzadas (filtros de búsqueda, restricciones de dominio)
* Compatibilidad multiplataforma con iOS, Android, Web y escritorio
* Diseño preparado para el futuro, con soporte de cadenas de modelo personalizadas para los nuevos lanzamientos de Perplexity

<div id="prerequisites">
  ## Requisitos previos
</div>

* Dart SDK 2.17.0 o superior
* Flutter SDK 3.0.0 o superior (para las funciones específicas de Flutter)
* Una API key de Perplexity API obtenida en la consola de Perplexity API
* Conocimientos básicos del patrón BLoC de Flutter para la integración de widgets

<div id="installation">
  ## Instalación
</div>

<div id="for-dart-projects-core-api-only">
  ### Para proyectos Dart (solo la API del núcleo)
</div>

```bash theme={null}
dart pub add perplexity_dart
```

<div id="for-flutter-projects-full-widget-support">
  ### Para proyectos de Flutter (compatibilidad total con widgets)
</div>

```bash theme={null}
flutter pub add perplexity_flutter
```

<div id="usage">
  ## Uso
</div>

<div id="core-api-integration">
  ### Integración de la API del núcleo
</div>

* Cliente con tipado seguro compatible con todos los modelos de Perplexity (Sonar, Sonar Pro, Deep Research, Reasoning)
* Chat completions con y sin streaming
* Procesamiento multimodal con un sistema MessagePart flexible para texto e imágenes

<div id="flutter-widget-layer">
  ### Capa de widgets de Flutter
</div>

* `ChatWrapperWidget` para la gestión de estado con BLoC
* `PerplexityChatView` para mostrar mensajes en tiempo real
* `PerplexityChatInput` para gestionar la interacción del usuario

<div id="code-explanation">
  ## Explicación del código
</div>

* Capa del núcleo: cliente de API en Dart puro (`perplexity_dart`) para integrar la Perplexity API de forma multiplataforma
* Capa de interfaz: widgets de Flutter (`perplexity_flutter`) con gestión de estado BLoC para un desarrollo ágil
* Seguridad de tipos: modelos y respuestas totalmente tipados que evitan errores en tiempo de ejecución y habilitan IntelliSense
* Multimodalidad: sistema flexible de MessagePart para combinar texto e imágenes en una misma solicitud
* Streaming: compatibilidad integrada con chat completions en tiempo real y manejo adecuado de los fragmentos
* Arquitectura: el diseño en dos capas permite un uso ligero de la API o una integración completa con widgets de Flutter

<div id="architecture">
  ## Arquitectura
</div>

<div id="two-layer-design">
  ### Diseño de dos capas
</div>

* **Núcleo (`perplexity_dart`)** - Cliente de API en Dart puro para todas las plataformas
* **UI (`perplexity_flutter`)** - Widgets de Flutter + gestión de estado con BLoC

Utiliza un sistema MessagePart flexible para contenido multimodal que combina texto e imágenes.
