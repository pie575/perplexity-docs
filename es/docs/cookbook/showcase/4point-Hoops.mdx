**4Point Hoops** es una plataforma avanzada de análisis de la NBA que convierte las estadísticas de baloncesto en bruto en información útil y con contexto narrativo. Al extraer datos de Basketball-Reference en tiempo real y enviar prompts ricos en contexto al modelo Sonar Pro de Perplexity, ayuda a aficionados, analistas y jugadores de fantasy a entender el «por qué» y el «qué viene después», no solo las cifras.

<div id="features">
  ## Funcionalidades
</div>

* **Analítica de jugadores** con desgloses por temporada regular y playoffs, tipos de tiro y radar de rendimiento para cualquier jugador de la NBA
* **Comparaciones entre épocas** que permiten contrastar estadísticas en paralelo (por ejemplo, Michael Jordan &#39;97 frente a Stephen Curry &#39;22)
* **Paneles de equipos** con clasificaciones, diagramas Sankey de probabilidad de playoffs y tarjetas de KPI que se actualizan automáticamente
* **Explicación con IA y jugadores similares**, que ofrece explicaciones de Sonar con un solo clic sobre las líneas estadísticas y atletas comparables elegidos por IA
* **Chat de IA sobre baloncesto** que permite a los usuarios consultar a un LLM experto sobre historia, plantillas o proyecciones de la NBA
* **Sistema SaaS basado en créditos** con Firebase Auth, inicio de sesión con Google, monederos de créditos y herramientas de administración

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js 16+ y npm
* Python 3.8+ y pip
* Un proyecto de Firebase configurado
* API key de Perplexity (Sonar Pro)
* Acceso a Basketball-Reference

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clona el repositorio del frontend
git clone https://github.com/rapha18th/hoop-ai-frontend-44.git
cd hoop-ai-frontend-44
npm install

# Clona el repositorio del backend
git clone https://github.com/rapha18th/4Point-Hoops-Server.git
cd 4Point-Hoops-Server
pip install -r requirements.txt
```

<div id="configuration">
  ## Configuración
</div>

Crea un archivo `.env` en el directorio del backend:

```ini theme={null}
PERPLEXITY_API_KEY=your_sonar_pro_api_key
FIREBASE_PROJECT_ID=your_firebase_project_id
FIREBASE_PRIVATE_KEY=your_firebase_private_key
FIREBASE_CLIENT_EMAIL=your_firebase_client_email
```

<div id="usage">
  ## Uso
</div>

1. **Inicia el backend**:
   ```bash theme={null}
   cd 4Point-Hoops-Server
   python app.py
   ```

2. **Inicia el frontend**:
   ```bash theme={null}
   cd hoop-ai-frontend-44
   npm run dev
   ```

3. **Accede a la aplicación**: abre la URL del frontend y explora el análisis de la NBA con información generada por IA.

4. **Usa las funciones de IA**: haz clic en «Explicación con IA» en cualquier jugador o estadística para obtener un análisis inteligente impulsado por Perplexity Sonar.

<div id="code-explanation">
  ## Explicación del código
</div>

* **Frontend**: React con componentes de shadcn/ui y Recharts para la visualización de datos
* **Backend**: API en Python Flask que sirve datos de Basketball-Reference y gestiona las llamadas a la Perplexity API
* **Canalización de datos**: BRScraper para la recopilación de datos en tiempo real con caché en Firebase
* **Integración de IA**: Perplexity Sonar Pro para análisis y explicaciones inteligentes de baloncesto
* **Autenticación**: Firebase Auth con inicio de sesión con Google y control de acceso basado en créditos
* **Despliegue**: frontend en Netlify y backend en Hugging Face Spaces con Docker
