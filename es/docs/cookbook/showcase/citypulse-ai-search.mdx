<div id="citypulse-ai-powered-geospatial-discovery">
  # CityPulse: descubrimiento geoespacial con IA
</div>

![Interfaz principal de CityPulse](https://raw.githubusercontent.com/anevsky/CityPulse/main/assets/CityPulse-GeoSearch-App-1.jpg)

CityPulse es un buscador inteligente de descubrimiento por ubicación que permite a los usuarios explorar lo que ocurre a su alrededor en tiempo real. Muestra cómo generar información local personalizada y en tiempo real con los modelos Sonar de Perplexity.

[![Video de demostración](https://cdn.loom.com/sessions/thumbnails/6507fa27571442e680edf787b0f0690d-2fa2c36169822631-full-play.gif)](https://youtu.be/Y0UIhh3diJg)

<div id="what-citypulse-does">
  ## Qué hace CityPulse
</div>

* **Descubrimiento local en tiempo real**: encuentra eventos vigentes, restaurantes y alertas locales cerca de cualquier ubicación
* **Sugerencias de búsqueda con IA**: obtén recomendaciones de búsqueda inteligentes a medida que escribes
* **Información personalizada**: recibe consejos generados por IA sobre qué probar, cuáles son los mejores momentos para visitar y trucos de experto
* **Mapas interactivos**: explora los resultados en un mapa interactivo con marcadores personalizados y ventanas emergentes detalladas

![Interfaz de búsqueda](https://raw.githubusercontent.com/anevsky/CityPulse/main/assets/CityPulse-GeoSearch-App-2.jpg)

<div id="how-it-uses-perplexity-sonar">
  ## Cómo utiliza Perplexity Sonar
</div>

CityPulse se apoya en dos modelos clave de Perplexity:

**Sonar para datos en tiempo real**

```python theme={null}
# Obtener información local actualizada con contexto geográfico
response = client.chat.completions.create(
    model="sonar",
    messages=[{
        "role": "user", 
        "content": f"Find current events, restaurants, and alerts near {lat}, {lng}"
    }],
    response_format={"type": "json_schema", "json_schema": {"schema": LOCAL_INFO_SCHEMA}}
)
```

**Sonar Reasoning Pro para obtener información personalizada**

```python theme={null}
# Generar recomendaciones de lugares con IA
response = client.chat.completions.create(
    model="sonar-reasoning-pro",
    messages=[{
        "role": "user",
        "content": f"Provide personalized insights for {location_name}: what to try, best times to visit, pro tips"
    }]
)
```

La aplicación utiliza esquemas JSON estructurados para garantizar un formato de datos coherente e incluye seguimiento de citas para verificar las fuentes.
