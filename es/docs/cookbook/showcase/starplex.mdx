**StarPlex** es una plataforma de inteligencia para startups basada en IA que ayuda a los emprendedores a validar sus ideas de negocio y a conectarse con los recursos que necesitan para tener éxito. Funciona principalmente con **Perplexity Sonar Pro** y su interfaz principal es un **globo terráqueo 3D** interactivo. Basta con introducir tu idea de startup y observar cómo el motor de IA analiza y visualiza la información directamente sobre el globo: sitúa en el mapa competidores, mercados, datos demográficos, fondos de capital de riesgo y posibles cofundadores de todo el mundo en tiempo real.

<div id="features">
  ## Funcionalidades
</div>

* **Análisis de validación de mercado** con puntuación de resistencia a la IA, estimación de capitalización de mercado y análisis de tendencias de crecimiento
* **Interfaz interactiva de globo 3D** para visualizar datos de inteligencia global sobre startups
* **Investigación de competidores** con puntuación de amenaza y mapeo del panorama competitivo
* **Emparejamiento con fondos de capital riesgo e inversores** según la tesis de inversión y la afinidad con la cartera
* **Búsqueda de cofundadores** con puntuación de compatibilidad y coincidencia de experiencia
* **Investigación demográfica** con visualización en mapa de calor de las ubicaciones del público objetivo
* **Generación de pitch decks con IA** que crea presentaciones listas para inversores
* **Chatbot consciente del contexto** e integración de RAG sobre todos los datos de investigación

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js 18+ y npm
* Python 3.8+ y pip
* API key de Perplexity (Sonar Pro)
* Token de Mapbox y API key de SERP

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clonar el repositorio
git clone https://github.com/JerryWu0430/StarPlex.git
cd StarPlex

# Configuración del backend
cd backend
pip install -r requirements.txt

# Configuración del frontend
cd ../frontend
npm install
```

  ## Configuración

```ini theme={null}

MAPBOX_TOKEN=your_mapbox_token
SERPAPI_KEY=your_serpapi_key
```

<div id="usage">
  ## Uso
</div>

1. **Iniciar el backend**:
   ```bash theme={null}
   cd backend
   python main.py
   ```

2. **Iniciar el frontend**:
   ```bash theme={null}
   cd frontend
   npm run dev
   ```

3. **Acceder a la aplicación**: abre [http://localhost:3000](http://localhost:3000) e introduce tu idea de startup

4. **Explorar la información**: usa el globo 3D para visualizar competidores, fondos de capital riesgo, datos demográficos y posibles cofundadores

5. **Generar recursos**: crea pitch decks y conversa con el asistente de IA sobre tu análisis

<div id="how-starplex-uses-perplexity-sonar-api">
  ## Cómo usa StarPlex la Sonar API de Perplexity
</div>

StarPlex aprovecha la Sonar API de Perplexity mediante una **arquitectura de inteligencia multimódulo**:

**Motor de análisis de mercado**
Usa Sonar Pro para una validación integral del mercado: combina datos de Google Trends con análisis de IA para generar estimaciones de capitalización de mercado, puntuaciones de disrupción por IA y proyecciones de crecimiento, con salidas JSON estructuradas.

**Inteligencia competitiva**
Emplea múltiples consultas simultáneas a Sonar para identificar empresas competidoras, su estado de financiación y sus niveles de amenaza. Cada competidor recibe una puntuación de amenaza de 1 a 10 junto con un análisis detallado de su posicionamiento competitivo.

**Emparejamiento con fondos de capital riesgo y cofundadores**
Aprovecha el conocimiento web en tiempo real de Sonar para encontrar inversores relevantes y posibles cofundadores, y puntúa las coincidencias según la alineación con la tesis de inversión, la afinidad de experiencia y la proximidad geográfica.

**Asistente de negocio consciente del contexto**
Implementa RAG (generación aumentada por recuperación) inyectando todos los datos de investigación en las conversaciones de Sonar, lo que da lugar a un asesor de startups bien informado, capaz de responder preguntas sobre posicionamiento de mercado, amenazas competitivas y decisiones estratégicas.

**Inteligencia geográfica**
Combina los datos demográficos de Sonar con la geocodificación de Mapbox para crear mapas de calor interactivos que muestran dónde se concentran las audiencias objetivo a nivel mundial.

<div id="code-explanation">
  ## Explicación del código
</div>

* **Backend**: Python FastAPI con AsyncIO para realizar llamadas concurrentes a la Perplexity API desde varios módulos de análisis
* **Frontend**: Next.js con React 19, con Cobe para la visualización del globo en 3D y Mapbox GL para mapas interactivos
* **Integración de IA**: estrategia multimodelo de Perplexity que usa Sonar Pro para análisis complejos y Sonar para consultas más rápidas
* **Canalización de datos**: almacenamiento en caché inteligente, respuestas JSON estructuradas y streaming en tiempo real para ofrecer retroalimentación inmediata al usuario
* **Visualización**: vinculación dinámica de datos entre los hallazgos de Perplexity y las interfaces interactivas de globo y mapa
