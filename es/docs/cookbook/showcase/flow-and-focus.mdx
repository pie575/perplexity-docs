**Flow &amp; Focus** es una aplicación de noticias personalizada que convierte el consumo de noticias en una experiencia de aprendizaje. Combina de forma singular el descubrimiento rápido a través de un feed vertical de noticias (Flow) con diálogos de aprendizaje interactivos y en profundidad (Focus), impulsados por los modelos Sonar Pro y Sonar Deep Research de Perplexity.

<div id="features">
  ## Funcionalidades
</div>

* **Interfaz de doble modo**: Flow Feed para descubrir noticias rápidamente y Focus para profundizar de forma personalizada
* **Feed vertical de noticias**: fragmentos de noticias deslizables con resúmenes generados por IA, etiquetas e imágenes de fondo
* **Análisis profundos interactivos**: toca frases clave para acceder a contenido específico, con paneles de detalle desplazables en horizontal
* **Aprendizaje personalizado**: segmentos de conversación impulsados por IA con personajes como «Oracle» y «Explorer»
* **Personalización inteligente**: analiza los hábitos de lectura para adaptar automáticamente la selección de contenido
* **Contenido en tiempo real**: aprovecha Sonar Pro para noticias actualizadas y Sonar Deep Research para análisis detallados
* **Mejora visual**: imágenes de fondo dinámicas generadas con Runware.ai a partir de las palabras clave del contenido

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node.js 18+ y npm
* Clave de API de Perplexity
* Clave de API de Runware para la generación de imágenes
* Entorno con Next.js 15 y React 19

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clonar el repositorio
git clone https://github.com/michitomo/NewsReel.git
cd NewsReel

# Instalar las dependencias
npm install

# Configurar las variables de entorno
cp .env.example .env.local
```

<div id="configuration">
  ## Configuración
</div>

Crea el archivo `.env.local`:

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key_here
RUNWARE_API_KEY=your_runware_api_key_here
PERPLEXITY_FOCUS_MODEL=sonar-deep-research
```

<div id="usage">
  ## Uso
</div>

1. **Iniciar el servidor de desarrollo**:
   ```bash theme={null}
   npm run dev
   ```

2. **Acceder a la aplicación**: abre [http://localhost:3000](http://localhost:3000) en tu navegador

3. **Flow Feed**: desplázate verticalmente por los fragmentos de noticias y toca las frases clave para un análisis profundo

4. **Focus Mode**: genera resúmenes personalizados con segmentos de conversación interactivos

5. **Personalización**: tus hábitos de visualización influyen automáticamente en la selección del contenido

<div id="code-explanation">
  ## Explicación del código
</div>

* **Frontend**: Next.js 15 con React 19, TypeScript, Tailwind CSS y Framer Motion para las animaciones
* **Gestión del estado**: Zustand con persistencia en localStorage para las preferencias del usuario
* **Integración de IA**: Perplexity Sonar Pro para noticias en tiempo real y Sonar Deep Research para análisis en profundidad
* **Generación de imágenes**: integración del SDK de Runware para generar imágenes de fondo dinámicas según las palabras clave del contenido
* **Rutas de API**: integración del lado del servidor que gestiona las llamadas a las API de Perplexity y Runware
* **Diseño mobile-first**: gestos de deslizamiento y diseño adaptable para una experiencia móvil intuitiva
