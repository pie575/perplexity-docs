**MVP LifeLine** es una plataforma de IA multilingüe y offline-first que empodera a los jóvenes en lo emocional, lo financiero y lo profesional, en cualquier momento y lugar. Más de 1300 millones de jóvenes en todo el mundo se enfrentan a barreras para acceder a oportunidades profesionales y al bienestar mental, sobre todo en regiones remotas y desatendidas. MVP LifeLine derriba esas barreras combinando IA, acceso sin conexión, soporte multilingüe y un ecosistema integral de herramientas.

<div id="features">
  ## Funcionalidades
</div>

* **IA de doble modo** con Coach Profesional y Compañero Emocional impulsados por la Sonar API de Perplexity
* **Soporte multilingüe** en más de 10 idiomas, entre ellos inglés, francés, árabe, español, hindi e idiomas regionales
* **Diseño offline-first** con integración de SMS/USSD para regiones con poca conectividad
* **Ecosistema integral de herramientas** que abarca carrera profesional, bienestar, finanzas y productividad
* **Acceso SmartQ** para respuestas de IA contextuales y emocionalmente inteligentes
* **Digital Hustle Hub** con descubrimiento de trabajos temporales mediante IA y herramientas para freelancers
* **Zona de Bienestar** con meditaciones guiadas y ejercicios de reinicio mental
* **Zona de Finanzas** con seguimiento del presupuesto y consejos financieros pensados para jóvenes
* **Zona de Productividad** con tablero Kanban con IA y seguimiento de hábitos

<div id="prerequisites">
  ## Requisitos previos
</div>

* SDK de Flutter y Dart
* Proyecto de Firebase configurado
* Cuenta de Twilio para la integración con SMS/USSD
* API key de Perplexity (Sonar)
* API key de OpenAI (para el enriquecimiento)

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clonar el repositorio
git clone https://github.com/JohnUmoh/asgard.git
cd asgard

# Instalar las dependencias de Flutter
flutter pub get

# Configurar Firebase
flutterfire configure

# Configurar las variables de entorno
cp .env.example .env
```

<div id="configuration">
  ## Configuración
</div>

Crea el archivo `.env`:

```ini theme={null}
PERPLEXITY_API_KEY=your_sonar_api_key
OPENAI_API_KEY=your_openai_api_key
FIREBASE_PROJECT_ID=your_firebase_project_id
TWILIO_ACCOUNT_SID=your_twilio_sid
TWILIO_AUTH_TOKEN=your_twilio_token
```

<div id="usage">
  ## Uso
</div>

1. **Configurar Firebase**:
   ```bash theme={null}
   flutterfire configure
   ```

2. **Ejecutar la aplicación**:
   ```bash theme={null}
   flutter run
   ```

3. **Acceder a las funciones**:
   * Alterna entre los modos Career Coach y Emotional Companion
   * Usa SmartQ para obtener asistencia con IA en varios idiomas
   * Accede a las funciones sin conexión mediante SMS/USSD cuando la conectividad sea limitada
   * Explora las herramientas profesionales, las funciones de bienestar y los impulsores de productividad

<div id="code-explanation">
  ## Explicación del código
</div>

* **Frontend**: aplicación multiplataforma en Flutter con diseño adaptable para móvil y web
* **Backend**: Firebase para autenticación, almacenamiento de datos y sincronización en tiempo real
* **Integración de IA**: Sonar API de Perplexity para interacciones de IA en doble modo (Career Coach y Emotional Companion)
* **Soporte sin conexión**: integración con Twilio para comunicación por SMS/USSD en zonas con poca conectividad
* **Multilingüe**: Sonar API admite más de 10 idiomas con respuestas adaptadas al contexto
* **Sincronización de datos**: captura de datos sin conexión con resincronización automática al recuperarse la conectividad
* **Personalización**: la IA se adapta al idioma, el nivel de alfabetización, el historial de estados de ánimo y las preferencias del usuario
