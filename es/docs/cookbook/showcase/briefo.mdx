**Briefo** ofrece un feed de noticias personalizado y generado con IA, además de análisis en profundidad de empresas. Los lectores pueden seguir las noticias de última hora, solicitar análisis financieros bajo demanda y comentar los hallazgos con sus amigos, todo en una única experiencia móvil impulsada por la Sonar API de Perplexity.

<div id="features">
  ## Funcionalidades
</div>

* Feed de noticias personalizado en 17 categorías, con resúmenes generados por IA y enlaces a las fuentes
* Hilos privados y públicos para comentar y compartir artículos
* Lista de seguimiento con panorámicas del mercado en tiempo real y análisis opcionales con IA
* Informes de investigación profunda generados a partir de 12 criterios seleccionables, como dirección, competencia y valoración
* Asistente de chat de propósito general que recuerda los temas preferidos de cada usuario

<div id="prerequisites">
  ## Requisitos previos
</div>

* Node 18 LTS o superior
* npm, Yarn o pnpm
* Expo CLI (`npm i -g expo-cli`)
* Supabase CLI 1.0 o superior para la emulación local y el despliegue de Edge Functions

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
git clone https://github.com/adamblackman/briefo-public.git
cd briefo-public
npm install
```

<div id="environment-variables">
  ### Variables de entorno
</div>

```ini theme={null}

MY_SUPABASE_SERVICE_ROLE_KEY=...
PERPLEXITY_API_KEY=...
LINKPREVIEW_API_KEY=...
ALPACA_API_KEY=...

# .env.local        (dentro de supabase/)
# duplica o sobrescribe los secretos que requieran las Edge Functions
```

<div id="usage">
  ## Uso
</div>

Ejecuta el servidor de desarrollo de Expo:

```bash theme={null}
npx expo start
```

Despliega las Edge Functions cuando todo esté listo:

```bash theme={null}
supabase functions deploy perplexity-news perplexity-chat perplexity-research portfolio-tab-data
```

<div id="code-explanation">
  ## Explicación del código
</div>

* Frontend: React Native con Expo Router (Typescript) para iOS, Android y Web
* Backend: Supabase (PostgreSQL, Row Level Security, Realtime) para datos y autenticación
* Edge Functions: Typescript sobre Deno que invoca las APIs de Perplexity, Alpaca, Alpha Vantage y LinkPreview
* Hooks: los hooks de datos reutilizables al estilo React Query están en lib/ y hooks/
* Pruebas y linting: ESLint, Prettier y Expo Lint mantienen la calidad del código
