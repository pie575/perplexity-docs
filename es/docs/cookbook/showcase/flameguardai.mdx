<div id="how-it-works">
  ## ⚙️ Cómo funciona
</div>

<div id="the-flameguard-ai-process">
  ### El proceso de FlameGuard AI™
</div>

1. **📸 Carga**: el usuario sube una foto de su propiedad
2. **👁️ Análisis visual con IA**: la OpenAI Vision API identifica vulnerabilidades específicas (por ejemplo, un tejado inflamable o maleza seca en las inmediaciones)
3. **🔍 Investigación profunda**: para cada riesgo, generamos un **plan de investigación personalizado** y ejecutamos **llamadas iterativas de estilo agéntico** a Perplexity Sonar
4. **📄 Generación del informe**: la investigación se **agrega, organiza y formatea** en un informe HTML accionable, con citas, enlaces y orientación visual
5. **📧 Entrega**: el informe detallado se envía por correo electrónico con soluciones de bricolaje y recomendaciones profesionales

<div id="deep-research-with-perplexity-sonar-api">
  ### 🔍 Investigación profunda con la Perplexity Sonar API
</div>

La verdadera innovación está en cómo usamos la **Perplexity Sonar API**:

* La tratamos como un asistente de investigación que reúne la mejor información disponible
* Cada vulnerabilidad activa múltiples consultas sobre gravedad, estrategias de mitigación e información local
* Los resultados incluyen normativas regionales contra incendios, patrones climáticos y disponibilidad de contratistas locales

Este tipo de **investigación estructurada, confiable y potenciada por IA no sería posible sin Perplexity**.

<div id="technical-stack">
  ### Stack técnico
</div>

FlameGuard AI™ se apoya en un stack moderno de GenAI y está diseñado para escalar:

* **Frontend**: panel ligero en HTML con gestión de cuentas de usuario, carga de fotos y acceso a informes
* **Backend**: Python (Flask) con APIs RESTful
* **Base de datos**: PostgreSQL (local) con un esquema **listo para Azure SQL**
* **Integración de IA**: OpenAI Vision API + Perplexity Sonar API
* **Preparado para la nube**: creado para **Azure App Service** con despliegue en Docker

<div id="what-we-learned">
  ## 📚 Lo que aprendimos
</div>

* La **Perplexity Sonar API** es increíblemente potente cuando se usa de forma agéntica: no solo para obtener respuestas, sino para razonar.
* Combinar **IA multimodal (imagen + investigación)** abre la puerta a potentes herramientas de apoyo a la toma de decisiones.
* Los usuarios quieren **información aplicable a la práctica**, no solo datos: combinar la investigación con recomendaciones concretas marca la diferencia.
* La confianza y la claridad son fundamentales: nuestro diseño tenía que comunicar información compleja de forma sencilla y útil.
