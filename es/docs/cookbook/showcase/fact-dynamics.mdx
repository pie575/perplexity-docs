  # Fact Dynamics | Aplicación Flutter de verificación de datos en tiempo real
</div>

<p align="center">
  <img src="https://raw.githubusercontent.com/vishnu32510/fact_pulse/main/assets/icon/icon.png" alt="Fact Dynamics logo" width="80" height="80" style={{ borderRadius: '14px' }} />
</p>

**Proyecto de hackatón**: creado para el Perplexity Hackathon en las categorías Information Tools y Deep Research.

Fact Dynamics es una aplicación multiplataforma desarrollada en Flutter que verifica en tiempo real el contenido hablado y las imágenes. Ideal para debates en directo, presentaciones y verificación de información sobre la marcha.

<div id="features">
  ## Funcionalidades
</div>

* Transcripción de voz y verificación de datos en tiempo real durante conversaciones en vivo

* Extracción de texto de imágenes y verificación de afirmaciones con citas de las fuentes

* Sistema de calificación de afirmaciones (TRUE, FALSE, MISLEADING, UNVERIFIABLE) con explicaciones

* Citas de fuentes: proporciona URL de referencia que respaldan cada veredicto

* Modo debate con reconocimiento de voz continuo y respuesta en streaming

* Autenticación de usuarios mediante Firebase (Google, correo electrónico) con historial de chat persistente

* Compatibilidad multiplataforma con iOS, Android y web

<div id="prerequisites">
  ## Requisitos previos
</div>

* Flutter SDK 3.0.0 o posterior
* Dart SDK 2.17.0 o posterior
* Firebase CLI para la autenticación y la configuración de la base de datos
* API key de Perplexity para la integración con Sonar
* Dispositivo con acceso al micrófono para el reconocimiento de voz

<div id="usage">
  ## Uso
</div>

<div id="real-time-speech-fact-checking">
  ### Verificación de hechos del habla en tiempo real
</div>

* Transmite fragmentos de audio de 5 segundos mediante `speech_to_text` de Flutter
* Envía los fragmentos transcritos a la Sonar API con prompts estructurados
* Devuelve un JSON con afirmaciones, calificaciones (TRUE/FALSE/MISLEADING/UNVERIFIABLE), explicaciones y fuentes

<div id="image-analysis">
  ### Análisis de imágenes
</div>

* Sube imágenes o URL a la Sonar API para extraer texto
* Verifica las afirmaciones extraídas contra fuentes autorizadas
* Ofrece un análisis exhaustivo con atribución de fuentes

<div id="code-explanation">
  ## Explicación del código
</div>

* Frontend: Flutter con el patrón BLoC para la gestión del estado, con soporte para iOS, Android y Web
* Backend: Firebase (Firestore, Authentication) para los datos de usuario y la persistencia del historial de chat
* Procesamiento de voz: paquete speech&#95;to&#95;text para la transcripción de audio en tiempo real
* Integración de API: cliente personalizado en Dart que llama a la Sonar API de Perplexity con prompts estructurados
* Procesamiento de imágenes: selector de imágenes integrado con codificación base64 para el análisis multimodal
* Arquitectura de datos: colecciones de Firestore por usuario con subcolecciones para debates, discursos e imágenes
