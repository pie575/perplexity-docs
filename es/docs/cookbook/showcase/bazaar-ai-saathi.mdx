**BazaarAISaathi** es una plataforma impulsada por IA diseñada para ofrecer a los inversores información práctica sobre el mercado bursátil indio. Gracias al procesamiento avanzado de lenguaje natural, el análisis de datos en tiempo real y el modelado financiero elaborado por expertos, la aplicación ofrece estrategias de inversión personalizadas, análisis del sentimiento del mercado y recomendaciones para optimizar la cartera.

<div id="features">
  ## Funcionalidades
</div>

* **Planificador de independencia financiera (FIRE)** con planes personalizados según la edad, el salario y los objetivos
* **Verificador de consejos de inversión** que usa EasyOCR para la extracción de texto y validación con IA
* **Análisis fundamental y técnico** con informes completos de empresas y estrategias de trading
* **Análisis de carteras** con análisis multidimensional y recomendaciones por acción
* **Investigación de mercado y comparativa de la competencia** mediante análisis de tendencias del sector impulsado por IA
* **Datos bursátiles en tiempo real** con seguimiento de precios en directo y análisis de tendencias
* **Contraste de hipótesis** con datos de mercado históricos y en tiempo real
* **Resúmenes de libros de inversión** con síntesis concisas de los 50 mejores libros de inversión

<div id="prerequisites">
  ## Requisitos previos
</div>

* Python 3.8+ y pip
* Streamlit como framework de aplicaciones web
* API key de Perplexity (modelos Sonar)
* Opcional: EasyOCR para extraer texto de imágenes

<div id="installation">
  ## Instalación
</div>

```bash theme={null}
# Clonar el repositorio
git clone https://github.com/mahanteshimath/BazaarAISaathi.git
cd BazaarAISaathi

# Instalar las dependencias
pip install -r requirements.txt
```

<div id="configuration">
  ## Configuración
</div>

Crea el archivo `secrets.toml` para los secretos de Streamlit:

```ini theme={null}
PERPLEXITY_API_KEY = "your_perplexity_api_key"
# Añade otras API keys si las necesitas
```

<div id="usage">
  ## Uso
</div>

1. **Inicia la aplicación**:
   ```bash theme={null}
   streamlit run Home.py
   ```

2. **Accede a las funcionalidades**:
   * Navega por las distintas páginas para usar funciones específicas
   * Usa el panel principal para tener una visión general y desplazarte por la app
   * Accede a herramientas especializadas como el análisis de carteras, la planificación FIRE y la comprobación de recomendaciones

3. **Ejecuta módulos concretos**:
   ```bash theme={null}
   streamlit run pages/Financial_Independence.py
   streamlit run pages/Portfolio_Analysis.py
   streamlit run pages/Tip_Tester.py
   ```

<div id="code-explanation">
  ## Explicación del código
</div>

* **Frontend**: aplicación web en Streamlit con páginas interactivas y visualización de datos en tiempo real
* **Backend**: lógica de negocio en Python con Pandas para la manipulación y el análisis de datos
* **Integración de IA**: modelos de la Sonar API de Perplexity (sonar-deep-research, sonar-reasoning-pro, sonar-pro) para el análisis financiero
* **Procesamiento de datos**: obtención de datos bursátiles en tiempo real, gestión de datos en CSV y generación de información del mercado
* **Extracción de texto**: integración con EasyOCR para procesar consejos de inversión a partir de imágenes
* **Gestión de carteras**: análisis integral de carteras con recomendaciones de optimización
* **Análisis de mercado**: análisis técnico y fundamental con puntuación de sentimiento
