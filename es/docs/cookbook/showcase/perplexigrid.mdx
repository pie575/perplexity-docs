**PerplexiGrid** convierte el lenguaje natural en paneles interactivos y llenos de información. Conecta tus datos, combínalos con datos web en tiempo real, haz una pregunta y deja que la Sonar API se encargue del resto. Incluye diseño de arrastrar y soltar, generación de widgets con IA y visualizaciones basadas en ECharts.

<div id="features">
  ## Funcionalidades
</div>

* **De lenguaje natural a paneles**: convierte indicaciones en lenguaje natural en paneles de analítica totalmente funcionales con más de 25 tipos de widgets
* **Integración de datos en vivo**: combina tus propias fuentes de datos con datos web en tiempo real para obtener información completa
* **Diseño de cuadrícula interactivo**: interfaz de arrastrar y soltar para personalizar la disposición y el estilo de los paneles
* **Refinamiento con IA**: refina o añade widgets mediante actualizaciones conversacionales
* **Exportar y compartir**: genera exportaciones en PDF, imágenes de alta resolución y enlaces de paneles para compartir

<div id="how-it-uses-sonar">
  ## Cómo utiliza Sonar
</div>

PerplexiGrid aprovecha la Sonar API mediante cuatro modos especializados:

* **Generación completa de paneles (f1)**: crea paneles integrales con múltiples widgets aprovechando las capacidades avanzadas de Sonar Pro
* **Modo ligero (l1)**: genera visualizaciones rápidas para sistemas embebidos y aplicaciones en tiempo real
* **Actualización de paneles (r1)**: permite modificaciones dinámicas mediante lenguaje natural sin perder el contexto
* **Refinamiento de widgets (r2)**: ofrece un control preciso sobre la actualización de cada widget

El sistema utiliza respuestas con esquema JSON estructurado para garantizar una salida coherente y compatible con ECharts, que puede renderizarse directamente como visualizaciones interactivas.

<div id="code-explanation">
  ## Explicación del código
</div>

El usuario envía mensajes que se convierten en prompts dirigidos a una Supabase Edge Function que actúa como envoltorio de la Sonar API de Perplexity.
Según el modo (`f1`, `l1`, `r1` o `r2`), la función genera salidas estructuradas completas para paneles, visualizaciones ligeras o actualizaciones puntuales.
El diseño generado se analiza para obtener definiciones estructuradas de widgets, que luego pasan por nuestro motor de creación de widgets.

Explora nuestro [servicio principal sonar-api aquí.](https://github.com/PetarRan/perplexigrid/blob/main/server/supabase/functions/_shared/perplexityService.ts)

<div id="prompt-modes">
  ## Modos de prompt
</div>

| Modo | Descripción                           | Caso de uso                                                                                 | Notas                                                                                        |
| ---- | ------------------------------------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `f1` | Generación completa inicial del panel | El usuario parte de un lienzo vacío e introduce un prompt inicial                           | Genera un diseño de panel completo con varios widgets                                        |
| `l1` | Generación ligera del panel           | Útil para obtener información o vistas previas rápidas con pocos tokens                     | Más rápido y económico, pero devuelve menos widgets y con menor profundidad de instrucciones |
| `r1` | Regeneración completa del panel       | El usuario quiere reemplazar todos los widgets existentes con un nuevo prompt               | Reconstruye todo el panel sin alterar el diseño                                              |
| `r2` | Actualización puntual de un widget    | El usuario quiere cambiar un widget concreto (p. ej., «conviértelo en un gráfico circular») | Solo se modifica el widget seleccionado según la nueva instrucción                           |

<div id="tech-stack">
  ## Stack tecnológico
</div>

* **Frontend**: React + Vite (Typescript), ECharts, react-grid-layout
* **Backend**: Supabase Edge Functions (Typescript sobre Deno)
* **Motor de IA**: Perplexity Sonar Pro
* **Infraestructura**: Supabase (PostgreSQL, RLS, Auth), despliegue en Vercel
