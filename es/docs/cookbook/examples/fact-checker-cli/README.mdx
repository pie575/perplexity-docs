<div id="fact-checker-cli">
  # CLI de verificación de datos
</div>

Una herramienta de línea de comandos que identifica afirmaciones falsas o engañosas en artículos o declaraciones usando la Sonar API de Perplexity para investigar en la web.

<div id="features">
  ## Funcionalidades
</div>

* Analiza afirmaciones o artículos completos para verificar su exactitud factual
* Identifica afirmaciones falsas, engañosas o no verificables
* Proporciona explicaciones y correcciones de la información inexacta
* Devuelve los resultados en formato legible para humanos o en JSON estructurado
* Cita fuentes confiables para respaldar las evaluaciones de verificación de datos
* Aprovecha las salidas estructuradas de Perplexity para un parseo de JSON confiable (para usuarios de Tier 3 o superior)

<div id="installation">
  ## Instalación
</div>

<div id="1-install-required-dependencies">
  ### 1. Instala las dependencias necesarias
</div>

```bash theme={null}
# Instalar desde el archivo de requisitos (recomendado)
pip install -r requirements.txt

# O instalar manualmente
pip install requests pydantic newspaper3k
```

<div id="2-make-the-script-executable">
  ### 2. Da permisos de ejecución al script
</div>

```bash theme={null}
chmod +x fact_checker.py
```

<div id="api-key-setup">
  ## Configuración de la API key
</div>

La herramienta necesita una API key de Perplexity para funcionar. Puedes proporcionarla de una de estas formas:

<div id="1-as-a-command-line-argument">
  ### 1. Como argumento de línea de comandos
</div>

```bash theme={null}
./fact_checker.py --api-key YOUR_API_KEY
```

<div id="2-as-an-environment-variable">
  ### 2. Como variable de entorno
</div>

```bash theme={null}
export PPLX_API_KEY=YOUR_API_KEY
```

<div id="3-in-a-file">
  ### 3. En un archivo
</div>

Crea un archivo llamado `pplx_api_key` o `.pplx_api_key` en el mismo directorio que el script:

```bash theme={null}
echo "YOUR_API_KEY" > .pplx_api_key
chmod 600 .pplx_api_key
```

**Nota:** Si usas la función de salidas estructuradas, necesitarás una cuenta de Perplexity API con nivel de acceso Tier 3 o superior.

<div id="quick-start">
  ## Inicio rápido
</div>

Ejecuta el siguiente comando justo después de la configuración:

```bash theme={null}
./fact_checker.py -t "The Earth is flat and NASA is hiding the truth."
```

Esto analizará la afirmación, la investigará con la Sonar API de Perplexity y devolverá una verificación de hechos detallada con valoraciones, explicaciones y fuentes.

<div id="usage">
  ## Uso
</div>

<div id="check-a-claim">
  ### Verificar una afirmación
</div>

```bash theme={null}
./fact_checker.py --text "The Earth is flat and NASA is hiding the truth."
```

<div id="check-an-article-from-a-file">
  ### Verificar un artículo desde un archivo
</div>

```bash theme={null}
./fact_checker.py --file article.txt
```

<div id="check-an-article-from-a-url">
  ### Verificar un artículo desde una URL
</div>

```bash theme={null}
./fact_checker.py --url https://www.example.com/news/article-to-check
```

<div id="specify-a-different-model">
  ### Especificar un modelo diferente
</div>

```bash theme={null}
./fact_checker.py --text "Global temperatures have decreased over the past century." --model "sonar-pro"
```

<div id="output-results-as-json">
  ### Devolver los resultados en formato JSON
</div>

```bash theme={null}
./fact_checker.py --text "Mars has a breathable atmosphere." --json
```

<div id="use-a-custom-prompt-file">
  ### Usar un archivo de prompt personalizado
</div>

```bash theme={null}
./fact_checker.py --text "The first human heart transplant was performed in the United States." --prompt-file custom_prompt.md
```

<div id="enable-structured-outputs-for-tier-3-users">
  ### Habilitar salidas estructuradas (para usuarios de Tier 3 o superior)
</div>

La salida estructurada está deshabilitada de forma predeterminada. Para activarla, pasa la opción `--structured-output`:

```bash theme={null}
./fact_checker.py --text "Vaccines cause autism." --structured-output
```

<div id="get-help">
  ### Obtener ayuda
</div>

```bash theme={null}
./fact_checker.py --help
```

<div id="output-format">
  ## Formato de salida
</div>

La herramienta genera una salida que incluye:

* **Calificación general**: MOSTLY&#95;TRUE, MIXED o MOSTLY&#95;FALSE
* **Resumen**: una síntesis breve de los resultados de la verificación de datos
* **Análisis de afirmaciones**: una lista de afirmaciones específicas con calificaciones individuales:
  * TRUE: exacta y respaldada por evidencia
  * FALSE: contradicha por la evidencia
  * MISLEADING: contiene algo de verdad, pero puede llevar a conclusiones incorrectas
  * UNVERIFIABLE: no se puede verificar de forma concluyente con la información disponible
* **Explicaciones**: razonamiento detallado de cada afirmación
* **Fuentes**: citas y URL utilizadas para la verificación

<div id="example">
  ## Ejemplo
</div>

Ejecuta el siguiente comando:

```bash theme={null}
./fact_checker.py -t "The Great Wall of China is visible from the moon."
```

Salida de ejemplo:

```
Verificación de datos en curso...

🔴 VALORACIÓN GENERAL: MOSTLY_FALSE

📝 RESUMEN:
La afirmación de que la Gran Muralla China es visible desde la Luna es falsa. Se trata de una idea errónea muy extendida que han refutado tanto los astronautas de la NASA como la evidencia científica.

🔍 ANÁLISIS DE LAS AFIRMACIONES:

Afirmación 1: ❌ FALSA  
  Declaración: «La Gran Muralla China es visible desde la Luna».  
  Explicación: La Gran Muralla China no se ve desde la Luna a simple vista. Los astronautas de la NASA así lo han confirmado, entre ellos Neil Armstrong, quien declaró que no pudo ver la Muralla desde la órbita lunar. La Muralla es demasiado estrecha y su color se confunde con el del entorno al observarla desde esa distancia.  
  Fuentes:
    - NASA.gov
    - Scientific American
    - National Geographic
```

<div id="limitations">
  ## Limitaciones
</div>

* La precisión de la verificación de datos depende de la calidad de la información disponible a través de la Sonar API de Perplexity.
* Como ocurre con todos los modelos de lenguaje, la IA subyacente puede tener limitaciones en ciertos dominios especializados.
* La función de salidas estructuradas requiere una cuenta de Perplexity API de Tier 3 o superior.
* La herramienta no sustituye a los servicios profesionales de verificación de datos cuando se trata de contenido muy delicado o complejo.
