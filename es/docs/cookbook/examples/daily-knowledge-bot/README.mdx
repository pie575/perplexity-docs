<div id="daily-knowledge-bot">
  # Daily Knowledge Bot
</div>

Una aplicación en Python que ofrece datos curiosos sobre temas rotativos mediante la API de Perplexity AI. Ideal para el aprendizaje diario, el contenido de boletines o la formación personal.

<div id="features">
  ## 🌟 Características
</div>

* **Rotación diaria de temas**: selecciona automáticamente los temas según el día del mes
* **Datos generados con IA**: usa la Sonar API de Perplexity para generar datos curiosos y precisos
* **Temas personalizables**: amplía o modifica fácilmente la lista de temas
* **Almacenamiento persistente**: guarda los datos en archivos de texto fechados para consultarlos más adelante
* **Manejo robusto de errores**: gestiona sin contratiempos los fallos de la API y los errores inesperados
* **Configurable**: usa variables de entorno para gestionar de forma segura la API key

<div id="requirements">
  ## 📋 Requisitos
</div>

* Python 3.6+
* Paquetes necesarios:
  * requests
  * python-dotenv
  * (opcional) logging

<div id="installation">
  ## 🚀 Instalación
</div>

1. Clona este repositorio o descarga el script
2. Instala los paquetes necesarios:

```bash theme={null}
# Instalar desde el archivo de requisitos (recomendado)
pip install -r requirements.txt

# O instalar manualmente
pip install requests python-dotenv
```

3. Configura tu API key de Perplexity:
   * Crea un archivo `.env` en el mismo directorio que el script
   * Añade tu API key: `PERPLEXITY_API_KEY=your_api_key_here`

<div id="usage">
  ## 🔧 Uso
</div>

<div id="running-the-bot">
  ### Ejecutar el bot
</div>

Basta con ejecutar el script:

```bash theme={null}
python daily_knowledge_bot.py
```

Esto hará lo siguiente:

1. Seleccionar un tema según el día actual
2. Obtener un dato interesante de Perplexity AI
3. Guardar el dato en un archivo de texto fechado en tu directorio actual
4. Mostrar el dato en la consola

<div id="customizing-topics">
  ### Personalizar los temas
</div>

Edita el archivo `topics.txt` (un tema por línea) o modifica la lista `topics` directamente en el script.

Temas de ejemplo:

```
astronomía
historia
biología
tecnología
psicología
vida marina
civilizaciones antiguas
física cuántica
historia del arte
ciencia culinaria
```

<div id="automated-scheduling">
  ### Programación automatizada
</div>

<div id="on-linuxmacos-using-cron">
  #### En Linux/macOS (con cron):
</div>

```bash theme={null}
# Edita tu crontab
crontab -e

# Añade esta línea para ejecutarlo todos los días a las 8:00 AM
0 8 * * * /path/to/python3 /path/to/daily_knowledge_bot.py
```

<div id="on-windows-using-task-scheduler">
  #### En Windows (con el Programador de tareas):
</div>

1. Abre el Programador de tareas
2. Crea una tarea básica nueva
3. Configúrala para que se ejecute a diario
4. Añade la acción: Iniciar un programa
5. Programa o script: `C:\path\to\python.exe`
6. Argumentos: `C:\path\to\daily_knowledge_bot.py`

<div id="configuration-options">
  ## 🔍 Opciones de configuración
</div>

Las siguientes variables de entorno se pueden definir en tu archivo `.env`:

* `PERPLEXITY_API_KEY` (obligatoria): tu API key de Perplexity
* `OUTPUT_DIR` (opcional): directorio donde se guardarán los archivos de datos (valor predeterminado: directorio actual)
* `TOPICS_FILE` (opcional): ruta a tu archivo de temas personalizado

<div id="extending-the-bot">
  ## 🛠️ Cómo ampliar el bot
</div>

Algunas formas de ampliar este bot:

* Añadir capacidades de envío por correo electrónico o SMS
* Crear una interfaz web para consultar el historial de datos curiosos
* Integrarlo con la publicación en redes sociales
* Añadir contenido multimedia relacionado con los datos
* Implementar una programación avanzada con temas concretos en días concretos

<div id="limitations">
  ## ⚠️ Limitaciones
</div>

* Pueden aplicarse límites de velocidad de la API según tu cuenta de Perplexity
* La calidad de los datos depende del modelo de IA
* La versión gratuita de la Sonar API tiene un límite de tokens que puede truncar las respuestas más largas
