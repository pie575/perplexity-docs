<div id="academic-research-finder-cli">
  # CLI de búsqueda de literatura académica
</div>

Una herramienta de línea de comandos que utiliza la Sonar API de Perplexity para encontrar y resumir literatura académica (artículos de investigación, publicaciones, etc.) relacionada con una pregunta o un tema determinado.

<div id="features">
  ## Características
</div>

* Recibe como entrada una pregunta o un tema en lenguaje natural, ideal para consultas académicas.
* Aprovecha la Sonar API de Perplexity, guiada por un prompt especializado para priorizar fuentes académicas (por ejemplo, revistas científicas, actas de congresos y bases de datos académicas).
* Genera un resumen conciso a partir de los hallazgos de la literatura académica.
* Enumera las principales fuentes académicas utilizadas, procurando incluir detalles como autores, año, título, publicación y DOI o enlace cuando sea posible.
* Admite distintos modelos de Perplexity (por defecto, `sonar-pro`).
* Permite obtener los resultados en formato JSON.

<div id="installation">
  ## Instalación
</div>

<div id="1-install-required-dependencies">
  ### 1. Instala las dependencias necesarias
</div>

Asegúrate de usar el entorno de Python con el que vas a ejecutar el script (por ejemplo, `python3.10` si esa es tu versión de destino).

```bash theme={null}
# Instalar desde el archivo de requisitos (recomendado)
pip install -r requirements.txt

# O instalar manualmente
pip install requests
```

<div id="2-make-the-script-executable-optional">
  ### 2. Dar permisos de ejecución al script (opcional)
</div>

```bash theme={null}
chmod +x research_finder.py
```

Como alternativa, puedes ejecutar el script con `python3 research_finder.py ...`.

<div id="api-key-setup">
  ## Configuración de la API key
</div>

La herramienta necesita una API key de Perplexity (`PPLX_API_KEY`) para funcionar. Puedes proporcionarla de cualquiera de estas formas (se comprueban en este orden):

1. **Como argumento de línea de comandos:**
   ```bash theme={null}
   python3 research_finder.py "Your query" --api-key YOUR_API_KEY
   ```
2. **Como variable de entorno:**
   ```bash theme={null}
   export PPLX_API_KEY=YOUR_API_KEY
   python3 research_finder.py "Your query"
   ```
3. **En un archivo:** Crea un archivo llamado `pplx_api_key`, `.pplx_api_key`, `PPLX_API_KEY` o `.PPLX_API_KEY` en el *mismo directorio que el script* o en el *directorio de trabajo actual*, que contenga únicamente tu API key.
   ```bash theme={null}
   echo "YOUR_API_KEY" > .pplx_api_key
   chmod 600 .pplx_api_key # Opcional: restringir permisos
   python3 research_finder.py "Your query"
   ```

<div id="usage">
  ## Uso
</div>

Ejecuta el script desde el directorio `sonar-use-cases/research_finder` o indica la ruta completa.

```bash theme={null}
# Uso básico
python3 research_finder.py "What are the latest advancements in quantum computing?"

# Uso de un modelo específico
python3 research_finder.py "Explain the concept of Large Language Models" --model sonar-small-online

# Obtener la salida en formato JSON
python3 research_finder.py "Summarize the plot of Dune Part Two" --json

# Uso de un archivo de system prompt personalizado
python3 research_finder.py "Benefits of renewable energy" --prompt-file /path/to/your/custom_prompt.md

# Uso de una API key mediante argumento
python3 research_finder.py "Who won the last FIFA World Cup?" --api-key sk-...

# Uso del ejecutable (si se aplicó chmod +x)
./research_finder.py "Latest news about Mars exploration"
```

<div id="arguments">
  ### Argumentos
</div>

* `query`: (Obligatorio) La pregunta o el tema de investigación (enciérralo entre comillas si contiene espacios).
* `-m`, `--model`: Especifica el modelo de Perplexity (por defecto: `sonar-pro`).
* `-k`, `--api-key`: Proporciona la API key directamente.
* `-p`, `--prompt-file`: Ruta a un archivo de system prompt personalizado.
* `-j`, `--json`: Devuelve los resultados en formato JSON.

<div id="limitations">
  ## Limitaciones
</div>

* La capacidad de Sonar API para priorizar y acceder de forma consistente a bases de datos académicas concretas o para extraer información detallada de las citas (como los DOI) puede variar. La calidad depende de las capacidades de búsqueda de la API y de la estructura de los sitios web de origen.
* El script hace un análisis básico para separar el resumen de las fuentes; puede que las respuestas complejas o poco habituales de la API no se analicen correctamente. Si surgen problemas, revisa la respuesta sin procesar.
* Las consultas demasiado amplias o poco adecuadas para la búsqueda académica pueden arrojar resultados menos relevantes.
* El manejo de errores para los límites de tasa u otros errores específicos de la API podría ser más granular.
