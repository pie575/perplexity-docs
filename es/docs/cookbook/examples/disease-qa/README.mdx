<div id="disease-information-app">
  # Aplicación de información sobre enfermedades
</div>

Una aplicación interactiva que se ejecuta en el navegador y ofrece información estructurada sobre enfermedades mediante la Sonar API de Perplexity. Esta aplicación genera una interfaz HTML autónoma que permite a los usuarios hacer preguntas sobre distintas enfermedades y recibir respuestas organizadas con citas.

<div id="features">
  ## 🌟 Características
</div>

* **Interfaz intuitiva**: diseño limpio y adaptable que funciona en cualquier dispositivo
* **Respuestas con IA**: aprovecha la Sonar API de Perplexity para ofrecer información médica precisa
* **Tarjetas de conocimiento estructuradas**: organiza la información en Descripción general, Causas y Tratamientos
* **Seguimiento de citas**: enumera las fuentes de información con enlaces clicables
* **Caché en el cliente**: evita llamadas duplicadas a la API para preguntas ya realizadas
* **Despliegue autónomo**: genera un único archivo HTML que puede usarse sin servidor
* **Gestión integral de errores**: mensajes de error claros y un manejo de errores robusto

<div id="requirements">
  ## 📋 Requisitos
</div>

* Python 3.6+
* Jupyter Notebook o JupyterLab (para desarrollo/generación)
* Paquetes necesarios:
  * requests
  * pandas
  * python-dotenv
  * IPython

<div id="setup-installation">
  ## 🚀 Configuración e instalación
</div>

1. Clona este repositorio o descarga el notebook
2. Instala los paquetes necesarios:

```bash theme={null}
# Instalar desde el archivo de requisitos (recomendado)
pip install -r requirements.txt

# O instalar manualmente
pip install requests pandas python-dotenv ipython
```

3. Configura tu API key de Perplexity:
   * Crea un archivo `.env` en el mismo directorio que el notebook
   * Añade tu API key: `PERPLEXITY_API_KEY=your_api_key_here`

<div id="usage">
  ## 🔧 Uso
</div>

<div id="running-the-notebook">
  ### Ejecutar el notebook
</div>

1. Abre el notebook en Jupyter:

```bash theme={null}
jupyter notebook Disease_Information_App.ipynb
```

2. Ejecuta todas las celdas para generar e iniciar la aplicación basada en navegador
3. La aplicación se abrirá automáticamente en tu navegador web predeterminado

<div id="using-the-generated-html">
  ### Uso del HTML generado
</div>

También puedes usar directamente el archivo `disease_qa.html` generado:

1. Ábrelo en cualquier navegador web moderno
2. Escribe una pregunta sobre una enfermedad (por ejemplo, «¿Qué es la diabetes?» o «Háblame de la enfermedad de Alzheimer»)
3. Haz clic en «Ask» para obtener información estructurada sobre la enfermedad

<div id="deploying-the-app">
  ### Despliegue de la aplicación
</div>

Para uso personal o educativo, basta con compartir el archivo HTML generado.

Para uso en producción, ten en cuenta lo siguiente:

1. Configurar un backend adecuado para proteger tu API key
2. Alojar el archivo en un servidor web
3. Añadir analíticas y gestión de usuarios según sea necesario

<div id="how-it-works">
  ## 🔍 Cómo funciona
</div>

Esta aplicación:

1. Usa un prompt cuidadosamente diseñado para indicarle a la IA que devuelva JSON estructurado
2. Procesa ese JSON para extraer descripción general, Causas, Tratamientos y citas
3. Presenta la información en un formato claro de tarjeta de conocimiento
4. Implementa llamadas a la API desde el cliente con un manejo de errores adecuado
5. Ofrece un diseño adaptable, apto tanto para escritorio como para móvil

<div id="technical-details">
  ## ⚙️ Detalles técnicos
</div>

<div id="api-structure">
  ### Estructura de la API
</div>

La aplicación espera que la IA devuelva un objeto JSON con esta estructura:

```json theme={null}
{
  "overview": "A brief description of the disease.",
  "causes": "The causes of the disease.",
  "treatments": "Possible treatments for the disease.",
  "citations": ["https://example.com/citation1", "https://example.com/citation2"]
}
```

<div id="customization-options">
  ### Opciones de personalización
</div>

Puedes modificar:

* Los estilos HTML/CSS de la función `create_html_ui`
* El modelo de IA utilizado (por defecto, &quot;sonar-pro&quot;)
* La estructura del prompt para los distintos campos de información
* La ubicación y el nombre del archivo de salida

<div id="extending-the-app">
  ## 🛠️ Cómo ampliar la aplicación
</div>

Posibles ampliaciones:

* Añadir un backend con Flask/Django para proteger la API key
* Implementar cuentas de usuario y preguntas guardadas
* Añadir visualizaciones de estadísticas de enfermedades
* Crear una vista comparativa de varias enfermedades
* Añadir reformulación de preguntas en lenguaje natural
* Implementar mecanismos de comentarios sobre la calidad de las respuestas

<div id="important-notes">
  ## ⚠️ Notas importantes
</div>

* **Seguridad de la API key**: la implementación actual incrusta tu API key en el archivo HTML. Esto resulta adecuado para uso personal, pero no para un despliegue público.
* **No es asesoramiento médico**: esta aplicación ofrece información general y no debe utilizarse para tomar decisiones médicas. Consulta siempre a profesionales de la salud.
* **Uso de la API**: ten en cuenta los límites de tasa y los precios de la Perplexity API aplicables a tu cuenta.
