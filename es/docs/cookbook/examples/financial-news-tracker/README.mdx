<div id="financial-news-tracker">
  # Rastreador de noticias financieras
</div>

Una herramienta de línea de comandos que obtiene y analiza noticias financieras en tiempo real con la Sonar API de Perplexity. Consigue análisis completos del mercado, resúmenes de noticias y análisis de inversión sobre cualquier tema financiero.

<div id="features">
  ## Funcionalidades
</div>

* Agregación de noticias financieras en tiempo real desde múltiples fuentes
* Análisis del sentimiento del mercado (alcista/bajista/neutral)
* Evaluación del impacto de cada noticia (alto/medio/bajo)
* Análisis por sector y por empresa
* Perspectivas y recomendaciones de inversión
* Rangos temporales personalizables (de 24 h a 1 año)
* Compatibilidad con salida estructurada en JSON
* Salida en la CLI atractiva y enriquecida con emojis

<div id="api-key-setup">
  ## Configuración de la API key
</div>

La herramienta requiere una API key de Perplexity. Puedes proporcionarla de una de estas formas:

<div id="1-as-an-environment-variable-recommended">
  ### 1. Como variable de entorno (recomendado)
</div>

```bash theme={null}
export PPLX_API_KEY=YOUR_API_KEY
```

<div id="2-as-a-command-line-argument">
  ### 2. Como argumento de línea de comandos
</div>

```bash theme={null}
./financial_news_tracker.py "tech stocks" --api-key YOUR_API_KEY
```

<div id="3-in-a-file">
  ### 3. En un archivo
</div>

Crea un archivo llamado `pplx_api_key` o `.pplx_api_key` en el mismo directorio:

```bash theme={null}
echo "YOUR_API_KEY" > .pplx_api_key
chmod 600 .pplx_api_key
```

<div id="time-range-options">
  ## Opciones de rango temporal
</div>

<div id="output-format">
  ## Formato de salida
</div>

La herramienta ofrece un análisis financiero completo que incluye:

<div id="1-executive-summary">
  ### 1. Resumen ejecutivo
</div>

Una breve descripción general de los principales acontecimientos financieros

<div id="2-market-analysis">
  ### 2. Análisis de mercado
</div>

* **Sentimiento del mercado**: Clima general del mercado (🐂 Alcista, 🐻 Bajista, ⚖️ Neutral)
* **Factores clave**: Elementos que influyen en el mercado
* **Riesgos**: Riesgos e inquietudes actuales del mercado
* **Oportunidades**: Posibles oportunidades de inversión

<div id="3-news-items">
  ### 3. Noticias
</div>

Cada noticia incluye:

* **Titular**: el título principal de la noticia
* **Impacto**: nivel de impacto en el mercado (🔴 Alto, 🟡 Medio, 🟢 Bajo)
* **Resumen**: breve descripción de la noticia
* **Sectores afectados**: sectores o empresas afectadas
* **Fuente**: atribución de la fuente de la noticia

<div id="4-investment-insights">
  ### 4. Perspectivas de inversión
</div>

<div id="tips-for-best-results">
  ## Consejos para obtener los mejores resultados
</div>

1. **Sé específico**: incluye tickers de empresas, nombres de sectores o eventos concretos
2. **Combina temas**: mezcla nombres de empresas con temáticas relevantes (por ejemplo, «TSLA vehículos eléctricos»)
3. **Usa rangos temporales**: ajusta el rango temporal a tu horizonte de inversión
4. **Monitoreo periódico**: configura tareas cron para recibir actualizaciones diarias del mercado

<div id="limitations">
  ## Limitaciones
</div>

* Los resultados dependen de la información pública disponible
* No constituye asesoramiento financiero: investiga siempre por tu cuenta
* Los datos históricos pueden ser limitados en el caso de sucesos muy recientes
* La salida estructurada requiere acceso de nivel 3 o superior a la Perplexity API

<div id="python-integration">
  ### Integración con Python
</div>

```python theme={null}
import subprocess
import json

def get_financial_news(query, time_range="24h"):
    result = subprocess.run(
        ["./financial_news_tracker.py", query, "--time-range", time_range, "--json"],
        capture_output=True,
        text=True
    )
    
    if result.returncode == 0:
        return json.loads(result.stdout)
    else:
        raise Exception(f"Error fetching news: {result.stderr}")

# Ejemplo de uso
news = get_financial_news("tech stocks", "1w")
print(f"Market sentiment: {news['market_analysis']['market_sentiment']}")
```
