<div id="configuration">
  ## Configuración
</div>

| Ajuste                     | `quick` (predeterminado) | `showcase` |
| -------------------------- | -----------------------: | ---------: |
| Esfuerzo de razonamiento   |                 `medium` |     `high` |
| Límite de tokens de salida |                   49.152 |     65.536 |
| Máximo de pasos del agente |                        8 |         20 |

Puedes anular cualquiera de estos valores:

```bash theme={null}
python data_story.py "AI inference economics" \
  --effort xhigh \
  --max-output-tokens 64000 \
  --max-steps 14
```

`max_output_tokens` es un tope, no una reserva. Se te factura por el trabajo que la ejecución realiza efectivamente. Consulta los [precios vigentes](/es/docs/getting-started/pricing) antes de lanzar ejecuciones grandes.

Ese tope abarca tanto los tokens de razonamiento como la página visible, y este modelo razona extensamente antes de escribir. Un presupuesto que parece generoso para un único archivo HTML puede agotarse a mitad del documento; por eso `quick` establece 49.152 y no una cifra más cercana al tamaño de la página final. Si una ejecución agota su presupuesto, el script lo indica y menciona el tope, en lugar de devolver un documento mal formado.

Los seis niveles de esfuerzo funcionan. En `perplexityai==0.43.1` el tipo generado no incluye `max`, así que el script envía ese único valor a través del mecanismo `extra_body` del SDK y usa el campo tipado `reasoning` para todo lo demás.

<div id="how-it-works">
  ## Cómo funciona
</div>

1. Construye una única solicitud de la Agent API con `web_search`, un nivel de esfuerzo, un tope de salida y un límite de pasos.
2. Envíala una sola vez con `background=True` y `store=True`, y con los reintentos de creación desactivados.
3. El ID de la respuesta se devuelve de inmediato. Escríbelo en el comprobante antes que nada, porque ese ID es tu vía de recuperación.
4. Sondea `client.responses.retrieve(response_id)` con tiempos de espera acotados y backoff, imprimiendo los cambios de estado y las nuevas consultas de búsqueda a medida que aparecen.
5. Kimi K3 etiqueta cada tarjeta de estadísticas y cada marca de gráfico con un ID de resultado numérico y deja un marcador de posición `PERPLEXITY_SOURCES`.
6. Al completarse, valida el documento, coteja cada ID referenciado con los `search_results` de la API, inyecta las URL reales y una Content Security Policy, y luego escribe el archivo de forma atómica.

Solo `completed` cuenta como éxito. `queued` e `in_progress` indican que hay que seguir esperando; cualquier otro valor se trata como terminal, de modo que un estado nuevo nunca puede dejarte atrapado en un sondeo infinito.

Si la llamada de creación falla antes de devolver un ID, el resultado queda realmente en el aire. La CLI registra `submission_unknown` y se detiene en lugar de arriesgarse a cobrarte dos veces. Revisa la actividad de tu API antes de volver a enviar la solicitud.

<div id="trace-every-number-to-a-source">
  ### Rastrea cada cifra hasta su fuente
</div>

K3 nunca escribe una URL externa. El prompt le pide fragmentos de cita como `#source-3` y `data-source-id="3"`, y la CLI sustituye la URL real del resultado 3 tomada de la salida estructurada de la API. Un modelo puede alucinar una URL; lo que no puede alucinar es un índice de array que tiene que coincidir.

El validador rechaza documentos incompletos, IDs de fuente desconocidos, URLs escritas por el modelo, recursos remotos, marcos, formularios activos, JavaScript con acceso a la red, marcas de gráficos no enfocables, animaciones SVG SMIL y marcas dibujadas fuera del `viewBox` de su gráfico. También bloquea las reglas globales `svg { width: 100% }`, que sin avisar convierten iconos de 16px en gráficos a página completa.

Con eso se detectan los fallos estructurales y de renderizado, pero no dice nada sobre si una frase interpreta correctamente su fuente.

<div id="prompting-notes">
  ## Notas sobre el prompting
</div>

* Mantén la investigación y la construcción de la página en un único prompt de dos fases para que K3 pueda vincular los IDs de las fuentes con el marcado que escribe.
* Pide la terminología propia de la fuente y descarta cualquier alcance inferido. Una cita puede ser real y, aun así, la frase que la rodea puede exagerar el hallazgo.
* Especifica el contrato del gráfico de forma mecánica: `data-source-id` numérico, cita coincidente, geometría enfocable, escala de ejes compartida, límites visibles y un tooltip por marca.
* Exige animación con CSS y una consulta de movimiento reducido. SMIL queda descartado porque CSS no puede desactivarlo de forma fiable.
* Limita el dimensionamiento adaptable a `figure svg`, nunca a todos los SVG de la página.

<div id="3-define-the-errors-and-the-run-receipt">
  ### 3. Definir los errores y el comprobante de ejecución
</div>

Cinco tipos de excepción que distinguen entre «sigue en curso», «falló» y «realmente no lo sabemos». `SubmissionUnknownError` es el clave: si la conexión se cae antes de que llegue un ID, no hay forma de saber si se te cobró. `atomic_write_text` escribe en un archivo temporal y luego lo renombra, así que un fallo a mitad de la escritura no puede dejarte un informe escrito a medias.

<Accordion title="Mostrar el código (133 líneas)">
  ```python data_story.py (part 3 of 10) theme={null}
  class RunError(RuntimeError):
      """Base class for recoverable or terminal run failures."""


  class SubmissionUnknownError(RunError):
      """The create connection failed before a response ID was received."""


  class PendingRunError(RunError):
      """Local waiting ended while the durable server-side run may continue."""

      def __init__(self, response_id: str):
          self.response_id = response_id
          super().__init__(
              f"Run {response_id} did not reach a known terminal state locally. "
              "Resume without creating a new run: "
              f"python data_story.py --resume {response_id}"
          )


  class TerminalRunError(RunError):
      """The Agent API reported a non-success terminal status."""


  class StoryValidationError(RunError):
      """The completed response did not satisfy the artifact contract."""


  def get_value(value: Any, name: str, default: Any = None) -> Any:
      if isinstance(value, dict):
          return value.get(name, default)
      return getattr(value, name, default)


  def plain_value(value: Any) -> Any:
      if value is None or isinstance(value, (str, int, float, bool)):
          return value
      if isinstance(value, dict):
          return {str(key): plain_value(item) for key, item in value.items()}
      if isinstance(value, (list, tuple)):
          return [plain_value(item) for item in value]
      if hasattr(value, "model_dump"):
          return value.model_dump(mode="json")
      return str(value)


  def utc_now() -> str:
      return datetime.now(timezone.utc).isoformat()


  def atomic_write_text(path: Path, text: str) -> None:
      path.parent.mkdir(parents=True, exist_ok=True)
      temporary: Path | None = None
      try:
          with tempfile.NamedTemporaryFile(
              "w", encoding="utf-8", dir=path.parent, prefix=f".{path.name}.", delete=False
          ) as handle:
              handle.write(text)
              handle.flush()
              os.fsync(handle.fileno())
              temporary = Path(handle.name)
          os.replace(temporary, path)
          temporary = None
      finally:
          if temporary is not None:
              temporary.unlink(missing_ok=True)


  def write_receipt(path: Path, receipt: dict[str, Any]) -> None:
      receipt["updated_at"] = utc_now()
      api_key = os.environ.get("PERPLEXITY_API_KEY")

      def redacted(value: Any) -> Any:
          if isinstance(value, str):
              return value.replace(api_key, "[REDACTED]") if api_key else value
          if isinstance(value, dict):
              return {key: redacted(item) for key, item in value.items()}
          if isinstance(value, list):
              return [redacted(item) for item in value]
          return value

      atomic_write_text(path, json.dumps(redacted(receipt), indent=2, ensure_ascii=False) + "\n")


  def begin_client_attempt(receipt: dict[str, Any], mode: str) -> dict[str, Any]:
      """Start a receipt attempt and migrate receipts created by older versions."""
      if not receipt.get("attempts") and (
          "client_elapsed_seconds" in receipt or "client_error" in receipt
      ):
          legacy: dict[str, Any] = {
              "mode": "resume" if receipt.get("resume_history") else "submit",
              "status": receipt.get("status", "unknown"),
              "finished_at": receipt.get("updated_at"),
          }
          if "client_elapsed_seconds" in receipt:
              legacy["elapsed_seconds"] = receipt["client_elapsed_seconds"]
          if "client_error" in receipt:
              legacy["error"] = receipt["client_error"]
          receipt.setdefault("attempts", []).append(legacy)

      receipt.pop("client_error", None)
      receipt.pop("client_wait_status", None)
      attempt = {"mode": mode, "status": "running", "started_at": utc_now()}
      receipt.setdefault("attempts", []).append(attempt)
      return attempt


  def finish_client_attempt(
      receipt: dict[str, Any],
      attempt: dict[str, Any],
      status: str,
      elapsed_seconds: float,
      error: BaseException | None = None,
  ) -> None:
      elapsed = round(elapsed_seconds, 3)
      attempt.update({"status": status, "finished_at": utc_now(), "elapsed_seconds": elapsed})
      if error is not None:
          detail = {"type": type(error).__name__, "message": str(error)}
          attempt["error"] = detail
          receipt["client_error"] = detail
      else:
          receipt.pop("client_error", None)
          receipt.pop("client_wait_status", None)
      elapsed_attempts = [
          float(item["elapsed_seconds"])
          for item in receipt.get("attempts", [])
          if isinstance(item, dict) and isinstance(item.get("elapsed_seconds"), (int, float))
      ]
      receipt["attempt_count"] = len(receipt.get("attempts", []))
      receipt["last_client_attempt_elapsed_seconds"] = elapsed
      receipt["client_elapsed_seconds"] = round(sum(elapsed_attempts), 3)
  ```

<div id="4-build-the-request-and-record-the-response">
  ### 4. Construir la solicitud y registrar la respuesta
</div>

`build_request` arma el payload y enruta el esfuerzo `max` mediante `extra_body` (el campo tipado no lo acepta en el SDK 0.43.1). `checkpoint_response` guarda en disco el ID de la respuesta en el momento en que llega, antes de cualquier otra operación, de modo que, si se produce un fallo en la línea siguiente, aún tendrás disponible la vía de `--resume`.

  ```python data_story.py (part 4 of 10) theme={null}
      provider_status = get_value(response, "status")
      if provider_status is not None:

      receipt["model"] = get_value(response, "model", receipt.get("model"))
  ```

  ### 5. Consulta periódicamente hasta que la ejecución termine
</div>

Recupera la respuesta a intervalos hasta que termine o venza el plazo local. Los errores transitorios se reintentan un número limitado de veces; las nuevas consultas de búsqueda se imprimen a medida que aparecen, de modo que una ejecución de diez minutos no deje la terminal en blanco.   def poll_response(
  ```python data_story.py (part 5 of 10) theme={null}
      client: Perplexity,
      response_id: str,
      receipt: dict[str, Any],
      receipt_path: Path,
      wait_timeout: float,
      poll_interval: float = POLL_INTERVAL_SECONDS,
      sleep: Callable[[float], None] = time.sleep,
      monotonic: Callable[[], float] = time.monotonic,
      started_at: float | None = None,
  ) -> Any:
      started = monotonic() if started_at is None else started_at
      deadline = started + wait_timeout
      poll_client = client.with_options(max_retries=0)
      last_status: str | None = None
      last_heartbeat = started
      retry_attempt = 0
      receipt["status"] = "waiting"
      write_receipt(receipt_path, receipt)
      while True:
          before_request = monotonic()
          if before_request >= deadline:
              receipt["client_wait_status"] = "timed_out"
              write_receipt(receipt_path, receipt)
              raise PendingRunError(response_id)
          remaining = deadline - before_request
          try:
              response = poll_client.responses.retrieve(
                  response_id,
                  timeout=min(remaining, 30.0),
              )
              retry_attempt = 0
          except (
              APIConnectionError, InternalServerError, RateLimitError, httpx.HTTPError
          ) as error:
              retry_attempt += 1
              now = monotonic()
              if retry_attempt >= POLL_RETRY_ATTEMPTS:
                  receipt["client_wait_status"] = "retrieval_failed"
                  write_receipt(receipt_path, receipt)
                  raise PendingRunError(response_id) from error
              delay = min(2 ** (retry_attempt - 1), 8, max(0.0, deadline - now))
              if delay <= 0:
                  receipt["client_wait_status"] = "timed_out"
                  write_receipt(receipt_path, receipt)
                  raise PendingRunError(response_id)
              print(f"\n  retrieval interrupted; retrying in {delay:g}s", file=sys.stderr)
              sleep(delay)
              continue

          status = str(get_value(response, "status", "unknown"))
          checkpoint_response(response, receipt, receipt_path)
          queries, sources = response_research(response)
          if queries or sources:
              known_queries = set(receipt.get("queries", []))
              record_research(receipt, receipt_path, queries, sources)
              for query in queries:
                  if query not in known_queries:
                      print(f"\r  searched: {query}" + " " * 20, file=sys.stderr)

          now = monotonic()
          if status != last_status or now - last_heartbeat >= 15:
              print(
                  f"\r  {status} · {now - started:,.0f}s elapsed" + " " * 20,
                  end="",
                  file=sys.stderr,
                  flush=True,
              )
              last_status = status
              last_heartbeat = now

          if status == "completed":
              print(file=sys.stderr)
              return response
          if status not in PENDING_STATUSES:
              print(file=sys.stderr)
              detail = response_error(response) or "No provider error detail was returned."
              raise TerminalRunError(f"Run {response_id} ended with status {status}: {detail}")
          if now >= deadline:
              receipt["client_wait_status"] = "timed_out"
              write_receipt(receipt_path, receipt)
              print(file=sys.stderr)
              raise PendingRunError(response_id)
          sleep(min(poll_interval, deadline - now))
  ```

  ```python data_story.py (part 7 of 10) theme={null}
  def svg_viewbox(value: str) -> tuple[float, float, float, float] | None:
      parts = [part for part in re.split(r"[\s,]+", value.strip()) if part]
      if len(parts) != 4:
          return None
      try:
          x, y, width, height = (float(part) for part in parts)
      except ValueError:
          return None
      if width <= 0 or height <= 0:
          return None
      return x, y, width, height

      tag: str, values: dict[str, str]
  ) -> tuple[float, float, float, float] | None:
      """Return untransformed bounds for simple SVG mark primitives."""

          return cx - rx, cy - ry, cx + rx, cy + ry  # type: ignore[operator]
      if tag == "rect":
          x = numeric_attribute(values, "x", 0.0)
          y = numeric_attribute(values, "y", 0.0)
          width = numeric_attribute(values, "width")
          height = numeric_attribute(values, "height")
          if None in {x, y, width, height} or width < 0 or height < 0:  # type: ignore[operator]
              return None
          return x, y, x + width, y + height  # type: ignore[operator]

          x2 = numeric_attribute(values, "x2", 0.0)
          y2 = numeric_attribute(values, "y2", 0.0)
  ```

<div id="9-inject-the-real-source-urls">
  ### 9. Inyectar las URL reales de las fuentes
</div>

Aquí es donde ocurre realmente el anclaje. Cada `data-source-id` que escribió el modelo se compara con los `search_results` estructurados de la API, y se sustituyen el título, la fecha y la URL reales. Un ID sin resultado coincidente hace fallar la ejecución.

Hay tres detalles que evitan que la lista inyectada parezca postiza. `has_sources_heading` comprueba si el modelo ya escribió su propio encabezado de Fuentes encima del marcador de posición y, en ese caso, omite el nuestro, de modo que la página nunca muestre la palabra dos veces. `SOURCE_STYLE` aplica estilos a la lista mediante `inherit` y `currentColor` en lugar de colores fijos, de forma que adopta la paleta que haya elegido el modelo, y una regla `:target` resalta la entrada a la que salta una cita.

`renumber_sources` se encarga de la numeración. El modelo cita los ID de resultados de búsqueda en bruto, que son dispersos, por lo que un marcador que dice `[33]` quedaría encima de una lista ordenada que lo representa como `3.`. La función asigna cada ID citado a su posición según el orden de primera aparición y luego reescribe el texto del marcador, el destino del ancla y el atributo `data-source-id` de forma conjunta, en una sola pasada, para que un intercambio como 1 por 2 y 2 por 1 no se propague en cascada.

  ```python data_story.py (part 9 of 10) theme={null}
  def authoritative_sources(sources: Iterable[dict[str, Any]]) -> dict[str, dict[str, Any]]:
      authoritative: dict[str, dict[str, Any]] = {}
      for source in sources:
          source_id = str(source.get("id", ""))

              raise StoryValidationError(f"Search result has an invalid numeric ID: {source_id!r}")

  def has_sources_heading(document: str, placeholder_index: int) -> bool:
      """Report whether the model already wrote a Sources heading above the placeholder.

      Only the innermost enclosing section is inspected, so a heading somewhere
      earlier in the page does not suppress our own.
      """
      prefix = document[:placeholder_index]
      section_start = prefix.rfind("<section")
      segment = prefix[section_start:] if section_start != -1 else prefix
      return re.search(r"<h[1-6]\b[^>]*>\s*sources\s*</h[1-6]>", segment, re.IGNORECASE) is not None


  def renumber_sources(document: str, used_ids: list[str]) -> tuple[str, list[str]]:
      """Renumber citations 1..N in order of first appearance.

      The model cites raw search-result IDs, which are sparse, so an ordered list
      renders "1." next to a marker that reads "[33]". Every marker, anchor target,
      and data-source-id is rewritten together, and the returned IDs are the new
      ones in list order.
      """
      mapping = {old: str(index) for index, old in enumerate(used_ids, start=1)}

      def rewrite_anchor(match: re.Match[str]) -> str:
          anchor = match.group(0)
          old = match.group(1)
          new = mapping.get(old)
          if new is None:
              return anchor
          opening_end = anchor.index(">") + 1
          opening = anchor[:opening_end].replace(f"#source-{old}", f"#source-{new}")
          body = re.sub(rf"\b{re.escape(old)}\b", new, anchor[opening_end:], count=1)
          return opening + body

      document = re.sub(
          r'<a\b[^>]*\bhref="#source-(\d+)"[^>]*>.*?</a>',
          rewrite_anchor,
          document,
          flags=re.DOTALL,
      )
      document = re.sub(
          r'data-source-id="(\d+)"',
          lambda match: f'data-source-id="{mapping.get(match.group(1), match.group(1))}"',
          document,
      )
      return document, [mapping[old] for old in used_ids]

          url = escape(str(source["url"]), quote=True)

          '  <h2 id="sources-heading">Sources</h2>\n'
          + ordered_list
          + "\n</section>"
      )


  def insert_csp(document: str) -> str:

              linked_ids.append(mark["source_id"])

                      or right > view_x + view_width + epsilon
                      or bottom > view_y + view_height + epsilon

          if not chart_ids.issubset(set(figure["citation_ids"])):
              raise StoryValidationError(
                  "Each figure must cite every source ID used by its chart marks."
              )

      if any(source_id is None or not re.fullmatch(r"\d+", source_id) for source_id in linked_ids):
          raise StoryValidationError("Every stat card and data mark needs a numeric data-source-id.")
      citation_ids = inspector.citation_ids
      if len(set(citation_ids)) < MIN_CITED_SOURCES:
          raise StoryValidationError(f"Expected citations to at least {MIN_CITED_SOURCES} sources.")

      sources = authoritative_sources(search_sources)
      used_ids = list(dict.fromkeys(citation_ids))
      missing = sorted(set(used_ids) - set(sources))
      if missing:
          raise StoryValidationError(f"Citations reference unknown search result IDs: {missing}")

      renumbered_html, new_ids = renumber_sources(raw_html, used_ids)
      renumbered_sources = {new: sources[old] for old, new in zip(used_ids, new_ids)}

      placeholder_index = renumbered_html.index(SOURCE_PLACEHOLDER)

          new_ids,
          renumbered_sources,
          include_heading=not has_sources_heading(renumbered_html, placeholder_index),
      )
      finalized = renumbered_html.replace(SOURCE_PLACEHOLDER, rendered)
  ```

<div id="limitations">
  ## Limitaciones
</div>

* **Es un borrador.** Las verificaciones estructurales de citas no permiten saber si una oración malinterpreta o exagera su fuente.
* **La geometría de un gráfico puede estar dentro de los límites y aun así ser incorrecta.** Las marcas se comprueban contra el `viewBox`, no contra el eje que dan a entender. Verifica la escala.
* **Revisa el tamaño de las etiquetas en móvil.** Un gráfico puede no desbordarse y aun así resultar ilegible a 390 px.
* **Una cobertura de búsqueda escasa falla de forma cerrada.** Si los resultados son escasos o contradictorios, la validación falla y no se escribe nada.
* **Las ejecuciones de alto esfuerzo tardan minutos.** Usa `--resume` con el ID de la respuesta en lugar de reenviar la solicitud.
* **Un tema denso puede agotar el presupuesto.** El razonamiento y la página comparten un mismo tope. La ejecución falla después de que ya la pagaste, así que aumenta `--max-output-tokens` en lugar de reintentar con el mismo presupuesto.
* **Una página, un archivo.** Una salida de varias páginas requiere otro enfoque.
* **Los comprobantes excluyen la API key**, pero pueden incluir el tema y fragmentos de las fuentes. Revísalos antes de compartirlos.
