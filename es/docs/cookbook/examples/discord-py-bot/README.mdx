Un sencillo bot de `discord.py` que integra la [Sonar API de Perplexity](https://docs.perplexity.ai/) en tu servidor de Discord. Haz preguntas y obtén respuestas generadas por IA con acceso a la web mediante comandos de barra o mencionando al bot.

<div id="features">
  ## ✨ Características
</div>

* **🌐 IA conectada a la web**: usa la Sonar API de Perplexity para obtener información actualizada
* **⚡ Comando de barra**: sencillo comando `/ask` para hacer preguntas
* **💬 Compatibilidad con menciones**: haz preguntas mencionando al bot
* **🔗 Citas de fuentes**: da formato y enlaza a las fuentes automáticamente
* **🔒 Configuración segura**: configuración basada en variables de entorno para las API keys

<div id="prerequisites">
  ## 🛠️ Requisitos previos
</div>

<Steps>
  <Step title="Entorno de Python">
    **Python 3.8+** instalado en tu sistema

    ```bash theme={null}
    python --version  # Debe ser 3.8 o superior
    ```
  </Step>

  <Step title="Acceso a la Perplexity API">
    **API key activa de la Perplexity API** desde la [consola de Perplexity API Platform](https://console.perplexity.ai)

    <Note>Necesitarás una cuenta de pago de Perplexity para acceder a la API. Consulta la [página de precios](https://www.perplexity.ai/pricing) para ver las tarifas actuales.</Note>
  </Step>

  <Step title="Aplicación de bot de Discord">
    **Token de bot de Discord** desde el [Discord Developer Portal](https://discord.com/developers/applications)
  </Step>
</Steps>

<div id="quick-start">
  ## 🚀 Inicio rápido
</div>

<div id="1-repository-setup">
  ### 1. Configuración del repositorio
</div>

Clona el repositorio y accede al directorio del bot:

```bash theme={null}
git clone https://github.com/ppl-ai/api-cookbook.git
cd api-cookbook/docs/examples/discord-py-bot/
```

<div id="2-install-dependencies">
  ### 2. Instalar dependencias
</div>

```bash theme={null}
# Crea un entorno virtual (recomendado)
python -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate

# Instala los paquetes necesarios
pip install -r requirements.txt
```

<div id="3-configure-api-keys">
  ### 3. Configurar las API keys
</div>

<Steps>
  <Step title="Obtén tu API key de Perplexity">
    1. Entra en la [consola de Perplexity API Platform](https://console.perplexity.ai)
    2. Genera una nueva API key
    3. Copia la clave en el archivo .env

    <Warning>¡Mantén tu API key a salvo! Nunca la subas al control de versiones ni la compartas públicamente.</Warning>
  </Step>

  <Step title="Crea la aplicación del bot de Discord">
    1. Ve al [Discord Developer Portal](https://discord.com/developers/applications)
    2. Haz clic en **&quot;New Application&quot;** y asígnale un nombre descriptivo
    3. Ve a la sección **&quot;Bot&quot;**
    4. Haz clic en **&quot;Reset Token&quot;** (o en &quot;Add Bot&quot; si es la primera vez)
    5. Copia el token del bot
  </Step>

  <Step title="Configura las variables de entorno">
    Copia el archivo de entorno de ejemplo y añade tus claves:

    ```bash theme={null}
    cp env.example .env
    ```

    Edita `.env` con tus credenciales:

    ```bash title=".env" theme={null}
    DISCORD_TOKEN="your_discord_bot_token_here"
    PERPLEXITY_API_KEY="your_perplexity_api_key_here"
    ```
  </Step>
</Steps>

<div id="usage-guide">
  ## 🎯 Guía de uso
</div>

<div id="bot-invitation-setup">
  ### Invitación y configuración del bot
</div>

<Steps>
  <Step title="Generar la URL de invitación">
    En el Discord Developer Portal:

    1. Ve a **OAuth2** → **URL Generator**
    2. Selecciona los scopes: `bot` y `applications.commands`
    3. Selecciona los permisos del bot: `Send Messages`, `Use Slash Commands`
    4. Copia la URL generada
  </Step>

  <Step title="Invitar al servidor">
    1. Pega la URL en tu navegador
    2. Selecciona el servidor de Discord al que quieres añadir el bot
    3. Confirma los permisos
  </Step>

  <Step title="Iniciar el bot">
    ```bash theme={null}
    python bot.py
    ```

    Deberías ver una salida que confirme que el bot está en línea y que los comandos se han sincronizado.
  </Step>
</Steps>

<div id="response-format">
  ## 📊 Formato de respuesta
</div>

El bot ofrece respuestas claras y legibles con:

* **Respuesta de la IA**: respuesta directa de la Sonar API de Perplexity
* **Citas de fuentes**: enlaces a las fuentes (cuando estén disponibles)
* **Truncamiento automático**: las respuestas se recortan para ajustarse a los límites de Discord

<div id="technical-details">
  ## 🔧 Detalles técnicos
</div>

Este bot utiliza:

* **Modelo**: el modelo `sonar-pro` de Perplexity
* **Límite de respuesta**: 2000 tokens de la API, truncados para ajustarse a Discord
* **Temperatura**: 0.2, para obtener respuestas coherentes y basadas en hechos
* **Sin permisos**: cualquier persona del servidor puede usar el bot
