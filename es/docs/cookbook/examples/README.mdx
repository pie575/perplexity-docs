<div id="examples-overview">
  # Descripción general de los ejemplos
</div>

<div id="api-key-setup">
  ## Configuración de la API key
</div>

Todos los ejemplos requieren una API key de Perplexity. Defínela como variable de entorno:

```bash theme={null}
export PERPLEXITY_API_KEY="your-api-key-here"
```

<Tip>
  Obtén tu API key en [perplexity.ai/account/api](https://perplexity.ai/account/api).
</Tip>

<div id="common-requirements">
  ## Requisitos comunes
</div>

* **Python 3.9+** o **Node.js 18+** (según el ejemplo)
* **Clave de API de Perplexity**
* **Conexión a internet** para las llamadas a la API

Los requisitos adicionales varían según el ejemplo y se indican en la documentación de cada proyecto.
