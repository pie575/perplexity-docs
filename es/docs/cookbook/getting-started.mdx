<div id="quick-start">
  ## Inicio rápido
</div>

<Steps>
  <Step title="Obtén acceso a la API">
    Para usar la plataforma de API de Perplexity, necesitarás una API key. Si aún no tienes una:

    <Card title="Obtén tu API key de Perplexity" icon="key" arrow="True" horizontal="True" iconType="solid" cta="Haz clic aquí" href="https://perplexity.ai/account/api">
      Ve a la pestaña **API Keys** del portal de API y genera una nueva clave.
    </Card>
  </Step>

  <Step title="Instala el SDK">
    El SDK de Perplexity API está disponible en Python y TypeScript. Instala el paquete del lenguaje que prefieras:

    <CodeGroup>
      ```bash Python theme={null}
      pip install perplexityai
      ```

      ```bash TypeScript theme={null}
      npm install @perplexity-ai/perplexity_ai
      ```
    </CodeGroup>
  </Step>

  <Step title="Elige un punto de partida">
    La plataforma de API de Perplexity admite una amplia variedad de casos de uso en sus distintas APIs. Estos son algunos puntos de partida recomendados según tus objetivos:

    * ¿Es tu primera vez en la plataforma? Consulta nuestra <u>[Guía de inicio rápido](/es/docs/getting-started/quickstart)</u>
    * ¿Quieres desarrollar algo? Echa un vistazo a nuestros <u>[Ejemplos](/es/docs/cookbook/examples/README)</u>
  </Step>
</Steps>
