Esta guía muestra cómo consumir respuestas en streaming de la Agent API, extraer las citas a medida que llegan, validar las URL de las fuentes y construir una salida completamente citada. El streaming resulta esencial para interfaces fluidas y búsquedas de larga duración: puedes mostrar el texto y las fuentes de forma progresiva en lugar de esperar a la respuesta completa.

<Info>
  El preset `fast` está optimizado para respuestas rápidas y ricas en citas. El modelo inserta referencias numeradas como `[1]`, `[2]` en el texto, y las URL de las fuentes correspondientes llegan en el elemento de salida `search_results`. Consulta la documentación de [presets de la Agent API](/es/docs/agent-api/presets) para conocer todos los presets disponibles.
</Info>

<div id="how-streaming-citations-work">
  ## Cómo funcionan las citas en streaming
</div>

Cuando recibes en streaming una respuesta de la Agent API con un preset que tiene la búsqueda habilitada, la API envía una secuencia de eventos server-sent (SSE). El flujo es el siguiente:

1. Los **resultados de búsqueda** llegan mediante eventos `response.reasoning.search_results` —un evento por cada búsqueda que ejecuta el model— y contienen las URL, los títulos y los fragmentos de cada fuente.
2. Los **fragmentos de contenido** llegan de forma incremental a medida que el model genera el texto, mediante eventos `response.output_text.delta`.
3. Las **referencias de citas** aparecen en el texto como marcadores numerados del tipo `[1]`, `[2]`, que se corresponden con el campo `id` del resultado de búsqueda.

Tu cliente acumula el texto, recopila los resultados de búsqueda y después asocia las referencias numeradas con las URL de las fuentes mediante el campo `id`.

<Warning>
  **Una respuesta puede contener más de un lote de resultados de búsqueda.** Los presets de un solo paso, como `fast`, suelen buscar una sola vez, pero los presets de varios pasos (como deep research) ejecutan muchas búsquedas: un evento `search_results` (en streaming) o un elemento de salida (sin streaming) por cada búsqueda, y todos comparten un mismo espacio de `id` de citas. Recopila siempre los resultados de **todos** los eventos o elementos. Si conservas solo el primer lote, la mayoría de las referencias `[N]` del texto no se resolverán y las citas parecerán alucinadas.
</Warning>

<div id="basic-streaming-with-citations">
  ## Streaming básico con citas
</div>

<CodeGroup>
  ```python Python theme={null}
  import os
  from openai import OpenAI

  # El SDK de OpenAI admite streaming de la Agent API mediante el alias /v1/responses
  client = OpenAI(
      api_key=os.environ["PERPLEXITY_API_KEY"],
      base_url="https://api.perplexity.ai/v1",
  )

  stream = client.responses.create(
      input="What are the latest breakthroughs in quantum computing?",
      stream=True,
      extra_body={"preset": "fast"},
  )

  full_content = ""
  search_results = []

  for event in stream:
      event_type = event.type

      # Recopila los resultados de búsqueda (un evento por búsqueda: acumula, no sobrescribas)
      if event_type == "response.reasoning.search_results":
          search_results.extend(event.results or [])

      # Acumula el contenido de cada delta
      if event_type == "response.output_text.delta":
          full_content += event.delta
          print(event.delta, end="", flush=True)

  print("\n\n--- Citations ---")
  for result in search_results:
      print(f"[{result['id']}] {result['title']} — {result['url']}")
  ```

<div id="parsing-citation-references-from-text">
  ## Análisis de referencias de citas en el texto
</div>

El modelo inserta referencias numeradas como `[1]`, `[2]` en el texto generado. Para construir una salida enriquecida con enlaces en los que se pueda hacer clic, analiza esas referencias y asígnalas a las URL de las fuentes usando los resultados de búsqueda.

<CodeGroup>
  ```python Python theme={null}
  import re
  from perplexity import Perplexity

  client = Perplexity()


  def extract_citation_refs(text: str) -> list[int]:
      """Extrae todos los números de referencia de cita del texto, p. ej. [1], [2]."""
      return sorted(set(int(m) for m in re.findall(r"\[(\d+)\]", text)))


  def build_cited_output(content: str, search_results: list) -> str:
      """Reemplaza las referencias [N] por enlaces markdown y añade una sección de referencias."""
      cited_content = content

      # Construye un mapa de id a URL
      url_map = {r.id: r.url for r in search_results}
      title_map = {r.id: r.title for r in search_results}

      # Reemplaza las referencias en línea por enlaces markdown
      for ref_id, url in url_map.items():
          cited_content = cited_content.replace(
              f"[{ref_id}]",
              f"[[{ref_id}]]({url})"
          )

      # Añade una sección de referencias con todas las fuentes citadas
      used_refs = extract_citation_refs(content)
      if used_refs:
          cited_content += "\n\n---\n**References:**\n"
          for ref in used_refs:
              if ref in url_map:
                  cited_content += f"- [{ref}] {title_map[ref]} — {url_map[ref]}\n"

      return cited_content


  # Solicitud sin streaming para obtener el contenido + los resultados de búsqueda
  response = client.responses.create(
      preset="fast",
      input="What is CRISPR gene editing and how does it work?",
  )

  # Extrae los resultados de búsqueda de la salida de la respuesta.
  # Los presets de varios pasos devuelven un elemento search_results por cada paso de investigación,
  # y todos comparten un mismo espacio de ids: recopila los resultados de cada elemento.
  content = response.output_text
  search_results = []
  for item in response.output:
      if item.type == "search_results":
          search_results.extend(item.results or [])

  # Construye la salida final con las citas enlazadas
  output = build_cited_output(content, search_results)
  print(output)
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from "@perplexity-ai/perplexity_ai";

  const client = new Perplexity();

  function extractCitationRefs(text: string): number[] {
      const refs = new Set<number>();
      for (const match of text.matchAll(/\[(\d+)\]/g)) {
          refs.add(parseInt(match[1]));
      }
      return [...refs].sort((a, b) => a - b);
  }

  function buildCitedOutput(
      content: string,
      searchResults: Array<{ id: number; url: string; title: string }>
  ): string {
      let cited = content;

      // Construye mapas de id a URL y a título
      const urlMap = new Map(searchResults.map((r) => [r.id, r.url]));
      const titleMap = new Map(searchResults.map((r) => [r.id, r.title]));

      // Reemplaza las referencias en línea por enlaces markdown
      for (const [id, url] of urlMap) {
          cited = cited.replaceAll(`[${id}]`, `[[${id}]](${url})`);
      }

      // Añade una sección de referencias
      const usedRefs = extractCitationRefs(content);
      if (usedRefs.length > 0) {
          cited += "\n\n---\n**References:**\n";
          for (const ref of usedRefs) {
              if (urlMap.has(ref)) {
                  cited += `- [${ref}] ${titleMap.get(ref)} — ${urlMap.get(ref)}\n`;
              }
          }
      }

      return cited;
  }

  // Solicitud sin streaming para obtener el contenido + los resultados de búsqueda
  const response = await client.responses.create({
      preset: "fast",
      input: "What is CRISPR gene editing and how does it work?",
  });

  // Extrae los resultados de búsqueda de la salida de la respuesta.
  // Los presets de varios pasos devuelven un elemento search_results por cada paso de investigación,
  // y todos comparten un mismo espacio de ids: recopila los resultados de cada elemento.
  const content = response.output_text;
  const searchResults: Array<{ id: number; url: string; title: string }> = [];
  for (const item of response.output) {
      if (item.type === "search_results") {
          searchResults.push(...((item as any).results ?? []));
      }
  }

  const output = buildCitedOutput(content, searchResults);
  console.log(output);
  ```
</CodeGroup>

<div id="validating-citation-urls">
  ## Validación de las URL de las citas
</div>

En sistemas de producción, conviene validar que las URL de las citas estén bien formadas y sean accesibles antes de mostrarlas a los usuarios. Así se evitan enlaces rotos y se refuerza la confianza en la salida.

<CodeGroup>
  ```python Python theme={null}
  import asyncio
  import aiohttp
  from urllib.parse import urlparse


  def is_valid_url(url: str) -> bool:
      """Comprueba que una URL tenga una estructura válida."""
      try:
          result = urlparse(url)
          return all([result.scheme in ("http", "https"), result.netloc])
      except Exception:
          return False


  async def check_url_reachable(url: str, timeout: float = 5.0) -> dict:
      """Envía una petición HEAD a una URL para comprobar si es accesible."""
      if not is_valid_url(url):
          return {"url": url, "valid": False, "reason": "malformed URL"}

      try:
          async with aiohttp.ClientSession() as session:
              async with session.head(url, timeout=aiohttp.ClientTimeout(total=timeout), allow_redirects=True) as resp:
                  return {
                      "url": url,
                      "valid": resp.status < 400,
                      "status": resp.status,
                  }
      except asyncio.TimeoutError:
          return {"url": url, "valid": False, "reason": "timeout"}
      except Exception as e:
          return {"url": url, "valid": False, "reason": str(e)}


  async def validate_citations(search_results: list) -> list[dict]:
      """Valida de forma concurrente todas las URL de las citas de los resultados de búsqueda."""
      tasks = [check_url_reachable(r.url) for r in search_results]
      return await asyncio.gather(*tasks)


  # Uso tras obtener una respuesta:
  # results = asyncio.run(validate_citations(search_results))
  # for r in results:
  #     status = "OK" if r["valid"] else f"FAILED ({r.get('reason', r.get('status'))})"
  #     print(f"  {r['url']}: {status}")
  ```

  ```typescript TypeScript theme={null}
  function isValidUrl(url: string): boolean {
      try {
          const parsed = new URL(url);
          return parsed.protocol === "http:" || parsed.protocol === "https:";
      } catch {
          return false;
      }
  }

  async function checkUrlReachable(url: string, timeoutMs = 5000): Promise<{ url: string; valid: boolean; reason?: string; status?: number }> {
      if (!isValidUrl(url)) {
          return { url, valid: false, reason: "malformed URL" };
      }

      try {
          const controller = new AbortController();
          const timer = setTimeout(() => controller.abort(), timeoutMs);
          const resp = await fetch(url, { method: "HEAD", signal: controller.signal, redirect: "follow" });
          clearTimeout(timer);
          return { url, valid: resp.status < 400, status: resp.status };
      } catch (e: any) {
          return { url, valid: false, reason: e.message };
      }
  }

  async function validateCitations(searchResults: Array<{ url: string }>): Promise<Array<{ url: string; valid: boolean; reason?: string }>> {
      return Promise.all(searchResults.map(r => checkUrlReachable(r.url)));
  }

  //     console.log(`  ${r.url}: ${status}`);
  // });
  ```
</CodeGroup>

<Warning>
  **Nunca pidas al modelo que genere URL de fuentes.** Usa siempre la salida `search_results` de la respuesta de la API. Las URL generadas por el modelo pueden ser alucinaciones. Los resultados de búsqueda contienen URL verificadas procedentes de búsquedas web reales.
</Warning>

<div id="progressive-display-with-live-citation-count">
  ## Visualización progresiva con conteo de citas en vivo
</div>

En las interfaces de chat resulta útil mostrar un contador de citas en vivo a medida que el texto llega en streaming y, cuando el flujo termina, renderizar la lista completa de referencias.

<CodeGroup>
  ```python Python theme={null}
  import os
  import re
  import sys
  from openai import OpenAI

  client = OpenAI(
      api_key=os.environ["PERPLEXITY_API_KEY"],
      base_url="https://api.perplexity.ai/v1",
  )


  def stream_with_progress(query: str):
      """Transmite una respuesta con un contador de citas en vivo."""
      stream = client.responses.create(
          input=query,
          stream=True,
          extra_body={"preset": "fast"},
      )

      full_content = ""
      search_results = []
      seen_refs = set()

      for event in stream:
          if event.type == "response.reasoning.search_results":
              search_results.extend(event.results or [])

          if event.type == "response.output_text.delta":
              full_content += event.delta
              sys.stdout.write(event.delta)
              sys.stdout.flush()

              # Detecta nuevas referencias de citas en el texto acumulado
              # (los deltas individuales pueden dividir [N] entre fragmentos)
              current_refs = set(int(m) for m in re.findall(r"\[(\d+)\]", full_content))
              if current_refs - seen_refs:
                  seen_refs = current_refs
                  sys.stdout.write(f" [📚 {len(seen_refs)} sources]")
                  sys.stdout.flush()

      # Resumen final
      print(f"\n\n{'='*60}")
      print(f"Response complete: {len(search_results)} sources found, {len(seen_refs)} cited")
      print(f"{'='*60}")

      # Construye el mapa de URL a partir de los resultados de búsqueda
      url_map = {r["id"]: r for r in search_results}
      for ref_id in sorted(seen_refs):
          if ref_id in url_map:
              r = url_map[ref_id]
              print(f"  ✓ [{ref_id}] {r['title']} — {r['url']}")

      return full_content, search_results


  content, results = stream_with_progress(
      "What are the environmental impacts of lithium mining?"
  )
  ```

<div id="complete-example-streaming-research-assistant">
  ## Ejemplo completo: asistente de investigación con streaming
</div>

Un script autónomo que transmite en streaming una respuesta de la Agent API, extrae las citas, valida las URL y genera una salida con formato markdown.

<CodeGroup>
  ```python Python theme={null}
  import os
  import re
  from urllib.parse import urlparse
  from openai import OpenAI

  client = OpenAI(
      api_key=os.environ["PERPLEXITY_API_KEY"],
      base_url="https://api.perplexity.ai/v1",
  )


  def is_valid_url(url: str) -> bool:
      try:
          result = urlparse(url)
          return all([result.scheme in ("http", "https"), result.netloc])
      except Exception:
          return False


  def stream_and_collect(query: str) -> tuple[str, list[dict]]:
      """Transmite una respuesta de la Agent API y devuelve el contenido completo y los resultados de búsqueda."""
      stream = client.responses.create(
          input=query,
          stream=True,
          extra_body={"preset": "fast"},
      )

      content = ""
      search_results = []

      for event in stream:
          if event.type == "response.reasoning.search_results":
              search_results.extend(event.results or [])

          if event.type == "response.output_text.delta":
              content += event.delta
              print(event.delta, end="", flush=True)

      print()  # salto de línea tras el streaming
      return content, search_results


  def format_markdown_report(query: str, content: str, search_results: list[dict]) -> str:
      """Construye un informe en markdown con enlaces de cita en línea."""
      # Construye el mapa de URL a partir de los resultados de búsqueda
      url_map = {r["id"]: r["url"] for r in search_results}
      title_map = {r["id"]: r["title"] for r in search_results}

      # Sustituye [N] por enlaces de markdown
      formatted = content
      for ref_id, url in url_map.items():
          if is_valid_url(url):
              formatted = formatted.replace(f"[{ref_id}]", f"[\\[{ref_id}\\]]({url})")

      # Construye el informe
      report = f"# {query}\n\n{formatted}\n\n"

      # Añade las fuentes
      used_refs = sorted(set(int(m) for m in re.findall(r"\[(\d+)\]", content)))
      if search_results:
          report += "## Sources\n\n"
          for result in search_results:
              marker = "→" if result["id"] in used_refs else " "
              report += f"{marker} **[{result['id']}]** {result['title']} — {result['url']}\n\n"

      return report


  if __name__ == "__main__":
      query = "What are the most promising approaches to carbon capture technology?"

      print(f"Researching: {query}\n")
      print("-" * 60)

      content, search_results = stream_and_collect(query)

      print(f"\n{'=' * 60}")
      print(f"Collected {len(search_results)} sources\n")

      # Descarta las URL mal formadas
      valid_results = [r for r in search_results if is_valid_url(r["url"])]
      invalid_count = len(search_results) - len(valid_results)
      if invalid_count:
          print(f"Warning: {invalid_count} sources had malformed URLs and were excluded.\n")

      report = format_markdown_report(query, content, valid_results)
      print(report)
  ```
</CodeGroup>

<div id="tips-and-best-practices">
  ## Consejos y buenas prácticas
</div>

1. **Usa un preset con búsqueda habilitada** como `fast` o `low` para obtener respuestas ricas en citas. Cada preset usa un formato de cita distinto: `fast` usa `[1]`, mientras que `low` usa `[web:1]`.

2. **Acumula los resultados de búsqueda de todos los eventos o elementos.** Una respuesta contiene un evento `search_results` (en streaming) o un elemento de salida (sin streaming) por cada búsqueda que haya ejecutado el model; los presets de varios pasos ejecutan muchas. Añade cada lote a una única lista: sobrescribir en cada evento o leer solo el primer elemento descarta silenciosamente la mayoría de las fuentes.

3. **Usa el campo `id` para asociar las citas.** Cada resultado de búsqueda tiene un `id` numérico que corresponde a la referencia `[N]` del texto.

4. **Valida las URL antes de mostrarlas.** Usa solicitudes HEAD con tiempos de espera para descartar las fuentes inaccesibles.

5. **Nunca generes tus propias URL.** Usa únicamente los `search_results` de la respuesta de la API. Las URL generadas por el model pueden ser alucinaciones.

6. **Gestiona con elegancia las referencias faltantes.** Si una referencia `[N]` del texto no tiene un `id` coincidente en los resultados de búsqueda que recopilaste, muestra el número de referencia sin enlace en lugar de provocar un fallo.

7. **Ten en cuenta la limitación de tasa al validar las URL.** Si la respuesta incluye muchas fuentes, valídalas con límites de concurrencia para no saturar los servidores de destino.
