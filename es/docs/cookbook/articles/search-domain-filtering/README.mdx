Esta guía trata el filtrado por dominio en la búsqueda en la Agent API. Aprenderás a usar listas de permitidos para limitar la búsqueda a dominios confiables, listas de exclusión para descartar fuentes no deseadas y patrones prácticos para casos de uso habituales, como la búsqueda exclusiva de noticias, los datos gubernamentales y la exclusión de competidores.

<Info>
  El filtrado por dominio se configura por herramienta dentro del arreglo `tools`, mediante `tools[].filters.search_domain_filter`. Para consultar la referencia completa, revisa [Filtros de la Agent API](/es/docs/agent-api/tools/web-search#filters).
</Info>

<div id="how-domain-filtering-works">
  ## Cómo funciona el filtrado por dominio
</div>

El parámetro `search_domain_filter` acepta una lista de cadenas de dominios:

* **Lista de permitidos** (sin prefijo): incluye solo los resultados de esos dominios. `["reuters.com", "apnews.com"]` significa buscar únicamente en Reuters y AP News.
* **Lista de exclusión** (prefijo `-`): excluye los resultados de esos dominios. `["-reddit.com", "-twitter.com"]` significa excluir Reddit y Twitter.

*También puedes añadir una ruta a un dominio para acotar los resultados a una sección concreta de un sitio: `["nature.com/articles"]` busca solo en esa sección, mientras que `["-reddit.com/r/all"]` excluye esa sección, pero sigue buscando en el resto del sitio.*

<Warning>
  **Nunca mezcles entradas de lista de permitidos y de lista de exclusión en la misma solicitud.** La API no admite combinar `"reuters.com"` y `"-reddit.com"` en el mismo arreglo. Usa o bien solo entradas de lista de permitidos, o bien solo de lista de exclusión.
</Warning>

<div id="basic-domain-filtering">
  ## Filtrado básico por dominio
</div>

Los filtros de dominio se configuran por herramienta dentro del arreglo `tools`.

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  # Lista de permitidos: buscar solo en dominios específicos
  response = client.responses.create(
      model="openai/gpt-5.4",
      input="What are the latest developments in AI regulation?",
      tools=[{
          "type": "web_search",
          "filters": {
              "search_domain_filter": ["reuters.com", "apnews.com", "bbc.com"],
          },
      }],
  )
  print(response.output_text)
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      model: "openai/gpt-5.4",
      input: "What are the latest developments in AI regulation?",
      tools: [{
          type: "web_search" as const,
          filters: {
              search_domain_filter: ["reuters.com", "apnews.com", "bbc.com"],
          },
      }],
  });
  console.log(response.output_text);
  ```
</CodeGroup>

<div id="pattern-path-filtering">
  ## Patrón: filtrado por ruta
</div>

Agrega una ruta después de un dominio para limitar los resultados a una sección de un sitio, como la documentación, un subreddit, un blog o una sección de noticias. Esto funciona tanto en modo de lista de permitidos como de lista de exclusión.

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  # Permitir una sola sección de un sitio y excluir una sección de otro
  response = client.responses.create(
      model="openai/gpt-5.4",
      input="Summarize recent peer-reviewed CRISPR results",
      tools=[{
          "type": "web_search",
          "filters": {
              "search_domain_filter": ["nature.com/articles", "science.org"],
          },
      }],
  )
  print(response.output_text)
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      model: "openai/gpt-5.4",
      input: "Summarize recent peer-reviewed CRISPR results",
      tools: [{
          type: "web_search" as const,
          filters: {
              search_domain_filter: ["nature.com/articles", "science.org"],
          },
      }],
  });
  console.log(response.output_text);
  ```
</CodeGroup>

<Note>
  Las rutas coinciden en los límites de segmento, por lo que `"example.com/docs"` coincide con `/docs` y `/docs/intro`, pero no con `/documentation`. Los subdominios se incluyen (`blog.example.com/docs` coincide). Se permiten cadenas de consulta después del límite (`/docs?x=1`).
</Note>

<div id="pattern-news-only-search">
  ## Patrón: búsqueda solo en noticias
</div>

Restringe los resultados a los principales medios informativos para cubrir la actualidad y las noticias de última hora.

<CodeGroup>
  ```python Python theme={null}

      "nytimes.com",

      tools=[{
          "type": "web_search",
          "filters": {
              "search_domain_filter": NEWS_DOMAINS,
              "search_recency_filter": "day",
          },
      }],
  )
  print(response.output_text)
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const NEWS_DOMAINS = [
      "reuters.com",
      "apnews.com",

      "bloomberg.com",
      "ft.com",
  ];

  const response = await client.responses.create({
      model: "openai/gpt-5.4",
      input: "What happened in global markets today?",
      tools: [{
          type: "web_search" as const,

          },
  ```

  Combina `search_domain_filter` con `search_recency_filter` en consultas que dependen de la actualidad. Las opciones son `day`, `week`, `month` y `year`.
</Tip>

<div id="configurable-filter-builder">
  ## Constructor de filtros configurable
</div>

Una función auxiliar reutilizable que crea configuraciones de filtros de dominio a partir de presets con nombre.

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  # Presets de filtros con nombre
  FILTER_PRESETS = {
      "news": ["reuters.com", "apnews.com", "bbc.com", "bloomberg.com", "ft.com"],
      "academic": [".edu", "arxiv.org", "nature.com", "science.org", "pubmed.ncbi.nlm.nih.gov"],
      "government": [".gov", ".gov.uk", ".europa.eu", "who.int"],
      "tech": ["techcrunch.com", "arstechnica.com", "theverge.com", "wired.com"],
      "no_social": ["-reddit.com", "-twitter.com", "-facebook.com", "-tiktok.com", "-quora.com"],
      "no_seo_spam": ["-pinterest.com", "-medium.com", "-hubspot.com"],
  }


  def search_with_preset(query: str, preset: str, recency: str = None) -> str:
      """Ejecuta una búsqueda con un preset de filtro de dominio con nombre."""
      if preset not in FILTER_PRESETS:
          raise ValueError(f"Unknown preset: {preset}. Options: {list(FILTER_PRESETS.keys())}")

      filters = {"search_domain_filter": FILTER_PRESETS[preset]}
      if recency:
          filters["search_recency_filter"] = recency

      response = client.responses.create(
          model="openai/gpt-5.4",
          input=query,
          tools=[{"type": "web_search", "filters": filters}],
      )
      return response.output_text


  # Uso
  print("--- News Search ---")
  print(search_with_preset("Latest AI regulation news", "news", recency="week"))

  print("\n--- Academic Search ---")
  print(search_with_preset("CRISPR gene editing recent papers", "academic"))

  print("\n--- Clean Search (no social media) ---")
  print(search_with_preset("Best Python testing frameworks", "no_social"))
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const FILTER_PRESETS: Record<string, string[]> = {
      news: ["reuters.com", "apnews.com", "bbc.com", "bloomberg.com", "ft.com"],
      academic: [".edu", "arxiv.org", "nature.com", "science.org", "pubmed.ncbi.nlm.nih.gov"],
      government: [".gov", ".gov.uk", ".europa.eu", "who.int"],
      tech: ["techcrunch.com", "arstechnica.com", "theverge.com", "wired.com"],
      no_social: ["-reddit.com", "-twitter.com", "-facebook.com", "-tiktok.com", "-quora.com"],
      no_seo_spam: ["-pinterest.com", "-medium.com", "-hubspot.com"],
  };

  async function searchWithPreset(query: string, preset: string, recency?: string): Promise<string> {
      if (!(preset in FILTER_PRESETS)) {
          throw new Error(`Unknown preset: ${preset}. Options: ${Object.keys(FILTER_PRESETS).join(", ")}`);
      }

      const filters: Record<string, any> = { search_domain_filter: FILTER_PRESETS[preset] };
      if (recency) filters.search_recency_filter = recency;

      const response = await client.responses.create({
          model: "openai/gpt-5.4",
          input: query,
          tools: [{ type: "web_search" as const, filters }],
      });
      return response.output_text;
  }

  console.log("--- News Search ---");
  console.log(await searchWithPreset("Latest AI regulation news", "news", "week"));

  console.log("\n--- Academic Search ---");
  console.log(await searchWithPreset("CRISPR gene editing recent papers", "academic"));

  console.log("\n--- Clean Search (no social media) ---");
  console.log(await searchWithPreset("Best Python testing frameworks", "no_social"));
  ```
</CodeGroup>

<div id="common-pitfalls">
  ## Errores comunes
</div>

<div id="mixing-allowlist-and-denylist">
  ### Mezclar lista de permitidos y lista de exclusión
</div>

```python theme={null}
# ❌ INCORRECTO: mezclar lista de permitidos y lista de exclusión
search_domain_filter=["reuters.com", "-reddit.com"]

# ✅ CORRECTO: usar solo la lista de permitidos
search_domain_filter=["reuters.com", "apnews.com", "bbc.com"]

# ✅ CORRECTO: usar solo la lista de exclusión
search_domain_filter=["-reddit.com", "-twitter.com"]
```

<div id="using-wildcards-incorrectly">
  ### Uso incorrecto de comodines
</div>

```python theme={null}
# ❌ INCORRECTO: no se admiten comodines
search_domain_filter=["*.gov"]

# ✅ CORRECTO: usa el TLD directamente
search_domain_filter=[".gov"]

# ✅ CORRECTO: limita a una sección con un prefijo de ruta (sin comodines)
search_domain_filter=["example.com/blog"]
```

<div id="empty-filter-arrays">
  ### Arreglos de filtros vacíos
</div>

```python theme={null}
# ❌ INCORRECTO: un arreglo vacío tiene un comportamiento indefinido
search_domain_filter=[]

# ✅ CORRECTO: omite el parámetro para buscar en todos los dominios
# (simplemente no incluyas search_domain_filter)
```

<div id="tips-and-best-practices">
  ## Consejos y buenas prácticas
</div>

1. **Mantén acotadas las listas de permitidos.** De 5 a 10 dominios suele bastar. Demasiados dominios diluyen el propósito del filtro.

2. **Usa listas de exclusión para exclusiones amplias.** Cuando quieras excluir unas pocas fuentes ruidosas pero seguir buscando en toda la web, las listas de exclusión son más prácticas que intentar incluir todo lo demás en una lista de permitidos.

3. **Combínalos con filtros de actualidad.** Para consultas sensibles al tiempo, añade `search_recency_filter` junto con los filtros de dominio.

4. **Prueba tus filtros.** Ejecuta la misma consulta con y sin filtros para verificar que los resultados cambian como esperas.

5. **Los filtros de TLD actúan de forma amplia.** Usar `.gov` coincide con cualquier dominio terminado en `.gov`, incluidos `whitehouse.gov`, `irs.gov` y dominios estatales como `ca.gov`.

6. **Guarda los presets en la configuración.** Define presets de filtros en la configuración de tu aplicación en lugar de codificarlos en cada solicitud.
