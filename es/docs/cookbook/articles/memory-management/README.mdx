<div id="memory-management-with-llamaindex-and-perplexity-sonar-api">
  # Gestión de memoria con LlamaIndex y la Sonar API de Perplexity
</div>

<div id="overview">
  ## Descripción general
</div>

Este artículo explora soluciones avanzadas para preservar la memoria conversacional en aplicaciones basadas en modelos de lenguaje de gran tamaño (LLM). El objetivo es lograr conversaciones coherentes de varios turnos conservando el contexto entre interacciones, incluso cuando el límite de tokens del modelo supone una restricción.

<div id="problem-statement">
  ## Planteamiento del problema
</div>

Los LLM tienen una ventana de contexto limitada, lo que dificulta mantener una memoria conversacional a largo plazo. Sin una gestión de memoria adecuada, las preguntas de seguimiento pueden perder relevancia o dar lugar a respuestas alucinadas y sin relación con el tema.

<div id="approaches">
  ## Enfoques
</div>

Con LlamaIndex, implementamos dos estrategias distintas para resolver este problema:

<div id="1-chat-summary-memory-buffer">
  ### 1. **Búfer de memoria con resumen del chat**
</div>

* **Objetivo**: resumir los mensajes más antiguos para ajustarse al límite de tokens sin perder el contexto clave.
* **Enfoque**:
  * Usa el `ChatSummaryMemoryBuffer` de LlamaIndex para truncar y resumir dinámicamente el historial de la conversación.
  * Garantiza que los detalles clave de interacciones anteriores se conserven de forma compacta.
* **Caso de uso**: ideal para conversaciones de corta duración en las que la eficiencia de la memoria resulta crítica.
* **Implementación**: [Ver la guía completa →](/es/docs/cookbook/articles/memory-management/chat-summary-memory-buffer/README)

<div id="2-persistent-memory-with-lancedb">
  ### 2. **Memoria persistente con LanceDB**
</div>

* **Objetivo**: permitir la persistencia de la memoria a largo plazo entre sesiones.
* **Enfoque**:
  * Almacena el historial de la conversación como embeddings vectoriales en LanceDB.
  * Recupera el contexto histórico relevante mediante búsqueda semántica y filtros de metadatos.
  * Integra la Sonar API de Perplexity para generar respuestas a partir del contexto recuperado.
* **Caso de uso**: adecuado para aplicaciones que requieren conservar la memoria a largo plazo y recuperar el contexto.
* **Implementación**: [Ver la guía completa →](/es/docs/cookbook/articles/memory-management/chat-with-persistence/README)
