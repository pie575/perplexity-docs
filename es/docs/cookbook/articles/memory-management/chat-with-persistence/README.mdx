<div id="persistent-chat-memory-with-perplexity-sonar-api">
  # Memoria de conversación persistente con la Sonar API de Perplexity
</div>

<div id="overview">
  ## Descripción general
</div>

Esta implementación muestra cómo preservar la memoria de conversación a largo plazo con el almacenamiento vectorial de LlamaIndex y la Sonar API de Perplexity. Mantiene el contexto entre llamadas a la API mediante recuperación y resumen inteligentes.

<div id="key-features">
  ## Características principales
</div>

* **Retención de contexto en varios turnos**: recuerda las consultas y respuestas anteriores
* **Búsqueda semántica**: encuentra el historial de conversación relevante mediante embeddings vectoriales
* **Integración con Perplexity**: aprovecha el modelo Sonar-pro para obtener respuestas precisas
* **Almacenamiento con LanceDB**: historial de conversación persistente mediante una base de datos vectorial columnar

<div id="implementation-details">
  ## Detalles de implementación
</div>

<div id="core-components">
  ### Componentes principales
</div>

```python theme={null}
# Inicialización de la memoria
vector_store = LanceDBVectorStore(uri="./lancedb", table_name="chat_history")
storage_context = StorageContext.from_defaults(vector_store=vector_store)
index = VectorStoreIndex([], storage_context=storage_context)
```

<div id="conversation-flow">
  ### Flujo de conversación
</div>

1. Almacena las consultas del usuario como embeddings vectoriales
2. Recupera las 3 interacciones anteriores más relevantes
3. Genera solicitudes a la Sonar API con el historial contextual
4. Guarda las respuestas para conversaciones futuras
