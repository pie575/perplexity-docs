<div id="overview">
  ## Descripción general
</div>

Pro Search ofrece dos herramientas integradas que el modelo utiliza automáticamente para responder a tus consultas. El modelo decide qué herramientas usar y cuándo, por lo que no necesitas configurar nada. El sistema invoca estas herramientas de forma automática; no es posible registrar herramientas personalizadas.

<Info>
  Todas las ejecuciones de herramientas aparecen en el arreglo `reasoning_steps` de las respuestas en streaming, lo que te permite ver cómo el modelo investigó tu consulta.
</Info>

<div id="web_search">
  ## web_search
</div>

Realiza búsquedas web para encontrar información actualizada, estadísticas y opiniones de expertos.

**Ejemplo en acción:**

```json theme={null}
{
  "thought": "I need current data on EV market trends",
  "type": "web_search",
  "web_search": {
    "search_keywords": [
      "EV Statistics 2023-2024",
      "electric vehicle sales data",
      "global EV market trends"
    ],
    "search_results": [
      {
        "title": "Trends in electric cars",
        "url": "https://www.iea.org/reports/global-ev-outlook-2024/trends-in-electric-cars",
        "date": "2024-03-15",
        "last_updated": null,
        "snippet": "Electric car sales neared 14 million in 2023, 95% of which were in China, Europe and the United States...",
        "source": "web"
      }
    ]
  }
}
```

<div id="fetch_url_content">
  ## fetch_url_content
</div>

Recupera el contenido completo de URLs específicas para acceder a información detallada que va más allá de los fragmentos de los resultados de búsqueda.

**Ejemplo en acción:**

```json theme={null}
{
  "thought": "This research paper contains detailed methodology I need to review",
  "type": "fetch_url_content",
  "fetch_url_content": {
    "contents": [
      {
        "title": "Attention Is All You Need",
        "url": "https://arxiv.org/pdf/1706.03762",
        "date": null,
        "last_updated": null,
        "snippet": "The dominant sequence transduction models are based on complex recurrent or convolutional neural networks that include an encoder and a decoder...",
        "source": "web"
      }
    ]
  }
}
```

<div id="multi-tool-workflows">
  ## Flujos de trabajo con múltiples herramientas
</div>

El modelo combina automáticamente varias herramientas cuando es necesario. Por ejemplo, si se le pide investigar opciones de paneles solares, podría:

1. Usar `web_search` para encontrar los incentivos y costos vigentes
2. Usar `fetch_url_content` para leer documentos normativos detallados
3. Usar `web_search` de nuevo para verificar las tarifas eléctricas y comparar proveedores
