<div id="overview">
  ## Descripción general
</div>

Pro Search amplía [Sonar Pro](/es/docs/sonar/models/sonar-pro) con el uso automatizado de herramientas, lo que permite el razonamiento en varios pasos mediante una orquestación inteligente de herramientas que incluye la búsqueda web y la obtención de contenido de URL.

<Warning>
  Pro Search solo funciona cuando el streaming está habilitado. Las solicitudes sin streaming recurrirán al comportamiento estándar de Sonar Pro.
</Warning>

<div id="basic-usage">
  ## Uso básico
</div>

Para habilitar Pro Search debes establecer `stream` en `true` y especificar `"search_type": "pro"` en la solicitud a la API. El tipo de búsqueda predeterminado es `"fast"` para Sonar Pro estándar.

A continuación se muestra un ejemplo de cómo habilitar Pro Search con streaming:

<CodeGroup>
  ```python Python SDK theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  messages = [
      {
          "role": "user", 
          "content": "Summarize developments in post-quantum cryptography and how lattice-based and hash-based schemes are being standardized by NIST."
      }
  ]

  response = client.chat.completions.create(
      model="sonar-pro",
      messages=messages,
      stream=True,
      web_search_options={
          "search_type": "pro"
      }
  )

  for chunk in response:
      if chunk.choices[0].delta.content:
          print(chunk.choices[0].delta.content, end="")
  ```

  ```typescript Typescript SDK theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.chat.completions.create({
    model: 'sonar-pro',
    messages: [
      {
        role: 'user',
        content: 'Summarize developments in post-quantum cryptography and how lattice-based and hash-based schemes are being standardized by NIST.'
      }
    ],
    stream: true,
    web_search_options: {
      search_type: 'pro'
    }
  });

  for await (const chunk of response) {
    if (chunk.choices[0]?.delta?.content) {
      process.stdout.write((chunk.choices[0]?.delta?.content ?? '') as string);
    }
  }
  ```

  ```bash cURL theme={null}
  curl --request POST \
    --url https://api.perplexity.ai/v1/sonar \
    --header "Authorization: Bearer $PERPLEXITY_API_KEY" \
    --header "Content-Type: application/json" \
    --data '{
      "model": "sonar-pro",
      "messages": [
        {
          "role": "user",

        }
      ],
      "stream": true,
      "web_search_options": {
        "search_type": "pro"
      }
    }' --no-buffer
  ```

<div id="enabling-automatic-classification">
  ## Habilitar la clasificación automática
</div>

Sonar Pro se puede configurar para clasificar automáticamente las consultas como Pro Search o Fast Search según su complejidad. Este es el enfoque recomendado para la mayoría de las aplicaciones.

Establece `search_type: "auto"` para que el sistema enrute las consultas de forma inteligente según su complejidad.

<CodeGroup>
  ```python Python SDK theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.chat.completions.create(
      model="sonar-pro",
      messages=[
          {
              "role": "user",
              "content": "Compare the energy efficiency (kWh/100mi and MPGe) of the Tesla Model 3, Chevrolet Bolt, and Nissan Leaf using EPA data."
          }
      ],
      stream=True,
      web_search_options={
          "search_type": "auto"  # Clasificación automática
      }
  )

  for chunk in response:
      if chunk.choices[0].delta.content:
          print(chunk.choices[0].delta.content, end="")
  ```

<div id="how-classification-works">
  #### Cómo funciona la clasificación
</div>

El clasificador analiza tu consulta y la enruta automáticamente a:

* **Pro Search** para consultas complejas que requieren:
  * Razonamiento o análisis de varios pasos
  * Análisis comparativo entre múltiples fuentes
  * Flujos de trabajo de investigación profunda

* **Fast Search** para consultas sencillas como:
  * Búsquedas simples de datos
  * Recuperación directa de información
  * Respuestas a preguntas básicas

<div id="billing-with-auto-classification">
  #### Facturación con clasificación automática
</div>

**Se te factura según el tipo de búsqueda que active tu consulta:**

* Si se clasifica como **Pro Search**: entre $14 y $22 por cada 1000 solicitudes (según el tamaño del contexto)
* Si se clasifica como **Fast Search**: entre $6 y $14 por cada 1000 solicitudes (según el tamaño del contexto: igual que Sonar Pro estándar)

Para ver todos los detalles de precios, consulta la sección <a href="/es/docs/sonar/pro-search/quickstart#pricing">Precios</a>.

<Tip>
  Se recomienda la clasificación automática para la mayoría de las aplicaciones, ya que equilibra la optimización de costes con el rendimiento de las consultas. Obtienes las capacidades de Pro Search cuando las necesitas, sin pagar de más por consultas sencillas.
</Tip>

<div id="manually-specifying-the-search-type">
  ### Especificar manualmente el tipo de búsqueda
</div>

Si lo necesitas, puedes especificar manualmente el tipo de búsqueda. Esto resulta útil en casos de uso concretos en los que sabes que la consulta requiere las capacidades de Pro Search.

* **`"search_type": "pro"`**: especifica manualmente Pro Search para consultas complejas cuando sabes que hace falta usar herramientas en varios pasos
* **`"search_type": "fast"`**: especifica manualmente Fast Search para consultas simples y así optimizar la velocidad y el coste (también es el valor predeterminado cuando se omite `search_type`)
