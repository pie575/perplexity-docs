title: "Filtros de fecha y hora en la búsqueda"
---

<Note>
  Los parámetros `search_after_date_filter` y `search_before_date_filter` permiten restringir los resultados de búsqueda a un rango de fechas de publicación específico. Solo se devolverán los resultados cuya fecha de publicación esté comprendida entre esas fechas.

  Los parámetros `last_updated_after_filter` y `last_updated_before_filter` permiten filtrar según cuándo se modificó o actualizó el contenido por última vez, en lugar de su fecha de publicación original.

  El parámetro `search_recency_filter` ofrece una forma práctica de filtrar los resultados por períodos de tiempo predefinidos (por ejemplo, &quot;hour&quot;, &quot;day&quot;, &quot;week&quot;, &quot;month&quot;, &quot;year&quot;) respecto a la fecha actual.
</Note>

<Info>
  Los filtros de fechas específicas deben indicarse con el formato &quot;%m/%d/%Y&quot; (por ejemplo, &quot;3/1/2025&quot;). Los filtros de recencia usan valores predefinidos como &quot;hour&quot;, &quot;day&quot;, &quot;week&quot;, &quot;month&quot; o &quot;year&quot;. Todos los filtros son opcionales: puedes usar fechas específicas o filtros de recencia, según lo que necesites.
</Info>

<div id="overview">
  ## Descripción general
</div>

Los filtros de fecha y hora de la Search API te permiten controlar qué resultados de búsqueda se devuelven, limitándolos a periodos concretos. Existen tres tipos de filtros de fecha y hora:

<div id="publication-date-filters">
  ### Filtros por fecha de publicación
</div>

Los parámetros `search_after_date_filter` y `search_before_date_filter` filtran los resultados según la fecha en que el contenido se **creó o publicó originalmente**. Esto resulta útil cuando necesitas:

* Encontrar contenido publicado dentro de un período específico
* Excluir publicaciones desactualizadas o demasiado recientes
* Centrarte en contenido de un período de publicación concreto

<div id="last-updated-date-filters">
  ### Filtros por fecha de última actualización
</div>

Los parámetros `last_updated_after_filter` y `last_updated_before_filter` filtran los resultados según la fecha en que el contenido se **modificó o actualizó por última vez**. Esto resulta útil cuando necesitas:

* Encontrar contenido actualizado o mantenido recientemente
* Excluir contenido obsoleto que no se haya actualizado recientemente
* Centrarte en contenido que se haya renovado dentro de un período específico

<div id="search-recency-filter">
  ### Filtro de recencia de búsqueda
</div>

El parámetro `search_recency_filter` ofrece una forma sencilla de filtrar resultados por periodos de tiempo predefinidos en relación con la fecha actual. Resulta útil cuando necesitas:

* Encontrar contenido de la última hora, día, semana, mes o año
* Obtener resultados recientes sin especificar fechas exactas
* Filtrar rápidamente información de actualidad

**Valores disponibles:**

* `"hour"`: contenido de la última hora. Úsalo para datos en tiempo real, como noticias de última hora o eventos en directo.
* `"day"`: contenido de las últimas 24 horas
* `"week"`: contenido de los últimos 7 días
* `"month"`: contenido de los últimos 30 días
* `"year"`: contenido de los últimos 365 días

**Importante:** los filtros de fecha de publicación se basan en la fecha original de creación o publicación; los de última actualización, en la fecha de modificación; y los de recencia, en un periodo de tiempo relativo a la fecha actual.

Para restringir los resultados de búsqueda por fecha de publicación:

```bash theme={null}
"search_after_date_filter": "3/1/2025",
"search_before_date_filter": "3/5/2025"
```

Para limitar los resultados de búsqueda por fecha de última actualización:

```bash theme={null}
"last_updated_after_filter": "07/01/2025",
"last_updated_before_filter": "12/30/2025"
```

Para limitar los resultados de búsqueda según su antigüedad:

```bash theme={null}
"search_recency_filter": "week"
```

Estos filtros se aplicarán además de cualquier otro parámetro de búsqueda.

<div id="best-practices">
  ## Buenas prácticas
</div>

**Formato de fecha**

* Formato estricto: las fechas deben ajustarse exactamente al formato &quot;%m/%d/%Y&quot;. Por ejemplo, &quot;3/1/2025&quot; o &quot;03/01/2025&quot; son valores válidos.
* Coherencia: usa uno o ambos filtros de fecha de forma coherente según tus necesidades de búsqueda. Al combinar los dos, defines un rango claro.

**Selección de filtros**

* Elige el tipo de filtro adecuado: usa los filtros de fecha de publicación (`search_after_date_filter`/`search_before_date_filter`) cuando te interese saber cuándo se creó originalmente el contenido. Usa los filtros de última actualización (`last_updated_after_filter`/`last_updated_before_filter`) cuando necesites contenido actualizado recientemente. Usa los filtros de recencia (`search_recency_filter`) para un filtrado temporal relativo y rápido.
* Actualidad frente a fechas exactas: usa `search_recency_filter` por comodidad cuando busques contenido reciente (por ejemplo, &quot;la última semana&quot;). Usa filtros de fecha específicos cuando necesites un control preciso del rango temporal.
* Combinación de filtros: puedes usar a la vez los filtros de fecha de publicación y de última actualización para encontrar contenido que cumpla ambos criterios (por ejemplo, publicado en 2024 pero actualizado recientemente). Ten en cuenta que `search_recency_filter` no se puede combinar con filtros de fecha específicos (`search_after_date_filter`/`search_before_date_filter` o `last_updated_after_filter`/`last_updated_before_filter`).

**Validación en el cliente**

* Comprobación con expresión regular: valida las cadenas de fecha en el cliente con una expresión regular como:

<CodeGroup>
  ```bash theme={null}
  date_regex='^(0?[1-9]|1[0-2])/(0?[1-9]|[12][0-9]|3[01])/[0-9]{4}$'
  ```

  ```python theme={null}
  date_regex = r'^(0?[1-9]|1[0-2])/(0?[1-9]|[12]\d|3[01])/\d{4}$'
  ```
</CodeGroup>

Así te aseguras de que las fechas cumplan el formato requerido antes de enviar la solicitud.

**Consideraciones de rendimiento**

* Acotar la búsqueda: aplicar filtros de rango de fechas suele reducir el número de resultados, lo que puede mejorar los tiempos de respuesta y la relevancia de los resultados.
* Evita restringir en exceso: asegúrate de que el rango de fechas no sea demasiado estrecho (lo que limitaría resultados útiles) ni demasiado amplio (lo que anularía el propósito del filtro).

Al usar filtros de fecha, asegúrate de manejar correctamente los errores por formatos de fecha no válidos:

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity
  import re

  def validate_date_format(date_string):
      pattern = r'^(0?[1-9]|1[0-2])/(0?[1-9]|[12]\d|3[01])/\d{4}$'
      return bool(re.match(pattern, date_string))

  def search_with_date_filter(query, after_date=None, before_date=None):
      client = Perplexity()
      
      # Validar los formatos de fecha
      if after_date and not validate_date_format(after_date):
          raise ValueError(f"Invalid date format: {after_date}")
      if before_date and not validate_date_format(before_date):
          raise ValueError(f"Invalid date format: {before_date}")
      
      try:
          response = client.search(
              query=query,
              search_after_date_filter=after_date,
              search_before_date_filter=before_date
          )
          return response
      except Exception as e:
          print(f"Search failed: {e}")
          return None
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  function validateDateFormat(dateString: string): boolean {
    const pattern = /^(0?[1-9]|1[0-2])\/(0?[1-9]|[12]\d|3[01])\/\d{4}$/;
    return pattern.test(dateString);
  }

  async function searchWithDateFilter(
    query: string, 
    afterDate?: string, 
    beforeDate?: string
  ) {
    const client = new Perplexity();
    
    // Validar los formatos de fecha
    if (afterDate && !validateDateFormat(afterDate)) {
      throw new Error(`Invalid date format: ${afterDate}`);
    }
    if (beforeDate && !validateDateFormat(beforeDate)) {
      throw new Error(`Invalid date format: ${beforeDate}`);
    }
    
    try {
      const response = await client.search.create({
        query,
        search_after_date_filter: afterDate,
        search_before_date_filter: beforeDate
      });
      return response;
    } catch (error) {
      console.error('Search failed:', error);
      return null;
    }
  }
  ```
