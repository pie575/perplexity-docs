Aunque Sonar Chat Completions sigue siendo compatible, la Agent API ofrece mejor rendimiento y un costo más bajo para cargas de trabajo en producción. Incorpora las innovaciones más recientes de Perplexity en tecnología de búsqueda y razonamiento, incluidos Search as Code y presets optimizados.

<Note>
  Recomendamos:

  * Migrar el uso actual de Sonar Chat Completions a la Agent API.
  * Usar la Agent API en todos los proyectos nuevos.
</Note>

<div id="about-the-agent-api">
  ## Acerca de la Agent API
</div>

Agent API es una interfaz unificada para crear aplicaciones de agentes potentes.

Incluye:

* Una sola API para invocar todos los principales modelos de frontera y de código abierto.
* Herramientas integradas como [búsqueda web](/es/docs/agent-api/tools/web-search), [obtención de contenido de URL](/es/docs/agent-api/tools/fetch-url-content), [sandbox](/es/docs/agent-api/tools/sandbox) y [MCP](/es/docs/agent-api/tools/mcp), además de fuentes de datos premium como [finanzas](/es/docs/agent-api/tools/finance-search) y [búsqueda de personas](/es/docs/agent-api/tools/people-search).
* Configuraciones respaldadas por investigación para flujos de trabajo agénticos, según la intensidad de cada tarea (fast, low, medium, high, xhigh — [presets](/es/docs/agent-api/presets)).
* Compatibilidad con el estándar [Open Responses](https://www.openresponses.org/) para garantizar la portabilidad y evitar la dependencia de un proveedor: queremos ganarnos tu confianza por rendimiento y eficiencia, no atándote con costes de migración desorbitados.
* Interacciones fluidas de varios turnos que te permiten [pasar respuestas anteriores](/es/docs/agent-api/conversation-state#resume-from-a-prior-response) para obtener un razonamiento más preciso.

<div id="why-migrate">
  ## Por qué migrar
</div>

Agent API ofrece varias ventajas frente a Sonar Chat Completions:

* Flexibilidad total para elegir entre las familias de modelos de OpenAI, Anthropic, Google, xAI, Z.AI, Moonshot AI y NVIDIA, además del modelo Sonar de Perplexity.
* La posibilidad de combinar varias herramientas y poner en marcha un bucle agéntico que razona, actúa, observa los resultados y continúa dentro de una misma solicitud.
* Un [sandbox](/es/docs/agent-api/tools/sandbox) seguro para ejecutar el código generado: calcular resultados, analizar datos y verificar salidas sin salir de la solicitud.
* Conecta servidores externos con [MCP](/es/docs/agent-api/tools/mcp) o define tus propias [funciones personalizadas](/es/docs/agent-api/tools/custom-functions) para ampliar el agente con tus herramientas y tus datos privados.
* [Wide Research](/es/docs/agent-api/wide-research) para ejecutar tareas amplias y profundas en segundo plano y crear grandes colecciones respaldadas por evidencia en una sola solicitud.

<div id="sonar-vs-agent-api">
  ## Sonar frente a Agent API
</div>

| Capacidad                                    |       Sonar API       |       Agent API       |
| -------------------------------------------- | :-------------------: | :-------------------: |
| Modelos frontera líderes y de código abierto |                       | <Icon icon="check" /> |
| Búsqueda web integrada                       | <Icon icon="check" /> | <Icon icon="check" /> |
| Búsqueda de personas                         |                       | <Icon icon="check" /> |
| Finance Search                               |                       | <Icon icon="check" /> |
| sandbox de código                            |                       | <Icon icon="check" /> |
| Servidores MCP                               |                       | <Icon icon="check" /> |
| Modelo de respaldo                           |                       | <Icon icon="check" /> |
| Salidas estructuradas                        | <Icon icon="check" /> | <Icon icon="check" /> |
| Streaming                                    | <Icon icon="check" /> | <Icon icon="check" /> |
| Modo asíncrono                               | <Icon icon="check" /> | <Icon icon="check" /> |

Ambas invocan un modelo, pero dan forma a la solicitud de manera distinta.
Sonar recibe un arreglo `messages` y devuelve `choices`.
La Agent API recibe un `input` y devuelve un arreglo `output` tipado: un elemento por cada paso que ejecutó el modelo, con un elemento `message` para el texto de la respuesta y un elemento `search_results` para las fuentes.

<div id="how-sonar-chat-completions-maps-to-agent-api-presets">
  ## Correspondencia entre Sonar Chat Completions y los presets de Agent API
</div>

Aunque las mejoras de rendimiento variarán según el caso de uso, nuestras pruebas comparativas internas muestran mejoras de rendimiento en las siguientes correspondencias entre Sonar Chat Completions y los presets de Agent API.

| Sonar Chat Completions | Preset de Agent API | Ideal para                                                                                        | Qué mejora                                                                                                                                               |
| ---------------------- | ------------------- | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sonar                  | `fast`              | Búsquedas de un solo dato, definiciones y resúmenes rápidos.                                      | Más preciso que Sonar, con las mejoras más notables en preguntas de tipo investigación y de varios pasos.                                                |
| Sonar Pro              | `low`               | Preguntas de investigación cotidianas y búsquedas ligeras de varios pasos con información actual. | Mucho más preciso y habilita la verdadera investigación agéntica de varios pasos que Sonar Pro no logra ofrecer.                                         |
| Sonar Reasoning Pro    | `medium`            | Navegación de múltiples saltos y agregación amplia entre muchas fuentes.                          | Mucho más sólido en razonamiento paso a paso y en el encadenamiento de evidencia a lo largo de varias rondas de búsqueda.                                |
| Sonar Deep Research    | `high`              | Razonamiento a nivel experto y cobertura exhaustiva de fuentes.                                   | El nivel más preciso en tareas exigentes de nivel experto e investigación profunda, y a menudo con un costo por solicitud menor que Sonar Deep Research. |

<Tip>
  Para investigación profunda de última generación, usa el preset `xhigh`: la mayor calidad de la gama y el líder en las pruebas comparativas que ejecutamos.
</Tip>

Consulta [Elegir un preset](/es/docs/agent-api/presets#choosing-a-preset) para saber en qué destaca cada preset, y la [página de pruebas comparativas](/es/docs/agent-api/migrate-from-sonar/benchmarks) para ver las puntuaciones.
