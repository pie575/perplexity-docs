<div id="overview">
  ## Descripción general
</div>

La Agent API de Perplexity es totalmente compatible con la interfaz de la Responses API de OpenAI. Puedes seguir usando tus bibliotecas cliente de OpenAI con solo cambiar la URL base y proporcionar tu API key de Perplexity.

<Info>
  **Nota sobre el endpoint:** el endpoint canónico de la Agent API de Perplexity es `POST /v1/agent`. Por compatibilidad con el SDK de OpenAI, también se acepta `POST /v1/responses` como alias: el SDK de OpenAI dirige automáticamente `client.responses.create()` a `/v1/responses`, que Perplexity gestiona sin problemas. No hace falta ningún cambio en el SDK más allá de configurar la URL base.
</Info>

<Tip>
  **Recomendamos usar el [SDK de Perplexity](/es/docs/sdk/overview)** para obtener la mejor experiencia, con seguridad de tipos completa, funciones mejoradas y soporte de presets. Usa los SDK de OpenAI si ya tienes una integración y necesitas compatibilidad inmediata.
</Tip>

    ```python theme={null}
    import os

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),

    )

    response = client.responses.create(
    ```

<div id="agent-api">
  ## Agent API
</div>

La Agent API de Perplexity sigue el formato de solicitud/respuesta de la Responses API de OpenAI. El método `client.responses.create()` del SDK de OpenAI funciona sin necesidad de configuración adicional: el SDK envía las solicitudes a `/v1/responses`, que Perplexity acepta además del endpoint canónico `/v1/agent`.

<div id="basic-usage">
  ### Uso básico
</div>

<Tabs>
  <Tab title="Python">
    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    response = client.responses.create(
        model="openai/gpt-5.6-sol",
        input="Explain the key differences between REST and GraphQL APIs"
    )

    print(response.output_text)
    print(f"Response ID: {response.id}")
    ```
  </Tab>

Los presets son configuraciones predefinidas y optimizadas para casos de uso específicos. Usa `extra_body` para pasar presets a través del SDK de OpenAI:

<Tabs>
  <Tab title="Python">
    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    # Pasar el preset mediante extra_body
    response = client.responses.create(
        input="Compare the design philosophy of Apple's A-series and Qualcomm's Snapdragon mobile SoCs at a high level: CPU and GPU choices and overall system integration.",
        extra_body={
            "preset": "low"
        }
    )

    print(response.output_text)
    ```
  </Tab>

    ```typescript theme={null}
    import OpenAI from 'openai';

    const client = new OpenAI({

    const response = await (client.responses.create as any)({
    ```

  ### Uso de herramientas

La Agent API admite herramientas integradas, incluida la búsqueda web. Con el SDK de OpenAI, pasa las herramientas mediante `extra_body` en Python; en TypeScript/JS, pasa `tools` como parámetro de nivel superior y haz una conversión de tipo en la llamada para evitar la comprobación de tipos del SDK:

<Tabs>
  <Tab title="Python">
    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    # Pasa las herramientas mediante extra_body
    response = client.responses.create(
        model="openai/gpt-5.6-sol",
        input="What is an acquisition premium in M&A, and how do strategic vs financial buyers typically differ in their approach?",
        extra_body={
            "tools": [
                {
                    "type": "web_search",
                    "filters": {
                        "search_domain_filter": ["techcrunch.com", "crunchbase.com"]
                    }
                }
            ]
        }
    )

    print(response.output_text)
    ```

<div id="standard-openai-parameters">
  ### Parámetros estándar de OpenAI
</div>

Estos parámetros funcionan exactamente igual que en la API de OpenAI:

**Agent API:**

* `model` - Nombre del modelo (usa modelos de terceros como `openai/gpt-5.6-sol`)
* `input` - Texto de entrada o array de mensajes
* `instructions` - Instrucciones del sistema
* `max_output_tokens` - Número máximo de tokens en la respuesta
* `stream` - Habilita las respuestas en streaming
* `tools` - Array de herramientas, incluida `web_search`
* `store` - Indica si la respuesta es visible mediante recuperación; consulta [Estado de la conversación](/es/docs/agent-api/conversation-state#storage-behavior)
* `previous_response_id` - Continúa a partir de una respuesta anterior ya completada; consulta [Estado de la conversación](/es/docs/agent-api/conversation-state#resume-from-a-prior-response)

* `tools[].filters` - Filtros de búsqueda dentro de la herramienta web&#95;search

<div id="endpoint-mapping">
  ## Correspondencia de endpoints
</div>

| Método                        | Endpoint de Perplexity | Equivalente en OpenAI    | Notas                                                                     |
| ----------------------------- | ---------------------- | ------------------------ | ------------------------------------------------------------------------- |
| `client.responses.create()`   | `POST /v1/agent`       | `POST /v1/responses`     | Perplexity acepta ambas rutas por compatibilidad                          |
| `client.responses.retrieve()` | `GET /v1/agent/{id}`   | `GET /v1/responses/{id}` | Perplexity acepta ambas rutas por compatibilidad                          |
| `client.models.list()`        | `GET /v1/models`       | `GET /v1/models`         | Lista los modelos disponibles de la Agent API. No requiere autenticación. |

<Info>
  Al usar el SDK de OpenAI, `client.responses.create()` envía las solicitudes a `/v1/responses`. Perplexity acepta esta ruta como alias de `/v1/agent`, por lo que no hace falta cambiar nada en la configuración del SDK aparte de `base_url`.
</Info>

<div id="model-discovery">
  ### Descubrimiento de modelos
</div>

El endpoint `GET /v1/models` devuelve todos los modelos disponibles para la Agent API en formato compatible con OpenAI. No requiere autenticación.

<Tabs>
  <Tab title="Python">
    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    models = client.models.list()
    for model in models.data:
        print(f"{model.id} (owned by {model.owned_by})")
    ```
  </Tab>

    ```typescript theme={null}
    }
    ```

    ```python theme={null}
    client = OpenAI(
    ```
