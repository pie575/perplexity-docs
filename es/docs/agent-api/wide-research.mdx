<div id="overview">
  ## Descripción general
</div>

`wide-research` es el preset para crear colecciones amplias y respaldadas por evidencia. Dale una tarea del tipo «encuentra todas las empresas que coincidan con X y cita una fuente para cada una» y descubrirá las entidades que cumplen los criterios, reunirá evidencia de respaldo para cada una y escribirá los resultados en un archivo que podrás descargar.

Este es el tipo de tarea que mide el [benchmark WANDR](https://research.perplexity.ai/articles/wandr-benchmark-evaluating-research-agents-that-must-search-wide-and-deep) (Wide ANd Deep Research) de Perplexity: descubrir un conjunto amplio de elementos (wide) e investigar cada uno con la profundidad suficiente para respaldar cada afirmación con una fuente (deep). Es justo el tipo de investigación para el que se diseñó la Agent API: el sistema de orquestación de búsqueda de Perplexity encabeza el benchmark WANDR, y `wide-research` pone esa misma configuración al alcance de un único preset.

<div id="quickstart">
  ## Inicio rápido
</div>

Las ejecuciones de wide research tardan varios minutos, así que envíalas con `background=true`, consulta la respuesta por su id hasta que termine y luego descarga el archivo generado por el agente.

<CodeGroup>
  ```python Python theme={null}
  import time
  from perplexity import Perplexity

  client = Perplexity()

  # 1. Enviar en segundo plano
  response = client.responses.create(
      preset="wide-research",
      background=True,
      input=(
          "Find at least 70 US-based companies with a CEO or CFO appointment first "
          "announced between March 1 and April 30, 2026. For each, cite an authoritative "
          "page that names the company and appointee and gives the role and date. Write "
          "the results to results.jsonl, one JSON record per line with fields: "
          "company, appointee, role, announcement_date, url."
      ),
  )

  # 2. Consultar hasta que la ejecución alcance un estado terminal
  while response.status not in ("completed", "failed", "cancelled", "incomplete"):
      time.sleep(5)
      response = client.responses.retrieve(response.id)

  # 3. Descargar todos los archivos generados por la ejecución
  for file in client.responses.files.list(response.id).data:
      client.responses.files.content(
          file_id=file.id, response_id=response.id
      ).write_to_file(file.filename)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  let response = await client.responses.create({

      'announced between March 1 and April 30, 2026. For each, cite an authoritative ' +
      'page that names the company and appointee and gives the role and date. Write ' +
      'the results to results.jsonl, one JSON record per line with fields: ' +
      'company, appointee, role, announcement_date, url.',
  });

  // 2. Consultar hasta que la ejecución alcance un estado terminal
  while (!['completed', 'failed', 'cancelled', 'incomplete'].includes(response.status)) {
    await new Promise((r) => setTimeout(r, 5000));
    response = await client.responses.retrieve(response.id);
  }

  // 3. Listar los archivos generados por la ejecución y descargar cada uno por su id
  const files = await client.responses.files.list(response.id);
  for (const file of files.data) {
    console.log(file.id, file.filename, file.bytes);
  }
  ```

<div id="how-it-works">
  ## Cómo funciona
</div>

Una ejecución de wide-research consta de tres partes, cada una documentada en su propia página:

<Steps>
  <Step title="Enviar en segundo plano">
    Establece `preset="wide-research"` y `background=true`, y pasa la tarea como `input`. La llamada de envío devuelve de inmediato un `id` de respuesta y el estado `queued`; la ejecución continúa en el servidor incluso si tu cliente se desconecta. Consulta [Modo en segundo plano](/es/docs/agent-api/background-mode).
  </Step>

  <Step title="Consultar hasta que termine">
    Recupera la respuesta por `id` hasta que su `status` sea terminal: `completed`, `failed`, `cancelled` o `incomplete`. También puedes transmitir la ejecución en vivo y volver a conectarte tras una caída; consulta [Modo en segundo plano](/es/docs/agent-api/background-mode#stream-and-reconnect).
  </Step>

  <Step title="Descargar los resultados">
    El agente escribe la colección en un archivo dentro del sandbox y lo entrega, de modo que aparece como un elemento `share_file` en el `output` de la respuesta. Puedes listarlo y descargarlo con el `id` de la respuesta. Consulta [Trabajar con archivos](/es/docs/agent-api/working-with-files).
  </Step>
</Steps>

<Tip>
  La calidad de wide-research depende de la precisión con la que especifiques la tarea. Indica un objetivo concreto («al menos 70 empresas»), reglas de calificación claras (fechas, geografía, umbrales), una fuente obligatoria por registro y un formato de salida explícito: nombra el archivo y enumera los campos exactos de cada fila. Una salida estructurada y con citas es más fácil de verificar y de aprovechar en procesos posteriores.
</Tip>
