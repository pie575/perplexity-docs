<div id="streaming-responses">
  ## Respuestas en streaming
</div>

El streaming te permite recibir respuestas parciales de la Perplexity API a medida que se generan, en lugar de esperar a que la respuesta esté completa. Resulta especialmente útil para experiencias de usuario en tiempo real, respuestas largas y aplicaciones interactivas.

<Info>
  El streaming es compatible con todos los modelos disponibles a través de la Agent API.
</Info>

Para habilitar el streaming, define `stream=True` (Python) o `stream: true` (TypeScript) al crear respuestas:

<CodeGroup>
  ```python Python SDK theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  # Crear respuesta en streaming
  stream = client.responses.create(
      preset="fast",
      input="Explain what a model card is in the context of large language models: the typical sections (intended use, training data, limitations, evaluation).",
      stream=True
  )

  # Procesar la respuesta en streaming
  for event in stream:
      if event.type == "response.output_text.delta":
          print(event.delta, end="")
      elif event.type == "response.completed":
          print(f"\n\nCompleted: {event.response.usage}")
  ```

  ```typescript TypeScript SDK theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  // Crear respuesta en streaming
  const stream = await client.responses.create({
    preset: "fast",
    input: "Explain what a model card is in the context of large language models: the typical sections (intended use, training data, limitations, evaluation).",
    stream: true
  });

  // Procesar la respuesta en streaming
  for await (const chunk of stream) {
    if (chunk.type === "response.output_text.delta") {
      process.stdout.write((chunk as any).delta);
    }
  }
  ```

  ```bash cURL theme={null}
      "preset": "fast",

      "stream": true
    }'
  ```

  ```python Python theme={null}
  import time

  client = Perplexity()


  def get_output_text(response) -> str:
      return "".join(
          content.text
          for item in response.output or []
          if getattr(item, "type", None) == "message"
          for content in getattr(item, "content", None) or []
          if getattr(content, "type", None) == "output_text"
      )


  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Produce a competitive landscape report for the EV charging market.",
      tools=[{"type": "web_search"}, {"type": "sandbox"}],
      background=True,
  )

  while response.status in ("queued", "in_progress"):
      time.sleep(2)
      response = client.responses.retrieve(response.id)

  print(get_output_text(response))
  ```

<div id="structured-outputs">
  ## Salidas estructuradas
</div>

Las salidas estructuradas te permiten exigir formatos de respuesta específicos a los modelos de Perplexity, lo que garantiza datos coherentes y legibles por máquina que pueden integrarse directamente en tus aplicaciones sin necesidad de un análisis manual.

Actualmente admitimos salidas estructuradas con **JSON Schema**. Para habilitarlas, añade el campo `response_format` a tu solicitud:

```json theme={null}
{
  "response_format": {
    "type": "json_schema",
    "json_schema": {
      "name": "your_schema_name",
      "schema": { /* tu objeto de esquema JSON */ }
    }
  }
}
```

El campo `name` es obligatorio y debe tener entre 1 y 64 caracteres alfanuméricos. El esquema debe ser un objeto de esquema JSON válido. Las respuestas del LLM se ajustarán al formato especificado, salvo que la salida supere `max_tokens`.

Las propiedades incluidas en el array `required` del esquema son obligatorias en la salida. Toda propiedad declarada que se omita de `required` sigue siendo opcional y puede resolverse como `null` de JSON. Si `required` se omite o está vacío, todas las propiedades declaradas son opcionales. Este comportamiento es el mismo para las solicitudes con y sin streaming, tanto en `/v1/agent` como en su alias de compatibilidad `/v1/responses`.

<Tip>
  **Mejora el cumplimiento del esquema**: incluye en tus prompts algunas pistas sobre el formato de salida para que el LLM se ajuste mejor al formato estructurado. Por ejemplo, añade frases como &quot;Devuelve los datos como un objeto JSON con la siguiente estructura...&quot; o &quot;Extrae la información y dale el formato especificado en el esquema.&quot;
</Tip>

<Info>
  Es previsible que la primera solicitud con un nuevo esquema JSON sufra demora en el primer token. Normalmente, preparar el nuevo esquema tarda entre 10 y 30 segundos, lo que puede provocar errores de tiempo de espera. Una vez preparado el esquema, las solicitudes posteriores no presentarán esa demora.
</Info>
