sidebarTitle: "Descripción general"
description: "Las herramientas que puede invocar una ejecución de la Agent API: herramientas integradas alojadas por Perplexity, servidores MCP remotos y tus propias funciones personalizadas, además de dónde consultar cada una."
---

Las herramientas son lo que convierte un modelo en un agente.
Por sí solo, un modelo responde únicamente a partir de lo que ya sabe; las herramientas le permiten buscar en la web en tiempo real, obtener una página, ejecutar código o llamar a tus propios sistemas.
Para habilitar herramientas, basta con enumerarlas en el arreglo `tools`: dentro de una misma solicitud, el modelo ejecuta un bucle agéntico en el que razona, invoca una herramienta, observa el resultado y repite el ciclo hasta que puede responder.

<div id="three-kinds-of-tools">
  ## Tres tipos de herramientas
</div>

| Tipo                                                               | Qué es                                                       | Dónde lo ejecuta el modelo                                                  |
| ------------------------------------------------------------------ | ------------------------------------------------------------ | --------------------------------------------------------------------------- |
| Herramientas integradas                                            | Capacidades alojadas por Perplexity, habilitadas con `type`. | Dentro del bucle; Perplexity la ejecuta y devuelve los resultados en línea. |
| [Servidores MCP](/es/docs/agent-api/tools/mcp)                        | Tu propio servidor MCP remoto, conectado con `type: mcp`.    | Dentro del bucle; el modelo llama a sus herramientas automáticamente.       |
| [Funciones personalizadas](/es/docs/agent-api/tools/custom-functions) | Funciones que tú controlas, declaradas con un JSON Schema.   | El control vuelve a ti; tú ejecutas la llamada y devuelves el resultado.    |

<div id="built-in-tools">
  ## Herramientas integradas
</div>

Habilita cada una mediante su `type`. Cada herramienta tiene su propia página de referencia con la configuración completa, la estructura de la respuesta y los precios.

| Herramienta                                                  | `type`           | Úsala para                                                                 |
| ------------------------------------------------------------ | ---------------- | -------------------------------------------------------------------------- |
| [Web Search](/es/docs/agent-api/tools/web-search)               | `web_search`     | Buscar en la web en tiempo real, con filtros de dominio, fecha y ubicación |
| [Sandbox](/es/docs/agent-api/tools/sandbox)                     | `sandbox`        | Ejecutar código en un contenedor aislado                                   |
| [Fetch URL Content](/es/docs/agent-api/tools/fetch-url-content) | `fetch_url`      | Obtener y extraer contenido de URL concretas                               |
| [Finance Search](/es/docs/agent-api/tools/finance-search)       | `finance_search` | Recuperar datos financieros y de mercado estructurados                     |
| [People Search](/es/docs/agent-api/tools/people-search)         | `people_search`  | Encontrar profesionales y personas                                         |
