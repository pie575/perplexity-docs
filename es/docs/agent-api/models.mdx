<div id="available-models">
  ## Modelos disponibles
</div>

La Agent API permite el acceso directo a modelos de múltiples proveedores. Se accede a todos los modelos directamente desde los proveedores originales, con precios transparentes basados en tokens.

Las tarifas se actualizan mensualmente y **reflejan el precio directo del proveedor original, sin recargos**. Todos los cargos se basan en el consumo real de tokens, y cada respuesta de la API incluye el recuento exacto de tokens para que conozcas tus costos por solicitud.

<Tip>
  ¿Buscas configuraciones de modelos ya preparadas? Consulta [**Presets**](/es/docs/agent-api/presets), optimizados para casos de uso específicos.
</Tip>

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Explain the difference between supervised and unsupervised learning in machine learning.",
      max_output_tokens=300,
  )

  print(f"Response ID: {response.id}")
  print(response.output_text)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      model: "openai/gpt-5.6-sol",
      input: "Explain the difference between supervised and unsupervised learning in machine learning.",
      max_output_tokens: 300,
  });

  console.log(`Response ID: ${response.id}`);
  console.log(response.output_text);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "Explain the difference between supervised and unsupervised learning in machine learning.",
      "max_output_tokens": 300
    }' | jq
  ```
</CodeGroup>

<div id="model-fallback">
  ## Respaldo de modelos
</div>

Para aplicaciones de alta disponibilidad, puedes especificar varios modelos en una cadena de respaldo. Cuando un modelo falla o no está disponible, la API prueba automáticamente el siguiente modelo de la cadena.

<Card title="Cadena de respaldo de modelos" icon="square-rounded-arrow-down" href="/es/docs/agent-api/model-fallback">
  Aprende a usar cadenas de respaldo de modelos para garantizar alta disponibilidad y fiabilidad probando automáticamente varios modelos cuando uno falla.
</Card>

<Info>
  **Ejemplo:**

  ```python theme={null}
  response = client.responses.create(
      models=["openai/gpt-5.6-sol", "anthropic/claude-sonnet-4-6", "google/gemini-3-flash-preview"],
      input="Your question here",
      max_output_tokens=8192,
  )
  ```

  Para ver ejemplos detallados, información sobre precios y buenas prácticas, consulta la [documentación de respaldo de modelos](/es/docs/agent-api/model-fallback).
</Info>
