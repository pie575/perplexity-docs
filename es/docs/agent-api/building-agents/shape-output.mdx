---
title: "Estructurar la salida"
description: "Obliga al modelo a devolver JSON que tu código pueda parsear, en lugar de prosa que tengas que extraer a mano."
---

De forma predeterminada, una ejecución devuelve un único bloque de texto al finalizar. Cuando un sistema posterior tiene que consumir el resultado, la prosa de formato libre resulta difícil de manejar: acabas escribiendo parsers frágiles. La salida estructurada hace que el modelo devuelva JSON conforme a un esquema que tú defines, de modo que puedas deserializarlo directamente. Para la referencia completa —streaming, ejecuciones en segundo plano, manejo de errores y ejemplos completos de esquemas—, consulta [Control de la salida](/es/docs/agent-api/output-control).

<div id="structured-output">
  ## Salida estructurada
</div>

Define `response_format` como un `json_schema` con un `name` y un `schema`. El texto de la respuesta se ajusta al esquema, salvo que la generación se interrumpa. El siguiente ejemplo construye el esquema a partir de un modelo de Pydantic y valida la respuesta con él:

<CodeGroup>
  ```python Python theme={null}
  from typing import List, Optional
  from pydantic import BaseModel
  from perplexity import Perplexity

  class CompanySummary(BaseModel):
      name: str
      sector: str
      headquarters: str
      key_products: Optional[List[str]] = None

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Summarize NVIDIA: sector, headquarters, and key products.",
      response_format={
          "type": "json_schema",
          "json_schema": {
              "name": "company_summary",
              "schema": {
                  **CompanySummary.model_json_schema(),
                  "required": list(CompanySummary.model_fields.keys()),
                  "additionalProperties": False,
              },
          },
      },
  )

  summary = CompanySummary.model_validate_json(response.output_text)
  print(summary.name, summary.sector)
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "Summarize NVIDIA: sector, headquarters, and key products.",
      "response_format": {
        "type": "json_schema",
        "json_schema": {
          "name": "company_summary",
          "schema": {
            "type": "object",
            "properties": {
              "name": { "type": "string" },
              "sector": { "type": "string" },
              "headquarters": { "type": "string" },
              "key_products": { "type": "array", "items": { "type": "string" } }
            },
            "required": ["name", "sector", "headquarters"]
          }
        }
      }
    }' | jq
  ```
</CodeGroup>

<Tip>
  Refuerza el esquema en tu prompt («Devuelve los datos como un objeto JSON que coincida con el esquema») para mejorar el cumplimiento.
</Tip>

<Warning>
  Evita pedir enlaces dentro del JSON. Un modelo que genera URLs como parte de una salida estructurada puede producir enlaces mal formados o inventados. En su lugar, obtén los enlaces de los elementos `citations` o `search_results` del `output` de la respuesta.
</Warning>
