---
title: "Conservar el contexto"
description: "Mantén una conversación a lo largo de varios turnos reproduciéndola en el array de entrada, para que un mensaje de seguimiento entienda lo que ocurrió antes."
---

Reproduce tú mismo la conversación en el array `input` cuando necesites un control preciso sobre qué contexto se envía; por ejemplo, para resumir, censurar, reordenar u omitir turnos anteriores antes del mensaje de seguimiento. Consulta [Reproducir los turnos de la conversación por tu cuenta](/es/docs/agent-api/conversation-state#replay-conversation-turns-yourself) para ver el patrón y ejemplos de código.

<div id="storage-backed-continuity">
  ## Continuidad respaldada por almacenamiento
</div>

Para la mayoría de las conversaciones de varios turnos, usa `previous_response_id` para continuar a partir de una respuesta anterior ya completada sin necesidad de reenviar la conversación. Consulta [Estado de la conversación](/es/docs/agent-api/conversation-state) para ver la guía completa.
