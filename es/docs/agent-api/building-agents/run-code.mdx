---
title: "Ejecutar código"
description: "Dale al agente un sandbox para que calcule respuestas exactas en lugar de estimarlas, ejecute código real y devuelva los archivos generados."
---

Los modelos de lenguaje aproximan la aritmética exacta y la manipulación de datos en lugar de calcularlas. La herramienta `sandbox` proporciona al agente un contenedor Linux aislado donde ejecutar código real y usar la salida en su respuesta, ideal para resultados que deben ser exactos, como un número calculado, un conjunto de datos transformado o un informe generado. Desde dentro del contenedor, el agente también puede invocar las herramientas de Perplexity [Web Search](/es/docs/agent-api/tools/web-search), [Fetch URL Content](/es/docs/agent-api/tools/fetch-url-content) y [People Search](/es/docs/agent-api/tools/people-search) sin necesidad de añadirlas a la solicitud, y después operar sobre lo que devuelven; cada una se factura a su tarifa estándar. La [referencia de la herramienta Sandbox](/es/docs/agent-api/tools/sandbox) recoge todos los ajustes, la estructura de la respuesta y los precios.

<div id="enable-the-sandbox">
  ## Habilitar el sandbox
</div>

Agrega `{"type": "sandbox"}` al arreglo `tools`. El model decide cuándo ejecutar código según tu prompt.

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()


  def get_output_text(response) -> str:
      return "".join(
          content.text
          for item in response.output or []
          if getattr(item, "type", None) == "message"
          for content in getattr(item, "content", None) or []
          if getattr(content, "type", None) == "output_text"
      )


  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Compute the compound annual growth rate from 4.2M in 2019 to 11.8M in 2025.",
      tools=[{"type": "sandbox"}],
      instructions="Use the sandbox to compute the exact figure before answering.",
  )

  print(get_output_text(response))
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
    model: 'openai/gpt-5.6-sol',
    input: 'Compute the compound annual growth rate from 4.2M in 2019 to 11.8M in 2025.',
    tools: [{ type: 'sandbox' as const }],
    instructions: 'Use the sandbox to compute the exact figure before answering.',
  });

  console.log(response.output_text);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "Compute the compound annual growth rate from 4.2M in 2019 to 11.8M in 2025.",
      "tools": [{ "type": "sandbox" }],
      "instructions": "Use the sandbox to compute the exact figure before answering."
    }' | jq
  ```
</CodeGroup>

<div id="when-to-reach-for-it">
  ## Cuándo utilizarlo
</div>

* Cálculos numéricos y análisis estadísticos en los que una estimación no basta
* Limpieza, análisis sintáctico y transformación de datos
* Ejecución de código para comprobar la lógica o reproducir un error
* Generación de archivos y artefactos: CSV, JSON, HTML, informes o cualquier otro archivo que genere el código
* Flujos de trabajo de varios pasos que requieren archivos intermedios o un estado calculado

<Tip>
  Combina `sandbox` con `web_search` y el agente podrá recopilar evidencia para luego procesarla dentro del contenedor. Consulta la [referencia de Sandbox](/es/docs/agent-api/tools/sandbox) para ver cómo interactúa el sandbox con otras herramientas.
</Tip>

<div id="read-the-computed-result">
  ## Leer el resultado calculado
</div>

Cuando el agente ejecuta código, el array `output` de la respuesta incluye uno o más elementos `sandbox_results` junto al `message`. Cada uno contiene el `code` ejecutado, el `language` y un array `results` con `stdout`, `stderr`, `exit_code` y `status`. Así es como puedes verificar que el agente calculó la respuesta en lugar de adivinarla. Consulta la [referencia de la estructura de la respuesta](/es/docs/agent-api/tools/sandbox#response-shape) para ver todos los campos.

Extrae ese elemento de la respuesta (aquí `response` proviene del ejemplo [Habilitar el sandbox](#enable-the-sandbox) anterior):

```python Python theme={null}
for item in response.output:
    if item.type == "sandbox_results":
        print(item.code)
        print(item.results[0].stdout)
```

Para esa solicitud, el agente escribió y ejecutó este código Python en el sandbox y luego utilizó el valor impreso en su respuesta:

<div id="return-files">
  ## Devolver archivos
</div>

Cuando el código del sandbox escribe un archivo y lo comparte, el `output` de la respuesta incluye un elemento `share_file`. Los bytes no vienen incluidos en línea: lístalos y descárgalos con los endpoints de archivos de respuestas, indexados por el `id` de la respuesta:

<CodeGroup>
  ```python Python theme={null}
  files = client.responses.files.list(response.id)
  for f in files.data:
      print(f.id, f.filename, f.bytes)

  content = client.responses.files.content(
      file_id=files.data[0].id,
      response_id=response.id,
  )
  content.write_to_file(files.data[0].filename)
  ```

  ```bash cURL theme={null}
  # Lista los archivos que produjo la respuesta
  curl https://api.perplexity.ai/v1/agent/$RESPONSE_ID/files \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" | jq

  # Descarga uno por su id de archivo
  curl https://api.perplexity.ai/v1/agent/$RESPONSE_ID/files/$FILE_ID/content \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -o output.csv
  ```
</CodeGroup>

<Note>
  Las tareas prolongadas en el sandbox se complementan bien con las ejecuciones en segundo plano: envía la solicitud con `background: true` y consulta el estado por ID. Consulta [Control de salida](/es/docs/agent-api/output-control) y la [referencia de Sandbox](/es/docs/agent-api/tools/sandbox#running-in-the-background).
