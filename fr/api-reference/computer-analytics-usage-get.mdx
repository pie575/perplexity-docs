---
title: "Analyses d'utilisation"
description: "Renvoie les analyses d'utilisation de Perplexity de votre
  organisation sous forme de série temporelle découpée en intervalles, pour un
  seul jeu de données. Nécessite une API key d'analyse d'organisation, générée
  par un administrateur de l'organisation depuis Settings → Organization →
  Computer dans l'application web Perplexity. Seuls les intervalles complets de
  la grille UTC sont renvoyés : start_time est ramené au début de son intervalle
  et l'intervalle en cours n'est jamais inclus. Chaque jeu de données
  comptabilise des éléments différents : les crédits pour credit_usage, les
  requêtes pour query_volume, les membres actifs distincts pour
  daily_active_users et le nombre de fils de discussion pour les autres. Les
  intervalles de daily_active_users ne sont pas additifs : un membre actif
  plusieurs jours est compté une fois par jour, si bien que leur somme ne
  correspond pas au nombre de membres actifs sur la période."
openapi: "/fr/openapi/openapi.json GET /v1/analytics/computer/usage"
