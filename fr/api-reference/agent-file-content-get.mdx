title: "Télécharger le fichier d'une réponse d'agent"
description: "Téléchargez les octets bruts d'un fichier transmis par la réponse
  via l'outil `share_file`. Le `file_id` provient du point de terminaison de
  liste des fichiers et diffère de l'`id` de la réponse. La réponse renvoie un
  flux d'octets bruts, et non du JSON, avec un `Content-Type` correspondant au
  fichier et un en-tête `Content-Disposition: attachment` indiquant le nom de
  fichier d'origine."
openapi: "/fr/openapi/openapi.json GET /v1/agent/{id}/files/{file_id}/content"
