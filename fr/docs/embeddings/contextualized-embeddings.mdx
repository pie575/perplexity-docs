---
title: "Embeddings contextualisés"
description: "Générez des embeddings tenant compte du document pour des fragments partageant un même contexte, afin d'améliorer la qualité de la récupération dans les applications basées sur des documents."
---

<div id="overview">
  ## Vue d&#39;ensemble
</div>

Les embeddings contextualisés génèrent des embeddings pour des fragments de document qui partagent une même connaissance du contexte. Contrairement aux embeddings standards, où chaque texte est encodé indépendamment, les embeddings contextualisés tiennent compte du fait que les fragments appartiennent au même document et intègrent cette relation.

<Info>
  Utilisez les embeddings contextualisés lorsque vous encodez des fragments issus d&#39;un même document (paragraphes, sections, etc.). Utilisez les [embeddings standards](/fr/docs/embeddings/quickstart) pour des textes indépendants tels que des requêtes de recherche ou des phrases isolées.
</Info>

<div id="models">
  ## Modèles
</div>

|            Modèle            | Dimensions | Contexte | MRL | Quantification | Prix ($/1M tokens) |
| :--------------------------: | :--------: | :------: | :-: | :------------: | :----------------: |
| `pplx-embed-context-v1-0.6b` |    1024    |    32K   | Oui |   INT8/BINARY  |       $0.008       |
|  `pplx-embed-context-v1-4b`  |    2560    |    32K   | Oui |   INT8/BINARY  |        $0.05       |

Tous les modèles utilisent le mean pooling et ne nécessitent aucun préfixe d&#39;instruction.

<div id="basic-usage">
  ## Utilisation de base
</div>

Transmettez les documents sous forme de tableaux imbriqués, où chaque tableau interne représente les fragments d&#39;un même document :

<Warning>
  **Ordre des fragments :** les fragments de chaque document doivent être envoyés dans l&#39;ordre où ils apparaissent dans le document source. Le modèle s&#39;appuie sur le contexte séquentiel pour générer des embeddings tenant compte du document ; conserver l&#39;ordre d&#39;origine est donc essentiel pour obtenir des résultats optimaux.
</Warning>

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.contextualized_embeddings.create(
      input=[
          # Document 1 : trois fragments
          [
              "Curiosity begins in childhood with endless questions about the world.",
              "As we grow, curiosity drives us to explore new ideas and challenge assumptions.",
              "Scientific breakthroughs often start with a simple curious question."
          ],
          # Document 2 : deux fragments
          [
              "The Curiosity rover explores Mars, searching for signs of ancient life.",
              "Each discovery on Mars sparks new questions about our place in the universe."
          ]
      ],
      model="pplx-embed-context-v1-4b"
  )

  for doc in response.data:
      for chunk in doc.data:
          print(f"Doc {doc.index}, Chunk {chunk.index}: {chunk.embedding}")
  ```

<div id="parameters">
  ## Paramètres
</div>

| Paramètre         | Type                 | Requis |   Par défaut  | Description                                                                                                                            |
| ----------------- | -------------------- | :----: | :-----------: | -------------------------------------------------------------------------------------------------------------------------------------- |
| `input`           | array[array[string]] |   Oui  |       -       | Tableau imbriqué : chaque tableau interne contient les fragments d&#39;un même document. 512 documents et 16 000 fragments au maximum. |
| `model`           | string               |   Oui  |       -       | Identifiant du modèle : `pplx-embed-context-v1-0.6b` ou `pplx-embed-context-v1-4b`                                                      |
| `dimensions`      | integer              |   Non  |    Complète   | Dimension Matryoshka (128-1024 pour le 0.6b, 128-2560 pour le 4b)                                                                      |
| `encoding_format` | string               |   Non  | `base64_int8` | Encodage de sortie : `base64_int8` (int8 signé) ou `base64_binary` (bits compactés)                                                    |

<Warning>
  **Limites d&#39;entrée :** le nombre total de tokens par document ne doit pas dépasser 32 K. Le nombre total de fragments, tous documents confondus, ne doit pas dépasser 16 000. L&#39;ensemble des fragments d&#39;une même requête ne doit pas dépasser 120 000 tokens cumulés. Les chaînes vides ne sont pas autorisées.
</Warning>

<div id="golden-chunk-retrieval-example">
  ## Exemple de récupération de golden fragments
</div>

Créez un système de récupération de fragments dans lequel les fragments issus d&#39;un même document partagent le même contexte :

<CodeGroup>
  ```python Python theme={null}
  import base64
  import numpy as np
  from perplexity import Perplexity

  client = Perplexity()

  def decode_embedding(b64_string):
      """Decode a base64-encoded int8 embedding."""
      return np.frombuffer(base64.b64decode(b64_string), dtype=np.int8).astype(np.float32)

  def cosine_similarity(a, b):
      return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

  # Vos documents, chacun découpé en segments
  documents = [
      {
          "title": "Machine Learning Guide",
          "chunks": [
              "Machine learning is a subset of AI that enables systems to learn.",
              "Supervised learning uses labeled data for training models.",
              "Unsupervised learning finds patterns in unlabeled data."
          ]
      },
      {
          "title": "Deep Learning Fundamentals",
          "chunks": [
              "Deep learning uses neural networks with multiple layers.",
              "Convolutional networks excel at image processing tasks.",
              "Transformers revolutionized natural language processing."
          ]
      }
  ]

  # 1. Encoder tous les segments des documents en tenant compte du contexte
  doc_chunks = [doc["chunks"] for doc in documents]
  doc_response = client.contextualized_embeddings.create(
      input=doc_chunks,
      model="pplx-embed-context-v1-4b"
  )

  # Construire l'index
  chunk_index = []
  for doc_obj in doc_response.data:
      for chunk_obj in doc_obj.data:
          chunk_index.append({
              "doc_idx": doc_obj.index,
              "chunk_idx": chunk_obj.index,
              "embedding": decode_embedding(chunk_obj.embedding),
              "text": documents[doc_obj.index]["chunks"][chunk_obj.index],
              "doc_title": documents[doc_obj.index]["title"]
          })

  # 2. Encoder la requête avec le même model contextualisé
  # Encapsuler chaque requête dans une liste interne à un seul élément : [[query1], [query2]]
  query = "How do neural networks process images?"
  query_response = client.contextualized_embeddings.create(
      input=[[query]],
      model="pplx-embed-context-v1-4b"
  )
  query_embedding = decode_embedding(query_response.data[0].data[0].embedding)

  # 3. Trouver les segments les plus pertinents
  results = []
  for item in chunk_index:
      score = cosine_similarity(query_embedding, item["embedding"])
      results.append({**item, "score": score})

  results = sorted(results, key=lambda x: x["score"], reverse=True)

  print(f"Query: {query}\n")
  print("Top results:")
  for r in results[:3]:
      print(f"  [{r['doc_title']}] {r['score']:.4f}: {r['text'][:60]}...")
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  function decodeEmbedding(b64String: string): Int8Array {
      const buffer = Buffer.from(b64String, 'base64');
      return new Int8Array(buffer.buffer, buffer.byteOffset, buffer.byteLength);
  }

  function cosineSimilarity(a: Int8Array, b: Int8Array): number {
      let dotProduct = 0, normA = 0, normB = 0;
      for (let i = 0; i < a.length; i++) {
          dotProduct += a[i] * b[i];
          normA += a[i] * a[i];
          normB += b[i] * b[i];
      }
      return dotProduct / (Math.sqrt(normA) * Math.sqrt(normB));
  }

  // Vos documents, chacun découpé en fragments
  const documents = [
      {
          title: "Machine Learning Guide",
          chunks: [
              "Machine learning is a subset of AI that enables systems to learn.",
              "Supervised learning uses labeled data for training models.",
              "Unsupervised learning finds patterns in unlabeled data."
          ]
      },
      {
          title: "Deep Learning Fundamentals",
          chunks: [
              "Deep learning uses neural networks with multiple layers.",
              "Convolutional networks excel at image processing tasks.",
              "Transformers revolutionized natural language processing."
          ]
      }
  ];

  // 1. Encoder tous les fragments des documents en tenant compte du contexte
  const docChunks = documents.map(doc => doc.chunks);
  const docResponse = await client.contextualizedEmbeddings.create({
      input: docChunks,
      model: "pplx-embed-context-v1-4b"
  });

  // Construire l'index
  const chunkIndex = docResponse.data!.flatMap(docObj =>
      docObj.data!.map(chunkObj => ({
          docIdx: docObj.index,
          chunkIdx: chunkObj.index,
          embedding: decodeEmbedding(chunkObj.embedding!),
          text: documents[docObj.index as number].chunks[chunkObj.index as number],
          docTitle: documents[docObj.index as number].title
      }))
  );

  // 2. Encoder la requête avec le même modèle contextualisé
  // Encapsuler chaque requête dans une liste interne à un seul élément : [[query1], [query2]]
  const query = "How do neural networks process images?";
  const queryResponse = await client.contextualizedEmbeddings.create({
      input: [[query]],
      model: "pplx-embed-context-v1-4b"
  });
  const queryEmbedding = decodeEmbedding(queryResponse.data![0].data![0].embedding!);

  // 3. Trouver les fragments les plus pertinents
  const results = chunkIndex
      .map(item => ({
          ...item,
          score: cosineSimilarity(queryEmbedding, item.embedding)
      }))
      .sort((a, b) => b.score - a.score);

  console.log(`Query: ${query}\n`);
  console.log("Top results:");
  for (const r of results.slice(0, 3)) {
      console.log(`  [${r.docTitle}] ${r.score.toFixed(4)}: ${r.text.slice(0, 60)}...`);
  }
  ```
</CodeGroup>

<div id="when-to-use-contextualized-vs-standard">
  ## Quand utiliser les embeddings contextualisés plutôt que standards
</div>

| Cas d&#39;usage              | Recommandation            |
| ---------------------------- | ------------------------- |
| Phrases indépendantes        | Embeddings standards      |
| Entrées de FAQ               | Embeddings standards      |
| Récupération à usage général | Embeddings standards      |
| Paragraphes de documents     | Embeddings contextualisés |
| Sections de PDF              | Embeddings contextualisés |
| Fragments d&#39;articles     | Embeddings contextualisés |
| Segments de fichiers de code | Embeddings contextualisés |

<Tip>
  **Règle empirique :** si les fragments proviennent du même document source et que leur sens dépend du contexte environnant, utilisez des embeddings contextualisés. Si chaque texte se suffit à lui-même, utilisez des embeddings standards. Avec des embeddings contextualisés, encodez les requêtes avec le même modèle contextualisé, en encapsulant chaque requête dans une liste interne à un seul élément (par exemple, `[[query]]`).
</Tip>
