<div id="financial-news-tracker">
  # Suivi de l&#39;actualité financière
</div>

Un outil en ligne de commande qui récupère et analyse l&#39;actualité financière en temps réel grâce à la Sonar API de Perplexity. Obtenez une vision complète des marchés, des synthèses d&#39;actualités et des analyses d&#39;investissement sur n&#39;importe quel sujet financier.

<div id="features">
  ## Fonctionnalités
</div>

* Agrégation en temps réel de l&#39;actualité financière issue de sources multiples
* Analyse du sentiment de marché (haussier/baissier/neutre)
* Évaluation de l&#39;impact des actualités (élevé/moyen/faible)
* Analyse par secteur et par entreprise
* Perspectives d&#39;investissement et recommandations d&#39;investissement
* Plages temporelles personnalisables (de 24 h à 1 an)
* Prise en charge des sorties JSON structurées
* Sortie CLI soignée et enrichie d&#39;émojis

<div id="time-range-options">

</div>

<div id="output-format">
  ## Format de sortie
</div>

L&#39;outil fournit une analyse financière complète comprenant :

<div id="1-executive-summary">
  ### 1. Résumé exécutif
</div>

Un bref aperçu des principales évolutions financières

<div id="2-market-analysis">
  ### 2. Analyse de marché
</div>

* **Sentiment de marché** : tendance générale du marché (🐂 haussier, 🐻 baissier, ⚖️ neutre)
* **Facteurs clés** : éléments influençant le marché
* **Risques** : risques et préoccupations actuels du marché
* **Opportunités** : opportunités d&#39;investissement potentielles

<div id="3-news-items">
  ### 3. Actualités
</div>

Chaque actualité comprend :

* **Titre** : le titre principal de l&#39;actualité
* **Impact** : niveau d&#39;impact sur le marché (🔴 élevé, 🟡 moyen, 🟢 faible)
* **Résumé** : brève description de l&#39;actualité
* **Secteurs concernés** : secteurs d&#39;activité ou entreprises touchés
* **Source** : mention de la source d&#39;information

<div id="4-investment-insights">
  ### 4. Perspectives d&#39;investissement
</div>

Recommandations concrètes et analyses fondées sur l&#39;actualité

<div id="tips-for-best-results">
  ## Conseils pour obtenir les meilleurs résultats
</div>

1. **Soyez précis** : indiquez les symboles boursiers, les noms de secteurs ou des événements spécifiques
2. **Combinez les sujets** : associez des noms d&#39;entreprises à des thèmes pertinents (par exemple, « TSLA véhicules électriques »)
3. **Utilisez des plages temporelles** : adaptez la plage temporelle à votre horizon d&#39;investissement
4. **Surveillez régulièrement** : planifiez des tâches cron pour recevoir chaque jour les actualités du marché

<div id="limitations">
  ## Limitations
</div>

* Les résultats dépendent des informations publiques disponibles
* Il ne s&#39;agit pas de conseils financiers : effectuez toujours vos propres recherches
* Les données historiques peuvent être limitées pour les événements très récents
* La sortie structurée nécessite un accès à la Perplexity API de niveau 3 ou supérieur

<div id="python-integration">
  ### Intégration Python
</div>

```python theme={null}
import subprocess
import json

def get_financial_news(query, time_range="24h"):
    result = subprocess.run(
        ["./financial_news_tracker.py", query, "--time-range", time_range, "--json"],
        capture_output=True,
        text=True
    )
    
    if result.returncode == 0:
        return json.loads(result.stdout)
    else:
        raise Exception(f"Error fetching news: {result.stderr}")

# Exemple d'utilisation
news = get_financial_news("tech stocks", "1w")
print(f"Market sentiment: {news['market_analysis']['market_sentiment']}")
```
