<div id="daily-knowledge-bot">
  # Daily Knowledge Bot
</div>

Une application Python qui propose des faits intéressants sur des sujets qui changent chaque jour, grâce à l&#39;API Perplexity AI. Idéale pour l&#39;apprentissage quotidien, le contenu de newsletters ou la formation personnelle.

<div id="features">
  ## 🌟 Fonctionnalités
</div>

* **Rotation quotidienne des sujets** : sélectionne automatiquement les sujets en fonction du jour du mois
* **Faits générés par IA** : utilise la Sonar API de Perplexity pour produire des faits intéressants et exacts
* **Sujets personnalisables** : étendez ou modifiez facilement la liste des sujets
* **Stockage persistant** : enregistre les faits dans des fichiers texte datés pour consultation ultérieure
* **Gestion robuste des erreurs** : gère proprement les échecs de l&#39;API et les erreurs inattendues
* **Configurable** : utilise des variables d&#39;environnement pour une gestion sécurisée de la clé API

<div id="requirements">
  ## 📋 Prérequis
</div>

* Python 3.6+
* Paquets requis :
  * requests
  * python-dotenv
  * (facultatif) logging

<div id="installation">
  ## 🚀 Installation
</div>

1. Clonez ce dépôt ou téléchargez le script
2. Installez les paquets requis :

```bash theme={null}
# Installation depuis le fichier requirements (recommandé)
pip install -r requirements.txt

# Ou installation manuelle
pip install requests python-dotenv
```

3. Configurez votre clé API Perplexity :
   * Créez un fichier `.env` dans le même répertoire que le script
   * Ajoutez-y votre clé API : `PERPLEXITY_API_KEY=your_api_key_here`

<div id="usage">
  ## 🔧 Utilisation
</div>

<div id="running-the-bot">
  ### Exécution du bot
</div>

Il suffit d&#39;exécuter le script :

```bash theme={null}
python daily_knowledge_bot.py
```

Ce script va :

1. Sélectionner un sujet en fonction du jour en cours
2. Récupérer un fait intéressant auprès de Perplexity AI
3. Enregistrer ce fait dans un fichier texte daté, dans votre répertoire courant
4. Afficher ce fait dans la console

<div id="customizing-topics">
  ### Personnaliser les sujets
</div>

Modifiez le fichier `topics.txt` (un sujet par ligne) ou adaptez directement la liste `topics` dans le script.

Exemples de sujets :

```
astronomie
histoire
biologie
technologie
psychologie
vie marine
civilisations anciennes
physique quantique
histoire de l'art
science culinaire
```

<div id="automated-scheduling">
  ### Planification automatisée
</div>

<div id="on-linuxmacos-using-cron">
  #### Sous Linux/macOS (avec cron) :
</div>

```bash theme={null}
# Modifiez votre crontab
crontab -e

# Ajoutez cette ligne pour une exécution quotidienne à 8h00
0 8 * * * /path/to/python3 /path/to/daily_knowledge_bot.py
```

<div id="on-windows-using-task-scheduler">
  #### Sous Windows (avec le Planificateur de tâches) :
</div>

1. Ouvrez le Planificateur de tâches
2. Créez une tâche de base
3. Configurez-la pour une exécution quotidienne
4. Ajoutez l&#39;action : Démarrer un programme
5. Programme/script : `C:\path\to\python.exe`
6. Arguments : `C:\path\to\daily_knowledge_bot.py`

<div id="configuration-options">
  ## 🔍 Options de configuration
</div>

Les variables d&#39;environnement suivantes peuvent être définies dans votre fichier `.env` :

* `PERPLEXITY_API_KEY` (obligatoire) : votre clé API Perplexity
* `OUTPUT_DIR` (facultatif) : répertoire d&#39;enregistrement des fichiers de faits (par défaut : le répertoire courant)
* `TOPICS_FILE` (facultatif) : chemin vers votre fichier de sujets personnalisé

  ## 📄 Exemple de sortie
</div>

Sujet : astronomie

<div id="extending-the-bot">
  ## 🛠️ Étendre le bot
</div>

Quelques pistes pour étendre ce bot :

* Ajouter l&#39;envoi par e-mail ou SMS
* Créer une interface web pour consulter l&#39;historique des faits
* Intégrer la publication sur les réseaux sociaux
* Ajouter du contenu multimédia en lien avec les faits
* Mettre en place une planification avancée avec des thèmes précis selon les jours

<div id="limitations">
  ## ⚠️ Limitations
</div>

* Des limites de débit peuvent s&#39;appliquer selon votre compte Perplexity
* La qualité des faits dépend du modèle d&#39;IA
* La version gratuite de la Sonar API impose une limite de tokens qui peut tronquer les réponses longues
