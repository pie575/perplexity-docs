Un bot `discord.py` simple qui intègre [la Sonar API de Perplexity](https://docs.perplexity.ai/) à votre serveur Discord. Posez vos questions et obtenez des réponses générées par l&#39;IA avec accès au web, via des commandes slash ou en mentionnant le bot.

<img src="https://mintcdn.com/perplexity/y2ljsQXTUHXyDIEa/docs/cookbook/static/img/discord-py-bot-demo.png?fit=max&auto=format&n=y2ljsQXTUHXyDIEa&q=85&s=af7e57165646fd8bff36ad04c0d22635" alt="Démonstration du bot Discord" />

<div id="features">
  ## ✨ Fonctionnalités
</div>

* **🌐 IA connectée au web** : utilise la Sonar API de Perplexity pour obtenir des informations à jour
* **⚡ Commande slash** : une simple commande `/ask` pour poser vos questions
* **💬 Prise en charge des mentions** : posez vos questions en mentionnant le bot
* **🔗 Citation des sources** : mise en forme automatique et liens vers les sources
* **🔒 Configuration sécurisée** : configuration des API keys par variables d&#39;environnement

<div id="prerequisites">
  ## 🛠️ Prérequis
</div>

<Steps>
  <Step title="Environnement Python">
    **Python 3.8+** installé sur votre système

    ```bash theme={null}
    python --version  # Doit être 3.8 ou supérieur
    ```

  </Step>

  <Step title="Accès à la Perplexity API">
    **clé API Perplexity active** obtenue depuis la [console de la plateforme Perplexity API](https://console.perplexity.ai)

  </Step>

  <Step title="Application bot Discord">
    **Token de bot Discord** obtenu depuis le [portail développeur Discord](https://discord.com/developers/applications)
  </Step>
</Steps>

<div id="quick-start">
  ## 🚀 Démarrage rapide
</div>

<div id="1-repository-setup">
  ### 1. Configuration du dépôt
</div>

Clonez le dépôt et accédez au répertoire du bot :

```bash theme={null}
git clone https://github.com/ppl-ai/api-cookbook.git
cd api-cookbook/docs/examples/discord-py-bot/
```

<div id="2-install-dependencies">
  ### 2. Installer les dépendances
</div>

```bash theme={null}
# Créer un environnement virtuel (recommandé)
python -m venv venv
source venv/bin/activate  # Sous Windows : venv\Scripts\activate

# Installer les paquets requis
pip install -r requirements.txt
```

<div id="3-configure-api-keys">
  ### 3. Configurer les clés API
</div>

<Steps>
  <Step title="Obtenir votre clé API Perplexity">
    1. Rendez-vous sur la [console Perplexity API Platform](https://console.perplexity.ai)
    2. Générez une nouvelle clé API
    3. Copiez la clé dans le fichier .env

    <Warning>Conservez votre clé API en lieu sûr ! Ne la committez jamais dans un gestionnaire de versions et ne la partagez jamais publiquement.</Warning>
  </Step>

  <Step title="Créer une application de bot Discord">
    1. Accédez au [portail développeur Discord](https://discord.com/developers/applications)
    2. Cliquez sur **« New Application »** et donnez-lui un nom explicite
    3. Rendez-vous dans la section **« Bot »**
    4. Cliquez sur **« Reset Token »** (ou « Add Bot » lors de la première utilisation)
    5. Copiez le token du bot
  </Step>

  <Step title="Configurer les variables d'environnement">
    Copiez le fichier d&#39;environnement d&#39;exemple et ajoutez-y vos clés :

    ```bash theme={null}
    cp env.example .env
    ```

    Modifiez `.env` avec vos identifiants :

    ```bash title=".env" theme={null}
    DISCORD_TOKEN="your_discord_bot_token_here"
    PERPLEXITY_API_KEY="your_perplexity_api_key_here"
    ```
  </Step>
</Steps>

<div id="usage-guide">
  ## 🎯 Guide d&#39;utilisation
</div>

<div id="bot-invitation-setup">
  ### Invitation et configuration du bot
</div>

<Steps>
  <Step title="Générer l'URL d'invitation">
    Dans le portail développeur Discord :

    1. Rendez-vous dans **OAuth2** → **URL Generator**
    2. Sélectionnez les scopes : `bot` et `applications.commands`
    3. Sélectionnez les permissions du bot : `Send Messages`, `Use Slash Commands`
    4. Copiez l&#39;URL générée
  </Step>

  <Step title="Inviter sur un serveur">
    1. Collez l&#39;URL dans votre navigateur
    2. Sélectionnez le serveur Discord auquel ajouter le bot
    3. Confirmez les permissions
  </Step>

  <Step title="Démarrer le bot">
    ```bash theme={null}
    python bot.py
    ```

    Une sortie devrait confirmer que le bot est en ligne et que les commandes ont été synchronisées.
  </Step>
</Steps>

<div id="response-format">
  ## 📊 Format des réponses
</div>

Le bot fournit des réponses claires et lisibles, avec :

* **Réponse de l&#39;IA** : réponse directe de la Sonar API de Perplexity
* **Citations des sources** : liens cliquables vers les sources (lorsqu&#39;elles sont disponibles)
* **Troncature automatique** : les réponses sont raccourcies pour respecter les limites de Discord

<div id="technical-details">
  ## 🔧 Détails techniques
</div>

Ce bot utilise :

* **Modèle** : le modèle `sonar-pro` de Perplexity
* **Limite de réponse** : 2000 tokens renvoyés par l&#39;API, tronqués pour tenir dans Discord
* **Température** : 0.2 pour des réponses cohérentes et factuelles
* **Aucune permission requise** : n&#39;importe qui sur le serveur peut utiliser le bot
