<div id="academic-research-finder-cli">
  # CLI de recherche de publications académiques
</div>

Un outil en ligne de commande qui s&#39;appuie sur la Sonar API de Perplexity pour trouver et résumer la littérature académique (articles de recherche, publications, etc.) se rapportant à une question ou à un sujet donné.

<div id="features">
  ## Fonctionnalités
</div>

* Accepte en entrée une question ou un sujet en langage naturel, particulièrement adapté à la recherche universitaire.
* S&#39;appuie sur la Sonar API de Perplexity, guidée par un prompt spécialisé afin de privilégier les sources académiques (revues, actes de conférences, bases de données universitaires, etc.).
* Produit un résumé concis à partir des résultats issus de la littérature académique.
* Répertorie les principales sources académiques utilisées, en s&#39;efforçant d&#39;indiquer les auteurs, l&#39;année, le titre, la publication et le DOI ou le lien lorsque c&#39;est possible.
* Prend en charge différents modèles Perplexity (`sonar-pro` par défaut).
* Permet de restituer les résultats au format JSON.

<div id="installation">
  ## Installation
</div>

<div id="1-install-required-dependencies">
  ### 1. Installer les dépendances requises
</div>

Assurez-vous d&#39;utiliser l&#39;environnement Python avec lequel vous comptez exécuter le script (par exemple `python3.10` si c&#39;est la version visée).

```bash theme={null}
# Installation depuis le fichier requirements (recommandé)
pip install -r requirements.txt

# Ou installation manuelle
pip install requests
```

<div id="2-make-the-script-executable-optional">
  ### 2. Rendre le script exécutable (facultatif)
</div>

```bash theme={null}
chmod +x research_finder.py
```

Vous pouvez également exécuter le script avec `python3 research_finder.py ...`.

<div id="api-key-setup">
  ## Configuration de la clé API
</div>

L&#39;outil nécessite une clé API Perplexity (`PPLX_API_KEY`) pour fonctionner. Vous pouvez la fournir de l&#39;une des manières suivantes (vérifiées dans cet ordre) :

1. **En argument de ligne de commande :**
   ```bash theme={null}
   python3 research_finder.py "Your query" --api-key YOUR_API_KEY
   ```
2. **En variable d&#39;environnement :**
   ```bash theme={null}
   export PPLX_API_KEY=YOUR_API_KEY
   python3 research_finder.py "Your query"
   ```
3. **Dans un fichier :** créez un fichier nommé `pplx_api_key`, `.pplx_api_key`, `PPLX_API_KEY` ou `.PPLX_API_KEY` dans le *même répertoire que le script* ou dans le *répertoire de travail courant*, ne contenant que votre clé API.
   ```bash theme={null}
   echo "YOUR_API_KEY" > .pplx_api_key
   chmod 600 .pplx_api_key # Facultatif : restreindre les permissions
   python3 research_finder.py "Your query"
   ```

<div id="usage">
  ## Utilisation
</div>

Exécutez le script depuis le répertoire `sonar-use-cases/research_finder` ou indiquez le chemin complet.

```bash theme={null}
# Utilisation de base
python3 research_finder.py "What are the latest advancements in quantum computing?"

# Utilisation d'un modèle spécifique
python3 research_finder.py "Explain the concept of Large Language Models" --model sonar-small-online

# Obtention de la sortie au format JSON
python3 research_finder.py "Summarize the plot of Dune Part Two" --json

# Utilisation d'un fichier de prompt système personnalisé
python3 research_finder.py "Benefits of renewable energy" --prompt-file /path/to/your/custom_prompt.md

# Utilisation d'une clé API passée en argument
python3 research_finder.py "Who won the last FIFA World Cup?" --api-key sk-...

# Utilisation de l'exécutable (si chmod +x a été appliqué)
./research_finder.py "Latest news about Mars exploration"
```

<div id="arguments">
  ### Arguments
</div>

* `query` : (Obligatoire) La question ou le sujet de recherche (à placer entre guillemets s&#39;il contient des espaces).
* `-m`, `--model` : Spécifie le modèle Perplexity à utiliser (par défaut : `sonar-pro`).
* `-k`, `--api-key` : Fournit directement la clé API.
* `-p`, `--prompt-file` : Chemin vers un fichier de prompt système personnalisé.
* `-j`, `--json` : Affiche les résultats au format JSON.

<div id="limitations">
  ## Limitations
</div>

* La capacité de la Sonar API à privilégier systématiquement certaines bases de données académiques, à y accéder ou à en extraire des informations de citation détaillées (comme les DOI) peut varier. La qualité dépend des capacités de recherche de l&#39;API et de la structure des sites sources.
* Le script effectue une analyse syntaxique basique pour séparer le résumé et les sources ; les réponses d&#39;API complexes ou inhabituelles risquent de ne pas être analysées correctement. En cas de problème, consultez la réponse brute.
* Les requêtes trop larges ou mal adaptées à la recherche académique peuvent donner des résultats moins pertinents.
* La gestion des erreurs liées aux limites de débit ou à des erreurs d&#39;API spécifiques pourrait être plus fine.
