<div id="api-key-setup">
  ## Configuration de la clé API
</div>

Tous les exemples nécessitent une clé API Perplexity. Définissez-la dans une variable d&#39;environnement :

```bash theme={null}
export PERPLEXITY_API_KEY="your-api-key-here"
```

<Tip>
  Obtenez votre clé API sur [perplexity.ai/account/api](https://perplexity.ai/account/api).
</Tip>

<div id="common-requirements">
  ## Prérequis communs
</div>

* **Python 3.9+** ou **Node.js 18+** (selon l&#39;exemple)
* **Clé API Perplexity**
* **Connexion Internet** pour les appels d&#39;API

Les prérequis supplémentaires varient d&#39;un exemple à l&#39;autre et sont indiqués dans la documentation de chaque projet.
