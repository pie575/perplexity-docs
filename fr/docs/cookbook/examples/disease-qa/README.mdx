<div id="disease-information-app">
  # Application d&#39;information sur les maladies
</div>

Une application interactive exécutée dans le navigateur qui fournit des informations structurées sur les maladies grâce à la Sonar API de Perplexity. Cette application génère une interface HTML autonome permettant aux utilisateurs de poser des questions sur diverses maladies et d&#39;obtenir des réponses organisées, accompagnées de leurs citations.

<div id="features">
  ## 🌟 Fonctionnalités
</div>

* **Interface conviviale** : design épuré et responsive, adapté à tous les appareils
* **Réponses propulsées par l&#39;IA** : s&#39;appuie sur la Sonar API de Perplexity pour fournir des informations médicales précises
* **Fiches de connaissances structurées** : organise les informations en sections Aperçu, Causes et Traitements
* **Suivi des citations** : répertorie les sources avec des liens cliquables
* **Mise en cache côté client** : évite les appels d&#39;API redondants pour les questions déjà posées
* **Déploiement autonome** : génère un fichier HTML unique utilisable sans serveur
* **Gestion complète des erreurs** : messages d&#39;erreur clairs et traitement robuste des erreurs

<div id="requirements">
  ## 📋 Prérequis
</div>

* Python 3.6+
* Jupyter Notebook ou JupyterLab (pour le développement/la génération)
* Paquets requis :
  * requests
  * pandas
  * python-dotenv
  * IPython

<div id="setup-installation">
  ## 🚀 Configuration et installation
</div>

1. Clonez ce dépôt ou téléchargez le notebook
2. Installez les paquets requis :

```bash theme={null}
# Installation à partir du fichier requirements (recommandé)
pip install -r requirements.txt

# Ou installation manuelle
pip install requests pandas python-dotenv ipython
```

3. Configurez votre API key Perplexity :
   * Créez un fichier `.env` dans le même répertoire que le notebook
   * Ajoutez votre API key : `PERPLEXITY_API_KEY=your_api_key_here`

<div id="usage">
  ## 🔧 Utilisation
</div>

<div id="running-the-notebook">
  ### Exécution du notebook
</div>

1. Ouvrez le notebook dans Jupyter :

```bash theme={null}
jupyter notebook Disease_Information_App.ipynb
```

2. Exécutez toutes les cellules pour générer et lancer l&#39;application web
3. L&#39;application s&#39;ouvrira automatiquement dans votre navigateur web par défaut

<div id="using-the-generated-html">
  ### Utiliser le HTML généré
</div>

Vous pouvez aussi utiliser directement le fichier `disease_qa.html` généré :

1. Ouvrez-le dans n&#39;importe quel navigateur web moderne
2. Saisissez une question sur une maladie (par exemple « Qu&#39;est-ce que le diabète ? » ou « Parlez-moi de la maladie d&#39;Alzheimer »)
3. Cliquez sur « Ask » pour obtenir des informations structurées sur la maladie

<div id="deploying-the-app">
  ### Déployer l&#39;application
</div>

Pour un usage personnel ou pédagogique, il suffit de partager le fichier HTML généré.

En production, pensez à :

1. Mettre en place un véritable backend pour sécuriser votre API key
2. Héberger le fichier sur un serveur web
3. Ajouter des outils d&#39;analytics et une gestion des utilisateurs selon vos besoins

<div id="how-it-works">
  ## 🔍 Fonctionnement
</div>

Cette application :

1. Utilise un prompt soigneusement conçu pour demander à l&#39;IA de produire du JSON structuré
2. Traite ce JSON pour en extraire l&#39;aperçu, les causes, les traitements et les citations
3. Présente les informations sous forme de fiche de connaissances épurée
4. Implémente des appels API côté client avec une gestion des erreurs appropriée
5. Offre un design responsive adapté aussi bien à l&#39;ordinateur qu&#39;au mobile

<div id="technical-details">
  ## ⚙️ Détails techniques
</div>

<div id="api-structure">
  ### Structure de l&#39;API
</div>

L&#39;application attend de l&#39;IA qu&#39;elle renvoie un objet JSON ayant la structure suivante :

```json theme={null}
{
  "overview": "A brief description of the disease.",
  "causes": "The causes of the disease.",
  "treatments": "Possible treatments for the disease.",
  "citations": ["https://example.com/citation1", "https://example.com/citation2"]
}
```

<div id="important-notes">
  ## ⚠️ Remarques importantes
</div>

* **Sécurité de l’API key** : l&#39;implémentation actuelle intègre votre API key directement dans le fichier HTML. Cette approche convient à un usage personnel, mais pas à un déploiement public.
* **Ne constitue pas un avis médical** : cette application fournit des informations générales et ne doit pas servir de base à des décisions médicales. Consultez toujours un professionnel de santé pour tout avis médical.
* **Utilisation de l&#39;API** : tenez compte des limites de débit et de la tarification de la Perplexity API applicables à votre compte.
