<div id="persistent-chat-memory-with-perplexity-sonar-api">
  # Mémoire de conversation persistante avec la Sonar API de Perplexity
</div>

<div id="overview">
  ## Vue d&#39;ensemble
</div>

Cette implémentation illustre la préservation de la mémoire conversationnelle à long terme grâce au stockage vectoriel de LlamaIndex et à la Sonar API de Perplexity. Elle conserve le contexte d&#39;un appel d&#39;API à l&#39;autre grâce à une récupération et une synthèse intelligentes.

<div id="key-features">
  ## Fonctionnalités clés
</div>

* **Conservation du contexte multi-tours** : mémorise les requêtes et réponses précédentes
* **Recherche sémantique** : retrouve les échanges pertinents de l&#39;historique grâce aux embeddings vectoriels
* **Intégration Perplexity** : s&#39;appuie sur le modèle Sonar-pro pour des réponses précises
* **Stockage LanceDB** : historique de conversation persistant grâce à une base de données vectorielle en colonnes

<div id="implementation-details">
  ## Détails d&#39;implémentation
</div>

<div id="core-components">
  ### Composants principaux
</div>

```python theme={null}
# Initialisation de la mémoire
vector_store = LanceDBVectorStore(uri="./lancedb", table_name="chat_history")
storage_context = StorageContext.from_defaults(vector_store=vector_store)
index = VectorStoreIndex([], storage_context=storage_context)
```

<div id="conversation-flow">
  ### Flux de conversation
</div>

1. Stocke les requêtes de l&#39;utilisateur sous forme d&#39;embeddings vectoriels
2. Récupère les 3 interactions passées les plus pertinentes
3. Génère des requêtes vers la Sonar API enrichies de l&#39;historique contextuel
4. Conserve les réponses pour les conversations futures
