Ce guide traite du filtrage par domaine de recherche dans l&#39;Agent API. Vous apprendrez à utiliser des listes d&#39;autorisation pour restreindre la recherche à des domaines fiables, des listes d&#39;exclusion pour écarter les sources indésirables, ainsi que des modèles pratiques répondant à des cas d&#39;usage courants : recherche limitée à l&#39;actualité, données gouvernementales ou exclusion des concurrents.

<Info>
  Le filtrage par domaine se configure outil par outil dans le tableau `tools`, via `tools[].filters.search_domain_filter`. Pour la référence complète, consultez [Filtres de l&#39;Agent API](/fr/docs/agent-api/tools/web-search#filters).
</Info>

<div id="how-domain-filtering-works">
  ## Fonctionnement du filtrage par domaine
</div>

Le paramètre `search_domain_filter` accepte une liste de chaînes de domaines :

* **Liste d&#39;autorisation** (sans préfixe) : n&#39;inclure que les résultats issus de ces domaines. `["reuters.com", "apnews.com"]` limite la recherche à Reuters et AP News.
* **Liste d&#39;exclusion** (préfixe `-`) : exclure les résultats issus de ces domaines. `["-reddit.com", "-twitter.com"]` exclut Reddit et Twitter.

*Vous pouvez également ajouter un chemin à un domaine pour restreindre les résultats à une section d&#39;un site : `["nature.com/articles"]` ne recherche que dans cette section, tandis que `["-reddit.com/r/all"]` l&#39;exclut tout en continuant de parcourir le reste du site.*

<Warning>
  **Ne mélangez jamais des entrées de liste d&#39;autorisation et de liste d&#39;exclusion dans une même requête.** L&#39;API ne permet pas de combiner `"reuters.com"` et `"-reddit.com"` dans le même tableau. Utilisez soit uniquement des entrées d&#39;autorisation, soit uniquement des entrées d&#39;exclusion.
</Warning>

<div id="basic-domain-filtering">
  ## Filtrage par domaine de base
</div>

Les filtres de domaine se configurent par outil, dans le tableau `tools`.

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  # Liste d'autorisation : rechercher uniquement sur des domaines spécifiques
  response = client.responses.create(
      model="openai/gpt-5.4",
      input="What are the latest developments in AI regulation?",
      tools=[{
          "type": "web_search",
          "filters": {
              "search_domain_filter": ["reuters.com", "apnews.com", "bbc.com"],
          },
      }],
  )
  print(response.output_text)
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      model: "openai/gpt-5.4",
      input: "What are the latest developments in AI regulation?",
      tools: [{
          type: "web_search" as const,
          filters: {
              search_domain_filter: ["reuters.com", "apnews.com", "bbc.com"],
          },
      }],
  });
  console.log(response.output_text);
  ```
</CodeGroup>

<div id="pattern-path-filtering">
  ## Modèle : filtrage par chemin
</div>

Ajoutez un chemin après un domaine pour limiter les résultats à une section précise d&#39;un site : une documentation, un subreddit, un blog ou une rubrique d&#39;actualité, par exemple. Cela fonctionne aussi bien en mode liste d&#39;autorisation qu&#39;en mode liste d&#39;exclusion.

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  # Autoriser une seule section d'un site, et exclure une section d'un autre
  response = client.responses.create(
      model="openai/gpt-5.4",
      input="Summarize recent peer-reviewed CRISPR results",
      tools=[{
          "type": "web_search",
          "filters": {
              "search_domain_filter": ["nature.com/articles", "science.org"],
          },
      }],
  )
  print(response.output_text)
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      model: "openai/gpt-5.4",
      input: "Summarize recent peer-reviewed CRISPR results",
      tools: [{
          type: "web_search" as const,
          filters: {
              search_domain_filter: ["nature.com/articles", "science.org"],
          },
      }],
  });
  console.log(response.output_text);
  ```
</CodeGroup>

<Note>
  La correspondance des chemins s&#39;effectue sur les limites de segment : `"example.com/docs"` correspond donc à `/docs` et `/docs/intro`, mais pas à `/documentation`. Les sous-domaines sont inclus (`blog.example.com/docs` correspond). Les chaînes de requête placées après la limite sont autorisées (`/docs?x=1`).
</Note>

<div id="pattern-news-only-search">
  ## Modèle : recherche limitée à l&#39;actualité
</div>

Restreignez les résultats aux grands médias d&#39;information pour suivre l&#39;actualité et les dernières informations de dernière minute.

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  NEWS_DOMAINS = [
      "reuters.com",
      "apnews.com",
      "bbc.com",
      "nytimes.com",
      "washingtonpost.com",
      "theguardian.com",
      "bloomberg.com",
      "ft.com",
  ]

  response = client.responses.create(
      model="openai/gpt-5.4",
      input="What happened in global markets today?",
      tools=[{
          "type": "web_search",
          "filters": {
              "search_domain_filter": NEWS_DOMAINS,
              "search_recency_filter": "day",
          },
      }],
  )
  print(response.output_text)
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const NEWS_DOMAINS = [
      "reuters.com",
      "apnews.com",
      "bbc.com",
      "nytimes.com",
      "washingtonpost.com",
      "theguardian.com",
      "bloomberg.com",
      "ft.com",
  ];

  const response = await client.responses.create({
      model: "openai/gpt-5.4",
      input: "What happened in global markets today?",
      tools: [{
          type: "web_search" as const,
          filters: {
              search_domain_filter: NEWS_DOMAINS,
              search_recency_filter: "day",
          },
      }],
  });
  console.log(response.output_text);
  ```
</CodeGroup>

<Tip>
  Combinez `search_domain_filter` et `search_recency_filter` pour les requêtes sensibles à la fraîcheur des informations. Les options disponibles sont `day`, `week`, `month` et `year`.
</Tip>

<div id="configurable-filter-builder">
  ## Générateur de filtres configurable
</div>

Une fonction utilitaire réutilisable qui construit des configurations de filtrage par domaine à partir de presets nommés.

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  # Presets de filtres nommés
  FILTER_PRESETS = {
      "news": ["reuters.com", "apnews.com", "bbc.com", "bloomberg.com", "ft.com"],
      "academic": [".edu", "arxiv.org", "nature.com", "science.org", "pubmed.ncbi.nlm.nih.gov"],
      "government": [".gov", ".gov.uk", ".europa.eu", "who.int"],
      "tech": ["techcrunch.com", "arstechnica.com", "theverge.com", "wired.com"],
      "no_social": ["-reddit.com", "-twitter.com", "-facebook.com", "-tiktok.com", "-quora.com"],
      "no_seo_spam": ["-pinterest.com", "-medium.com", "-hubspot.com"],
  }


  def search_with_preset(query: str, preset: str, recency: str = None) -> str:
      """Exécute une recherche avec un preset de filtrage par domaine nommé."""
      if preset not in FILTER_PRESETS:
          raise ValueError(f"Unknown preset: {preset}. Options: {list(FILTER_PRESETS.keys())}")

      filters = {"search_domain_filter": FILTER_PRESETS[preset]}
      if recency:
          filters["search_recency_filter"] = recency

      response = client.responses.create(
          model="openai/gpt-5.4",
          input=query,
          tools=[{"type": "web_search", "filters": filters}],
      )
      return response.output_text


  # Utilisation
  print("--- News Search ---")
  print(search_with_preset("Latest AI regulation news", "news", recency="week"))

  print("\n--- Academic Search ---")
  print(search_with_preset("CRISPR gene editing recent papers", "academic"))

  print("\n--- Clean Search (no social media) ---")
  print(search_with_preset("Best Python testing frameworks", "no_social"))
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const FILTER_PRESETS: Record<string, string[]> = {
      news: ["reuters.com", "apnews.com", "bbc.com", "bloomberg.com", "ft.com"],
      academic: [".edu", "arxiv.org", "nature.com", "science.org", "pubmed.ncbi.nlm.nih.gov"],
      government: [".gov", ".gov.uk", ".europa.eu", "who.int"],
      tech: ["techcrunch.com", "arstechnica.com", "theverge.com", "wired.com"],
      no_social: ["-reddit.com", "-twitter.com", "-facebook.com", "-tiktok.com", "-quora.com"],
      no_seo_spam: ["-pinterest.com", "-medium.com", "-hubspot.com"],
  };

  async function searchWithPreset(query: string, preset: string, recency?: string): Promise<string> {
      if (!(preset in FILTER_PRESETS)) {
          throw new Error(`Unknown preset: ${preset}. Options: ${Object.keys(FILTER_PRESETS).join(", ")}`);
      }

      const filters: Record<string, any> = { search_domain_filter: FILTER_PRESETS[preset] };
      if (recency) filters.search_recency_filter = recency;

      const response = await client.responses.create({
          model: "openai/gpt-5.4",
          input: query,
          tools: [{ type: "web_search" as const, filters }],
      });
      return response.output_text;
  }

  console.log("--- News Search ---");
  console.log(await searchWithPreset("Latest AI regulation news", "news", "week"));

  console.log("\n--- Academic Search ---");
  console.log(await searchWithPreset("CRISPR gene editing recent papers", "academic"));

  console.log("\n--- Clean Search (no social media) ---");
  console.log(await searchWithPreset("Best Python testing frameworks", "no_social"));
  ```
</CodeGroup>

<div id="common-pitfalls">
  ## Pièges courants
</div>

<div id="mixing-allowlist-and-denylist">
  ### Combiner liste d&#39;autorisation et liste d&#39;exclusion
</div>

```python theme={null}
# ❌ INCORRECT : mélange d'une liste d'autorisation et d'une liste d'exclusion
search_domain_filter=["reuters.com", "-reddit.com"]

# ✅ CORRECT : utiliser uniquement une liste d'autorisation
search_domain_filter=["reuters.com", "apnews.com", "bbc.com"]

# ✅ CORRECT : utiliser uniquement une liste d'exclusion
search_domain_filter=["-reddit.com", "-twitter.com"]
```

<div id="using-wildcards-incorrectly">
  ### Mauvaise utilisation des caractères génériques
</div>

```python theme={null}
# ❌ INCORRECT : les caractères génériques ne sont pas pris en charge
search_domain_filter=["*.gov"]

# ✅ CORRECT : utilisez directement le TLD
search_domain_filter=[".gov"]

# ✅ CORRECT : ciblez une section à l'aide d'un préfixe de chemin (sans caractères génériques)
search_domain_filter=["example.com/blog"]
```

<div id="empty-filter-arrays">
  ### Tableaux de filtres vides
</div>

```python theme={null}
# ❌ INCORRECT : un tableau vide entraîne un comportement indéfini
search_domain_filter=[]

# ✅ CORRECT : omettez le paramètre pour rechercher dans tous les domaines
# (n'incluez simplement pas search_domain_filter)
```

<div id="tips-and-best-practices">
  ## Conseils et bonnes pratiques
</div>

1. **Gardez vos listes d&#39;autorisation ciblées.** 5 à 10 domaines suffisent généralement. Un trop grand nombre de domaines dilue l&#39;objectif du filtre.

2. **Utilisez les listes d&#39;exclusion pour les exclusions larges.** Lorsque vous souhaitez exclure quelques sources parasites tout en interrogeant l&#39;ensemble du web, les listes d&#39;exclusion sont plus pratiques que d&#39;essayer d&#39;autoriser tout le reste.

3. **Combinez-les avec des filtres de récence.** Pour les requêtes sensibles au facteur temps, ajoutez `search_recency_filter` en complément des filtres de domaine.

4. **Testez vos filtres.** Exécutez la même requête avec et sans filtres afin de vérifier que les résultats évoluent comme prévu.

5. **Les filtres de TLD s&#39;appliquent largement.** `.gov` correspond à tout domaine se terminant par `.gov`, y compris `whitehouse.gov`, `irs.gov` et des domaines d&#39;États comme `ca.gov`.

6. **Stockez les presets dans la configuration.** Définissez vos presets de filtres dans la configuration de votre application plutôt que de les coder en dur dans chaque requête.
