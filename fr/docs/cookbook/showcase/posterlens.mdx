**PosterLens** est une application iOS qui transforme les posters scientifiques statiques en contenus interactifs et explorables grâce à l&#39;OCR et à l&#39;IA. Conçue pour le Perplexity Hackathon 2025, elle permet aux chercheurs, aux MSL et aux rédacteurs médicaux de scanner des posters et de les explorer de façon interactive en langage naturel, afin d&#39;en extraire le sens et de faire remonter instantanément les études associées.

![Capture d'écran de PosterLens](https://cdn.prod.website-files.com/66d49e8555a289120a81ec3e/68930ad938e072c05d1be0b9_PosterLens.png)

<div id="features">
  ## Fonctionnalités
</div>

* **Numérisation de posters scientifiques** avec la caméra de l&#39;appareil et l&#39;OCR Apple Vision
* **Questions-réponses en langage naturel** sur le contenu des posters, avec des réponses générées par IA
* **Intégration de la recherche sémantique** via Perplexity Sonar Pro pour les études connexes
* **Validation des citations** avec les E-utilities de PubMed pour garantir la rigueur académique
* **Génération automatique de questions de recherche** et de pistes de recherche futures
* **Traitement sur l&#39;appareil** pour la confidentialité et les performances
* **Expérience de recherche interactive** qui transforme un contenu statique en informations dynamiques

<div id="prerequisites">
  ## Prérequis
</div>

* Appareil iOS 17+ équipé d&#39;un appareil photo
* Xcode 15+ pour le développement
* Compte Apple Developer pour la distribution sur l&#39;App Store
* Clé API Perplexity (Sonar Pro)
* Clé API OpenAI (GPT-3.5)
* Accès aux E-utilities de PubMed

<div id="configuration">
  ## Configuration
</div>

Ajoutez vos clés API à la configuration du projet :

```swift theme={null}
// Configuration de l'API
PERPLEXITY_API_KEY=your_sonar_pro_api_key
OPENAI_API_KEY=your_gpt_api_key
PUBMED_API_KEY=your_pubmed_api_key
```

<div id="usage">
  ## Utilisation
</div>

1. **Installer depuis l&#39;App Store** : téléchargez PosterLens sur l&#39;App Store iOS
2. **Scanner un poster** : dirigez votre appareil photo vers un poster scientifique
3. **Traitement OCR** : Apple Vision extrait automatiquement le contenu textuel
4. **Poser des questions** : interrogez le contenu du poster en langage naturel
5. **Explorer les travaux connexes** : découvrez des études sémantiquement proches grâce à Sonar Pro
6. **Valider les citations** : vérifiez les références académiques grâce à l&#39;intégration PubMed

<div id="code-explanation">
  ## Explication du code
</div>

* **Frontend** : application iOS native conçue avec SwiftUI pour une UI/UX moderne
* **Traitement OCR** : framework Apple Vision pour l&#39;extraction de texte à partir d&#39;images
* **Intégration IA** : API Perplexity Sonar Pro pour la recherche sémantique et la compréhension du contexte
* **Langage naturel** : GPT-3.5 pour les questions-réponses et l&#39;interprétation du contenu
* **Validation académique** : E-utilities de PubMed pour la vérification des citations
* **Traitement sur l&#39;appareil** : OCR et traitement en local pour la confidentialité et les performances
* **Enrichissement de la recherche** : génération automatique de questions de recherche et de pistes futures
