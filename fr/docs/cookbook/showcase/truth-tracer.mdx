**TruthTracer** est une plateforme complète de détection de la désinformation qui s&#39;appuie sur la Sonar API de Perplexity pour offrir une analyse des affirmations à plusieurs niveaux. La plateforme combine vérification des faits, traçage des chaînes de confiance et raisonnement socratique afin de produire des résultats de vérification précis et étayés par des preuves, assortis de scores de confiance et de sources détaillées.

<div id="features">
  ## Fonctionnalités
</div>

* **Analyse multi-méthodes** combinant vérification des faits, analyse de la chaîne de confiance et raisonnement socratique
* **Vérification assistée par IA** reposant sur les modèles Sonar, Sonar Deep Research et Sonar Reasoning Pro de Perplexity
* **Traitement en temps réel** avec exécution parallèle de plusieurs méthodes d&#39;analyse
* **Résultats fondés sur des preuves** fournissant sources, scores de confiance et raisonnement détaillé
* **Architecture propre** avec un backend NestJS et un frontend React
* **Prêt pour la production** avec déploiement Docker, tests complets et documentation d&#39;API
* **Score de confiance configurable** avec des pondérations et des seuils personnalisables

<div id="prerequisites">
  ## Prérequis
</div>

* Node.js 18+ et npm
* Clé API Perplexity (accès aux modèles Sonar)
* Docker (facultatif, pour le déploiement)
* Git pour cloner le dépôt

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt backend
git clone https://github.com/anthony-okoye/truth-tracer-backend.git
cd truth-tracer-backend

# Installer les dépendances
npm install

# Cloner le dépôt frontend
git clone https://github.com/anthony-okoye/truth-tracer-front.git
cd truth-tracer-front

# Installer les dépendances du frontend
npm install
```

<div id="configuration">
  ## Configuration
</div>

Créez un fichier `.env` dans le répertoire backend :

```ini theme={null}
# Obligatoire
SONAR_API_KEY=your_perplexity_api_key
SONAR_API_URL=https://api.perplexity.ai

# Configuration facultative
SONAR_TIMEOUT=30000
SONAR_MAX_RETRIES=3
CONFIDENCE_WEIGHT_FACT_CHECK=0.35
CONFIDENCE_WEIGHT_TRUST_CHAIN=0.25
CONFIDENCE_WEIGHT_SOCRATIC=0.20
```

<div id="usage">
  ## Utilisation
</div>

1. **Démarrer le backend** :

```bash theme={null}
   cd truth-tracer-backend
   npm run start:dev
```

2. **Démarrer le frontend** :

```bash theme={null}
   cd truth-tracer-front
   npm start
```

3. **Accéder à l&#39;application** : ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur

4. **Analyser des affirmations** :
   * Saisissez une affirmation dans la zone de texte
   * Cliquez sur &quot;Analyze Claim&quot; pour lancer la vérification des faits, l&#39;analyse de la chaîne de confiance et le raisonnement socratique
   * Consultez les résultats, accompagnés des scores de confiance, des sources et d&#39;explications détaillées

<div id="code-explanation">
  ## Explication du code
</div>

* **Backend** : application NestJS dotée d&#39;une architecture propre, conforme aux bonnes pratiques TypeScript
* **Intégration de l&#39;IA** : Sonar API de Perplexity avec trois modèles spécialisés — Sonar pour la vérification des faits, Sonar Deep Research pour l&#39;analyse de la chaîne de confiance et Sonar Reasoning Pro pour l&#39;évaluation logique
* **Traitement parallèle** : exécution simultanée des trois méthodes d&#39;analyse pour une vérification efficace des affirmations
* **Nettoyage des réponses** : analyse et validation JSON personnalisées pour prendre en charge les différents formats de réponse de l&#39;API
* **Score de confiance** : système de notation pondérée combinant les résultats des trois méthodes d&#39;analyse
* **Frontend** : application React offrant une interface intuitive de soumission des affirmations et une visualisation détaillée des résultats
* **Tests** : suite de tests complète comprenant des tests unitaires, des tests de bout en bout et des tests d&#39;analyse des affirmations

<div id="how-the-sonar-api-is-used">
  ## Comment l&#39;API Sonar est utilisée
</div>

TruthTracer exploite l&#39;API Sonar de Perplexity selon trois approches d&#39;analyse distinctes :

```typescript theme={null}
// Exécution en parallèle de plusieurs modèles Sonar
const [factCheckResult, trustChainResult, socraticResult] = await Promise.all([
  sonarClient.chat.completions.create({
    model: "sonar",
    messages: [{ role: "user", content: factCheckPrompt }],
    max_tokens: 500
  }),
  sonarClient.chat.completions.create({
    model: "sonar-deep-research", 
    messages: [{ role: "user", content: trustChainPrompt }],
    max_tokens: 2500
  }),
  sonarClient.chat.completions.create({
    model: "sonar-reasoning-pro",
    messages: [{ role: "user", content: socraticPrompt }],
    max_tokens: 4000
  })
]);
```
