**StarPlex** est une plateforme d&#39;intelligence startup propulsée par l&#39;IA, qui aide les entrepreneurs à valider leurs idées d&#39;entreprise et à accéder aux ressources dont ils ont besoin pour réussir. Reposant principalement sur **Perplexity Sonar Pro**, elle s&#39;appuie sur une **interface de globe 3D** interactive comme interface principale. Il vous suffit de saisir votre idée de startup pour voir le moteur d&#39;IA analyser puis visualiser les informations directement sur le globe : concurrents, marchés, données démographiques, sociétés de capital-risque et cofondateurs potentiels sont cartographiés dans le monde entier, en temps réel.

<div id="features">
  ## Fonctionnalités
</div>

* **Analyse de validation de marché** avec score de résistance à l&#39;IA, estimation de la capitalisation boursière et analyse des tendances de croissance
* **Interface interactive de globe 3D** pour visualiser les données de veille mondiale sur les startups
* **Recherche concurrentielle** avec score de menace et cartographie du paysage concurrentiel
* **Mise en relation avec les VC et les investisseurs** selon la thèse d&#39;investissement et l&#39;adéquation avec le portefeuille
* **Recherche de cofondateurs** avec score de compatibilité et correspondance des expertises
* **Recherche démographique** avec visualisation par carte de chaleur des localisations de l&#39;audience cible
* **Génération de pitch decks par IA** produisant des présentations prêtes à présenter aux investisseurs
* **Chatbot contextuel** avec intégration RAG sur l&#39;ensemble des données de recherche

<div id="prerequisites">
  ## Prérequis
</div>

* Node.js 18+ et npm
* Python 3.8+ et pip
* Clé API Perplexity (Sonar Pro)
* Token Mapbox et clé API SERP

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/JerryWu0430/StarPlex.git
cd StarPlex

# Configuration du backend
cd backend
pip install -r requirements.txt

# Configuration du frontend
cd ../frontend
npm install
```

</div>

Créez un fichier `.env` dans le répertoire backend :


<div id="usage">
  ## Utilisation
</div>

1. **Démarrer le backend** :
   ```bash theme={null}
   cd backend
   python main.py
   ```

2. **Démarrer le frontend** :
   ```bash theme={null}
   cd frontend
   npm run dev
   ```

3. **Accéder à l&#39;application** : ouvrez [http://localhost:3000](http://localhost:3000) et saisissez votre idée de startup

4. **Explorer les données** : utilisez le globe 3D pour visualiser les concurrents, les VC, les données démographiques et les cofondateurs potentiels

5. **Générer des ressources** : créez des pitch decks et échangez avec l&#39;assistant IA à propos de votre analyse

<div id="how-starplex-uses-perplexity-sonar-api">
  ## Comment StarPlex utilise la Sonar API de Perplexity
</div>

StarPlex exploite la Sonar API de Perplexity via une **architecture d&#39;intelligence multimodule** :

**Moteur d&#39;analyse de marché**
Utilise Sonar Pro pour une validation de marché complète, en combinant les données Google Trends et l&#39;analyse par IA afin de générer des estimations de capitalisation boursière, des scores de disruption par l&#39;IA et des projections de croissance, avec des sorties JSON structurées.

**Veille concurrentielle**
Exécute plusieurs requêtes Sonar en parallèle pour identifier les entreprises concurrentes, leur situation de financement et leur niveau de menace. Chaque concurrent se voit attribuer un score de menace de 1 à 10, accompagné d&#39;une analyse détaillée de son positionnement concurrentiel.

**Mise en relation avec des VC et des cofondateurs**
S&#39;appuie sur la connaissance du web en temps réel de Sonar pour trouver des investisseurs pertinents et des cofondateurs potentiels, en notant les correspondances selon l&#39;alignement avec la thèse d&#39;investissement, l&#39;adéquation des expertises et la proximité géographique.

**Assistant métier sensible au contexte**
Met en œuvre le RAG (retrieval-augmented generation) en injectant l&#39;ensemble des données de recherche dans les conversations Sonar, créant ainsi un conseiller en création d&#39;entreprise capable de répondre aux questions portant sur le positionnement sur le marché, les menaces concurrentielles et les décisions stratégiques.

**Intelligence géographique**
Associe les analyses démographiques de Sonar au géocodage Mapbox pour créer des cartes de chaleur interactives montrant où se concentrent les audiences cibles à l&#39;échelle mondiale.

<div id="code-explanation">
  ## Explication du code
</div>

* **Backend** : Python FastAPI avec AsyncIO pour des appels concurrents à l&#39;API Perplexity répartis sur plusieurs modules d&#39;analyse
* **Frontend** : Next.js avec React 19, s&#39;appuyant sur Cobe pour la visualisation du globe 3D et sur Mapbox GL pour la cartographie interactive
* **Intégration de l&#39;IA** : stratégie Perplexity multi-modèles utilisant Sonar Pro pour les analyses complexes et Sonar pour les requêtes plus rapides
* **Pipeline de données** : mise en cache intelligente, réponses JSON structurées et streaming en temps réel pour un retour utilisateur immédiat
* **Visualisation** : liaison dynamique des données entre les analyses de Perplexity et les interfaces interactives de globe et de carte
