**Flow &amp; Focus** est une application d&#39;actualités personnalisée qui transforme la consommation d&#39;informations en expérience d&#39;apprentissage. Elle associe de façon inédite la découverte rapide via un fil d&#39;actualité vertical (Flow) et des dialogues d&#39;apprentissage interactifs et approfondis (Focus), le tout propulsé par les modèles Sonar Pro et Sonar Deep Research de Perplexity.

<div id="features">
  ## Fonctionnalités
</div>

* **Interface à deux modes** : Flow Feed pour découvrir rapidement l&#39;actualité et Focus pour des approfondissements personnalisés
* **Fil d&#39;actualité vertical** : extraits d&#39;actualité à faire défiler, avec résumés générés par IA, tags et images d&#39;arrière-plan
* **Approfondissements interactifs** : appuyez sur les expressions clés pour afficher un contenu ciblé, dans des volets de détail à défilement horizontal
* **Apprentissage personnalisé** : segments de conversation propulsés par l&#39;IA avec des personas comme « Oracle » et « Explorer »
* **Personnalisation intelligente** : analyse les habitudes de lecture pour adapter automatiquement la sélection de contenu
* **Contenu en temps réel** : s&#39;appuie sur Sonar Pro pour une actualité à jour et sur Sonar Deep Research pour des analyses détaillées
* **Enrichissement visuel** : images de fond dynamiques générées via Runware.ai à partir des mots-clés du contenu

<div id="prerequisites">
  ## Prérequis
</div>

* Node.js 18+ et npm
* Clé API Perplexity
* Clé API Runware pour la génération d&#39;images
* Environnement Next.js 15 et React 19

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/michitomo/NewsReel.git
cd NewsReel

# Installer les dépendances
npm install

# Configurer les variables d'environnement
cp .env.example .env.local
```

<div id="configuration">
  ## Configuration
</div>

Créez le fichier `.env.local` :

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key_here
RUNWARE_API_KEY=your_runware_api_key_here
PERPLEXITY_FOCUS_MODEL=sonar-deep-research
```

<div id="usage">
  ## Utilisation
</div>

1. **Démarrer le serveur de développement** :
   ```bash theme={null}
   npm run dev
   ```

2. **Accéder à l&#39;application** : ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur

3. **Flow Feed** : faites défiler verticalement les extraits d&#39;actualité et appuyez sur les expressions clés pour un approfondissement

4. **Mode Focus** : générez des synthèses personnalisées comportant des segments de conversation interactifs

5. **Personnalisation** : vos habitudes de consultation influencent automatiquement la sélection des contenus

<div id="code-explanation">
  ## Explication du code
</div>

* **Frontend** : Next.js 15 avec React 19, TypeScript, Tailwind CSS et Framer Motion pour les animations
* **Gestion de l&#39;état** : Zustand avec persistance dans le localStorage pour les préférences utilisateur
* **Intégration IA** : Perplexity Sonar Pro pour l&#39;actualité en temps réel et Sonar Deep Research pour les analyses approfondies
* **Génération d&#39;images** : intégration du SDK Runware pour générer des images d&#39;arrière-plan dynamiques à partir des mots-clés du contenu
* **Routes d&#39;API** : intégration côté serveur gérant les appels aux API Perplexity et Runware
* **Conception mobile-first** : gestes de balayage et mise en page responsive pour une expérience mobile intuitive
