**PerplexiGrid** transforme le langage naturel en tableaux de bord riches et interactifs. Connectez vos données, croisez-les avec des données web en temps réel, posez une question et laissez la Sonar API faire le reste ! Le tout avec une mise en page par glisser-déposer, la génération de widgets par IA et des visualisations propulsées par ECharts.

<div id="features">
  ## Fonctionnalités
</div>

* **Du langage naturel aux tableaux de bord** : transformez de simples prompts en anglais courant en tableaux de bord analytiques pleinement fonctionnels, avec plus de 25 types de widgets
* **Intégration de données en direct** : combinez vos propres sources de données avec des données web en temps réel pour obtenir une vision complète
* **Disposition en grille interactive** : interface glisser-déposer pour personnaliser la mise en page et le style de vos tableaux de bord
* **Affinage assisté par l&#39;IA** : affinez vos widgets ou ajoutez-en de nouveaux par simple conversation
* **Export et partage** : générez des exports PDF, des images haute résolution et des liens de tableau de bord partageables

<div id="how-it-uses-sonar">
  ## Comment PerplexiGrid utilise Sonar
</div>

PerplexiGrid exploite la Sonar API via quatre modes spécialisés :

* **Génération complète de tableau de bord (f1)** : crée des tableaux de bord complets comportant plusieurs widgets, en s&#39;appuyant sur les capacités avancées de Sonar Pro
* **Mode léger (l1)** : génère des visualisations rapides pour les systèmes embarqués et les applications temps réel
* **Mises à jour de tableau de bord (r1)** : permet des modifications dynamiques en langage naturel, tout en conservant le contexte
* **Affinage de widget (r2)** : offre un contrôle précis sur la mise à jour de chaque widget

Le système s&#39;appuie sur des réponses structurées selon un schéma JSON afin de garantir une sortie cohérente et compatible avec ECharts, directement affichable sous forme de visualisations interactives.

<div id="code-explanation">
  ## Explication du code
</div>

L&#39;utilisateur envoie des messages qui sont transformés en prompts à destination d&#39;une Supabase Edge Function encapsulant la Sonar API de Perplexity.
Selon le mode (`f1`, `l1`, `r1` ou `r2`), la fonction génère des sorties structurées complètes pour les tableaux de bord, des visualisations légères ou des mises à jour ciblées.
La mise en page générée est convertie en définitions de widgets structurées, puis transmise à notre moteur de création de widgets.

Découvrez notre [service sonar-api principal ici.](https://github.com/PetarRan/perplexigrid/blob/main/server/supabase/functions/_shared/perplexityService.ts)

<div id="prompt-modes">
  ## Modes de prompt
</div>

| Mode | Description                                     | Cas d&#39;usage                                                                                     | Remarques                                                                                         |
| ---- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `f1` | Première génération complète du tableau de bord | L&#39;utilisateur part d&#39;un canevas vide et saisit un prompt initial                            | Produit une mise en page complète du tableau de bord avec plusieurs widgets                       |
| `l1` | Génération allégée du tableau de bord           | Pour obtenir rapidement des aperçus ou des informations avec un minimum de tokens                   | Plus rapide et moins coûteuse, mais renvoie moins de widgets et des instructions moins détaillées |
| `r1` | Régénération complète du tableau de bord        | L&#39;utilisateur souhaite remplacer tous les widgets existants par un nouveau prompt               | Reconstruit l&#39;intégralité du tableau de bord tout en conservant la mise en page               |
| `r2` | Mise à jour ciblée d&#39;un widget              | L&#39;utilisateur souhaite modifier un widget précis (par exemple « transforme ceci en camembert ») | Seul le widget sélectionné est modifié selon la nouvelle instruction                              |

<div id="tech-stack">
  ## Stack technique
</div>

* **Frontend** : React + Vite (Typescript), ECharts, react-grid-layout
* **Backend** : Supabase Edge Functions (Typescript sur Deno)
* **Moteur d&#39;IA** : Perplexity Sonar Pro
* **Infrastructure** : Supabase (PostgreSQL, RLS, Auth), déploiement sur Vercel
