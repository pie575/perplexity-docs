**FirstPrinciples App** est un outil propulsé par l&#39;IA qui transforme vos objectifs d&#39;apprentissage généraux en feuilles de route structurées et personnalisées. Au fil d&#39;un échange interactif, l&#39;IA dialogue avec vous et pose des questions ciblées afin de préciser vos besoins d&#39;apprentissage avant de générer un plan détaillé. L&#39;application est conçue pour vous aider à apprendre plus efficacement en traçant une voie claire à suivre.

<video controls className="w-full aspect-video rounded-xl" src="https://github.com/user-attachments/assets/6016c5dd-6c18-415e-b982-fafb56170b87" />

<div id="features">
  ## Fonctionnalités
</div>

* **Interface de chat interactive** pour définir et affiner les objectifs d&#39;apprentissage au fil de la conversation
* **Ciblage du sujet assisté par IA** grâce à des questions pertinentes et ciblées permettant de préciser les objectifs d&#39;apprentissage
* **Gestion des sessions** permettant de mener plusieurs discussions autour des feuilles de route et de suivre la progression
* **Indicateurs de progression visuels** signalant que suffisamment d&#39;informations ont été recueillies
* **Plans d&#39;apprentissage personnalisés** avec des feuilles de route structurées, étape par étape
* **Flux conversationnel piloté par IA** combinant les API OpenAI et Perplexity pour des interactions intelligentes

<div id="prerequisites">
  ## Prérequis
</div>

* Python 3.8+ et pip
* Node.js 16+ et npm
* Clé API OpenAI
* Clé API Perplexity

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/william-Dic/First-Principle.git
cd First-Principle

# Configuration du backend
cd flask-server
pip install -r requirements.txt

# Configuration du frontend
cd ../client
npm install
```

<div id="configuration">
  ## Configuration
</div>

Créez un fichier `.env` dans le répertoire `flask-server` :

```ini theme={null}
OPENAI_API_KEY=your_openai_api_key
PERPLEXITY_API_KEY=your_perplexity_api_key
PERPLEXITY_API_KEY=your_perplexity_api_key
```

<div id="usage">
  ## Utilisation
</div>

1. **Démarrer le backend** :
   ```bash theme={null}
   cd flask-server
   python server.py
   ```
   Le serveur s&#39;exécute sur [http://localhost:5000](http://localhost:5000)

2. **Démarrer le frontend** :
   ```bash theme={null}
   cd client
   npm start
   ```
   Le client s&#39;exécute sur [http://localhost:3000](http://localhost:3000)

3. **Générer une feuille de route** :
   * Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur
   * Décrivez ce que vous souhaitez apprendre dans l&#39;interface de chat
   * Répondez aux questions complémentaires de l&#39;IA pour affiner vos objectifs d&#39;apprentissage
   * Recevez une feuille de route d&#39;apprentissage personnalisée et structurée

<div id="code-explanation">
  ## Explication du code
</div>

* **Frontend** : application React avec interface de chat conversationnelle et indicateurs de progression
* **Backend** : serveur Flask gérant les appels d&#39;API, l&#39;état de la session et le déroulement de la conversation
* **Intégration de l&#39;IA** : combine l&#39;API OpenAI pour le fil conversationnel et l&#39;API Perplexity pour l&#39;analyse intelligente des sujets
* **Gestion des sessions** : suit l&#39;état de la conversation et l&#39;affinage de l&#39;objectif d&#39;apprentissage
* **Génération de feuille de route** : crée des plans d&#39;apprentissage structurés et concrets à partir des données saisies par l&#39;utilisateur
* **Déroulement conversationnel** : met en œuvre un dialogue orienté objectif afin de préciser les objectifs d&#39;apprentissage
