**BazaarAISaathi** est une plateforme d&#39;IA conçue pour fournir aux investisseurs des analyses exploitables du marché boursier indien. En s&#39;appuyant sur le traitement avancé du langage naturel, l&#39;analyse de données en temps réel et la modélisation financière élaborée par des experts, l&#39;application propose des stratégies d&#39;investissement personnalisées, des analyses du sentiment de marché et des recommandations d&#39;optimisation de portefeuille.

<div id="features">
  ## Fonctionnalités
</div>

* **Planificateur d&#39;indépendance financière (FIRE)** avec des plans personnalisés selon l&#39;âge, le salaire et les objectifs
* **Testeur de conseils en investissement** s&#39;appuyant sur EasyOCR pour l&#39;extraction de texte et la validation par IA
* **Analyse fondamentale et technique** avec des rapports d&#39;entreprise complets et des stratégies de trading
* **Analyse de portefeuille** multidimensionnelle, avec des recommandations action par action
* **Étude de marché et analyse comparative de la concurrence** grâce à l&#39;analyse des tendances sectorielles pilotée par l&#39;IA
* **Données boursières en temps réel** avec suivi des cours en direct et analyse des tendances
* **Test d&#39;hypothèses** à partir de données de marché historiques et en temps réel
* **Synthèses de livres sur l&#39;investissement** avec des résumés concis des 50 meilleurs ouvrages du domaine

<div id="prerequisites">
  ## Prérequis
</div>

* Python 3.8+ et pip
* Streamlit comme framework d&#39;application web
* Une clé API Perplexity (modèles Sonar)
* Facultatif : EasyOCR pour l&#39;extraction de texte depuis des images

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/mahanteshimath/BazaarAISaathi.git
cd BazaarAISaathi

# Installer les dépendances
pip install -r requirements.txt
```

<div id="configuration">
  ## Configuration
</div>

Créez un fichier `secrets.toml` pour les secrets Streamlit :

```ini theme={null}
PERPLEXITY_API_KEY = "your_perplexity_api_key"
# Ajoutez d'autres clés API selon vos besoins
```

<div id="usage">
  ## Utilisation
</div>

1. **Démarrer l&#39;application** :
   ```bash theme={null}
   streamlit run Home.py
   ```

2. **Accéder aux fonctionnalités** :
   * Parcourez les différentes pages pour accéder à des fonctionnalités précises
   * Utilisez le tableau de bord principal pour la vue d&#39;ensemble et la navigation
   * Accédez à des outils spécialisés tels que l&#39;analyse de portefeuille, la planification FIRE et le test de conseils

3. **Exécuter des modules spécifiques** :
   ```bash theme={null}
   streamlit run pages/Financial_Independence.py
   streamlit run pages/Portfolio_Analysis.py
   streamlit run pages/Tip_Tester.py
   ```

<div id="code-explanation">
  ## Explication du code
</div>

* **Frontend** : application web Streamlit avec pages interactives et visualisation des données en temps réel
* **Backend** : logique métier en Python, avec Pandas pour la manipulation et l&#39;analyse des données
* **Intégration de l&#39;IA** : modèles de la Sonar API de Perplexity (sonar-deep-research, sonar-reasoning-pro, sonar-pro) pour l&#39;analyse financière
* **Traitement des données** : récupération de données boursières en temps réel, gestion des données CSV et génération d&#39;analyses de marché
* **Extraction de texte** : intégration d&#39;EasyOCR pour extraire les conseils d&#39;investissement à partir d&#39;images
* **Gestion de portefeuille** : analyse complète du portefeuille assortie de recommandations d&#39;optimisation
* **Analyse de marché** : analyse technique et fondamentale avec notation du sentiment
