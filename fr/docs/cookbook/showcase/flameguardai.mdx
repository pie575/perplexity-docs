<div id="the-flameguard-ai-process">
  ### Le processus FlameGuard AI™
</div>

1. **📸 Envoi** : l&#39;utilisateur envoie une photo de sa propriété
2. **👁️ Analyse visuelle par IA** : l&#39;OpenAI Vision API identifie les vulnérabilités précises (par exemple, toiture inflammable, broussailles sèches à proximité)
3. **🔍 Recherche approfondie** : pour chaque risque, nous générons un **plan de recherche sur mesure** et exécutons des **appels itératifs de type agentique** vers Perplexity Sonar
4. **📄 Génération du rapport** : les résultats de recherche sont **agrégés, structurés et mis en forme** dans un rapport HTML exploitable — avec citations, liens et repères visuels
5. **📧 Livraison** : rapport détaillé envoyé par e-mail, avec des solutions à réaliser soi-même et des recommandations de professionnels

<div id="deep-research-with-perplexity-sonar-api">
  ### 🔍 Recherche approfondie avec la Sonar API de Perplexity
</div>

La véritable innovation réside dans la façon dont nous exploitons la **Sonar API de Perplexity** :

* Nous la traitons comme un assistant de recherche chargé de réunir les meilleures informations disponibles
* Chaque vulnérabilité déclenche plusieurs requêtes portant sur la gravité, les stratégies d&#39;atténuation et les spécificités locales
* Les résultats incluent les codes de sécurité incendie régionaux, les tendances météorologiques et la disponibilité des entrepreneurs locaux

Ce type de **recherche structurée, fiable et assistée par l&#39;IA ne serait pas possible sans Perplexity**.

<div id="technical-stack">
  ### Stack technique
</div>

FlameGuard AI™ s&#39;appuie sur une stack GenAI moderne, conçue pour passer à l&#39;échelle :

* **Frontend** : tableau de bord HTML léger avec gestion des comptes utilisateurs, téléversement de photos et accès aux rapports
* **Backend** : Python (Flask) avec des API RESTful
* **Base de données** : PostgreSQL (local) avec un schéma **compatible Azure SQL**
* **Intégration IA** : OpenAI Vision API + Sonar API de Perplexity
* **Prêt pour le cloud** : conçu pour **Azure App Service**, avec un déploiement dockerisé

<div id="what-we-learned">
  ## 📚 Ce que nous avons appris
</div>

* La **Sonar API de Perplexity** est incroyablement puissante lorsqu&#39;on l&#39;utilise de façon agentique — pas seulement pour obtenir des réponses, mais aussi pour raisonner.
* Combiner **IA multimodale (image + recherche)** ouvre la voie à de puissants outils d&#39;aide à la décision.
* Les utilisateurs attendent des **enseignements exploitables**, pas de simples données : associer la recherche à des recommandations change tout.
* La confiance et la clarté sont essentielles : notre conception devait restituer des informations complexes de façon simple et utile.
