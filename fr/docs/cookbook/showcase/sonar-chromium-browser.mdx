**Sonar Chromium Browser** est un correctif pour le navigateur Chromium qui intègre nativement l&#39;API Sonar de Perplexity afin de proposer des fonctionnalités basées sur l&#39;IA directement dans le navigateur. Les utilisateurs peuvent saisir `sonar <query>` dans l&#39;omnibox pour obtenir des réponses instantanées de l&#39;IA, ou sélectionner du texte et faire un clic droit sur &quot;Summarize with Sonar&quot; pour générer des résumés rapides, ce qui fluidifie les tâches de recherche et de navigation.

<div id="features">
  ## Fonctionnalités
</div>

* **Réponses IA dans l&#39;omnibox** avec la syntaxe `sonar <query>` pour des réponses instantanées
* **Synthèse via le menu contextuel** du texte sélectionné, accessible en un clic
* **Intégration native au navigateur** via les API omnibox et menu contextuel de Chromium
* **Prise en charge de deux modèles** : Sonar Pro pour l&#39;omnibox et Sonar pour les résumés
* **Gestion des saisies avec anti-rebond** pour une utilisation efficace de l&#39;API
* **Build de navigateur personnalisé** illustrant les schémas d&#39;intégration de l&#39;IA

<div id="prerequisites">
  ## Prérequis
</div>

* Ubuntu 22.04 (WSL2 recommandé)
* Copie locale du code source de Chromium
* Clé API Perplexity
* 16 Go de RAM minimum pour la compilation de Chromium
* Git et les outils de compilation standard

  ## Configuration

Mettez à jour les clés API dans les fichiers modifiés :

```cpp theme={null}
// Dans sonar_autocomplete_provider.cc et render_view_context_menu.cc
const std::string API_KEY = "your_perplexity_api_key_here";
```

<div id="usage">
  ## Utilisation
</div>

1. **Compilez Chromium** avec les correctifs appliqués, en suivant les instructions du dépôt
2. **Lancez le navigateur personnalisé** doté de l&#39;intégration IA
3. **Utilisez l&#39;IA de l&#39;Omnibox** : saisissez `sonar what is quantum tunneling?` dans la barre d&#39;adresse
4. **Utilisez la synthèse contextuelle** : sélectionnez du texte, puis faites un clic droit et choisissez « Summarize with Sonar »

<div id="code-explanation">
  ## Explication du code
</div>

* **Intégration à l&#39;omnibox** : fournisseur d&#39;autocomplétion personnalisé qui se greffe sur l&#39;API omnibox de Chromium
* **Menu contextuel** : menu contextuel de la vue de rendu modifié pour la synthèse de texte
* **Intégration de l&#39;API** : appels directs à l&#39;API Sonar de Perplexity avec gestion anti-rebond des saisies
* **Choix du modèle** : Sonar Pro pour les requêtes de l&#39;omnibox, Sonar pour la synthèse de texte
* **Architecture du navigateur** : illustre les points d&#39;extension de Chromium pour les fonctionnalités d&#39;IA
* **Processus de compilation** : compilation personnalisée de Chromium avec les correctifs IA appliqués
