**Greenify** est une application mobile conçue pour encourager les pratiques durables en analysant des images en direct et en fédérant des communautés. Les utilisateurs prennent des photos de leur espace (balcon, bord de route, sous-sol, etc.) et Greenify analyse automatiquement l&#39;image à l&#39;aide de la Sonar API de Perplexity afin de suggérer les plantes adaptées à cet emplacement. L&#39;application met également en relation des personnes partageant les mêmes valeurs à proximité, afin de créer des communautés propices à une croissance durable, économique et sociale.

<div id="features">
  ## Fonctionnalités
</div>

* **Analyse des plantes par IA** à partir de la reconnaissance d&#39;images et des données de localisation pour suggérer des plantes adaptées
* **Recommandations géolocalisées** tenant compte de la météo, de l&#39;ensoleillement et des conditions environnementales
* **Animation de communauté** mettant en relation des utilisateurs partageant les mêmes intérêts botaniques et objectifs de durabilité
* **Application mobile multiplateforme** développée avec Expo pour iOS, Android et le web
* **Intégration météo en temps réel** pour évaluer avec précision l&#39;adéquation des plantes
* **Sortie JSON structurée** grâce aux modèles Pydantic pour un traitement cohérent des données
* **Prise en charge des modèles AR** pour une visualisation enrichie des plantes

<div id="prerequisites">
  ## Prérequis
</div>

* Node.js 20.19.4+ et npm
* Python 3.10.0+ et pip
* Expo CLI et SDK 51+
* Clé API Perplexity (Sonar Pro et Sonar Deep Research)
* Android SDK/Studio ou Xcode (pour les builds locaux)
* Appareil mobile doté d&#39;un appareil photo pour la capture d&#39;images

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/deepjyotipaulhere/greenify.git
cd greenify

# Installer les dépendances du frontend
npm install

# Installer les dépendances du backend
cd service
pip install -r requirements.txt
```

<div id="configuration">
  ## Configuration
</div>

Créez un fichier `.env` dans le répertoire `service` :

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key_here
```

<div id="usage">
  ## Utilisation
</div>

1. **Démarrer le service backend** :
   ```bash theme={null}
   cd service
   python app.py
   ```

2. **Démarrer l&#39;application frontend** :
   ```bash theme={null}
   npx expo start
   ```

3. **Accéder à l&#39;application** :
   * Installez l&#39;application Expo Go et scannez le QR code, ou
   * Ouvrez un navigateur web sur mobile et rendez-vous à l&#39;URL affichée

4. **Utiliser l&#39;application** :
   * Accordez les autorisations d&#39;accès à la caméra et à la localisation
   * Prenez une photo de votre espace (balcon, jardin, etc.)
   * Recevez des recommandations de plantes générées par l&#39;IA
   * Entrez en contact avec les utilisateurs à proximité pour l&#39;animation de communauté

<div id="code-explanation">
  ## Explication du code
</div>

* **Frontend** : React Native avec Expo pour le développement mobile multiplateforme
* **Backend** : API Python Flask gérant le traitement des images et l&#39;intégration de l&#39;API Perplexity
* **Intégration de l&#39;IA** : Perplexity Sonar Pro pour l&#39;analyse d&#39;images et Sonar Deep Research pour les recommandations de plantes
* **Modèles de données** : modèles Pydantic pour une sortie JSON structurée et la validation des données
* **Traitement d&#39;images** : analyse d&#39;images en temps réel avec contexte géolocalisé
* **Fonctionnalités communautaires** : mise en relation des utilisateurs selon les suggestions de plantes et les centres d&#39;intérêt liés à la durabilité
* **Intégration météo** : données météorologiques en temps réel pour évaluer précisément l&#39;adéquation des plantes
