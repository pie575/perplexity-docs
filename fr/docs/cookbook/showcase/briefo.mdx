**Briefo** propose un fil d&#39;actualité personnalisé généré par IA ainsi que des analyses approfondies d&#39;entreprises. Les lecteurs peuvent suivre les dernières actualités, demander des analyses financières à la demande et partager leurs observations avec leurs amis, le tout dans une seule expérience mobile propulsée par la Sonar API de Perplexity.

<div id="features">
  ## Fonctionnalités
</div>

* Fil d&#39;actualité personnalisé couvrant 17 catégories, avec résumés générés par IA et liens vers les sources
* Fils de discussion privés et publics pour commenter et partager des articles
* Liste de suivi avec instantanés des marchés en temps réel et analyses IA optionnelles
* Rapports de recherche approfondie générés selon 12 critères au choix, tels que la direction, les concurrents ou la valorisation
* Assistant conversationnel polyvalent qui mémorise les sujets de prédilection de chaque utilisateur

<div id="prerequisites">
  ## Prérequis
</div>

* Node 18 LTS ou version ultérieure
* npm, Yarn ou pnpm
* Expo CLI (`npm i -g expo-cli`)
* Supabase CLI 1.0 ou version ultérieure pour l&#39;émulation locale et le déploiement des Edge Functions

<div id="installation">
  ## Installation
</div>

```bash theme={null}
git clone https://github.com/adamblackman/briefo-public.git
cd briefo-public
npm install
```

<div id="environment-variables">
  ### Variables d&#39;environnement
</div>

```ini theme={null}
# .env              (racine du projet)
MY_SUPABASE_URL=https://<project>.supabase.co
MY_SUPABASE_SERVICE_ROLE_KEY=...
PERPLEXITY_API_KEY=...
LINKPREVIEW_API_KEY=...
ALPACA_API_KEY=...
ALPACA_SECRET_KEY=...

# .env.local        (dans supabase/)
# dupliquez ou redéfinissez les secrets requis par les Edge Functions
```

<div id="usage">
  ## Utilisation
</div>

Lancez le serveur de développement Expo :

```bash theme={null}
npx expo start
```

Déployez les Edge Functions lorsque vous êtes prêt :

```bash theme={null}
supabase functions deploy perplexity-news perplexity-chat perplexity-research portfolio-tab-data
```

<div id="code-explanation">
  ## Explication du code
</div>

* Frontend : React Native avec Expo Router (Typescript) pour iOS, Android et le Web
* Backend : Supabase (PostgreSQL, Row Level Security, Realtime) pour les données et l&#39;authentification
* Edge Functions : Typescript sur Deno, appelant les API Perplexity, Alpaca, Alpha Vantage et LinkPreview
* Hooks : les hooks de données réutilisables de style React Query se trouvent dans lib/ et hooks/
* Tests et linting : ESLint, Prettier et Expo Lint garantissent la qualité du code
