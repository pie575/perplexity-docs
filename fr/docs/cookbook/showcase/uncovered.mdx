**UnCovered** est une extension Chrome qui vérifie textes, images, sites web et captures d&#39;écran en temps réel, directement dans votre navigateur. Reposant sur la Sonar API de Perplexity, elle donne accès instantanément à des informations vérifiées, avec sources, verdicts et analyse approfondie, d&#39;un simple clic droit et sans interrompre votre navigation.

<div id="features">
  ## Fonctionnalités
</div>

* **Vérification en 3 clics** : sélectionner → clic droit → vérifier (texte, image, lien ou capture d&#39;écran)
* **Modes d&#39;analyse de texte** : Quick Search, vérification des faits et Deep Research
* **Vérification d&#39;images** : recherche d&#39;image inversée et vérification multimodale des affirmations
* **Capture d&#39;écran et d&#39;images vidéo** : analysez des visuels tels qu&#39;infographies, mèmes ou extraits de graphiques
* **Résultats étayés par des sources** : chaque réponse s&#39;accompagne de ses sources et d&#39;un verdict factuel (vrai / faux / non confirmé)
* **Générateur de réfutations instantanées** : rédigez des réponses concises et factuelles face à la désinformation
* **Expérience sans friction** : restez sur la même page — ni copier-coller, ni nouvel onglet

<div id="prerequisites">
  ## Prérequis
</div>

* Navigateur Chrome
* Node.js 16+ et npm
* Base de données MongoDB
* Compte Cloudinary pour le stockage des images
* Clé API Perplexity (accès à Sonar Pro et Deep Research)
* Identifiants Google OAuth

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/aayushsingh7/UnCovered.git
cd UnCovered

# Installer les dépendances
npm install

# Compiler l'extension Chrome
npm run build
```

  ## Configuration
</div>

Définissez vos variables d&#39;environnement :

```ini theme={null}

CLOUDINARY_URL=your_cloudinary_credentials

```

<div id="usage">
  ## Utilisation
</div>

1. **Vérification de texte/lien** :
   * Sélectionnez du texte ou faites un clic droit sur un lien
   * Choisissez Quick Search / Fact-Check / Deep Research
   * Obtenez des résultats fiables assortis de verdicts et de citations

2. **Vérification d&#39;image** :
   * Faites un clic droit sur n&#39;importe quelle image
   * Choisissez Quick Search ou Fact-Check
   * Détectez la désinformation et les manipulations visuelles

3. **Analyse de captures d&#39;écran/infographies** :
   * Cliquez sur l&#39;icône UnCovered dans la barre d&#39;outils
   * Utilisez « Capture Screen » pour analyser le contenu visuel

4. **Obtenir une réfutation instantanée** :
   * Générez automatiquement des réponses factuelles pour corriger la désinformation

<div id="code-explanation">
  ## Explication du code
</div>

* **Frontend** : extension Chrome en JavaScript pur avec intégration au menu contextuel
* **Backend** : serveur Node.js Express gérant les requêtes API et l&#39;authentification des utilisateurs
* **Intégration IA** : API Perplexity Sonar Pro et Deep Research pour une vérification intelligente des faits
* **Traitement d&#39;images** : intégration de Cloudinary pour l&#39;analyse des captures d&#39;écran et des images
* **Base de données** : MongoDB pour les données utilisateur et l&#39;historique des vérifications
* **Authentification** : Google OAuth pour une gestion sécurisée des utilisateurs
* **Analyse multimodale** : prise en charge du texte, des images, des captures d&#39;écran et des images vidéo

<div id="technical-implementation">
  ## Implémentation technique
</div>

UnCovered exploite l&#39;API Perplexity Sonar selon trois modes principaux :

```javascript theme={null}
// Quick Search et vérification des faits avec Sonar Pro
const quickResponse = await perplexityClient.chat.completions.create({
  model: "sonar-pro",
  messages: [{ role: "user", content: factCheckPrompt }]
});

// Deep Research pour une analyse exhaustive
const deepResponse = await perplexityClient.chat.completions.create({
  model: "sonar-deep-research", 
  messages: [{ role: "user", content: deepAnalysisPrompt }]
});
```
