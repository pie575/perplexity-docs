**4Point Hoops** est une plateforme d&#39;analyse NBA avancée qui transforme les statistiques brutes de basket-ball en enseignements exploitables et narratifs. En extrayant les données de Basketball-Reference en temps réel et en acheminant des prompts riches en contexte vers le modèle Sonar Pro de Perplexity, elle aide les fans, les analystes et les joueurs de fantasy à comprendre le « pourquoi » et le « et maintenant ? » – et pas seulement les chiffres.

<div id="features">
  ## Fonctionnalités
</div>

* **Statistiques des joueurs** avec répartition saison régulière/playoffs, ventilation par type de tir et radar de performance pour n&#39;importe quel joueur NBA
* **Comparaisons entre époques** permettant de confronter les statistiques côte à côte (par exemple Michael Jordan &#39;97 face à Stephen Curry &#39;22)
* **Tableaux de bord d&#39;équipe** avec classements, diagrammes de Sankey des probabilités de qualification en playoffs et tuiles d&#39;indicateurs clés actualisées automatiquement
* **Explication par IA et joueurs similaires** offrant des explications Sonar en un clic sur les lignes statistiques et une sélection d&#39;athlètes comparables par IA
* **Chat IA basketball** permettant aux utilisateurs d&#39;interroger un LLM expert sur l&#39;histoire de la NBA, les effectifs ou les projections
* **Système SaaS à crédits** avec Firebase Auth, connexion Google, portefeuilles de crédits et outils d&#39;administration

<div id="prerequisites">
  ## Prérequis
</div>

* Node.js 16+ et npm
* Python 3.8+ et pip
* Un projet Firebase configuré
* Clé API Perplexity (Sonar Pro)
* Accès à Basketball-Reference

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt frontend
git clone https://github.com/rapha18th/hoop-ai-frontend-44.git
cd hoop-ai-frontend-44
npm install

# Cloner le dépôt backend
git clone https://github.com/rapha18th/4Point-Hoops-Server.git
cd 4Point-Hoops-Server
pip install -r requirements.txt
```

<div id="configuration">
  ## Configuration
</div>

Créez un fichier `.env` dans le répertoire backend :

```ini theme={null}
PERPLEXITY_API_KEY=your_sonar_pro_api_key
FIREBASE_PROJECT_ID=your_firebase_project_id
FIREBASE_PRIVATE_KEY=your_firebase_private_key
FIREBASE_CLIENT_EMAIL=your_firebase_client_email
```

<div id="usage">
  ## Utilisation
</div>

1. **Démarrer le backend** :
   ```bash theme={null}
   cd 4Point-Hoops-Server
   python app.py
   ```

2. **Démarrer le frontend** :
   ```bash theme={null}
   cd hoop-ai-frontend-44
   npm run dev
   ```

3. **Accéder à l&#39;application** : ouvrez l&#39;URL du frontend et explorez les analyses NBA enrichies par l&#39;IA

4. **Utiliser les fonctionnalités IA** : cliquez sur « AI Explain » au niveau d&#39;un joueur ou d&#39;une statistique pour obtenir une analyse intelligente propulsée par Perplexity Sonar

<div id="code-explanation">
  ## Explication du code
</div>

* **Frontend** : React avec les composants shadcn/ui et Recharts pour la visualisation des données
* **Backend** : API Python Flask exposant les données Basketball-Reference et gérant les appels à la Perplexity API
* **Pipeline de données** : BRScraper pour la collecte de données en temps réel, avec mise en cache Firebase
* **Intégration IA** : Perplexity Sonar Pro pour des analyses et des explications intelligentes sur le basketball
* **Authentification** : Firebase Auth avec connexion Google et contrôle d&#39;accès basé sur des crédits
* **Déploiement** : frontend sur Netlify, backend sur Hugging Face Spaces avec Docker
