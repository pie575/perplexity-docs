**Executive Intelligence** est une application complète propulsée par Perplexity Sonar qui fournit aux dirigeants et aux membres de conseils d&#39;administration des informations instantanées, fiables et crédibles pour la prise de décision stratégique. Elle produit des analyses prêtes à être présentées en conseil, issues de sources de données en temps réel et propulsées par la Sonar API de Perplexity.

<div id="features">
  ## Fonctionnalités
</div>

* **Notes de veille concurrentielle** offrant une analyse concurrentielle complète, prête à présenter en conseil d&#39;administration, avec des citations vérifiables
* **Planification de scénarios (analyse « et si ? »)** pour générer dynamiquement des scénarios prospectifs à partir de données en temps réel
* **Mémoire du Board Pack** pour enregistrer et organiser les notes de veille, les analyses de scénarios et les rapports de benchmark
* **Benchmarking instantané et comparaison avec les pairs**, avec des comparaisons visuelles sourcées sur les indicateurs clés
* **Intégration de données en temps réel** s&#39;appuyant sur la Sonar API de Perplexity pour une veille de marché toujours à jour
* **Mise en forme professionnelle** avec des rapports structurés, des synthèses pour la direction et des présentations prêtes à présenter en conseil d&#39;administration

<div id="prerequisites">
  ## Prérequis
</div>

* Node.js 18+ et npm/yarn
* Git
* Clé API Perplexity (Sonar Pro)

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/raishs/perplexityhackathon.git
cd perplexityhackathon

# Installer les dépendances
npm install

# Configurer les variables d'environnement
cp .env.example .env.local
```

<div id="configuration">
  ## Configuration
</div>

Créez le fichier `.env.local` :

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key
```

<div id="usage">
  ## Utilisation
</div>

1. **Démarrer le serveur de développement** :
   ```bash theme={null}
   npm run dev
   ```

2. **Accéder à l&#39;application** : ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur

3. **Générer des analyses** :
   * Saisissez le nom d&#39;une entreprise dans le champ prévu à cet effet
   * Cliquez sur « analyse concurrentielle » pour obtenir des synthèses complètes
   * Utilisez « planification de scénarios » pour les analyses de scénarios hypothétiques
   * Ouvrez « Benchmarking » pour comparer l&#39;entreprise à ses pairs
   * Enregistrez les rapports dans « Board Pack » pour y accéder ultérieurement

4. **Gestion du Board Pack** : utilisez le bouton « 📁 Board Pack » pour consulter et gérer les rapports d&#39;analyse enregistrés

<div id="code-explanation">
  ## Explication du code
</div>

* **Frontend** : Next.js avec TypeScript et React pour une interface moderne et responsive
* **Backend** : routes API Next.js assurant l&#39;intégration de la Sonar API de Perplexity
* **Intégration IA** : Sonar Pro de Perplexity pour la veille concurrentielle en temps réel et l&#39;analyse de scénarios
* **Gestion de l&#39;état** : React Context pour la mémoire du conseil et le stockage persistant des données
* **Traitement Markdown** : utilitaires personnalisés pour analyser les réponses de l&#39;IA et gérer les citations
* **Gestion des erreurs** : gestion complète des délais d&#39;expiration et des erreurs lors des appels API
* **Rendu professionnel** : mise en forme structurée pour des présentations prêtes à présenter au conseil d&#39;administration, avec citation des sources
