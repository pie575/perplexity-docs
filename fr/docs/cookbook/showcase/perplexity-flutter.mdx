<div id="perplexity-dart-flutter-sdks">
  # SDK Dart et Flutter de Perplexity
</div>

Les **SDK Dart et Flutter de Perplexity** offrent une boîte à outils complète pour intégrer les capacités d&#39;IA de Perplexity dans vos applications Dart et Flutter. Conçus spécifiquement pour la communauté Flutter, ces packages comprennent un client d&#39;API léger ainsi que des widgets Flutter prêts à l&#39;emploi avec gestion d&#39;état BLoC.

<div id="features">
  ## Fonctionnalités
</div>

* Client d&#39;API typé, avec des modèles entièrement typés et une sécurité à la compilation
* Complétions de chat en streaming ou non, avec gestion des réponses en temps réel
* Prise en charge de tous les modèles Perplexity (Sonar, Sonar Pro, Deep Research, variantes Reasoning)
* Traitement multi-images prenant en charge le base64, les data URI et les URL HTTPS
* Widgets Flutter prêts à l&#39;emploi, intégrés à la gestion d&#39;état BLoC
* Options de configuration avancées (filtres de recherche, restrictions de domaines)
* Prise en charge multiplateforme : iOS, Android, Web et desktop
* Conception pérenne acceptant des chaînes de modèle personnalisées pour les nouveautés Perplexity

<div id="prerequisites">
  ## Prérequis
</div>

* Dart SDK 2.17.0 ou version ultérieure
* Flutter SDK 3.0.0 ou version ultérieure (pour les fonctionnalités propres à Flutter)
* Une API key Perplexity obtenue depuis la console Perplexity API
* Des connaissances de base du pattern BLoC de Flutter pour l&#39;intégration des widgets

<div id="installation">
  ## Installation
</div>

<div id="for-dart-projects-core-api-only">
  ### Pour les projets Dart (API principale uniquement)
</div>

```bash theme={null}
dart pub add perplexity_dart
```

<div id="for-flutter-projects-full-widget-support">
  ### Pour les projets Flutter (prise en charge complète des widgets)
</div>

```bash theme={null}
flutter pub add perplexity_flutter
```

<div id="usage">
  ## Utilisation
</div>

<div id="core-api-integration">
  ### Intégration de l&#39;API principale
</div>

* Client typé prenant en charge tous les modèles Perplexity (Sonar, Sonar Pro, Deep Research, Reasoning)
* Complétions de chat avec ou sans streaming
* Traitement multimodal avec un système MessagePart flexible pour le texte et les images

<div id="flutter-widget-layer">
  ### Couche de widgets Flutter
</div>

* `ChatWrapperWidget` pour la gestion d&#39;état BLoC
* `PerplexityChatView` pour l&#39;affichage des messages en temps réel
* `PerplexityChatInput` pour la gestion des interactions utilisateur

<div id="code-explanation">
  ## Explication du code
</div>

* Couche cœur : client d&#39;API en Dart pur (`perplexity_dart`) pour une intégration multiplateforme de la Perplexity API
* Couche interface : widgets Flutter (`perplexity_flutter`) avec gestion d&#39;état BLoC pour un développement rapide
* Sûreté de typage : des modèles et des réponses entièrement typés évitent les erreurs d&#39;exécution et activent l&#39;autocomplétion IntelliSense
* Multimodalité : système MessagePart flexible permettant de combiner texte et images dans une même requête
* Streaming : prise en charge native des complétions de chat en temps réel, avec une gestion adaptée des chunks
* Architecture : une conception en deux couches permet un usage léger de l&#39;API ou une intégration complète des widgets Flutter

<div id="architecture">
  ## Architecture
</div>

<div id="two-layer-design">
  ### Architecture à deux couches
</div>

* **Cœur (`perplexity_dart`)** — Client d'API en Dart pur, compatible avec toutes les plateformes
* **Interface (`perplexity_flutter`)** — Widgets Flutter + gestion d&#39;état BLoC

S&#39;appuie sur le système flexible MessagePart pour gérer des contenus multimodaux combinant texte et images.
