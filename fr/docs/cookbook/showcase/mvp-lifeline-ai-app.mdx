**MVP LifeLine** est une plateforme d&#39;IA multilingue et pensée pour fonctionner avant tout hors ligne, qui accompagne les jeunes sur les plans émotionnel, financier et professionnel — à tout moment et où qu&#39;ils soient. Dans le monde, plus de 1,3 milliard de jeunes se heurtent à des obstacles en matière de perspectives professionnelles et de santé mentale, en particulier dans les régions isolées ou mal desservies. MVP LifeLine fait tomber ces barrières en combinant IA, accès hors ligne, prise en charge multilingue et un écosystème d&#39;outils complet.

<div id="features">
  ## Fonctionnalités
</div>

* **IA à double mode** avec Coach de carrière et Compagnon émotionnel, propulsés par la Sonar API de Perplexity
* **Prise en charge multilingue** dans plus de 10 langues, dont l&#39;anglais, le français, l&#39;arabe, l&#39;espagnol, l&#39;hindi et des langues régionales
* **Conception « offline-first »** avec intégration SMS/USSD pour les régions à faible connectivité
* **Écosystème d&#39;outils complet** couvrant la carrière, le bien-être, les finances et la productivité
* **Accès SmartQ** pour des réponses d&#39;IA contextuelles et émotionnellement intelligentes
* **Digital Hustle Hub** avec découverte de missions par IA et outils pour freelances
* **Espace bien-être** avec méditations guidées et exercices de réinitialisation mentale
* **Espace finances** avec suivi budgétaire et conseils financiers adaptés aux jeunes
* **Espace productivité** avec tableau Kanban piloté par IA et suivi des habitudes

<div id="prerequisites">
  ## Prérequis
</div>

* SDK Flutter et Dart
* Projet Firebase configuré
* Compte Twilio pour l&#39;intégration SMS/USSD
* Clé API Perplexity (Sonar)
* Clé API OpenAI (pour l&#39;enrichissement)

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/JohnUmoh/asgard.git
cd asgard

# Installer les dépendances Flutter
flutter pub get

# Configurer Firebase
flutterfire configure

# Configurer les variables d'environnement
cp .env.example .env
```

<div id="configuration">
  ## Configuration
</div>

Créez le fichier `.env` :

```ini theme={null}
PERPLEXITY_API_KEY=your_sonar_api_key
OPENAI_API_KEY=your_openai_api_key
FIREBASE_PROJECT_ID=your_firebase_project_id
TWILIO_ACCOUNT_SID=your_twilio_sid
TWILIO_AUTH_TOKEN=your_twilio_token
```

<div id="usage">
  ## Utilisation
</div>

1. **Configurer Firebase** :
   ```bash theme={null}
   flutterfire configure
   ```

2. **Lancer l&#39;application** :
   ```bash theme={null}
   flutter run
   ```

3. **Accéder aux fonctionnalités** :
   * Basculer entre les modes coach de carrière et compagnon émotionnel
   * Utiliser SmartQ pour bénéficier d&#39;une assistance par IA en plusieurs langues
   * Accéder aux fonctionnalités hors ligne par SMS/USSD lorsque la connectivité est limitée
   * Explorer les outils de carrière, les fonctionnalités de bien-être et les leviers de productivité

<div id="code-explanation">
  ## Explication du code
</div>

* **Frontend** : application multiplateforme Flutter avec design responsive pour mobile et web
* **Backend** : Firebase pour l&#39;authentification, le stockage des données et la synchronisation en temps réel
* **Intégration de l&#39;IA** : Sonar API de Perplexity pour des interactions IA en double mode (coach de carrière et compagnon émotionnel)
* **Prise en charge hors ligne** : intégration de Twilio pour la communication SMS/USSD dans les zones à faible connectivité
* **Multilingue** : Sonar API prend en charge plus de 10 langues avec des réponses adaptées au contexte
* **Synchronisation des données** : collecte des données hors ligne avec resynchronisation automatique dès le retour de la connectivité
* **Personnalisation** : l&#39;IA s&#39;adapte à la langue, au niveau d&#39;alphabétisation, à l&#39;historique d&#39;humeur et aux préférences de l&#39;utilisateur
