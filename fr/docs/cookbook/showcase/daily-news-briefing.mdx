**Daily News Briefing** est un plugin Obsidian qui livre des résumés d&#39;actualité générés par IA directement dans votre coffre. Restez informé sur les sujets qui vous intéressent grâce à une collecte et une synthèse de l&#39;actualité automatisées et intelligentes, appuyées sur la Sonar API de Perplexity pour une curation de contenu pertinente.

<div id="features">
  ## Fonctionnalités
</div>

* **Collecte d&#39;actualités personnalisée** en fonction de vos centres d&#39;intérêt et de vos préférences
* **Synthèse générée par IA** des articles d&#39;actualité grâce à la Sonar API de Perplexity
* **Briefings quotidiens automatisés** livrés directement dans votre coffre Obsidian
* **Fréquence de diffusion et format personnalisables**
* **Intégration transparente à Obsidian**, au sein de votre flux de gestion des connaissances existant
* **Filtrage par sources fiables** pour garantir la qualité et la fiabilité
* **Mise en forme Markdown** pour faciliter les liens et l&#39;organisation au sein de votre coffre

<div id="prerequisites">
  ## Prérequis
</div>

* Application de bureau Obsidian installée
* Clé API Perplexity (accès à Sonar API)
* Connexion Internet pour récupérer les articles d&#39;actualité
* Environnement de développement TypeScript (pour la personnalisation)

<div id="configuration">
  ## Configuration
</div>

1. **Installer le plugin** : copiez le plugin compilé dans votre dossier de plugins Obsidian
2. **Activer le plugin** : activez-le dans les paramètres d&#39;Obsidian
3. **Configuration de l&#39;API** : saisissez votre clé API Perplexity dans les paramètres du plugin
4. **Configurer les sujets** : définissez vos sujets d&#39;actualité et vos préférences de diffusion

<div id="usage">
  ## Utilisation
</div>

1. **Configurer les centres d&#39;intérêt** : définissez les sujets, les sources et la fréquence de diffusion souhaités
2. **Collecte automatisée** : le plugin utilise la Sonar API de Perplexity pour recueillir les dernières actualités
3. **Synthèse par IA** : les articles sont traités et résumés grâce aux capacités de Perplexity
4. **Livraison dans le coffre** : les résumés sont mis en forme en notes Markdown dans votre coffre Obsidian
5. **Intégration aux connaissances** : reliez les briefings d&#39;actualité aux autres notes de votre base de connaissances

<div id="technical-implementation">
  ## Implémentation technique
</div>

Le plugin s&#39;appuie sur la Sonar API de Perplexity pour :

```typescript theme={null}
// Collecte d'actualités avec la Sonar API de Perplexity
const newsQuery = `latest news about ${topic} in the past 24 hours`;
const searchResponse = await perplexityClient.search({
  query: newsQuery,
  max_results: 5,
  include_domains: userPreferences.trustedSources || []
});

// Synthèse générée par IA
const summaryPrompt = `Summarize these news articles about ${topic}`;
const summaryResponse = await perplexityClient.generate({
  prompt: summaryPrompt,
  model: "sonar-medium-online",
  max_tokens: 500
});
```
