**PerplexiCart** aide les utilisateurs à prendre des décisions d&#39;achat éclairées et conformes à leurs valeurs. Propulsé par l'**API Perplexity Sonar**, il analyse les produits sur l&#39;ensemble du web et renvoie des analyses structurées assorties de recommandations hiérarchisées, d&#39;avantages et d&#39;inconvénients, d&#39;une analyse des compromis et du sentiment des utilisateurs — le tout adapté à des préférences telles que le respect de l&#39;environnement, la durabilité, l&#39;éthique et les besoins propres à chaque région.

<div id="features">
  ## Fonctionnalités
</div>

* **Recommandations de produits intelligentes** allant au-delà de la simple comparaison de caractéristiques
* **Alignement sur vos priorités et vos valeurs** (meilleur rapport qualité-prix, écoresponsable, éthique, durabilité, fabriqué en Inde)
* **Personnalisation contextuelle** (type de peau, habitudes d&#39;utilisation, région, etc.)
* **Résultats de recherche structurés** comprenant :
  * Une synthèse de la recherche et les principales recommandations
  * L&#39;alignement sur les valeurs, argumentaire à l&#39;appui
  * Les avantages/inconvénients et les caractéristiques clés
  * Le sentiment des utilisateurs et les retours des communautés (Reddit, Quora)
  * Une analyse des compromis et des conseils d&#39;achat
* **Sources transparentes** avec citations permettant la vérification

<div id="prerequisites">
  ## Prérequis
</div>

* Node.js 18+ et npm/yarn
* Python 3.10+ et pip
* Clé API Perplexity

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/fizakhan90/perplexicart.git
cd perplexicart

# Configuration du backend (FastAPI)
cd backend
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Configuration du frontend (Next.js)
cd ../frontend
npm install
```

<div id="configuration">
  ## Configuration
</div>

Créez un fichier `.env` dans le répertoire backend :

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key
```

(Facultatif) Ajoutez les paramètres propres à votre application selon vos besoins (cache, région par défaut, etc.).

<div id="usage">
  ## Utilisation
</div>

1. **Démarrer le backend (FastAPI)** :
   ```bash theme={null}
   cd backend
   uvicorn main:app --reload  # adaptez module:app si votre point d'entrée diffère
   ```

2. **Démarrer le frontend (Next.js)** :
   ```bash theme={null}
   cd frontend
   npm run dev
   ```

3. **Ouvrir l&#39;application** : rendez-vous sur `http://localhost:3000` et lancez une recherche de produit. Sélectionnez votre priorité (par exemple, Éco‑responsable) et ajoutez un contexte facultatif (type de peau, région).

<div id="code-explanation">
  ## Explication du code
</div>

* **Backend (FastAPI)** : orchestre les appels à Sonar avec un prompt engineering dynamique basé sur la requête, la priorité sélectionnée et le contexte
* **Sorties structurées** : impose un schéma JSON strict via `response_format` afin de garantir un rendu cohérent de l&#39;interface
* **Recherche web en temps réel** : demande à Sonar d&#39;explorer les plateformes d&#39;e-commerce, les forums, les blogs d&#39;avis et les rapports de durabilité
* **Analyse sémantique** : dégage l&#39;alignement avec les valeurs, les avantages et inconvénients, le sentiment, et cite les sources pour plus de transparence
* **Frontend (Next.js/React)** : présente une vue claire et intuitive des recommandations, des compromis et des citations

<div id="how-the-sonar-api-is-used">
  ## Utilisation de l&#39;API Sonar
</div>

PerplexiCart s&#39;appuie sur l&#39;**API Perplexity Sonar** comme moteur d&#39;intelligence : elle génère dynamiquement des prompts personnalisés à partir des saisies de l&#39;utilisateur, comme les requêtes de recherche, les priorités et le contexte. L&#39;API mène des recherches web approfondies sur les sites d&#39;e-commerce, les forums et les plateformes d&#39;avis, et renvoie des réponses structurées dans un format JSON cohérent. Grâce à l&#39;analyse sémantique, elle extrait les informations clés sur les produits : adéquation avec les priorités de l&#39;utilisateur, avantages et inconvénients, sentiment — le tout étayé par des sources citées. Le backend FastAPI traite ces réponses structurées avant de les transmettre au frontend Next.js, pour une expérience utilisateur soignée.
