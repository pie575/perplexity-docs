**Perplexity Lens** est une puissante extension de navigateur qui transforme votre expérience de navigation : elle fournit des éclairages générés par l’IA grâce à Perplexity AI et crée un graphe de connaissances personnalisé reliant visuellement les concepts que vous rencontrez en ligne.

<div id="features">
  ## Fonctionnalités
</div>

* **Sélection de texte intelligente** avec des explications générées par IA pour le texte sélectionné
* **Résumé de pages web** pour obtenir instantanément un aperçu concis de pages entières
* **Analyses contextuelles par RAG** s&#39;appuyant sur la génération augmentée par récupération pour fournir un contexte et des significations détaillés
* **Visualisation de graphe de connaissances** avec des graphes D3.js interactifs illustrant les liens entre les concepts
* **Partage public** avec génération d&#39;URL pour partager les graphes avec d&#39;autres personnes
* **Authentification des utilisateurs** via Firebase pour un accès sécurisé
* **Double stockage** avec IndexedDB en local et Firebase dans le cloud
* **Interface adaptative** pleinement fonctionnelle sur tous les appareils

<div id="prerequisites">
  ## Prérequis
</div>

* Node.js v14+ et npm v6+
* Google Chrome ou un navigateur compatible
* Un compte Firebase pour les fonctionnalités cloud
* Firebase CLI (`npm install -g firebase-tools`)
* Une clé API Perplexity et une clé API OpenAI

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/iamaayushijain/perplexity-lens.git
cd perplexity_lens

# Installer les dépendances
npm install

# Compiler l'extension
npm run build
```

<div id="configuration">
  ## Configuration
</div>

Modifiez `src/config.ts` :

```typescript theme={null}
export const PERPLEXITY_API_KEY = 'your-perplexity-key';
export const EMBEDDING_API_KEY = 'your-openai-key';
export const FIREBASE_HOSTING_URL = 'https://your-project-id.web.app';
```

<div id="usage">
  ## Utilisation
</div>

1. **Charger l&#39;extension** : rendez-vous sur `chrome://extensions/`, activez le mode développeur, cliquez sur « Charger l&#39;extension non empaquetée » et sélectionnez le répertoire `dist/`

2. **Se connecter** : cliquez sur l&#39;icône de l&#39;extension et authentifiez-vous via Firebase

3. **Utiliser les fonctionnalités** :
   * **Surligner du texte** : sélectionnez du texte sur n&#39;importe quelle page web pour obtenir des éclairages générés par l&#39;IA
   * **Résumer la page** : utilisez la fonctionnalité « Résumer » pour obtenir une vue d&#39;ensemble d&#39;une page web
   * **Tout demander** : survolez ou cliquez sur un mot ou une expression pour en obtenir la définition ou l&#39;explication
   * **Afficher le graphe** : accédez à l&#39;onglet Graphe pour consulter votre graphe de connaissances
   * **Explorer** : zoomez, faites glisser et survolez les nœuds du graphe interactif
   * **Partager** : cliquez sur « Partager le graphe » pour générer un lien public

<div id="code-explanation">
  ## Explication du code
</div>

* **Frontend** : React avec Typescript et TailwindCSS pour une interface moderne et responsive
* **Extension de navigateur** : architecture d&#39;extension Chrome avec popup et scripts de contenu
* **Intégration de l&#39;IA** : Perplexity AI pour des explications et des résumés de texte intelligents
* **Graphe de connaissances** : D3.js pour la visualisation interactive du graphe et les liens entre concepts
* **Stockage** : système de stockage double, avec IndexedDB en local et Firebase dans le cloud
* **Authentification** : Firebase Auth pour un accès utilisateur sécurisé et la gestion des données
* **Système RAG** : génération augmentée par récupération (Retrieval-Augmented Generation) pour des éclairages et des définitions contextuels
