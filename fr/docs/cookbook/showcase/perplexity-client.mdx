**Perplexity Client** est une application de bureau basée sur Electron qui offre une interface soignée pour interagir avec la Sonar API de Perplexity. Elle donne accès à des paramètres d&#39;API avancés tels que le nombre maximal de tokens, ce qui en fait l&#39;outil idéal pour les développeurs qui souhaitent un contrôle fin de leurs interactions avec l&#39;IA, tout en profitant d&#39;une superbe interface inspirée de macOS.

<img src="https://mintcdn.com/perplexity/y2ljsQXTUHXyDIEa/docs/cookbook/static/img/perplexity-client-main.png?fit=max&auto=format&n=y2ljsQXTUHXyDIEa&q=85&s=0e79dbca21cdd63a15fbf72e9fc2becc" alt="Interface de Perplexity Client" width="1344" height="750" data-path="docs/cookbook/static/img/perplexity-client-main.png" />

<div id="features">
  ## Fonctionnalités
</div>

* **Plusieurs modèles Sonar** avec prise en charge de Sonar, Sonar Pro et Sonar Reasoning Pro
* **Spaces personnalisés** avec sauvegarde/chargement selon les cas d&#39;usage
* **Contrôle des paramètres de l&#39;API**, dont l&#39;ajustement du nombre maximal de tokens
* **Mode de débogage de l&#39;API** affichant l&#39;intégralité des charges utiles des requêtes et réponses pour faciliter le diagnostic
* **Suivi de la consommation de tokens** pour surveiller l&#39;utilisation de l&#39;API et les coûts associés
* **Modes de focalisation** pour des tâches spécialisées : développement, rédaction ou recherche

<div id="prerequisites">
  ## Prérequis
</div>

* Node.js v16 ou version ultérieure
* npm ou yarn
* Clé API Perplexity

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/straight-heart/Perplexity-client-.git
cd Perplexity-client-

# Installer les dépendances
npm install

npm run dev
```

<div id="build">
  ## Build
</div>

Compilez l&#39;application pour votre plateforme :

```bash theme={null}
npm run build:win    # Windows
npm run build:mac    # macOS
npm run build:linux  # Linux
```

<div id="configuration">
  ## Configuration
</div>

Les clés API se gèrent directement dans l&#39;application :

1. Lancez l&#39;application et ouvrez les Paramètres (icône d&#39;engrenage)
2. Dans la section **API Keys**, cliquez sur **Add Key**
3. Saisissez votre clé API Perplexity
4. La clé est stockée de manière sécurisée et conservée d&#39;une session à l&#39;autre

Pour des prompts système personnalisés, utilisez la fonctionnalité **Spaces** afin d&#39;enregistrer différents jeux d&#39;instructions et de passer de l&#39;un à l&#39;autre.

<div id="usage">
  ## Utilisation
</div>

1. **Lancement** : exécutez `npm run dev` ou utilisez l&#39;application compilée
2. **Ajouter une clé API** : ouvrez les paramètres et ajoutez votre clé API Perplexity
3. **Sélectionner un modèle** : utilisez le menu déroulant pour choisir parmi les variantes Sonar
4. **Créer des Spaces** : définissez des prompt système personnalisés selon les tâches
5. **Discuter** : lancez la conversation avec des réponses diffusées en temps réel
6. **Déboguer** : activez le débogage de l&#39;API pour consulter l&#39;intégralité des détails des requêtes et des réponses
7. **Suivre l&#39;utilisation** : surveillez la consommation de tokens dans le panneau des paramètres
