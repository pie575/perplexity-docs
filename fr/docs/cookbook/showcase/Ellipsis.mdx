**Ellipsis** est un agent de génération de podcasts de nouvelle génération qui donne vie, en un seul clic, à des contenus audio de haute qualité dignes d&#39;une production humaine, sur n&#39;importe quel sujet. Qu&#39;il s&#39;agisse d&#39;actualités de dernière minute, de décryptages techniques approfondis, de critiques de films ou de débriefings sportifs d&#39;après-match, Ellipsis conçoit des épisodes de podcast intelligents que l&#39;on croirait réalisés par des animateurs chevronnés dans un studio professionnel.

<div id="features">
  ## Fonctionnalités
</div>

* **Dialogue intelligent multi-intervenants** avec plusieurs voix et personnalités distinctes
* **Couverture exhaustive des sujets**, des architectures de LLM aux éclipses lunaires
* **Moteur d&#39;évaluation personnalisé** garantissant l&#39;exactitude factuelle, la conformité juridique et la qualité conversationnelle
* **Génération de podcasts entièrement automatisée** avec un rendu audio naturel, prêt à être diffusé
* **Mises à jour en streaming en temps réel** via Server-Sent Events (SSE)
* **Intégration Podbean** pour la publication directe de podcasts
* **Détection des sujets tendance** grâce à l&#39;API Perplexity

<div id="prerequisites">
  ## Prérequis
</div>

* Node.js v16+ et npm/yarn
* Python 3.10+ et pip
* Un serveur Redis en cours d&#39;exécution (port 6380 par défaut)
* Une clé API Perplexity et des identifiants Podbean

<div id="installation">
  ## Installation
</div>

```bash theme={null}
# Cloner le dépôt
git clone https://github.com/dineshkannan010/Ellipsis.git
cd Ellipsis

# Configuration du backend
cd backend
python -m venv venv
source venv/bin/activate    # macOS/Linux
pip install -r requirements.txt

# Installer les paquets natifs
pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
pip install git+https://github.com/freddyaboulton/orpheus-cpp.git
pip install huggingface_hub[hf_xet] hf_xet

# Configuration du frontend
cd ../frontend
npm install
```

<div id="configuration">
  ## Configuration
</div>

Créez `backend/.env` :

```ini theme={null}
REDIS_URL=redis://your-redis-host:6379
PERPLEXITY_API_KEY=your_key_here
PODBEAN_CLIENT_ID=...
PODBEAN_CLIENT_SECRET=...
```

Créez `frontend/.env` :

```ini theme={null}
REACT_APP_API_URL=http://your-backend-host:5000
```

<div id="usage">
  ## Utilisation
</div>

1. **Démarrer le serveur Redis** :
   ```bash theme={null}
   redis-server --port 6380
   ```

2. **Lancer le backend** :
   ```bash theme={null}
   cd backend
   python app.py
   ```

3. **Lancer le frontend** :
   ```bash theme={null}
   cd frontend
   npm run dev
   ```

4. **Facultatif : intégration Podbean** :
   ```bash theme={null}
   cd backend/integrations/podbean_mcp
   pip install -e .
   python server.py
   python client.py server.py
   ```

5. **Générer du contenu** : saisissez un sujet dans le champ de texte de la page d&#39;accueil, puis appuyez sur Entrée. Basculez vers `ContentGenerationView` pour suivre en direct la progression du script et de l&#39;audio.

<div id="code-explanation">
  ## Explication du code
</div>

* **Backend** : Python Flask avec Redis pub/sub, llama.cpp et Orpheus TTS pour la génération audio
* **Frontend** : React avec Vite, Tailwind CSS et Server-Sent Events pour les mises à jour en temps réel
* **Intégration IA** : Perplexity API pour la génération de contenu et la détection des sujets tendance
* **Traitement audio** : TTS multi-locuteurs avec des personnalités vocales distinctes
* **Évaluation du contenu** : pipelines intégrés pour l&#39;exactitude factuelle et la conformité juridique
* **Publication de podcasts** : intégration directe avec Podbean via un serveur MCP
