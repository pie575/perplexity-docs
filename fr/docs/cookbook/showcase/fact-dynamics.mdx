  # Fact Dynamics | Application Flutter de vérification des faits en temps réel
</div>

<p align="center">
  <img src="https://raw.githubusercontent.com/vishnu32510/fact_pulse/main/assets/icon/icon.png" alt="Fact Dynamics logo" width="80" height="80" style={{ borderRadius: '14px' }} />
</p>

**Projet soumis au hackathon** - Développé pour le hackathon Perplexity dans les catégories Information Tools et Deep Research.

Fact Dynamics est une application Flutter multiplateforme qui assure la vérification des faits en temps réel pour les contenus parlés et les images. Idéale pour les débats en direct, les présentations et la vérification d&#39;informations à la volée.

<div id="features">
  ## Fonctionnalités
</div>

* Transcription vocale et vérification des faits en temps réel pendant les conversations en direct

* Extraction du texte des images et vérification des affirmations avec citation des sources

* Système d&#39;évaluation des affirmations (TRUE, FALSE, MISLEADING, UNVERIFIABLE) accompagné d&#39;explications

* Citation des sources : fournit les URL faisant autorité qui étayent chaque verdict

* Mode débat avec reconnaissance vocale continue et retour en streaming

* Authentification des utilisateurs via Firebase (Google, e-mail) avec historique de conversation persistant

* Prise en charge multiplateforme : iOS, Android et Web

<div id="prerequisites">
  ## Prérequis
</div>

* Flutter SDK 3.0.0 ou version ultérieure
* Dart SDK 2.17.0 ou version ultérieure
* Firebase CLI pour la configuration de l&#39;authentification et de la base de données
* Une API key Perplexity pour l&#39;intégration de Sonar
* Un appareil disposant d&#39;un accès au microphone pour la reconnaissance vocale

<div id="usage">
  ## Utilisation
</div>

<div id="real-time-speech-fact-checking">
  ### Vérification des faits vocale en temps réel
</div>

* Diffuse des segments audio de 5 secondes via le `speech_to_text` de Flutter
* Envoie les extraits transcrits à la Sonar API avec des prompts structurés
* Renvoie un JSON contenant les affirmations, les évaluations (TRUE/FALSE/MISLEADING/UNVERIFIABLE), les explications et les sources

<div id="image-analysis">
  ### Analyse d&#39;images
</div>

* Envoie des images ou des URL à la Sonar API pour en extraire le texte
* Vérifie les affirmations extraites en les confrontant à des sources faisant autorité
* Fournit une analyse complète avec attribution des sources

<div id="code-explanation">
  ## Explication du code
</div>

* Frontend : Flutter avec le pattern BLoC pour la gestion d&#39;état, ciblant iOS, Android et le Web
* Backend : Firebase (Firestore, Authentication) pour la persistance des données utilisateur et de l&#39;historique des conversations
* Traitement vocal : package speech&#95;to&#95;text pour la transcription audio en temps réel
* Intégration d&#39;API : client Dart personnalisé appelant la Sonar API de Perplexity avec des prompts structurés
* Traitement d&#39;images : sélecteur d&#39;images intégré avec encodage base64 pour l&#39;analyse multimodale
* Architecture des données : collections Firestore par utilisateur, avec des sous-collections pour les débats, les discours et les images
