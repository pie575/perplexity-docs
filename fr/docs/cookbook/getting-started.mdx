<div id="quick-start">
  ## Démarrage rapide
</div>

<Steps>
  <Step title="Obtenir un accès à l'API">
    Pour utiliser la plateforme d&#39;API de Perplexity, il vous faut une API key. Si vous n&#39;en avez pas encore :

    <Card title="Obtenez votre Perplexity API Key" icon="key" arrow="True" horizontal="True" iconType="solid" cta="Cliquez ici" href="https://perplexity.ai/account/api">
      Rendez-vous dans l&#39;onglet **API Keys** du portail API et générez une nouvelle clé.
    </Card>
  </Step>

  <Step title="Installer le SDK">
    Le SDK Perplexity API est disponible en Python et en TypeScript. Installez le paquet correspondant au langage de votre choix :

    <CodeGroup>
      ```bash Python theme={null}
      pip install perplexityai
      ```

      ```bash TypeScript theme={null}
      npm install @perplexity-ai/perplexity_ai
      ```
    </CodeGroup>
  </Step>

  <Step title="Choisir un point de départ">
    La plateforme d&#39;API de Perplexity couvre un large éventail de cas d&#39;usage à travers ses différentes API. Voici quelques points de départ recommandés selon vos objectifs :

    * Vous découvrez la plateforme ? Consultez notre <u>[guide de démarrage rapide](/fr/docs/getting-started/quickstart)</u>
    * Vous voulez passer à la pratique ? Jetez un œil à nos <u>[exemples](/fr/docs/cookbook/examples/README)</u>
  </Step>
</Steps>
