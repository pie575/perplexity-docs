<div id="overview">
  ## Vue d&#39;ensemble
</div>

Pro Search enrichit [Sonar Pro](/fr/docs/sonar/models/sonar-pro) d&#39;une utilisation automatisée des outils, permettant un raisonnement en plusieurs étapes grâce à une orchestration intelligente des outils, notamment la recherche web et la récupération du contenu d&#39;URL.

<Warning>
  Pro Search fonctionne uniquement lorsque le streaming est activé. Les requêtes sans streaming retombent sur le comportement standard de Sonar Pro.
</Warning>

<div id="basic-usage">
  ## Utilisation de base
</div>

Pour activer Pro Search, définissez `stream` sur `true` et spécifiez `"search_type": "pro"` dans votre requête API. Le type de recherche par défaut est `"fast"` pour Sonar Pro classique.

Voici un exemple d&#39;activation de Pro Search avec le streaming :

<CodeGroup>
  ```python Python SDK theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  messages = [
      {
          "role": "user", 
          "content": "Summarize developments in post-quantum cryptography and how lattice-based and hash-based schemes are being standardized by NIST."
      }
  ]

  response = client.chat.completions.create(
      model="sonar-pro",
      messages=messages,
      stream=True,
      web_search_options={
          "search_type": "pro"
      }
  )

  for chunk in response:
      if chunk.choices[0].delta.content:
          print(chunk.choices[0].delta.content, end="")
  ```

  ```typescript Typescript SDK theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.chat.completions.create({
    model: 'sonar-pro',
    messages: [
      {
        role: 'user',
        content: 'Summarize developments in post-quantum cryptography and how lattice-based and hash-based schemes are being standardized by NIST.'
      }
    ],
    stream: true,
    web_search_options: {
      search_type: 'pro'
    }
  });

  for await (const chunk of response) {
    if (chunk.choices[0]?.delta?.content) {
      process.stdout.write((chunk.choices[0]?.delta?.content ?? '') as string);
    }
  }
  ```

  ```bash cURL theme={null}
  curl --request POST \
    --url https://api.perplexity.ai/v1/sonar \
    --header "Authorization: Bearer $PERPLEXITY_API_KEY" \
    --header "Content-Type: application/json" \
    --data '{
      "model": "sonar-pro",
      "messages": [
        {
          "role": "user",
          "content": "Summarize developments in post-quantum cryptography and how lattice-based and hash-based schemes are being standardized by NIST."
        }
      ],
      "stream": true,
      "web_search_options": {
        "search_type": "pro"
      }
    }' --no-buffer
  ```

<div id="enabling-automatic-classification">
  ## Activer la classification automatique
</div>

Sonar Pro peut être configuré pour classer automatiquement les requêtes en Pro Search ou Fast Search selon leur complexité. C&#39;est l&#39;approche recommandée pour la plupart des applications.

Définissez `search_type: "auto"` pour laisser le système acheminer intelligemment les requêtes en fonction de leur complexité.

<CodeGroup>
  ```python Python SDK theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.chat.completions.create(
      model="sonar-pro",
      messages=[
          {
              "role": "user",
              "content": "Compare the energy efficiency (kWh/100mi and MPGe) of the Tesla Model 3, Chevrolet Bolt, and Nissan Leaf using EPA data."
          }
      ],
      stream=True,
      web_search_options={
          "search_type": "auto"  # Classification automatique
      }
  )

  for chunk in response:
      if chunk.choices[0].delta.content:
          print(chunk.choices[0].delta.content, end="")
  ```

  ```typescript Typescript SDK theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();
  ```

<div id="how-classification-works">
  #### Fonctionnement de la classification
</div>

Le classificateur analyse votre requête et l&#39;achemine automatiquement vers :

* **Pro Search** pour les requêtes complexes nécessitant :
  * un raisonnement ou une analyse en plusieurs étapes
  * une analyse comparative de plusieurs sources
  * des flux de travail de recherche approfondie

* **Fast Search** pour les requêtes simples, par exemple :
  * la recherche de faits ponctuels
  * la récupération directe d&#39;informations
  * les réponses à des questions basiques

<div id="billing-with-auto-classification">
  #### Facturation avec la classification automatique
</div>

**Vous êtes facturé selon le type de recherche déclenché par votre requête :**

* Si la requête est classée comme **Pro Search** : 14 à 22 $ pour 1 000 requêtes (selon la taille du contexte)
* Si la requête est classée comme **Fast Search** : 6 à 14 $ pour 1 000 requêtes (selon la taille du contexte — identique à Sonar Pro standard)

Pour tous les détails tarifaires, consultez la section <a href="/fr/docs/sonar/pro-search/quickstart#pricing">Tarification</a>.

<Tip>
  La classification automatique est recommandée pour la plupart des applications, car elle concilie optimisation des coûts et performance des requêtes. Vous bénéficiez des capacités de Pro Search quand elles sont nécessaires, sans payer trop cher pour des requêtes simples.
</Tip>

<div id="manually-specifying-the-search-type">
  ### Spécifier manuellement le type de recherche
</div>

Si nécessaire, vous pouvez spécifier manuellement le type de recherche. C&#39;est utile dans les cas d&#39;usage précis où vous savez que la requête nécessite les capacités de Pro Search.

* **`"search_type": "pro"`** : spécifiez manuellement Pro Search pour les requêtes complexes lorsque vous savez qu&#39;une utilisation d&#39;outils en plusieurs étapes est nécessaire
* **`"search_type": "fast"`** : spécifiez manuellement Fast Search pour les requêtes simples afin d&#39;optimiser la vitesse et le coût (il s&#39;agit également de la valeur par défaut lorsque `search_type` est omis)
