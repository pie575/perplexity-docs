<div id="overview">
  ## Vue d&#39;ensemble
</div>

Pro Search fournit deux outils intégrés que le modèle utilise automatiquement pour répondre à vos requêtes. Le modèle détermine lui-même quels outils utiliser et à quel moment : aucune configuration n&#39;est donc nécessaire. Ces outils sont appelés automatiquement par le système ; il n&#39;est pas possible d&#39;enregistrer des outils personnalisés.

<Info>
  Toutes les exécutions d&#39;outils apparaissent dans le tableau `reasoning_steps` des réponses en streaming, ce qui vous permet de voir comment le modèle a mené ses recherches pour répondre à votre requête.
</Info>

<div id="web_search">
  ## web_search
</div>

Effectue des recherches web pour trouver des informations à jour, des statistiques et des avis d&#39;experts.

**Exemple d&#39;utilisation :**

```json theme={null}
{
  "thought": "I need current data on EV market trends",
  "type": "web_search",
  "web_search": {
    "search_keywords": [
      "EV Statistics 2023-2024",
      "electric vehicle sales data",
      "global EV market trends"
    ],
    "search_results": [
      {
        "title": "Trends in electric cars",
        "url": "https://www.iea.org/reports/global-ev-outlook-2024/trends-in-electric-cars",
        "date": "2024-03-15",
        "last_updated": null,
        "snippet": "Electric car sales neared 14 million in 2023, 95% of which were in China, Europe and the United States...",
        "source": "web"
      }
    ]
  }
}
```

<div id="fetch_url_content">
  ## fetch_url_content
</div>

Récupère le contenu intégral d&#39;URL spécifiques afin d&#39;accéder à des informations détaillées, au-delà des extraits renvoyés par les résultats de recherche.

**Exemple concret :**

```json theme={null}
{
  "thought": "This research paper contains detailed methodology I need to review",
  "type": "fetch_url_content",
  "fetch_url_content": {
    "contents": [
      {
        "title": "Attention Is All You Need",
        "url": "https://arxiv.org/pdf/1706.03762",
        "date": null,
        "last_updated": null,
        "snippet": "The dominant sequence transduction models are based on complex recurrent or convolutional neural networks that include an encoder and a decoder...",
        "source": "web"
      }
    ]
  }
}
```

<div id="multi-tool-workflows">
  ## Workflows multi-outils
</div>

Le modèle combine automatiquement plusieurs outils lorsque c&#39;est nécessaire. Par exemple, si on lui demande de se renseigner sur des options de panneaux solaires, il pourrait :

1. Utiliser `web_search` pour trouver les aides et les coûts actuels
2. Utiliser `fetch_url_content` pour lire en détail les documents réglementaires
3. Utiliser à nouveau `web_search` pour vérifier les tarifs de l&#39;électricité et comparer les fournisseurs
