<Note>
  L&#39;API Router est en préversion privée. Écrivez à [api@perplexity.ai](mailto:api@perplexity.ai) pour demander un accès.
</Note>

<div id="overview">
  ## Vue d&#39;ensemble
</div>

Chaque modèle ci-dessous est accessible via les deux points de terminaison du Router — [Chat Completions](/fr/api-reference/gateway-chat-completions-post) et [Messages](/fr/api-reference/gateway-messages-post) — sous le même identifiant `creator/model-name`. Les prix sont exprimés en USD par million de tokens, et la facturation s&#39;effectue aux tarifs du modèle demandé, quelle que soit la manière dont la requête est traitée.

Pour obtenir le catalogue à jour, interrogez [`GET /models`](/fr/api-reference/gateway-models-get) ; les tableaux ci-dessous présentent le catalogue actuel.

<Note>
  Les entrées mises en cache sont facturées séparément des nouvelles entrées : les lectures de cache le sont au tarif réduit propre à chaque modèle indiqué dans la colonne « lecture de cache », et les écritures de cache au tarif affiché (ou au tarif d&#39;entrée lorsqu&#39;aucun tarif d&#39;écriture dédié n&#39;est indiqué). Les tokens de raisonnement sont facturés au tarif de sortie.
</Note>

<div id="listing-models-programmatically">
  ## Lister les modèles par programmation
</div>

```bash theme={null}
curl 'https://api.perplexity.ai/router/v1/models' \
  -H "Authorization: Bearer $PERPLEXITY_API_KEY" | jq
```

La réponse répertorie tous les modèles disponibles, triés par id, avec les prix de base par token de chaque modèle. Demander un modèle absent du catalogue renvoie une erreur `400` précisant le modèle invalide — le catalogue sert également de liste d&#39;autorisation.
