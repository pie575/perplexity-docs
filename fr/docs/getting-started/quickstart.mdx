<div id="overview">
  ## Vue d&#39;ensemble
</div>

La Perplexity API propose quatre API principales répondant à différents cas d&#39;usage : **Router**, pour un accès direct aux modèles à poids ouverts via des points de terminaison compatibles OpenAI et Anthropic ; **Agent API**, pour des réponses d&#39;IA ancrées dans le web avec accès aux modèles OpenAI, Anthropic, Google et xAI, des outils de recherche unifiés et une tarification transparente ; **Search**, pour des résultats de recherche web classés ; et **Embeddings**, pour générer des embeddings de texte.

Toutes ces API sont accessibles aussi bien en REST que via les SDK, avec streaming, filtrage et contrôles avancés.

<div id="choosing-the-right-api">
  ## Choisir la bonne API
</div>

<AccordionGroup>
  <Accordion title="Utilisez la Router API lorsque..." icon="arrows-shuffle">
    * Vous voulez **une seule API pour les modèles à poids ouverts** — des modèles hébergés par Perplexity avec un point de terminaison et une clé uniques
    * Vous avez déjà **du code utilisant les SDK OpenAI ou Anthropic** — la migration se résume à un changement d&#39;URL de base
    * Vous voulez que **le routage et le basculement soient gérés automatiquement** plutôt que de les implémenter vous-même

    **Idéal pour :** les produits agnostiques vis-à-vis des modèles, les charges de travail multi-modèles, la consolidation des comptes par fournisseur
  </Accordion>

  <Accordion title="Utilisez l'Agent API lorsque..." icon="code-circle">
    * Vous voulez des **réponses ancrées dans le web avec des citations intégrées** — envoyez un message et obtenez une réponse documentée et sourcée, avec le contexte conversationnel si vous en avez besoin
    * Vous préférez la **simplicité** : choisissez un [preset](/fr/docs/agent-api/presets) et obtenez une réponse documentée en un seul appel, ou gardez un **contrôle granulaire** sur le model, le raisonnement, les budgets de tokens et les outils
    * Vous avez besoin d&#39;un **accès multi-fournisseurs** à OpenAI, Anthropic, Google, xAI et au model Sonar de Perplexity via une seule API

    **Idéal pour :** les assistants IA, les outils de recherche et de questions-réponses, les workflows agentiques, les applications IA personnalisées
  </Accordion>

  <Accordion title="Utilisez la Search API lorsque..." icon="search">
    * Vous avez besoin de **résultats de recherche bruts** sans traitement par un LLM
    * Vous voulez **créer des workflows IA personnalisés** avec vos propres modèles
    * Vous avez besoin de **données de recherche** pour l&#39;indexation, l&#39;analyse ou l&#39;entraînement

    **Idéal pour :** les pipelines IA personnalisés, la collecte de données, l&#39;intégration de la recherche
  </Accordion>

  <Accordion title="Utilisez l'Embeddings API lorsque..." icon="cube">
    * Vous avez besoin de mesurer la **similarité sémantique** entre des textes pour la recherche ou les recommandations
    * Vous construisez des **pipelines RAG** qui nécessitent des représentations vectorielles de documents
    * Vous devez **regrouper, classifier ou comparer** du texte sans générer de réponse

    **Idéal pour :** la recherche sémantique, les applications RAG, la classification de texte, les systèmes de recommandation
  </Accordion>
</AccordionGroup>

<div id="making-your-first-api-call">

</div>

Choisissez votre API en fonction de votre cas d&#39;usage :

<Tabs>
  <Tab title="API Router">
    À utiliser pour un accès direct aux modèles à poids ouverts avec le SDK OpenAI :

    <CodeGroup>
      ```python Python theme={null}
      from openai import OpenAI
      import os

      # Faire pointer le SDK OpenAI vers l'URL de base du Router
      client = OpenAI(
          api_key=os.environ.get("PERPLEXITY_API_KEY"),
          base_url="https://api.perplexity.ai/router/v1"
      )

      # Effectuer l'appel API avec n'importe quel modèle du catalogue Router
      response = client.chat.completions.create(
          model="perplexity/kimi-k3",
          max_tokens=1024,
          messages=[
              {"role": "user", "content": "Summarize the key trade-offs between vector and keyword search."}
          ]
      )

      print(response.choices[0].message.content)
      ```

      ```typescript TypeScript theme={null}
      import OpenAI from 'openai';

      // Faire pointer le SDK OpenAI vers l'URL de base du Router
      const client = new OpenAI({
          apiKey: process.env.PERPLEXITY_API_KEY,
          baseURL: "https://api.perplexity.ai/router/v1"
      });

      // Effectuer l'appel API avec n'importe quel modèle du catalogue Router
      const response = await client.chat.completions.create({
          model: "perplexity/kimi-k3",
          max_tokens: 1024,
          messages: [
              { role: "user", content: "Summarize the key trade-offs between vector and keyword search." }
          ]
      });

      console.log(response.choices[0].message.content);
      ```

      ```bash cURL theme={null}
      curl -X POST 'https://api.perplexity.ai/router/v1/chat/completions' \
        -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
        -H "Content-Type: application/json" \
        -d '{
          "model": "perplexity/kimi-k3",
          "max_tokens": 1024,
          "messages": [
            {"role": "user", "content": "Summarize the key trade-offs between vector and keyword search."}
          ]
        }' | jq
      ```
    </CodeGroup>

  <Tab title="Search API">
    À utiliser pour obtenir des résultats de recherche web classés, sans traitement par un LLM :

    <CodeGroup>
      ```python Python theme={null}
      from perplexity import Perplexity

      # Initialiser le client (utilise la variable d'environnement PERPLEXITY_API_KEY)
      client = Perplexity()

      # Effectuer l'appel API
      search = client.search.create(
          query="SpaceX Starship architecture and orbital test milestones",
          max_results=5
      )

      # Afficher les résultats de recherche
      for result in search.results:
          print(f"{result.title}: {result.url}")
      ```

      ```typescript TypeScript theme={null}
      import Perplexity from '@perplexity-ai/perplexity_ai';

      // Initialiser le client (utilise la variable d'environnement PERPLEXITY_API_KEY)
      const client = new Perplexity();

      // Effectuer l'appel API
      const search = await client.search.create({
          query: "SpaceX Starship architecture and orbital test milestones",
          max_results: 5
      });

      // Afficher les résultats de recherche
      for (const result of search.results) {
          console.log(`${result.title}: ${result.url}`);
      }
      ```
