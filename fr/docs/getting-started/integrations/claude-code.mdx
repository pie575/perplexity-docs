<div id="overview">
  ## Vue d&#39;ensemble
</div>

[Claude Code](https://docs.claude.com/en/docs/claude-code) est l&#39;outil de codage agentique d&#39;Anthropic, qui vit dans votre terminal, votre IDE et votre CI. Il peut modifier des fichiers, exécuter des commandes et appeler des serveurs Model Context Protocol (MCP) dans le cadre de son flux de travail. Ce guide présente trois modes d&#39;intégration avec Perplexity :

<CardGroup cols={3}>
  <Card title="SDK TypeScript officiel" icon="code">
    Laissez Claude Code écrire et exécuter du code applicatif qui appelle directement la Perplexity API. **Recommandé.**
  </Card>

  <Card title="SDK compatible OpenAI" icon="plug">
    Réutilisez un client OpenAI existant en faisant pointer `baseURL` vers `https://api.perplexity.ai/v1`.
  </Card>

  <Card title="MCP Claude Code" icon="book">
    Enregistrez le Perplexity Docs MCP hébergé avec `claude mcp add` pour que Claude Code puisse consulter la documentation Perplexity pendant que vous travaillez.
  </Card>
</CardGroup>

<Info>
  **Approche recommandée :** laissez Claude Code développer des fonctionnalités à partir du code de votre projet avec le SDK officiel (ou le SDK compatible OpenAI), et enregistrez le Perplexity Docs MCP pour consulter la documentation directement dans l&#39;éditeur. Claude Code ne prend **pas** officiellement en charge le remplacement de son model sous-jacent par la Perplexity API — voir [Remplacer le model de Claude Code (non recommandé)](#replacing-claude-codes-model-not-recommended).
</Info>

<div id="prerequisites">
  ## Prérequis
</div>

* Claude Code installé — consultez le [guide de démarrage rapide de Claude Code](https://docs.claude.com/en/docs/claude-code/quickstart)
* Node.js 18+ pour les exemples TypeScript
* Une clé API Perplexity

<Card title="Obtenir une clé API" icon="key" arrow="True" horizontal="True" iconType="solid" cta="Obtenir une clé" href="https://console.perplexity.ai/project/keys">
  Générez une clé depuis le portail Perplexity API.
</Card>

<div id="api-key-handling">
  ## Gestion de la clé API
</div>

Ne codez jamais en dur votre clé API dans les fichiers sources et ne la committez jamais dans un dépôt. Stockez-la dans une variable d&#39;environnement et lisez-la à l&#39;exécution :

<Tabs>
  <Tab title="macOS/Linux">
    ```bash theme={null}
    export PERPLEXITY_API_KEY="your_api_key_here"
    ```
  </Tab>

  <Tab title="Windows">
    ```powershell theme={null}
    setx PERPLEXITY_API_KEY "your_api_key_here"
    ```
  </Tab>

  <Tab title=".env (local au projet)">
    Créez un fichier `.env` à la racine de votre projet et ajoutez-le au `.gitignore` :

    ```bash theme={null}
    # .env
    PERPLEXITY_API_KEY=your_api_key_here
    ```

    Chargez-le au démarrage (par exemple avec [`dotenv`](https://www.npmjs.com/package/dotenv)) :

    ```typescript theme={null}
    import "dotenv/config";
    ```
  </Tab>
</Tabs>

<Warning>
  Traitez `PERPLEXITY_API_KEY` comme un mot de passe. Ne la collez pas dans des prompts, ne la partagez pas avec Claude Code et ne la committez pas dans un gestionnaire de versions. Si une clé est exposée, [renouvelez-la](https://console.perplexity.ai/project/keys) immédiatement.
</Warning>

<div id="path-1-official-typescript-sdk-recommended">
  ## Option 1 : SDK TypeScript officiel (recommandé)
</div>

Demandez à Claude Code de générer et de modifier le code qui appelle la Perplexity API à l&#39;aide du SDK officiel. C&#39;est l&#39;approche la plus fiable : elle vous offre un typage sûr et complet, la prise en charge des presets et l&#39;accès à toutes les fonctionnalités de l&#39;API.

<div id="install">
  ### Installation
</div>

```bash theme={null}
npm install @perplexity-ai/perplexity_ai
```

<Tip>
  `pnpm` et `yarn` fonctionnent de la même manière : `pnpm add @perplexity-ai/perplexity_ai` / `yarn add @perplexity-ai/perplexity_ai`.
</Tip>

<div id="agent-api-with-low">
  ### Agent API avec `low`
</div>

L&#39;Agent API est l&#39;interface recommandée pour la plupart des applications. Utilisez le preset `low` pour obtenir des réponses ancrées dans le web avec des valeurs par défaut pertinentes :

```typescript theme={null}
import Perplexity from "@perplexity-ai/perplexity_ai";

const client = new Perplexity(); // lit PERPLEXITY_API_KEY depuis l'environnement

const response = await client.responses.create({
  preset: "low",
  input: "Summarize the latest changes to the Perplexity Agent API.",
});

console.log(`Model used: ${response.model}`);
console.log(response.output_text);
```

<Accordion title="Équivalent en Python">
  ```python theme={null}
  from perplexity import Perplexity

  client = Perplexity()  # lit PERPLEXITY_API_KEY depuis l'environnement

  response = client.responses.create(
      preset="low",
      input="Summarize the latest changes to the Perplexity Agent API.",
  )

  print(f"Model used: {response.model}")
  print(response.output_text)
  ```
</Accordion>

<div id="add-web-search">
  ### Ajouter la recherche web
</div>

Activez l&#39;outil `web_search` pour contrôler explicitement le moment où la recherche est utilisée :

```typescript theme={null}
import Perplexity from "@perplexity-ai/perplexity_ai";

const client = new Perplexity();

const response = await client.responses.create({
  model: "openai/gpt-5.4",
  input: "What are the latest developments in AI inference hardware?",
  tools: [{ type: "web_search" }],
  instructions:
    "You have access to a web_search tool. Use it for questions about current events, news, or recent developments.",
});

if (response.status === "completed") {
  console.log(response.output_text);
}
```

<Tip>
  Demandez à Claude Code de générer ces appels pour vous — par exemple, *« Ajoute un script `summarize.ts` qui utilise `@perplexity-ai/perplexity_ai` avec le preset `low` et lit `PERPLEXITY_API_KEY` depuis l&#39;environnement. »* Claude Code modifiera le fichier, installera le paquet et l&#39;exécutera.
</Tip>

Pour découvrir d&#39;autres presets, outils et options de configuration, consultez le [démarrage rapide de l&#39;Agent API](/fr/docs/agent-api/quickstart) et la [vue d&#39;ensemble du SDK](/fr/docs/sdk/overview).

<div id="path-2-openai-compatible-sdk">
  ## Option 2 : SDK compatible OpenAI
</div>

Si votre projet utilise déjà un client OpenAI, vous pouvez le réutiliser en faisant pointer `baseURL` vers `https://api.perplexity.ai/v1`. Perplexity accepte `POST /v1/responses` comme alias de l&#39;Agent API.

<div id="install-2">
  ### Installation
</div>

```bash theme={null}
npm install openai
```

<div id="use-it">
  ### Utilisation
</div>

```typescript theme={null}
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.PERPLEXITY_API_KEY,
  baseURL: "https://api.perplexity.ai/v1",
});

const response = await client.responses.create({
  model: "openai/gpt-5.4",
  input: "Explain the key differences between REST and GraphQL APIs.",
});

console.log(response.output_text);
```

<Accordion title="Équivalent Python">
  ```python theme={null}
  import os
  from openai import OpenAI

  client = OpenAI(
      api_key=os.environ.get("PERPLEXITY_API_KEY"),
      base_url="https://api.perplexity.ai/v1",
  )

  response = client.responses.create(
      model="openai/gpt-5.4",
      input="Explain the key differences between REST and GraphQL APIs.",
  )

  print(response.output_text)
  ```
</Accordion>

<Info>
  Utilisez `baseURL` (TypeScript) ou `base_url` (Python) — les deux doivent inclure le suffixe `/v1`. Consultez le [guide de compatibilité OpenAI](/fr/docs/agent-api/openai-compatibility) pour la liste complète des paramètres pris en charge et pour savoir quelles fonctionnalités Perplexity sont accessibles par ce biais.
</Info>

<div id="path-3-claude-code-mcp-for-docs-lookup">
  ## Parcours 3 : MCP Claude Code pour consulter la documentation
</div>

Claude Code prend en charge le Model Context Protocol (MCP). Le serveur **Perplexity Docs MCP** hébergé à l&#39;adresse `https://docs.perplexity.ai/mcp` permet à Claude Code de rechercher et de lire directement la documentation de Perplexity — pratique pour ancrer les suggestions de code dans la documentation de référence sans avoir à basculer vers un navigateur.

<div id="add-the-server">
  ### Ajouter le serveur
</div>

Claude Code peut enregistrer un serveur MCP distant via HTTP à l&#39;aide de la commande `claude mcp add` avec l&#39;option `--transport http` :

<Tabs>
  <Tab title="Portée projet">
    Ajoutez le serveur uniquement pour le projet en cours (écrit dans le fichier `.mcp.json` à la racine de votre dépôt) :

    ```bash theme={null}
    claude mcp add --transport http --scope project perplexity-docs https://docs.perplexity.ai/mcp
    ```
  </Tab>

  <Tab title="Portée utilisateur">
    Ajoutez le serveur pour tous les projets de cette machine :

    ```bash theme={null}
    claude mcp add --transport http --scope user perplexity-docs https://docs.perplexity.ai/mcp
    ```
  </Tab>
</Tabs>

<Tip>
  Si vous préférez ne pas passer par la CLI, vous pouvez aussi modifier directement le fichier `.mcp.json` du projet :

  ```json theme={null}
  {
    "mcpServers": {
      "perplexity-docs": {
        "type": "http",
        "url": "https://docs.perplexity.ai/mcp"
      }
    }
  }
  ```

  Pour les serveurs à portée projet, Claude Code lit le fichier `.mcp.json` situé à la racine du dépôt. Consultez la [documentation MCP de Claude Code](https://docs.claude.com/en/docs/claude-code/mcp) pour connaître le schéma de référence et les éventuelles nouvelles options de transport.
</Tip>

<div id="verify-and-use">
  ### Vérifier et utiliser
</div>

<Steps>
  <Step title="Vérifier que le serveur est bien enregistré">
    Exécutez `claude mcp list` et vérifiez que `perplexity-docs` figure dans la sortie.
  </Step>

  <Step title="Redémarrer Claude Code">
    Quittez puis relancez Claude Code (ou exécutez `/mcp` depuis une session en cours) afin que le nouveau serveur soit chargé.
  </Step>

  <Step title="L'utiliser depuis un prompt">
    Demandez à Claude Code quelque chose comme *« À l&#39;aide du MCP de la documentation Perplexity, montre-moi comment activer `low` dans l&#39;Agent API. »* Claude Code appellera le serveur MCP et s&#39;appuiera sur la documentation à jour pour formuler sa réponse.
  </Step>
</Steps>

<Info>
  Le Docs MCP est en lecture seule et ne nécessite aucune clé API : il se contente de servir la documentation Perplexity. Pour donner à Claude Code accès aux outils de **recherche et de raisonnement** de Perplexity (et pas seulement à la documentation), installez le [serveur MCP Perplexity](/fr/docs/getting-started/integrations/mcp-server), qui repose sur `@perplexity-ai/mcp-server` et requiert `PERPLEXITY_API_KEY`.
</Info>

<div id="replacing-claude-codes-model-not-recommended">
  ## Remplacer le model de Claude Code (déconseillé)
</div>

Claude Code est conçu pour fonctionner avec les models Claude d&#39;Anthropic : l&#39;utilisation des outils, le prompting et le comportement d&#39;édition de l&#39;agent sont optimisés pour ces models. Faire pointer la CLI Claude Code vers la Perplexity API en tant que fournisseur de model alternatif n&#39;est **pas une configuration officiellement prise en charge**.

À la place :

* **Utilisez Perplexity depuis le code de votre projet** (Voie 1 ou Voie 2). Claude Code se chargera sans difficulté d&#39;écrire, de modifier et d&#39;exécuter du code qui appelle Perplexity pour obtenir des réponses ancrées dans le web, des recherches approfondies et des résultats de recherche.
* **Ajoutez le Perplexity Docs MCP** (Voie 3) pour que Claude Code puisse consulter la documentation Perplexity en cours de session.

Cette combinaison vous permet de conjuguer les points forts de Claude Code en matière d&#39;édition et d&#39;orchestration avec les réponses de Perplexity ancrées dans la recherche, sans dépendre d&#39;un comportement de substitution de model non documenté.
