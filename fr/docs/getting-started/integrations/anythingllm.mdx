<div id="overview">
  ## Vue d&#39;ensemble
</div>

[AnythingLLM](https://anythingllm.com) est une application de productivité IA tout-en-un qui transforme n&#39;importe quel document, ressource ou contenu en contexte pour des conversations propulsées par des LLM. Elle prend en charge les déploiements sur poste de travail comme en auto-hébergement et fonctionne avec des dizaines de fournisseurs de LLM — dont Perplexity, intégré comme fournisseur cloud de premier plan, ce qui donne à chaque espace de travail accès à des réponses ancrées dans le web et accompagnées de citations.

<Info>
  **AnythingLLM** est développé et maintenu par Mintplex Labs. L&#39;application permet de configurer le LLM par espace de travail : vous pouvez ainsi utiliser Perplexity dans un espace de travail et un autre fournisseur ailleurs. Pour en savoir plus, rendez-vous sur [anythingllm.com](https://anythingllm.com).
</Info>

<div id="setup">
  ## Configuration
</div>

<Steps>
  <Step title="Obtenir votre clé API">
    Générez une clé API Perplexity depuis le [portail API](https://console.perplexity.ai/project/keys).

    <Card title="Obtenir une clé API" icon="key" href="https://console.perplexity.ai/project/keys">
      Générez votre clé API Perplexity.
    </Card>
  </Step>

  <Step title="Ouvrir les paramètres LLM">
    Dans AnythingLLM, rendez-vous dans **Settings → LLM Preference**.
  </Step>

  <Step title="Sélectionner Perplexity AI">
    Choisissez **Perplexity AI** dans la liste des fournisseurs, puis collez votre clé API.
  </Step>

  <Step title="Choisir un modèle">
    Une fois la clé saisie, le menu déroulant **Chat Model Selection** se remplit automatiquement avec les modèles Perplexity disponibles. Sélectionnez le modèle souhaité (par exemple `sonar-pro`), puis enregistrez.
  </Step>
</Steps>

<div id="system-vs-workspace-models">
  ## Modèles système et modèles d&#39;espace de travail
</div>

AnythingLLM permet de définir le choix du LLM à deux niveaux :

* **LLM système** — Le fournisseur par défaut utilisé pour tous les espaces de travail et tous les agents.
* **LLM d&#39;espace de travail** — Un réglage propre à un espace de travail, qui prévaut lors des conversations menées dans cet espace.

Vous pouvez combiner librement les fournisseurs. Par exemple, définissez Anthropic comme fournisseur système par défaut et utilisez Perplexity dans un espace de travail donné, lorsque vous avez besoin d&#39;un ancrage web en temps réel pour des échanges à forte composante de recherche.

Pour définir une surcharge par espace de travail : ouvrez l&#39;espace de travail, allez dans **Workspace Settings → Chat Settings → Workspace LLM Provider**, puis sélectionnez **Perplexity AI** avec le modèle souhaité.

<div id="available-models">
  ## Modèles disponibles
</div>

Tous les modèles Perplexity pris en charge par l&#39;API sont accessibles aux utilisateurs d&#39;AnythingLLM — la liste déroulante des modèles se remplit dynamiquement dès que votre clé API est validée. Modèles recommandés :

* `sonar` — chat ancré sur le web, rapide et économique
* `sonar-pro` — raisonnement avancé avec des citations plus approfondies
* `sonar-reasoning-pro` — raisonnement en plusieurs étapes avec recherche

Consultez la liste complète des [modèles Perplexity et de leurs capacités](/fr/docs/sonar/models).

<div id="use-cases">
  ## Cas d&#39;usage
</div>

Associer Perplexity à AnythingLLM vous apporte :

* **Des réponses web en temps réel au cœur de vos flux documentaires** — votre espace de travail peut répondre, dans une même conversation, à des questions portant sur les PDF importés comme sur le web ouvert.
* **Une recherche étayée par des citations** — Perplexity renvoie les URL sources, que vous pouvez vérifier en regard de votre contexte issu du RAG.
* **Un repli sans RAG pour l&#39;actualité** — lorsque les documents ne contiennent pas la réponse, le modèle peut automatiquement faire appel au contexte web en temps réel.

<div id="agent-configuration">
  ## Agent Configuration
</div>

Lorsque vous utilisez les [agents IA](https://docs.anythingllm.com/agent/setup) d&#39;AnythingLLM, vous pouvez définir Perplexity comme LLM de l&#39;agent dans le menu **Agent Configuration** de l&#39;espace de travail. Cela s&#39;avère utile pour les agents qui doivent combiner la recherche web avec des compétences telles que la navigation web, les questions-réponses sur documents ou les appels à des API externes.
