<div id="overview">
  ## Vue d&#39;ensemble
</div>

[Agno](https://docs.agno.com) est un framework Python open source permettant de créer des agents, des équipes et des workflows. Connectez-le à l&#39;[Agent API](/fr/docs/agent-api/quickstart) de Perplexity via la classe de modèle d&#39;Agno compatible avec OpenAI Responses.

<div id="installation">
  ## Installation
</div>

```bash theme={null}
pip install agno openai
```

<div id="api-key-setup">
  ## Configuration de la clé API
</div>

Définissez votre clé API Perplexity comme variable d&#39;environnement :

```bash theme={null}
export PERPLEXITY_API_KEY="your_api_key_here"
```

<Card title="Obtenir une clé API" icon="key" href="https://console.perplexity.ai/project/keys">
  Générez votre clé API Perplexity depuis le portail API.
</Card>

<div id="quick-start">
  ## Démarrage rapide
</div>

Utilisez `OpenAIResponses` avec l&#39;URL de base de l&#39;Agent API et n&#39;importe quel modèle pris en charge par l&#39;Agent API. Transmettez un [preset](/fr/docs/agent-api/presets) de recherche via `extra_body` afin que les réponses s&#39;appuient sur des résultats web en temps réel :

```python theme={null}
import os

from agno.agent import Agent
from agno.models.openai import OpenAIResponses

agent = Agent(
    model=OpenAIResponses(
        id="openai/gpt-5.6-luna",
        base_url="https://api.perplexity.ai/v1",
        api_key=os.environ["PERPLEXITY_API_KEY"],
        extra_body={"preset": "medium"},
    ),
    markdown=True,
)

agent.print_response(
    "What are the latest breakthroughs in fusion energy this year?",
    stream=True,
)
```

Remplacez `id` par n&#39;importe quel [modèle de l&#39;Agent API](/fr/docs/agent-api/models) pour acheminer des modèles tiers via Perplexity. L&#39;Agent API propose également des [presets](/fr/docs/agent-api/presets) issus de la recherche ainsi que des [outils](/fr/docs/agent-api/tools) intégrés supplémentaires.
