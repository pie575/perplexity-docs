<div id="what-is-a-project">
  ## Qu&#39;est-ce qu&#39;un projet ?
</div>

Un **projet** est l&#39;espace de travail de votre organisation dans le portail Perplexity API. Il vous permet de :

* **Gérer la facturation** et les moyens de paiement liés à l&#39;utilisation de l&#39;API
* **Créer et gérer des clés API** pour accéder à la Perplexity API
* **Inviter des membres de votre équipe** et définir leurs autorisations (facultatif)
* **Suivre l&#39;utilisation et les coûts** de l&#39;ensemble de vos clés API

<div id="prerequisites">
  ## Prérequis
</div>

Avant de commencer, assurez-vous de disposer des éléments suivants :

* Un compte Perplexity (inscrivez-vous sur [perplexity.ai](https://perplexity.ai))
* Des **droits d&#39;administrateur** pour la facturation et la gestion des clés API
* Une **carte bancaire** prête pour la configuration du paiement (aucun montant ne vous sera facturé dans un premier temps)

<Note>
  Si vous rejoignez une équipe existante, vous devrez obtenir une invitation d&#39;un administrateur. Contactez le responsable de votre équipe pour obtenir un accès.
</Note>

<div id="accessing-the-api-portal">
  ## Accéder au portail Perplexity API
</div>

Rendez-vous sur [console.perplexity.ai](https://console.perplexity.ai) pour accéder à votre projet. La barre latérale de gauche comporte deux sections :

* **Project** : Settings, Members, Billing, clés API, Files
* **API Playground** : Search API, Agent API

<div id="billing-and-payment-methods">
  ## Facturation et moyens de paiement
</div>

<div id="how-billing-works">
  ### Fonctionnement de la facturation
</div>

L&#39;API Perplexity utilise un **système de facturation par crédits** :

* Les **crédits** sont achetés à l&#39;avance et consommés lors des appels à l&#39;API
* **Chaque modèle** consomme un nombre de crédits différent par requête
* **L&#39;utilisation est facturée** en fonction des tokens traités et des recherches effectuées
* La **recharge automatique** peut être activée pour éviter toute interruption de service

<Info>
  Consultez notre [page Tarifs](./pricing) pour connaître le détail des coûts par modèle et par type d&#39;utilisation.
</Info>

<div id="setting-up-payment">
  ### Configurer le paiement
</div>

<Card title="Accéder au tableau de bord de facturation" icon="credit-card" arrow="True" horizontal="True" iconType="solid" cta="Accéder à la facturation" href="https://console.perplexity.ai/project/billing">
  Accédez directement au tableau de bord de facturation de l&#39;API pour gérer vos moyens de paiement, consulter votre consommation et configurer vos paramètres de facturation.
</Card>

<Steps>
  <Step title="Accéder à la facturation">
    Cliquez sur **Billing** dans la barre latérale gauche. Cette page affiche votre solde de crédits, votre moyen de paiement, le graphique d&#39;utilisation et le détail de la facturation.

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_billing.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=6d6e71d28dcf4d39faa4fc8b14c6ad48" alt="Tableau de bord de facturation de l'API" />
    </Frame>
  </Step>

  <Step title="Ajouter un moyen de paiement">
    Cliquez sur **Add payment method** et saisissez les informations de votre carte bancaire. Le paiement est géré via Stripe — vous pouvez également cliquer sur **Manage ↗** pour accéder directement au portail Stripe.

    <Note>
      L&#39;ajout d&#39;un moyen de paiement n&#39;entraîne aucun débit de votre carte bancaire : il enregistre simplement vos informations de paiement en vue de votre utilisation future de l&#39;API.
    </Note>
  </Step>

  <Step title="Configurer le rechargement automatique (recommandé)">
    Activez le rechargement automatique des crédits en cliquant sur **Change preferences** à côté de **Auto reload**.

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_topup.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=3aa16c75b424292781b61005b1ab32df" alt="Tableau de bord de facturation de l'API" />
    </Frame>

    <Warning>
      Si vous n&#39;avez plus de crédits, vos clés API seront bloquées jusqu&#39;à ce que vous rechargiez votre solde. Le rechargement automatique évite cette situation en ajoutant des crédits dès que votre solde passe sous un seuil défini.
    </Warning>
  </Step>
</Steps>

<div id="credit-balance">
  ### Solde de crédits
</div>

La page Facturation affiche en haut, bien en évidence, votre **solde de crédits restant**. Vous pouvez acheter des crédits supplémentaires à tout moment via le lien **Buy more credits**.

Votre **palier d&#39;utilisation** actuel y figure également — cliquez sur **Learn more ↗** pour en savoir plus sur les seuils et les avantages associés à chaque palier.

<div id="managing-api-keys">
  ## Gestion des clés API
</div>

<div id="what-are-api-keys">
  ### Que sont les clés API ?
</div>

Les clés API sont vos identifiants d&#39;accès à l&#39;API Perplexity. Chaque clé :

* **Authentifie vos requêtes** auprès de l&#39;API Perplexity
* **Assure le suivi de la consommation** à des fins d&#39;attribution
* **Peut être révoquée** pour des raisons de sécurité
* **Doit rester confidentielle** et ne jamais être partagée publiquement

<Info>
  Vous devrez inclure votre clé API dans l&#39;en-tête Authorization de chaque requête API : `Authorization: Bearer $PERPLEXITY_API_KEY`
</Info>

<div id="creating-an-api-key">
  ### Créer une clé API
</div>

<Steps>
  <Step title="Accéder aux clés API">
    Cliquez sur **clés API** dans la barre latérale de gauche.

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_api_keys.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=d72bcb05e281c05a5a7a2f7b3a469f50" alt="API Keys" />
    </Frame>
  </Step>

  <Step title="Générer une nouvelle clé">
    Cliquez sur **+ Generate clé API** pour créer une nouvelle clé API.

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_api_keys_new.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=ca3c652417faa90238d299ddc72b0249" alt="API Keys" />
    </Frame>
  </Step>
</Steps>

<Warning>
  Les clés API sont des identifiants sensibles. Ne les exposez jamais dans du code côté client et ne les partagez jamais dans des dépôts publics.
</Warning>

<div id="adding-and-managing-members">
  ## Ajouter et gérer les membres
</div>

Les administrateurs peuvent inviter des membres de l&#39;équipe à rejoindre l&#39;organisation en leur attribuant un rôle précis : **Admin** ou **Member**.

<div id="adding-a-member">
  ### Ajouter un membre
</div>

<Steps>
  <Step title="Accéder à Members">
    Cliquez sur **Members** dans la barre latérale de gauche. Cette page affiche les membres actuels de votre équipe et leurs rôles.
  </Step>

  <Frame>
    <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_members.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=78f439f1a1567dc49c7ff06c4033b3af" alt="Members" />
  </Frame>

  <Step title="Envoyer une invitation à un membre">
    Cliquez sur **+ Add Member**. Saisissez l&#39;adresse e-mail de l&#39;utilisateur, puis cliquez sur **Invite**.

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_add_member.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=c4fab8e720fb1db15206846289399a3a" alt="Add Member" />
    </Frame>
  </Step>

  <Step title="Le membre reçoit l'invitation">
    L&#39;utilisateur invité reçoit un e-mail contenant un lien pour rejoindre votre projet.

    <Check>
      Dès qu&#39;il accepte, il apparaît dans votre liste de membres avec le rôle qui lui a été attribué.
    </Check>
  </Step>
</Steps>

<div id="filtering-members-by-role">
  ### Filtrer les membres par rôle
</div>

Utilisez le menu déroulant pour filtrer la liste des membres de votre équipe par rôle.

<div id="roles">
  ### Rôles
</div>

* **Admin** : accès complet pour inviter ou retirer des membres, gérer la facturation et consulter les données d&#39;utilisation.
* **Membre** : peut consulter l&#39;utilisation et les limites du compte, mais ne peut pas modifier les paramètres.

<Warning>
  Seuls les Admins peuvent modifier la facturation et les autorisations des membres.
</Warning>

<div id="viewing-usage-metrics">
  ## Consultation des métriques d&#39;utilisation
</div>

Tous les membres peuvent suivre l&#39;utilisation de l&#39;API directement depuis la page **Billing** de la console.

<Frame>
  <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_usage_metrics.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=80e6246097068cf8854370c98a9de338" alt="Métriques d'utilisation" />
</Frame>

Le graphique **Usage** vous permet de suivre l&#39;activité dans le temps à l&#39;aide des filtres suivants :

* **Sélecteur de métrique** : choisissez parmi Chat Completions API Requests, Input Tokens, Output Tokens, Citation Tokens, Reasoning Tokens, Deep Research Requests Count, Search API Requests Count ou Pro Search API Requests Count
* **Plage temporelle** : filtrez par Last 7 Days, Last 30 Days ou une plage personnalisée

Sous le graphique, le tableau **détail de la facturation** détaille, pour chaque modèle, la quantité utilisée, le tarif et le coût — vous donnant une vision claire des dépenses par produit.

<Check>
  Les métriques d&#39;utilisation vous aident à surveiller l&#39;activité de l&#39;API et à l&#39;optimiser en termes de coût ou de performance.
</Check>

<div id="invoice-history">
  ## Historique des factures
</div>

Sous le graphique d&#39;utilisation et le détail de la facturation de la page **Billing**, vous trouverez votre **historique des factures** — un relevé de toutes les factures passées, avec leur date, leur statut et leur montant.

<Frame>
  <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_invoices.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=4df3bb3d07fef0c321d8b82272651c14" alt="Invoice History" />

Les factures sont générées automatiquement à chaque cycle de facturation. Utilisez les boutons **Previous** et **Next** pour parcourir les enregistrements plus anciens.
