<Update label="August 2026" tags={["Agent API", "Presets"]}>
  **Mise en cache des prompts pour les presets**

  Les presets de l&#39;Agent API utilisent désormais automatiquement des clés de cache de prompt stables, ce qui permet à des requêtes indépendantes utilisant le même preset de réutiliser le préfixe de prompt partagé (system prompt et définitions d&#39;outils). Aucune modification des requêtes n&#39;est nécessaire, et une valeur `prompt_cache_key` explicite continue de prévaloir sur la valeur par défaut du preset. Cela peut réduire les coûts d&#39;environ 5 % pour les applications qui utilisent fréquemment des presets, selon le taux d&#39;utilisation du cache. Les [valeurs actuelles des presets](/fr/docs/agent-api/presets#current-preset-values) indiquent la clé de chaque configuration figée.
</Update>

<Update label="July 2026" tags={["Agent API", "Presets"]}>
  **Citations en ligne pour les presets de recherche**

  Les presets de l&#39;Agent API adossés à la recherche incluent des citations en ligne : `fast` cite les affirmations issues des résultats de recherche avec des citations numérotées telles que `[1]`, tandis que `low`, `medium` et `high` citent désormais les affirmations issues des résultats d&#39;outils ou des artefacts sources fournis avec des citations typées par source, telles que `[web:1]`. Après un appel d&#39;outil réussi, les presets `low`, `medium` et `high` incluent au moins une citation dans la réponse finale. Les [valeurs actuelles des presets](/fr/docs/agent-api/presets#current-preset-values) comprennent les system prompts destinés aux configurations figées.
</Update>

<Update label="July 2026" tags={["MCP", "Agent API"]}>
  **serveur MCP 1.0 : désormais propulsé par l&#39;Agent API**

  La version 1.0.0 du [serveur MCP Perplexity](/fr/docs/getting-started/integrations/mcp-server) fait passer ses outils adossés à un modèle des anciens modèles Sonar aux [presets de l&#39;Agent API](/fr/docs/agent-api/presets) : `perplexity_ask` utilise le preset `fast`, `perplexity_reason` le preset `medium` et `perplexity_research` le preset `high`. Les noms des outils et la forme des réponses restent inchangés, et les trois outils sont en moyenne plus rapides et moins coûteux que leurs prédécesseurs Sonar. Les recherches de longue durée diffusent désormais leur progression aux clients MCP qui en font la demande, et l&#39;annulation d&#39;une requête MCP annule l&#39;exécution sous-jacente.

  Les paramètres `strip_thinking` et `reasoning_effort` ont été retirés des schémas d&#39;outils (l&#39;Agent API n&#39;émet aucune balise de réflexion, et les presets gèrent l&#39;effort de raisonnement) ; les clients qui les envoient encore sont ignorés sans erreur.
</Update>

<Update label="May 2026" tags={["Agent API", "Tools", "Finance"]}>
  **Finance Search : désormais disponible**

  L&#39;outil `finance_search` est désormais disponible dans l&#39;Agent API. Récupérez des données financières et boursières structurées — cours, états financiers, résultats, estimations d&#39;analystes, indicateurs clés par segment, composition d&#39;ETF, et bien plus — pour les entreprises cotées et les instruments financiers. Le modèle détermine les champs à récupérer en fonction de votre prompt : un seul appel peut donc renvoyer à la fois valorisation, résultats et contexte.

  **Points clés :**

  * **Cours et cotations** : prix en temps quasi réel, données OHLCV, séances avant ouverture et après clôture
  * **États financiers** : compte de résultat, bilan, flux de trésorerie (trimestriels et annuels), ratios clés
  * **Résultats** : transcription de la dernière conférence de résultats, dépôts réglementaires, historique des surprises positives/négatives, prévisions
  * **Couverture et activité de marché** : estimations d&#39;analystes, plus fortes hausses/baisses, actionnariat et opérations sur titres
  * **Configurations recommandées** : presets pour les cours en direct, les recherches historiques sur une seule entreprise et les recherches multi-étapes portant sur plusieurs entreprises

  Commencez ici : [Finance Search](/fr/docs/agent-api/tools/finance-search)
</Update>

<Update label="December 2025" tags={["Models", "Deprecation", "Search"]}>

  **Nouveau : Media Classifier pour du contenu visuel intelligent**

  Nous avons le plaisir de présenter le **Media Classifier** — un système intelligent qui détecte automatiquement les requêtes pour lesquelles du contenu visuel apporte une valeur ajoutée et joint les images ou vidéos pertinentes aux réponses.

  **Principales capacités :**

  * **Détection automatique** : analyse les requêtes afin d&#39;identifier les cas où le contenu visuel apporte une réelle valeur
  * **Sélection intelligente des médias** : choisit judicieusement entre images, vidéos ou les deux, selon le type de requête
  * **Sensible au contexte** : idéal pour le contenu éducatif, les requêtes géographiques, les processus et les démonstrations
  * **Contrôle configurable** : activez ou désactivez la fonctionnalité et remplacez les types de médias selon vos besoins

  Disponible exclusivement avec `sonar-pro`, le Media Classifier enrichit les réponses portant sur des concepts visuels, des lieux, des processus étape par étape et du contenu éducatif. [En savoir plus →](/fr/docs/sonar/media)

  **Améliorations de la Search API**

  Nous avons apporté plusieurs améliorations à la Search API :

  * **Nouveau paramètre `max_tokens`** : contrôlez le nombre maximal de tokens extraits par page dans les résultats de recherche. Vous disposez ainsi d&#39;un contrôle plus fin sur la taille des réponses et sur les coûts. [En savoir plus →](/fr/docs/search/quickstart)
  * **Prise en charge de `last_updated_filter`** : filtrez les résultats de recherche selon la date de dernière mise à jour du contenu, en complément de la date de publication. Idéal pour trouver les informations les plus récentes. [En savoir plus →](/fr/docs/search/filters/date-time-filters)
  * **Prise en charge du Vercel AI SDK** : la Search API est désormais compatible avec le Vercel AI SDK, ce qui vous permet de développer avec Perplexity indépendamment du framework. [En savoir plus →](https://ai-sdk.dev/tools-registry/perplexity-search)

Créée par la communauté pour les développeurs qui souhaitent un contrôle fin de leurs interactions avec Sonar.

<Update label="November 2025" tags={["Pro Search", "MCP", "Multimodal"]}>
  **Pro Search : désormais disponible pour tous**

  Nous sommes ravis d&#39;annoncer la disponibilité générale de **Pro Search** pour Sonar Pro ! Pro Search enrichit vos requêtes grâce à l&#39;utilisation automatisée d&#39;outils, permettant un raisonnement en plusieurs étapes via une orchestration intelligente des outils.

  * **Diffusion du raisonnement en temps réel** : suivez le cheminement du modèle pendant qu&#39;il traite votre question
  * **Classification automatique** : utilisez `search_type: "auto"` pour laisser le système acheminer intelligemment les requêtes selon leur complexité
  * **Outils intégrés** : accédez aux outils `web_search` et `fetch_url_content` que le modèle utilise automatiquement
