La Perplexity API Platform est proposée sous forme d&#39;offre SaaS sur AWS Marketplace. Vous achetez des crédits d&#39;API depuis votre compte AWS : ces crédits sont ajoutés à votre solde Perplexity API et sont valables sur l&#39;ensemble des API (Router, Agent, Search, Sonar et Embeddings).

<Note>
  Cette offre concerne l&#39;**API Platform** (Router API, Agent API, Search API, Sonar et Embeddings). Il s&#39;agit d&#39;un produit distinct d&#39;**Enterprise Pro**, qui n&#39;inclut pas l&#39;accès aux API.
</Note>

<div id="why-subscribe-through-aws-marketplace">
  ## Pourquoi souscrire via AWS Marketplace ?
</div>

L&#39;achat via AWS Marketplace présente plusieurs avantages par rapport à la facturation directe :

* **Facturation AWS consolidée** — les frais apparaissent sur votre facture AWS existante, aux côtés des autres services AWS, ce qui simplifie les processus financiers et comptables
* **Achats en entreprise** — répond aux exigences d&#39;achat des organisations qui imposent le recours à AWS Marketplace ; aucune relation fournisseur distincte n&#39;est nécessaire
* **Éligible à l&#39;EDP** — les achats sont pris en compte dans vos engagements au titre du programme AWS Enterprise Discount Program (EDP)
* **Gestion des fournisseurs simplifiée** — aucun contrat ni moyen de paiement distinct à gérer ; AWS se charge de la facturation

<div id="pricing">
  ## Tarification
</div>

La Perplexity API Platform sur AWS Marketplace est proposée sous forme de **contrat d&#39;un mois** assorti de crédits de plateforme d&#39;API :

| Formule                  |       Crédits      | Contrat |
| ------------------------ | :----------------: | :-----: |
| **Crédits API Platform** | À partir de $1 000 |  1 mois |

Les crédits sont libellés à parité avec le dollar américain — 1 crédit = $1. Ils sont ajoutés au solde de votre compte et décomptés au fur et à mesure de vos requêtes d&#39;API.

<Note>
  Tous les produits de la Perplexity API — Router API, Agent API, Search API, Sonar et Embeddings — puisent dans le même pool de crédits partagé. Inutile de prévoir un budget distinct par produit.

  Pour le détail des tarifs par requête et par token, consultez la <u>[page Tarification](/fr/docs/getting-started/pricing)</u>.
</Note>

<div id="how-to-subscribe">
  ## Comment s&#39;abonner
</div>

<Tip>
  Les crédits n&#39;expirent pas — le **contrat d&#39;un mois** correspond au cycle de facturation, et non à une date limite d&#39;utilisation : les crédits non utilisés restent donc sur votre solde.
</Tip>

1. Rendez-vous sur l&#39;<u>[offre Perplexity API Platform](https://aws.amazon.com/marketplace/pp/prodview-fslss6gnscauq)</u> sur AWS Marketplace
2. Cliquez sur **View purchase options**
3. Choisissez le montant de crédits souhaité, puis cliquez sur **Create contract**
4. Confirmez l&#39;achat — AWS traitera l&#39;abonnement et vous en informera par e-mail

<div id="getting-started-after-subscribing">
  ## Premiers pas après votre souscription
</div>

Une fois votre abonnement AWS Marketplace confirmé :

1. **Connectez-vous ou créez un compte** — rendez-vous sur <u>[console.perplexity.ai](https://console.perplexity.ai)</u> et connectez-vous avec votre compte Perplexity (ou créez-en un si vous n&#39;en avez pas encore)
2. **Associez votre abonnement** — suivez les instructions de la console pour relier votre achat AWS Marketplace à votre compte Perplexity ; cette opération rattache les crédits achetés à votre projet
3. **Configurez votre projet** — vos crédits sont rattachés à un projet (l&#39;espace de travail de votre organisation dans l&#39;API Portal). La personne qui finalise la configuration devient Admin, avec un accès complet à la facturation, aux API keys et aux invitations de membres. D&#39;autres personnes peuvent rejoindre le projet en tant qu&#39;Admins (accès complet) ou Members (lecture seule). Consultez <u>[Projets et facturation](/fr/docs/getting-started/projects)</u>.
4. **Générez une API key** — rendez-vous dans la section API Keys de la console pour créer une clé destinée à votre projet. Consultez <u>[Gestion des API keys](/fr/docs/admin/api-key-management)</u>.
5. **Commencez à envoyer des requêtes** — les crédits sont imputés sur le solde de votre projet et partagés entre tous les produits (Router API, Agent API, Search API, Sonar, Embeddings). Vous pouvez suivre à tout moment le solde restant et votre consommation dans la console.

<div id="refund-policy">
  ## Politique de remboursement
</div>

Si vous devez annuler votre abonnement, un remboursement est possible **dans les 14 jours suivant l&#39;achat**, à condition qu&#39;**aucun crédit n&#39;ait été utilisé**. Pour demander un remboursement, contactez <u>[aws-api@perplexity.ai](mailto:aws-api@perplexity.ai)</u> en indiquant votre identifiant de commande AWS Marketplace.

<Warning>
  Aucun remboursement n&#39;est possible dès lors que des crédits ont été consommés, ni après l&#39;expiration du délai de 14 jours.
</Warning>
