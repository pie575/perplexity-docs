Les outils sont ce qui transforme un modèle en agent.
Livré à lui-même, un modèle ne répond qu&#39;à partir de ce qu&#39;il sait déjà ; les outils lui permettent d&#39;effectuer des recherches sur le web en temps réel, de récupérer une page, d&#39;exécuter du code ou d&#39;appeler vos propres systèmes.
Pour activer des outils, il suffit de les indiquer dans le tableau `tools` : au sein d&#39;une même requête, le modèle exécute alors une boucle agentique — il raisonne, appelle un outil, observe le résultat et répète l&#39;opération jusqu&#39;à pouvoir répondre.

<div id="three-kinds-of-tools">
  ## Trois types d&#39;outils
</div>

| Type                                                               | Description                                                      | Où le modèle l&#39;exécute                                                    |
| ------------------------------------------------------------------ | ---------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Outils intégrés                                                    | Capacités hébergées par Perplexity, activées via `type`.         | Dans la boucle ; Perplexity les exécute et renvoie les résultats directement. |
| [Serveurs MCP](/fr/docs/agent-api/tools/mcp)                          | Votre propre serveur MCP distant, connecté avec `type: mcp`.     | Dans la boucle ; le modèle appelle ses outils automatiquement.                |
| [Fonctions personnalisées](/fr/docs/agent-api/tools/custom-functions) | Des fonctions que vous contrôlez, déclarées avec un JSON Schema. | La main vous est rendue : vous exécutez l&#39;appel et renvoyez le résultat.  |

<div id="built-in-tools">
  ## Outils intégrés
</div>

Activez chaque outil via son `type`. Chaque outil dispose de sa propre page de référence détaillant l&#39;ensemble des paramètres, la structure de la réponse et la tarification.

| Outil                                                        | `type`           | À utiliser pour                                                                              |
| ------------------------------------------------------------ | ---------------- | -------------------------------------------------------------------------------------------- |
| [Web Search](/fr/docs/agent-api/tools/web-search)               | `web_search`     | Rechercher sur le web en temps réel, avec des filtres de domaine, de date et de localisation |
| [Sandbox](/fr/docs/agent-api/tools/sandbox)                     | `sandbox`        | Exécuter du code dans un conteneur isolé                                                     |
| [Fetch URL Content](/fr/docs/agent-api/tools/fetch-url-content) | `fetch_url`      | Récupérer et extraire le contenu d&#39;URL spécifiques                                       |
| [Finance Search](/fr/docs/agent-api/tools/finance-search)       | `finance_search` | Obtenir des données financières et boursières structurées                                    |
| [People Search](/fr/docs/agent-api/tools/people-search)         | `people_search`  | Trouver des professionnels et des personnes                                                  |
