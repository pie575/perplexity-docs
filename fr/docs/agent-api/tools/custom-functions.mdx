---
title: "Fonctions personnalisées"
description: "Définissez une fonction personnalisée, exécutez dans votre code les appels demandés par le modèle et renvoyez chaque résultat à l'Agent API."
---

Les fonctions personnalisées permettent à un agent d&#39;utiliser du code que vous contrôlez : une requête de base de données, une API interne ou encore de la logique métier. Vous décrivez la fonction dans la requête, mais l&#39;Agent API ne l&#39;exécute jamais à votre place. C&#39;est votre application qui gère l&#39;appel et renvoie le résultat.

    <CodeGroup>
      ```python Python theme={null}
      import json

      from perplexity import Perplexity

      MODEL = "openai/gpt-5.6-sol"
      QUESTION = "What's the status of order ORD-10042?"

      client = Perplexity()

      tools = [
          {
              "type": "function",
              "name": "get_order_status",
              "description": "Look up the current status of an order by its order ID.",
              "parameters": {
                  "type": "object",
                  "properties": {"order_id": {"type": "string"}},
                  "required": ["order_id"],
                  "additionalProperties": False,
              },
              "strict": True,
          }
      ]


      def get_order_status(order_id: str) -> dict[str, str]:
          """Replace this sample data with a database or API call."""
          orders = {
              "ORD-10042": {
                  "status": "in_transit",
                  "carrier": "DHL",
                  "estimated_delivery": "2026-08-08",
              }
          }
          return orders.get(order_id, {"error": "Order not found."})


      # 1. Envoyer la question et les outils disponibles au modèle.
      response = client.responses.create(
          model=MODEL,
          input=QUESTION,
          tools=tools,
      )

      # 2. Ajouter les éléments de sortie du modèle à la conversation.
      next_input = [
          {"type": "message", "role": "user", "content": QUESTION},
          *[item.model_dump(exclude_none=True) for item in response.output],
      ]

      # 3. Exécuter chaque fonction demandée par le modèle, puis ajouter son résultat.
      for item in response.output:
          if item.type != "function_call":
              continue
          if item.name != "get_order_status":
              raise ValueError(f"Unknown function: {item.name}")

          arguments = json.loads(item.arguments)
          result = get_order_status(**arguments)
          next_input.append(
              {
                  "type": "function_call_output",
                  "call_id": item.call_id,
                  "output": json.dumps(result),
              }
          )

      # 4. Renvoyer la conversation mise à jour pour que le modèle puisse répondre.
      final_response = client.responses.create(
          model=MODEL,
          input=next_input,
          tools=tools,
      )

      print(final_response.output_text)
      ```

      ```typescript Typescript theme={null}
      import Perplexity from '@perplexity-ai/perplexity_ai';
      import type { InputItem } from '@perplexity-ai/perplexity_ai/resources/responses/responses';

      const MODEL = 'openai/gpt-5.6-sol';
      const QUESTION = "What's the status of order ORD-10042?";

      const client = new Perplexity();

      const tools = [
        {
          type: 'function' as const,
          name: 'get_order_status',
          description: 'Look up the current status of an order by its order ID.',
          parameters: {
            type: 'object',
            properties: { order_id: { type: 'string' } },
            required: ['order_id'],
            additionalProperties: false,
          },
          strict: true,
        },
      ];

      function getOrderStatus(orderId: string): Record<string, string> {
        // Remplacez ces données d'exemple par un appel à une base de données ou à une API.
        const orders: Record<string, Record<string, string>> = {
          'ORD-10042': {
            status: 'in_transit',
            carrier: 'DHL',
            estimated_delivery: '2026-08-08',
          },
        };
        return orders[orderId] ?? { error: 'Order not found.' };
      }

      // 1. Envoyez la question et les outils disponibles au modèle.
      const response = await client.responses.create({
        model: MODEL,
        input: QUESTION,
        tools,
      });

      // 2. Amorcez la suite de la conversation avec la question d'origine.
      const nextInput: InputItem[] = [
        { type: 'message', role: 'user', content: QUESTION },
      ];

      // 3. Rejouez chaque appel de fonction, exécutez-le en local et ajoutez son résultat.
      for (const item of response.output) {
        if (item.type !== 'function_call') continue;
        nextInput.push({
          type: 'function_call',
          call_id: item.call_id,
          name: item.name,
          arguments: item.arguments,
          ...(item.thought_signature
            ? { thought_signature: item.thought_signature }
            : {}),
        });

        if (item.name !== 'get_order_status') {
          throw new Error(`Unknown function: ${item.name}`);
        }
        const args = JSON.parse(item.arguments) as { order_id: string };
        const result = getOrderStatus(args.order_id);
        nextInput.push({
          type: 'function_call_output',
          call_id: item.call_id,
          output: JSON.stringify(result),
        });
      }

      // 4. Renvoyez la conversation mise à jour pour que le modèle puisse répondre.
      const finalResponse = await client.responses.create({
        model: MODEL,
        input: nextInput,
        tools,
      });

      console.log(finalResponse.output_text);
      ```

<div id="how-the-loop-works">
  ## Fonctionnement de la boucle
</div>

Les deux requêtes à l&#39;Agent API encadrent une seule exécution de fonction locale :

1. **Déclarer et appeler.** Votre première requête contient la question de l&#39;utilisateur ainsi que le schéma de la fonction dans `tools`.
2. **Lire `function_call`.** Le modèle renvoie un élément `function_call` dans `response.output`. Son champ `arguments` est une chaîne JSON : analysez-la avant d&#39;appeler votre code.
3. **Exécuter localement.** Votre application appelle `get_order_status` avec ces arguments. Ce code ne s&#39;exécute pas dans l&#39;Agent API.
4. **Renvoyer `function_call_output`.** Ajoutez les éléments de sortie du modèle ainsi qu&#39;un `function_call_output` contenant le résultat local, puis envoyez une nouvelle requête. Reprenez le `call_id` d&#39;origine pour que le modèle puisse associer le résultat à son appel.
5. **Lire la réponse.** Une fois le résultat de la fonction reçu, le modèle renvoie un `message` d&#39;assistant classique. S&#39;il demande une nouvelle fonction à la place, répétez la même boucle.
