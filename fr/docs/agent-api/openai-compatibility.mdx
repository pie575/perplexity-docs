<div id="overview">
  ## Vue d&#39;ensemble
</div>

L&#39;Agent API de Perplexity est entièrement compatible avec l&#39;interface API Responses d&#39;OpenAI. Vous pouvez conserver vos bibliothèques clientes OpenAI existantes : il suffit de modifier l&#39;URL de base et de fournir votre clé API Perplexity.

<Info>
  **Remarque sur le point de terminaison :** le point de terminaison canonique de l&#39;Agent API de Perplexity est `POST /v1/agent`. Pour la compatibilité avec le SDK OpenAI, `POST /v1/responses` est également accepté comme alias : le SDK OpenAI achemine automatiquement `client.responses.create()` vers `/v1/responses`, que Perplexity traite de façon transparente. Aucune modification du SDK n&#39;est nécessaire, hormis la définition de l&#39;URL de base.
</Info>

<Tip>
  **Nous recommandons d&#39;utiliser le [SDK Perplexity](/fr/docs/sdk/overview)** pour profiter de la meilleure expérience possible : sûreté de typage complète, fonctionnalités avancées et prise en charge des presets. Optez pour les SDK OpenAI si votre intégration est déjà en place et que vous avez besoin d&#39;une compatibilité immédiate.
</Tip>

<div id="agent-api">
  ## Agent API
</div>

L&#39;Agent API de Perplexity reprend le format de requête/réponse de l&#39;API Responses d&#39;OpenAI. La méthode `client.responses.create()` du SDK OpenAI fonctionne sans configuration supplémentaire : le SDK envoie les requêtes à `/v1/responses`, que Perplexity accepte au même titre que le point de terminaison canonique `/v1/agent`.

<div id="basic-usage">
  ### Utilisation de base
</div>

<Tabs>
  <Tab title="Python">
    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    response = client.responses.create(
        model="openai/gpt-5.6-sol",
        input="Explain the key differences between REST and GraphQL APIs"
    )

    print(response.output_text)
    print(f"Response ID: {response.id}")
    ```

  ### Utiliser les presets

Les presets sont des configurations prêtes à l&#39;emploi, optimisées pour des cas d&#39;usage spécifiques. Utilisez `extra_body` pour transmettre un preset via le SDK OpenAI :

<Tabs>
  <Tab title="Python">
    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    # Transmettre le preset via extra_body
    response = client.responses.create(
        input="Compare the design philosophy of Apple's A-series and Qualcomm's Snapdragon mobile SoCs at a high level: CPU and GPU choices and overall system integration.",
        extra_body={
            "preset": "low"
        }
    )

    print(response.output_text)
    ```
  </Tab>

  <Tab title="Typescript">
    ```typescript theme={null}
    import OpenAI from 'openai';

    const client = new OpenAI({

    // Utiliser le transtypage (as any) pour transmettre directement le preset
    const response = await (client.responses.create as any)({

      preset: "low"
    ```

<div id="endpoint-mapping">
  ## Correspondance des points de terminaison
</div>

| Méthode                       | Point de terminaison Perplexity  | Équivalent OpenAI        | Notes                                                                              |
| ----------------------------- | -------------------- | ------------------------ | ---------------------------------------------------------------------------------- |
| `client.responses.create()`   | `POST /v1/agent`     | `POST /v1/responses`     | Les deux chemins sont acceptés par Perplexity pour la compatibilité                |
| `client.responses.retrieve()` | `GET /v1/agent/{id}` | `GET /v1/responses/{id}` | Les deux chemins sont acceptés par Perplexity pour la compatibilité                |
| `client.models.list()`        | `GET /v1/models`     | `GET /v1/models`         | Liste les modèles disponibles de l&#39;Agent API. Aucune authentification requise. |

  Avec le SDK OpenAI, `client.responses.create()` envoie les requêtes vers `/v1/responses`. Perplexity accepte ce chemin comme alias de `/v1/agent` : aucune modification de la configuration du SDK n&#39;est donc nécessaire, hormis `base_url`.
</Info>

<div id="model-discovery">

</div>

Le point de terminaison `GET /v1/models` renvoie tous les modèles disponibles pour l&#39;Agent API, dans un format compatible OpenAI. Aucune authentification n&#39;est requise.

<Tabs>
  <Tab title="Python">
    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    models = client.models.list()
    for model in models.data:
        print(f"{model.id} (owned by {model.owned_by})")
    ```
