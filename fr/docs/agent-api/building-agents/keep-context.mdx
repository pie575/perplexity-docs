---
title: "Conserver le contexte"
description: "Poursuivez une conversation d'un tour à l'autre en la rejouant dans le tableau input, afin qu'une question de suivi tienne compte de ce qui précède."
---

Rejouez vous-même la conversation dans le tableau `input` lorsque vous avez besoin d&#39;un contrôle précis sur le contexte exactement transmis, par exemple pour résumer, expurger, réorganiser ou omettre des tours antérieurs avant la question de suivi. Consultez [Rejouer vous-même les tours de conversation](/fr/docs/agent-api/conversation-state#replay-conversation-turns-yourself) pour le schéma à suivre et des exemples de code.

<div id="storage-backed-continuity">
  ## Continuité assurée par le stockage
</div>

Pour la plupart des conversations multitours, utilisez `previous_response_id` pour reprendre à partir d&#39;une réponse précédente déjà terminée, sans avoir à renvoyer vous-même la conversation. Consultez [État de la conversation](/fr/docs/agent-api/conversation-state) pour le guide complet.
