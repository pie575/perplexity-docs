---
title: "Exécuter du code"
description: "Donnez un sandbox à l'agent pour qu'il calcule des réponses exactes au lieu de les estimer, exécute du vrai code et renvoie les fichiers générés."
---

Les modèles de langage approximent les calculs arithmétiques et les manipulations de données exacts au lieu de les effectuer réellement. L&#39;outil `sandbox` met à disposition de l&#39;agent un conteneur Linux isolé où exécuter du vrai code et réutiliser le résultat dans sa réponse — pour tout ce qui doit être exact : une valeur calculée, un jeu de données transformé ou un rapport généré. Depuis ce conteneur, l&#39;agent peut également appeler les outils [Web Search](/fr/docs/agent-api/tools/web-search), [Fetch URL Content](/fr/docs/agent-api/tools/fetch-url-content) et [People Search](/fr/docs/agent-api/tools/people-search) de Perplexity sans les ajouter à la requête, puis effectuer des calculs sur ce qu&#39;ils renvoient — chacun étant facturé à son tarif standard. La [référence de l&#39;outil Sandbox](/fr/docs/agent-api/tools/sandbox) détaille l&#39;ensemble des paramètres, la structure de la réponse et la tarification.

<div id="enable-the-sandbox">
  ## Activer le sandbox
</div>

Ajoutez `{"type": "sandbox"}` au tableau `tools`. Le model décide quand exécuter du code en fonction de votre prompt.

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()


  def get_output_text(response) -> str:
      return "".join(
          content.text
          for item in response.output or []
          if getattr(item, "type", None) == "message"
          for content in getattr(item, "content", None) or []
          if getattr(content, "type", None) == "output_text"
      )


  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Compute the compound annual growth rate from 4.2M in 2019 to 11.8M in 2025.",
      tools=[{"type": "sandbox"}],
      instructions="Use the sandbox to compute the exact figure before answering.",
  )

  print(get_output_text(response))
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
    model: 'openai/gpt-5.6-sol',
    input: 'Compute the compound annual growth rate from 4.2M in 2019 to 11.8M in 2025.',
    tools: [{ type: 'sandbox' as const }],
    instructions: 'Use the sandbox to compute the exact figure before answering.',
  });

  console.log(response.output_text);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "Compute the compound annual growth rate from 4.2M in 2019 to 11.8M in 2025.",
      "tools": [{ "type": "sandbox" }],
      "instructions": "Use the sandbox to compute the exact figure before answering."
    }' | jq
  ```
</CodeGroup>

<div id="when-to-reach-for-it">
  ## Quand l&#39;utiliser
</div>

* Calculs numériques et analyses statistiques pour lesquels une estimation ne suffit pas
* Nettoyage, analyse et transformation de données
* Exécution de code pour vérifier une logique ou reproduire une erreur
* Génération de fichiers et d&#39;artefacts — CSV, JSON, HTML, rapports ou tout autre fichier produit par le code
* Workflows en plusieurs étapes nécessitant des fichiers intermédiaires ou un état calculé

<Tip>
  Combinez `sandbox` avec `web_search` : l&#39;agent peut alors collecter des données probantes, puis effectuer des calculs dessus au sein du conteneur. Consultez la [référence Sandbox](/fr/docs/agent-api/tools/sandbox) pour savoir comment le sandbox interagit avec les autres outils.
</Tip>

<div id="read-the-computed-result">
  ## Lire le résultat calculé
</div>

Lorsque l&#39;agent exécute du code, le tableau `output` de la réponse contient un ou plusieurs éléments `sandbox_results` en plus du `message`. Chacun comporte le `code` exécuté, le `language` ainsi qu&#39;un tableau `results` avec `stdout`, `stderr`, `exit_code` et `status`. C&#39;est ainsi que vous pouvez vérifier que l&#39;agent a réellement calculé la réponse plutôt que de la deviner. Consultez la [référence de la structure de la réponse](/fr/docs/agent-api/tools/sandbox#response-shape) pour le détail de chaque champ.

Récupérez cet élément dans la réponse (ici, `response` provient de l&#39;exemple [Activer le sandbox](#enable-the-sandbox) ci-dessus) :

```python Python theme={null}
for item in response.output:
    if item.type == "sandbox_results":
        print(item.code)
        print(item.results[0].stdout)
```

Pour cette requête, l&#39;agent a écrit et exécuté ce code Python dans le sandbox, puis a utilisé la valeur affichée dans sa réponse :

<div id="return-files">
  ## Renvoyer des fichiers
</div>

Lorsque du code exécuté dans le sandbox écrit un fichier et le partage, le champ `output` de la réponse contient un élément `share_file`. Les octets ne sont pas inclus directement : listez et téléchargez les fichiers via les points de terminaison de fichiers des réponses, en utilisant l&#39;`id` de la réponse comme clé :

<CodeGroup>
  ```python Python theme={null}
  files = client.responses.files.list(response.id)
  for f in files.data:
      print(f.id, f.filename, f.bytes)

  content = client.responses.files.content(
      file_id=files.data[0].id,
      response_id=response.id,
  )
  content.write_to_file(files.data[0].filename)
  ```

  ```bash cURL theme={null}
  # Lister les fichiers produits par la réponse
  curl https://api.perplexity.ai/v1/agent/$RESPONSE_ID/files \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" | jq

  # Télécharger un fichier via son identifiant
  curl https://api.perplexity.ai/v1/agent/$RESPONSE_ID/files/$FILE_ID/content \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -o output.csv
  ```
</CodeGroup>

<Note>
  Les traitements longs dans le sandbox se prêtent bien aux exécutions en arrière-plan : envoyez la requête avec `background: true`, puis interrogez son statut par identifiant. Consultez [Contrôle des sorties](/fr/docs/agent-api/output-control) et la [référence Sandbox](/fr/docs/agent-api/tools/sandbox#running-in-the-background).
</Note>
