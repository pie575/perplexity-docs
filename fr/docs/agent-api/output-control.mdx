<div id="streaming-responses">
  ## Réponses en streaming
</div>

Le streaming vous permet de recevoir les réponses de la Perplexity API de façon partielle, au fur et à mesure de leur génération, plutôt que d&#39;attendre la réponse complète. C&#39;est particulièrement utile pour les expériences utilisateur en temps réel, les réponses longues et les applications interactives.

<Info>
  Le streaming est pris en charge par tous les modèles disponibles via l&#39;Agent API.
</Info>

Pour activer le streaming, définissez `stream=True` (Python) ou `stream: true` (TypeScript) lors de la création des réponses :

<CodeGroup>
  ```python Python SDK theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  # Créer une réponse en streaming
  stream = client.responses.create(
      preset="fast",
      input="Explain what a model card is in the context of large language models: the typical sections (intended use, training data, limitations, evaluation).",
      stream=True
  )

  # Traiter la réponse en streaming
  for event in stream:
      if event.type == "response.output_text.delta":
          print(event.delta, end="")
      elif event.type == "response.completed":
          print(f"\n\nCompleted: {event.response.usage}")
  ```

  ```typescript TypeScript SDK theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  // Créer une réponse en streaming
  const stream = await client.responses.create({
    preset: "fast",
    input: "Explain what a model card is in the context of large language models: the typical sections (intended use, training data, limitations, evaluation).",
    stream: true
  });

  // Traiter la réponse en streaming
  for await (const chunk of stream) {
    if (chunk.type === "response.output_text.delta") {
      process.stdout.write((chunk as any).delta);
    }
  }
  ```

  ```bash cURL theme={null}
      "preset": "fast",

      "stream": true
    }'
  ```

<div id="structured-outputs">
  ## Sorties structurées
</div>

Les sorties structurées vous permettent d&#39;imposer des formats de réponse précis aux modèles de Perplexity, garantissant des données cohérentes et lisibles par une machine, directement intégrables à vos applications sans analyse manuelle.

Nous prenons actuellement en charge les sorties structurées au format **JSON Schema**. Pour les activer, ajoutez un champ `response_format` à votre requête :

```json theme={null}
{
  "response_format": {
    "type": "json_schema",
    "json_schema": {
      "name": "your_schema_name",
      "schema": { /* votre objet JSON Schema */ }
    }
  }
}
```

Le champ `name` est obligatoire et doit contenir de 1 à 64 caractères alphanumériques. Le schéma doit être un objet JSON Schema valide. Les réponses du LLM respecteront le format spécifié, sauf si la sortie dépasse `max_tokens`.

Les propriétés listées dans le tableau `required` du schéma sont obligatoires dans la sortie. Toute propriété déclarée mais absente de `required` reste facultative et peut être résolue en `null` JSON. Si `required` est omis ou vide, toutes les propriétés déclarées sont facultatives. Ce comportement est identique pour les requêtes en streaming et hors streaming, aussi bien sur `/v1/agent` que sur son alias de compatibilité `/v1/responses`.

<Tip>
  **Améliorer la conformité au schéma** : donnez au LLM des indications sur le format de sortie dans vos prompts afin de renforcer le respect du format structuré. Par exemple, incluez des formulations telles que « Veuillez retourner les données sous forme d&#39;objet JSON avec la structure suivante... » ou « Extrayez les informations et formatez-les comme spécifié dans le schéma. »
</Tip>

<Info>
  La première requête utilisant un nouveau JSON Schema est susceptible d&#39;entraîner un délai sur le premier token. La préparation du nouveau schéma prend généralement de 10 à 30 secondes et peut provoquer des erreurs de dépassement de délai. Une fois le schéma préparé, les requêtes suivantes ne subissent plus ce délai.
</Info>
