<div id="available-models">
  ## Modèles disponibles
</div>

L&#39;Agent API prend en charge l&#39;accès direct aux modèles de plusieurs fournisseurs. Tous les modèles sont accessibles directement auprès des fournisseurs d&#39;origine, avec une tarification transparente basée sur les tokens.

Les tarifs sont mis à jour chaque mois et **reflètent la tarification directe des fournisseurs d&#39;origine, sans marge**. Tous les frais reposent sur la consommation réelle de tokens, et chaque réponse de l&#39;API inclut le décompte exact des tokens, afin que vous connaissiez vos coûts pour chaque requête.

<Tip>
  Vous cherchez des configurations de modèles prêtes à l&#39;emploi ? Consultez les [**presets**](/fr/docs/agent-api/presets) — optimisés pour des cas d&#39;usage spécifiques.
</Tip>

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Explique la différence entre l'apprentissage supervisé et l'apprentissage non supervisé en apprentissage automatique.",
      max_output_tokens=300,
  )

  print(f"Response ID: {response.id}")
  print(response.output_text)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      model: "openai/gpt-5.6-sol",
      input: "Explique la différence entre l'apprentissage supervisé et l'apprentissage non supervisé en apprentissage automatique.",
      max_output_tokens: 300,
  });

  console.log(`Response ID: ${response.id}`);
  console.log(response.output_text);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "Explique la différence entre l'\''apprentissage supervisé et l'\''apprentissage non supervisé en apprentissage automatique.",
      "max_output_tokens": 300
    }' | jq
  ```
</CodeGroup>

<div id="model-fallback">
  ## Bascule de modèle
</div>

Pour les applications à haute disponibilité, vous pouvez spécifier plusieurs modèles dans une chaîne de bascule. Lorsqu&#39;un modèle échoue ou est indisponible, l&#39;API essaie automatiquement le modèle suivant dans la chaîne.

<Card title="Chaîne de bascule de modèles" icon="square-rounded-arrow-down" href="/fr/docs/agent-api/model-fallback">
  Découvrez comment utiliser les chaînes de bascule de modèles pour garantir une haute disponibilité et une grande fiabilité en essayant automatiquement plusieurs modèles lorsque l&#39;un d&#39;eux échoue.
</Card>

<Info>
  **Exemple :**

  ```python theme={null}
  response = client.responses.create(
      models=["openai/gpt-5.6-sol", "anthropic/claude-sonnet-4-6", "google/gemini-3-flash-preview"],
      input="Your question here",
      max_output_tokens=8192,
  )
  ```

  Pour des exemples détaillés, des informations tarifaires et les bonnes pratiques, consultez la [documentation sur la bascule de modèles](/fr/docs/agent-api/model-fallback).
</Info>
