D&#39;après les benchmarks que nous réalisons, les presets de l&#39;Agent API offrent un meilleur rapport qualité-prix que Sonar : la courbe des presets se situe au-dessus de celle de tous les modèles Sonar.
L&#39;écart est le plus marqué sur les tâches complexes et multi-étapes comme BrowseComp et WideSearch, où le preset le plus performant fait plus que doubler le meilleur score de Sonar.

<div id="what-we-measured">
  ## Ce que nous avons mesuré
</div>

Nous avons évalué les presets de l&#39;Agent API et les modèles Sonar sur les mêmes charges de travail, à travers trois benchmarks :

* **[BrowseComp](https://arxiv.org/abs/2504.12516)** mesure la navigation agentique sur des questions difficiles qui nécessitent d&#39;enchaîner de nombreuses recherches.
* **[DSQA (DeepSearchQA)](https://arxiv.org/abs/2601.20975)** mesure la qualité des réponses à des questions de recherche approfondie.
* **[WideSearch](https://arxiv.org/abs/2508.07999)** mesure l&#39;exhaustivité avec laquelle une exécution collecte et renseigne des résultats structurés, évaluée par un score F1 au niveau des lignes.

Les presets de l&#39;Agent API parviennent même à égaler le meilleur modèle Sonar, Deep Research, pour une fraction du coût.

<div id="which-preset-should-you-use">
  ## Quel preset choisir ?
</div>

Les résultats varient selon le cas d&#39;usage, mais chaque preset se situe plus haut sur la courbe de qualité que son équivalent Sonar — et, dans le palier deep research, pour moins cher.
Utilisez la correspondance ci-dessous comme point de départ, puis validez-la sur votre propre trafic.

| Sonar Chat Completions | preset de l’Agent API | Idéal pour                                                                                                       | Ce qui s&#39;améliore                                                                                                                                            |
| ---------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sonar                  | `fast`           | Recherches de faits ponctuels, définitions, résumés rapides.                                                     | Plus précis que Sonar, avec des gains particulièrement nets sur les questions de recherche multi-étapes.                                                  |
| Sonar Pro              | `low`            | Questions de recherche du quotidien, recherches légères multi-étapes nécessitant des informations à jour. | Bien plus précis, et donne accès à la véritable recherche agentique multi-étapes, hors de portée de Sonar Pro.                                            |
| Sonar Reasoning Pro    | `medium`         | Navigation multi-sauts et agrégation large sur de nombreuses sources.                                            | Nettement plus solide sur le raisonnement étape par étape et sur le chaînage d&#39;indices sur plusieurs cycles de recherche.                                    |
| Sonar Deep Research    | `high`           | Raisonnement de niveau expert et couverture exhaustive des sources.                                              | Le palier le plus précis sur les travaux exigeants de niveau expert et de deep research, souvent à un coût par requête inférieur à celui de Sonar Deep Research. |

<Tip>
  Pour de la deep research à l&#39;état de l&#39;art, utilisez le preset `xhigh` — la meilleure qualité de la gamme, en tête sur l&#39;ensemble des benchmarks que nous exécutons.
</Tip>
