<div id="why-use-the-agent-api">
  ## Pourquoi utiliser l&#39;Agent API ?
</div>

<CardGroup cols={2}>
  <Card title="Réponses ancrées dans le web" icon="globe">
    Obtenez des réponses précises et à jour, ancrées dans une recherche web en temps réel, avec des citations en ligne en un seul appel et un contexte conversationnel conservé d&#39;un tour à l&#39;autre.
  </Card>

  <Card title="Accès multi-fournisseurs" icon="stack-3" iconType="solid">
    Accédez à OpenAI, Anthropic, Google, xAI et bien d&#39;autres via une seule API unifiée, sans avoir à gérer plusieurs clés API.
  </Card>

  <Card title="Tarification transparente" icon="receipt">
    Consultez le nombre exact de tokens et le coût de chaque requête, sans majoration : uniquement le tarif direct du fournisseur.
  </Card>

  <Card title="Contrôle granulaire" icon="adjustments">
    Modifiez le modèle, le raisonnement, les tokens et les outils avec une syntaxe cohérente.
  </Card>
</CardGroup>

<Info>
  Nous recommandons d&#39;utiliser nos [SDK officiels](/fr/docs/sdk/overview) pour interagir avec l&#39;Agent API de façon plus pratique et avec un typage sûr.
</Info>

<Note>
  **Point de terminaison :** l&#39;Agent API est disponible à l&#39;adresse `POST https://api.perplexity.ai/v1/agent`. Pour la compatibilité avec le SDK OpenAI, `POST /v1/responses` est également accepté comme alias. Consultez le [guide de compatibilité OpenAI](/fr/docs/agent-api/openai-compatibility) pour savoir comment utiliser les SDK OpenAI avec Perplexity.
</Note>

<div id="installation">
  ## Installation
</div>

Installez le SDK correspondant au langage de votre choix :

<CodeGroup>
  ```bash Python theme={null}
  pip install perplexityai
  ```

  ```bash Typescript theme={null}
  npm install @perplexity-ai/perplexity_ai
  ```
</CodeGroup>

<div id="authentication">
  ## Authentification
</div>

Définissez votre clé API dans une variable d&#39;environnement. Le SDK la lira automatiquement :

<Tabs>
  <Tab title="macOS/Linux">
    ```bash theme={null}
    export PERPLEXITY_API_KEY="your_api_key_here"
    ```
  </Tab>

  <Tab title="Windows">
    ```powershell theme={null}
    setx PERPLEXITY_API_KEY "your_api_key_here"
    ```
  </Tab>
</Tabs>

<Info>
  Tous les exemples de SDK ci-dessous utilisent automatiquement la variable d&#39;environnement `PERPLEXITY_API_KEY`. Vous pouvez aussi passer la clé explicitement si nécessaire.
</Info>

<div id="basic-usage">
  ## Utilisation de base
</div>

<Tip>
  **Propriété pratique :** les SDK Python et TypeScript fournissent tous deux une propriété `output_text` qui regroupe l&#39;ensemble du contenu textuel des sorties de la réponse. Au lieu de parcourir `response.output`, utilisez simplement `response.output_text` pour un code plus lisible.
</Tip>

<div id="using-a-third-party-model">
  ### Utiliser un modèle tiers
</div>

Utilisez des modèles tiers d&#39;OpenAI, Anthropic, Google, xAI et d&#39;autres fournisseurs pour des capacités spécifiques :

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Explain the difference between supervised and unsupervised learning in machine learning."
  )

  print(f"Response ID: {response.id}")
  print(response.output_text)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      model: "openai/gpt-5.6-sol",
      input: "Explain the difference between supervised and unsupervised learning in machine learning."
  });

  console.log(`Response ID: ${response.id}`);
  console.log(response.output_text);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "Explain the difference between supervised and unsupervised learning in machine learning."
    }' | jq
  ```
</CodeGroup>

<div id="using-a-preset">
  ### Utiliser un preset
</div>

Les presets fournissent des valeurs par défaut optimisées pour des cas d&#39;usage spécifiques.

Commencez par un preset pour une configuration rapide :

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      preset="low",
      input="Explain what the MMLU benchmark measures for large language models, and how the Apache 2.0 license differs from a restricted research-only license for model weights.",
  )

  print(f"Model used: {response.model}")
  print(response.output_text)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      preset: "low",
      input: "Explain what the MMLU benchmark measures for large language models, and how the Apache 2.0 license differs from a restricted research-only license for model weights.",
  });

  console.log(`Model used: ${response.model}`);
  console.log(response.output_text);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "preset": "low",
      "input": "Explain what the MMLU benchmark measures for large language models, and how the Apache 2.0 license differs from a restricted research-only license for model weights."
    }' | jq
  ```
</CodeGroup>

<div id="with-web-search">
  ### Avec la recherche web
</div>

L&#39;Agent API donne accès à un ensemble d&#39;outils permettant d&#39;étendre les capacités du modèle.

Activez les fonctionnalités de recherche web à l&#39;aide de l&#39;outil `web_search` :

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Explain the original Transformer architecture from 'Attention Is All You Need' (Vaswani et al. 2017): encoder-decoder structure, multi-head self-attention, and positional encodings.",
      tools=[{"type": "web_search"}],
      instructions="You have access to a web_search tool. Use it for questions about current events, news, or recent developments. Use 1 query for simple questions. Keep queries brief: 2-5 words. NEVER ask permission to search - just search when appropriate",
  )

  if response.status == "completed":
      print(response.output_text)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      model: "openai/gpt-5.6-sol",
      input: "Explain the original Transformer architecture from 'Attention Is All You Need' (Vaswani et al. 2017): encoder-decoder structure, multi-head self-attention, and positional encodings.",
      tools: [{ type: "web_search" }],
      instructions: "You have access to a web_search tool. Use it for questions about current events, news, or recent developments.",
  });

  if (response.status === "completed") {
      console.log(response.output_text);
  }
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    --data @- <<'JSON' | jq
  {
      "model": "openai/gpt-5.6-sol",

      "tools": [{"type": "web_search"}],

  ```
