<div id="overview">
  ## Vue d&#39;ensemble
</div>

Les exécutions d&#39;agent peuvent produire des fichiers tels que des CSV, JSON, JSONL et des rapports dans le sandbox. Lorsque le code exécuté par le model dans l&#39;outil `sandbox` écrit un fichier et le transmet via l&#39;outil `share_file`, le tableau `output` de la réponse contient un élément `share_file`. Le contenu du fichier n&#39;est pas renvoyé directement dans la réponse : récupérez-le séparément via les points de terminaison de fichiers de réponse, en utilisant l&#39;`id` de la réponse.

<div id="produce-a-file">
  ## Produire un fichier
</div>

Donnez à l&#39;agent l&#39;outil `sandbox` et demandez-lui d&#39;écrire un fichier. Ici, il génère un CSV des dernières actualités sur l&#39;IA. Conservez le `response.id` obtenu : il vous servira à lister et télécharger le fichier.

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      preset="xhigh",
      tools=[{"type": "sandbox"}],
      input=(
          "Find the 10 latest AI news stories and write them to ai_news.csv "
          "with columns: title, source, url, published_date. Deliver the file."
      ),
  )

  print(response.id, response.status)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
    preset: 'xhigh',
    tools: [{ type: 'sandbox' }],
    input:
      'Find the 10 latest AI news stories and write them to ai_news.csv ' +
      'with columns: title, source, url, published_date. Deliver the file.',
  });

  console.log(response.id, response.status);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "preset": "xhigh",
      "tools": [{ "type": "sandbox" }],
      "input": "Find the 10 latest AI news stories and write them to ai_news.csv with columns: title, source, url, published_date. Deliver the file."
    }'
  ```
</CodeGroup>

<Note>
  Pour les exécutions longues, envoyez la requête avec `background=true` et interrogez son état avant de lister les fichiers. Voir [Mode arrière-plan](/fr/docs/agent-api/background-mode).
</Note>

<div id="list-a-responses-files">
  ## Lister les fichiers d&#39;une réponse
</div>

`GET /v1/agent/{id}/files`

Utilisez l&#39;`id` de réponse de l&#39;exécution ci-dessus pour lister les fichiers qu&#39;elle a produits.

<CodeGroup>
  ```python Python theme={null}
  files = client.responses.files.list(response.id)

  for file in files.data:
      print(file.id, file.filename, file.bytes)
  ```

  ```typescript Typescript theme={null}
  const files = await client.responses.files.list(response.id);

  for (const file of files.data) {
    console.log(file.id, file.filename, file.bytes);
  }
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent/$RESPONSE_ID/files \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY"
  ```
</CodeGroup>

```json theme={null}
{
  "data": [
    {
      "bytes": 8002,
      "created_at": 1780923289,
      "filename": "ai_news.csv",
      "id": "9198548a-490b-4119-858f-fd3676b60319",
      "object": "file"
    }
  ],
  "object": "list"
}
```

| Champ        | Type      | Description                                                                                           |
| ------------ | --------- | ----------------------------------------------------------------------------------------------------- |
| `id`         | `string`  | Identifiant du fichier, utilisé pour le téléchargement ; distinct de l&#39;identifiant de la réponse. |
| `filename`   | `string`  | Nom attribué au fichier par le sandbox.                                                               |
| `bytes`      | `integer` | Taille du fichier en octets.                                                                          |
| `created_at` | `integer` | Horodatage Unix de la création.                                                                       |
| `object`     | `string`  | Toujours `file`.                                                                                      |

<div id="download-a-file">
  ## Télécharger un fichier
</div>

`GET /v1/agent/{id}/files/{file_id}/content`

Utilisez l&#39;`id` du fichier pour en télécharger le contenu. L&#39;`id` du fichier est distinct de l&#39;`id` de la réponse.

<Note>
  Ce point de terminaison renvoie les octets bruts du fichier, et non du JSON. La réponse comporte un `Content-Type` correspondant au fichier ainsi qu&#39;un en-tête `Content-Disposition: attachment` indiquant le nom de fichier d&#39;origine.
</Note>

<CodeGroup>
  ```python Python theme={null}
  file = files.data[0]

  content = client.responses.files.content(
      file_id=file.id,
      response_id=response.id,
  )
  content.write_to_file(file.filename)
  ```

  ```typescript Typescript theme={null}
  import { writeFile } from 'node:fs/promises';

  const file = files.data[0];

  const content = await client.responses.files.content(file.id, {
    response_id: response.id,
  });
  await writeFile(file.filename, Buffer.from(await content.arrayBuffer()));
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent/$RESPONSE_ID/files/$FILE_ID/content \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -o ai_news.csv
  ```
</CodeGroup>

<div id="full-example">
  ## Exemple complet
</div>

Créez une exécution qui écrit un fichier, puis listez et téléchargez tout ce qu&#39;elle a produit.

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      preset="xhigh",
      tools=[{"type": "sandbox"}],
      input=(
          "Find the 10 latest AI news stories and write them to ai_news.csv "
          "with columns: title, source, url, published_date. Deliver the file."
      ),
  )

  for file in client.responses.files.list(response.id).data:
      content = client.responses.files.content(
          file_id=file.id,
          response_id=response.id,
      )
      content.write_to_file(file.filename)
      print(f"Downloaded {file.filename} ({file.bytes} bytes)")
  ```

  ```typescript Typescript theme={null}
  import { writeFile } from 'node:fs/promises';
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
    preset: 'xhigh',
    tools: [{ type: 'sandbox' }],
    input:
      'Find the 10 latest AI news stories and write them to ai_news.csv ' +
      'with columns: title, source, url, published_date. Deliver the file.',
  });

  const files = await client.responses.files.list(response.id);

  for (const file of files.data) {
    const content = await client.responses.files.content(file.id, {
      response_id: response.id,
    });
    await writeFile(file.filename, Buffer.from(await content.arrayBuffer()));
    console.log(`Downloaded ${file.filename} (${file.bytes} bytes)`);
  }
  ```
</CodeGroup>
