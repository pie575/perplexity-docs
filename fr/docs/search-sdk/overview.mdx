<div id="search-as-code">
  ## La recherche en tant que code
</div>

La recherche traditionnelle traite la récupération d&#39;information comme un bloc monolithique : un modèle émet une requête, le moteur de recherche exécute un pipeline prédéfini, puis le modèle consomme les résultats traités. Ce contrat atteint ses limites pour des agents confrontés à des tâches complexes et ouvertes — il produit un contexte grossier, gaspille les connaissances métier du modèle et fait passer par une interface séquentielle un travail naturellement parallèle.

[Search as Code](https://research.perplexity.ai/articles/rethinking-search-as-code-generation) est la réponse de Perplexity : exposer la pile de recherche sous forme de primitives composables que les agents orchestrent au moyen de code généré. L&#39;agent contrôle directement la récupération, le classement, le filtrage, la diffusion parallèle et le rendu, conserve l&#39;état intermédiaire dans le runtime plutôt que dans le contexte du modèle, et ne consomme que les informations utiles.

Le SDK Perplexity Search apporte cette approche à vos propres agents et applications. Il expose les résultats web classés en temps réel de la [Search API](/fr/docs/search/quickstart) ainsi que les extraits de pages pertinents pour la requête sous forme de primitives Python, avec concurrence, traçabilité de la provenance et points de reprise intégrés pour les workflows à forte intensité de récupération.

<div id="built-for-agents">
  ## Conçu pour les agents
</div>

Ce SDK adopte une approche « agents d&#39;abord » : il est pensé pour être piloté par des agents de codage, et non pour être appris dans une documentation rédigée. La référence d&#39;utilisation canonique est l&#39;Agent Skill du SDK, qui couvre l&#39;installation, l&#39;authentification, l&#39;ensemble des méthodes disponibles, les schémas de workflow et les pièges connus :

<Card title="Agent Skill pplx-search-sdk" icon="github" horizontal="true" arrow="true" href="https://github.com/perplexityai/api-platform-developers/tree/main/skills/pplx-search-sdk">
  Installez cette skill dans votre agent de codage et laissez-le écrire l&#39;intégration.
</Card>

Le code source se trouve sur [perplexityai/perplexity-search-sdk](https://github.com/perplexityai/perplexity-search-sdk), et le paquet est publié sur PyPI sous le nom [pplx-srch-sdk](https://pypi.org/project/pplx-srch-sdk/).
