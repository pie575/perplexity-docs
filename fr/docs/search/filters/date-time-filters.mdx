title: "Filtres de date et d'heure de recherche"
---

<Note>
  Les paramètres `search_after_date_filter` et `search_before_date_filter` permettent de restreindre les résultats de recherche à une plage de dates de publication précise. Seuls les résultats dont la date de publication est comprise entre ces deux dates sont renvoyés.

  Les paramètres `last_updated_after_filter` et `last_updated_before_filter` permettent de filtrer selon la date de dernière modification ou de mise à jour du contenu, plutôt que selon sa date de publication initiale.

  Le paramètre `search_recency_filter` offre un moyen pratique de filtrer les résultats sur des périodes prédéfinies (par exemple `hour`, `day`, `week`, `month`, `year`) par rapport à la date du jour.
</Note>

<Info>
  Les filtres de date spécifiques doivent être fournis au format `%m/%d/%Y` (par exemple `3/1/2025`). Les filtres de récence acceptent des valeurs prédéfinies telles que `hour`, `day`, `week`, `month` ou `year`. Tous les filtres sont facultatifs : vous pouvez indiquer, selon vos besoins, soit des dates précises, soit des filtres de récence.
</Info>

<div id="overview">
  ## Vue d&#39;ensemble
</div>

Les filtres de date et d&#39;heure de la Search API vous permettent de contrôler les résultats de recherche renvoyés en les limitant à des périodes précises. Trois types de filtres de date et d&#39;heure sont disponibles :

<div id="publication-date-filters">
  ### Filtres de date de publication
</div>

Les paramètres `search_after_date_filter` et `search_before_date_filter` filtrent les résultats selon la date à laquelle le contenu a été **initialement créé ou publié**. C&#39;est utile lorsque vous devez :

* Trouver du contenu publié sur une période donnée
* Exclure les publications obsolètes ou trop récentes
* Vous concentrer sur le contenu d&#39;une période de publication précise

<div id="last-updated-date-filters">
  ### Filtres de date de dernière mise à jour
</div>

Les paramètres `last_updated_after_filter` et `last_updated_before_filter` filtrent les résultats selon la date de **dernière modification ou mise à jour** du contenu. C&#39;est utile lorsque vous devez :

* Trouver du contenu récemment mis à jour ou régulièrement entretenu
* Exclure le contenu obsolète qui n&#39;a pas été mis à jour récemment
* Vous concentrer sur le contenu actualisé au cours d&#39;une période donnée

<div id="search-recency-filter">
  ### Filtre de récence de recherche
</div>

Le paramètre `search_recency_filter` offre un moyen simple de filtrer les résultats selon des périodes prédéfinies relatives à la date actuelle. C&#39;est utile lorsque vous devez :

* Trouver du contenu publié au cours de la dernière heure, des dernières 24 heures, de la dernière semaine, du dernier mois ou de la dernière année
* Obtenir des résultats récents sans spécifier de dates précises
* Filtrer rapidement les informations d&#39;actualité

**Valeurs disponibles :**

* `"hour"` - Contenu de la dernière heure. À utiliser pour les données en temps réel, comme les actualités de dernière minute ou les événements en direct.
* `"day"` - Contenu des dernières 24 heures
* `"week"` - Contenu des 7 derniers jours
* `"month"` - Contenu des 30 derniers jours
* `"year"` - Contenu des 365 derniers jours

**Important :** les filtres de publication s&#39;appuient sur la date de création/publication d&#39;origine, les filtres de dernière mise à jour sur la date de modification, tandis que les filtres de récence utilisent une période relative à la date actuelle.

Pour restreindre les résultats de recherche selon la date de publication :

```bash theme={null}
"search_after_date_filter": "3/1/2025",
"search_before_date_filter": "3/5/2025"
```

Pour restreindre les résultats de recherche en fonction de la date de dernière mise à jour :

```bash theme={null}
"last_updated_after_filter": "07/01/2025",
"last_updated_before_filter": "12/30/2025"
```

Pour limiter les résultats de recherche selon leur ancienneté :

```bash theme={null}
"search_recency_filter": "week"
```

Ces filtres s&#39;appliquent en complément des autres paramètres de recherche.

  ```python Python theme={null}
  from perplexity import Perplexity

      max_results=10,
  ```

<div id="best-practices">
  ## Bonnes pratiques
</div>

**Format de date**

* Format strict : les dates doivent respecter exactement le format « %m/%d/%Y ». Par exemple, « 3/1/2025 » ou « 03/01/2025 » sont acceptés.
* Cohérence : utilisez un seul ou les deux filtres de date, de manière cohérente, selon vos besoins de recherche. En combinant les deux, vous délimitez clairement une plage.

**Choix du filtre**

* Choisissez le bon type de filtre : utilisez les filtres de date de publication (`search_after_date_filter`/`search_before_date_filter`) lorsque c&#39;est la date de création initiale du contenu qui compte. Utilisez les filtres de dernière mise à jour (`last_updated_after_filter`/`last_updated_before_filter`) lorsque vous avez besoin de contenu tenu à jour récemment. Utilisez les filtres de récence (`search_recency_filter`) pour un filtrage temporel relatif et rapide.
* Récence ou dates exactes : utilisez `search_recency_filter` par commodité lorsque vous souhaitez du contenu récent (par exemple, « la semaine passée »). Utilisez des filtres de date spécifiques lorsque vous avez besoin d&#39;un contrôle précis sur la plage temporelle.
* Combinaison de filtres : vous pouvez utiliser conjointement les filtres de publication et de dernière mise à jour pour trouver du contenu répondant aux deux critères (par exemple, publié en 2024 mais mis à jour récemment). Notez que `search_recency_filter` ne peut pas être combiné avec des filtres de date spécifiques (`search_after_date_filter`/`search_before_date_filter` ou `last_updated_after_filter`/`last_updated_before_filter`).

**Validation côté client**

* Vérification par expression régulière : validez les chaînes de date côté client à l&#39;aide d&#39;une expression régulière telle que :

<CodeGroup>
  ```bash theme={null}
  date_regex='^(0?[1-9]|1[0-2])/(0?[1-9]|[12][0-9]|3[01])/[0-9]{4}$'
  ```

  ```python theme={null}
  date_regex = r'^(0?[1-9]|1[0-2])/(0?[1-9]|[12]\d|3[01])/\d{4}$'
  ```
</CodeGroup>

Cela garantit que les dates sont conformes au format requis avant l&#39;envoi de la requête.

**Considérations de performance**

* Restreindre la recherche : l&#39;application de filtres de plage de dates réduit généralement le nombre de résultats, ce qui peut améliorer les temps de réponse et la pertinence des résultats.
* Évitez les restrictions excessives : assurez-vous que la plage de dates n&#39;est ni trop étroite (ce qui limiterait les résultats utiles) ni trop large (ce qui priverait le filtre de son intérêt).

Lorsque vous utilisez des filtres de date, veillez à bien gérer les erreurs liées aux formats de date invalides :

  ```python Python theme={null}
  from perplexity import Perplexity
  import re

  def validate_date_format(date_string):
      pattern = r'^(0?[1-9]|1[0-2])/(0?[1-9]|[12]\d|3[01])/\d{4}$'
      return bool(re.match(pattern, date_string))

  def search_with_date_filter(query, after_date=None, before_date=None):
      client = Perplexity()
      
      # Valider les formats de date
      if after_date and not validate_date_format(after_date):
          raise ValueError(f"Invalid date format: {after_date}")
      if before_date and not validate_date_format(before_date):
          raise ValueError(f"Invalid date format: {before_date}")
      
      try:
          response = client.search(
              query=query,
              search_after_date_filter=after_date,
              search_before_date_filter=before_date
          )
          return response
      except Exception as e:
          print(f"Search failed: {e}")
          return None
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  function validateDateFormat(dateString: string): boolean {
    const pattern = /^(0?[1-9]|1[0-2])\/(0?[1-9]|[12]\d|3[01])\/\d{4}$/;
    return pattern.test(dateString);
  }

  async function searchWithDateFilter(
    query: string, 
    afterDate?: string, 
    beforeDate?: string
  ) {
    const client = new Perplexity();
    
    // Valider les formats de date
    if (afterDate && !validateDateFormat(afterDate)) {
      throw new Error(`Invalid date format: ${afterDate}`);
    }
    if (beforeDate && !validateDateFormat(beforeDate)) {
      throw new Error(`Invalid date format: ${beforeDate}`);
    }
    
    try {
      const response = await client.search.create({
        query,
        search_after_date_filter: afterDate,
        search_before_date_filter: beforeDate
      });
      return response;
    } catch (error) {
      console.error('Search failed:', error);
      return null;
    }
  }
  ```
