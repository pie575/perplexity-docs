<div id="overview">
  ## Vue d&#39;ensemble
</div>

Les SDK Perplexity offrent une gestion robuste des erreurs, avec des types d&#39;exceptions spécifiques selon les scénarios d&#39;erreur. Ce guide explique comment intercepter et traiter proprement les erreurs d&#39;API les plus courantes.

<div id="common-error-types">
  ## Types d&#39;erreurs courants
</div>

Les SDK fournissent des types d&#39;exception spécifiques selon les scénarios d&#39;erreur :

* **APIConnectionError** – Problèmes de connexion réseau
* **RateLimitError** – Limite de débit de l&#39;API dépassée
* **APIStatusError** – Erreurs de statut HTTP (4xx, 5xx)
* **AuthenticationError** – API key invalide ou problèmes d&#39;authentification
* **ValidationError** – Paramètres de requête invalides

<div id="basic-error-handling">
  ## Gestion basique des erreurs
</div>

Gérez les erreurs d&#39;API courantes avec des blocs try-catch :

<CodeGroup>
  ```python Python theme={null}
  import perplexity
  from perplexity import Perplexity

  client = Perplexity()

  try:
      search = client.search.create(query="OpenAI o-series reasoning model benchmarks")
      print(search.results)
  except perplexity.APIConnectionError as e:
      print("Échec de la connexion réseau")
      print(e.__cause__)
  except perplexity.RateLimitError as e:
      print("Limite de débit dépassée, veuillez réessayer plus tard")
  except perplexity.APIStatusError as e:
      print(f"Erreur d'API : {e.status_code}")
      print(e.response)
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  try {
      const search = await client.search.create({ query: "OpenAI o-series reasoning model benchmarks" });
      console.log(search.results);
  } catch (error: any) {
      if (error.constructor.name === 'APIConnectionError') {
          console.log("Échec de la connexion réseau");
          console.log(error.cause);
      } else if (error.constructor.name === 'RateLimitError') {
          console.log("Limite de débit dépassée, veuillez réessayer plus tard");
      } else if (error.constructor.name === 'APIStatusError') {
          console.log(`Erreur d'API : ${error.status}`);
          console.log(error.response);
      }
  }
  ```
</CodeGroup>

<div id="exponential-backoff-for-rate-limits">
  ### Backoff exponentiel pour les limites de débit
</div>

Implémentez une logique de nouvelle tentative intelligente pour les erreurs de limite de débit :

<CodeGroup>
  ```python Python theme={null}
  import time
  import random
  import perplexity
  from perplexity import Perplexity

  def search_with_retry(client, query, max_retries=3):
      for attempt in range(max_retries):
          try:
              return client.search.create(query=query)
          except perplexity.RateLimitError:
              if attempt == max_retries - 1:
                  raise  # Relancer l'exception à la dernière tentative
              
              # Backoff exponentiel avec jitter
              delay = (2 ** attempt) + random.uniform(0, 1)
              print(f"Rate limited. Retrying in {delay:.2f} seconds...")
              time.sleep(delay)
          except perplexity.APIConnectionError:
              if attempt == max_retries - 1:
                  raise
              
              # Délai plus court pour les erreurs de connexion
              delay = 1 + random.uniform(0, 1)
              print(f"Connection error. Retrying in {delay:.2f} seconds...")
              time.sleep(delay)

  # Utilisation
  client = Perplexity()
  result = search_with_retry(client, "artificial intelligence")
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  async function searchWithRetry(
      client: Perplexity, 
      query: string, 
      maxRetries: number = 3
  ) {
      for (let attempt = 0; attempt < maxRetries; attempt++) {
          try {
              return await client.search.create({ query });
          } catch (error: any) {
              if (attempt === maxRetries - 1) {
                  throw error; // Relancer l'erreur à la dernière tentative
              }

              if (error.constructor.name === 'RateLimitError') {
                  // Backoff exponentiel avec jitter
                  const delay = (2 ** attempt + Math.random()) * 1000;
                  console.log(`Rate limited. Retrying in ${delay}ms...`);
                  await new Promise(resolve => setTimeout(resolve, delay));
              } else if (error.constructor.name === 'APIConnectionError') {
                  // Délai plus court pour les erreurs de connexion
                  const delay = (1 + Math.random()) * 1000;
                  console.log(`Connection error. Retrying in ${delay}ms...`);
                  await new Promise(resolve => setTimeout(resolve, delay));
              } else {
                  throw error; // Ne pas réessayer pour les autres erreurs
              }
          }
      }
  }

  // Utilisation
  const client = new Perplexity();
  const result = await searchWithRetry(client, "artificial intelligence");
  ```
</CodeGroup>

<div id="error-context-and-debugging">
  ### Contexte d&#39;erreur et débogage
</div>

Extrayez des informations d&#39;erreur détaillées pour le débogage :

<CodeGroup>
  ```python Python theme={null}
  import perplexity
  from perplexity import Perplexity

  client = Perplexity()

  try:
      response = client.responses.create(
          preset="low",
          input="Explain how the 10-year US Treasury yield is determined and how it influences mortgage rates."
      )
  except perplexity.APIStatusError as e:
      print(f"Status Code: {e.status_code}")
      print(f"Error Type: {e.type}")
      print(f"Error Message: {e.message}")
      
      # Accéder à la réponse brute pour un débogage détaillé
      if hasattr(e, 'response'):
          print(f"Raw Response: {e.response.text}")
          print(f"Request ID: {e.response.headers.get('X-Request-ID')}")
          
  except perplexity.ValidationError as e:
      print(f"Validation Error: {e}")
      # Gérer les erreurs de validation des paramètres
      
  except Exception as e:
      print(f"Unexpected error: {type(e).__name__}: {e}")
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  try {
      const response = await client.responses.create({

      if (error.constructor.name === 'APIStatusError') {
          console.log(`Status Code: ${error.status}`);
          console.log(`Error Type: ${error.type}`);
          console.log(`Error Message: ${error.message}`);
          
          // Accéder à la réponse brute pour un débogage détaillé

              console.log(`Raw Response: ${await error.response.text()}`);

          }
      } else if (error.constructor.name === 'ValidationError') {
          console.log(`Validation Error: ${error.message}`);
          // Gérer les erreurs de validation des paramètres
      } else {
          console.log(`Unexpected error: ${error.constructor.name}: ${error.message}`);
      }
  }
  ```

<div id="graceful-degradation">
  ### Dégradation progressive
</div>

Mettez en place des mécanismes de repli en cas d&#39;échec des appels API :

<CodeGroup>
  ```python Python theme={null}
  import perplexity
  from perplexity import Perplexity

  def get_ai_response(query, fallback_response="I'm sorry, I'm temporarily unavailable."):
      client = Perplexity()
      
      try:
          response = client.responses.create(
              preset="low",
              input=query
          )
          return response.output_text
          
      except perplexity.RateLimitError:
          return fallback_response
              
      except perplexity.APIConnectionError:
          # Problèmes réseau - renvoyer une réponse en cache ou de repli
          return fallback_response
          
      except Exception as e:
          print(f"Unexpected error: {e}")
          return fallback_response

  # Utilisation
  response = get_ai_response("What is machine learning?")
  print(response)
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  async function getAIResponse(
      query: string, 
      fallbackResponse: string = "I'm sorry, I'm temporarily unavailable."
  ): Promise<string> {
      const client = new Perplexity();
      
      try {
          const response = await client.responses.create({
              preset: "low",
              input: query
          });
          return response.output_text ?? fallbackResponse;
          
      } catch (error: any) {
          if (error.constructor.name === 'RateLimitError') {
              return fallbackResponse;
          } else if (error.constructor.name === 'APIConnectionError') {
              // Problèmes réseau - renvoyer une réponse en cache ou de repli
              return fallbackResponse;
          } else {
              console.log(`Unexpected error: ${error.message}`);
              return fallbackResponse;
          }
      }
  }

  // Utilisation
  const response = await getAIResponse("What is machine learning?");
  console.log(response);
  ```
</CodeGroup>

  ## Bonnes pratiques

<Steps>
  <Step title="Gérez toujours les limites de requêtes">
    La limitation de débit est fréquente lors de l&#39;utilisation d&#39;une API. Implémentez toujours une logique de nouvelle tentative avec backoff exponentiel.

    <Warning>
      N&#39;implémentez pas de boucles de nouvelles tentatives agressives sans délai : cela peut aggraver la limitation de débit.
    </Warning>
  </Step>

  <Step title="Consignez les erreurs à des fins de surveillance">
    Mettez en place une journalisation adaptée pour suivre les tendances d&#39;erreurs et l&#39;état de santé de l&#39;API.

    <CodeGroup>
      ```python Python theme={null}
      import logging
      import perplexity
      from perplexity import Perplexity

      logging.basicConfig(level=logging.INFO)
      logger = logging.getLogger(__name__)

      client = Perplexity()

      try:
          result = client.search.create(query="discovery of penicillin by Alexander Fleming")
      except perplexity.APIStatusError as e:
          logger.error(f"API Error {e.status_code}: {e.message}", 
                      extra={'request_id': e.response.headers.get('X-Request-ID')})
      ```

      ```typescript TypeScript theme={null}
      import Perplexity from '@perplexity-ai/perplexity_ai';

      const client = new Perplexity();

      try {
          const result = await client.search.create({ query: "discovery of penicillin by Alexander Fleming" });
      } catch (error: any) {
          console.error(`API Error ${error.status}: ${error.message}`, {
              requestId: error.response?.headers.get('X-Request-ID')
          });
      }
      ```
