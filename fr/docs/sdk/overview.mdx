<div id="overview">
  ## Vue d&#39;ensemble
</div>

Les SDK officiels de Perplexity offrent un accès simplifié aux API Perplexity depuis des applications Python 3.8+ et Node.js. Les deux SDK fournissent les définitions de types de tous les paramètres de requête et champs de réponse, ainsi que des clients synchrones et asynchrones.

Accédez à quatre API : l&#39;**Agent API** pour les modèles tiers avec outils de recherche web et presets, **Search** pour des résultats de recherche web classés, **Sonar** pour des réponses d&#39;IA ancrées dans le web, et **Embeddings** pour générer des embeddings de texte.

<div id="installation">
  ## Installation
</div>

Installez le SDK du langage de votre choix :

<CodeGroup>
  ```bash Python theme={null}
  pip install perplexityai
  ```

  ```bash TypeScript theme={null}
  npm install @perplexity-ai/perplexity_ai
  ```
</CodeGroup>

<div id="authentication">
  ## Authentification
</div>

<Card title="Obtenez votre clé API Perplexity" icon="key" arrow="True" horizontal="True" iconType="solid" cta="Cliquez ici" href="https://console.perplexity.ai/project/keys">
  Générez une nouvelle clé depuis la page **API Keys** de l&#39;API Console.
</Card>

Une fois la clé générée, définissez-la comme variable d&#39;environnement dans votre terminal :

<Tabs>
  <Tab title="Windows">
    ```bash theme={null}
    setx PERPLEXITY_API_KEY "your_api_key_here"
    ```
  </Tab>

  <Tab title="MacOS/Linux">
    ```bash theme={null}
    export PERPLEXITY_API_KEY="your_api_key_here"
    ```
  </Tab>
</Tabs>

<div id="using-environment-variables">
  ### Utiliser les variables d&#39;environnement
</div>

Vous pouvez utiliser directement la variable d&#39;environnement :

<CodeGroup>
  ```python Python theme={null}
  import os
  from perplexity import Perplexity

  client = Perplexity() # Utilise automatiquement PERPLEXITY_API_KEY
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity({
    apiKey: process.env['PERPLEXITY_API_KEY'], // Valeur par défaut, peut être omise
  });
  ```
</CodeGroup>

Vous pouvez aussi utiliser [python-dotenv](https://pypi.org/project/python-dotenv/) (Python) ou [dotenv](https://www.npmjs.com/package/dotenv) (Node.js) pour charger la variable d&#39;environnement depuis un fichier `.env` :

<CodeGroup>
  ```python Python theme={null}
  import os
  from dotenv import load_dotenv
  from perplexity import Perplexity

  load_dotenv()

  client = Perplexity() # Utilise PERPLEXITY_API_KEY depuis le fichier .env
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';
  import dotenv from 'dotenv';

  dotenv.config();

  const client = new Perplexity(); // Utilise PERPLEXITY_API_KEY depuis le fichier .env
  ```
</CodeGroup>
