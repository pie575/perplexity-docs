<div id="overview">
  ## Vue d&#39;ensemble
</div>

Les SDK Perplexity offrent plusieurs fonctionnalités permettant d&#39;optimiser les performances des applications à haut débit. Ce guide couvre les opérations asynchrones, le pool de connexions, l&#39;accès aux réponses brutes et d&#39;autres techniques d&#39;optimisation des performances.

<div id="async-support">
  ## Prise en charge de l&#39;asynchrone
</div>

<div id="basic-async-usage">
  ### Utilisation asynchrone de base
</div>

Pour les applications devant traiter plusieurs requêtes en parallèle :

<CodeGroup>
  ```bash Python Installation theme={null}
  pip install perplexityai httpx-aiohttp
  ```

  ```bash TypeScript Installation theme={null}
  npm install @perplexity-ai/perplexity_ai
  # La prise en charge de l'asynchrone est native en TypeScript
  ```
</CodeGroup>

<CodeGroup>
  ```python Python theme={null}
  import asyncio
  from perplexity import AsyncPerplexity, DefaultAioHttpClient

  async def main():
      async with AsyncPerplexity(
          http_client=DefaultAioHttpClient()
      ) as client:
          # Requête asynchrone unique
          search = await client.search.create(query="OpenAI o-series reasoning model benchmarks")
          print(search.results)

  asyncio.run(main())
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  async function main() {
      const client = new Perplexity();
      
      // L'asynchrone est natif en TypeScript
      const search = await client.search.create({ query: "OpenAI o-series reasoning model benchmarks" });
      console.log(search.results);
  }

  main();
  ```

<div id="concurrent-requests">
  ### Requêtes concurrentes
</div>

Traitez plusieurs requêtes simultanément pour améliorer le débit :

<CodeGroup>
  ```python Python theme={null}
  import asyncio
  from perplexity import AsyncPerplexity, DefaultAioHttpClient

  async def concurrent_searches():
      async with AsyncPerplexity(
          http_client=DefaultAioHttpClient()
      ) as client:
          # Requêtes concurrentes
          queries = ["AI", "machine learning", "deep learning", "neural networks"]
          tasks = [
              client.search.create(query=query)
              for query in queries
          ]
          
          results = await asyncio.gather(*tasks)
          
          for i, result in enumerate(results):
              print(f"Query '{queries[i]}': {len(result.results)} results")

  asyncio.run(concurrent_searches())
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  async function concurrentSearches() {
      const client = new Perplexity();
      
      // Requêtes concurrentes
      const queries = ["AI", "machine learning", "deep learning", "neural networks"];
      const tasks = queries.map(query => 
          client.search.create({ query })
      );
      
      const results = await Promise.all(tasks);
      
      results.forEach((result, i) => {
          console.log(`Query '${queries[i]}': ${result.results.length} results`);
      });
  }

  concurrentSearches();
  ```
</CodeGroup>

<div id="batch-processing-with-rate-limiting">
  ### Traitement par lots avec limitation de débit
</div>

Traitez un grand nombre de requêtes tout en respectant les limites de débit :

<CodeGroup>
  ```python Python theme={null}
  import asyncio
  from perplexity import AsyncPerplexity, DefaultAioHttpClient

  async def batch_process_with_limit(queries, batch_size=5, delay=1.0):
      async with AsyncPerplexity(
          http_client=DefaultAioHttpClient()
      ) as client:
          results = []
          
          for i in range(0, len(queries), batch_size):
              batch = queries[i:i + batch_size]
              
              # Traiter le lot en parallèle
              tasks = [
                  client.search.create(query=query)
                  for query in batch
              ]
              
              batch_results = await asyncio.gather(*tasks, return_exceptions=True)
              results.extend(batch_results)
              
              # Délai entre les lots pour respecter les limites de débit
              if i + batch_size < len(queries):
                  await asyncio.sleep(delay)
          
          return results

  # Utilisation
  queries = [f"query {i}" for i in range(20)]
  results = asyncio.run(batch_process_with_limit(queries))
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  async function batchProcessWithLimit(
      queries: string[], 
      batchSize: number = 5, 
      delay: number = 1000
  ) {
      const client = new Perplexity();
      const results = [];
      
      for (let i = 0; i < queries.length; i += batchSize) {
          const batch = queries.slice(i, i + batchSize);
          
          // Traiter le lot en parallèle
          const tasks = batch.map(query => 
              client.search.create({ query }).catch(error => error)
          );
          
          const batchResults = await Promise.all(tasks);
          results.push(...batchResults);
          
          // Délai entre les lots pour respecter les limites de débit
          if (i + batchSize < queries.length) {
              await new Promise(resolve => setTimeout(resolve, delay));
          }
      }
      
      return results;
  }

  // Utilisation
  const queries = Array.from({ length: 20 }, (_, i) => `query ${i}`);
  const results = await batchProcessWithLimit(queries);
  ```
</CodeGroup>

<div id="raw-response-access">
  ## Accès à la réponse brute
</div>

Accédez aux en-têtes, aux codes de statut et aux données brutes de la réponse pour les cas d&#39;usage avancés :

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  # Récupérer la réponse brute avec les en-têtes
  response = client.search.with_raw_response.create(
      query="OpenAI o-series reasoning model benchmarks"
  )

  print(f"Status Code: {response.status_code}")
  print(f"Request ID: {response.headers.get('X-Request-ID')}")
  print(f"Rate Limit Remaining: {response.headers.get('X-RateLimit-Remaining')}")
  print(f"Rate Limit Reset: {response.headers.get('X-RateLimit-Reset')}")

  # Analyser les résultats de recherche proprement dits
  search = response.parse()
  print(f"Found {len(search.results)} results")
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  // Récupérer la réponse brute avec les en-têtes
  const { data: search, response: rawResponse } = await client.search
      .create({ query: "OpenAI o-series reasoning model benchmarks" })
      .withResponse();

  console.log(`Status Code: ${rawResponse.status}`);
  console.log(`Request ID: ${rawResponse.headers.get('X-Request-ID')}`);
  console.log(`Rate Limit Remaining: ${rawResponse.headers.get('X-RateLimit-Remaining')}`);
  console.log(`Rate Limit Reset: ${rawResponse.headers.get('X-RateLimit-Reset')}`);
  console.log(`Found ${search.results.length} results`);
  ```
</CodeGroup>

<div id="request-timing-and-metrics">
  ### Chronométrage des requêtes et métriques
</div>

Surveillez les métriques de performance pour identifier les goulots d&#39;étranglement :

<CodeGroup>
  ```python Python theme={null}
  import time
  import asyncio
  from perplexity import AsyncPerplexity, DefaultAioHttpClient

  class PerformanceMonitor:
      def __init__(self):
          self.request_times = []
          self.error_count = 0
          
      async def timed_request(self, client, query):
          start_time = time.time()
          try:
              result = await client.search.create(query=query)
              duration = time.time() - start_time
              self.request_times.append(duration)
              return result
          except Exception as e:
              self.error_count += 1
              raise e
      
      def get_stats(self):
          if not self.request_times:
              return {"error": "No successful requests"}
          
          return {
              "total_requests": len(self.request_times),
              "error_count": self.error_count,
              "avg_response_time": sum(self.request_times) / len(self.request_times),
              "min_response_time": min(self.request_times),
              "max_response_time": max(self.request_times)
          }

  async def run_performance_test():
      monitor = PerformanceMonitor()
      
      async with AsyncPerplexity(
          http_client=DefaultAioHttpClient()
      ) as client:
          queries = [f"test query {i}" for i in range(10)]
          
          tasks = [
              monitor.timed_request(client, query)
              for query in queries
          ]
          
          await asyncio.gather(*tasks, return_exceptions=True)
          
      print(monitor.get_stats())

  asyncio.run(run_performance_test())
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  class PerformanceMonitor {
      private requestTimes: number[] = [];
      private errorCount: number = 0;
      
      async timedRequest(client: Perplexity, query: string) {
          const startTime = performance.now();
          try {
              const result = await client.search.create({ query });
              const duration = performance.now() - startTime;
              this.requestTimes.push(duration);
              return result;
          } catch (error) {
              this.errorCount++;
              throw error;
          }
      }
      
      getStats() {
          if (this.requestTimes.length === 0) {
              return { error: "No successful requests" };
          }
          
          return {
              totalRequests: this.requestTimes.length,
              errorCount: this.errorCount,
              avgResponseTime: this.requestTimes.reduce((a, b) => a + b, 0) / this.requestTimes.length,
              minResponseTime: Math.min(...this.requestTimes),
              maxResponseTime: Math.max(...this.requestTimes)
          };
      }
  }

  async function runPerformanceTest() {
      const monitor = new PerformanceMonitor();
      const client = new Perplexity();
      
      const queries = Array.from({ length: 10 }, (_, i) => `test query ${i}`);
      
      const tasks = queries.map(query => 
          monitor.timedRequest(client, query).catch(error => error)
      );
      
      await Promise.all(tasks);
      
      console.log(monitor.getStats());
  }

  runPerformanceTest();
  ```

<div id="efficient-data-processing">
  ### Traitement efficace des données
</div>

Traitez efficacement de grands jeux de données grâce au streaming et à la pagination :

<CodeGroup>
  ```python Python theme={null}
  import asyncio
  from perplexity import AsyncPerplexity, DefaultAioHttpClient

  async def process_large_dataset(queries, process_fn):
      """Traiter les requêtes par lots pour maîtriser l'utilisation de la mémoire"""
      
      async with AsyncPerplexity(
          http_client=DefaultAioHttpClient()
      ) as client:
          
          async def process_single(query):
              try:
                  result = await client.search.create(query=query)
                  # Traiter immédiatement pour éviter de conserver en mémoire
                  processed = process_fn(result)
                  # Libérer le résultat d'origine de la mémoire
                  del result
                  return processed
              except Exception as e:
                  return f"Error processing {query}: {e}"
          
          # Traiter par petits lots
          batch_size = 5
          for i in range(0, len(queries), batch_size):
              batch = queries[i:i + batch_size]
              
              # Traiter le lot
              tasks = [process_single(query) for query in batch]
              batch_results = await asyncio.gather(*tasks)
              
              # Renvoyer les résultats au lieu de les accumuler
              for result in batch_results:
                  yield result
              
              # Optionnel : court délai pour ne pas saturer l'API
              await asyncio.sleep(0.1)

  # Utilisation
  async def summarize_result(search_result):
      """Fonction de traitement qui extrait uniquement ce dont nous avons besoin"""
      return {
          "query": search_result.query,
          "result_count": len(search_result.results),
          "top_title": search_result.results[0].title if search_result.results else None
      }

  async def main():
      queries = [f"query {i}" for i in range(100)]
      
      async for processed_result in process_large_dataset(queries, summarize_result):
          print(processed_result)

  asyncio.run(main())
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  async function* processLargeDataset<T>(
      queries: string[], 
      processFn: (result: any) => T
  ): AsyncGenerator<T | string> {
      const client = new Perplexity();
      
      async function processSingle(query: string): Promise<T | string> {
          try {
              const result = await client.search.create({ query });
              // Traiter immédiatement pour éviter de conserver en mémoire
              const processed = processFn(result);
              return processed;
          } catch (error) {
              return `Error processing ${query}: ${error}`;
          }
      }
      
      // Traiter par petits lots
      const batchSize = 5;
      for (let i = 0; i < queries.length; i += batchSize) {
          const batch = queries.slice(i, i + batchSize);
          
          // Traiter le lot
          const tasks = batch.map(query => processSingle(query));
          const batchResults = await Promise.all(tasks);
          
          // Renvoyer les résultats au lieu de les accumuler
          for (const result of batchResults) {
              yield result;
          }
          
          // Optionnel : court délai pour ne pas saturer l'API
          await new Promise(resolve => setTimeout(resolve, 100));
      }
  }

  // Utilisation
  function summarizeResult(searchResult: any) {
      return {
          query: searchResult.query,
          resultCount: searchResult.results.length,
          topTitle: searchResult.results[0]?.title || null
      };
  }

  async function main() {
      const queries = Array.from({ length: 100 }, (_, i) => `query ${i}`);
      
      for await (const processedResult of processLargeDataset(queries, summarizeResult)) {
          console.log(processedResult);
      }
  }

  main();
  ```
</CodeGroup>

<Steps>
  <Step title="Utiliser l'asynchrone pour les opérations concurrentes">
    Utilisez toujours des clients asynchrones lorsque vous devez traiter plusieurs requêtes simultanément.

    <Tip>
      Pour les traitements gourmands en CPU après les appels d&#39;API, envisagez d&#39;utiliser des threads ou des processus de travail.
    </Tip>
  </Step>

  <Step title="Mettre en place un pool de connexions">
    Configurez des limites de connexion adaptées aux besoins de votre application.

    <CodeGroup>
      ```python Python theme={null}
      # Bien : optimisé pour votre cas d'usage
      limits = httpx.Limits(
          max_keepalive_connections=20,  # Selon la concurrence attendue
          max_connections=50,
          keepalive_expiry=30.0
      )
      ```

      ```typescript TypeScript theme={null}
      // Bien : optimisé pour votre cas d'usage
      const agent = new https.Agent({
          keepAlive: true,
          maxSockets: 20,  // Selon la concurrence attendue
          keepAliveMsecs: 30000
      });
      ```
    </CodeGroup>
  </Step>

  <Step title="Surveiller et ajuster les performances">
    Utilisez des métriques pour identifier les goulots d&#39;étranglement et optimiser en conséquence.

    <Warning>
      N&#39;optimisez pas prématurément : mesurez d&#39;abord, puis optimisez en vous appuyant sur des données de performance réelles.
    </Warning>
  </Step>

  <Step title="Gérer la contre-pression">
    Mettez en place une limitation de débit et une gestion de la contre-pression appropriées pour les applications à haut débit.

      ```python Python theme={null}
      # Utilisez des sémaphores pour limiter les requêtes concurrentes
      semaphore = asyncio.Semaphore(10)  # 10 requêtes concurrentes maximum

      async def rate_limited_request(client, query):
          async with semaphore:
              return await client.search.create(query=query)
      ```

      ```typescript TypeScript theme={null}
      // Utilisez une file d'attente ou une bibliothèque de limitation
      import pLimit from 'p-limit';

      const limit = pLimit(10);  // 10 requêtes concurrentes maximum

      const rateLimitedRequest = (client: Perplexity, query: string) =>
          limit(() => client.search.create({ query }));
      ```
