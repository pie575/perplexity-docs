<div id="data-privacy-retention">
  ## データプライバシーとデータ保持
</div>

<div id="zero-data-retention-policy">
  ### ゼロデータ保持ポリシー
</div>

Perplexity は、Chat Completions API について厳格な **ゼロデータ保持ポリシー** を適用しています。Chat Completions API を通じて送信されたデータを保持することはなく、お客様のデータをモデルの学習に使用したり、当該リクエストの処理以外の目的に使用したりすることもありません。

<div id="data-we-collect">
  ### 当社が収集するデータ
</div>

Chat Completions API を通じて当社が収集するデータは、サービス運用に必要な課金関連の基本指標のみです。

* 処理された token 数
* 各リクエストで使用された モデル
* リクエストのタイムスタンプと所要時間
* API key の識別情報 (課金目的) 

この課金メタデータには、プロンプトや応答の内容、その他のユーザーデータは一切含まれません。
