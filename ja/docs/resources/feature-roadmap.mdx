<div id="upcoming-and-in-progress">
  ## 予定・進行中の項目
</div>

<AccordionGroup>
  <Accordion title="Sandbox API" description="隔離された Python および Bash 実行環境">
    PythonおよびBashコードを実行するための隔離環境を提供するSandbox APIを導入します。各sandboxは専用リソースを備えた独立したコンテナで動作し、ファイル操作、バックグラウンドプロセス、pause/resumeによる状態の永続化に対応します。

    * より強固な隔離を実現する**sandboxごとの専用コンテナ**
    * ファイル操作とプロセスに対応した**PythonおよびBashの実行**
    * 反復的なワークフローに役立つ**pause/resumeによる状態の永続化**
  </Accordion>

  <Accordion title="Chat Completions のパフォーマンス改善" description="既存エンドポイントのレイテンシ低減">
    互換性を維持しながら、パフォーマンス改善を順次展開しています。

    * 後方互換性を備えた**同一のエンドポイント仕様**
    * 一般的なリクエストパターンにおける**レイテンシの改善**
    * ほとんどのユーザーで移行作業が不要な**自動展開**
  </Accordion>

  <Accordion title="動画アップロード機能" description="マルチモーダル動画処理">
    マルチモーダル対応を拡張し、動画の直接アップロードにも対応する予定です。

    * アップロードされたファイルの**動画コンテンツ解析**
    * 特定の時点に関するインサイトを得るための**フレーム単位の推論**
    * 長尺メディア全体にわたる**視覚的なシーン理解**
    * テキスト・画像・動画のコンテキストを横断する**マルチモーダル検索**
  </Accordion>

  <Accordion title="ファイル検索とコネクター" description="データアクセスの拡張">
    現在、API 組織向けに、ファイルおよびデータソースへのさらに踏み込んだアクセス機能を開発中です。

    * 組織データ全体を対象とした**リポジトリおよびコネクター検索**
    * 一般的なドキュメント形式に対応する**マルチフォーマット対応**
    * エンタープライズワークフロー向けの**外部データソース連携**
  </Accordion>

  <Accordion title="非同期APIのWebhook対応" description="イベント駆動の完了通知">
    非同期ワークフロー向けのWebhookコールバックを追加し、長時間実行されるジョブが自動的にお客様のシステムへ通知できるようにする予定です。

    * 非同期リクエスト向けの**ジョブ完了Webhook**
    * リトライしても安全な配信セマンティクスを備えた**失敗通知Webhook**
    * 安全なコールバック処理のための**署名検証**
  </Accordion>

  <Accordion title="モデルとSDKの拡充" description="新たなモデル対応とSDKの使いやすさ">
    今後も対応モデルの拡充とSDKの使いやすさの向上に取り組んでいきます。

    * **新しいモデルのリリース**とライフサイクルの明確化
    * PythonおよびTypeScript向け**SDKの利便性向上**
    * 一般的な統合パターンを対象とした**本番運用に適したサンプルの拡充**
  </Accordion>

  <Accordion title="コンテキスト管理とメモリ" description="呼び出し間のコンテキスト処理を改善">
    メモリ指向のワークフローを改善し、コンテキスト永続化の制約に対応しています。

    * **セッションを認識した状態管理**
    * リクエスト間での**手動によるコンテキスト連結の削減**
    * **長時間にわたる対話型ワークフローの制御性の向上**
  </Accordion>

  <Accordion title="エラーハンドリングの改善" description="トラブルシューティングと復旧の明確化">
    API 全体で、エラーの報告方法と診断方法を改善しています。

    * **より具体的な対応につながるエラーメッセージ**
    * **ドキュメントにおける対処方法の解説の強化**
    * **リトライとバックオフに関するより明確な推奨事項**
  </Accordion>

  <Accordion title="音声間 API" description="リアルタイム音声インタラクション">
    リアルタイムな体験を実現する、音声ネイティブなインタラクション機能を開発中です。

    * **音声の直接入力とストリーミング音声出力**
    * **多言語サポート**
    * **低遅延の会話ループ**
  </Accordion>

  <Accordion title="専用APIコンソール" description="Perplexity アプリとは独立した開発者コンソール">
    現在、専用のAPIコンソールを開発中です。これはPerplexityのWebサイトとは切り離された、開発者向けの独立したインターフェースです。API keyの管理、使用状況の把握、チーム管理を行う中心的な拠点となります。

    * **Perplexityアプリから独立** — API開発者のために専用設計
    * **API keyの管理** — きめ細かな権限設定とローテーションに対応
    * **使用状況とコストの可視化** — キー単位およびチーム単位で確認可能
    * **組織向けの管理機能** — チームのアクセス権と共同作業を制御
  </Accordion>

  <Accordion title="開発者向け分析ダッシュボード" description="運用に関する利用状況の分析情報">
    API チーム向けに分析データの可視性を拡張しています。

    * **クエリおよびレイテンシの分析**
    * **エラー傾向のモニタリング**
    * **コストと使用量の予測**
  </Accordion>

  <Accordion title="金融ツールの統合" description="財務データと分析">
    より充実した構造化アクセスにより、金融リサーチ機能を拡張しています。

    * **市場および提出書類のワークフロー**
    * **金融領域に特化した検索の制御機能の強化**
    * **アナリストのユースケース向けのエンドツーエンドの実例の拡充**
  </Accordion>

  <Accordion title="ドキュメントの刷新" description="より充実したドキュメントとガイド">
    ドキュメントの改善は現在も進行中です。

    * **より分かりやすいAPI選定ガイド**
    * **より踏み込んだ実装ガイド**
    * **より実践的で本番運用を想定したサンプル**
  </Accordion>

  <Accordion title="API 経由の Labs 機能" description="実験的機能">
    一部の実験的機能を開発者プレビューとして提供していく予定です。

    * **早期アクセス向けの機能チャネル**
    * **フィードバック収集用のプロトタイプ連携**
    * **ロードマップ策定に向けた、より迅速な開発者フィードバックループ**
  </Accordion>
</AccordionGroup>
