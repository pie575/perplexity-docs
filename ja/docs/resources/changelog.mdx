<Update label="August 2026" tags={["Agent API", "Presets"]}>
  **preset のプロンプトキャッシュ**

  Agent API の preset で、安定したプロンプトキャッシュキーが自動的に使用されるようになりました。これにより、同じ preset を使用する独立したリクエスト間で、共通のプロンプト接頭部 (system prompt とツール定義) を再利用できます。リクエスト側の変更は不要で、`prompt_cache_key` を明示的に指定した場合は従来どおり preset の既定値を上書きします。preset を頻繁に使用するアプリケーションでは、キャッシュの利用状況に応じてコストを約5%削減できます。[現在の preset の値](/ja/docs/agent-api/presets#current-preset-values)には、固定した設定の場合に使用する各キーも記載しています。
</Update>

<Update label="August 2026" tags={["Agent API", "Presets"]}>
  **fast preset の更新**

  Agent API の `fast` preset は、`openai/gpt-5.6-luna` を `minimal` の推論の努力度および優先処理で使用するようになりました。動的な `fast` preset のリクエストには、この変更が自動的に反映されます。[固定した設定](/ja/docs/agent-api/presets#current-preset-values)している場合は、モデルと推論の努力度を更新し、`service_tier` を `priority` に設定してください。優先処理では、モデルの標準 token 価格の2倍が適用されます。
</Update>

<Update label="July 2026" tags={["Router", "Features"]}>
  **新機能: Router API**

  Perplexity がホストするオープンウェイトモデルに、単一のエンドポイントから統一的にアクセスできます。既存の Perplexity API key をそのまま利用できます。

  **主な機能:**

  * OpenAI Chat Completions および Anthropic Messages との互換性: 切り替えはベース URL の変更のみ
  * モデルのデプロイ全体にわたるヘルス状況に基づく自動ルーティングとフェイルオーバー
  * 各モデルの公開レートによる token 単位の料金設定、リクエストごとの追加費用なし

  [Router API を使ってみる →](/ja/docs/router/quickstart)
</Update>

<Update label="July 2026" tags={["Agent API", "Presets"]}>
  **リサーチ向け preset のインライン引用**

  Agent API の検索対応 preset にはインライン引用が含まれます。`fast` は検索結果に基づく主張を `[1]` のような番号付き引用で示し、`low`、`medium`、`high` はツール結果や提供されたソース成果物に基づく主張を `[web:1]` のようなソース種別付き引用で示すようになりました。ツール呼び出しが成功した場合、`low`、`medium`、`high` の各 preset は最終回答に少なくとも 1 件の引用を含めます。[現在の preset の値](/ja/docs/agent-api/presets#current-preset-values)には、固定した設定向けの system prompt も記載しています。
</Update>

<Update label="July 2026" tags={["MCP", "Agent API"]}>
  **MCP Server 1.0: Agent API を基盤に**

  [Perplexity MCP サーバー](/ja/docs/getting-started/integrations/mcp-server) v1.0.0 では、モデルを利用するツールの基盤をレガシーの Sonar モデルから [Agent API の preset](/ja/docs/agent-api/presets) に移行しました。`perplexity_ask` は `fast` preset、`perplexity_reason` は `medium`、`perplexity_research` は `high` を使用します。ツール名とレスポンス形式に変更はなく、3 つのツールはいずれも従来の Sonar ベースの実装より平均して高速かつ低コストです。長時間実行されるリサーチでは、要求した MCP クライアントに対して進捗がストリーミングされ、MCP リクエストをキャンセルすると基盤の実行もキャンセルされます。

  `strip_thinking` および `reasoning_effort` パラメータはツールスキーマから削除されました (Agent API は think タグを出力せず、推論の努力度は preset が管理します) 。これらを送信し続けるクライアントに対しても、エラーとせず無視します。
</Update>

<Update label="May 2026" tags={["Agent API", "Tools", "Finance"]}>
  **Finance Search: 提供開始**

  `finance_search` ツールが Agent API で利用可能になりました。上場企業や金融商品について、株価、財務諸表、決算、アナリスト予想、セグメント別KPI、ETF構成銘柄などの構造化された金融・市場データを取得できます。プロンプトに応じてモデルが取得するフィールドを判断するため、1回の呼び出しでバリュエーション、決算、関連情報をまとめて取得できます。

  **主なポイント:**

  * **株価と価格情報**: ほぼリアルタイムの価格、OHLCVレンジ、時間外・夜間取引データ
  * **財務データ**: 損益計算書、貸借対照表、キャッシュフロー (四半期・通期) 、主要指標
  * **決算**: 直近の決算説明会トランスクリプト、提出書類、予想比の実績推移、ガイダンス
  * **カバレッジと市場動向**: アナリスト予想、値上がり・値下がり上位、保有状況とコーポレートアクション
  * **推奨構成**: リアルタイム株価、単一企業の過去データ照会、複数企業にまたがる多段階リサーチ向けのpreset

  まずはこちらから: [Finance Search](/ja/docs/agent-api/tools/finance-search)
</Update>

<Update label="April 2026" tags={["Integrations", "AWS", "Models", "Billing", "Security"]}>
  **Agent API: サードパーティモデルを追加**

  Agent API が Claude Opus 4.7、GPT-5.5、Grok 4.20 Reasoning に対応しました。ツール呼び出し、構造化出力、フォールバックチェーンで選べるモデルの幅が広がります。全一覧は [Agent API モデルリファレンス](/ja/docs/agent-api/models)をご覧ください。

  **API key の管理: セキュリティ強化**

  API key の管理をワンタイム表示方式にアップグレードしました。tokenの完全な値は**作成時に一度だけ**返され、コンソールやいずれのエンドポイントからも再取得できません。これにより認証情報が漏洩した際の影響範囲を大幅に抑え、業界のベストプラクティスに沿った運用が可能になります。作成後もkeyを識別できるよう、必ずわかりやすい `token_name` を設定し、定期的にローテーションしてください。

  まずはこちらから: [API key の管理](/ja/docs/admin/api-key-management)

  **新しい連携: n8n**

  n8n にネイティブの Perplexity ノードが追加され、Chat Completions、Agent、Search、Embeddings のすべてをビジュアルキャンバス上から設定できるようになりました。モデルは API から動的に読み込まれるため、ドロップダウンには常に最新の選択肢が反映されます。

  まずはこちらから: [n8n 連携ガイド](/ja/docs/getting-started/integrations/n8n)

  **新しい連携: OpenClaw**

  オープンソースのターミナル AI エージェント OpenClaw が、ネイティブのWeb検索プロバイダーとして Search API に対応しました。API key を一度設定するだけで、構造化された検索結果 (`title`、`url`、`snippet`) をターミナルのワークフロー内で直接利用できます。

  まずはこちらから: [OpenClaw 連携ガイド](/ja/docs/getting-started/integrations/openclaw)

  **API クレジットが AWS Marketplace で購入可能に**

  Perplexity API プラットフォームが AWS Marketplace の SaaS リスティングとして提供開始されました。AWS アカウント経由で API クレジットを購入すれば、請求を一本化でき、調達プロセスも簡素化されるうえ、個別のベンダー契約も不要です。

  まずはこちらから: [AWS Marketplace](/ja/docs/resources/aws-marketplace)

  **`/v1/models` エンドポイント**

  新しい `GET /v1/models` エンドポイントは、利用可能なすべての Agent API モデルを OpenAI 互換フォーマットで一覧表示します。認証は不要で、連携における動的なモデル選択に役立ちます。
</Update>

<Update label="December 2025" tags={["Models", "Deprecation", "Search"]}>
  **モデルの廃止: `sonar-reasoning` を削除**

  2025年12月15日をもって、`sonar-reasoning` モデルは廃止され、API から削除されました。このモデルをご利用だった場合は、ウェブ検索を伴う多段階推論機能が強化された `sonar-reasoning-pro` への移行を推奨します。

  **新機能: 視覚コンテンツを賢く扱う Media Classifier**

  **Media Classifier** の提供を開始しました。視覚コンテンツがあると効果的なクエリを自動的に検出し、関連する画像や動画を応答に含めるインテリジェントな仕組みです。

  **主な機能:**

  * **自動検出**: クエリを分析し、視覚コンテンツが有効な場面を特定します
  * **最適なメディア選択**: クエリの種類に応じて、画像・動画・その両方を賢く選択します
  * **コンテキスト認識**: 教育コンテンツ、地理に関するクエリ、手順の説明、実演などに最適です
  * **設定可能な制御**: 必要に応じて有効化/無効化やメディアタイプの上書きができます

  Media Classifier は `sonar-pro` でのみ利用可能で、視覚的な概念、場所、ステップごとの手順、教育コンテンツに関する応答を強化します。[詳細はこちら →](/ja/docs/sonar/media)

  **Search API の機能強化**

  Search API にいくつかの改善を加えました:

  * **新しい `max_tokens` パラメータ**: 検索結果でページごとに抽出される最大token数を制御できます。応答サイズとコストをより細かく調整できるようになります。[詳細はこちら →](/ja/docs/search/quickstart)
  * **`last_updated_filter` のサポート**: 公開日に加えて、コンテンツの最終更新日時で検索結果をフィルタリングできます。最新の情報を探すのに最適です。[詳細はこちら →](/ja/docs/search/filters/date-time-filters)

  * アプリケーションでのキー管理には環境変数を使用する
  * まずステージング環境でキーのローテーションをテストする
  * キーの利用状況を監視し、移行が正しく完了したことを確認する

<Update label="March 2025" tags={["Models", "Search", "Pricing"]}>
  **Sonar モデルの改善: 新しい検索モード**

  より低コストで優れたパフォーマンスを実現する、Sonar モデルの大幅な改善をお知らせします。最新のベンチマークテストでは、Sonar と Sonar Pro が主要な競合を上回る性能を発揮しつつ、より手頃な価格を維持していることが確認されました。

  主な更新内容:

  * ほとんどの Sonar モデルで利用できる **3 つの新しい検索モード**:
    * High: 複雑なクエリ向けに検索の深さを最大化
    * Medium: 中程度の複雑さに適したバランス重視
    * Low: 単純なクエリ向けのコスト効率重視 (現在の価格と同等)

  * **簡素化された課金体系**:
    * 入力/出力 token の透明性の高い価格設定
    * レスポンス内の引用 token は課金対象外 (Sonar Deep Research を除く)

  現在の課金体系は、30 日間 (2025 年 4 月 18 日まで) デフォルトのオプションとしてサポートされます。この期間中、新しい検索モードはオプトイン機能としてご利用いただけます。

  **重要な注意事項:** 2025 年 4 月 18 日以降、Sonar Pro および Sonar Reasoning Pro は、API レスポンスの usage フィールドに引用 token や検索結果数を返さなくなります。
</Update>

<Update label="January 2025" tags={["Models", "Features"]}>
  **Perplexity の新しい API で開発する**

  利用可能な中で最も効率的かつコストパフォーマンスに優れた検索ソリューションとして、**Sonar** と **Sonar Pro** を追加し、API のラインアップを拡充します。

  **Sonar** は、高速で簡潔な回答を提供します

  **Sonar Pro** は、より深いリサーチが必要な複雑な質問に対応し、より多くの情報源を提示します

  どちらの モデル にも、組み込みの引用、レート制限の自動スケーリング、構造化出力や検索ドメインフィルターといった高度な機能への一般公開されたアクセスが含まれます。なお、お客様のデータを学習に使用することは一切ありません。お客様の情報はお客様のものです。

  新しい API の詳細はこちらをご覧ください - [https://docs.perplexity.ai](https://docs.perplexity.ai)
</Update>
