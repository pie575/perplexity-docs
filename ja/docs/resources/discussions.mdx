<div id="sales-enterprise">
  ## 営業・エンタープライズ
</div>

エンタープライズ向けソリューション、カスタム価格、営業に関するご質問は、当社の営業チームまでお問い合わせください。

<Card title="営業チームへのお問い合わせ" icon="file-pencil" iconType="solid" href="https://perplexity.typeform.com/to/m3WnMaG6">
  エンタープライズ向けお問い合わせフォームにご記入ください。ユースケースを確認のうえ、ご要望に沿った対応をご提案します。

  チームや組織のお客様には、カスタム価格、専任サポート、エンタープライズ機能をご提供しています。
</Card>

<div id="technical-support">
  ## テクニカルサポート
</div>

技術的なサポートが必要ですか？サポートチームがお手伝いします。

<Warning>
  **まずは[コミュニティフォーラム](https://community.perplexity.ai/)をご利用ください。**

  フォーラムを定期的に確認している活発なコミュニティメンバーやチームメンバーから、より迅速に回答を得られます。
</Warning>

**メール**: [api@perplexity.ai](mailto:api@perplexity.ai) — 技術的な問題に関するお問い合わせ

<div id="developer-resources">
  ## 開発者向けリソース
</div>

<Steps>
  <Step title="問題を報告する">
    バグを見つけたら、詳細なバグレポートを送信して改善にご協力ください。

    [コミュニティフォーラム](https://community.perplexity.ai/)で `Bug Reports` タグを付けて新しい投稿を作成してください。
  </Step>

  <Step title="成果を共有する">
    Perplexity API で何かを作りましたか？ぜひその成果を紹介させてください。

    * [API Cookbook](https://github.com/perplexityai/api-cookbook) に貢献する
    * X/Twitter で [@perplexitydevs](https://twitter.com/perplexitydevs) をメンションして共有する
    * 毎月開催の開発者ショーケースで発表する
  </Step>

  <Step title="紹介される">
    特に優れたプロジェクトは、ニュースレター、ブログ、ソーシャルメディア、[Cookbook コミュニティショーケース](/ja/docs/cookbook/showcase/briefo)で紹介されることがあります。

    <Tip>
      プロジェクトの詳細やユースケースを共有していただくと、紹介される可能性が高まります。
    </Tip>
  </Step>
</Steps>
