Perplexity API Platform は、AWS Marketplace の SaaS リスティングとして提供されています。API クレジットは AWS アカウントから購入でき、購入したクレジットは Perplexity API の残高に反映され、すべての API (Router、Agent、Search、Sonar、Embeddings) で利用できます。

<Frame caption="AWS Marketplace 上の Perplexity API Platform リスティング">
  <img src="https://mintcdn.com/perplexity/Br6sHZfZGOM6gS1X/docs/assets/images/aws_marketplace/aws_listing_overview.png?fit=max&auto=format&n=Br6sHZfZGOM6gS1X&q=85&s=0cebd6f05fc1f00ad74355d60ffc1065" alt="Perplexity API Platform on AWS Marketplace" />
</Frame>

<Note>
  このリスティングは **API Platform** (Router API、Agent API、Search API、Sonar、Embeddings) を対象としています。API アクセスを含まない **Enterprise Pro** とは別の製品です。
</Note>

<div id="why-subscribe-through-aws-marketplace">
  ## AWS Marketplace 経由でサブスクライブするメリット
</div>

AWS Marketplace 経由での購入には、直接請求と比べて次のような利点があります。

* **AWS請求への一本化** — 料金が他のAWSサービスと同じ既存のAWS請求書にまとめて表示されるため、経理・会計業務が簡素化されます
* **エンタープライズ調達に対応** — AWS Marketplace 経由での購入が義務付けられている組織の調達要件を満たします。個別のベンダー契約は不要です
* **EDP対象** — 購入額はAWS Enterprise Discount Program (EDP) のコミットメントに算入されます
* **ベンダー管理の簡素化** — 個別の契約や支払い方法を管理する必要はなく、請求はAWSが処理します

<div id="pricing">
  ## 料金
</div>

AWS Marketplace の Perplexity API Platform は、API プラットフォームクレジット付きの **1か月契約** で提供されます。

| プラン                   |   クレジット   | 契約期間 |
| --------------------- | :-------: | :--: |
| **API プラットフォームクレジット** | $1,000 から |  1か月 |

クレジットは USD と 1:1 で換算されます (1 クレジット = $1) 。クレジットはアカウント残高に加算され、API リクエストに応じて消費されます。

<Note>
  Router API、Agent API、Search API、Sonar、Embeddings といった Perplexity API のすべての製品は、同一の共有クレジットプールから消費されます。製品ごとに個別の予算を用意する必要はありません。

  リクエスト単位および token 単位の料金の詳細は、<u>[料金ページ](/ja/docs/getting-started/pricing)</u>をご覧ください。
</Note>

<div id="how-to-subscribe">
  ## サブスクリプションの登録方法
</div>

<Tip>
  クレジットに有効期限はありません。**1か月契約**とは請求サイクルを指すもので、利用期限ではないため、未使用のクレジットは残高にそのまま残ります。
</Tip>

1. AWS Marketplace の <u>[Perplexity API Platform のリスティング](https://aws.amazon.com/marketplace/pp/prodview-fslss6gnscauq)</u> にアクセスします
2. **View purchase options** をクリックします
3. クレジット額を選択し、**Create contract** をクリックします
4. 購入を確定します — AWS 側でサブスクリプションが処理され、メールで通知が届きます

<Frame caption="AWS Marketplace リスティングの料金セクション">
  <img src="https://mintcdn.com/perplexity/Br6sHZfZGOM6gS1X/docs/assets/images/aws_marketplace/aws_listing_pricing.png?fit=max&auto=format&n=Br6sHZfZGOM6gS1X&q=85&s=c4a59c6a7e55363f2152d28046b3400d" alt="AWS Marketplace pricing — API platform credits at $1,000/month" />
</Frame>

サブスクリプションが確定すると、AWS Marketplace アカウントを Perplexity API Platform に連携するための手順が届きます。

<div id="getting-started-after-subscribing">
  ## サブスクリプション登録後の始め方
</div>

AWS Marketplace のサブスクリプションが確定したら、以下の手順を実行します。

1. **サインインまたはアカウント作成** — <u>[console.perplexity.ai](https://console.perplexity.ai)</u> にアクセスし、Perplexity アカウントでサインインします (アカウントをお持ちでない場合は新規作成してください)
2. **サブスクリプションの連携** — コンソールの指示に従って、AWS Marketplace での購入を Perplexity アカウントに紐付けます。これにより、購入したクレジットがプロジェクトに関連付けられます
3. **プロジェクトのセットアップ** — クレジットはプロジェクト (API ポータル内の組織のワークスペース) に紐付けられます。セットアップを完了したユーザーが Admin となり、請求、API key、メンバー招待のすべてを操作できます。他のメンバーは Admin (フルアクセス) または Member (閲覧のみ) として参加できます。<u>[Projects &amp; Billing](/ja/docs/getting-started/projects)</u> を参照してください。
4. **API key の生成** — コンソールの API Keys に移動し、プロジェクト用のキーを作成します。<u>[API Key Management](/ja/docs/admin/api-key-management)</u> を参照してください。
5. **リクエストの開始** — クレジットはプロジェクトの残高に反映され、すべての製品 (Router API、Agent API、Search API、Sonar、Embeddings) で共有されます。残高と使用状況はコンソールでいつでも確認できます。

<div id="refund-policy">
  ## 返金ポリシー
</div>

サブスクリプションをキャンセルする場合、**クレジットが一切使用されていない**場合に限り、**購入から14日以内**であれば返金を受けられます。返金をリクエストするには、AWS Marketplaceの注文IDを添えて <u>[aws-api@perplexity.ai](mailto:aws-api@perplexity.ai)</u> までご連絡ください。

<Warning>
  クレジットが少しでも消費されている場合、または14日間の期間を過ぎた場合は、返金はできません。
</Warning>

<div id="support">
  ## サポート
</div>

AWS Marketplace のサブスクリプション、請求、API の利用に関するご質問は、Perplexity API チームまでお問い合わせください。

**メール:** <u>[aws-api@perplexity.ai](mailto:aws-api@perplexity.ai)</u>

AWS Marketplace への登録やアカウント連携に関する問題は、Clazar のサポートチームまでお問い合わせください。

**メール:** <u>[support@clazar.io](mailto:support@clazar.io)</u>

お問い合わせの際は、サブスクリプションを速やかに特定できるよう、AWS Marketplace の注文 ID またはアカウントのメールアドレスをご記載ください。
