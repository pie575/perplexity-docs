<div id="perplexity-dart-flutter-sdks">
  # Perplexity Dart &amp; Flutter SDK
</div>

**Perplexity Dart &amp; Flutter SDK** は、Perplexity の AI 機能を Dart および Flutter アプリケーションに組み込むための包括的なツールキットです。Flutter コミュニティ向けに設計されたこれらのパッケージには、軽量なコア API クライアントと、BLoC による状態管理を備えたすぐに使える Flutter ウィジェットが含まれています。

<div id="features">
  ## 機能
</div>

* 完全に型付けされたモデルとコンパイル時の安全性を備えた型安全な API クライアント
* リアルタイムなレスポンス処理に対応したストリーミング／非ストリーミングのチャット補完
* すべての Perplexity モデルに対応 (Sonar、Sonar Pro、Deep Research、Reasoning 系バリアント) 
* base64、データ URI、HTTPS URL に対応したマルチ画像処理
* BLoC による状態管理と統合済みの、すぐに使える Flutter ウィジェット
* 高度な設定オプション (検索フィルター、ドメイン制限) 
* iOS、Android、Web、デスクトップに対応したクロスプラットフォーム
* Perplexity の新モデルにも備え、カスタムモデル文字列を指定できる将来性のある設計

<div id="prerequisites">
  ## 前提条件
</div>

* Dart SDK 2.17.0 以降
* Flutter SDK 3.0.0 以降 (Flutter 固有の機能を利用する場合) 
* Perplexity API Console で取得した Perplexity API key
* ウィジェット統合に必要な Flutter BLoC パターンの基本知識

<div id="usage">
  ## 使い方
</div>

<div id="core-api-integration">
  ### コアAPI統合
</div>

* すべてのPerplexity モデル (Sonar、Sonar Pro、Deep Research、Reasoning) に対応した型安全なクライアント
* ストリーミングおよび非ストリーミングのチャット補完
* テキストと画像に対応する柔軟なMessagePartシステムによるマルチモーダル処理

<div id="flutter-widget-layer">
  ### Flutter ウィジェット層
</div>

* `ChatWrapperWidget`: BLoC による状態管理
* `PerplexityChatView`: リアルタイムのメッセージ表示
* `PerplexityChatInput`: ユーザー操作のハンドリング

<div id="code-explanation">
  ## コードの解説
</div>

* コアレイヤー: クロスプラットフォームでの Perplexity API 統合を実現する純粋な Dart 製 API クライアント (`perplexity_dart`)
* UI レイヤー: BLoC による状態管理を備え、迅速な開発を可能にする Flutter ウィジェット (`perplexity_flutter`)
* 型安全性: 完全に型付けされたモデルとレスポンスにより、実行時エラーを防ぎ IntelliSense を利用可能
* マルチモーダル: 1 回のリクエストでテキストと画像を組み合わせられる柔軟な MessagePart システム
* ストリーミング: 適切なチャンク処理を備えたリアルタイムのチャット補完を標準サポート
* アーキテクチャ: 2 層構成により、軽量な API 利用から Flutter ウィジェットのフル統合まで対応

<div id="architecture">
  ## アーキテクチャ
</div>

<div id="two-layer-design">
  ### 2層構造の設計
</div>

* **コア (`perplexity_dart`)** - 全プラットフォームに対応する純粋な Dart 製 API クライアント
* **UI (`perplexity_flutter`)** - Flutter ウィジェット + BLoC による状態管理

テキストと画像を組み合わせたマルチモーダルコンテンツには、柔軟な MessagePart システムを使用します。
