**Briefo** は、AIが生成するパーソナライズされたニュースフィードと、企業の詳細分析を提供します。速報を追いかけ、必要なときに財務分析をリクエストし、得られたインサイトを友人と語り合う——そのすべてが、PerplexityのSonar APIを活用した1つのモバイル体験にまとまっています。

<div id="features">
  ## 機能
</div>

* 17カテゴリにわたるパーソナライズされたニュースフィード (AI要約とソースリンク付き) 
* 記事の議論・共有に使えるプライベートスレッドとパブリックスレッド
* リアルタイムの市場スナップショットとAI分析 (任意) を備えたウォッチリスト
* 経営陣、競合、バリュエーションなど12の基準を選んで生成できるディープリサーチレポート
* 各ユーザーの関心トピックを記憶する汎用チャットアシスタント

<div id="prerequisites">
  ## 前提条件
</div>

* Node 18 LTS 以降
* npm、Yarn、または pnpm
* Expo CLI (`npm i -g expo-cli`) 
* Supabase CLI 1.0 以降 (ローカルエミュレーションと Edge Function のデプロイに使用)

<div id="installation">
  ## インストール
</div>

```bash theme={null}
git clone https://github.com/adamblackman/briefo-public.git
cd briefo-public
npm install
```

<div id="environment-variables">
  ### 環境変数
</div>

```ini theme={null}
# .env              (プロジェクトルート)
MY_SUPABASE_URL=https://<project>.supabase.co
MY_SUPABASE_SERVICE_ROLE_KEY=...
PERPLEXITY_API_KEY=...
LINKPREVIEW_API_KEY=...
ALPACA_API_KEY=...
ALPACA_SECRET_KEY=...

# .env.local        (supabase/ 内)
# Edge Functions で必要なシークレットをここに複製、または上書きする
```

<div id="usage">
  ## 使い方
</div>

Expo 開発サーバーを起動します。

```bash theme={null}
npx expo start
```

準備ができたら、Edge Functions をデプロイします。

```bash theme={null}
supabase functions deploy perplexity-news perplexity-chat perplexity-research portfolio-tab-data
```

<div id="code-explanation">
  ## コードの解説
</div>

* フロントエンド: iOS、Android、Web を対象とした React Native + Expo Router (Typescript) 
* バックエンド: データと認証を担う Supabase (PostgreSQL、行レベルセキュリティ、Realtime) 
* Edge Functions: Deno 上の Typescript で Perplexity、Alpaca、Alpha Vantage、LinkPreview の各 API を呼び出し
* Hooks: 再利用可能な React Query スタイルのデータフックは lib/ と hooks/ に配置
* テストとリント: ESLint、Prettier、Expo Lint でコード品質を維持
