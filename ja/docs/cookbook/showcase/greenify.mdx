**Greenify** は、リアルタイムで撮影した画像を分析し、コミュニティづくりを支援することで、サステナブルな取り組みを後押しするモバイルアプリケーションです。ユーザーが自分のスペース (バルコニー、道端、地下室など) の写真を撮影すると、Greenify が Perplexity の Sonar API を使って画像を自動的に分析し、その場所に適した植物を提案します。さらに、同じ志を持つ地域の人々をつなぎ、環境・経済・社会の面で持続的な成長を目指すコミュニティの形成を促します。

<div id="features">
  ## 機能
</div>

* **AIによる植物分析** — 画像認識と位置情報から適した植物を提案
* **位置情報に基づくおすすめ** — 天候、日照、環境条件を考慮
* **コミュニティ形成** — 植物への関心や持続可能性の目標が近いユーザー同士をつなぐ
* **クロスプラットフォーム対応モバイルアプリ** — Expoで構築し、iOS、Android、Webに対応
* **リアルタイムの気象データ連携** — 植物の適性を正確に評価
* **構造化されたJSON出力** — Pydanticモデルにより一貫したデータ処理を実現
* **ARモデル対応** — 植物をより分かりやすく可視化

<div id="prerequisites">
  ## 前提条件
</div>

* Node.js 20.19.4以上とnpm
* Python 3.10.0以上とpip
* Expo CLIおよびSDK 51以上
* Perplexity API key (Sonar ProおよびSonar Deep Research) 
* Android SDK/StudioまたはXcode (ローカルビルドの場合) 
* 画像撮影用のカメラを備えたモバイル端末

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/deepjyotipaulhere/greenify.git
cd greenify

# フロントエンドの依存関係をインストール
npm install

# バックエンドの依存関係をインストール
cd service
pip install -r requirements.txt
```

<div id="configuration">
  ## 設定
</div>

`service` ディレクトリに `.env` ファイルを作成します。

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key_here
```

<div id="usage">
  ## 使い方
</div>

1. **バックエンドサービスの起動**：
   ```bash theme={null}
   cd service
   python app.py
   ```

2. **フロントエンドアプリの起動**：
   ```bash theme={null}
   npx expo start
   ```

3. **アプリへのアクセス**：
   * Expo Go アプリをインストールして QR コードをスキャンする、または
   * モバイル端末の Web ブラウザを開き、表示された URL にアクセスする

4. **アプリの利用**：
   * カメラと位置情報の利用を許可する
   * 自分のスペース (ベランダ、庭など) を撮影する
   * AI による植物のおすすめを受け取る
   * 近くのユーザーとつながり、コミュニティを広げる

<div id="code-explanation">
  ## コードの解説
</div>

* **フロントエンド**: クロスプラットフォームのモバイル開発に対応する Expo + React Native
* **バックエンド**: 画像処理と Perplexity API 連携を担う Python Flask API
* **AI 連携**: 画像解析に Perplexity Sonar Pro、植物のおすすめに Sonar Deep Research を使用
* **データモデル**: 構造化 JSON 出力とデータ検証のための Pydantic モデル
* **画像処理**: 位置情報のコンテキストを踏まえたリアルタイム画像解析
* **コミュニティ機能**: 植物の提案内容とサステナビリティへの関心に基づくユーザーマッチング
* **気象データ連携**: 植物の適性を正確に評価するためのリアルタイム気象データ
