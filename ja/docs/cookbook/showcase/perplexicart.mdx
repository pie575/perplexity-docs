**PerplexiCart** は、ユーザーが十分な情報に基づき、自らの価値観に沿った購買判断を下せるよう支援します。**Perplexity Sonar API** を活用してウェブ上の製品を分析し、優先順位付けされたおすすめ、メリットとデメリット、トレードオフ分析、ユーザーのセンチメントといった構造化されたインサイトを返します。これらの結果は、環境への配慮、耐久性、倫理性、地域固有のニーズなど、ユーザーの重視するポイントに合わせて最適化されます。

<div id="features">
  ## 機能
</div>

* 単純なスペック比較にとどまらない**インテリジェントな製品おすすめ**
* **優先条件に基づく価値観のマッチング** (コストパフォーマンス、環境配慮、倫理性、耐久性、Made in India) 
* **文脈に応じたパーソナライズ** (肌質、使用状況、地域など) 
* 以下を含む**構造化されたリサーチ結果**
  * リサーチの要約とおすすめ上位製品
  * 根拠を添えた価値観のマッチング
  * メリット・デメリットと主要スペック
  * ユーザーのセンチメントとコミュニティの声 (Reddit、Quora) 
  * トレードオフ分析と購入のヒント
* 検証に使える引用付きの**透明性の高い情報源**

<div id="prerequisites">
  ## 前提条件
</div>

* Node.js 18以降とnpm/yarn
* Python 3.10以降とpip
* Perplexity APIキー

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/fizakhan90/perplexicart.git
cd perplexicart

# バックエンド（FastAPI）のセットアップ
cd backend
python -m venv .venv
source .venv/bin/activate  # Windowsの場合: .venv\Scripts\activate
pip install -r requirements.txt

# フロントエンド（Next.js）のセットアップ
cd ../frontend
npm install
```

<div id="configuration">
  ## 設定
</div>

バックエンドディレクトリに `.env` ファイルを作成します。

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key
```

 (任意) 必要に応じて、アプリ固有の設定 (キャッシュ、リージョンの既定値など) を追加します。

<div id="usage">
  ## 使い方
</div>

1. **バックエンドの起動 (FastAPI)&#x20;**:
   ```bash theme={null}
   cd backend
   uvicorn main:app --reload  # エントリポイントが異なる場合は module:app を適宜変更してください
   ```

2. **フロントエンドの起動 (Next.js)&#x20;**:
   ```bash theme={null}
   cd frontend
   npm run dev
   ```

3. **アプリを開く**: `http://localhost:3000` にアクセスして製品を検索します。重視する条件 (例: 環境への配慮) を選択し、必要に応じて追加のコンテキスト (肌質、地域) を入力します。

<div id="code-explanation">
  ## コードの解説
</div>

* **バックエンド (FastAPI)**: クエリ、選択された優先条件、コンテキストに応じて動的にプロンプトを組み立て、Sonar の呼び出しを統括します
* **構造化出力**: `response_format` で厳密な JSON スキーマを適用し、UI のレンダリングを一貫させます
* **リアルタイムのウェブ調査**: EC プラットフォーム、フォーラム、レビューブログ、サステナビリティレポートを検索するよう Sonar に指示します
* **セマンティック分析**: 価値観との適合性、メリット・デメリット、センチメントを抽出し、透明性を確保するために出典を引用します
* **フロントエンド (Next.js/React)**: おすすめ、トレードオフ、引用元を分かりやすく使いやすい形で表示します

<div id="how-the-sonar-api-is-used">
  ## Sonar APIの活用方法
</div>

PerplexiCartは**Perplexity Sonar API**をインテリジェンスの中核に据え、検索クエリ、優先条件、コンテキストといったユーザー入力に応じてカスタマイズされたプロンプトを動的に生成します。APIはeコマースサイト、フォーラム、レビュープラットフォームを横断して包括的なWebリサーチを行い、そのレスポンスは一貫したJSON形式で構造化されます。セマンティック解析により、ユーザーの優先条件との適合度、メリット・デメリット、センチメントといった主要な商品インサイトを抽出し、いずれも引用元によって裏付けられています。FastAPIバックエンドはこれらの構造化レスポンスを処理したうえでNext.jsフロントエンドに渡し、洗練されたユーザー体験を実現します。
