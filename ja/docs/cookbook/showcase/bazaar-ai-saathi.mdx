**BazaarAISaathi** は、インド株式市場に関する実践的なインサイトを投資家に届けることを目指す、AI 搭載のプラットフォームです。高度な自然言語処理、リアルタイムのデータ分析、専門家の知見に基づく金融モデリングを活用し、一人ひとりに合わせた投資戦略、市場センチメント分析、ポートフォリオ最適化の提案を提供します。

<div id="features">
  ## 機能
</div>

* **経済的自立プランナー (FIRE)&#x20;**&#x20;— 年齢、収入、目標に応じたパーソナライズされたプランを提供
* **投資アドバイス検証ツール** — EasyOCRによるテキスト抽出とAIによる検証
* **ファンダメンタル分析・テクニカル分析** — 総合的な企業レポートとトレード戦略
* **ポートフォリオ分析** — 多角的な分析と銘柄別の推奨
* **市場調査・競合ベンチマーク** — AIを活用した業界トレンド分析
* **リアルタイム株価データ** — 価格のライブ追跡とトレンド分析
* **仮説検証** — 過去およびリアルタイムの市場データを活用
* **投資書籍サマリー** — 主要な投資書籍50冊の簡潔な要約

<div id="prerequisites">
  ## 前提条件
</div>

* Python 3.8以上とpip
* Webアプリケーションフレームワークとしての Streamlit
* Perplexity API key (Sonar モデル) 
* 任意: 画像からのテキスト抽出用の EasyOCR

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/mahanteshimath/BazaarAISaathi.git
cd BazaarAISaathi

# 依存関係をインストール
pip install -r requirements.txt
```

<div id="configuration">
  ## 設定
</div>

Streamlit のシークレット用に `secrets.toml` ファイルを作成します。

```ini theme={null}
PERPLEXITY_API_KEY = "your_perplexity_api_key"
# 必要に応じて他のAPIキーを追加
```

<div id="usage">
  ## 使い方
</div>

1. **アプリケーションの起動**:
   ```bash theme={null}
   streamlit run Home.py
   ```

2. **機能へのアクセス**:
   * 各ページに移動して、目的の機能を利用します
   * メインダッシュボードで全体の概要確認とナビゲーションを行います
   * ポートフォリオ分析、FIRE プランニング、ヒントのテストなどの専用ツールを利用します

3. **特定のモジュールの実行**:
   ```bash theme={null}
   streamlit run pages/Financial_Independence.py
   streamlit run pages/Portfolio_Analysis.py
   streamlit run pages/Tip_Tester.py
   ```

<div id="code-explanation">
  ## コードの説明
</div>

* **フロントエンド**: インタラクティブなページとリアルタイムのデータ可視化を備えた Streamlit ウェブアプリケーション
* **バックエンド**: データ操作と分析に Pandas を利用した Python ベースのビジネスロジック
* **AI 統合**: 金融分析に使用する Perplexity Sonar API モデル (sonar-deep-research、sonar-reasoning-pro、sonar-pro) 
* **データ処理**: リアルタイムの株価データ取得、CSV データ管理、市場インサイトの生成
* **テキスト抽出**: 画像から投資のヒントを読み取るための EasyOCR 統合
* **ポートフォリオ管理**: 最適化の提案を含む包括的なポートフォリオ分析
* **市場分析**: センチメントスコアリングを伴うテクニカル分析およびファンダメンタル分析
