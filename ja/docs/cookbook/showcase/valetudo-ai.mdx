<div id="valetudo-ai">
  # Valetudo AI
</div>

**Valetudo AI** は、Perplexity Sonar API を活用した科学的根拠に基づく医療アシスタントです。健康に関する質問に、迅速かつ明快で出典の明示された回答を返し、フィルター、画像解析、すぐに使えるプロンプトテンプレートによって、ユーザーが誤情報に惑わされずに済むよう支援します。

保護者、患者、医学生など、信頼できる情報を求める意識の高いユーザー向けに設計されています。

<div id="features">
  ## 機能
</div>

* **引用付き回答** — 厳選された信頼性の高い10の医療系ドメインを情報源として利用
* **スマートフィルター** — 日付と国で絞り込み、地域に即した最新の情報を取得
* **画像アップロード** — 薬剤、症状、パッケージの写真を解析
* **プロンプトテンプレート** — 症状チェック、薬剤の安全性、リサーチなど7カテゴリー
* **シンプルなUI** — ReactとTailwind CSSで構築

<div id="how-it-uses-the-sonar-api">
  ## Sonar API の活用方法
</div>

Valetudo AI は [Perplexity Sonar Pro](https://docs.perplexity.ai) と連携し、ドメイン特化型の検索と情報量の多い応答を実現する高度な機能を活用しています。

| 機能        | API フィールド                         | 目的                           |
| --------- | --------------------------------- | ---------------------------- |
| コンテキスト制御  | `search_context_size: medium`     | 医療 Q&amp;A に適した速度と深さのバランスを取る |
| 信頼できるドメイン | `search_domain_filter`            | 検証済みの health 情報ソースに結果を限定する   |
| 画像入力      | `image_url`                       | 画像を用いた医療クエリを可能にする            |
| 鮮度フィルター   | `search_after/before_date_filter` | 最新かつ関連性の高い情報を見つけやすくする        |
| 地域的な関連性   | `user_location`                   | ユーザーの地域に合わせて回答を最適化する         |
