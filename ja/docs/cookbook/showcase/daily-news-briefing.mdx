**Daily News Briefing** は、AIによるニュース要約をVaultに直接届けるObsidianプラグインです。PerplexityのSonar APIを活用したインテリジェントなコンテンツキュレーションにより、ニュースの収集と要約を自動化し、関心のあるトピックの最新情報を効率よく把握できます。

<div id="features">
  ## 機能
</div>

* 関心のあるトピックや好みに基づく**パーソナライズされたニュース収集**
* Perplexity Sonar API を利用したニュース記事の **AI による要約**
* Obsidian のVaultへ直接配信される**自動デイリーブリーフィング**
* **カスタマイズ可能な配信スケジュール**とフォーマットオプション
* 既存のナレッジ管理ワークフローに溶け込む**シームレスな Obsidian 連携**
* 品質と信頼性を担保する**信頼できる情報源のフィルタリング**
* ボールト内でのリンクや整理を容易にする **Markdown フォーマット**

<div id="prerequisites">
  ## 前提条件
</div>

* Obsidian デスクトップアプリがインストールされていること
* Perplexity API キー (Sonar API へのアクセス権) 
* ニュース記事を取得するためのインターネット接続
* Typescript 開発環境 (カスタマイズを行う場合)

  ## インストール
</div>


<div id="configuration">
  ## 設定
</div>

1. **プラグインのインストール**: ビルドしたプラグインを Obsidian のプラグインフォルダにコピーします
2. **プラグインの有効化**: Obsidian の設定画面で有効化します
3. **API のセットアップ**: プラグインの設定に Perplexity API キーを入力します
4. **トピックの設定**: ニューストピックと配信方法を設定します

<div id="usage">
  ## 使い方
</div>

1. **関心事項の設定**: 対象トピック、情報源、配信スケジュールを設定します
2. **自動収集**: プラグインが Perplexity Sonar API を使って最新ニュースを収集します
3. **AI による要約**: Perplexity の機能で記事を処理し、要約します
4. **Vault への配信**: 要約は Markdown ノートとして Obsidian の Vault に出力されます
5. **ナレッジ連携**: ニュースブリーフィングをナレッジベース内の他のノートとリンクします

<div id="code-explanation">
  ## コードの解説
</div>

* **フロントエンド**: カスタムUIコンポーネントを備えたTypescriptベースのObsidianプラグイン

* **コンテンツ処理**: 記事の抽出と要約を自動化したワークフロー
* **スケジューリング**: 配信スケジュールとトピック監視を柔軟に設定可能
* **Markdown生成**: Obsidian互換の構造化されたコンテンツ整形
* **エラー処理**: APIの上限やネットワークの問題に対する堅牢なエラー管理

<div id="technical-implementation">
  ## 技術的な実装
</div>

このプラグインは、以下の用途で Perplexity Sonar API を活用しています。

```typescript theme={null}
// Perplexity Sonar API によるニュース収集
const newsQuery = `latest news about ${topic} in the past 24 hours`;
const searchResponse = await perplexityClient.search({
  query: newsQuery,
  max_results: 5,
  include_domains: userPreferences.trustedSources || []
});

// AI による要約生成
const summaryPrompt = `Summarize these news articles about ${topic}`;
const summaryResponse = await perplexityClient.generate({
  prompt: summaryPrompt,
  model: "sonar-medium-online",
  max_tokens: 500
});
```
