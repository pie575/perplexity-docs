**UnCovered** は、テキスト、画像、ウェブサイト、スクリーンショットを、閲覧中のその場でリアルタイムに検証する Chrome 拡張機能です。Perplexity の Sonar API を基盤としており、右クリックするだけで、閲覧の流れを妨げることなく、出典・判定・詳細な分析とともに事実を即座に提示します。

<div id="features">
  ## 機能
</div>

* **3クリックで検証**: 選択 → 右クリック → 検証 (テキスト、画像、リンク、スクリーンショット) 
* **テキスト分析モード**: クイック検索、ファクトチェック、ディープリサーチに対応
* **画像のファクトチェック**: 画像の逆検索分析とマルチモーダルな主張検証
* **スクリーンショット・動画フレームのキャプチャ**: インフォグラフィック、ミーム、グラフのスナップショットといった視覚情報を分析
* **出典付きの結果**: すべての回答に出典と事実判定 (真／偽／未確認) が付属
* **即時反論ジェネレーター**: 誤情報に対する簡潔で事実に基づいた返答を作成
* **ストレスのないUX**: 同じページに留まったまま操作可能 — コピー＆ペーストも新しいタブも不要

<div id="prerequisites">
  ## 前提条件
</div>

* Chrome ブラウザ
* Node.js 16 以上および npm
* MongoDB データベース
* 画像保存用の Cloudinary アカウント
* Perplexity API key (Sonar Pro および ディープリサーチ へのアクセス権) 
* Google OAuth の認証情報

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/aayushsingh7/UnCovered.git
cd UnCovered

# 依存関係をインストール
npm install

# Chrome拡張機能をビルド
npm run build
```

<div id="configuration">
  ## 設定
</div>

環境変数を設定します。

```ini theme={null}
PERPLEXITY_API_KEY=your_sonar_api_key
MONGODB_URI=your_mongodb_connection_string
CLOUDINARY_URL=your_cloudinary_credentials
GOOGLE_OAUTH_CLIENT_ID=your_google_oauth_id
```

<div id="usage">
  ## 使い方
</div>

1. **テキスト/リンクの検証**:
   * テキストを選択するか、リンクを右クリックします
   * クイック検索 / ファクトチェック / ディープリサーチ のいずれかを選択します
   * 判定と出典付きの信頼できる結果が得られます

2. **画像の検証**:
   * 画像を右クリックします
   * クイック検索 または ファクトチェック を選択します
   * 誤情報や画像の改ざんを検出します

3. **スクリーンショット/インフォグラフィックの分析**:
   * ツールバーの UnCovered アイコンをクリックします
   * 「Capture Screen」でビジュアルコンテンツを分析します

4. **即座に反論を取得**:
   * 誤情報を正すための事実に基づいた回答を自動生成します

<div id="code-explanation">
  ## コードの解説
</div>

* **フロントエンド**: コンテキストメニュー連携を備えたバニラ JavaScript 製の Chrome 拡張機能
* **バックエンド**: API リクエストとユーザー認証を処理する Node.js Express サーバー
* **AI 連携**: 高度なファクトチェックを実現する Perplexity Sonar Pro および ディープリサーチ API
* **画像処理**: スクリーンショットと画像の解析に利用する Cloudinary 連携
* **データベース**: ユーザーデータと検証履歴を保存する MongoDB
* **認証**: セキュアなユーザー管理を実現する Google OAuth
* **マルチモーダル分析**: テキスト、画像、スクリーンショット、動画フレームに対応

<div id="technical-implementation">
  ## 技術実装
</div>

UnCovered は、Perplexity Sonar API を次の 3 つの主要モードで活用しています。

```javascript theme={null}
// Sonar Pro によるクイック検索とファクトチェック
const quickResponse = await perplexityClient.chat.completions.create({
  model: "sonar-pro",
  messages: [{ role: "user", content: factCheckPrompt }]
});

// 包括的な分析にはディープリサーチを使用
const deepResponse = await perplexityClient.chat.completions.create({
  model: "sonar-deep-research", 
  messages: [{ role: "user", content: deepAnalysisPrompt }]
});
```
