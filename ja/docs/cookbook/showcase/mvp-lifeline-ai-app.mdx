**MVP LifeLine** は、多言語対応かつオフラインファーストのAIプラットフォームで、若者を感情面・経済面・キャリア面から、いつでもどこでも支えます。世界では13億人を超える若者が、特に支援の行き届かない地域や遠隔地において、キャリア機会や心の健康に関する障壁に直面しています。MVP LifeLineは、AI、オフラインアクセス、多言語サポート、そして包括的なツールエコシステムを組み合わせることで、こうした障壁を打ち破ります。

<div id="features">
  ## 機能
</div>

* **デュアルモードAI** — Perplexity Sonar API を活用したキャリアコーチとエモーショナルコンパニオン
* **多言語対応** — 英語、フランス語、アラビア語、スペイン語、ヒンディー語、各地域言語を含む10以上の言語
* **オフラインファースト設計** — 通信環境が limited な地域向けのSMS/USSD連携
* **総合的なツールエコシステム** — キャリア、ウェルネス、家計、生産性をカバー
* **SmartQ アクセス** — 文脈を理解し、感情に配慮したAI応答
* **デジタルハッスルハブ** — AIによる案件探索とフリーランス向けツール
* **ウェルネスゾーン** — ガイド付き瞑想とメンタルリセット用プロンプト
* **ファイナンスゾーン** — 予算管理と若年層向けのお金のヒント
* **プロダクティビティゾーン** — AIカンバンボードと習慣トラッキング

<div id="prerequisites">
  ## 前提条件
</div>

* Flutter SDK と Dart
* Firebase プロジェクトのセットアップ
* SMS/USSD 連携用の Twilio アカウント
* Perplexity API キー (Sonar) 
* OpenAI API キー (拡張処理用)

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/JohnUmoh/asgard.git
cd asgard

# Flutter の依存関係をインストール
flutter pub get

# Firebase を構成
flutterfire configure

# 環境変数をセットアップ
cp .env.example .env
```

<div id="configuration">
  ## 設定
</div>

`.env` ファイルを作成します。

```ini theme={null}
PERPLEXITY_API_KEY=your_sonar_api_key
OPENAI_API_KEY=your_openai_api_key
FIREBASE_PROJECT_ID=your_firebase_project_id
TWILIO_ACCOUNT_SID=your_twilio_sid
TWILIO_AUTH_TOKEN=your_twilio_token
```

<div id="usage">
  ## 使い方
</div>

1. **Firebase のセットアップ**:
   ```bash theme={null}
   flutterfire configure
   ```

2. **アプリケーションの実行**:
   ```bash theme={null}
   flutter run
   ```

3. **機能の利用**:
   * キャリアコーチ モードと エモーショナルコンパニオン モードを切り替える
   * SmartQ を使って複数言語で AI による支援を受ける
   * 接続環境が限られている場合は SMS/USSD 経由でオフライン機能を利用する
   * キャリアツール、ウェルネス機能、生産性向上機能を活用する

<div id="code-explanation">
  ## コードの説明
</div>

* **フロントエンド**: モバイルとWebに対応したレスポンシブデザインのFlutterクロスプラットフォームアプリケーション
* **バックエンド**: 認証、データ保存、リアルタイム同期を担うFirebase
* **AI連携**: デュアルモードのAI対話 (キャリアコーチとエモーショナルコンパニオン) を実現するPerplexity Sonar API
* **オフライン対応**: 通信環境が不安定な地域でのSMS/USSD通信を可能にするTwilio連携
* **多言語対応**: 文脈を考慮した応答で10以上の言語に対応するSonar API
* **データ同期**: オフライン時のデータ取得と、接続復帰時の自動再同期
* **パーソナライズ**: ユーザーの言語、識字レベル、気分の履歴、好みに合わせて適応するAI
