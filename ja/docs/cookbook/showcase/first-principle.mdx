**FirstPrinciples App** は、漠然とした学習目標を、構造化されたパーソナライズ済みのロードマップに変換する AI ツールです。対話型チャットで AI が会話しながら的を絞った質問を投げかけ、学習ニーズを明確にしたうえで詳細な計画を生成します。進むべき道筋をはっきり示すことで、より効率的な学習を支援するアプリケーションです。

<div id="features">
  ## 機能
</div>

* **対話型チャットインターフェース** — 会話を通じて学習目標を定義し、明確にしていきます
* **AIによるトピックの絞り込み** — 的を絞った質問で学習目標を具体化します
* **セッション管理** — 複数のロードマップの検討と進捗の追跡が可能です
* **視覚的な進捗インジケーター** — 十分な情報が集まったタイミングを表示します
* **パーソナライズされた学習プラン** — 体系立てられた段階的なロードマップを提供します
* **対話型AIフロー** — OpenAIとPerplexity APIを組み合わせ、高度なやり取りを実現します

<div id="prerequisites">
  ## 前提条件
</div>

* Python 3.8以降とpip
* Node.js 16以降とnpm
* OpenAIのAPI key
* PerplexityのAPI key

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/william-Dic/First-Principle.git
cd First-Principle

# バックエンドのセットアップ
cd flask-server
pip install -r requirements.txt

# フロントエンドのセットアップ
cd ../client
npm install
```

<div id="configuration">
  ## 設定
</div>

`flask-server` ディレクトリに `.env` ファイルを作成します。

```ini theme={null}
OPENAI_API_KEY=your_openai_api_key
PERPLEXITY_API_KEY=your_perplexity_api_key
PERPLEXITY_API_KEY=your_perplexity_api_key
```

<div id="usage">
  ## 使い方
</div>

1. **バックエンドの起動**:
   ```bash theme={null}
   cd flask-server
   python server.py
   ```
   サーバーは [http://localhost:5000](http://localhost:5000) で起動します

2. **フロントエンドの起動**:
   ```bash theme={null}
   cd client
   npm start
   ```
   クライアントは [http://localhost:3000](http://localhost:3000) で起動します

3. **ロードマップの生成**:
   * ブラウザで [http://localhost:3000](http://localhost:3000) を開きます
   * チャットインターフェースで学びたい内容を入力します
   * AIからの追加質問に答えて学習目標を明確にします
   * 自分に合わせた構造化された学習ロードマップが生成されます

<div id="code-explanation">
  ## コードの解説
</div>

* **フロントエンド**: 対話型チャットインターフェースと進捗インジケーターを備えた React アプリケーション
* **バックエンド**: API 呼び出し、セッション状態、会話フローを管理する Flask サーバー
* **AI 統合**: 会話フローに OpenAI API、高度なトピック分析に Perplexity API を組み合わせて利用
* **セッション管理**: 会話の状態と学習目標の絞り込み状況を追跡
* **ロードマップ生成**: ユーザーの入力に基づき、構造化された実行可能な学習計画を作成
* **会話フロー**: 学習目標を絞り込むための目標指向型の対話を実装
