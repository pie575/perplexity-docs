**Perplexity Lens** は、Perplexity AI によるAIインサイトを提供し、オンラインで目にした概念どうしを視覚的につなぐパーソナライズされたナレッジグラフを作成することで、ブラウジング体験を一変させる強力なブラウザ拡張機能です。

<div id="features">
  ## 機能
</div>

* **スマートテキスト選択** — 選択したテキストについてAIが生成した解説を表示
* **ウェブページ要約** — ページ全体を即座に簡潔にまとめて表示
* **文脈に応じたRAGインサイト** — RAG (Retrieval-Augmented Generation) により詳細な文脈と意味を提供
* **ナレッジグラフの可視化** — D3.jsのインタラクティブなグラフで概念間のつながりを表示
* **公開共有** — URLを生成してグラフを他のユーザーと共有
* **ユーザー認証** — Firebaseによる安全なアクセス
* **デュアルストレージ** — ローカルのIndexedDBとクラウドのFirebaseストレージに対応
* **レスポンシブUI** — あらゆるデバイスで問題なく動作

<div id="prerequisites">
  ## 前提条件
</div>

* Node.js v14以上、npm v6以上
* Google Chrome または互換ブラウザ
* クラウド機能を利用するための Firebase アカウント
* Firebase CLI (`npm install -g firebase-tools`) 
* Perplexity API キーおよび OpenAI API キー

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/iamaayushijain/perplexity-lens.git
cd perplexity_lens

# 依存関係をインストール
npm install

# 拡張機能をビルド
npm run build
```

</div>

`src/config.ts` を編集します。

```typescript theme={null}

export const EMBEDDING_API_KEY = 'your-openai-key';

```

<div id="usage">
  ## 使い方
</div>

1. **拡張機能を読み込む**: `chrome://extensions/` を開き、デベロッパーモードを有効にして「パッケージ化されていない拡張機能を読み込む」をクリックし、`dist/` ディレクトリを選択します

2. **サインイン**: 拡張機能のアイコンをクリックし、Firebase で認証します

3. **機能を使う**:
   * **テキストをハイライト**: 任意のウェブページでテキストを選択すると、AIインサイトが得られます
   * **ページを要約**: 「Summarize」機能でウェブページの概要を確認します
   * **何でも質問**: 単語やフレーズにカーソルを合わせるか、クリックすると定義や解説が表示されます
   * **グラフを表示**: Graph タブを開くと、自分のナレッジグラフを確認できます
   * **探索**: インタラクティブなグラフ上で、ノードのズーム・ドラッグ・ホバー操作ができます
   * **共有**: 「Share Graph」をクリックすると、公開リンクが生成されます

<div id="code-explanation">
  ## コードの解説
</div>

* **フロントエンド**: React と Typescript、TailwindCSS によるモダンでレスポンシブな UI
* **ブラウザ拡張機能**: ポップアップとコンテンツスクリプトで構成される Chrome 拡張機能アーキテクチャ
* **AI 連携**: Perplexity AI によるインテリジェントなテキスト解説と要約
* **ナレッジグラフ**: D3.js によるインタラクティブなグラフ可視化と概念間のつながりの表示
* **ストレージ**: ローカルの IndexedDB とクラウドの Firebase を組み合わせた二重ストレージ構成
* **認証**: Firebase Auth による安全なユーザーアクセスとデータ管理
* **RAG システム**: 文脈に応じたインサイトと定義を提供する RAG (検索拡張生成)
