**Flow &amp; Focus** は、ニュースを読む行為を学びの体験へと変えるパーソナライズドニュースアプリケーションです。縦型ニュースフィード (Flow) によるスピーディーな発見と、深く掘り下げた対話型の学習 (Focus) を独自に組み合わせ、Perplexity の Sonar Pro および Sonar Deep Research モデルで動作します。

<div id="features">
  ## 機能
</div>

* **デュアルモードインターフェース**: ニュースをすばやく見つけるFlow Feedと、パーソナライズされた深掘りができるFocus
* **縦型ニュースフィード**: AI生成の要約・タグ・背景画像付きの、スワイプで読めるニューススニペット
* **インタラクティブな深掘り**: キーフレーズをタップすると関連コンテンツを表示。詳細ペインは横スクロールで閲覧可能
* **パーソナライズされた学習**: 「Oracle」「Explorer」などのペルソナによるAI会話セグメント
* **スマートなパーソナライズ**: 閲覧傾向を追跡し、表示するコンテンツを自動で最適化
* **リアルタイムなコンテンツ**: 最新ニュースにはSonar Pro、詳細な分析にはSonar Deep Researchを活用
* **ビジュアルの強化**: コンテンツのキーワードに基づき、Runware.aiで背景画像を動的に生成

<div id="prerequisites">
  ## 前提条件
</div>

* Node.js 18以上とnpm
* Perplexity APIキー
* 画像生成用のRunware APIキー
* Next.js 15およびReact 19の環境

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/michitomo/NewsReel.git
cd NewsReel

# 依存関係をインストール
npm install

# 環境変数を設定
cp .env.example .env.local
```

<div id="configuration">
  ## 設定
</div>

`.env.local` ファイルを作成します。

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key_here
RUNWARE_API_KEY=your_runware_api_key_here
PERPLEXITY_FOCUS_MODEL=sonar-deep-research
```

<div id="usage">
  ## 使い方
</div>

1. **開発サーバーの起動**:
   ```bash theme={null}
   npm run dev
   ```

2. **アプリケーションへのアクセス**: ブラウザで [http://localhost:3000](http://localhost:3000) を開きます

3. **Flow Feed**: ニューススニペットを縦にスクロールし、キーフレーズをタップして深掘りします

4. **Focus Mode**: インタラクティブな会話セグメントを含む、パーソナライズされたダイジェストを生成します

5. **パーソナライズ**: 閲覧の傾向がコンテンツの選択に自動的に反映されます

<div id="code-explanation">
  ## コードの解説
</div>

* **フロントエンド**: Next.js 15、React 19、TypeScript、Tailwind CSS、アニメーションには Framer Motion を使用
* **状態管理**: Zustand を使用し、ユーザー設定を localStorage に永続化
* **AI 連携**: リアルタイムのニュース取得には Perplexity Sonar Pro、詳細な分析には Sonar Deep Research を使用
* **画像生成**: コンテンツのキーワードに応じた動的な背景画像を生成する Runware SDK 連携
* **API ルート**: Perplexity と Runware への API 呼び出しを処理するサーバーサイド連携
* **モバイルファースト設計**: 直感的なモバイル体験を実現するスワイプ操作とレスポンシブレイアウト
