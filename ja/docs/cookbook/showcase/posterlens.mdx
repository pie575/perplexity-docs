**PosterLens** は、OCR と AI を活用して、静的な学術ポスターをインタラクティブに探索できるインサイトへと変える iOS アプリです。Perplexity Hackathon 2025 向けに開発されたもので、研究者、MSL、メディカルライターがポスターをスキャンし、自然言語で対話しながら内容を読み解き、関連研究を瞬時に見つけ出せます。

![PosterLens Screenshot](https://cdn.prod.website-files.com/66d49e8555a289120a81ec3e/68930ad938e072c05d1be0b9_PosterLens.png)

<div id="features">
  ## 機能
</div>

* デバイスのカメラとApple Vision OCRを使用した**学術ポスターのスキャン**
* ポスターの内容についてAIが回答する**自然言語Q&amp;A**
* 関連研究を探すためにPerplexity Sonar Proを活用した**セマンティック検索の統合**
* 学術的な正確性を担保するPubMed E-utilitiesによる**引用の検証**
* **研究課題の自動生成**と今後の研究の方向性の提示
* プライバシーとパフォーマンスに配慮した**オンデバイス処理**
* 静的なコンテンツを動的なインサイトへと変える**インタラクティブな研究体験**

<div id="prerequisites">
  ## 前提条件
</div>

* カメラを搭載した iOS 17 以降のデバイス
* 開発用の Xcode 15 以降
* App Store 配布用の Apple Developer アカウント
* Perplexity API key (Sonar Pro) 
* OpenAI API key (GPT-3.5) 
* PubMed E-utilities へのアクセス権

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/nickjlamb/PosterLens.git
cd PosterLens

# Xcode で開く
open PosterLens.xcodeproj
```

<div id="configuration">
  ## 設定
</div>

プロジェクトの設定に API キーを追加します。

```swift theme={null}
// API設定
PERPLEXITY_API_KEY=your_sonar_pro_api_key
OPENAI_API_KEY=your_gpt_api_key
PUBMED_API_KEY=your_pubmed_api_key
```

<div id="usage">
  ## 使い方
</div>

1. **App Store からインストール**: iOS App Store から PosterLens をダウンロードします
2. **ポスターをスキャン**: カメラを学術ポスターに向けます
3. **OCR 処理**: Apple Vision がテキストを自動で抽出します
4. **質問する**: 自然言語でポスターの内容について質問します
5. **関連研究を探索**: Sonar Pro で意味的に関連する研究を見つけます
6. **引用を検証**: PubMed 連携で学術文献の参照を確認します

<div id="code-explanation">
  ## コードの解説
</div>

* **フロントエンド**: モダンなUI/UXを実現するSwiftUIで構築したネイティブiOSアプリ
* **OCR処理**: 画像からのテキスト抽出にApple Visionフレームワークを使用
* **AI統合**: セマンティック検索と文脈理解にPerplexity Sonar Pro APIを利用
* **自然言語**: Q&amp;Aとコンテンツ解釈にGPT-3.5を使用
* **学術的検証**: 引用の検証にPubMed E-utilitiesを利用
* **オンデバイス処理**: プライバシーとパフォーマンスに配慮し、OCRと処理をローカルで実行
* **研究支援**: 研究課題と今後の方向性を自動生成
