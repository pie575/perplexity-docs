  ### 主な機能:

* 📸 住宅の写真をアップロード

* 📄 AI が生成する詳細なレポートを取得:

* 🧾 GDPR 準拠のデータ管理

自宅を守りたい方も、新居の購入を検討している方も、ただ安心を得たい方も — **FlameGuard AI™ が1枚の写真を対策プランに変えます**。

<div id="how-it-works">
  ## ⚙️ 仕組み
</div>

<div id="the-flameguard-ai-process">
  ### FlameGuard AI™ の処理の流れ
</div>

1. **📸 アップロード**: ユーザーが自宅・所有物件の写真をアップロード
2. **👁️ AIによる画像解析**: OpenAI Vision APIが具体的な火災リスクを特定 (例: 燃えやすい屋根材、近くの乾燥した低木など) 
3. **🔍 ディープリサーチ**: リスクごとに**個別のリサーチ計画**を生成し、Perplexity Sonarへの**エージェント的な反復呼び出し**を実行
4. **📄 レポート生成**: リサーチ結果を**集約・整理・整形**し、実行につながるHTMLレポートを作成 — 引用、リンク、図解によるガイダンス付き
5. **📧 配信**: DIYでの対策方法と専門業者への依頼に関する提案をまとめた詳細レポートをメールで送信

<div id="deep-research-with-perplexity-sonar-api">
  ### 🔍 Perplexity Sonar API によるディープリサーチ
</div>

本当に革新的なのは、**Perplexity Sonar API** の使い方です。

* 入手可能な最良の情報を収集するリサーチアシスタントとして活用します
* 各火災リスクに対して、深刻度、リスク軽減策、地域固有の知見を網羅する複数のクエリを実行します
* 結果には、地域の防火基準、気象パターン、地元施工業者の対応可否などが含まれます

こうした**構造化された信頼性の高いAIを活用したリサーチは、Perplexity なしには実現できません**。

<div id="technical-stack">
  ### 技術スタック
</div>

FlameGuard AI™ は最新の生成AIスタックを基盤とし、スケーラビリティを考慮して構築されています。

* **フロントエンド**: ユーザーアカウント管理、写真アップロード、レポート閲覧に対応した軽量な HTML ダッシュボード
* **バックエンド**: Python (Flask) ＋ RESTful API
* **データベース**: PostgreSQL (ローカル) 、**Azure SQL 対応**スキーマ
* **AI 連携**: OpenAI Vision API + Perplexity Sonar API
* **クラウド対応**: **Azure App Service** を想定し、Docker コンテナでデプロイ可能
