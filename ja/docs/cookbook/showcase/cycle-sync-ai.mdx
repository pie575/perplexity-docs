**CycleSyncAI** は、女性の**生理周期のフェーズ**に合わせた、パーソナライズされた**食事とワークアウトの提案**を行う iOS アプリです。

Apple **HealthKit** の生理データと、任意で入力できるユーザープロフィール (年齢、体重、身長、既往症、食事制限、目標、好み) を組み合わせ、総合的なウェルネスをサポートする、その時々のフェーズに応じた提案を動的に生成します。

内容が固定的なウェルネスツールとは異なり、**CycleSyncAI** は **Perplexity の Sonar Pro API** を活用し、**専門的な知見に基づく** LLM 生成のガイダンス (毎日の買い物リストやモチベーションを高めるフィードバックなど) を、ユーザーの周期とライフスタイルに合わせて提供します。

<div id="problem-solution">
  ## 課題と解決策
</div>

> **なぜ重要か:**
> 多くのアプリは、月経周期に伴うホルモン変化が女性のフィットネスや栄養のニーズに与える影響を考慮しておらず、ユーザーには一般的なアドバイスしか届きません。

**CycleSyncAI** は、Apple HealthKit のデータと Sonar Pro の LLM を組み合わせてこのギャップを埋め、より良い健康成果につながる **周期に適応したレコメンデーション** を生成します。

<div id="features">
  ## 機能
</div>

* 月経周期のフェーズに応じた**パーソナライズされた食事・運動の提案**
* Apple HealthKit と連携し、リアルタイムで周期を追跡
* 高度なパーソナライズのためのユーザープロフィール入力 (年齢、目標、制限事項など) 
* **毎日の買い物リストを自動生成**
* グラデーションと控えめなアニメーションによる、滑らかでモダンな UI
* ユーザーの好みに合わせた**モチベーションを高める AI フィードバック**
* ローカルでのデータ保存とプライベートな処理

<div id="setup-instructions">
  ## セットアップ手順
</div>

1. リポジトリをクローンする
2. **Xcode** で開く
3. デバイスで Apple HealthKit が有効になっていることを確認する
4. **Sonar Pro の API key** を設定する
5. 実機でアプリを実行する (推奨)

<div id="sonar-api-usage">
  ## Sonar API の利用
</div>

このアプリは、以下の情報を含む構造化されたプロンプトを **Sonar Pro API** に送信します。

* 月経周期のフェーズ (HealthKit から取得) 
* ユーザープロフィール情報 (年齢、体重、目標など) 
* 食事の好みと制限

そのレスポンスとして、次の内容を受け取ります。

* **パーソナライズされた食事プラン**
* **カスタムのワークアウトプラン**
* **毎日の買い物リスト**
* **モチベーションを高めるフィードバック**

これらはパースされ、WebView を使ってアプリ内にスタイル付きの HTML として表示されます。
