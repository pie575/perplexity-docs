**Sonar Chromium Browser** は、Perplexity の Sonar API をネイティブに統合し、AI 機能をブラウザ上で直接利用できるようにする Chromium ブラウザ用パッチです。オムニボックスに `sonar <query>` と入力すれば即座に AI の回答が得られ、テキストを選択して右クリックから「Summarize with Sonar」を選べば手早く要約できます。調査やブラウジングのワークフローがこれにより効率化されます。

<div id="features">
  ## 機能
</div>

* **オムニボックスでのAI回答** — `sonar <query>` 構文で即座に回答を取得
* **コンテキストメニューからの要約** — 選択したテキストをワンクリックで要約
* **ネイティブなブラウザ統合** — ChromiumのオムニボックスおよびコンテキストメニューAPIを利用
* **2つのモデルに対応** — オムニボックスにはSonar Pro、要約にはSonarを使用
* **デバウンスによる入力処理** — 効率的なAPI利用を実現
* **カスタムブラウザビルド** — AI統合パターンの実例を提示

<div id="prerequisites">
  ## 前提条件
</div>

* Ubuntu 22.04 (WSL2 推奨) 
* Chromium ソースコードのチェックアウト
* Perplexity API key
* Chromium のビルドに 16GB 以上の RAM
* Git および標準的なビルドツール

<div id="installation">
  ## インストール
</div>

```bash theme={null}

cd perplexity-hackathon-chromium

# Chromium のソースにパッチを適用
# Chromium の詳細なセットアップ手順は README を参照
```

<div id="configuration">
  ## 設定
</div>

変更したファイル内の API キーを更新します。

```cpp theme={null}
// sonar_autocomplete_provider.cc および render_view_context_menu.cc 内
const std::string API_KEY = "your_perplexity_api_key_here";
```

<div id="usage">
  ## 使い方
</div>

1. リポジトリの手順に従って、パッチを適用した **Chromium をビルド**します
2. AI 統合を組み込んだ**カスタムブラウザを起動**します
3. **オムニボックス AI を使う**: アドレスバーに `sonar what is quantum tunneling?` と入力します
4. **コンテキスト要約を使う**: テキストを選択し、右クリックして「Summarize with Sonar」を選択します

<div id="code-explanation">
  ## コードの説明
</div>

* **オムニボックス統合**: Chromium のオムニボックス API に接続するカスタムオートコンプリートプロバイダー
* **コンテキストメニュー**: テキスト要約用に改変したレンダービューのコンテキストメニュー
* **API 統合**: デバウンス処理した入力による Perplexity Sonar API の直接呼び出し
* **モデルの選択**: オムニボックスのクエリには Sonar Pro、テキスト要約には Sonar を使用
* **ブラウザーアーキテクチャ**: AI 機能を実装するための Chromium の拡張ポイントを実演
* **ビルド手順**: AI 用パッチを適用したカスタム Chromium ビルド
