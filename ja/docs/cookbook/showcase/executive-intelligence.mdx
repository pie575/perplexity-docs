**Executive Intelligence** は、経営幹部や取締役会メンバーに、戦略的意思決定に必要なインテリジェンスを即座に、正確かつ信頼できる形で提供する、Perplexity Sonar 活用の総合アプリケーションです。Perplexity の Sonar API を基盤に、リアルタイムのデータソースから導き出した、取締役会にそのまま提出できる水準のインサイトをお届けします。

<div id="features">
  ## 機能
</div>

* **競合インテリジェンスブリーフ** — 包括的で取締役会にそのまま提出できる競合分析と、検証可能な引用を提供
* **シナリオプランニング (「What If?」分析)&#x20;**&#x20;— リアルタイムデータに基づく動的な将来シナリオの生成
* **ボードパックメモリ** — インテリジェンスブリーフ、シナリオ分析、ベンチマークレポートの保存と整理
* **即時ベンチマーキングと同業他社比較** — 主要指標について出典付きの視覚的な比較を提供
* **リアルタイムデータ連携** — Perplexity Sonar API を活用した最新の市場インテリジェンス
* **プロフェッショナルな書式** — 構造化されたレポート、エグゼクティブサマリー、取締役会向けプレゼンテーション

<div id="prerequisites">
  ## 前提条件
</div>

* Node.js 18以上、および npm/yarn
* Git
* Perplexity API key (Sonar Pro)

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/raishs/perplexityhackathon.git
cd perplexityhackathon

# 依存関係をインストール
npm install

# 環境変数を設定
cp .env.example .env.local
```

<div id="configuration">
  ## 設定
</div>

`.env.local` ファイルを作成します。

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key
```

<div id="usage">
  ## 使い方
</div>

1. **開発サーバーの起動**:
   ```bash theme={null}
   npm run dev
   ```

2. **アプリケーションへのアクセス**: ブラウザで [http://localhost:3000](http://localhost:3000) を開きます

3. **インテリジェンスの生成**:
   * 入力欄に企業名を入力します
   * 「Competitive Analysis」をクリックすると、包括的なブリーフが生成されます
   * 「what-if」分析には「シナリオプランニング」を使用します
   * 同業他社との比較には「ベンチマーキング」を利用します
   * レポートを「ボードパック」に保存しておけば、後から参照できます

4. **ボードパック の管理**: 「📁 ボードパック」ボタンから、保存したインテリジェンスレポートを閲覧・管理できます

<div id="code-explanation">
  ## コードの解説
</div>

* **フロントエンド**: TypeScriptとReactを使ったNext.jsで、モダンでレスポンシブなUIを実現
* **バックエンド**: Perplexity Sonar APIとの連携を担うNext.jsのAPIルート
* **AI連携**: リアルタイムの競合インテリジェンスとシナリオ分析にPerplexity Sonar Proを利用
* **状態管理**: React Contextによるボードルームメモリと永続的なデータ保存
* **Markdown処理**: AI応答のパースと引用処理を行うカスタムユーティリティ
* **エラー処理**: API呼び出しにおける包括的なタイムアウト・エラー管理
* **プロフェッショナルな出力**: 出典付きで取締役会にそのまま提出できる構造化フォーマット
