**Perplexity Client** は、PerplexityのSonar APIを利用するための洗練されたインターフェースを備えたElectronベースのデスクトップアプリケーションです。最大トークン数 などの高度なAPIパラメータも扱えるため、美しいmacOS風のUIを使いながらAIとのやり取りをきめ細かく制御したい開発者に最適です。

<img src="https://mintcdn.com/perplexity/y2ljsQXTUHXyDIEa/docs/cookbook/static/img/perplexity-client-main.png?fit=max&auto=format&n=y2ljsQXTUHXyDIEa&q=85&s=0e79dbca21cdd63a15fbf72e9fc2becc" alt="Perplexity Client Interface" width="1344" height="750" data-path="docs/cookbook/static/img/perplexity-client-main.png" />

<div id="features">
  ## 機能
</div>

* **複数の Sonar モデル**：Sonar、Sonar Pro、Sonar Reasoning Pro に対応
* **カスタムスペース**：用途に応じて保存・読み込みが可能
* **API パラメータの制御**：最大トークン数の調整など
* **API デバッグモード**：リクエスト/レスポンスのペイロード全体を表示し、トラブルシューティングを支援
* **トークン使用量の追跡**：API の消費量とコストを把握
* **フォーカスモード**：コーディング、ライティング、リサーチなどの特定用途向け

<div id="prerequisites">
  ## 前提条件
</div>

* Node.js v16 以上
* npm または yarn
* Perplexity API キー

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/straight-heart/Perplexity-client-.git
cd Perplexity-client-

# 依存関係をインストール
npm install

npm run dev
```

<div id="build">
  ## ビルド
</div>

対象のプラットフォーム向けにアプリケーションをビルドします。

```bash theme={null}
npm run build:win    # Windows
npm run build:mac    # macOS
npm run build:linux  # Linux
```

<div id="configuration">
  ## 設定
</div>

API キーはアプリケーション内で直接管理します。

1. アプリを起動し、設定 (歯車アイコン) を開きます
2. **API Keys** セクションで **Add Key** をクリックします
3. Perplexity API キーを入力します
4. キーは安全に保存され、セッションをまたいで保持されます

カスタムのシステムプロンプトを使う場合は、**スペース** 機能で複数の命令セットを保存し、切り替えて利用できます。

<div id="usage">
  ## 使い方
</div>

1. **起動**: `npm run dev` を実行するか、ビルド済みのアプリケーションを使用します
2. **API キーの追加**: 設定を開き、Perplexity の API キーを追加します
3. **モデルの選択**: ドロップダウンから Sonar の各バリアントを選択します
4. **スペースの作成**: タスクごとにカスタムのシステムプロンプトを設定します
5. **チャット**: リアルタイムのストリーミング応答で会話を開始します
6. **デバッグ**: API デバッグを有効にして、リクエスト/レスポンスの詳細をすべて確認します
7. **使用量の追跡**: 設定パネルでトークンの消費量を監視します

<div id="limitations">
  ## 制限事項
</div>

* デスクトップのみ対応 (Windows、macOS、Linux) — モバイル版・ウェブ版はありません
* API 呼び出しにはインターネット接続が必要です
* 動作には API キー が必要です
