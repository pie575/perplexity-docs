<div id="citypulse-ai-powered-geospatial-discovery">
  # CityPulse - AIを活用した地理空間ディスカバリー
</div>

![CityPulse Main Interface](https://raw.githubusercontent.com/anevsky/CityPulse/main/assets/CityPulse-GeoSearch-App-1.jpg)

CityPulseは、ユーザーが今まさに周囲で起きていることを探索できる、インテリジェントな位置情報ベースの検索アプリです。PerplexityのSonarモデルを使って、パーソナライズされたリアルタイムのローカルインサイトを提供する方法を紹介します。

[![Demo Video](https://cdn.loom.com/sessions/thumbnails/65077fa27571442e680edf787b0f0690d-2fa2c36169822631-full-play.gif)](https://youtu.be/Y0UIhh3diJg)

<div id="what-citypulse-does">
  ## CityPulse でできること
</div>

* **リアルタイムのローカル探索** - 任意の地点の周辺で開催中のイベント、レストラン、地域アラートを検索
* **AI による検索候補** - 入力に合わせて最適な検索候補を提示
* **パーソナライズされたインサイト** - おすすめの体験、訪れるのに最適な時間帯、通ならではのヒントを AI が生成
* **インタラクティブな地図表示** - カスタムマーカーと詳細なポップアップを備えたインタラクティブな地図上で結果を探索

![Search Interface](https://raw.githubusercontent.com/anevsky/CityPulse/main/assets/CityPulse-GeoSearch-App-2.jpg)

<div id="how-it-uses-perplexity-sonar">
  ## Perplexity Sonar の活用方法
</div>

CityPulse は、主要な 2 つの Perplexity モデルを活用しています。

**リアルタイムデータ向けの Sonar**

```python theme={null}
# 位置情報を踏まえて最新のローカル情報を取得する
response = client.chat.completions.create(
    model="sonar",
    messages=[{
        "role": "user", 
        "content": f"Find current events, restaurants, and alerts near {lat}, {lng}"
    }],
    response_format={"type": "json_schema", "json_schema": {"schema": LOCAL_INFO_SCHEMA}}
)
```

**パーソナライズされたインサイトを実現する Sonar Reasoning Pro**

```python theme={null}
# AIを活用した場所のおすすめを生成
response = client.chat.completions.create(
    model="sonar-reasoning-pro",
    messages=[{
        "role": "user",
        "content": f"Provide personalized insights for {location_name}: what to try, best times to visit, pro tips"
    }]
)
```

このアプリは構造化されたJSONスキーマを利用してデータ形式の一貫性を確保し、出典検証のための引用トラッキング機能も備えています。
