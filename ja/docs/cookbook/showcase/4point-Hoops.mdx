**4Point Hoops** は、生のバスケットボール統計データを、実用的でストーリー性のあるインサイトへと変換する高度なNBA分析プラットフォームです。Basketball-Referenceをリアルタイムにスクレイピングし、文脈情報を豊富に含むプロンプトをPerplexityのSonar Proモデルにルーティングすることで、ファンやアナリスト、ファンタジープレイヤーが単なる数字にとどまらず「なぜそうなったのか」「次に何が起こるのか」を理解できるよう支援します。

<div id="features">
  ## 機能
</div>

* **選手アナリティクス** — レギュラーシーズン／プレーオフ別のデータ、シュートタイプ別の内訳、任意のNBA選手のパフォーマンスレーダーを提供
* **時代を超えた比較** — スタッツを並べて比較可能 (例: 1997年のMichael Jordan vs. 2022年のStephen Curry) 
* **チームダッシュボード** — 順位表、プレーオフ進出確率のサンキーフロー、自動更新されるKPIタイルを搭載
* **AI Explainと類似選手** — スタッツラインをワンクリックでSonarが解説し、比較対象となる選手をAIが選出
* **バスケットボールAIチャット** — NBAの歴史、ロスター、予測についてエキスパートLLMに質問可能
* **クレジット制SaaSシステム** — Firebase Auth、Googleログイン、クレジットウォレット、管理ツールを完備

<div id="prerequisites">
  ## 前提条件
</div>

* Node.js 16以上およびnpm
* Python 3.8以上およびpip
* Firebaseプロジェクトのセットアップ
* Perplexity APIキー (Sonar Pro) 
* Basketball-Referenceへのアクセス

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# フロントエンドのリポジトリをクローン
git clone https://github.com/rapha18th/hoop-ai-frontend-44.git
cd hoop-ai-frontend-44
npm install

# バックエンドのリポジトリをクローン
git clone https://github.com/rapha18th/4Point-Hoops-Server.git
cd 4Point-Hoops-Server
pip install -r requirements.txt
```

<div id="configuration">
  ## 設定
</div>

バックエンドディレクトリに `.env` ファイルを作成します。

```ini theme={null}
PERPLEXITY_API_KEY=your_sonar_pro_api_key
FIREBASE_PROJECT_ID=your_firebase_project_id
FIREBASE_PRIVATE_KEY=your_firebase_private_key
FIREBASE_CLIENT_EMAIL=your_firebase_client_email
```

<div id="usage">
  ## 使い方
</div>

1. **バックエンドの起動**:
   ```bash theme={null}
   cd 4Point-Hoops-Server
   python app.py
   ```

2. **フロントエンドの起動**:
   ```bash theme={null}
   cd hoop-ai-frontend-44
   npm run dev
   ```

3. **アプリケーションへのアクセス**: フロントエンドのURLを開き、AIによるインサイトを活用したNBA分析を試してみてください

4. **AI機能の利用**: 任意の選手やスタッツで「AI Explain」をクリックすると、Perplexity Sonarによる高度な分析が得られます

<div id="code-explanation">
  ## コードの説明
</div>

* **フロントエンド**: React に shadcn/ui コンポーネントと、データ可視化用の Recharts を組み合わせて構成
* **バックエンド**: Basketball-Reference のデータを提供し、Perplexity API の呼び出しを管理する Python Flask API
* **データパイプライン**: リアルタイムのデータ収集を行う BRScraper と Firebase によるキャッシュ
* **AI 連携**: バスケットボールの高度な分析と解説を担う Perplexity Sonar Pro
* **認証**: Google ログインとクレジットベースのアクセス制御を備えた Firebase Auth
* **デプロイ**: フロントエンドは Netlify、バックエンドは Docker を利用して Hugging Face Spaces にデプロイ
