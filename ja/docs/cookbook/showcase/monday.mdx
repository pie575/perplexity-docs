**Monday** は、自然言語のクエリと質の高い教育コンテンツとの間のギャップを埋めるために設計された、音声対応の AI 学習コンパニオンです。Marvel の JARVIS と FRIDAY に着想を得た Monday は、Basic、Reasoning、Deep Research の 3 つのモードでニーズに合わせた応答を返しつつ、没入感のある可視化、厳選された動画コンテンツ、アクセシビリティを最優先した設計を統合しています。

<div id="features">
  ## 機能
</div>

* **3つの学習モード**: 基本的な事実回答、段階的な推論、そして深掘りのリサーチ調査
* 自然言語処理によるハンズフリー学習を実現する**音声ファーストのインタラクション**
* Three.js と WebXR による概念の**リアルタイム3D可視化**
* 信頼できるソースから厳選した**教育系YouTube動画の統合**
* テキスト、音声 (ElevenLabs 利用) 、空間パネルを組み合わせた**マルチモーダルなフィードバック**
* ヘッドセットがなくても没入体験を得られる**VRオプショナルな設計**
* 肢体不自由・視覚障がいのある方にも配慮した**アクセシビリティ重視のインターフェース**

<div id="prerequisites">
  ## 前提条件
</div>

* Node.js 18 LTS 以降
* モダンな Web ブラウザ (Chrome、Edge、Firefox を推奨) 
* 音声対話用のマイク
* 任意: 没入モード用の VR ヘッドセット (WebXR 対応) 
* Perplexity API キー、ElevenLabs API キー、YouTube API キー

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/srivastavanik/monday.git
cd monday
git checkout final
cd nidsmonday

# 依存関係をインストール

```

```ini theme={null}
# .env ファイルを作成し、API キーを設定します
PERPLEXITY_API_KEY=your_api_key

```

```bash theme={null}
# バックエンドサーバーを起動
node backend-server.js

# フロントエンドを起動
npm run dev
```

<div id="usage">
  ## 使い方
</div>

1. ブラウザでアプリを起動します
2. **「Hey Monday」** と話しかけてアシスタントを有効化します
3. 次の3つのモードのいずれかで質問します。
   * **Basic Mode** – 「光合成とは何ですか?」
   * **Reasoning Mode** – 「ブロックチェーンの仕組みについて考えてください。」
   * **Deep Research Mode** – 「量子力学の歴史について調査してください。」
4. 回答はフローティングテキストパネル、音声応答、インタラクティブな3Dモデルとして表示されます

<div id="code-explanation">
  ## コードの解説
</div>

* **フロントエンド**: TypeScript に加え、3D 可視化に Three.js、VR 対応に WebXR を使用
* **バックエンド**: Node.js と Socket.IO によるリアルタイムな音声コマンド処理
* **AI 連携**: Perplexity Sonar API による、推論内容の抽出を伴うインテリジェントな応答
* **音声処理**: ElevenLabs による音声合成と自然言語理解
* **コンテンツのキュレーション**: 教育系動画向けのスマートなキーワード抽出を備えた YouTube API 連携
* **アクセシビリティ**: 空間オーディオとハプティックフィードバックに対応した音声ファーストの設計
