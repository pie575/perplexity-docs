**StarPlex** は、起業家がビジネスアイデアを検証し、成功に必要なリソースとつながることを支援する AI スタートアップインテリジェンスプラットフォームです。主に **Perplexity Sonar Pro** を基盤とし、メイン UI にインタラクティブな **3D グローブインターフェース** を採用しています。スタートアップのアイデアを入力するだけで、AI エンジンが分析を行い、インサイトをグローブ上に直接可視化します。競合、市場、人口統計、VC、共同創業者候補を、世界規模でリアルタイムにマッピングします。

<div id="features">
  ## 機能
</div>

* **市場検証分析** — AI耐性スコアリング、時価総額の推定、成長トレンド分析に対応
* **インタラクティブな3Dグローブインターフェース** — 世界のスタートアップインテリジェンスデータを可視化
* **競合リサーチ** — 脅威スコアリングと競争環境のマッピング
* **VC・投資家マッチング** — 投資テーゼとポートフォリオの適合性に基づくマッチング
* **共同創業者の探索** — 相性スコアリングと専門性のマッチング
* **デモグラフィックリサーチ** — ターゲット層の所在地をヒートマップで可視化
* **AIピッチデッキ生成** — 投資家向けプレゼンテーションを自動作成
* **コンテキスト認識型チャットボット** — すべてのリサーチデータを横断するRAG統合を搭載

<div id="prerequisites">
  ## 前提条件
</div>

* Node.js 18以上とnpm
* Python 3.8以上とpip
* Perplexity APIキー (Sonar Pro) 
* MapboxトークンとSERP APIキー

<div id="installation">
  ## インストール
</div>

```bash theme={null}
# リポジトリをクローン
git clone https://github.com/JerryWu0430/StarPlex.git
cd StarPlex

# バックエンドのセットアップ
cd backend
pip install -r requirements.txt

# フロントエンドのセットアップ
cd ../frontend
npm install
```

<div id="configuration">
  ## 設定
</div>

バックエンドディレクトリに `.env` ファイルを作成します。

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key
MAPBOX_TOKEN=your_mapbox_token
SERPAPI_KEY=your_serpapi_key
```

<div id="usage">
  ## 使い方
</div>

1. **バックエンドの起動**:
   ```bash theme={null}
   cd backend
   python main.py
   ```

2. **フロントエンドの起動**:
   ```bash theme={null}
   cd frontend
   npm run dev
   ```

3. **アプリケーションへのアクセス**: [http://localhost:3000](http://localhost:3000) を開き、スタートアップのアイデアを入力します

4. **インテリジェンスの探索**: 3Dグローブ上で競合、VC、人口統計、共同創業者候補を可視化します

5. **アセットの生成**: ピッチデッキを作成し、分析結果についてAIアシスタントと対話します

<div id="how-starplex-uses-perplexity-sonar-api">
  ## StarPlex における Perplexity Sonar API の活用方法
</div>

StarPlex は、**マルチモジュール型のインテリジェンスアーキテクチャ**を通じて Perplexity の Sonar API を活用しています。

**市場分析エンジン**
Sonar Pro を用いて包括的な市場検証を行い、Google トレンドのデータと AI 分析を組み合わせて、時価総額の推定値、AI による破壊度スコア、成長予測を構造化された JSON 出力として生成します。

**競合インテリジェンス**
複数の Sonar クエリを並行実行し、競合企業、資金調達状況、脅威レベルを特定します。各競合には 1〜10 の脅威スコアが付与され、詳細な競争ポジショニング分析が添えられます。

**VC・共同創業者マッチング**
Sonar のリアルタイムなウェブ知識を活用して、関連する投資家や共同創業者候補を発見し、投資テーゼとの整合性、専門性の適合度、地理的な近さに基づいてマッチングをスコアリングします。

**コンテキスト対応ビジネスアシスタント**
すべてのリサーチデータを Sonar の会話に渡すことで RAG (検索拡張生成) を実装し、市場ポジショニング、競合の脅威、戦略的意思決定に関する質問に答えられる、知見豊富なスタートアップアドバイザーを実現します。

**地理インテリジェンス**
Sonar の人口統計インサイトと Mapbox のジオコーディングを組み合わせ、ターゲットオーディエンスが世界のどこに集中しているかを示すインタラクティブなヒートマップを作成します。

<div id="code-explanation">
  ## コードの解説
</div>

* **バックエンド**: Python FastAPI と AsyncIO により、複数の分析モジュールにまたがる Perplexity API 呼び出しを並行実行
* **フロントエンド**: Next.js と React 19 を採用し、3D グローブの可視化に Cobe、インタラクティブな地図表示に Mapbox GL を利用
* **AI 連携**: 複雑な分析には Sonar Pro、高速性が求められるクエリには Sonar を使い分けるマルチモデル構成の Perplexity 活用戦略
* **データパイプライン**: インテリジェントなキャッシュ、構造化された JSON レスポンス、ユーザーに即座にフィードバックを返すリアルタイムストリーミング
* **可視化**: Perplexity から得たインサイトとインタラクティブな地球儀／地図インターフェースを動的にデータバインディング
