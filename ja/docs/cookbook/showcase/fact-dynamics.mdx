<div id="fact-dynamics-real-time-fact-checking-flutter-app">
  # Fact Dynamics | リアルタイムファクトチェック Flutter アプリ
</div>

<p align="center">
  <img src="https://raw.githubusercontent.com/vishnu32510/fact_pulse/main/assets/icon/icon.png" alt="Fact Dynamics logo" width="80" height="80" style={{ borderRadius: '14px' }} />
</p>

**ハッカソン応募作品** — Perplexity Hackathon の Information Tools 部門および Deep Research 部門向けに開発されました。

Fact Dynamics は、音声コンテンツと画像をリアルタイムでファクトチェックできるクロスプラットフォームの Flutter アプリです。ライブディベートやプレゼンテーション、その場での情報検証に最適です。

<div id="features">
  ## 機能
</div>

* ライブ会話中のリアルタイム音声書き起こしとファクトチェック

* 画像内テキストの抽出と、出典付きの主張検証

* 主張の評価システム (TRUE、FALSE、MISLEADING、UNVERIFIABLE) と、その根拠の説明

* 出典の提示 — 各判定の裏付けとなる信頼性の高いURLを提供

* 連続音声認識とストリーミングフィードバックに対応したディベートモード

* Firebase (Google、メール) によるユーザー認証と、チャット履歴の永続保存

* iOS、Android、Web のクロスプラットフォーム対応

<div id="prerequisites">
  ## 前提条件
</div>

* Flutter SDK 3.0.0 以降
* Dart SDK 2.17.0 以降
* 認証とデータベースのセットアップに使用する Firebase CLI
* Sonar 連携用の Perplexity API key
* 音声認識用にマイクを利用できるデバイス

<div id="usage">
  ## 使い方
</div>

<div id="real-time-speech-fact-checking">
  ### リアルタイム音声ファクトチェック
</div>

* Flutter の `speech_to_text` を使って5秒単位の音声チャンクをストリーミング
* 文字起こしした断片を構造化プロンプトとともに Sonar API へ送信
* 主張、判定 (TRUE/FALSE/MISLEADING/UNVERIFIABLE) 、説明、出典を含む JSON を返却

<div id="image-analysis">
  ### 画像解析
</div>

* 画像やURLをSonar APIにアップロードしてテキストを抽出
* 抽出した主張を権威ある情報源と照合して検証
* 出典を明示した包括的な分析を提供

<div id="code-explanation">
  ## コードの解説
</div>

* フロントエンド: iOS、Android、Web 向けの Flutter。状態管理には BLoC パターンを採用
* バックエンド: Firebase (Firestore、Authentication) 。ユーザーデータとチャット履歴を永続化
* 音声処理: speech&#95;to&#95;text パッケージによるリアルタイムの音声文字起こし
* API 連携: 構造化プロンプトで Perplexity Sonar API を呼び出すカスタム Dart クライアント
* 画像処理: マルチモーダル解析向けに base64 エンコードに対応した組み込みの画像ピッカー
* データ構成: ユーザーごとの Firestore コレクションと、ディベート・スピーチ・画像用のサブコレクション

<div id="open-source-sdks">
  ## オープンソース SDK
</div>

* **[perplexity&#95;flutter](https://pub.dev/packages/perplexity_flutter)** - Flutter ウィジェットと BLoC 連携
