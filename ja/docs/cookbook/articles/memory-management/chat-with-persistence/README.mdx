<div id="persistent-chat-memory-with-perplexity-sonar-api">
  # Perplexity Sonar API による永続的なチャットメモリ
</div>

<div id="overview">
  ## 概要
</div>

この実装では、LlamaIndex のベクトルストレージと Perplexity の Sonar API を利用して、長期的な会話メモリを保持する方法を紹介します。高度な検索と要約によって、複数の API 呼び出しをまたいでコンテキストを維持します。

<div id="key-features">
  ## 主な機能
</div>

* **マルチターンのコンテキスト保持**: 過去のクエリと応答を記憶します
* **セマンティック検索**: ベクトル埋め込みにより関連する会話履歴を検索します
* **Perplexity 連携**: sonar-pro モデルを活用して精度の高い応答を生成します
* **LanceDB ストレージ**: 列指向ベクトルデータベースによる会話履歴の永続化

<div id="implementation-details">
  ## 実装の詳細
</div>

<div id="core-components">
  ### 主要コンポーネント
</div>

```python theme={null}
# メモリの初期化
vector_store = LanceDBVectorStore(uri="./lancedb", table_name="chat_history")
storage_context = StorageContext.from_defaults(vector_store=vector_store)
index = VectorStoreIndex([], storage_context=storage_context)
```

<div id="conversation-flow">
  ### 会話フロー
</div>

1. ユーザーのクエリをベクトル埋め込みとして保存
2. 関連性の高い過去のやり取りを上位3件取得
3. 文脈となる履歴を付与した Sonar API リクエストを生成
4. 以降の会話に備えて応答を永続化

<div id="api-integration">
