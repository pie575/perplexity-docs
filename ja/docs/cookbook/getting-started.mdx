[**Perplexity の API プラットフォーム**](https://docs.perplexity.ai/) を使った開発のための、実践的なガイド、実行可能なサンプル、統合パターンを集めたコレクションです。Agent API、Search API、Embeddings API、Sonar API を扱います。

<Note>
  特定のレシピをお探しですか？[Cookbook のホームページ](/ja/docs/cookbook)では、すべてのレシピを製品・機能・トピックで絞り込んで閲覧できます。
</Note>

<div id="how-to-use-this-cookbook">
  ## この Cookbook の使い方
</div>

<CardGroup cols={2}>
  <Card title="ガイド" icon="book" href="/ja/docs/cookbook/articles/function-calling-e2e/README">
    ドキュメントの範囲を超えたパターンを実践的に掘り下げます。構造化出力、関数呼び出し、RAG パイプライン、横断的なベストプラクティスなどを扱います。
  </Card>

  <Card title="サンプル" icon="code-circle" href="/ja/docs/cookbook/examples/README">
    すべての API を網羅した実行可能なプロジェクト。リサーチアシスタントやニュース監視から、ドキュメントの Q&amp;A、画像解析まで、Python と TypeScript で提供します。
  </Card>

  <Card title="統合ガイド" icon="link" href="/ja/docs/cookbook/articles/openai-agents-integration/README">
    OpenAI Agents SDK、LangChain のメモリシステム、永続ストレージなど、外部フレームワークと Perplexity を連携させます。
  </Card>

  <Card title="コミュニティショーケース" icon="sparkles" href="/ja/docs/cookbook/showcase/briefo">
    コミュニティが実際に構築したアプリケーション。API プラットフォームで他の開発者がどのようなものを作っているかをご覧ください。
  </Card>
</CardGroup>

<div id="quick-start">
  ## クイックスタート
</div>

<Steps>
  <Step title="APIアクセスを取得する">
    Perplexity API プラットフォームを利用するには、API keyが必要です。まだお持ちでない場合は、以下から取得してください。

    <Card title="Perplexity API Key を取得する" icon="key" arrow="True" horizontal="True" iconType="solid" cta="こちらをクリック" href="https://perplexity.ai/account/api">
      API ポータルの **API Keys** タブを開き、新しいキーを生成します。
    </Card>
  </Step>

  <Step title="SDKをインストールする">
    Perplexity API SDK は Python と TypeScript で提供されています。使用する言語のパッケージをインストールしてください。

    <CodeGroup>
      ```bash Python theme={null}
      pip install perplexityai
      ```

      ```bash TypeScript theme={null}
      npm install @perplexity-ai/perplexity_ai
      ```
    </CodeGroup>
  </Step>

  <Step title="始め方を選ぶ">
    Perplexity API プラットフォームは、複数のAPIによって幅広いユースケースに対応しています。目的別におすすめの出発点は次のとおりです。

    * プラットフォームを初めて使う場合は、<u>[クイックスタートガイド](/ja/docs/getting-started/quickstart)</u>をご覧ください
    * 何かを作ってみたい場合は、<u>[サンプル](/ja/docs/cookbook/examples/README)</u>をご覧ください
  </Step>
</Steps>
