<div id="financial-news-tracker">
  # 金融ニューストラッカー
</div>

Perplexity の Sonar API を使用して、リアルタイムの金融ニュースを取得・分析するコマンドラインツールです。任意の金融トピックについて、包括的な市場インサイト、ニュース要約、投資分析を取得できます。

<div id="features">
  ## 機能
</div>

* 複数のソースから金融ニュースをリアルタイムに集約
* 市場センチメント分析 (強気／弱気／中立) 
* ニュースごとの影響度評価 (高／中／低) 
* セクター別・企業別の分析
* 投資インサイトと推奨事項の提示
* 期間の柔軟な指定 (24時間〜1年) 
* 構造化JSON出力に対応
* 絵文字で見やすくしたCLI出力

  ## インストール
</div>

<div id="1-install-required-dependencies">

</div>

```bash theme={null}
# requirements ファイルからインストール（推奨）

# または手動でインストール

```

<div id="2-make-the-script-executable">
  ### 2. スクリプトに実行権限を付与する
</div>

```bash theme={null}

```

<div id="api-key-setup">
  ## API keyの設定
</div>

このツールを使用するには、Perplexity の API key が必要です。次のいずれかの方法で指定できます。

<div id="1-as-an-environment-variable-recommended">
  ### 1. 環境変数として設定する (推奨) 
</div>

```bash theme={null}
export PPLX_API_KEY=YOUR_API_KEY
```

<div id="2-as-a-command-line-argument">
  ### 2. コマンドライン引数として渡す
</div>

```bash theme={null}
./financial_news_tracker.py "tech stocks" --api-key YOUR_API_KEY
```

<div id="3-in-a-file">
  ### 3. ファイルに保存する
</div>

同じディレクトリに `pplx_api_key` または `.pplx_api_key` という名前のファイルを作成します。

```bash theme={null}
echo "YOUR_API_KEY" > .pplx_api_key
chmod 600 .pplx_api_key
```

<div id="quick-start">
  ## クイックスタート
</div>

テック株の最新ニュースを取得します。


これにより、テック株に関する最新の金融ニュースを取得し、市場センチメントを分析して、実行可能なインサイトを提供します。

<div id="time-range-options">
  ## 期間の指定オプション
</div>

* `24h` - 過去24時間 (デフォルト) 
* `1w` - 過去1週間
* `1m` - 過去1か月
* `3m` - 過去3か月
* `1y` - 過去1年

<div id="output-format">
  ## 出力形式
</div>

このツールは、以下を含む包括的な財務分析を提供します。

<div id="1-executive-summary">
  ### 1. エグゼクティブサマリー
</div>

主要な財務動向の概要

<div id="2-market-analysis">
  ### 2. 市場分析
</div>

* **市場センチメント**: 市場全体の地合い (🐂 強気、🐻 弱気、⚖️ 中立) 
* **主な変動要因**: 市場に影響を与えている要因
* **リスク**: 現在の市場リスクと懸念事項
* **機会**: 潜在的な投資機会

<div id="3-news-items">
  ### 3. ニュース項目
</div>

各ニュース項目には以下が含まれます:

* **見出し**: ニュースのメインタイトル
* **影響度**: 市場への影響レベル(🔴 高、🟡 中、🟢 低)
* **概要**: ニュースの要約
* **影響セクター**: 影響を受ける業界や企業
* **出典**: ニュースの出典

<div id="4-investment-insights">
  ### 4. 投資インサイト
</div>

ニュースに基づく実用的な推奨事項と分析

<div id="tips-for-best-results">
  ## 最良の結果を得るためのヒント
</div>

1. **具体的に指定する**: 企業のティッカー、セクター名、特定のイベントを含めましょう
2. **トピックを組み合わせる**: 企業名と関連テーマを組み合わせます (例: 「TSLA electric vehicles」) 
3. **期間を指定する**: 投資期間に合わせて対象期間を設定しましょう
4. **定期的なモニタリング**: cron ジョブを設定して日次の市場動向を取得しましょう

<div id="limitations">
  ## 制限事項
</div>

* 結果は入手可能な公開情報に依存します
* 投資助言ではありません。必ずご自身で調査してください
* ごく最近の出来事については、過去データが限られている場合があります
* 構造化出力には Tier 3 以上の Perplexity API アクセスが必要です

<div id="python-integration">
  ### Python での統合
</div>

```python theme={null}
import subprocess
import json

def get_financial_news(query, time_range="24h"):
    result = subprocess.run(
        ["./financial_news_tracker.py", query, "--time-range", time_range, "--json"],
        capture_output=True,
        text=True
    )
    
    if result.returncode == 0:
        return json.loads(result.stdout)
    else:
        raise Exception(f"Error fetching news: {result.stderr}")

# 使用例
news = get_financial_news("tech stocks", "1w")
print(f"Market sentiment: {news['market_analysis']['market_sentiment']}")
```
