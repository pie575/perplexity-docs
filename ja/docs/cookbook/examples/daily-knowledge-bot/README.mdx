<div id="daily-knowledge-bot">
  # Daily Knowledge Bot
</div>

Perplexity AI API を使って、日替わりのトピックに関する興味深い豆知識を届ける Python アプリケーションです。日々の学習、ニュースレターのコンテンツ作成、自己学習に最適です。

<div id="features">
  ## 🌟 主な機能
</div>

* **日替わりトピック**: 日付に応じてトピックを自動選択
* **AIによる豆知識生成**: PerplexityのSonar APIを活用し、興味深く正確な豆知識を生成
* **トピックのカスタマイズ**: トピック一覧の追加・変更が簡単
* **データの永続化**: 生成した豆知識を日付入りのテキストファイルに保存し、後から参照可能
* **堅牢なエラー処理**: APIの障害や予期しないエラーにも適切に対応
* **柔軟な設定**: 環境変数によりAPIキーを安全に管理

<div id="requirements">
  ## 📋 要件
</div>

* Python 3.6以上
* 必要なパッケージ:
  * requests
  * python-dotenv
  *  (任意) logging

<div id="installation">
  ## 🚀 インストール
</div>

1. このリポジトリをクローンするか、スクリプトをダウンロードします
2. 必要なパッケージをインストールします:

```bash theme={null}
# requirements ファイルからインストール（推奨）
pip install -r requirements.txt

# または手動でインストール
pip install requests python-dotenv
```

3. Perplexity API キー を設定します。
   * スクリプトと同じディレクトリに `.env` ファイルを作成します
   * API キー を追加します: `PERPLEXITY_API_KEY=your_api_key_here`

<div id="usage">
  ## 🔧 使い方
</div>

<div id="running-the-bot">
  ### ボットの実行
</div>

スクリプトを実行するだけです。

```bash theme={null}
python daily_knowledge_bot.py
```

これにより、次の処理が行われます。

1. 現在の曜日に基づいてトピックを選択
2. Perplexity AI から興味深い事実を取得
3. 取得した事実を日付付きのテキストファイルとしてカレントディレクトリに保存
4. その事実をコンソールに表示

<div id="customizing-topics">
  ### トピックのカスタマイズ
</div>

`topics.txt` ファイルを編集する (1行に1トピック) か、スクリプト内の `topics` リストを直接変更してください。

トピックの例:

```
天文学
歴史
生物学
テクノロジー
心理学
海洋生物
古代文明
量子物理学
美術史
調理科学
```

<div id="automated-scheduling">
  ### 自動スケジューリング
</div>

<div id="on-linuxmacos-using-cron">
  #### Linux/macOS の場合 (cron を使用) :
</div>

```bash theme={null}
# crontab を編集
crontab -e

# 毎日午前8時に実行するには次の行を追加
0 8 * * * /path/to/python3 /path/to/daily_knowledge_bot.py
```

<div id="on-windows-using-task-scheduler">
  #### Windows の場合 (タスク スケジューラを使用) :
</div>

1. タスク スケジューラを開きます
2. 「基本タスクの作成」で新しいタスクを作成します
3. 毎日実行するように設定します
4. 操作として「プログラムの開始」を追加します
5. プログラム/スクリプト: `C:\path\to\python.exe`
6. 引数: `C:\path\to\daily_knowledge_bot.py`

<div id="configuration-options">
  ## 🔍 設定オプション
</div>

`.env` ファイルでは次の環境変数を設定できます。

* `PERPLEXITY_API_KEY` (必須) : Perplexity API キー
* `OUTPUT_DIR` (任意) : ファクトファイルの保存先ディレクトリ (デフォルト: カレントディレクトリ) 
* `TOPICS_FILE` (任意) : カスタムトピックファイルのパス

<div id="extending-the-bot">
  ## 🛠️ ボットの拡張
</div>

このボットを拡張する方法をいくつか紹介します。

* メールやSMSでの配信機能を追加する
* 豆知識の履歴を閲覧できるWebインターフェースを作成する
* ソーシャルメディアへの投稿と連携する
* 豆知識に応じたマルチメディアコンテンツを追加する
* 特定の曜日に特定のトピックを扱う高度なスケジューリングを実装する

<div id="limitations">
  ## ⚠️ 制限事項
</div>

* Perplexity アカウントによっては、API のレート制限が適用される場合があります
* 豆知識の品質は AI モデルに依存します
* Sonar API の無料版には token の上限があるため、長い応答が途中で切り詰められる場合があります
