<div id="disease-information-app">
  # 疾患情報アプリ
</div>

Perplexity の Sonar API を使って疾患に関する構造化された情報を提供する、ブラウザベースのインタラクティブなアプリケーションです。このアプリはスタンドアロンの HTML インターフェースを生成し、ユーザーはさまざまな疾患について質問して、引用付きの整理された回答を得られます。

<div id="features">
  ## 🌟 機能
</div>

* **使いやすいインターフェース**: さまざまなデバイスに対応する、シンプルでレスポンシブなデザイン
* **AIによる回答**: PerplexityのSonar APIを活用し、正確な医療情報を提供
* **構造化されたナレッジカード**: 情報を概要・原因・治療法に整理
* **引用の追跡**: 情報源をクリック可能なリンク付きで一覧表示
* **クライアントサイドキャッシュ**: 過去に質問された内容に対するAPI呼び出しの重複を防止
* **スタンドアロンでのデプロイ**: サーバーなしで利用できる単一のHTMLファイルを生成
* **包括的なエラー処理**: わかりやすいエラーメッセージと堅牢なエラー管理

<div id="requirements">
  ## 📋 要件
</div>

* Python 3.6以上
* Jupyter Notebook または JupyterLab (開発・生成用) 
* 必要なパッケージ:
  * requests
  * pandas
  * python-dotenv
  * IPython

<div id="setup-installation">
  ## 🚀 セットアップとインストール
</div>

1. このリポジトリをクローンするか、ノートブックをダウンロードします
2. 必要なパッケージをインストールします。

```bash theme={null}
# requirements ファイルからインストール（推奨）
pip install -r requirements.txt

# または手動でインストール
pip install requests pandas python-dotenv ipython
```

3. Perplexity API key を設定します。
   * ノートブックと同じディレクトリに `.env` ファイルを作成します
   * API key を追加します: `PERPLEXITY_API_KEY=your_api_key_here`

<div id="usage">
  ## 🔧 使い方
</div>

<div id="running-the-notebook">
  ### ノートブックの実行
</div>

1. Jupyter でノートブックを開きます。

```bash theme={null}
jupyter notebook Disease_Information_App.ipynb
```

2. すべてのセルを実行して、ブラウザベースのアプリケーションを生成・起動します
3. アプリはデフォルトのWebブラウザで自動的に開きます

<div id="using-the-generated-html">
  ### 生成された HTML の使い方
</div>

生成された `disease_qa.html` ファイルをそのまま利用することもできます。

1. 最新の Web ブラウザで開きます
2. 疾患に関する質問を入力します (例：「糖尿病とは何ですか？」「アルツハイマー病について教えてください」) 
3. 「Ask」をクリックすると、その疾患に関する構造化された情報が表示されます

<div id="deploying-the-app">
  ### アプリのデプロイ
</div>

個人利用や教育目的であれば、生成された HTML ファイルを共有するだけで十分です。

本番環境で利用する場合は、次の点を検討してください。

1. API key を保護するために適切なバックエンドを用意する
2. ファイルを Web サーバー上でホストする
3. 必要に応じて分析機能やユーザー管理を追加する

<div id="how-it-works">
  ## 🔍 仕組み
</div>

このアプリケーションは次のように動作します。

1. 綿密に設計したプロンプトで、AI に構造化された JSON を出力させます
2. この JSON を解析して、概要・原因・治療法・引用を抽出します
3. 抽出した情報を見やすいナレッジカード形式で表示します
4. 適切なエラー処理を備えたクライアントサイドの API 呼び出しを実装します
5. デスクトップとモバイルの双方に適したレスポンシブデザインを提供します

<div id="technical-details">
  ## ⚙️ 技術詳細
</div>

<div id="api-structure">
  ### API 構造
</div>

このアプリは、AI が次の構造の JSON オブジェクトを返すことを前提としています。

```json theme={null}
{
  "overview": "A brief description of the disease.",
  "causes": "The causes of the disease.",
  "treatments": "Possible treatments for the disease.",
  "citations": ["https://example.com/citation1", "https://example.com/citation2"]
}
```

<div id="files-generated">
  ### 生成されるファイル
</div>

* `disease_qa.html` - スタンドアロンアプリケーション
* `disease_app.log` - 詳細なアプリケーションログ (ノートブック実行時)

<div id="customization-options">
  ### カスタマイズオプション
</div>

以下を変更できます。

* `create_html_ui` 関数内の HTML/CSS スタイル
* 使用する AI モデル (デフォルトは &quot;sonar-pro&quot;) 
* 情報フィールドごとのプロンプトの構造
* 出力ファイルの保存先とファイル名

<div id="extending-the-app">
  ## 🛠️ アプリの拡張
</div>

拡張のアイデア:

* Flask/Django のバックエンドを追加して API key を保護する
* ユーザーアカウントと質問の保存機能を実装する
* 疾患統計の可視化を追加する
* 複数の疾患を比較できるビューを作成する
* 自然言語による質問の再整形機能を追加する
* 回答品質に対するフィードバックの仕組みを実装する

<div id="important-notes">
  ## ⚠️ 重要な注意事項
</div>

* **API keyのセキュリティ**: 現在の実装では、API keyをHTMLファイル内に埋め込んでいます。個人利用には問題ありませんが、一般公開する環境での利用には適していません。
* **医療アドバイスではありません**: このアプリが提供するのは一般的な情報であり、医療上の判断に使用しないでください。医療に関する助言は必ず医療専門家にご相談ください。
* **API利用**: ご利用のアカウントに適用されるPerplexity APIのレート制限と料金にご注意ください。
