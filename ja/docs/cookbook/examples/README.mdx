<div id="examples-overview">
  # サンプル概要
</div>

各 Perplexity API の実践的なユースケースを示す、すぐに実行できるプロジェクト集です。それぞれのサンプルには、詳細なセットアップ手順と動作するコードが含まれています。

<div id="api-key-setup">
  ## APIキーの設定
</div>

いずれの例でも Perplexity APIキーが必要です。次のように環境変数に設定してください。

```bash theme={null}
export PERPLEXITY_API_KEY="your-api-key-here"
```

<Tip>
  APIキーは [perplexity.ai/account/api](https://perplexity.ai/account/api) で取得できます。
</Tip>

<div id="common-requirements">
  ## 共通の要件
</div>

* **Python 3.9以上** または **Node.js 18以上** (サンプルによって異なります)
* **Perplexity APIキー**
* API呼び出し用の**インターネット接続**

その他の要件はサンプルごとに異なり、各プロジェクトのドキュメントに記載されています。
