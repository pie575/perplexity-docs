<div id="overview">
  ## 概要
</div>

[AnythingLLM](https://anythingllm.com) は、あらゆるドキュメント・リソース・コンテンツを LLM チャットのコンテキストとして活用できるようにする、オールインワンの AI 生産性アプリです。デスクトップ環境とセルフホスト環境の両方に対応し、数十種類の LLM プロバイダーと連携します。Perplexity もファーストクラスのクラウドプロバイダーとしてサポートされており、どのワークスペースからも引用付きのウェブグラウンディング型の回答を利用できます。

<Info>
  **AnythingLLM** は Mintplex Labs が開発・保守しています。LLM はワークスペース単位で設定できるため、あるワークスペースでは Perplexity を、別のワークスペースでは他のプロバイダーを使うといった運用が可能です。詳しくは [anythingllm.com](https://anythingllm.com) をご覧ください。
</Info>

<div id="setup">
  ## セットアップ
</div>

<Steps>
  <Step title="API キーを取得する">
    [API ポータル](https://console.perplexity.ai/project/keys)で Perplexity API キーを生成します。

    <Card title="API キーを取得" icon="key" href="https://console.perplexity.ai/project/keys">
      Perplexity API キーを生成します。
    </Card>
  </Step>

  <Step title="LLM 設定を開く">
    AnythingLLM で **Settings → LLM Preference** を開きます。
  </Step>

  <Step title="Perplexity AI を選択する">
    プロバイダー一覧から **Perplexity AI** を選び、API キーを貼り付けます。
  </Step>

  <Step title="モデルを選ぶ">
    キーを入力すると、**Chat Model Selection** のドロップダウンに利用可能な Perplexity のモデルが自動的に表示されます。使用したいモデル (例: `sonar-pro`) を選択して保存します。
  </Step>
</Steps>

<div id="system-vs-workspace-models">
  ## システムモデルとワークスペースモデル
</div>

AnythingLLM では、LLM の選択を 2 つのレベルで指定できます。

* **システム LLM** — すべてのワークスペースとエージェントで使用される既定のプロバイダー。
* **ワークスペース LLM** — ワークスペース単位の上書き設定。そのワークスペース内でチャットする際に優先されます。

プロバイダーは自由に組み合わせられます。たとえば、システムの既定を Anthropic にしておき、調査中心のチャットでリアルタイムのウェブグラウンディングが必要な特定のワークスペースでのみ Perplexity を使う、といった構成も可能です。

ワークスペース単位で上書きするには、対象のワークスペースを開き、**Workspace Settings → Chat Settings → Workspace LLM Provider** に移動して、**Perplexity AI** と使用したいモデルを選択します。

<div id="available-models">
  ## 利用可能なモデル
</div>

APIがサポートするPerplexityのモデルはすべてAnythingLLMで利用できます。API キーが検証されると、モデルのドロップダウンが動的に読み込まれます。推奨モデルは次のとおりです。

* `sonar` — 高速かつコスト効率に優れたウェブグラウンディング型チャット
* `sonar-pro` — 引用範囲がより広い高度な推論
* `sonar-reasoning-pro` — 検索を伴う多段階推論

すべてのモデルについては[Perplexityのモデルと機能](/ja/docs/sonar/models)をご覧ください。

<div id="use-cases">
  ## ユースケース
</div>

Perplexity と AnythingLLM を組み合わせると、次のことが可能になります。

* **ドキュメントワークフロー内でのリアルタイムなウェブ回答** — アップロードした PDF とウェブ上の最新情報に関する質問に、同じチャット内でワークスペースが回答できます。
* **引用に裏付けられた検索** — Perplexity は、RAG で取得したコンテキストとあわせて検証できるソース URL を返します。
* **時事的な話題に対する RAG 非依存のフォールバック** — ドキュメントに答えが含まれていない場合、モデルが自動的にリアルタイムのウェブコンテキストを参照できます。

<div id="agent-configuration">
  ## エージェント設定
</div>

AnythingLLM の [AI エージェント](https://docs.anythingllm.com/agent/setup)を使う場合、ワークスペースの **Agent Configuration** メニューで、エージェントの LLM として Perplexity を設定できます。Web ブラウジング、ドキュメント Q&amp;A、外部 API 呼び出しといったスキルと Web リサーチを組み合わせて実行する必要があるエージェントに便利です。
