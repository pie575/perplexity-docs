<div id="overview">
  ## 概要
</div>

[Agno](https://docs.agno.com) は、エージェント、チーム、ワークフローを構築するためのオープンソースの Python フレームワークです。Agno の OpenAI Responses 互換のモデルクラスを使って、Perplexity の [Agent API](/ja/docs/agent-api/quickstart) に接続できます。

<div id="installation">
  ## インストール
</div>

```bash theme={null}
pip install agno openai
```

<div id="api-key-setup">
  ## API キーのセットアップ
</div>

Perplexity API キーを環境変数に設定します。

```bash theme={null}
export PERPLEXITY_API_KEY="your_api_key_here"
```

<Card title="API キーを取得" icon="key" href="https://console.perplexity.ai/project/keys">
  API ポータルで Perplexity API キーを生成します。
</Card>

<div id="quick-start">
  ## クイックスタート
</div>

`OpenAIResponses` を、Agent API のベース URL とサポート対象の Agent API モデルと組み合わせて使用します。`extra_body` でリサーチ用の [プリセット](/ja/docs/agent-api/presets) を渡すと、リアルタイムのウェブ検索結果に基づいた回答が得られます。

```python theme={null}
import os

from agno.agent import Agent
from agno.models.openai import OpenAIResponses

agent = Agent(
    model=OpenAIResponses(
        id="openai/gpt-5.6-luna",
        base_url="https://api.perplexity.ai/v1",
        api_key=os.environ["PERPLEXITY_API_KEY"],
        extra_body={"preset": "medium"},
    ),
    markdown=True,
)

agent.print_response(
    "What are the latest breakthroughs in fusion energy this year?",
    stream=True,
)
```

`id` を任意の [Agent API モデル](/ja/docs/agent-api/models) に差し替えれば、サードパーティ製モデルへのリクエストを Perplexity 経由でルーティングできます。Agent API では、リサーチに裏付けられた [プリセット](/ja/docs/agent-api/presets) や、追加の組み込み [ツール](/ja/docs/agent-api/tools) も利用できます。
