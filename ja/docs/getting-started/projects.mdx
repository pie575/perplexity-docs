<div id="what-is-a-project">
  ## Project とは？
</div>

**Project** は、Perplexity API ポータルにおける組織のワークスペースです。Project では次のことができます。

* API 利用料の**請求**と支払い方法の**管理**
* Perplexity API にアクセスするための **API key の作成と管理**
* **チームメンバーの招待**と権限の設定 (任意) 
* すべての API key を対象とした**利用状況とコストの監視**

<div id="prerequisites">
  ## 前提条件
</div>

始める前に、以下を用意してください。

* Perplexity アカウント ([perplexity.ai](https://perplexity.ai) で登録) 
* 請求と API key の管理を行うための**管理者権限**
* 支払い設定に使用する**クレジットカード** (この時点では課金されません) 

<Note>
  既存のチームに参加する場合は、管理者からの招待が必要です。アクセス権については、チームリーダーにお問い合わせください。
</Note>

<div id="accessing-the-api-portal">
  ## API ポータルへのアクセス
</div>

[console.perplexity.ai](https://console.perplexity.ai) にアクセスして、プロジェクトを開きます。左側のサイドバーは、次の 2 つのセクションに分かれています。

* **Project**: Settings、Members、Billing、API keys、Files
* **API Playground**: Search API、Agent API

<div id="billing-and-payment-methods">
  ## 請求と支払い方法
</div>

<div id="how-billing-works">
  ### 請求の仕組み
</div>

Perplexity API は**クレジットベースの請求システム**を採用しています。

* **クレジット**は事前に購入し、API 呼び出しに使用します
* **モデルごとに**、リクエストあたりに消費するクレジット量が異なります
* **利用料金**は、処理した token 数と実行した検索クエリ数に基づいて課金されます
* **自動チャージ**を有効にすると、サービスの中断を回避できます

<Info>
  モデルおよび利用タイプごとの詳細な費用については、[料金ページ](./pricing)をご覧ください。
</Info>

<div id="setting-up-payment">
  ### 支払いの設定
</div>

<Card title="請求ダッシュボードにアクセス" icon="credit-card" arrow="True" horizontal="True" iconType="solid" cta="請求ページへ" href="https://console.perplexity.ai/project/billing">
  API の請求ダッシュボードに直接アクセスして、支払い方法の管理、使用状況の確認、請求設定の変更を行えます。
</Card>

<Steps>
  <Step title="請求ページに移動">
    左サイドバーの **Billing** をクリックします。このページには、クレジット残高、支払い方法、使用状況グラフ、請求内訳が表示されます。

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_billing.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=6d6e71d28dcf4d39faa4fc8b14c6ad48" alt="API Billing Dashboard" />
    </Frame>
  </Step>

  <Step title="支払い方法を追加">
    **Add payment method** をクリックし、クレジットカード情報を入力します。支払いは Stripe で管理されます。**Manage ↗** をクリックすれば、Stripe のポータルに直接アクセスすることもできます。

    <Note>
      支払い方法を追加しても、クレジットカードへの請求は発生しません。今後の API 利用に備えて支払い情報を保存するだけです。
    </Note>
  </Step>

  <Step title="自動リロードを設定（推奨）">
    **Auto reload** の横にある **Change preferences** をクリックすると、クレジットの自動チャージを有効にできます。

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_topup.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=3aa16c75b424292781b61005b1ab32df" alt="API Billing Dashboard" />
    </Frame>

    <Warning>
      クレジットを使い切ると、残高を追加するまで API key がブロックされます。自動リロードを設定しておけば、残高がしきい値を下回った時点でクレジットが自動的に追加されるため、この事態を防げます。
    </Warning>
  </Step>
</Steps>

<div id="credit-balance">
  ### クレジット残高
</div>

Billing ページの上部には、**残りのクレジット残高**が大きく表示されます。**Buy more credits** リンクから、いつでもクレジットを追加購入できます。

現在の**利用ティア**もここに表示されます。ティアのしきい値や特典の詳細は、**Learn more ↗** をクリックしてご確認ください。

<div id="managing-api-keys">
  ## API keyの管理
</div>

<div id="what-are-api-keys">
  ### API keyとは？
</div>

API keyは、Perplexity APIにアクセスするための認証情報です。各キーには次の特性があります。

* Perplexity APIへの**リクエストを認証する**
* 利用状況を把握するために**使用量を追跡する**
* セキュリティ上の理由で**失効させられる**
* **安全に保管する必要があり**、公開の場で共有してはならない

<Info>
  すべてのAPIリクエストのAuthorizationヘッダーにAPI keyを含める必要があります: `Authorization: Bearer $PERPLEXITY_API_KEY`
</Info>

<div id="creating-an-api-key">
  ### API keyの作成
</div>

<Steps>
  <Step title="API keys に移動">
    左サイドバーの **API keys** をクリックします。

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_api_keys.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=d72bcb05e281c05a5a7a2f7b3a469f50" alt="API Keys" />
    </Frame>
  </Step>

  <Step title="新しいキーを生成">
    **+ Generate API Key** をクリックして、新しいAPI keyを作成します。

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_api_keys_new.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=ca3c652417faa90238d299ddc72b0249" alt="API Keys" />
    </Frame>
  </Step>
</Steps>

<Warning>
  API keyは機密性の高い認証情報です。クライアントサイドのコードに記載したり、公開リポジトリで共有したりしないでください。
</Warning>

<div id="adding-and-managing-members">
  ## メンバーの追加と管理
</div>

管理者は、**Admin** または **Member** のロールを指定して、組織にチームメンバーを招待できます。

<div id="adding-a-member">
  ### メンバーの追加
</div>

<Steps>
  <Step title="Members に移動する">
    左サイドバーの **Members** をクリックします。このページでは、現在のチームメンバーとそのロールを確認できます。
  </Step>

  <Frame>
    <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_members.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=78f439f1a1567dc49c7ff06c4033b3af" alt="Members" />
  </Frame>

  <Step title="メンバーを招待する">
    **+ Add Member** をクリックします。ユーザーのメールアドレスを入力し、**Invite** をクリックします。

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_add_member.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=c4fab8e720fb1db15206846289399a3a" alt="Add Member" />
    </Frame>
  </Step>

  <Step title="メンバーが招待を受け取る">
    招待されたユーザーには、プロジェクトに参加するためのリンクが記載されたメールが届きます。

    <Check>
      招待が承諾されると、割り当てられたロールとともにメンバー一覧に表示されます。
    </Check>
  </Step>
</Steps>

<div id="filtering-members-by-role">
  ### ロール別のメンバーの絞り込み
</div>

ドロップダウンを使用すると、チームメンバーの一覧をロール別に絞り込めます。

<div id="roles">
  ### ロール
</div>

* **Admin**: メンバーの招待/削除、請求の管理、使用状況データの閲覧まで、すべての操作が可能です。
* **Member**: 使用状況とアカウントの上限を閲覧できますが、設定の変更はできません。

<Warning>
  請求およびメンバー権限を変更できるのは Admin のみです。
</Warning>

<div id="viewing-usage-metrics">
  ## 使用状況メトリクスの確認
</div>

すべてのメンバーは、コンソールの **Billing** ページから API の使用状況を直接モニタリングできます。

<Frame>
  <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_usage_metrics.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=80e6246097068cf8854370c98a9de338" alt="Usage Metrics" />
</Frame>

**Usage** チャートでは、次のフィルターを使って時系列でアクティビティを追跡できます。

* **メトリクスセレクター**: Chat Completions API Requests、Input Tokens、Output Tokens、Citation Tokens、Reasoning Tokens、Deep Research Requests Count、Search API Requests Count、Pro Search API Requests Count から選択します
* **期間**: Last 7 Days、Last 30 Days、またはカスタム範囲で絞り込みます

チャートの下にある **Billing breakdown** テーブルには、モデルごとの使用量・レート・コストの内訳が表示され、プロダクト別の支出状況を一目で把握できます。

<Check>
  使用状況メトリクスは、API のアクティビティをモニタリングし、コストやパフォーマンスを最適化するのに役立ちます。
</Check>

<div id="invoice-history">
  ## 請求書履歴
</div>

**Billing** ページの使用状況チャートと請求内訳の下に、**Invoice history** (請求書履歴) が表示されます。ここには過去のすべての請求書が日付・ステータス・金額とともに記録されています。

<Frame>
  <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_invoices.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=4df3bb3d07fef0c321d8b82272651c14" alt="Invoice History" />
</Frame>

請求書は請求サイクルごとに自動生成されます。**Previous** と **Next** のコントロールで、過去の記録をページ送りできます。
