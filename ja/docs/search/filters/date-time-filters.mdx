---
title: "検索の日付・時刻フィルター"
---

<Note>
  `search_after_date_filter` および `search_before_date_filter` パラメータを使うと、検索結果を特定の公開日の範囲に限定できます。公開日がこの範囲内にある結果のみが返されます。

  `last_updated_after_filter` および `last_updated_before_filter` パラメータを使うと、当初の公開日ではなく、コンテンツが最後に変更・更新された時期でフィルタリングできます。

  `search_recency_filter` パラメータを使えば、現在の日付を基準にあらかじめ定義された期間 (例: &quot;hour&quot;、&quot;day&quot;、&quot;week&quot;、&quot;month&quot;、&quot;year&quot;) で結果を手軽に絞り込めます。
</Note>

<Info>
  日付を指定するフィルターは &quot;%m/%d/%Y&quot; 形式で指定してください (例: &quot;3/1/2025&quot;) 。新しさフィルターには &quot;hour&quot;、&quot;day&quot;、&quot;week&quot;、&quot;month&quot;、&quot;year&quot; といったあらかじめ定義された値を使用します。これらのフィルターはすべて任意で、必要に応じて特定の日付または新しさフィルターのいずれかを指定できます。
</Info>

<div id="overview">
  ## 概要
</div>

Search API の日時フィルターを使うと、検索結果を特定の期間に限定して返すよう制御できます。利用できる日時フィルターは次の3種類です。

<div id="publication-date-filters">
  ### 公開日フィルター
</div>

`search_after_date_filter` および `search_before_date_filter` パラメータは、コンテンツが**最初に作成または公開された**時期に基づいて結果を絞り込みます。次のような場合に役立ちます。

* 特定の期間内に公開されたコンテンツを探したい
* 古すぎる、または新しすぎるコンテンツを除外したい
* 特定の公開期間のコンテンツに絞り込みたい

<div id="last-updated-date-filters">
  ### 最終更新日フィルター
</div>

`last_updated_after_filter` および `last_updated_before_filter` パラメータは、コンテンツが**最後に変更または更新された**時期に基づいて結果を絞り込みます。次のような場合に役立ちます。

* 最近更新・メンテナンスされているコンテンツを探したい
* 長期間更新されていない古いコンテンツを除外したい
* 特定の期間内に更新されたコンテンツに絞り込みたい

<div id="search-recency-filter">
  ### 検索期間フィルター
</div>

`search_recency_filter` パラメータを使うと、現在の日付を基準にあらかじめ定義された期間で結果を簡単に絞り込めます。次のような場合に便利です。

* 過去1時間、1日、1週間、1か月、または1年のコンテンツを探したい
* 正確な日付を指定せずに最近の結果を取得したい
* 時事性のある情報をすばやく絞り込みたい

**利用可能な値:**

* `"hour"` - 過去1時間のコンテンツ。速報ニュースやライブイベントなど、リアルタイム性の高いデータに使用します。
* `"day"` - 過去24時間のコンテンツ
* `"week"` - 過去7日間のコンテンツ
* `"month"` - 過去30日間のコンテンツ
* `"year"` - 過去365日間のコンテンツ

**重要:** 公開日フィルターは元の作成日・公開日を、最終更新日フィルターは更新日を基準とします。これに対し、新しさフィルターは現在の日付からの相対的な期間を基準とします。

公開日で検索結果を絞り込むには、次のようにします。

```bash theme={null}
"search_after_date_filter": "3/1/2025",
"search_before_date_filter": "3/5/2025"
```

最終更新日で検索結果を絞り込むには、次のようにします。

```bash theme={null}
"last_updated_after_filter": "07/01/2025",
"last_updated_before_filter": "12/30/2025"
```

検索結果を新しさで絞り込むには、次のようにします。

```bash theme={null}
"search_recency_filter": "week"
```

これらのフィルターは、他の検索パラメータに加えて適用されます。

**1. 公開日の範囲で結果を絞り込む**

この例では、検索結果を2025年3月1日から2025年3月5日までに公開されたコンテンツに限定します。

**リクエスト例**

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.search.create(
      query="transformer architecture attention mechanism",
      max_results=10,
      search_after_date_filter="3/1/2025",
      search_before_date_filter="3/5/2025"
  )

  print(response)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.search.create({
    query: "transformer architecture attention mechanism",
    max_results: 10,
    search_after_date_filter: "3/1/2025",
    search_before_date_filter: "3/5/2025"
  });

  console.log(response);
  ```

  ```bash cURL theme={null}
  curl -X POST 'https://api.perplexity.ai/search' \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H 'Content-Type: application/json' \
    -d '{
      "query": "transformer architecture attention mechanism",
      "max_results": 10,
      "search_after_date_filter": "3/1/2025",
      "search_before_date_filter": "3/5/2025"
    }' | jq
  ```

特定の日付以降に公開された結果のみに絞り込みたい場合は、`search_after_date_filter` だけを指定します。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.search.create(
      query="tech industry layoffs at major technology companies",
      max_results=10,
      search_after_date_filter="3/1/2025"
  )

  print(response)
  ```

<div id="search_after_date_filter">
  ### `search_after_date_filter`
</div>

* **型**: String
* **形式**: &quot;%m/%d/%Y&quot; (例: &quot;3/1/2025&quot;) 
* **説明**: 指定した日付より後に公開されたコンテンツのみを検索結果に含めます
* **省略可**: はい
* **例**: `"search_after_date_filter": "1/1/2025"`

<div id="search_before_date_filter">
  ### `search_before_date_filter`
</div>

* **型**: String
* **形式**: &quot;%m/%d/%Y&quot; (例: &quot;3/1/2025&quot;) 
* **説明**: この日付より前に公開されたコンテンツのみに検索結果を絞り込みます
* **任意**: はい
* **例**: `"search_before_date_filter": "12/31/2025"`

<div id="last_updated_after_filter">
  ### `last_updated_after_filter`
</div>

* **型**: String
* **形式**: &quot;%m/%d/%Y&quot; (例: &quot;07/01/2025&quot;) 
* **説明**: 指定した日付より後に最終更新されたコンテンツのみに検索結果を絞り込みます
* **省略可**: はい
* **例**: `"last_updated_after_filter": "07/01/2025"`

<div id="last_updated_before_filter">
  ### `last_updated_before_filter`
</div>

* **型**: String
* **形式**: &quot;%m/%d/%Y&quot; (例: &quot;12/30/2025&quot;) 
* **説明**: 指定した日付より前に最終更新されたコンテンツのみに検索結果を絞り込みます
* **任意**: はい
* **例**: `"last_updated_before_filter": "12/30/2025"`

<div id="search_recency_filter">
  ### `search_recency_filter`
</div>

* **型**: String
* **指定可能な値**: &quot;hour&quot;、&quot;day&quot;、&quot;week&quot;、&quot;month&quot;、&quot;year&quot;
* **説明**: 現在の日付を基準に、指定した期間内のコンテンツのみに検索結果を絞り込みます
* **任意**: はい
* **例**: `"search_recency_filter": "week"`

<div id="best-practices">
  ## ベストプラクティス
</div>

**日付形式**

* 厳密な形式: 日付は &quot;%m/%d/%Y&quot; 形式に正確に一致する必要があります。たとえば &quot;3/1/2025&quot; や &quot;03/01/2025&quot; は有効です。
* 一貫性: 検索の要件に応じて、いずれか一方または両方の日付フィルターを一貫して使用してください。両方を組み合わせれば、明確な範囲を指定できます。

**フィルターの選択**

* 適切なフィルタータイプを選ぶ: コンテンツが元々いつ作成されたかを重視する場合は、公開日フィルター (`search_after_date_filter`/`search_before_date_filter`) を使用します。最近メンテナンスされたコンテンツが必要な場合は、最終更新日フィルター (`last_updated_after_filter`/`last_updated_before_filter`) を使用します。相対的な期間で手軽に絞り込みたい場合は、新しさフィルター (`search_recency_filter`) を使用します。
* 新しさ vs. 厳密な日付: 最近のコンテンツ (例: 「過去1週間」) を手軽に取得したい場合は `search_recency_filter` が便利です。期間を厳密に制御する必要がある場合は、特定の日付フィルターを使用します。
* フィルターの組み合わせ: 公開日フィルターと最終更新日フィルターを併用すれば、両方の条件を満たすコンテンツ (例: 2024年に公開され、かつ最近更新されたもの) を検索できます。なお、`search_recency_filter` は特定の日付フィルター (`search_after_date_filter`/`search_before_date_filter` または `last_updated_after_filter`/`last_updated_before_filter`) と併用できません。

**クライアント側での検証**

* 正規表現チェック: 次のような正規表現を使用して、クライアント側で日付文字列を検証します:

<CodeGroup>
  ```bash theme={null}
  date_regex='^(0?[1-9]|1[0-2])/(0?[1-9]|[12][0-9]|3[01])/[0-9]{4}$'
  ```

  ```python theme={null}
  date_regex = r'^(0?[1-9]|1[0-2])/(0?[1-9]|[12]\d|3[01])/\d{4}$'
  ```
</CodeGroup>

これにより、リクエスト送信前に日付が必要な形式に準拠していることを確認できます。

**パフォーマンスに関する考慮事項**

* 検索範囲の絞り込み: 日付範囲フィルターを適用すると通常は結果件数が減るため、応答時間や結果の関連性が向上する場合があります。
* 過度な制限を避ける: 日付範囲が狭すぎて有用な結果が得られなかったり、広すぎてフィルターの意味がなくなったりしないように注意してください。

```python theme={null}
    query="breaking news technology",
    max_results=5,
    search_recency_filter="day"

```

  ```python Python theme={null}
  def validate_date_format(date_string):
      pattern = r'^(0?[1-9]|1[0-2])/(0?[1-9]|[12]\d|3[01])/\d{4}$'
      return bool(re.match(pattern, date_string))

  def search_with_date_filter(query, after_date=None, before_date=None):
      client = Perplexity()
      
      # 日付形式を検証する
      if after_date and not validate_date_format(after_date):

          raise ValueError(f"Invalid date format: {before_date}")
  ```

  ```typescript Typescript theme={null}
  function validateDateFormat(dateString: string): boolean {
    const pattern = /^(0?[1-9]|1[0-2])\/(0?[1-9]|[12]\d|3[01])\/\d{4}$/;
    return pattern.test(dateString);
  }

  async function searchWithDateFilter(
    query: string, 
    afterDate?: string, 
    beforeDate?: string
  ) {
    const client = new Perplexity();
    
    // 日付形式を検証する
    if (afterDate && !validateDateFormat(afterDate)) {
      throw new Error(`Invalid date format: ${afterDate}`);
    }
    if (beforeDate && !validateDateFormat(beforeDate)) {
      throw new Error(`Invalid date format: ${beforeDate}`);
    }
    
    try {
      const response = await client.search.create({
        query,
        search_after_date_filter: afterDate,
        search_before_date_filter: beforeDate
      });
      return response;
    } catch (error) {
      console.error('Search failed:', error);
      return null;
    }
  }
  ```
