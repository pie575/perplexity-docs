---
title: "コンテキストを保持する"
description: "会話を input 配列で再送してターンをまたいで引き継ぎ、後続の質問が直前までのやり取りを理解できるようにします。"
---

送信するコンテキストを厳密に制御したい場合、たとえば後続の質問の前に過去のターンを要約、秘匿化、並べ替え、あるいは省略したい場合は、`input` 配列で会話を自分で再送してください。パターンとコード例については [会話ターンを自分で再送する](/ja/docs/agent-api/conversation-state#replay-conversation-turns-yourself) を参照してください。

<div id="storage-backed-continuity">
  ## ストレージベースの継続
</div>

ほとんどのマルチターン会話では、`previous_response_id` を使うことで、会話履歴を自分で再送信せずに、完了済みの直前のレスポンスから続けられます。詳しくは [会話状態](/ja/docs/agent-api/conversation-state) を参照してください。
