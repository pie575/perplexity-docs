---
title: "コードを実行する"
description: "エージェントに sandbox を与えると、推定ではなく正確な答えを算出し、実際のコードを実行して、生成されたファイルを返せるようになります。"
---

言語モデルは、厳密な計算やデータ操作を実際に行うのではなく、近似しているにすぎません。`sandbox` ツールは、エージェントに隔離された Linux コンテナを提供し、実際のコードを実行してその出力を回答に活用できるようにします。計算結果の数値、変換済みのデータセット、生成したレポートなど、正確さが求められる結果に適しています。エージェントはコンテナ内部から、リクエストに追加していなくても Perplexity の [Web Search](/ja/docs/agent-api/tools/web-search)、[Fetch URL Content](/ja/docs/agent-api/tools/fetch-url-content)、[People Search](/ja/docs/agent-api/tools/people-search) を呼び出し、その結果をもとに計算することもできます (いずれも標準料金で課金されます) 。設定項目、レスポンス形式、料金の詳細は [Sandbox ツールリファレンス](/ja/docs/agent-api/tools/sandbox) を参照してください。

<div id="enable-the-sandbox">
  ## sandbox を有効にする
</div>

`tools` 配列に `{"type": "sandbox"}` を追加します。コードを実行するタイミングは、プロンプトの内容に応じて model が判断します。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()


  def get_output_text(response) -> str:
      return "".join(
          content.text
          for item in response.output or []
          if getattr(item, "type", None) == "message"
          for content in getattr(item, "content", None) or []
          if getattr(content, "type", None) == "output_text"
      )


  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Compute the compound annual growth rate from 4.2M in 2019 to 11.8M in 2025.",
      tools=[{"type": "sandbox"}],
      instructions="Use the sandbox to compute the exact figure before answering.",
  )

  print(get_output_text(response))
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
    model: 'openai/gpt-5.6-sol',
    input: 'Compute the compound annual growth rate from 4.2M in 2019 to 11.8M in 2025.',
    tools: [{ type: 'sandbox' as const }],
    instructions: 'Use the sandbox to compute the exact figure before answering.',
  });

  console.log(response.output_text);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "Compute the compound annual growth rate from 4.2M in 2019 to 11.8M in 2025.",
      "tools": [{ "type": "sandbox" }],
      "instructions": "Use the sandbox to compute the exact figure before answering."
    }' | jq
  ```
</CodeGroup>

<div id="when-to-reach-for-it">
  ## 利用が適した場面
</div>

* 概算では不十分な数値計算や統計分析
* データのクレンジング、パース、変換
* ロジックの確認やエラーの再現のためのコード実行
* ファイルや成果物の生成 — CSV、JSON、HTML、レポートなど、コードが書き出すあらゆるファイル
* 中間ファイルや計算結果の状態を必要とする多段階のワークフロー

<Tip>
  `sandbox` を `web_search` と組み合わせれば、エージェントが根拠を収集したうえで、コンテナ内でそのデータを計算処理できます。sandbox と他のツールの連携については、[Sandbox リファレンス](/ja/docs/agent-api/tools/sandbox)を参照してください。
</Tip>

<div id="read-the-computed-result">
  ## 計算結果を読み取る
</div>

エージェントがコードを実行すると、レスポンスの `output` 配列に、`message` と並んで 1 つ以上の `sandbox_results` 項目が含まれます。各項目には、実行された `code`、`language`、および `stdout`、`stderr`、`exit_code`、`status` を含む `results` 配列が格納されます。これにより、エージェントが答えを推測したのではなく実際に計算したことを確認できます。各フィールドの詳細は[レスポンス形式のリファレンス](/ja/docs/agent-api/tools/sandbox#response-shape)を参照してください。

レスポンスからこの項目を読み取ります (ここでの `response` は、上記の [sandbox を有効にする](#enable-the-sandbox)の例で得られたものです) :

```python Python theme={null}
for item in response.output:
    if item.type == "sandbox_results":
        print(item.code)
        print(item.results[0].stdout)
```

このリクエストでは、エージェントは sandbox 内で次の Python コードを記述・実行し、出力された値を回答に使用しました。

<Accordion title="レスポンス">

      ```python theme={null}
      from decimal import Decimal, getcontext

      getcontext().prec = 50
      start = Decimal('4.2')
      end = Decimal('11.8')
      years = Decimal(2025 - 2019)
      log_growth = (end / start).ln() / years
      cagr = log_growth.exp() - Decimal(1)
      print(cagr)
      print(cagr * 100)
      ```

<div id="return-files">
  ## ファイルの取得
</div>

sandbox 内のコードがファイルを書き出して共有すると、レスポンスの `output` に `share_file` 項目が含まれます。バイト列はインラインでは返されないため、レスポンスの `id` をキーとして、レスポンスファイル用のエンドポイントから一覧取得およびダウンロードしてください。

<CodeGroup>
  ```python Python theme={null}
  files = client.responses.files.list(response.id)
  for f in files.data:
      print(f.id, f.filename, f.bytes)

  content = client.responses.files.content(
      file_id=files.data[0].id,
      response_id=response.id,
  )
  content.write_to_file(files.data[0].filename)
  ```

  ```bash cURL theme={null}
  # レスポンスが生成したファイルを一覧表示
  curl https://api.perplexity.ai/v1/agent/$RESPONSE_ID/files \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" | jq

  # ファイル ID を指定して 1 件ダウンロード
  curl https://api.perplexity.ai/v1/agent/$RESPONSE_ID/files/$FILE_ID/content \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -o output.csv
  ```
</CodeGroup>

<Note>
  長時間かかる sandbox の処理は、バックグラウンド実行と組み合わせると効果的です。`background: true` を指定してリクエストを送信し、ID でポーリングしてください。詳しくは [出力制御](/ja/docs/agent-api/output-control) と [Sandbox リファレンス](/ja/docs/agent-api/tools/sandbox#running-in-the-background)を参照してください。
</Note>
