---
title: "出力を構造化する"
description: "解析のために抽出作業が必要な文章ではなく、コードでそのままパースできる JSON を model に返させます。"
---

デフォルトでは、実行が完了すると 1 つのテキストブロックが返されます。下流のシステムでその結果を処理する場合、自由形式の文章は扱いにくく、壊れやすいパーサーを書く羽目になります。構造化出力を使えば、model は自分で定義したスキーマに準拠した JSON を返すので、そのままデシリアライズできます。ストリーミング、バックグラウンド実行、エラー処理、スキーマの完全な例といった網羅的なリファレンスについては、[Output Control](/ja/docs/agent-api/output-control) を参照してください。

<div id="structured-output">
  ## 構造化出力
</div>

`response_format` に、`name` と `schema` を持つ `json_schema` を指定します。生成が途中で打ち切られない限り、レスポンステキストはスキーマに準拠します。以下の例では、Pydantic モデルからスキーマを構築し、レスポンスをそのスキーマで検証しています。

<CodeGroup>
  ```python Python theme={null}
  from typing import List, Optional
  from pydantic import BaseModel
  from perplexity import Perplexity

  class CompanySummary(BaseModel):
      name: str
      sector: str
      headquarters: str
      key_products: Optional[List[str]] = None

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Summarize NVIDIA: sector, headquarters, and key products.",
      response_format={
          "type": "json_schema",
          "json_schema": {
              "name": "company_summary",
              "schema": {
                  **CompanySummary.model_json_schema(),
                  "required": list(CompanySummary.model_fields.keys()),
                  "additionalProperties": False,
              },
          },
      },
  )

  summary = CompanySummary.model_validate_json(response.output_text)
  print(summary.name, summary.sector)
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "Summarize NVIDIA: sector, headquarters, and key products.",
      "response_format": {
        "type": "json_schema",
        "json_schema": {
          "name": "company_summary",
          "schema": {
            "type": "object",
            "properties": {
              "name": { "type": "string" },
              "sector": { "type": "string" },
              "headquarters": { "type": "string" },
              "key_products": { "type": "array", "items": { "type": "string" } }
            },
            "required": ["name", "sector", "headquarters"]
          }
        }
      }
    }' | jq
  ```
</CodeGroup>

<Tip>
  プロンプト側でもスキーマを念押しすると (「スキーマに一致する JSON オブジェクトとしてデータを返してください」など) 、準拠率が高まります。
</Tip>

<Warning>
  JSON 内にリンクを含めるよう指示するのは避けてください。構造化出力の一部として URL を生成させると、不正な形式のリンクや実在しないリンクが出力されるおそれがあります。リンクは、レスポンスの `output` にある `citations` または `search_results` の項目から取得してください。
</Warning>
