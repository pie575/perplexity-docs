<div id="available-models">
  ## 利用可能なモデル
</div>

Agent API は、複数のプロバイダーの モデル への直接アクセスに対応しています。すべての モデル はファーストパーティプロバイダーから直接利用でき、透明性の高い token ベースの料金体系が適用されます。

料金レートは毎月更新され、**マークアップなしのファーストパーティプロバイダー価格をそのまま反映**しています。課金はすべて実際の token 消費量に基づき、API レスポンスには常に正確な token 数が含まれるため、リクエストごとのコストを把握できます。

<Tip>
  事前構成済みの モデル 設定をお探しですか？特定のユースケース向けに最適化された [**Presets**](/ja/docs/agent-api/presets) をご覧ください。
</Tip>

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Explain the difference between supervised and unsupervised learning in machine learning.",
      max_output_tokens=300,
  )

  print(f"Response ID: {response.id}")
  print(response.output_text)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      model: "openai/gpt-5.6-sol",
      input: "Explain the difference between supervised and unsupervised learning in machine learning.",
      max_output_tokens: 300,
  });

  console.log(`Response ID: ${response.id}`);
  console.log(response.output_text);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "Explain the difference between supervised and unsupervised learning in machine learning.",
      "max_output_tokens": 300
    }' | jq
  ```
</CodeGroup>

<div id="model-fallback">
  ## モデルフォールバック
</div>

高可用性が求められるアプリケーションでは、フォールバックチェーンに複数のモデルを指定できます。あるモデルが失敗した場合や利用できない場合、APIはチェーン内の次のモデルを自動的に試行します。

<Card title="モデルフォールバックチェーン" icon="square-rounded-arrow-down" href="/ja/docs/agent-api/model-fallback">
  1つのモデルが失敗した際に複数のモデルを自動的に試行し、高い可用性と信頼性を確保するモデルフォールバックチェーンの使い方を学びます。
</Card>

<Info>
  **例:**

  ```python theme={null}
  response = client.responses.create(
      models=["openai/gpt-5.6-sol", "anthropic/claude-sonnet-4-6", "google/gemini-3-flash-preview"],
      input="Your question here",
      max_output_tokens=8192,
  )
  ```

  詳細な例、料金情報、ベストプラクティスについては、[モデルフォールバックのドキュメント](/ja/docs/agent-api/model-fallback)を参照してください。
</Info>
