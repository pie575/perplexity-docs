<div id="why-use-the-agent-api">
  ## Agent API を使う理由
</div>

<CardGroup cols={2}>
  <Card title="ウェブに基づいた回答" icon="globe">
    リアルタイムのウェブ検索に基づく正確で最新の回答を、インライン引用付きで1回の呼び出しで取得できます。ターンをまたいだ会話コンテキストも保持されます。
  </Card>

  <Card title="複数プロバイダーへのアクセス" icon="stack-3" iconType="solid">
    OpenAI、Anthropic、Google、xAI などに統一された単一の API からアクセスできるため、複数の API key を管理する必要はありません。
  </Card>

  <Card title="透明性のある料金体系" icon="receipt">
    リクエストごとの正確な token 数とコストを確認できます。上乗せは一切なく、プロバイダーの料金がそのまま適用されます。
  </Card>

  <Card title="きめ細かな制御" icon="adjustments">
    一貫した構文で model、推論、token、ツールを切り替えられます。
  </Card>
</CardGroup>

<Info>
  Agent API をより手軽に、型安全に利用するには、[公式 SDK](/ja/docs/sdk/overview) の使用をおすすめします。
</Info>

<Note>
  **エンドポイント:** Agent API は `POST https://api.perplexity.ai/v1/agent` で利用できます。OpenAI SDK との互換性のため、`POST /v1/responses` もエイリアスとして受け付けられます。OpenAI SDK を Perplexity で使用する方法の詳細は、[OpenAI 互換性ガイド](/ja/docs/agent-api/openai-compatibility)を参照してください。
</Note>

<div id="installation">
  ## インストール
</div>

使用する言語の SDK をインストールします。

<CodeGroup>
  ```bash Python theme={null}
  pip install perplexityai
  ```

  ```bash Typescript theme={null}
  npm install @perplexity-ai/perplexity_ai
  ```
</CodeGroup>

<div id="authentication">
  ## 認証
</div>

API keyを環境変数に設定します。SDKが自動的に読み取ります。

<Tabs>
  <Tab title="macOS/Linux">
    ```bash theme={null}
    export PERPLEXITY_API_KEY="your_api_key_here"
    ```
  </Tab>

  <Tab title="Windows">
    ```powershell theme={null}
    setx PERPLEXITY_API_KEY "your_api_key_here"
    ```
  </Tab>
</Tabs>

<Info>
  以下のSDKの例はすべて、`PERPLEXITY_API_KEY` 環境変数を自動的に使用します。必要に応じて、キーを明示的に渡すこともできます。
</Info>

<div id="basic-usage">
  ## 基本的な使い方
</div>

<Tip>
  **便利なプロパティ:** Python と TypeScript の両 SDK には、レスポンス出力に含まれるすべてのテキストコンテンツを集約する `output_text` プロパティが用意されています。`response.output` をループで処理する代わりに `response.output_text` を使えば、コードをよりシンプルに記述できます。
</Tip>

<div id="using-a-third-party-model">
  ### サードパーティ製 モデル の使用
</div>

特定の機能を利用したい場合は、OpenAI、Anthropic、Google、xAI などのプロバイダーが提供するサードパーティ製 モデル を使用します。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Explain the difference between supervised and unsupervised learning in machine learning."
  )

  print(f"Response ID: {response.id}")
  print(response.output_text)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      model: "openai/gpt-5.6-sol",
      input: "Explain the difference between supervised and unsupervised learning in machine learning."
  });

  console.log(`Response ID: ${response.id}`);
  console.log(response.output_text);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "Explain the difference between supervised and unsupervised learning in machine learning."
    }' | jq
  ```
</CodeGroup>

<div id="using-a-preset">
  ### presetの使用
</div>

presetは、特定のユースケースに最適化されたデフォルト設定を提供します。

まずはpresetを使って手軽にセットアップしましょう。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      preset="low",
      input="Explain what the MMLU benchmark measures for large language models, and how the Apache 2.0 license differs from a restricted research-only license for model weights.",
  )

  print(f"Model used: {response.model}")
  print(response.output_text)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      preset: "low",
      input: "Explain what the MMLU benchmark measures for large language models, and how the Apache 2.0 license differs from a restricted research-only license for model weights.",
  });

  console.log(`Model used: ${response.model}`);
  console.log(response.output_text);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "preset": "low",
      "input": "Explain what the MMLU benchmark measures for large language models, and how the Apache 2.0 license differs from a restricted research-only license for model weights."
    }' | jq
  ```
</CodeGroup>

<div id="with-web-search">
  ### ウェブ検索と組み合わせる
</div>

Agent API では、モデル の機能を拡張するためのさまざまなツールを利用できます。

`web_search` ツールで ウェブ検索 機能を有効にします:

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="Explain the original Transformer architecture from 'Attention Is All You Need' (Vaswani et al. 2017): encoder-decoder structure, multi-head self-attention, and positional encodings.",
      tools=[{"type": "web_search"}],
      instructions="You have access to a web_search tool. Use it for questions about current events, news, or recent developments. Use 1 query for simple questions. Keep queries brief: 2-5 words. NEVER ask permission to search - just search when appropriate",
  )

  if response.status == "completed":
      print(response.output_text)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({
      model: "openai/gpt-5.6-sol",
      input: "Explain the original Transformer architecture from 'Attention Is All You Need' (Vaswani et al. 2017): encoder-decoder structure, multi-head self-attention, and positional encodings.",
      tools: [{ type: "web_search" }],
      instructions: "You have access to a web_search tool. Use it for questions about current events, news, or recent developments.",
  });

  if (response.status === "completed") {
      console.log(response.output_text);
  }
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    --data @- <<'JSON' | jq
  {
      "model": "openai/gpt-5.6-sol",
      "input": "Explain the original Transformer architecture from 'Attention Is All You Need' (Vaswani et al. 2017): encoder-decoder structure, multi-head self-attention, and positional encodings.",
      "tools": [{"type": "web_search"}],
      "instructions": "You have access to a web_search tool. Use it for questions about current events, news, or recent developments."
  }
  JSON
  ```
</CodeGroup>

  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(

      input="Explain how to read a 10-K filing: what each major section contains (Item 1 Business, Item 1A Risk Factors, Item 7 MD&A, Item 8 Financial Statements) and how investors use them.",
      tools=[{"type": "finance_search"}],
      max_steps=3,
  )

  for item in response.output:
      if item.type == "message":
          print(item.content[0].text)
  ```
