<div id="overview">
  ## 概要
</div>

PerplexityのAgent APIは、OpenAIのResponses APIインターフェースと完全に互換性があります。ベースURLを変更し、Perplexity API keyを指定するだけで、既存のOpenAIクライアントライブラリをそのまま利用できます。

<Info>
  **エンドポイントに関する注意:** Perplexityの正式なAgent APIエンドポイントは `POST /v1/agent` です。OpenAI SDKとの互換性のため、`POST /v1/responses` もエイリアスとして受け付けられます。OpenAI SDKは `client.responses.create()` を自動的に `/v1/responses` へルーティングし、Perplexityはこれをシームレスに処理します。ベースURLの設定以外に、SDK側の変更は不要です。
</Info>

<Tip>
  **[Perplexity SDK](/ja/docs/sdk/overview) のご利用を推奨します。** 完全な型安全性、拡張機能、presetのサポートにより、最適な開発体験が得られます。すでにOpenAI SDKを組み込んでおり、そのまま差し替えられる互換性が必要な場合は、OpenAI SDKをご利用ください。
</Tip>

  ## クイックスタート
</div>

OpenAI SDK を Perplexity の Agent API で利用します。

    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    response = client.responses.create(
        model="openai/gpt-5.6-sol",
        input="Explain the key differences between REST and GraphQL APIs"
    )

    print(response.output_text)
    ```

<div id="agent-api">
  ## Agent API
</div>

Perplexity の Agent API は、OpenAI の Responses API のリクエスト/レスポンス形式に準拠しています。OpenAI SDK の `client.responses.create()` メソッドはそのまま利用できます。SDK は `/v1/responses` にリクエストを送信しますが、Perplexity は正式なエンドポイントである `/v1/agent` に加えて、このパスも受け付けます。

<div id="basic-usage">
  ### 基本的な使い方
</div>

<Tabs>
  <Tab title="Python">
    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    response = client.responses.create(
        model="openai/gpt-5.6-sol",
        input="Explain the key differences between REST and GraphQL APIs"
    )

    print(response.output_text)
    print(f"Response ID: {response.id}")
    ```

<div id="using-presets">
  ### presetの使用
</div>

presetは、特定のユースケース向けに最適化された事前構成済みの設定です。OpenAI SDK経由でpresetを渡すには`extra_body`を使用します。

<Tabs>
  <Tab title="Python">
    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    # extra_body 経由で preset を渡す
    response = client.responses.create(
        input="Compare the design philosophy of Apple's A-series and Qualcomm's Snapdragon mobile SoCs at a high level: CPU and GPU choices and overall system integration.",
        extra_body={
            "preset": "low"
        }
    )

    print(response.output_text)
    ```
  </Tab>

  <Tab title="Typescript">
    ```typescript theme={null}
    import OpenAI from 'openai';

    const client = new OpenAI({
      apiKey: process.env.PERPLEXITY_API_KEY,
      baseURL: "https://api.perplexity.ai/v1"
    });

    // 型キャスト (as any) を使って preset を直接渡す
    const response = await (client.responses.create as any)({
      input: "Compare the design philosophy of Apple's A-series and Qualcomm's Snapdragon mobile SoCs at a high level: CPU and GPU choices and overall system integration.",
      preset: "low"
    });

    console.log(response.output_text);
    ```

    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    response = client.responses.create(
        model="openai/gpt-5.6-sol",
        input="Write a short bedtime story about a curious fox who discovers a hidden meadow.",
        stream=True
    )

    for event in response:
        if event.type == "response.output_text.delta":
            print(event.delta, end="", flush=True)
    ```

    ```typescript theme={null}
    import OpenAI from 'openai';

    const client = new OpenAI({
    ```

Agent API は、ウェブ検索などの組み込みツールをサポートしています。OpenAI SDK を使う場合、Python では `extra_body` でツールを渡します。TypeScript/JS ではトップレベルのパラメータとして `tools` を渡し、SDK の型チェックを回避するために呼び出しをキャストします。

  <Tab title="Python">
    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai/v1"
    )

    # extra_body でツールを渡す
    response = client.responses.create(
        model="openai/gpt-5.6-sol",
        input="What is an acquisition premium in M&A, and how do strategic vs financial buyers typically differ in their approach?",
        extra_body={
            "tools": [
                {
                    "type": "web_search",
                    "filters": {
                        "search_domain_filter": ["techcrunch.com", "crunchbase.com"]
                    }
                }
            ]
        }
    )

    print(response.output_text)
    ```

    ```python theme={null}
    import os

        base_url="https://api.perplexity.ai/v1"

    models = client.models.list()
    ```

<div id="agent-api-2">
  ### Agent API
</div>

Perplexity の Agent API は、OpenAI の Responses API と同じレスポンス形式です。

* `output` - `content[].text` を持つメッセージを格納した構造化出力の配列
* `model` - 使用されたモデル名
* `usage` - token 消費量の詳細
* `id`、`created_at`、`status` - レスポンスのメタデータ
