model をエージェントに変えるのがツールです。
model 単体では既知の知識だけで回答しますが、ツールを使えば最新の Web を検索したり、ページを取得したり、コードを実行したり、自社システムを呼び出したりできるようになります。
ツールは `tools` 配列に列挙することで有効化します。1 回のリクエストの中で、model は推論し、ツールを呼び出し、その結果を確認し、回答できるようになるまで繰り返す、というエージェント的なループを実行します。

<div id="three-kinds-of-tools">
  ## 3種類のツール
</div>

| 種類                                               | 概要                                 | modelが実行する場所                         |
| ------------------------------------------------ | ---------------------------------- | ---------------------------------- |
| 組み込みツール                                          | Perplexityがホストする機能。`type` で有効化します。 | ループ内。Perplexityが実行し、結果をインラインで返します。 |
| [MCPサーバー](/ja/docs/agent-api/tools/mcp)             | 自前のリモートMCPサーバー。`type: mcp` で接続します。 | ループ内。modelがそのツールを自動的に呼び出します。         |
| [カスタム関数](/ja/docs/agent-api/tools/custom-functions) | 自身が制御する関数。JSON Schemaで宣言します。       | 処理が呼び出し側に戻ります。自分で呼び出しを実行し、結果を返します。 |

<div id="built-in-tools">
  ## 組み込みツール
</div>

各ツールは `type` を指定して有効化します。ツールごとに専用のリファレンスページがあり、設定項目、レスポンス形式、料金の詳細を確認できます。

| ツール                                                          | `type`           | 用途                              |
| ------------------------------------------------------------ | ---------------- | ------------------------------- |
| [Web Search](/ja/docs/agent-api/tools/web-search)               | `web_search`     | ドメイン・日付・地域フィルターを使ったリアルタイムのWeb検索 |
| [Sandbox](/ja/docs/agent-api/tools/sandbox)                     | `sandbox`        | 隔離されたコンテナでコードを実行                |
| [Fetch URL Content](/ja/docs/agent-api/tools/fetch-url-content) | `fetch_url`      | 特定のURLからコンテンツを取得・抽出             |
| [Finance Search](/ja/docs/agent-api/tools/finance-search)       | `finance_search` | 構造化された財務・市場データを取得               |
| [People Search](/ja/docs/agent-api/tools/people-search)         | `people_search`  | 専門家や人物を検索                       |
