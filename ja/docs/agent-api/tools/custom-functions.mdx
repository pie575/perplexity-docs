---
title: "カスタム関数"
description: "カスタム関数を定義し、モデルが要求した呼び出しを自分のコードで実行して、各結果を Agent API に返します。"
---

カスタム関数を使うと、データベースクエリ、社内 API、ビジネスロジックなど、自分で管理するコードをエージェントに利用させられます。関数の内容はリクエスト内で記述しますが、Agent API がそれを実行することはありません。呼び出しの実行と結果の返却は、アプリケーション側で行います。

<div id="run-a-complete-example">
  ## 完全な例を実行する
</div>

この例では、注文ステータスを取得する関数を定義し、ツールループ全体を完結させます。インメモリのルックアップ処理は、独自のデータベースやAPI呼び出しに置き換えてください。

<Steps>
  <Step title="SDK をインストールする">
    ```bash theme={null}
    pip install perplexityai
    ```
  </Step>

  <Step title="API キーを設定する">
    ```bash theme={null}
    export PERPLEXITY_API_KEY="your_api_key_here"
    ```
  </Step>

  <Step title="例を保存して実行する">
    いずれかの例を `custom_function.py` または `custom-function.ts` として保存し、実行してください。

    <CodeGroup>
      ```python Python theme={null}
      import json

      from perplexity import Perplexity

      MODEL = "openai/gpt-5.6-sol"
      QUESTION = "What's the status of order ORD-10042?"

      client = Perplexity()

      tools = [
          {
              "type": "function",
              "name": "get_order_status",
              "description": "Look up the current status of an order by its order ID.",
              "parameters": {
                  "type": "object",
                  "properties": {"order_id": {"type": "string"}},
                  "required": ["order_id"],
                  "additionalProperties": False,
              },
              "strict": True,
          }
      ]


      def get_order_status(order_id: str) -> dict[str, str]:
          """Replace this sample data with a database or API call."""
          orders = {
              "ORD-10042": {
                  "status": "in_transit",
                  "carrier": "DHL",
                  "estimated_delivery": "2026-08-08",
              }
          }
          return orders.get(order_id, {"error": "Order not found."})


      # 1. 質問と利用可能なツールを model に送信します。
      response = client.responses.create(
          model=MODEL,
          input=QUESTION,
          tools=tools,
      )

      # 2. model の出力アイテムを会話に追加します。
      next_input = [
          {"type": "message", "role": "user", "content": QUESTION},
          *[item.model_dump(exclude_none=True) for item in response.output],
      ]

      # 3. model が要求した関数をすべて実行し、その結果を追加します。
      for item in response.output:
          if item.type != "function_call":
              continue
          if item.name != "get_order_status":
              raise ValueError(f"Unknown function: {item.name}")

          arguments = json.loads(item.arguments)
          result = get_order_status(**arguments)
          next_input.append(
              {
                  "type": "function_call_output",
                  "call_id": item.call_id,
                  "output": json.dumps(result),
              }
          )

      # 4. 更新した会話を送り返して、model に回答させます。
      final_response = client.responses.create(
          model=MODEL,
          input=next_input,
          tools=tools,
      )

      print(final_response.output_text)
      ```

      ```typescript Typescript theme={null}
      import Perplexity from '@perplexity-ai/perplexity_ai';
      import type { InputItem } from '@perplexity-ai/perplexity_ai/resources/responses/responses';

      const MODEL = 'openai/gpt-5.6-sol';
      const QUESTION = "What's the status of order ORD-10042?";

      const client = new Perplexity();

      const tools = [
        {
          type: 'function' as const,
          name: 'get_order_status',
          description: 'Look up the current status of an order by its order ID.',
          parameters: {
            type: 'object',
            properties: { order_id: { type: 'string' } },
            required: ['order_id'],
            additionalProperties: false,
          },
          strict: true,
        },
      ];

      function getOrderStatus(orderId: string): Record<string, string> {
        // このサンプルデータは、データベースやAPI呼び出しに置き換えてください。
        const orders: Record<string, Record<string, string>> = {
          'ORD-10042': {
            status: 'in_transit',
            carrier: 'DHL',
            estimated_delivery: '2026-08-08',
          },
        };
        return orders[orderId] ?? { error: 'Order not found.' };
      }

      // 1. 質問と利用可能なツールをmodelに送信する。
      const response = await client.responses.create({
        model: MODEL,
        input: QUESTION,
        tools,
      });

      // 2. 元の質問から継続の入力を組み立てる。
      const nextInput: InputItem[] = [
        { type: 'message', role: 'user', content: QUESTION },
      ];

      // 3. 各関数呼び出しを再現し、ローカルで実行して結果を追加する。
      for (const item of response.output) {
        if (item.type !== 'function_call') continue;
        nextInput.push({
          type: 'function_call',
          call_id: item.call_id,
          name: item.name,
          arguments: item.arguments,
          ...(item.thought_signature
            ? { thought_signature: item.thought_signature }
            : {}),
        });

        if (item.name !== 'get_order_status') {
          throw new Error(`Unknown function: ${item.name}`);
        }
        const args = JSON.parse(item.arguments) as { order_id: string };
        const result = getOrderStatus(args.order_id);
        nextInput.push({
          type: 'function_call_output',
          call_id: item.call_id,
          output: JSON.stringify(result),
        });
      }

      // 4. 更新した会話を送り返し、modelに回答させる。
      const finalResponse = await client.responses.create({
        model: MODEL,
        input: nextInput,
        tools,
      });

      console.log(finalResponse.output_text);
      ```

<div id="how-the-loop-works">
  ## ループの仕組み
</div>

2回の Agent API リクエストで、1回のローカル関数実行を挟み込む形になります。

1. **宣言して呼び出す。** 最初のリクエストには、ユーザーの質問と `tools` 内の関数スキーマを含めます。
2. **`function_call` を読み取る。** model は `response.output` に `function_call` 項目を返します。その `arguments` フィールドは JSON 文字列なので、コードを呼び出す前にパースしてください。
3. **ローカルで実行する。** アプリケーション側でその引数を使って `get_order_status` を呼び出します。このコードは Agent API 上では実行されません。
4. **`function_call_output` を返す。** model の出力項目と、ローカルでの実行結果を含む `function_call_output` を追加したうえで、再度リクエストを送信します。model が結果と自身の呼び出しを対応付けられるよう、元の `call_id` をそのままコピーしてください。
5. **回答を読み取る。** 関数の結果を受け取ると、model は通常のアシスタント `message` を返します。代わりに別の関数が要求された場合は、同じループを繰り返します。

<div id="inspect-the-response-arrays">
  ## レスポンス配列を確認する
</div>

以下は、最初のリクエストで返された `output` 配列の全体です。`arguments` は JSON を文字列としてエンコードしたもので、ID はリクエストごとに異なります。

```json theme={null}
[
  {
    "id": "fc_a181bc3f-7a54-40b6-a85e-a50a0a6fac92",
    "arguments": "{\"order_id\":\"ORD-10042\"}",
    "call_id": "call_Ku9yfMSIZWrJBGm2wqCaFF0G",
    "name": "get_order_status",
    "status": "completed",
    "type": "function_call"
  }
]
```

アプリケーションは `get_order_status` を実行し、継続用の `input` 配列を送信します。`function_call` と `function_call_output` は同じ `call_id` を持ちます。

```json theme={null}
[
  {
    "type": "message",
    "role": "user",
    "content": "What's the status of order ORD-10042?"
  },
  {
    "id": "fc_a181bc3f-7a54-40b6-a85e-a50a0a6fac92",
    "arguments": "{\"order_id\":\"ORD-10042\"}",
    "call_id": "call_Ku9yfMSIZWrJBGm2wqCaFF0G",
    "name": "get_order_status",
    "status": "completed",
    "type": "function_call"
  },
  {
    "type": "function_call_output",
    "call_id": "call_Ku9yfMSIZWrJBGm2wqCaFF0G",
    "output": "{\"status\": \"in_transit\", \"carrier\": \"DHL\", \"estimated_delivery\": \"2026-08-08\"}"
  }
]
```

2回目のリクエストでは、次の完全な `output` 配列が返されます。

```json theme={null}
[
  {
    "id": "msg_b95a5d0d-bb02-4f09-bde4-22a781265e61",
    "content": [
      {
        "text": "Order **ORD-10042** is **in transit** with **DHL**. Estimated delivery is **Saturday, August 8, 2026**.",
        "type": "output_text",
        "annotations": []
      }
    ],
    "role": "assistant",
    "status": "completed",
    "type": "message"
  }
]
```

<Note>
  一部のモデルでは、`function_call` アイテムに `thought_signature` が含まれます。アイテムを再送する際は、この値を保持してください。Python の例では SDK オブジェクト全体をシリアライズすることで保持しており、TypeScript の例では値が存在する場合にコピーしています。
</Note>
