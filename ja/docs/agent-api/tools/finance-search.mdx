<div id="overview">
  ## 概要
</div>

`finance_search` を使うと、model が上場企業、ETF、および関連する金融商品の構造化された財務・市場データを取得できます。どのフィールドを取得するかは、プロンプトに応じて model が判断します。

同一の企業または企業リストについて、バリュエーション、決算、背景情報といった複数の種類の財務データを1つの回答にまとめる必要がある場合に使用してください。

<div id="capabilities">
  ### 機能
</div>

| データ領域            | 含まれる内容                                           |
| ---------------- | ------------------------------------------------ |
| 企業の基本情報          | 気配値、企業プロフィール、同業他社、市場メタデータ                        |
| 財務情報             | 損益計算書、貸借対照表、キャッシュフロー計算書 (四半期および年次) 、主要財務指標       |
| バリュエーションと価格      | 現在値・準リアルタイム価格、1分足から1か月足までのOHLCVデータ、時間前・時間外取引データ  |
| 決算               | 直近の決算説明会の書き起こし、決算報告の提出書類、予想比の達成・未達履歴、ガイダンスに関する言及 |
| セグメントおよびKPIの追跡   | セグメント別・地域別の売上／利益、ARPU、加入者数、GMV、その他の事業指標          |
| アナリストカバレッジ       | 今後の売上高およびEPS予想、カバレッジ数、予想値の変更履歴                   |
| 市場動向             | 値上がり率上位、値下がり率上位、出来高上位の銘柄                         |
| 保有状況とコーポレートアクション | インサイダー取引の動向、ティッカー単位のメタデータ、株式分割、関連する市場イベント        |
| ETFおよび指数の詳細      | 主要構成銘柄、株式数、構成比率、時価総額                             |

<div id="coverage">
  ## カバレッジ
</div>

`finance_search` のカバレッジは、銘柄シンボル、取引所、資産クラス、地域、およびソースデータの提供状況によって異なります。

| カバレッジ領域                | 現在のガイダンス                                  |
| ---------------------- | ----------------------------------------- |
| **ティッカーおよびシンボルのカバレッジ** | サポート対象のシンボルを解決できる場合の上場企業、ETF、および関連する金融商品。 |
| **資産クラス**              | 上場株式および ETF。                              |

<Warning>
  市場データは、一部のシンボルで遅延したり、不完全であったり、取得できなかったりする場合があります。`finance_search` は情報提供のみを目的としており、投資、法務、税務、財務に関する助言を提供するものではありません。
</Warning>

<div id="quickstart">
  ## クイックスタート
</div>

`tools` 配列に `finance_search` を追加します。preset を使わずに `model` または `models` を指定する場合は、`max_steps` に 3 以上を設定してください。省略した場合、モデル直接指定時のデフォルトは 1 ステップとなり、`finance_search` を初期化して実行するだけの余裕がありません。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="What's NVIDIA trading at right now, and what is its current P/E?",
      tools=[
          {"type": "web_search"},
          {"type": "finance_search"}
      ],
      max_steps=3
  )

  for item in response.output:
      if item.type == "message":
          print(item.content[0].text)
  ```

  ```bash cURL theme={null}
  curl -X POST "https://api.perplexity.ai/v1/agent" \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "What is NVIDIA trading at right now, and what is its current P/E?",
      "tools": [
        {"type": "web_search"},
        {"type": "finance_search"}
      ],
      "max_steps": 3
    }'
  ```
</CodeGroup>

<div id="example-prompts">
  ## プロンプト例
</div>

* **企業の総合ブリーフ:** 「NVIDIA の全体像をまとめてください。バリュエーション、直近四半期のセグメント別売上高、マージンガイダンスに関する経営陣の最新コメントを含めてください。」
* **1回のリクエストで複数企業を比較:** 「Apple、Microsoft、Alphabet について、直近会計年度の売上成長率、営業利益率、予想 PER を比較してください。」
* **決算＋市場反応の背景:** 「Tesla の直近の決算説明会を要約し、実績と市場予想の比較を含めたうえで、公表後に株価とアナリストの目標株価がどう動いたかを説明してください。」

<div id="prompt-guidance">
  ## プロンプトのガイダンス
</div>

`finance_search` は、データの形式ではなく得たい結果をプロンプトに記述すると最も効果的に機能します。

* まずビジネス上の問いを述べ、その後に企業名またはティッカーを含めます。
* 必要に応じて期間を指定します (`latest quarter`、`fiscal year to date`、`last 30 days`) 。
* どのレポート項目を取得するかは、ツールの判断に任せます。

<div id="recommended-configurations">
  ## 推奨構成
</div>

金融関連の質問の性質に合った構成から始めてください。

| 構成           | 最適な用途                 | レイテンシ | 品質 | コスト |
| ------------ | --------------------- | ----- | -- | --- |
| ライブ市場データと気配値 | リアルタイムの価格、気配値、最新の数値   | 高速    | 良好 | 低   |
| 単一企業の過去データ参照 | 1社または1銘柄の基本的な過去の財務データ | バランス型 | 高  | 中   |
| 多段階の金融リサーチ   | 企業間の比較や複雑な財務分析        | 徹底的   | 最高 | 高   |

<div id="live-market-data-and-quotes">
  ### ライブ市場データと気配値
</div>

リアルタイムの価格や気配値、最新の市場数値を必要とする、即時性の高い回答にはこの構成を使用します。ライブデータの取得において高い品質を保ちながら、最も低コストかつ高速な選択肢です。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="What is Apple's most recent annual revenue, and what segments contributed most to year-over-year growth?",
      tools=[{"type": "finance_search"}],
      max_steps=3,
      max_output_tokens=1024
  )

  for item in response.output:
      if item.type == "message":
          print(item.content[0].text)
  ```

  ```bash cURL theme={null}
  curl -X POST "https://api.perplexity.ai/v1/agent" \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "What is Apple\u0027s most recent annual revenue, and what segments contributed most to year-over-year growth?",
      "tools": [{"type": "finance_search"}],
      "max_steps": 3,
      "max_output_tokens": 1024
    }'
  ```
</CodeGroup>

<div id="single-company-historical-lookups">
  ### 単一企業の過去データ参照
</div>

単一企業の過去の数値を調べる場合や、構造化された金融データとウェブ上の文脈の両方が役立つ基本的な質問には、この構成を使用してください。GPT-5.5 は単純なウェブ検索を得意とし、過去データの参照ではトークン効率にも優れています。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="What was Microsoft's total revenue in its most recently completed fiscal year, and how did it compare with the prior fiscal year according to Microsoft's annual report?",
      tools=[
          {"type": "web_search"},
          {"type": "finance_search"},
          {"type": "fetch_url"}
      ],
      max_steps=5,
      max_output_tokens=2048,
      reasoning={"effort": "low"}
  )

  for item in response.output:
      if item.type == "message":
          print(item.content[0].text)
  ```

  ```bash cURL theme={null}
  curl -X POST "https://api.perplexity.ai/v1/agent" \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    --data @- <<'JSON'
  {
      "model": "openai/gpt-5.6-sol",
      "input": "What was Microsoft's revenue in its most recently completed fiscal year and the prior fiscal year, according to Microsoft's 10-K?",

        {"type": "web_search"},

      ],
      "max_steps": 5,

  JSON
  ```

<div id="multi-step-financial-research">
  ### 多段階の財務リサーチ
</div>

複数企業の比較、長期にわたる過去データの調査、財務諸表・提出書類・決算説明の書き起こし・ウェブ上の情報源をまたいで複数回のツール呼び出しを要する分析には、この構成が適しています。Opus は、すべてのツールを併用した場合に複雑な多段階推論で最も高い性能を発揮します。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="anthropic/claude-opus-4-7",
      input="Compare Apple, Microsoft, and Alphabet on revenue growth and operating margin trends over the last three fiscal years using their 10-K filings.",
      tools=[
          {"type": "web_search"},
          {"type": "finance_search"},
          {"type": "fetch_url"}
      ],
      max_steps=10,
      max_output_tokens=4096
  )

  for item in response.output:
      if item.type == "message":
          print(item.content[0].text)
  ```

<div id="response-shape">
  ## レスポンスの形式
</div>

`finance_search` が実行されると、レスポンスには最終的なアシスタントメッセージの前に `finance_results` 出力アイテムが含まれることがあります。各 `finance_results` アイテムには、リクエストされた金融カテゴリ、ティッカーシンボル、構造化コンテンツ、および利用可能な場合はソース URL が含まれます。最終的な `usage` オブジェクトには、token 数とコストの詳細に加え、ツール呼び出しの使用状況が報告される場合は `tool_calls_details.finance_search.invocation` も含まれます。

<Note>
  料金体系は他のツール呼び出しと同様で、呼び出し回数分に加えてモデルの token 分をお支払いいただきます。[料金](/ja/docs/getting-started/pricing)を参照してください。
</Note>

<div id="limits-quotas">
  ## 制限 / クォータ
</div>

`finance_search` は他のツールと同じ Agent API のリクエストフローを使用します。制限は、アカウントのティア、リクエストの設定、プロンプトに回答するために必要なツール呼び出し回数によって異なります。ティアごとのリクエスト制限については [レート制限と利用ティア](/ja/docs/admin/rate-limits-usage-tiers#agent-api-rate-limits) を参照してください。

| 制限の対象         | 想定される内容                                                                                                                                            |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **API レート制限** | `finance_search` を使用するリクエストには Agent API のレート制限が適用されます。                                                                                             |
| **ツール呼び出し**   | モデルが `finance_search` を呼び出すたびに、課金対象のツール呼び出し 1 回としてカウントされます。複数の企業を扱うプロンプトや複数ステップのプロンプトでは、2 回以上の呼び出しが必要になる場合があります。                                   |
| **ステップ制限**    | モデルを直接指定する場合は、`finance_search` の初期化と実行が行えるよう、`max_steps` を最低でも 3 に設定してください。`web_search` や `fetch_url` などのツールと組み合わせる複数ステップのリクエストでは、より大きな値を指定してください。 |
| **出力の制限**     | 大規模な比較、長い書き起こし、複数年にわたる財務テーブルでは、`max_output_tokens` やレスポンスの切り詰め設定の上限に達することがあります。                                                                    |
| **カバレッジの制限**  | ソースのカバレッジやデータの鮮度によっては、一部の銘柄コード、取引所、地域、資産クラス、フィールドが利用できない場合があります。                                                                                   |
