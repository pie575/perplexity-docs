<div id="overview">
  ## 概要
</div>

公式の Perplexity SDK を使うと、Python 3.8 以降および Node.js のアプリケーションから Perplexity API に簡単にアクセスできます。どちらの SDK にも、すべてのリクエストパラメータとレスポンスフィールドの型定義が含まれており、同期クライアントと非同期クライアントの両方を利用できます。

利用できる API は 4 つです。Web 検索ツールと preset を利用できるサードパーティ製モデル向けの **Agent API**、ランク付けされた Web 検索結果を返す **Search**、Web の情報に基づく AI レスポンスを返す **Sonar**、テキスト埋め込みを生成する **Embeddings** です。

<div id="installation">
  ## インストール
</div>

使用したい言語のSDKをインストールします。

<CodeGroup>
  ```bash Python theme={null}
  pip install perplexityai
  ```

  ```bash TypeScript theme={null}
  npm install @perplexity-ai/perplexity_ai
  ```
</CodeGroup>

<div id="authentication">
  ## 認証
</div>

<Card title="Perplexity API キーを取得する" icon="key" arrow="True" horizontal="True" iconType="solid" cta="こちらをクリック" href="https://console.perplexity.ai/project/keys">
  API Console の **API Keys** ページで新しいキーを生成します。
</Card>

キーを生成したら、ターミナルで環境変数として設定します。

<Tabs>
  <Tab title="Windows">
    ```bash theme={null}
    setx PERPLEXITY_API_KEY "your_api_key_here"
    ```
  </Tab>

  <Tab title="MacOS/Linux">
    ```bash theme={null}
    export PERPLEXITY_API_KEY="your_api_key_here"
    ```
  </Tab>
</Tabs>

<div id="using-environment-variables">
  ### 環境変数を使用する
</div>

環境変数をそのまま利用できます。

<CodeGroup>
  ```python Python theme={null}
  import os
  from perplexity import Perplexity

  client = Perplexity() # PERPLEXITY_API_KEY を自動的に使用します
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity({
    apiKey: process.env['PERPLEXITY_API_KEY'], // これがデフォルトのため、省略できます
  });
  ```
</CodeGroup>

また、[python-dotenv](https://pypi.org/project/python-dotenv/) (Python) や [dotenv](https://www.npmjs.com/package/dotenv) (Node.js) を使って、`.env` ファイルから環境変数を読み込むこともできます。

<CodeGroup>
  ```python Python theme={null}
  import os
  from dotenv import load_dotenv
  from perplexity import Perplexity

  load_dotenv()

  client = Perplexity() # .env ファイルの PERPLEXITY_API_KEY を使用します
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';
  import dotenv from 'dotenv';

  dotenv.config();

  const client = new Perplexity(); // .env ファイルの PERPLEXITY_API_KEY を使用します
  ```
</CodeGroup>
