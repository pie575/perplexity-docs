<div id="overview">
  ## 概要
</div>

Perplexity の Embeddings API は、セマンティック検索や情報検索に使える高品質なテキスト埋め込みを生成します。互いに独立したテキストには**標準の埋め込み**を、コンテキストを共有するドキュメントチャンクには**コンテキスト化埋め込み**を選択してください。

<Info>
  Embeddings API をより手軽かつ型安全に利用するには、[公式 SDK](/ja/docs/sdk/overview) の使用をおすすめします。
</Info>

<Card title="料金" icon="receipt" href="/ja/docs/getting-started/pricing" horizontal="True" cta="料金を見る">
  すべての API は従量課金制です。サブスクリプションは不要です。
</Card>

<div id="available-models">
  ## 利用可能なモデル
</div>

|              モデル             |  次元数 | コンテキスト | MRL |     量子化     | 価格 ($/100万 token)  |
| :--------------------------: | :--: | :----: | :-: | :---------: | :----------------: |
|     `pplx-embed-v1-0.6b`     | 1024 |   32K  |  あり | INT8/BINARY |       $0.004       |
|      `pplx-embed-v1-4b`      | 2560 |   32K  |  あり | INT8/BINARY |        $0.03       |
| `pplx-embed-context-v1-0.6b` | 1024 |   32K  |  あり | INT8/BINARY |       $0.008       |
|  `pplx-embed-context-v1-4b`  | 2560 |   32K  |  あり | INT8/BINARY |        $0.05       |

すべてのモデルは平均プーリングを使用し、命令プレフィックスは不要です。プロンプトエンジニアリングなしで、テキストをそのまま埋め込みに変換できます。

<Warning>
  Perplexity の埋め込みは**正規化されていません**。`base64_int8` の埋め込みは必ず**コサイン類似度**で比較してください (内積や L2 距離は使用しないでください) 。`base64_binary` の埋め込みは**ハミング距離**で比較します。詳細と正規化用のヘルパーについては[ベストプラクティス](/ja/docs/embeddings/best-practices)を参照してください。
</Warning>

<Tip>
  **使い分けの目安:**

  * **標準の埋め込み** (`pplx-embed-v1-*`) - 独立したテキスト、検索クエリ、単一の文
  * **コンテキスト化埋め込み** (`pplx-embed-context-v1-*`) - コンテキストの共有が有効なドキュメントチャンク (例: 同一記事内の段落)
</Tip>

<div id="authentication">
  ## 認証
</div>

API key を環境変数に設定します。

<Tabs>
  <Tab title="macOS/Linux">
    ```bash theme={null}
    export PERPLEXITY_API_KEY="your_api_key_here"
    ```
  </Tab>

  <Tab title="Windows">
    ```powershell theme={null}
    setx PERPLEXITY_API_KEY "your_api_key_here"
    ```
  </Tab>
</Tabs>
