<div id="overview">
  ## 概要
</div>

Router API は、単一の API と API キー で、Perplexity がホストするオープンウェイトモデルに統一的にアクセスできる仕組みを提供します。OpenAI Chat Completions、OpenAI Responses、または Anthropic Messages の形式でリクエストを送信し、[カタログ](/ja/docs/router/models)から任意の model を選択するだけで、プラットフォームが各リクエストを正常なデプロイメントへ自動的にルーティングします。プロバイダーごとのアカウントや SDK、フェイルオーバーロジックを自前で用意する必要はありません。

カタログ内のすべての model は、その model の提供元に関係なく、サポートされている任意のスキーマから呼び出せます。そのため Router は、既存の OpenAI または Anthropic 連携をそのまま置き換えられます。変更が必要なのはベース URL と API キー だけです。

独自のプロンプトやツールで model に直接アクセスしたい場合は Router API を使用してください。引用が組み込まれた、ウェブに基づく回答が必要な場合は [Agent API](/ja/docs/agent-api/quickstart) を使用してください。

ベース URL は `https://api.perplexity.ai/router/v1` で、既存の Perplexity API キー をそのまま利用できます。

<div id="installation">
  ## インストール
</div>

Router API は OpenAI の Chat Completions 形式および Responses 形式に加え、Anthropic の Messages 形式にも対応しています。そのため、どちらのプロバイダーの公式 SDK でも利用できます。ご自身の実装に合うものをインストールしてください (両方インストールしても構いません) 。

<CodeGroup>
  ```bash Python theme={null}
  pip install openai       # OpenAI の Chat Completions 形式および Responses 形式
  pip install anthropic    # Anthropic の Messages 形式
  ```

  ```bash Typescript theme={null}
  npm install openai              # OpenAI の Chat Completions 形式および Responses 形式
  npm install @anthropic-ai/sdk   # Anthropic の Messages 形式
  ```
</CodeGroup>

<div id="authentication">
  ## 認証
</div>

API キー を環境変数に設定します:

<Tabs>
  <Tab title="macOS/Linux">
    ```bash theme={null}
    export PERPLEXITY_API_KEY="your_api_key_here"
    ```
  </Tab>

  <Tab title="Windows">
    ```powershell theme={null}
    setx PERPLEXITY_API_KEY "your_api_key_here"
    ```
  </Tab>
</Tabs>

リクエストの認証には `Authorization: Bearer` ヘッダーを使用します。SDK を利用する場合は、`api_key` パラメータの値から自動的に設定されます。

<div id="basic-usage">
  ## 基本的な使い方
</div>

OpenAI SDK のベース URL を Router に向け、[カタログ](/ja/docs/router/models)にある任意の model id を指定します。model id は `creator/model-name` 形式のスラッグなので、プロバイダーの切り替えは1行の変更だけで済みます。

<CodeGroup>
  ```python Python theme={null}
  from openai import OpenAI
  import os

  client = OpenAI(
      api_key=os.environ.get("PERPLEXITY_API_KEY"),
      base_url="https://api.perplexity.ai/router/v1"
  )

  response = client.chat.completions.create(
      model="perplexity/kimi-k3",
      max_tokens=1024,
      messages=[
          {"role": "user", "content": "Explain the CAP theorem in two sentences."}
      ]
  )

  print(response.choices[0].message.content)
  ```

  ```typescript Typescript theme={null}
  import OpenAI from 'openai';

  const client = new OpenAI({
      apiKey: process.env.PERPLEXITY_API_KEY,
      baseURL: "https://api.perplexity.ai/router/v1"
  });

  const response = await client.chat.completions.create({
      model: "perplexity/kimi-k3",
      max_tokens: 1024,
      messages: [
          { role: "user", content: "Explain the CAP theorem in two sentences." }
      ]
  });

  console.log(response.choices[0].message.content);
  ```

  ```bash cURL theme={null}
  curl -X POST 'https://api.perplexity.ai/router/v1/chat/completions' \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "perplexity/kimi-k3",
      "max_tokens": 1024,
      "messages": [
        {"role": "user", "content": "Explain the CAP theorem in two sentences."}
      ]
    }' | jq
  ```
</CodeGroup>

<div id="openai-responses">
  ## OpenAI Responses
</div>

インテグレーションで OpenAI Responses 形式を使用している場合は、同じ Router のベース URL を指定して `client.responses.create()` を呼び出します。Router の Responses エンドポイントはステートレスなので、リクエストごとに会話全体を `input` に含めてください。

<CodeGroup>
  ```python Python theme={null}
  from openai import OpenAI
  import os

  client = OpenAI(
      api_key=os.environ.get("PERPLEXITY_API_KEY"),
      base_url="https://api.perplexity.ai/router/v1"
  )

  response = client.responses.create(
      model="perplexity/kimi-k3",
      input="Explain the CAP theorem in two sentences.",
      max_output_tokens=1024
  )

  print(response.output_text)
  ```

  ```typescript Typescript theme={null}
  import OpenAI from 'openai';

  const client = new OpenAI({
      apiKey: process.env.PERPLEXITY_API_KEY,
      baseURL: "https://api.perplexity.ai/router/v1"
  });

  const response = await client.responses.create({
      model: "perplexity/kimi-k3",
      input: "Explain the CAP theorem in two sentences.",
      max_output_tokens: 1024
  });

  console.log(response.output_text);
  ```

  ```bash cURL theme={null}
  curl -X POST 'https://api.perplexity.ai/router/v1/responses' \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "perplexity/kimi-k3",
      "input": "Explain the CAP theorem in two sentences.",
      "max_output_tokens": 1024
    }' | jq
  ```
</CodeGroup>

<div id="streaming-chat-completions">
  ## ストリーミングチャット補完
</div>

`stream: true` を設定すると、トークンがServer-Sent Events として順次送信されます。ストリーミングレスポンスでトークンの使用量を取得するには、あわせて `stream_options: {"include_usage": true}` を設定します。この場合、使用量は `data: [DONE]` の直前の最終チャンクに含まれます。

<CodeGroup>
  ```python Python theme={null}
  from openai import OpenAI
  import os

  client = OpenAI(
      api_key=os.environ.get("PERPLEXITY_API_KEY"),
      base_url="https://api.perplexity.ai/router/v1"
  )

  stream = client.chat.completions.create(
      model="perplexity/kimi-k3",
      max_tokens=1024,
      messages=[
          {"role": "user", "content": "Write a haiku about network latency."}
      ],
      stream=True,
      stream_options={"include_usage": True}
  )

  for chunk in stream:
      if chunk.choices and chunk.choices[0].delta.content:
          print(chunk.choices[0].delta.content, end="")
      if chunk.usage:
          print(f"\n\nTokens used: {chunk.usage.total_tokens}")
  ```

  ```typescript Typescript theme={null}
  import OpenAI from 'openai';

  const client = new OpenAI({
      apiKey: process.env.PERPLEXITY_API_KEY,
      baseURL: "https://api.perplexity.ai/router/v1"
  });

  const stream = await client.chat.completions.create({
      model: "perplexity/kimi-k3",
      max_tokens: 1024,
      messages: [
          { role: "user", content: "Write a haiku about network latency." }
      ],
      stream: true,
      stream_options: { include_usage: true }
  });

  for await (const chunk of stream) {
      if (chunk.choices[0]?.delta?.content) {
          process.stdout.write(chunk.choices[0].delta.content);
      }
      if (chunk.usage) {
          console.log(`\n\nTokens used: ${chunk.usage.total_tokens}`);
      }
  }
  ```

  ```bash cURL theme={null}
  curl -N -X POST 'https://api.perplexity.ai/router/v1/chat/completions' \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "perplexity/kimi-k3",
      "max_tokens": 1024,
      "messages": [
        {"role": "user", "content": "Write a haiku about network latency."}
      ],
      "stream": true,
      "stream_options": {"include_usage": true}
    }'
  ```
</CodeGroup>

<div id="anthropic-messages">
  ## Anthropic Messages
</div>

同じモデル群は `/router/v1/messages` でAnthropic Messages形式でも利用でき、Anthropic SDK向けに書かれたコードはベース URLを変更するだけで動作します。

<Info>
  Anthropic SDKはベース URLの末尾に `/v1/messages` を付加するため、`https://api.perplexity.ai/router` (`/v1` なし) を指定してください。OpenAI SDKは `/chat/completions` を付加するため、`https://api.perplexity.ai/router/v1` を指定します。
</Info>

<CodeGroup>
  ```python Python theme={null}
  from anthropic import Anthropic
  import os

  client = Anthropic(
      api_key=os.environ.get("PERPLEXITY_API_KEY"),
      base_url="https://api.perplexity.ai/router"
  )

  message = client.messages.create(
      model="perplexity/kimi-k3",
      max_tokens=1024,
      messages=[
          {"role": "user", "content": "Explain the CAP theorem in two sentences."}
      ]
  )

  print(message.content[0].text)
  ```

  ```typescript Typescript theme={null}
  import Anthropic from '@anthropic-ai/sdk';

  const client = new Anthropic({
      apiKey: process.env.PERPLEXITY_API_KEY,
      baseURL: "https://api.perplexity.ai/router"
  });

  const message = await client.messages.create({
      model: "perplexity/kimi-k3",
      max_tokens: 1024,
      messages: [
          { role: "user", content: "Explain the CAP theorem in two sentences." }
      ]
  });

  console.log(message.content[0].text);
  ```

  ```bash cURL theme={null}
  curl -X POST 'https://api.perplexity.ai/router/v1/messages' \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "perplexity/kimi-k3",
      "max_tokens": 1024,
      "messages": [
        {"role": "user", "content": "Explain the CAP theorem in two sentences."}
      ]
    }' | jq
  ```
</CodeGroup>
