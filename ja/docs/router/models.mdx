<div id="overview">
  ## 概要
</div>

以下のすべてのモデルは、Routerの2つのエンドポイント — [Chat Completions](/ja/api-reference/gateway-chat-completions-post) と [Messages](/ja/api-reference/gateway-messages-post) — のどちらからでも、同じ `creator/model-name` idで利用できます。価格は100万トークンあたりの米ドル建てで、リクエストがどのように処理されたかに関わらず、リクエストしたモデルの料金で課金されます。

最新のカタログは [`GET /models`](/ja/api-reference/gateway-models-get) で取得できます。以下の表は現時点のカタログを示しています。

<Note>
  キャッシュされた入力は、新規の入力とは別に課金されます。キャッシュの読み取りは「キャッシュ読み取り」列に記載されたモデルごとの割引レートで、キャッシュの書き込みは記載のレート (専用の書き込みレートがない場合は入力レート) で課金されます。推論トークンは出力レートで課金されます。
</Note>

<div id="listing-models-programmatically">
  ## プログラムによるモデル一覧の取得
</div>

```bash theme={null}
curl 'https://api.perplexity.ai/router/v1/models' \
  -H "Authorization: Bearer $PERPLEXITY_API_KEY" | jq
```

レスポンスには、利用可能なすべてのモデルが id 順に並べられて一覧表示され、各モデルの基本トークン価格も含まれます。カタログに存在しないモデルをリクエストすると、無効なモデル名を示す `400` が返されます。つまり、このカタログは許可リストも兼ねています。
