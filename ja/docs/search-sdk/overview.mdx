<div id="search-as-code">
  ## コードとしての検索
</div>

従来の検索は、情報の取得を一体不可分の処理として扱います。モデルがクエリを発行し、検索エンジンが定義済みのパイプラインを実行し、モデルが処理済みの結果を受け取る、という流れです。しかし、この前提は複雑で終わりの見えないタスクに取り組むエージェントには通用しません。得られるコンテキストは粒度が粗く、モデルが持つドメイン知識は活かされず、本来並列に進められる作業を直列のインターフェースに押し込めてしまうからです。

[Search as Code](https://research.perplexity.ai/articles/rethinking-search-as-code-generation) は、これに対するPerplexityの答えです。検索スタックを組み合わせ可能なプリミティブとして公開し、エージェントが生成したコードを通じてそれらを組み立てます。エージェントは取得、ランキング、フィルタリング、ファンアウト、レンダリングを直接制御し、中間状態をモデルのコンテキストではなくランタイム側に保持して、本当に必要な情報だけを取り込みます。

Perplexity Search SDKは、このアプローチをお使いのエージェントやアプリケーションでも利用できるようにします。[Search API](/ja/docs/search/quickstart) のリアルタイムなランク付きWeb結果とクエリに関連するページスニペットをPythonのプリミティブとして提供し、取得処理が中心となるワークフローに向けて並行処理、来歴 (プロベナンス) 、チェックポイントを標準で備えています。

<div id="built-for-agents">
  ## エージェントのために設計
</div>

このSDKはエージェントファーストです。文章によるドキュメントを読んで習得するのではなく、コーディングエージェントが操作することを前提に設計されています。標準的な利用リファレンスはSDKのAgent Skillで、インストール、認証、全メソッド、ワークフローパターン、既知の注意点を網羅しています。

<Card title="pplx-search-sdk Agent Skill" icon="github" horizontal="true" arrow="true" href="https://github.com/perplexityai/api-platform-developers/tree/main/skills/pplx-search-sdk">
  このスキルをコーディングエージェントにインストールして、統合コードはエージェントに書かせましょう。
</Card>

ソースコードは [perplexityai/perplexity-search-sdk](https://github.com/perplexityai/perplexity-search-sdk) にあり、パッケージは PyPI で [pplx-srch-sdk](https://pypi.org/project/pplx-srch-sdk/) として公開されています。
