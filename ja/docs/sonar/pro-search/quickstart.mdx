<div id="overview">
  ## 概要
</div>

Pro Search は [Sonar Pro](/ja/docs/sonar/models/sonar-pro) にツールの自動利用を追加し、Web 検索や URL コンテンツの取得といったツールをインテリジェントに組み合わせることで、多段階の推論を実現します。

<Warning>
  Pro Search はストリーミングが有効な場合にのみ動作します。ストリーミングを使用しないリクエストは、標準の Sonar Pro の動作にフォールバックします。
</Warning>

<div>
  <div>
    <h3>標準の Sonar Pro</h3>

    <ul>
      <li>単一の Web 検索の実行</li>
      <li>高速な回答の生成</li>
      <li>固定的な検索戦略</li>
      <li>静的な結果処理</li>
    </ul>
  </div>

  <div>
    <h3>Sonar Pro の Pro Search</h3>

    <ul>
      <li>ツールの自動実行による多段階の推論</li>
      <li>動的なツール実行</li>
      <li>リアルタイムの思考ストリーミング</li>
      <li>適応的なリサーチ戦略</li>
    </ul>
  </div>
</div>

<div id="basic-usage">
  ## 基本的な使い方
</div>

Pro Search を有効にするには、API リクエストで `stream` を `true` に設定し、`"search_type": "pro"` を指定します。通常の Sonar Pro では、検索タイプのデフォルトは `"fast"` です。

ストリーミングで Pro Search を有効にする例は次のとおりです。

<CodeGroup>
  ```python Python SDK theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  messages = [
      {
          "role": "user", 
          "content": "Summarize developments in post-quantum cryptography and how lattice-based and hash-based schemes are being standardized by NIST."
      }
  ]

  response = client.chat.completions.create(
      model="sonar-pro",
      messages=messages,
      stream=True,
      web_search_options={
          "search_type": "pro"
      }
  )

  for chunk in response:
      if chunk.choices[0].delta.content:
          print(chunk.choices[0].delta.content, end="")
  ```

  ```typescript Typescript SDK theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.chat.completions.create({
    model: 'sonar-pro',
    messages: [
      {
        role: 'user',
        content: 'Summarize developments in post-quantum cryptography and how lattice-based and hash-based schemes are being standardized by NIST.'
      }
    ],
    stream: true,
    web_search_options: {
      search_type: 'pro'
    }
  });

  for await (const chunk of response) {
    if (chunk.choices[0]?.delta?.content) {
      process.stdout.write((chunk.choices[0]?.delta?.content ?? '') as string);
    }
  }
  ```

  ```bash cURL theme={null}
  curl --request POST \
    --url https://api.perplexity.ai/v1/sonar \
    --header "Authorization: Bearer $PERPLEXITY_API_KEY" \
    --header "Content-Type: application/json" \
    --data '{
      "model": "sonar-pro",
      "messages": [
        {
          "role": "user",
          "content": "Summarize developments in post-quantum cryptography and how lattice-based and hash-based schemes are being standardized by NIST."
        }
      ],
      "stream": true,
      "web_search_options": {
        "search_type": "pro"
      }
    }' --no-buffer
  ```
</CodeGroup>

<div id="enabling-automatic-classification">
  ## 自動分類の有効化
</div>

Sonar Pro は、クエリの複雑さに応じて Pro Search と Fast Search のいずれかへ自動的に振り分けるように設定できます。ほとんどのアプリケーションでは、この方法を推奨します。

`search_type: "auto"` を設定すると、システムが複雑さに基づいてクエリを適切にルーティングします。

<CodeGroup>
  ```python Python SDK theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.chat.completions.create(
      model="sonar-pro",
      messages=[
          {
              "role": "user",
              "content": "Compare the energy efficiency (kWh/100mi and MPGe) of the Tesla Model 3, Chevrolet Bolt, and Nissan Leaf using EPA data."
          }
      ],
      stream=True,
      web_search_options={
          "search_type": "auto"  # 自動分類
      }
  )

  for chunk in response:
      if chunk.choices[0].delta.content:
          print(chunk.choices[0].delta.content, end="")
  ```

<div id="how-classification-works">
  #### 分類のしくみ
</div>

分類器はクエリを解析し、自動的に以下のいずれかへ振り分けます。

* 次のような複雑なクエリには **Pro Search**
  * 多段階の推論や分析を要するもの
  * 複数のソースを横断した比較分析
  * 深掘りしたリサーチのワークフロー

* 次のような単純なクエリには **Fast Search**
  * 簡単な事実の確認
  * 直接的な情報の取得
  * 基本的な質問への回答

<div id="billing-with-auto-classification">
  #### 自動分類での課金
</div>

**課金は、クエリがどの検索タイプを呼び出したかに基づいて行われます:**

* **Pro Search** に分類された場合: 1,000リクエストあたり $14〜$22 (コンテキストサイズに応じて)
* **Fast Search** に分類された場合: 1,000リクエストあたり $6〜$14 (コンテキストサイズに応じて － 標準のSonar Proと同じ)

料金の詳細については、<a href="/ja/docs/sonar/pro-search/quickstart#pricing">料金</a>セクションを参照してください。

<Tip>
  自動分類は、コスト最適化とクエリのパフォーマンスのバランスが取れるため、ほとんどのアプリケーションで推奨されます。単純なクエリに余分なコストをかけることなく、必要なときにPro Searchの機能を活用できます。
</Tip>

<div id="manually-specifying-the-search-type">
  ### 検索タイプを手動で指定する
</div>

必要に応じて、検索タイプを手動で指定できます。クエリに Pro Search の機能が必要だと事前に分かっている場合など、特定のユースケースで有用です。

* **`"search_type": "pro"`**: マルチステップのツール利用が必要だと分かっている複雑なクエリには、Pro Search を手動で指定します
* **`"search_type": "fast"`**: 単純なクエリには Fast Search を手動で指定し、速度とコストを最適化します (`search_type` を省略した場合のデフォルトでもあります)

  `search_type: "auto"` を使用する場合、クエリが複雑と分類されると Pro Search の料金、単純と分類されると Fast Search の料金で課金されます。料金の詳細は<a href="/ja/docs/getting-started/pricing">こちら</a>をご覧ください。
</Info>
