title: "使用状況分析"
description: "組織の Perplexity 使用状況分析を、単一データセットのバケット化された時系列として返します。組織分析用の API key
  が必要です。API key は、組織管理者が Perplexity ウェブアプリの Settings → Organization → Computer
  から生成します。返されるのは完全な UTC グリッドバケットのみで、start_time
  は該当するバケットの開始位置まで切り下げられ、進行中のバケットは含まれません。集計対象はデータセットごとに異なり、credit_usage
  はクレジット、query_volume はクエリ、daily_active_users
  は重複を除いたアクティブメンバー、それ以外はスレッド数を集計します。daily_active_users
  のバケットは加算できません。複数日にわたってアクティブなメンバーは日ごとに 1
  回カウントされるため、合計してもその期間のアクティブメンバー数にはなりません。"
openapi: "/ja/openapi/openapi.json GET /v1/analytics/computer/usage"
