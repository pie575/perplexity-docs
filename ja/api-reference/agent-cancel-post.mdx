description: "レスポンス `{id}`
  のキャンセルを要求します。永続化された状態に対して作用するため、クライアント接続が切れた後も続くバックグラウンド実行にも有効です。キャンセルは非同期で行わ\
  れます。`200` は要求を受理したことを示し（`status: cancelling`）、実行はその直後に停止します。最終的なステータスは `GET
  /v1/agent/{id}` をポーリングして確認してください。すでに終了状態にある実行をキャンセルした場合は `400`
  が返されます。所有権はサーバー側で検証され、テナントをまたぐ id や不明な id は `404` として返されます。"
openapi: "/ja/openapi/openapi.json POST /v1/agent/{id}/cancel"
