title: "エージェントのレスポンスファイルをダウンロード"
description: "レスポンスが `share_file` ツールで提供したファイルの生バイト列をダウンロードします。`file_id`
  はファイル一覧エンドポイントから取得でき、レスポンスの `id` とは別のものです。このエンドポイントは JSON
  ではなく生バイト列をストリーミングで返し、ファイルに応じた `Content-Type` と、元のファイル名を含む
  `Content-Disposition: attachment` ヘッダーが付与されます。"
openapi: "/ja/openapi/openapi.json GET /v1/agent/{id}/files/{file_id}/content"
