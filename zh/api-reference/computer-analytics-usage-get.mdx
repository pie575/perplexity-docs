description: "以按时间分桶的时间序列形式返回组织中单个数据集的 Perplexity 使用分析数据。需要组织分析 API key，由组织管理员在
  Perplexity 网页应用中通过 Settings → Organization → Computer 生成。仅返回完整的 UTC
  网格分桶：start_time 会向下对齐到其所属分桶，进行中的分桶不会包含在内。各数据集统计的内容不同：credit_usage
  统计额度，query_volume 统计查询数，daily_active_users
  统计去重后的活跃成员数，其余数据集统计线程数。daily_active_users
  的各分桶不可累加——某成员若在多天内活跃，则每天都会被计入一次，因此将各分桶相加并不等于该时间窗口内的活跃成员数。"
