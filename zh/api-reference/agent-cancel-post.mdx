title: "取消 Agent 响应"
description: "请求取消响应 `{id}`。该操作基于持久化状态，因此对生命周期长于客户端连接的后台运行同样有效。取消为异步过程：返回 `200`
  表示请求已受理（`status: cancelling`），运行会在随后不久停止——可轮询 `GET /v1/agent/{id}`
  查看其最终状态。取消已处于终态的运行会返回 `400`。服务端会校验所有权；跨租户或未知的 id 将返回 `404`。"
openapi: "/zh/openapi/openapi.json POST /v1/agent/{id}/cancel"
