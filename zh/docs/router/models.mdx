<div id="overview">
  ## 概览
</div>

下列每个 模型 都可通过两个 Router 端点访问——[Chat Completions](/zh/api-reference/gateway-chat-completions-post) 和 [Messages](/zh/api-reference/gateway-messages-post)——使用相同的 `creator/model-name` id。价格单位为美元/百万 token;无论请求以何种方式被处理,均按所请求 模型 的费率计费。

如需获取实时目录,请调用 [`GET /models`](/zh/api-reference/gateway-models-get);下方表格展示的是当前目录。

<Note>
  缓存输入与新输入分开计费:缓存读取按“缓存读取”列中显示的各 模型 折扣费率计费,缓存写入按所示费率计费(若未单独列出写入费率,则按输入费率计费)。推理 token 按输出费率计费。
</Note>

<div id="listing-models-programmatically">
  ## 以编程方式列出模型
</div>

```bash theme={null}
curl 'https://api.perplexity.ai/router/v1/models' \
  -H "Authorization: Bearer $PERPLEXITY_API_KEY" | jq
```

响应会按 id 排序列出所有可用的 模型，并包含每个 模型 的基础 token 价格。若请求的 模型 不在目录中，则会返回 `400` 并指明该无效 模型——该目录同时也是允许列表。
