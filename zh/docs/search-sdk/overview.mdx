<div id="search-as-code">
  ## 搜索即代码
</div>

传统搜索把检索当作一个铁板一块的整体：model 发出查询，搜索引擎跑一条预定义的流水线，model 再消费处理后的结果。对于处理复杂、开放式任务的智能体而言，这套约定就失效了——它给出的上下文过于粗糙，浪费了 model 的领域知识，还把天然可并行的工作硬塞进串行接口。

[Search as Code](https://research.perplexity.ai/articles/rethinking-search-as-code-generation) 正是 Perplexity 给出的答案：把搜索栈拆成可组合的原语对外暴露，由智能体通过生成代码来编排。智能体直接掌控检索、排序、过滤、扇出和渲染，把中间状态留在运行时而非 model 上下文中，只消费真正有价值的信息。

Perplexity Search SDK 将这一思路带入你自己的智能体和应用。它把 [Search API](/zh/docs/search/quickstart) 的实时排序网页结果和与查询相关的页面片段封装为 Python 原语，并为检索密集型工作流内置了并发、来源溯源和检查点能力。
