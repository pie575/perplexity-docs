<div id="overview">
  ## 概览
</div>

Perplexity 的 Sonar API 完全兼容 OpenAI 的 Chat Completions 格式。只需更改基础 URL 并提供你的 Perplexity API key，即可用现有的 OpenAI 客户端库调用 Sonar API。

<Info>
  **端点说明：** Perplexity 的标准 Sonar API 端点为 `POST /v1/sonar`。为兼容 OpenAI SDK，也接受以 `POST /chat/completions` 作为别名。OpenAI SDK 会自动将 `client.chat.completions.create()` 路由到 `/chat/completions`，Perplexity 可无缝处理此类请求。除设置基础 URL 外，无需对 SDK 做任何改动。
</Info>

<Tip>
  **推荐使用 [Perplexity SDK](/zh/docs/sdk/overview)**，以获得最佳体验：完整的类型安全、增强功能以及 preset 支持。如果你已完成集成、需要即插即用的兼容方案，则可继续使用 OpenAI SDK。
</Tip>

<div id="quick-start">
  ## 快速开始
</div>

将 OpenAI SDK 与 Perplexity 的 Sonar API 搭配使用：

<Tabs>
  <Tab title="Python">
    ```python theme={null}
    import os
    from openai import OpenAI

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),
        base_url="https://api.perplexity.ai"
    )

    completion = client.chat.completions.create(
        model="sonar-pro",
        messages=[
            {"role": "user", "content": "Explain the underlying physics of magnetic confinement fusion and the role of the Lawson criterion."}
        ]
    )

    print(completion.choices[0].message.content)
    ```
  </Tab>

<div id="api-compatibility">
  ## API 兼容性
</div>

<div id="standard-openai-parameters">
  ### 标准 OpenAI 参数
</div>

以下参数的行为与 OpenAI API 完全一致：

* `model` - 模型名称 (使用 Perplexity 的模型名称，例如 `sonar-pro`)
* `messages` - 聊天消息数组
* `max_tokens` - 响应的最大 token 数
* `stream` - 启用流式响应
* `temperature` - 响应随机性 (0-2)
* `top_p` - 核采样参数
* `response_format` - 响应格式设定

<div id="perplexity-specific-parameters-2">
  ### Perplexity 专属参数
</div>

Sonar API 还支持以下搜索与响应参数：

* `search_domain_filter` - 限定或排除特定域名
* `search_recency_filter` - 按内容时效性过滤 (&quot;day&quot;、&quot;week&quot;、&quot;month&quot;、&quot;year&quot;)
* `return_images` - 在响应中返回图片 URL
* `return_related_questions` - 返回相关问题
* `search_mode` - 模式选择器，可选 &quot;web&quot; (默认) 或 &quot;academic&quot;
* `enable_search_classifier` - 由 AI 判断何时执行搜索
* `disable_search` - 完全关闭联网搜索

<Info>
  完整的参数说明请参阅 [Sonar API 参考](/zh/api-reference/sonar-post)。
</Info>

<div id="endpoint-mapping">
  ## 端点映射
</div>

| 方法                                        | Perplexity 端点          | OpenAI 对应端点                    | 说明                       |
| ----------------------------------------- | ---------------------- | ------------------------------ | ------------------------ |
| `client.chat.completions.create()`        | `POST /v1/sonar`       | `POST /chat/completions`       | 为兼容起见，Perplexity 两个路径都接受 |
| `client.async_.chat.completions.create()` | `POST /v1/async/sonar` | `POST /async/chat/completions` | 为兼容起见，Perplexity 两个路径都接受 |

<Info>
  使用 OpenAI SDK 时，`client.chat.completions.create()` 会将请求发送到 `/chat/completions`。Perplexity 将该路径视为 `/v1/sonar` 的别名，因此除 `base_url` 外，无需对 SDK 做任何配置改动。
</Info>

<div id="response-structure">
  ## 响应结构
</div>

Perplexity 的响应格式与 OpenAI 完全一致，并额外包含以下字段：

<div id="standard-openai-fields">
  ### 标准 OpenAI 字段
</div>

* `choices[0].message.content` - AI 生成的响应内容
* `model` - 所使用的模型名称
* `usage` - token 消耗详情
* `id`、`created`、`object` - 标准响应元数据

<div id="perplexity-specific-fields">
  ### Perplexity 专属字段
</div>

* `search_results` - 网络来源数组，包含 `title`、`url` 和 `date`
* `citations` - 响应中所引用的来源 URL 数组

    ```python theme={null}
    import os
    from openai import OpenAI, APIError, RateLimitError

    client = OpenAI(
        api_key=os.environ.get("PERPLEXITY_API_KEY"),

    )

    try:
        completion = client.chat.completions.create(
            model="sonar-pro",
            messages=[{"role": "user", "content": "Hello"}]
        )
    except RateLimitError:
        print("Rate limit exceeded, please retry later")
    except APIError as e:
        print(f"API error: {e.message}")
    ```

    ```python theme={null}
    stream = client.chat.completions.create(

        stream=True
    )

    for chunk in stream:
        if chunk.choices[0].delta.content:
            print(chunk.choices[0].delta.content, end="", flush=True)
    ```
