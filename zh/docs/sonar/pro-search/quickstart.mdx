<div id="overview">
  ## 概述
</div>

Pro Search 为 [Sonar Pro](/zh/docs/sonar/models/sonar-pro) 增加了自动化工具调用能力，通过智能编排网页搜索、URL 内容抓取等工具，实现多步推理。

<Warning>
  Pro Search 仅在启用流式输出时生效。非流式请求将回退为标准 Sonar Pro 行为。
</Warning>

<div id="basic-usage">
  ## 基本用法
</div>

启用 Pro Search 需要在 API 请求中将 `stream` 设为 `true`，并指定 `"search_type": "pro"`。常规 Sonar Pro 的默认搜索类型为 `"fast"`。

下面的示例演示如何在流式输出下启用 Pro Search：

<CodeGroup>
  ```python Python SDK theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  messages = [
      {
          "role": "user", 
          "content": "Summarize developments in post-quantum cryptography and how lattice-based and hash-based schemes are being standardized by NIST."
      }
  ]

  response = client.chat.completions.create(
      model="sonar-pro",
      messages=messages,
      stream=True,
      web_search_options={
          "search_type": "pro"
      }
  )

  for chunk in response:
      if chunk.choices[0].delta.content:
          print(chunk.choices[0].delta.content, end="")
  ```

  ```typescript Typescript SDK theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.chat.completions.create({
    model: 'sonar-pro',
    messages: [
      {
        role: 'user',
        content: 'Summarize developments in post-quantum cryptography and how lattice-based and hash-based schemes are being standardized by NIST.'
      }
    ],
    stream: true,
    web_search_options: {
      search_type: 'pro'
    }
  });

  for await (const chunk of response) {
    if (chunk.choices[0]?.delta?.content) {
      process.stdout.write((chunk.choices[0]?.delta?.content ?? '') as string);
    }
  }
  ```

  ```bash cURL theme={null}
  curl --request POST \
    --url https://api.perplexity.ai/v1/sonar \
    --header "Authorization: Bearer $PERPLEXITY_API_KEY" \
    --header "Content-Type: application/json" \
    --data '{
      "model": "sonar-pro",
      "messages": [
        {
          "role": "user",
          "content": "Summarize developments in post-quantum cryptography and how lattice-based and hash-based schemes are being standardized by NIST."
        }
      ],
      "stream": true,
      "web_search_options": {
        "search_type": "pro"
      }
    }' --no-buffer
  ```
</CodeGroup>

<div id="enabling-automatic-classification">
  ## 启用自动分类
</div>

可以将 Sonar Pro 配置为根据查询的复杂度自动归类为 Pro Search 或 Fast Search。对于大多数应用场景，推荐采用这种方式。

设置 `search_type: "auto"`，即可让系统根据复杂度智能路由查询。

<CodeGroup>
  ```python Python SDK theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.chat.completions.create(
      model="sonar-pro",
      messages=[
          {
              "role": "user",
              "content": "Compare the energy efficiency (kWh/100mi and MPGe) of the Tesla Model 3, Chevrolet Bolt, and Nissan Leaf using EPA data."
          }
      ],
      stream=True,
      web_search_options={
          "search_type": "auto"  # 自动分类
      }
  )

  for chunk in response:
      if chunk.choices[0].delta.content:
          print(chunk.choices[0].delta.content, end="")
  ```

<div id="how-classification-works">
  #### 分类机制的工作原理
</div>

分类器会分析你的查询，并自动将其路由至：

* **Pro Search**：适用于需要以下能力的复杂查询：
  * 多步推理或分析
  * 跨多个来源的对比分析
  * 深度研究工作流

* **Fast Search**：适用于以下简单直接的查询：
  * 简单的事实查找
  * 直接的信息检索
  * 基础的问答

<div id="billing-with-auto-classification">
  #### 自动分类下的计费
</div>

**计费取决于你的查询触发了哪种搜索类型：**

* 若归类为 **Pro Search**：每 1,000 次请求 $14–$22 (视上下文大小而定)
* 若归类为 **Fast Search**：每 1,000 次请求 $6–$14 (视上下文大小而定，与标准 Sonar Pro 相同)

完整定价详情请参阅<a href="/zh/docs/sonar/pro-search/quickstart#pricing">定价</a>部分。

<Tip>
  大多数应用建议启用自动分类，它能在成本优化与查询性能之间取得平衡：需要时即可获得 Pro Search 能力，又不会为简单查询多付费用。
</Tip>

<div id="manually-specifying-the-search-type">
  ### 手动指定搜索类型
</div>

如有需要，你可以手动指定搜索类型。当你明确知道某个查询需要 Pro Search 能力时，这种做法尤为有用。

* **`"search_type": "pro"`**：当你确定需要多步工具调用时，为复杂查询手动指定 Pro Search
* **`"search_type": "fast"`**：为简单查询手动指定 Fast Search，以优化速度和成本 (省略 `search_type` 时也默认使用该类型)
