<div id="overview">
  ## 概述
</div>

Perplexity 的 Embeddings API 可生成高质量的文本嵌入，适用于语义搜索与检索场景。你可以根据需要选择：处理独立文本时使用**标准嵌入**，处理共享上下文的文档分块时使用**上下文化嵌入**。

<Info>
  建议使用我们的[官方 SDK](/zh/docs/sdk/overview)，以更便捷、类型安全的方式调用 Embeddings API。
</Info>

<Card title="定价" icon="receipt" href="/zh/docs/getting-started/pricing" horizontal="True" cta="查看定价">
  所有 API 均按用量付费，无需订阅。
</Card>

<div id="available-models">
  ## 可用模型
</div>

|              模型              |  维度  | 上下文 | MRL |      量化     | 价格 ($/100 万 token)  |
| :--------------------------: | :--: | :-: | :-: | :---------: | :-----------------: |
|     `pplx-embed-v1-0.6b`     | 1024 | 32K |  是  | INT8/BINARY |        $0.004       |
|      `pplx-embed-v1-4b`      | 2560 | 32K |  是  | INT8/BINARY |        $0.03        |
| `pplx-embed-context-v1-0.6b` | 1024 | 32K |  是  | INT8/BINARY |        $0.008       |
|  `pplx-embed-context-v1-4b`  | 2560 | 32K |  是  | INT8/BINARY |        $0.05        |

所有模型均采用平均池化，且无需指令前缀——你可以直接嵌入文本，无需做提示词工程。

<Warning>
  Perplexity 的嵌入向量**未经归一化**。比较 `base64_int8` 嵌入时请始终使用**余弦相似度** (而非内积或 L2 距离) ；比较 `base64_binary` 嵌入时请使用**汉明距离**。详情及归一化辅助函数请参见[最佳实践](/zh/docs/embeddings/best-practices)。
</Warning>

<Tip>
  **该如何选择：**

  * **标准嵌入** (`pplx-embed-v1-*`) ——彼此独立的文本、搜索查询、单个句子
  * **上下文化嵌入** (`pplx-embed-context-v1-*`) ——可从共享上下文中获益的文档分块 (例如同一篇文章中的各个段落)
</Tip>
