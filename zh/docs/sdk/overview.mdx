<div id="overview">
  ## 概述
</div>

官方 Perplexity SDK 让 Python 3.8+ 和 Node.js 应用能够便捷地访问 Perplexity API。两个 SDK 均包含所有请求参数和响应字段的类型定义，并同时提供同步和异步客户端。

可访问四类 API：**Agent API**，用于调用第三方模型并搭配网页搜索工具和 preset；**Search**，用于获取经过排序的网页搜索结果；**Sonar**，用于生成基于网页信息的 AI 回答；**Embeddings**，用于生成文本嵌入。

<div id="installation">
  ## 安装
</div>

安装你所用语言的 SDK：

<CodeGroup>
  ```bash Python theme={null}
  pip install perplexityai
  ```

  ```bash TypeScript theme={null}
  npm install @perplexity-ai/perplexity_ai
  ```
</CodeGroup>

<div id="authentication">
  ## 身份验证
</div>

<Card title="获取你的 Perplexity API key" icon="key" arrow="True" horizontal="True" iconType="solid" cta="点击此处" href="https://console.perplexity.ai/project/keys">
  在 API Console 的 **API Keys** 页面生成一个新密钥。
</Card>

生成密钥后，在终端中将其设置为环境变量：

<Tabs>
  <Tab title="Windows">
    ```bash theme={null}
    setx PERPLEXITY_API_KEY "your_api_key_here"
    ```
  </Tab>

  <Tab title="MacOS/Linux">
    ```bash theme={null}
    export PERPLEXITY_API_KEY="your_api_key_here"
    ```
  </Tab>
</Tabs>

<div id="using-environment-variables">
  ### 使用环境变量
</div>

你可以直接使用环境变量：

<CodeGroup>
  ```python Python theme={null}
  import os
  from perplexity import Perplexity

  client = Perplexity() # 自动使用 PERPLEXITY_API_KEY
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity({
    apiKey: process.env['PERPLEXITY_API_KEY'], // 这是默认值，可以省略
  });
  ```
</CodeGroup>

也可以使用 [python-dotenv](https://pypi.org/project/python-dotenv/) (Python) 或 [dotenv](https://www.npmjs.com/package/dotenv) (Node.js) 从 `.env` 文件加载环境变量：

<CodeGroup>
  ```python Python theme={null}
  import os
  from dotenv import load_dotenv
  from perplexity import Perplexity

  load_dotenv()

  client = Perplexity() # 使用 .env 文件中的 PERPLEXITY_API_KEY
  ```

  ```typescript TypeScript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';
  import dotenv from 'dotenv';

  dotenv.config();

  const client = new Perplexity(); // 使用 .env 文件中的 PERPLEXITY_API_KEY
  ```
</CodeGroup>
