[API 门户](https://console.perplexity.ai)提供四种登录方式。四种方式创建或复用的都是同一个 Perplexity 账户——无需在注册时选定一种并一直沿用。

<Frame>
  <img src="https://mintcdn.com/perplexity/Q1hEB7DMIN7YNoRc/docs/assets/images/api_portal/console_login.png?fit=max&auto=format&n=Q1hEB7DMIN7YNoRc&q=85&s=32311b5d5e12f9991dc20f9c9c8c65fd" alt="API 平台登录页面，包含通过 Google 继续、通过 Apple 继续、单点登录 (SSO) 和通过邮箱继续等选项" />
</Frame>

<div id="choosing-a-sign-in-option">
  ## 选择登录方式
</div>

| 方式                   | 适用对象                                     |
| -------------------- | ---------------------------------------- |
| **使用 Google 账号登录**   | 使用 Google Workspace 或个人 Google 账号的个人与团队。 |
| **使用 Apple 账号登录**    | 偏好“通过 Apple 登录” (含隐藏邮件地址功能) 的个人。         |
| **单点登录 (SSO)&#x20;**&#x20;| 所属域名已配置 SSO 的 Perplexity 组织成员。           |
| **使用邮箱登录**           | 任何人——系统会向你的收件箱发送魔法链接和一次性验证码。           |

<Info>
  登录会创建 Perplexity 账户，但不会自动创建 API 项目。首次登录后，设置向导会引导你创建或加入一个项目，然后才能生成密钥。参见[项目与计费](/zh/docs/getting-started/projects)。
</Info>

***

<div id="continue-with-google">
  ## 使用 Google 继续
</div>

使用任意 Google 或 Google Workspace 账号通过 Google 登录。

<Steps>
  <Step title="点击“使用 Google 继续”">
    在登录页面点击 **Continue with Google**，然后选择要使用的 Google 账号。
  </Step>

  <Step title="确认登录">
    Google 会要求你确认此次登录，并将你的姓名、邮箱和头像共享给 Perplexity。确认后即可继续。
  </Step>

  <Step title="进入 API 门户">
    确认后你会以登录状态返回 API 门户。如果这是你首次访问，设置向导会引导你创建一个项目。
  </Step>
</Steps>

<Tip>
  如果你已有使用相同邮箱地址的 Perplexity 账户，通过 Google 登录会将 Google 关联到该已有账号——项目、密钥和历史记录都会保留。
</Tip>

***

<div id="continue-with-apple">
  ## 通过 Apple 继续
</div>

使用“通过 Apple 登录”，包括“隐藏我的邮件地址”生成的中转地址。

<Steps>
  <Step title="点击“通过 Apple 继续”">
    在登录页面点击 **Continue with Apple**，然后通过面容 ID、触控 ID 或 Apple ID 密码完成身份验证。
  </Step>

  <Step title="选择邮件地址偏好">
    Apple 允许你共享真实邮件地址，或使用 **Hide My Email** 生成一个私密中转地址。Perplexity 将使用 Apple 返回的地址。
  </Step>

  <Step title="进入 API 门户">
    完成后你会以登录状态返回 API 门户。如果这是你首次访问，设置向导会引导你创建一个项目。
  </Step>
</Steps>

<Warning>
  如果你已使用真实邮件地址注册了 Perplexity 账户，之后又选择 **Hide My Email**，Apple 会返回另一个地址，并因此创建一个独立账户。请选定一种邮件地址偏好并始终保持一致；如需合并账户，请联系 [api@perplexity.ai](mailto:api@perplexity.ai)。
</Warning>

<div id="single-sign-on-sso">
  ## 单点登录 (SSO)
</div>

SSO 让贵组织可以通过自有身份提供商 (Okta、Azure AD、Google Workspace SAML 以及其他 SAML 或 OIDC IdP) 登录。该功能适用于已在已验证域名上配置 SSO 的组织。

<Note>
  SSO 仅向**拥有有效组织订阅 (付费或符合条件的试用) 的 Perplexity 组织**的管理员开放。个人 Pro 或 Max 套餐不支持 SSO，仅 API 计费的情况下也无法启用——贵组织必须先在 Perplexity 主应用中作为 Perplexity 组织存在。如果您的团队尚未创建 Perplexity 组织，请[联系销售团队](https://www.perplexity.ai/enterprise/contact-sales)。
</Note>

<div id="signing-in-with-sso">
  ### 使用 SSO 登录
</div>

<Steps>
  <Step title="点击单点登录 (SSO)">
    在登录页面点击 **Single sign-on (SSO)**，表单会切换为工作邮箱输入界面。

    <Frame>
      <img src="https://mintcdn.com/perplexity/Q1hEB7DMIN7YNoRc/docs/assets/images/api_portal/console_login_sso.png?fit=max&auto=format&n=Q1hEB7DMIN7YNoRc&q=85&s=b9a9634a1c254fe1546e1be9ef5d9be1" alt="包含工作邮箱字段、Continue with SSO 按钮以及 Back to all options 链接的单点登录视图" />
    </Frame>
  </Step>

  <Step title="输入你的工作邮箱">
    输入你所在组织已验证域名下的邮箱地址，然后点击 **Continue with SSO**。如需返回其他登录方式，请点击 **Back to all options**。
  </Step>

  <Step title="通过你的 IdP 完成身份验证">
    系统会将你重定向到所在组织的身份提供商。在那里完成登录 (包括任何 MFA 验证) ，之后你会回到 API 门户。
  </Step>
</Steps>

<Note>
  如果出现 **“SSO is not available for this email address”**，说明尚未为你的域名配置 SSO。请让组织管理员完成下文的设置步骤，或改用其他登录方式。
</Note>

<div id="configuring-sso-for-your-organization">
  ### 为你的组织配置 SSO
</div>

SSO 只需在组织的 Perplexity 组织设置中配置一次 (而非在 API 门户中配置) ，即可对 Perplexity 的所有登录场景生效，包括 API 门户。

如需了解在 Perplexity Enterprise 上设置 SSO 的更多帮助，请访问 [Perplexity 帮助中心的单点登录合集](https://www.perplexity.ai/help-center/en/collections/16665790-single-sign-on)。

<Steps>
  <Step title="确认资格">
    你的组织必须在 Perplexity 主应用中拥有**有效的组织订阅**，有效期内的试用同样符合条件。如果尚未设置账单，设置页面将显示**“Complete payment to begin setup”**，而不是启用按钮。SSO 本身没有最低席位数要求。
  </Step>

  <Step title="打开身份设置">
    以组织管理员身份，在 Perplexity 主应用中前往 [**Settings → Identity**](https://www.perplexity.ai/account/org/identity)。你需要拥有该组织的 **Admin** 角色。
  </Step>

  <Step title="验证域名">
    添加并验证至少一个团队用于收发邮件的域名 (例如 `yourcompany.com`) 。验证通过 DNS 记录完成。
  </Step>

  <Step title="连接你的身份提供商">
    点击 **Begin setup**，按照自助门户的指引连接你的 IdP。该门户支持 SAML 2.0 和 OIDC 连接，并会针对你所使用的具体 IdP 提供分步指导。如需更多帮助，请访问 [Perplexity 帮助中心的单点登录合集](https://www.perplexity.ai/help-center/en/collections/16665790-single-sign-on)。
  </Step>

  <Step title="为你的组织启用 API 访问权限">
    请确保组织已启用 **API 访问权限**，这样 SSO 用户登录后才能进入 API 门户。如果成员能够通过 SSO 登录却无法打开 Portal，请联系组织管理员或[销售团队](https://www.perplexity.ai/enterprise/contact-sales)，为该组织开启 API 访问权限。
  </Step>

  <Step title="（可选）强制使用 SSO">
    IdP 生效后，你可以在任意已验证的域名上启用**强制 SSO**。启用后，来自该域名的所有登录尝试——包括通过 Google、Apple 和电子邮件的登录——都将经由你的 IdP 进行。
  </Step>
</Steps>

<Tip>
  在 SSO 设置上需要帮助，或希望我们陪你一起完成配置？请联系你的 Perplexity 客户团队。
</Tip>

<div id="continue-with-email">
  ## 使用邮箱继续
</div>

邮箱登录无需密码，不必设置或记住任何密码。

<Steps>
  <Step title="输入你的邮箱">
    在 **Email** 字段中输入你的邮箱，然后点击 **Continue with email**。
  </Step>

  <Step title="查收邮件">
    你会收到一封邮件，其中同时包含**魔法链接**和**临时登录码**。任选其一即可——在同一设备上点击链接会立即完成登录，而登录码可在任意设备上使用。
  </Step>

  <Step title="进入 API 门户">
    验证通过后即完成登录。如果这是你首次访问，设置向导会引导你创建一个项目。
  </Step>
</Steps>

<Note>
  如果你的邮箱地址所属域名**强制 SSO**，邮箱登录流程会将你转到组织的身份提供商，而不会发送登录码。
</Note>

<div id="switching-between-sign-in-methods">
  ## 在不同登录方式之间切换
</div>

同一个账户可以在不同时候使用不同的登录方式。如果你最初使用邮箱注册，之后又用同一邮箱地址点击 **Continue with Google**，Google 就会关联到你已有的 Perplexity 账户——项目、密钥和账单信息都会原样保留。使用 Apple 登录或切换回邮箱登录也是如此。

<Warning>
  账户关联依据的是你的**邮箱地址**。使用不同的邮箱登录——例如用个人 Google 邮箱而非工作邮箱——会创建一个独立账户，它有自己的项目和密钥。如果你不小心创建了两个账户，请联系 [api@perplexity.ai](mailto:api@perplexity.ai)。
</Warning>
