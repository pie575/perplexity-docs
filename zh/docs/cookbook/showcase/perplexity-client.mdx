**Perplexity Client** 是一款基于 Electron 的桌面应用，为与 Perplexity 的 Sonar API 交互提供了精致的界面。它开放了 max tokens 等高级 API 参数，非常适合既想对 AI 交互进行精细控制、又想享受 macOS 风格美观界面的开发者。

<div id="features">
  ## 功能特性
</div>

* **多种 Sonar 模型**，支持 Sonar、Sonar Pro 和 Sonar Reasoning Pro
* **自定义 Spaces**，可针对不同使用场景保存/加载配置
* **API 参数控制**，包括调整 max tokens
* **API 调试模式**，显示完整的请求/响应负载，便于排查问题
* **Token 用量追踪**，便于监控 API 消耗与成本
* **Focus 模式**，适用于编程、写作、研究等专项任务

<div id="prerequisites">
  ## 前置条件
</div>

* Node.js v16 或更高版本
* npm 或 yarn
* Perplexity API key

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/straight-heart/Perplexity-client-.git
cd Perplexity-client-

# 安装依赖
npm install

npm run dev
```

<div id="build">
  ## 构建
</div>

为你的平台构建应用：

```bash theme={null}
npm run build:win    # Windows
npm run build:mac    # macOS
npm run build:linux  # Linux
```

<div id="configuration">
  ## 配置
</div>

API key 直接在应用内管理：

1. 启动应用并打开设置 (齿轮图标) 
2. 在 **API Keys** 部分点击 **Add Key**
3. 输入你的 Perplexity API key
4. 该密钥会被安全存储，并在会话之间持久保留

如需自定义系统提示词，可使用 **Spaces** 功能保存不同的指令集并在其间切换。

<div id="usage">
  ## 使用方法
</div>

1. **启动**：运行 `npm run dev` 或直接使用已构建的应用
2. **添加 API key**：打开设置，填入你的 Perplexity API key
3. **选择模型**：通过下拉菜单在各个 Sonar 版本之间切换
4. **创建 Spaces**：为不同任务配置自定义系统提示词
5. **对话**：开始聊天，实时获取流式响应
6. **调试**：启用 API 调试，查看完整的请求/响应详情
7. **跟踪用量**：在设置面板中查看 token 消耗情况
