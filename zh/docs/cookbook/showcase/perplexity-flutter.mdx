<div id="perplexity-dart-flutter-sdks">
  # Perplexity Dart 与 Flutter SDK
</div>

**Perplexity Dart 与 Flutter SDK** 提供了一套完整的工具，帮助你将 Perplexity 的 AI 能力集成到 Dart 和 Flutter 应用中。这些软件包专为 Flutter 社区打造，包含一个轻量级核心 API 客户端，以及采用 BLoC 状态管理、开箱即用的 Flutter 组件。

<div id="features">
  ## 功能特性
</div>

* 类型安全的 API 客户端，数据模型完全类型化，具备编译期安全保障
* 支持流式与非流式聊天补全，可实时处理响应
* 支持全部 Perplexity 模型 (Sonar、Sonar Pro、Deep Research、Reasoning 系列变体) 
* 多图像处理，支持 base64、data URI 和 HTTPS URL
* 开箱即用的 Flutter 组件，集成 BLoC 状态管理
* 高级配置选项 (搜索过滤器、域名限制) 
* 跨平台支持 iOS、Android、Web 和桌面端
* 面向未来的设计，支持自定义模型字符串，可适配 Perplexity 新发布的模型

<div id="prerequisites">
  ## 前置条件
</div>

* Dart SDK 2.17.0 或更高版本
* Flutter SDK 3.0.0 或更高版本 (用于 Flutter 专属功能) 
* 在 Perplexity API Console 中获取的 Perplexity API key
* 了解 Flutter BLoC 模式基础知识，以便进行组件集成

<div id="installation">
  ## 安装
</div>

<div id="for-dart-projects-core-api-only">

<div id="usage">
  ## 使用方式
</div>

<div id="core-api-integration">
  ### 核心 API 集成
</div>

* 类型安全的客户端，支持所有 Perplexity 模型 (Sonar、Sonar Pro、Deep Research、Reasoning) 
* 支持流式与非流式聊天补全
* 多模态处理：借助灵活的 MessagePart 系统处理文本 + 图像

<div id="flutter-widget-layer">
  ### Flutter 组件 层
</div>

* `ChatWrapperWidget`：用于 BLoC 状态管理
* `PerplexityChatView`：用于实时消息展示
* `PerplexityChatInput`：用于处理用户交互

<div id="code-explanation">
  ## 代码说明
</div>

* 核心层：纯 Dart API 客户端 (`perplexity_dart`) ，用于跨平台集成 Perplexity API
* UI 层：Flutter 组件 (`perplexity_flutter`) ，采用 BLoC 状态管理，助力快速开发
* 类型安全：完整类型化的模型与响应，可避免运行时错误并提供智能提示
* 多模态：灵活的 MessagePart 系统，可在单次请求中同时传入文本与图像
* 流式传输：内置实时聊天补全支持，并妥善处理数据块
* 架构：两层设计既可轻量调用 API，也可完整集成 Flutter 组件
