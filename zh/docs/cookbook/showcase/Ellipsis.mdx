**Ellipsis** 是新一代播客生成智能体，只需一键，即可围绕任意主题生成媲美真人的高质量音频内容。无论是突发新闻、深度技术解析、影评，还是赛后战术分析，Ellipsis 都能打造出颇具智慧的播客节目，听起来宛如资深主持人在专业录音棚中精心制作。

<div id="features">
  ## 功能特性
</div>

* **智能多人对话**：多个音色与人物性格各异的角色
* **话题覆盖广泛**：从 LLM 架构到月食无所不包
* **自定义评估引擎**：确保事实准确、合法合规与对话质量
* **播客全自动生成**：输出接近真人、可直接发布的播客音频
* **实时流式更新**：通过 Server-Sent Events (SSE) 实现
* **Podbean 集成**：支持直接发布播客
* **热门话题检测**：基于 Perplexity API

<div id="prerequisites">
  ## 前置条件
</div>

* Node.js v16+ 和 npm/yarn
* Python 3.10+ 和 pip
* 已运行的 Redis 服务器 (默认端口 6380) 
* Perplexity API key、Podbean 凭据

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/dineshkannan010/Ellipsis.git
cd Ellipsis

# 后端配置
cd backend
python -m venv venv
source venv/bin/activate    # macOS/Linux
pip install -r requirements.txt

# 安装原生依赖包
pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
pip install git+https://github.com/freddyaboulton/orpheus-cpp.git
pip install huggingface_hub[hf_xet] hf_xet

# 前端配置
cd ../frontend
npm install
```

<div id="configuration">
  ## 配置
</div>

创建 `backend/.env`：

```ini theme={null}
REDIS_URL=redis://your-redis-host:6379
PERPLEXITY_API_KEY=your_key_here
PODBEAN_CLIENT_ID=...
PODBEAN_CLIENT_SECRET=...
```

创建 `frontend/.env`：

```ini theme={null}
REACT_APP_API_URL=http://your-backend-host:5000
```

<div id="usage">
  ## 使用方法
</div>

1. **启动 Redis 服务器**：
   ```bash theme={null}
   redis-server --port 6380
   ```

2. **启动后端**：
   ```bash theme={null}
   cd backend
   python app.py
   ```

3. **启动前端**：
   ```bash theme={null}
   cd frontend
   npm run dev
   ```

4. **可选：Podbean 集成**：
   ```bash theme={null}
   cd backend/integrations/podbean_mcp
   pip install -e .
   python server.py
   python client.py server.py
   ```

5. **生成内容**：在首页文本框中输入主题并按回车。切换到 `ContentGenerationView` 即可实时查看脚本与音频的生成进度。

<div id="code-explanation">
  ## 代码说明
</div>

* **后端**：Python Flask，结合 Redis 发布/订阅、llama.cpp 和 Orpheus TTS 实现音频生成
* **前端**：React 搭配 Vite、Tailwind CSS 和 Server-Sent Events，实现实时更新
* **AI 集成**：使用 Perplexity API 进行内容生成和热门话题发现
* **音频处理**：多说话人 TTS，每个声音都有鲜明的个性
* **内容评估**：内置事实准确性与法律合规性检查流水线
* **播客发布**：通过 MCP 服务器直接对接 Podbean
