**PerplexiGrid** 可将自然语言转化为内容丰富的交互式仪表盘。接入你的数据，与实时网络数据相结合，提出问题，剩下的交给 Sonar API！它还支持拖放式布局、AI 组件生成，以及由 ECharts 驱动的可视化。

<div id="features">
  ## 功能
</div>

* **自然语言生成仪表板**：将自然语言提示词转换为功能完备的分析仪表板，支持 25 余种组件类型
* **实时数据集成**：将你自己的数据源与实时网络数据融合，获得全面洞察
* **交互式网格布局**：通过拖放界面自定义仪表板布局与样式
* **AI 驱动的优化**：通过对话式更新优化或新增组件
* **导出与分享**：生成 PDF 导出文件、高分辨率图片以及可分享的仪表板链接

<div id="how-it-uses-sonar">
  ## 如何使用 Sonar
</div>

PerplexiGrid 通过四种专用模式调用 Sonar API：

* **完整仪表板生成 (f1)&#x20;**：借助 Sonar Pro 的高级能力，生成包含多个组件的完整仪表板
* **轻量模式 (l1)&#x20;**：为嵌入式系统和实时应用快速生成可视化内容
* **仪表板更新 (r1)&#x20;**：在保留上下文的前提下，通过自然语言实现动态修改
* **组件精调 (r2)&#x20;**：对单个组件的更新提供精确控制

系统采用结构化 JSON schema 响应，确保输出格式一致且兼容 ECharts，可直接渲染为交互式可视化图表。

<div id="code-explanation">
  ## 代码说明
</div>

用户发送的消息会被转换成提示词，传递给封装了 Perplexity Sonar API 的 Supabase Edge Function。
根据模式 (`f1`、`l1`、`r1` 或 `r2`) 的不同，该函数会生成面向仪表板的完整结构化输出、轻量级可视化内容，或有针对性的局部更新。
生成的布局会被解析为结构化的组件定义，并传入我们的组件创建引擎。

点此查看我们的[主 sonar-api 服务。](https://github.com/PetarRan/perplexigrid/blob/main/server/supabase/functions/_shared/perplexityService.ts)

<div id="prompt-modes">
  ## 提示词模式
</div>

| 模式   | 说明        | 使用场景                       | 备注                      |
| ---- | --------- | -------------------------- | ----------------------- |
| `f1` | 首次生成完整仪表板 | 用户从空白画布开始，输入初始提示词          | 生成包含多个组件的完整仪表板布局        |
| `l1` | 轻量级仪表板生成  | 用于以最少 token 快速获取洞察或预览      | 更快、成本更低，但返回的组件更少，指令深度更浅 |
| `r1` | 重新生成整个仪表板 | 用户希望用新提示词替换所有现有组件          | 在保持布局不变的前提下重建整个仪表板      |
| `r2` | 定向更新单个组件  | 用户希望修改某个特定组件 (例如“把它改成饼图”)  | 仅根据新指令修改所选组件            |

<div id="tech-stack">
  ## 技术栈
</div>

* **前端**：React + Vite (Typescript) 、ECharts、react-grid-layout
* **后端**：Supabase Edge Functions (基于 Deno 的 Typescript) 
* **AI 引擎**：Perplexity Sonar Pro
* **基础设施**：Supabase (PostgreSQL、RLS、Auth) ，部署于 Vercel
