**CycleSyncAI** 是一款 iOS 应用，旨在根据女性所处的**月经周期阶段**，提供个性化的**饮食与运动建议**。

该应用整合 Apple **HealthKit** 中的月经数据以及可选填的用户档案信息 (年龄、体重、身高、健康状况、饮食禁忌、目标和偏好) ，动态生成契合周期阶段的建议，助力全方位健康管理。

与一成不变的健康工具不同，**CycleSyncAI** 借助 **Perplexity 的 Sonar Pro API**，生成**融入专业知识**的大模型指导建议——包括每日采购清单和激励性反馈——并针对用户的周期与生活方式量身定制。

<div id="problem-solution">
  ## 问题与解决方案
</div>

> **为什么重要：**
> 大多数应用忽视了女性在生理周期中因激素变化而产生的健身与营养需求差异，只能给出千篇一律的建议。

**CycleSyncAI** 将 Apple HealthKit 数据与 Sonar Pro 的大语言模型结合起来，填补了这一空白，生成**自适应、贴合周期的建议**，帮助用户获得更好的健康效果。

<div id="features">
  ## 功能
</div>

* 针对各月经周期阶段的**个性化饮食与运动建议**
* 与 Apple HealthKit 同步，实时追踪生理周期
* 支持填写用户档案以实现深度个性化 (年龄、目标、忌口等) 
* **自动生成每日采购清单**
* 流畅现代的界面，配有渐变与细腻动效
* 契合用户偏好的 **AI 激励反馈**
* 本地数据存储与隐私化处理

<div id="setup-instructions">
  ## 设置说明
</div>

1. 克隆仓库
2. 使用 **Xcode** 打开
3. 确保设备上已启用 Apple HealthKit
4. 填入你的 **Sonar Pro API key**
5. 在真机上运行应用 (推荐)

<div id="sonar-api-usage">
  ## Sonar API 用法
</div>

应用会向 **Sonar Pro API** 发送结构化提示词，其中包括：

* 月经周期阶段 (来自 HealthKit) 
* 用户档案信息 (年龄、体重、目标等) 
* 饮食偏好与忌口

随后返回：

* **个性化饮食计划**
* **定制运动计划**
* **每日采购清单**
* **激励性反馈**

这些内容经过解析后，通过 WebView 以带样式的 HTML 形式在应用内渲染。
