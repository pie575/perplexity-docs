**PosterLens** 是一款 iOS 应用，借助 OCR 与 AI 将静态的科研海报转化为可交互、可探索的洞察。它为 Perplexity Hackathon 2025 打造，让研究人员、医学科学联络官 (MSL) 和医学撰稿人可以扫描海报，用自然语言进行交互式探索，即时提炼要点并呈现相关研究。

![PosterLens 截图](https://cdn.prod.website-files.com/66d49e8555a289120a81ec3e/68930ad938e072c05d1be0b9_PosterLens.png)

<div id="features">
  ## 功能
</div>

* **科研海报扫描**：借助设备摄像头与 Apple Vision OCR 识别
* **自然语言问答**：就海报内容提供 AI 驱动的回答
* **语义搜索集成**：通过 Perplexity Sonar Pro 检索相关研究
* **引用校验**：借助 PubMed E-utilities 确保学术准确性
* **自动生成研究问题**及未来研究方向
* **端侧处理**：兼顾隐私与性能
* **交互式研究体验**：将静态内容转化为动态洞察

<div id="prerequisites">
  ## 前置条件
</div>

* 配备摄像头的 iOS 17+ 设备
* 用于开发的 Xcode 15+
* 用于 App Store 分发的 Apple Developer 账号
* Perplexity API key (Sonar Pro) 
* OpenAI API key (GPT-3.5) 
* PubMed E-utilities 访问权限

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/nickjlamb/PosterLens.git
cd PosterLens

# 在 Xcode 中打开
open PosterLens.xcodeproj
```

<div id="configuration">
  ## 配置
</div>

将你的 API key 添加到项目配置中：

```swift theme={null}
// API 配置
PERPLEXITY_API_KEY=your_sonar_pro_api_key
OPENAI_API_KEY=your_gpt_api_key
PUBMED_API_KEY=your_pubmed_api_key
```

<div id="usage">
  ## 使用方法
</div>

1. **从 App Store 安装**：在 iOS App Store 下载 PosterLens
2. **扫描海报**：将摄像头对准科研海报
3. **OCR 处理**：Apple Vision 自动提取文本内容
4. **提问**：用自然语言查询海报内容
5. **探索相关研究**：通过 Sonar Pro 发现语义相关的研究
6. **验证引用**：借助 PubMed 集成核查学术参考文献

<div id="code-explanation">
  ## 代码说明
</div>

* **前端**：使用 SwiftUI 构建的原生 iOS 应用，提供现代化 UI/UX
* **OCR 处理**：借助 Apple Vision 框架从图像中提取文本
* **AI 集成**：通过 Perplexity Sonar Pro API 实现语义搜索与上下文理解
* **自然语言**：使用 GPT-3.5 进行问答与内容解读
* **学术验证**：通过 PubMed E-utilities 核验引用文献
* **端侧处理**：OCR 与相关处理均在本地完成，兼顾隐私与性能
* **研究增强**：自动生成研究问题与未来研究方向
