**Briefo** 提供个性化的 AI 生成新闻流和公司深度解读。读者可以追踪突发新闻、随时发起财务分析，并与好友交流洞见，这一切都集成在由 Perplexity Sonar API 驱动的移动端体验中。

<div id="features">
  ## 功能
</div>

* 覆盖 17 个类别的个性化新闻流，附带 AI 摘要与来源链接
* 支持私密和公开话题，便于文章讨论与分享
* 自选关注列表，提供实时行情快照及可选的 AI 分析
* 深度研究报告，可围绕管理层、竞争对手、估值等 12 项可选维度生成
* 通用聊天助手，能记住每位用户关注的话题

<div id="prerequisites">
  ## 前置条件
</div>

* Node 18 LTS 或更高版本
* npm、Yarn 或 pnpm
* Expo CLI (`npm i -g expo-cli`) 
* Supabase CLI 1.0 或更高版本，用于本地模拟和 Edge Function 部署

<div id="installation">
  ## 安装
</div>

```bash theme={null}
git clone https://github.com/adamblackman/briefo-public.git
cd briefo-public
npm install
```

<div id="environment-variables">
  ### 环境变量
</div>

```ini theme={null}
# .env              (项目根目录)
MY_SUPABASE_URL=https://<project>.supabase.co
MY_SUPABASE_SERVICE_ROLE_KEY=...
PERPLEXITY_API_KEY=...
LINKPREVIEW_API_KEY=...
ALPACA_API_KEY=...
ALPACA_SECRET_KEY=...

# .env.local        (位于 supabase/ 目录下)
# 复制或覆盖 Edge Functions 所需的任何密钥
```

<div id="usage">
  ## 使用方式
</div>

启动 Expo 开发服务器：

```bash theme={null}
npx expo start
```

准备就绪后，部署 Edge Functions：

```bash theme={null}
supabase functions deploy perplexity-news perplexity-chat perplexity-research portfolio-tab-data
```

<div id="code-explanation">
  ## 代码说明
</div>

* 前端：React Native 搭配 Expo Router (Typescript) ，支持 iOS、Android 和 Web
* 后端：Supabase (PostgreSQL、行级安全、Realtime) ，负责数据与身份验证
* Edge Functions：基于 Deno 的 Typescript，调用 Perplexity、Alpaca、Alpha Vantage 和 LinkPreview API
* Hooks：可复用的 React Query 风格数据 hooks 位于 lib/ 和 hooks/ 目录
* 测试与代码检查：由 ESLint、Prettier 和 Expo Lint 保障代码质量
