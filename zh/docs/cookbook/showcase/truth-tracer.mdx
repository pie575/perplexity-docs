**TruthTracer** 是一个功能全面的虚假信息检测平台，借助 Perplexity 的 Sonar API 实现多层次的论断分析。该平台将事实核查、信任链追溯与苏格拉底式推理结合起来，输出准确、有据可依的验证结果，并附带置信度分数和详细的来源信息。

<div id="features">
  ## 功能特性
</div>

* **多方法分析**：融合事实核查、信任链分析与苏格拉底式推理
* **AI 驱动的验证**：使用 Perplexity 的 Sonar、Sonar Deep Research 和 Sonar Reasoning Pro 模型
* **实时处理**：并行执行多种分析方法
* **基于证据的结果**：提供来源、置信度分数与详细推理过程
* **整洁架构**：NestJS 后端搭配 React 前端
* **可用于生产环境**：支持 Docker 部署、全面测试与完整 API 文档
* **可配置的置信度评分**:权重与阈值均可自定义

<div id="prerequisites">
  ## 前置条件
</div>

* Node.js 18+ 和 npm
* Perplexity API key (需具备 Sonar 模型访问权限) 
* Docker (部署时可选) 
* Git，用于克隆仓库

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆后端仓库
git clone https://github.com/anthony-okoye/truth-tracer-backend.git
cd truth-tracer-backend

# 安装依赖
npm install

# 克隆前端仓库
git clone https://github.com/anthony-okoye/truth-tracer-front.git
cd truth-tracer-front

# 安装前端依赖
npm install
```

<div id="configuration">
  ## 配置
</div>

在后端目录中创建 `.env` 文件：

```ini theme={null}
# 必填
SONAR_API_KEY=your_perplexity_api_key
SONAR_API_URL=https://api.perplexity.ai

# 可选配置
SONAR_TIMEOUT=30000
SONAR_MAX_RETRIES=3
CONFIDENCE_WEIGHT_FACT_CHECK=0.35
CONFIDENCE_WEIGHT_TRUST_CHAIN=0.25
CONFIDENCE_WEIGHT_SOCRATIC=0.20
```

<div id="usage">
  ## 使用方法
</div>

1. **启动后端**：

```bash theme={null}
   cd truth-tracer-backend
   npm run start:dev
```

2. **启动前端**：

```bash theme={null}
   cd truth-tracer-front
   npm start
```

3. **访问应用**：在浏览器中打开 [http://localhost:3000](http://localhost:3000)

4. **分析论断**：
   * 在文本框中输入一条论断
   * 点击 &quot;Analyze Claim&quot;，运行事实核查、信任链分析和苏格拉底式推理
   * 查看结果，其中包含置信度分数、来源和详细说明

<div id="code-explanation">
  ## 代码说明
</div>

* **后端**：采用整洁架构的 NestJS 应用，遵循 TypeScript 最佳实践
* **AI 集成**：基于 Perplexity Sonar API，使用三个专用模型 —— Sonar 负责事实核查、Sonar Deep Research 负责信任链分析、Sonar Reasoning Pro 负责逻辑评估
* **并行处理**：三种分析方法同时执行，高效完成论断验证
* **响应清洗**：自定义 JSON 解析与校验，可处理各种 API 响应格式
* **置信度评分**：加权评分体系，综合三种分析方法的结果
* **前端**：React 应用，提供直观的论断提交界面与详尽的结果可视化
* **测试**：完善的测试套件，涵盖单元测试、端到端测试以及论断分析测试

<div id="how-the-sonar-api-is-used">
  ## Sonar API 的使用方式
</div>

TruthTracer 通过三种不同的分析方法调用 Perplexity 的 Sonar API：

```typescript theme={null}
// 并行调用多个 Sonar 模型
const [factCheckResult, trustChainResult, socraticResult] = await Promise.all([
  sonarClient.chat.completions.create({
    model: "sonar",
    messages: [{ role: "user", content: factCheckPrompt }],
    max_tokens: 500
  }),
  sonarClient.chat.completions.create({
    model: "sonar-deep-research", 
    messages: [{ role: "user", content: trustChainPrompt }],
    max_tokens: 2500
  }),
  sonarClient.chat.completions.create({
    model: "sonar-reasoning-pro",
    messages: [{ role: "user", content: socraticPrompt }],
    max_tokens: 4000
  })
]);
```
