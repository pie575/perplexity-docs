<div id="how-it-works">
  ## ⚙️ 工作原理
</div>

<div id="the-flameguard-ai-process">
  ### FlameGuard AI™ 流程
</div>

1. **📸 上传**：用户上传自家房屋的照片
2. **👁️ AI 视觉分析**：OpenAI Vision API 识别具体隐患 (例如易燃屋顶、附近的干枯灌木) 
3. **🔍 深度研究**：针对每项风险，我们生成**定制化研究方案**，并向 Perplexity Sonar 发起**迭代式的智能体风格调用**
4. **📄 报告生成**：将研究结果**汇总、整理并排版**为一份可落地执行的 HTML 报告——包含引用来源、链接和图示指引
5. **📧 交付**：通过邮件发送详细报告，附上自助解决方案与专业建议

<div id="deep-research-with-perplexity-sonar-api">
  ### 🔍 借助 Perplexity Sonar API 进行深度研究
</div>

真正的创新之处在于我们使用 **Perplexity Sonar API** 的方式：

* 我们把它当作研究助手，负责搜集现有的最佳信息
* 每一处风险隐患都会触发多次查询，涵盖严重程度、缓解措施以及本地化洞察
* 查询结果包含区域消防规范、天气模式以及当地承包商的可用情况

这种**结构化、可信赖的 AI 驱动研究，离开 Perplexity 是无法实现的**。

<div id="technical-stack">
  ### 技术栈
</div>

FlameGuard AI™ 采用现代 GenAI 技术栈构建，可轻松扩展：

* **前端**：轻量级 HTML 仪表盘，支持用户账户管理、照片上传和报告查看
* **后端**：Python (Flask) + RESTful API
* **数据库**：PostgreSQL (本地) ，schema **可直接迁移至 Azure SQL**
* **AI 集成**：OpenAI Vision API + Perplexity Sonar API
* **云端就绪**：面向 **Azure App Service** 构建，支持 Docker 化部署
