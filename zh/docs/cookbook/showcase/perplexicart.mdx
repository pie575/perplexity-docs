**PerplexiCart** 帮助用户做出明智且符合自身价值观的购买决策。它由 **Perplexity Sonar API** 驱动，在全网范围内分析商品，并输出结构化洞察，包括按优先级排列的推荐、优缺点、权衡分析和用户情感倾向，并可契合环保、耐用性、道德采购以及特定地区需求等偏好。

<div id="features">
  ## 功能特性
</div>

* **智能商品推荐**，不止于简单的参数对比
* **基于优先级的价值取向匹配** (高性价比、环保、道德生产、耐用、印度制造) 
* **情境化个性化** (肤质、使用习惯、地区等) 
* **结构化调研输出**，包括：
  * 调研摘要与首选推荐
  * 价值取向匹配及理由说明
  * 优缺点与关键规格
  * 用户情感倾向与社区洞察 (Reddit、Quora) 
  * 权衡分析与选购建议
* **来源透明**，附引用便于核实

<div id="prerequisites">
  ## 前置条件
</div>

* Node.js 18+ 和 npm/yarn
* Python 3.10+ 和 pip
* Perplexity API key

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/fizakhan90/perplexicart.git
cd perplexicart

# 后端（FastAPI）配置
cd backend
python -m venv .venv
source .venv/bin/activate  # Windows：.venv\Scripts\activate
pip install -r requirements.txt

# 前端（Next.js）配置
cd ../frontend
npm install
```

<div id="configuration">
  ## 配置
</div>

在 backend 目录中创建一个 `.env` 文件：

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key
```

 (可选) 根据需要添加应用专属的配置项 (缓存、默认区域等) 。

<div id="usage">
  ## 使用方法
</div>

1. **启动后端 (FastAPI)&#x20;**：
   ```bash theme={null}
   cd backend
   uvicorn main:app --reload  # 若入口模块不同，请相应调整 module:app
   ```

2. **启动前端 (Next.js)&#x20;**：
   ```bash theme={null}
   cd frontend
   npm run dev
   ```

3. **打开应用**：访问 `http://localhost:3000` 并搜索某个产品。选择你关注的优先级 (例如 Eco‑Friendly) ，并按需补充上下文信息 (肤质、地区) 。

<div id="code-explanation">
  ## 代码说明
</div>

* **后端 (FastAPI)&#x20;**：根据查询内容、所选优先级和上下文动态构造提示词，编排 Sonar 调用
* **结构化输出**：通过 `response_format` 强制约束严格的 JSON Schema，确保 UI 渲染保持一致
* **实时网络调研**：引导 Sonar 检索电商平台、论坛、评测博客和可持续发展报告
* **语义分析**：提取价值观契合度、优缺点和情感倾向，并标注来源以保证透明度
* **前端 (Next.js/React)&#x20;**：以清晰、易用的界面呈现推荐结果、权衡分析和引用来源

<div id="how-the-sonar-api-is-used">
  ## Sonar API 的使用方式
</div>

PerplexiCart 以 **Perplexity Sonar API** 作为智能核心，根据搜索查询、优先级、上下文等用户输入动态生成定制化提示词。该 API 会在电商网站、论坛和评测平台上进行全面的网络调研，并以统一的 JSON 格式返回结构化响应。借助语义分析，它能提取关键的产品洞察，包括与用户优先级的契合度、优缺点以及情感倾向，且全部附有引用来源。FastAPI 后端会先处理这些结构化响应，再将其交付给 Next.js 前端，从而带来精致的用户体验。
