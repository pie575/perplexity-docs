**UnCovered** 是一款 Chrome 扩展程序，可在你浏览网页时实时核查文本、图片、网站和截图。它基于 Perplexity 的 Sonar API 构建，只需右键点击，即可获得附带引用来源的即时结论、判定结果和深度分析，全程不打断你的浏览体验。

<div id="features">
  ## 功能特性
</div>

* **三步点击完成核查**：选中 → 右键 → 核查 (文本、图片、链接或截图) 
* **多种文本分析模式**：快速搜索、事实核查与深度研究
* **图片事实核查**：反向图片分析与多模态说法验证
* **截图与视频帧捕获**：分析信息图、梗图或图表截图等视觉内容
* **结果附带引用来源**：所有回答均包含来源和事实判定 (属实／不实／未经证实) 
* **即时反驳生成器**：针对不实信息生成简洁、有据可依的回复
* **零摩擦体验**：全程停留在当前页面——无需复制粘贴，也无需新开标签页

<div id="prerequisites">
  ## 前置条件
</div>

* Chrome 浏览器
* Node.js 16+ 和 npm
* MongoDB 数据库
* 用于存储图片的 Cloudinary 账户
* Perplexity API key (需具备 Sonar Pro 和 深度研究 访问权限) 
* Google OAuth 凭据

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/aayushsingh7/UnCovered.git
cd UnCovered

# 安装依赖
npm install

# 构建 Chrome 扩展程序
npm run build
```

<div id="configuration">
  ## 配置
</div>

设置环境变量：

```ini theme={null}
PERPLEXITY_API_KEY=your_sonar_api_key
MONGODB_URI=your_mongodb_connection_string
CLOUDINARY_URL=your_cloudinary_credentials
GOOGLE_OAUTH_CLIENT_ID=your_google_oauth_id
```

<div id="usage">
  ## 使用方式
</div>

1. **文本/链接核实**：
   * 选中文本，或右键点击链接
   * 选择 快速搜索 / 事实核查 / 深度研究
   * 获得附带结论与引用来源的可信结果

2. **图片核实**：
   * 右键点击任意图片
   * 选择 快速搜索 或 事实核查
   * 识别虚假信息与图像篡改

3. **截图/信息图分析**：
   * 点击工具栏中的 UnCovered 图标
   * 使用“Capture Screen”分析图像内容

4. **即时获取反驳**：
   * 自动生成基于事实的回应，纠正虚假信息

<div id="code-explanation">
  ## 代码说明
</div>

* **前端**：使用原生 JavaScript 编写的 Chrome 扩展，集成右键上下文菜单
* **后端**：Node.js Express 服务器，负责处理 API 请求与用户身份验证
* **AI 集成**：借助 Perplexity Sonar Pro 与 深度研究 API 实现智能事实核查
* **图像处理**：集成 Cloudinary，用于截图与图像分析
* **数据库**：使用 MongoDB 存储用户数据与核查历史
* **身份验证**：通过 Google OAuth 实现安全的用户管理
* **多模态分析**：支持文本、图像、截图和视频帧

<div id="technical-implementation">
  ## 技术实现
</div>

UnCovered 通过三种核心模式使用 Perplexity Sonar API：

```javascript theme={null}
// 使用 Sonar Pro 进行快速搜索与事实核查
const quickResponse = await perplexityClient.chat.completions.create({
  model: "sonar-pro",
  messages: [{ role: "user", content: factCheckPrompt }]
});

// 使用深度研究进行全面分析
const deepResponse = await perplexityClient.chat.completions.create({
  model: "sonar-deep-research", 
  messages: [{ role: "user", content: deepAnalysisPrompt }]
});
```
