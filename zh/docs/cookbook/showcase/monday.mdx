**Monday** 是一款支持语音交互的 AI 学习助手，旨在弥合自然语言提问与高质量教育内容之间的鸿沟。Monday 的灵感源自漫威的 JARVIS 与 FRIDAY，可通过基础、推理和深度研究三种模式给出量身定制的回答，同时融合沉浸式可视化、精选视频内容以及无障碍优先的设计理念。

<div id="features">
  ## 功能特性
</div>

* **三种学习模式**：基础事实问答、分步推理，以及深度研究式探究
* **语音优先交互**，结合自然语言处理，实现免提学习
* 借助 Three.js 与 WebXR 对概念进行**实时 3D 可视化**
* 集成来自可信来源的**精选教育类 YouTube 视频**
* **多模态反馈**，融合文本、语音 (由 ElevenLabs 提供) 与空间面板
* **VR 可选设计**，无需头显也能获得沉浸式体验
* **无障碍优先的界面**，照顾行动不便和视力障碍用户

<div id="prerequisites">
  ## 前置条件
</div>

* Node.js 18 LTS 或更高版本
* 现代浏览器 (推荐 Chrome、Edge 或 Firefox) 
* 用于语音交互的麦克风
* 可选：用于沉浸式模式的 VR 头显 (需兼容 WebXR) 
* Perplexity API key、ElevenLabs API key 和 YouTube API key

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/srivastavanik/monday.git
cd monday
git checkout final
cd nidsmonday

# 安装依赖
npm install
```

```ini theme={null}
# 创建 .env 文件并设置你的 API key
PERPLEXITY_API_KEY=your_api_key
ELEVENLABS_API_KEY=your_api_key
YOUTUBE_API_KEY=your_api_key
```

```bash theme={null}
# 启动后端服务器
node backend-server.js

# 启动前端
npm run dev
```

<div id="usage">
  ## 使用方法
</div>

1. 在浏览器中启动应用
2. 说出 **&quot;Hey Monday&quot;** 唤醒助手
3. 用以下三种模式之一提问：
   * **基础模式**——&quot;什么是光合作用？&quot;
   * **推理模式**——&quot;想一想区块链是如何运作的。&quot;
   * **深度研究模式**——&quot;研究一下量子力学的发展史。&quot;
4. 通过浮动文本面板、语音回复和交互式 3D 模型查看答案

<div id="code-explanation">
  ## 代码说明
</div>

* **前端**：TypeScript，搭配 Three.js 实现 3D 可视化，并通过 WebXR 支持 VR
* **后端**：Node.js，搭配 Socket.IO 实现实时语音指令处理
* **AI 集成**：使用 Perplexity Sonar API 生成智能响应并提取推理过程
* **语音处理**：使用 ElevenLabs 进行语音合成与自然语言理解
* **内容筛选**：集成 YouTube API，通过智能关键词提取获取教育类视频
* **无障碍**：语音优先的设计，支持空间音频与触觉反馈
