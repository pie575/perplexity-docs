**MVP LifeLine** 是一个多语言、离线优先的 AI 平台，随时随地为年轻人提供情感、财务和职业方面的支持。全球有超过 13 亿年轻人在获取职业机会和维护心理健康方面面临重重障碍，在服务欠缺地区和偏远地区尤为如此。MVP LifeLine 将 AI、离线访问、多语言支持与完整的工具生态系统融为一体，打破了这些障碍。

<div id="features">
  ## 功能特性
</div>

* **双模式 AI**：由 Perplexity Sonar API 驱动的职业教练与情感陪伴
* **多语言支持**：支持 10 余种语言，包括英语、法语、阿拉伯语、西班牙语、印地语及多种地区语言
* **离线优先设计**：集成短信/USSD，适配网络条件较差的地区
* **全方位工具生态**：覆盖职业、身心健康、理财与效率
* **SmartQ 入口**：提供情境感知、善解人意的 AI 回复
* **数字副业中心**：内置 AI 零工发现与自由职业工具
* **身心健康专区**：提供引导式冥想与心理调适引导
* **理财专区**：提供预算跟踪与贴合年轻人的理财贴士
* **效率专区**：提供 AI 看板与习惯打卡

<div id="prerequisites">
  ## 前置条件
</div>

* Flutter SDK 和 Dart
* 已完成 Firebase 项目配置
* 用于短信/USSD 集成的 Twilio 账户
* Perplexity API key (Sonar) 
* OpenAI API key (用于内容增强)

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/JohnUmoh/asgard.git
cd asgard

# 安装 Flutter 依赖
flutter pub get

# 配置 Firebase
flutterfire configure

# 配置环境变量
cp .env.example .env
```

<div id="configuration">
  ## 配置
</div>

创建 `.env` 文件：

```ini theme={null}
PERPLEXITY_API_KEY=your_sonar_api_key
OPENAI_API_KEY=your_openai_api_key
FIREBASE_PROJECT_ID=your_firebase_project_id
TWILIO_ACCOUNT_SID=your_twilio_sid
TWILIO_AUTH_TOKEN=your_twilio_token
```

<div id="usage">
  ## 使用方法
</div>

1. **配置 Firebase**：
   ```bash theme={null}
   flutterfire configure
   ```

2. **运行应用**：
   ```bash theme={null}
   flutter run
   ```

3. **体验功能**：
   * 在职业教练模式与情感陪伴模式之间切换
   * 使用 SmartQ 获得多语言 AI 智能助力
   * 网络连接受限时，通过短信/USSD 使用离线功能
   * 探索职业工具、身心健康功能与效率提升特性

<div id="code-explanation">
  ## 代码说明
</div>

* **前端**：Flutter 跨平台应用，采用响应式设计，适配移动端和 Web 端
* **后端**：Firebase 提供身份验证、数据存储和实时同步
* **AI 集成**：Perplexity Sonar API 支持双模式 AI 交互 (职业教练与情感陪伴) 
* **离线支持**：集成 Twilio，在弱网地区通过短信/USSD 进行通信
* **多语言**：Sonar API 支持 10 余种语言，并给出上下文感知的回复
* **数据同步**：离线采集数据，网络恢复后自动重新同步
* **个性化**：AI 会根据用户的语言、识字水平、情绪记录和偏好进行调整
