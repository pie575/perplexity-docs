**Daily News Briefing** 是一款 Obsidian 插件，可将 AI 生成的新闻摘要直接送入你的 vault。它借助 Perplexity 的 Sonar API 智能筛选内容，通过自动化的新闻采集与摘要，让你随时掌握所关注话题的动态。

<div id="features">
  ## 功能特性
</div>

* **个性化新闻采集**：基于你感兴趣的主题和偏好
* **AI 智能摘要**：使用 Perplexity Sonar API 为新闻文章生成摘要
* **自动化每日简报**：直接送达你的 Obsidian vault
* **可自定义的推送计划**与格式选项
* **无缝集成 Obsidian**：融入你现有的知识管理工作流
* **可信来源筛选**：确保内容质量与可靠性
* **Markdown 格式**：便于在 vault 内建立链接与整理内容

<div id="prerequisites">
  ## 前置条件
</div>

* 已安装 Obsidian 桌面应用
* Perplexity API key (具备 Sonar API 访问权限) 
* 可联网以抓取新闻文章
* Typescript 开发环境 (用于自定义扩展)

<div id="installation">
  ## 安装
</div>

```bash theme={null}

git clone https://github.com/ChenziqiAdam/Daily-News-Briefing.git

npm run build
```

<div id="configuration">
  ## 配置
</div>

1. **安装插件**：将构建好的插件复制到 Obsidian 插件目录
2. **启用插件**：在 Obsidian 设置中启用该插件
3. **API 设置**：在插件设置中填入你的 Perplexity API key
4. **配置主题**：设置需要关注的新闻主题及推送偏好

<div id="usage">
  ## 使用方式
</div>

1. **配置兴趣**：设置关注的主题、来源和推送计划
2. **自动收集**：插件通过 Perplexity Sonar API 抓取最新新闻
3. **AI 摘要**：借助 Perplexity 的能力对文章进行处理和总结
4. **写入 vault**：摘要以 Markdown 笔记的形式写入你的 Obsidian vault
5. **知识整合**：将新闻简报与知识库中的其他笔记相互关联

<div id="technical-implementation">
  ## 技术实现
</div>

该插件借助 Perplexity Sonar API 实现以下功能：

```typescript theme={null}
// 使用 Perplexity Sonar API 采集新闻
const newsQuery = `latest news about ${topic} in the past 24 hours`;
const searchResponse = await perplexityClient.search({
  query: newsQuery,
  max_results: 5,
  include_domains: userPreferences.trustedSources || []
});

// AI 驱动的摘要生成
const summaryPrompt = `Summarize these news articles about ${topic}`;
const summaryResponse = await perplexityClient.generate({
  prompt: summaryPrompt,
  model: "sonar-medium-online",
  max_tokens: 500
});
```
