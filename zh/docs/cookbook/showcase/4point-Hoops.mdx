**4Point Hoops** 是一个高级 NBA 数据分析平台，可将原始篮球统计数据转化为可落地、以叙事驱动的洞察。它实时抓取 Basketball-Reference 的数据，并将富含上下文的提示词路由到 Perplexity 的 Sonar Pro 模型，帮助球迷、分析师和梦幻篮球玩家看懂数字背后的“为什么”和“接下来会怎样”，而不只是数字本身。

<div id="features">
  ## 功能
</div>

* **球员数据分析**：提供常规赛与季后赛数据拆分、投篮类型分布，以及任意 NBA 球员的表现雷达图
* **跨时代对比**：支持并排数据对比 (例如 1997 年的 Michael Jordan 对阵 2022 年的 Stephen Curry) 
* **球队仪表盘**：包含排名、季后赛晋级概率桑基图，以及自动刷新的 KPI 卡片
* **AI 解读与相似球员**：一键调用 Sonar 解读数据表现，并由 AI 挑选风格相近的球员
* **篮球 AI 聊天**：用户可向专业 LLM 咨询 NBA 历史、阵容或赛况预测
* **基于额度的 SaaS 系统**：集成 Firebase Auth、Google 登录、额度钱包及管理工具

<div id="prerequisites">
  ## 前置条件
</div>

* Node.js 16+ 和 npm
* Python 3.8+ 和 pip
* 已创建并配置 Firebase 项目
* Perplexity API key (Sonar Pro) 
* Basketball-Reference 访问权限

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆前端仓库
git clone https://github.com/rapha18th/hoop-ai-frontend-44.git
cd hoop-ai-frontend-44
npm install

# 克隆后端仓库
git clone https://github.com/rapha18th/4Point-Hoops-Server.git
cd 4Point-Hoops-Server
pip install -r requirements.txt
```

<div id="configuration">
  ## 配置
</div>

在后端目录中创建 `.env` 文件：

```ini theme={null}
PERPLEXITY_API_KEY=your_sonar_pro_api_key
FIREBASE_PROJECT_ID=your_firebase_project_id
FIREBASE_PRIVATE_KEY=your_firebase_private_key
FIREBASE_CLIENT_EMAIL=your_firebase_client_email
```

<div id="usage">
  ## 使用方式
</div>

1. **启动后端**：
   ```bash theme={null}
   cd 4Point-Hoops-Server
   python app.py
   ```

2. **启动前端**：
   ```bash theme={null}
   cd hoop-ai-frontend-44
   npm run dev
   ```

3. **访问应用**：打开前端 URL，通过 AI 洞察探索 NBA 数据分析

4. **使用 AI 功能**：点击任意球员或数据旁的“AI Explain”，即可获得由 Perplexity Sonar 驱动的智能分析

<div id="code-explanation">
  ## 代码说明
</div>

* **前端**：React，搭配 shadcn/ui 组件，并使用 Recharts 实现数据可视化
* **后端**：Python Flask API，提供 Basketball-Reference 数据并管理 Perplexity API 调用
* **数据管道**：使用 BRScraper 实时采集数据，并借助 Firebase 缓存
* **AI 集成**：Perplexity Sonar Pro，用于智能篮球分析与解读
* **身份验证**：Firebase Auth，支持 Google 登录及基于额度的访问控制
* **部署**：前端部署在 Netlify，后端通过 Docker 部署在 Hugging Face Spaces
