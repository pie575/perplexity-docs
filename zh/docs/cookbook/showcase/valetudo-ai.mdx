<div id="valetudo-ai">
  # Valetudo AI
</div>

**Valetudo AI** 是一款基于科学证据的医疗助手，由 Perplexity Sonar API 驱动。它能针对健康问题给出快速、清晰且引用翔实的回答——借助筛选条件、图像分析和现成的提示词模板，帮助用户拨开错误信息的迷雾。

专为注重求证的用户设计——如家长、患者和医学生——满足他们获取可靠信息的需求。

<div id="features">
  ## 功能特性
</div>

* **带引用的回答** —— 内容来自精选的 10 个可信医学网站
* **智能筛选** —— 按日期和国家/地区筛选，获取本地化的最新信息
* **图片上传** —— 分析药品、病症或包装的照片
* **提示词模板** —— 涵盖症状自查、用药安全、研究等 7 大类别
* **简洁界面** —— 基于 React 和 Tailwind CSS 构建

<div id="how-it-uses-the-sonar-api">
  ## 它如何使用 Sonar API
</div>

Valetudo AI 集成了 [Perplexity Sonar Pro](https://docs.perplexity.ai)，借助其高级功能实现特定领域搜索和内容丰富的回答：

| 功能    | API 字段                            | 用途                 |
| ----- | --------------------------------- | ------------------ |
| 上下文控制 | `search_context_size: medium`     | 兼顾速度与深度，适用于聚焦的医疗问答 |
| 可信域名  | `search_domain_filter`            | 将结果限制在经过审核的健康信息来源  |
| 视觉输入  | `image_url`                       | 支持基于图像的医疗查询        |
| 时效性筛选 | `search_after/before_date_filter` | 帮助呈现较新且相关的研究结果     |
| 本地相关性 | `user_location`                   | 根据用户所在地区定制回答       |
