**BazaarAISaathi** 是一个 AI 驱动的平台，旨在为投资者提供切实可行的印度股市洞察。该应用借助先进的自然语言处理、实时数据分析和专家驱动的金融建模，提供个性化投资策略、市场情绪分析以及投资组合优化建议。

<div id="features">
  ## 功能
</div>

* **财务独立规划器 (FIRE)&#x20;**：根据年龄、薪资和目标生成个性化方案
* **投资建议检验器**：借助 EasyOCR 提取文本并由 AI 进行验证
* **基本面与技术面分析**：提供全面的公司研究报告与交易策略
* **投资组合分析**：多维度剖析并给出逐只股票的建议
* **市场研究与竞品对标**：基于 AI 的行业趋势分析
* **实时股票数据**：支持实时价格跟踪与趋势分析
* **假设检验**：结合历史与实时市场数据进行验证
* **投资书籍摘要**：精炼总结 50 本顶级投资书籍

<div id="prerequisites">
  ## 前置条件
</div>

* Python 3.8+ 和 pip
* Streamlit (Web 应用框架) 
* Perplexity API key (Sonar 模型) 
* 可选：EasyOCR，用于从图像中提取文本

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/mahanteshimath/BazaarAISaathi.git
cd BazaarAISaathi

# 安装依赖
pip install -r requirements.txt
```

<div id="configuration">
  ## 配置
</div>

创建 `secrets.toml` 文件，用于存放 Streamlit 密钥：

```ini theme={null}
PERPLEXITY_API_KEY = "your_perplexity_api_key"
# 按需添加其他 API key
```

<div id="usage">
  ## 使用方法
</div>

1. **启动应用**：
   ```bash theme={null}
   streamlit run Home.py
   ```

2. **使用各项功能**：
   * 切换到相应页面即可使用对应功能
   * 通过主仪表板查看总览并进行导航
   * 使用投资组合分析、FIRE 规划、投资建议测试等专用工具

3. **运行指定模块**：
   ```bash theme={null}
   streamlit run pages/Financial_Independence.py
   streamlit run pages/Portfolio_Analysis.py
   streamlit run pages/Tip_Tester.py
   ```

<div id="code-explanation">
  ## 代码说明
</div>

* **前端**：Streamlit Web 应用，提供交互式页面和实时数据可视化
* **后端**：基于 Python 的业务逻辑，使用 Pandas 进行数据处理与分析
* **AI 集成**：调用 Perplexity Sonar API 模型 (sonar-deep-research、sonar-reasoning-pro、sonar-pro) 进行金融分析
* **数据处理**：实时股票数据获取、CSV 数据管理以及市场洞察生成
* **文本提取**：集成 EasyOCR，从图片中提取投资建议
* **投资组合管理**：全面的投资组合分析，并给出优化建议
* **市场分析**：技术面与基本面分析，并提供情绪评分
