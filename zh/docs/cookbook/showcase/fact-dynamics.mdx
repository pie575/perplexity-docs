  # Fact Dynamics | 实时事实核查 Flutter 应用
</div>

<p align="center">
  <img src="https://raw.githubusercontent.com/vishnu32510/fact_pulse/main/assets/icon/icon.png" alt="Fact Dynamics logo" width="80" height="80" style={{ borderRadius: '14px' }} />
</p>

**黑客松参赛作品** — 为 Perplexity Hackathon 的信息工具与深度研究类别打造。

Fact Dynamics 是一款跨平台 Flutter 应用，可对语音内容和图像进行实时事实核查，非常适合现场辩论、演讲以及即时信息验证等场景。

<div id="features">
  ## 功能特性
</div>

* 在实时对话中进行语音转写与事实核查

* 提取图片文字并验证其中的主张，同时附上来源引用

* 主张评级体系 (TRUE、FALSE、MISLEADING、UNVERIFIABLE) ，并附解释说明

* 来源引用 —— 为每项结论提供权威 URL 佐证

* 辩论模式，支持连续语音识别与流式反馈

* 通过 Firebase 实现用户身份验证 (Google、邮箱) ，并持久保存聊天记录

* 跨平台支持 iOS、Android 和 Web

<div id="prerequisites">
  ## 前置条件
</div>

* Flutter SDK 3.0.0 或更高版本
* Dart SDK 2.17.0 或更高版本
* Firebase CLI，用于身份验证和数据库配置
* 用于集成 Sonar 的 Perplexity API key
* 可访问麦克风的设备，用于语音识别

<div id="usage">
  ## 使用方法
</div>

<div id="real-time-speech-fact-checking">
  ### 实时语音事实核查
</div>

* 通过 Flutter 的 `speech_to_text` 以 5 秒为单位流式传输音频块
* 将转写的片段与结构化提示一起发送至 Sonar API
* 返回 JSON，其中包含主张、评级 (TRUE/FALSE/MISLEADING/UNVERIFIABLE) 、解释说明和来源

<div id="image-analysis">
  ### 图像分析
</div>

* 将图像或图像 URL 上传至 Sonar API 进行文本提取
* 对照权威来源核实提取出的主张
* 提供附带来源标注的全面分析

<div id="code-explanation">
  ## 代码说明
</div>

* 前端：Flutter，采用 BLoC 模式管理状态，可同时面向 iOS、Android 和 Web
* 后端：Firebase (Firestore、Authentication) ，用于持久化用户数据和聊天记录
* 语音处理：使用 speech&#95;to&#95;text 包实现实时音频转写
* API 集成：自定义 Dart 客户端，通过结构化提示词调用 Perplexity Sonar API
* 图像处理：内置图片选择器，配合 base64 编码实现多模态分析
* 数据架构：按用户划分 Firestore 集合，并以子集合分别存储辩论、演讲和图像
