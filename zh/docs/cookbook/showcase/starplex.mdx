**StarPlex** 是一个 AI 驱动的创业情报平台，帮助创业者验证商业创意，并对接成功所需的各类资源。它主要由 **Perplexity Sonar Pro** 提供支持，以交互式 **3D 地球界面**作为主界面。只需输入你的创业创意，就能看到 AI 引擎实时分析，并将洞察直接可视化呈现在地球上——在全球范围内标注出竞争对手、市场、人群画像、风险投资机构以及潜在的联合创始人。

<div id="features">
  ## 功能
</div>

* **市场验证分析**：提供抗 AI 冲击评分、市场规模估算和增长趋势分析
* **交互式 3D 地球界面**：可视化呈现全球创业情报数据
* **竞品研究**：包含威胁评分与竞争格局图谱
* **风投与投资人匹配**：基于投资理念和投资组合契合度进行匹配
* **联合创始人发现**：提供契合度评分与专长匹配
* **人群画像研究**：以热力图直观展示目标受众的地域分布
* **AI 路演材料生成**：一键生成可直接面向投资人的演示文稿
* **上下文感知聊天机器人**：通过 RAG 集成打通全部研究数据

<div id="prerequisites">
  ## 前置条件
</div>

* Node.js 18+ 和 npm
* Python 3.8+ 和 pip
* Perplexity API key (Sonar Pro) 
* Mapbox token 和 SERP API key

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/JerryWu0430/StarPlex.git
cd StarPlex

# 配置后端
cd backend
pip install -r requirements.txt

# 配置前端
cd ../frontend
npm install
```

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key
MAPBOX_TOKEN=your_mapbox_token
SERPAPI_KEY=your_serpapi_key
```

<div id="how-starplex-uses-perplexity-sonar-api">
  ## StarPlex 如何使用 Perplexity Sonar API
</div>

StarPlex 通过**多模块智能架构**使用 Perplexity 的 Sonar API：

**市场分析引擎**
使用 Sonar Pro 进行全面的市场验证，将 Google Trends 数据与 AI 分析相结合，以结构化 JSON 输出的形式生成市场规模估算、AI 颠覆性评分和增长预测。

**竞争对手情报**
通过多个并发的 Sonar 查询识别竞争公司、融资状态和威胁等级。每个竞争对手都会获得 1-10 分的威胁评分，并附带详细的竞争定位分析。

**风险投资与联合创始人匹配**
利用 Sonar 的实时网络知识寻找合适的投资人和潜在联合创始人，并根据投资理念契合度、专业能力匹配度和地理位置邻近程度为匹配结果打分。

**上下文感知型业务助手**
将所有调研数据输入 Sonar 对话以实现 RAG (检索增强生成) ，打造一位见多识广的创业顾问，可解答市场定位、竞争威胁和战略决策方面的问题。

**地理情报**
将 Sonar 的人群画像与 Mapbox 地理编码相结合，生成交互式热力图，展示目标受众在全球范围内的聚集分布。

<div id="code-explanation">
  ## 代码说明
</div>

* **后端**：Python FastAPI 搭配 AsyncIO，在多个分析模块间并发调用 Perplexity API
* **前端**：Next.js + React 19，采用 Cobe 实现 3D 地球可视化，Mapbox GL 实现交互式地图
* **AI 集成**：多模型 Perplexity 策略——复杂分析使用 Sonar Pro，快速查询使用 Sonar
* **数据管道**：智能缓存、结构化 JSON 响应与实时流式传输，即时向用户反馈
* **可视化**：将 Perplexity 的分析洞察与交互式地球/地图界面动态绑定
