**Greenify** 是一款移动应用，通过分析实时拍摄的图像并建立社区，鼓励人们践行可持续生活方式。用户拍下自己所处空间 (阳台、路边、地下室等) 的照片，Greenify 便会调用 Perplexity 的 Sonar API 自动分析图像，为该场地推荐合适的植物。应用还会将当地志同道合的人聚到一起，组建社区，共同推动可持续发展与经济、社会层面的成长。

<div id="features">
  ## 功能特性
</div>

* **AI 驱动的植物分析**：结合图像识别与位置数据推荐适宜栽种的植物
* **基于位置的推荐**：综合考虑天气、光照和环境条件
* **构建社区**：将植物兴趣相近、追求可持续目标的用户连接起来
* **跨平台移动应用**：基于 Expo 构建，支持 iOS、Android 和 Web
* **实时天气集成**：精准评估植物的适宜性
* **结构化 JSON 输出**：借助 Pydantic 模型实现一致的数据处理
* **AR 模型支持**：提升植物可视化效果

<div id="prerequisites">
  ## 前置条件
</div>

* Node.js 20.19.4+ 和 npm
* Python 3.10.0+ 和 pip
* Expo CLI 及 SDK 51+
* Perplexity API key (Sonar Pro 和 Sonar Deep Research) 
* Android SDK/Studio 或 Xcode (用于本地构建) 
* 带摄像头的移动设备，用于拍摄图像

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/deepjyotipaulhere/greenify.git
cd greenify

# 安装前端依赖
npm install

# 安装后端依赖
cd service
pip install -r requirements.txt
```

<div id="configuration">
  ## 配置
</div>

在 `service` 目录下创建 `.env` 文件：

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key_here
```

<div id="usage">
  ## 使用方法
</div>

1. **启动后端服务**：
   ```bash theme={null}
   cd service
   python app.py
   ```

2. **启动前端应用**：
   ```bash theme={null}
   npx expo start
   ```

3. **访问应用**：
   * 安装 Expo Go 应用并扫描二维码，或
   * 在手机上打开浏览器，访问显示的网址

4. **使用应用**：
   * 授予相机和位置权限
   * 拍摄你的空间照片 (阳台、花园等) 
   * 获取 AI 生成的植物推荐
   * 与附近的用户建立联系，构建社区

<div id="code-explanation">
  ## 代码说明
</div>

* **前端**：使用 React Native 与 Expo 进行跨平台移动端开发
* **后端**：Python Flask API，负责图像处理以及与 Perplexity API 的集成
* **AI 集成**：使用 Perplexity Sonar Pro 进行图像分析，使用 Sonar Deep Research 生成植物推荐
* **数据模型**：使用 Pydantic 模型实现结构化 JSON 输出与数据校验
* **图像处理**：结合位置信息的实时图像分析
* **社区功能**：基于植物推荐和可持续发展兴趣进行用户匹配
* **实时天气集成**：借助实时天气数据准确评估植物适宜性
