**Perplexity Lens** 是一款功能强大的浏览器扩展，它借助 Perplexity AI 提供智能洞察，并构建个性化知识图谱，将你在网上接触到的各种概念可视化地关联起来，全面提升你的浏览体验。

<div id="features">
  ## 功能
</div>

* **智能文本选择**：为选中的文本生成 AI 解释
* **网页摘要**：即时生成整页内容的简明概览
* **上下文 RAG 洞察**：借助检索增强生成提供详尽的上下文与释义
* **知识图谱可视化**：通过交互式 D3.js 图形展示概念之间的关联
* **公开分享**：生成 URL，便于与他人分享图谱
* **用户身份验证**：通过 Firebase 实现安全访问
* **双重存储**：同时支持本地 IndexedDB 与 Firebase 云端存储
* **响应式界面**：在所有设备上均可完整使用

<div id="prerequisites">
  ## 前置条件
</div>

* Node.js v14+ 和 npm v6+
* Google Chrome 或兼容浏览器
* 用于云端功能的 Firebase 账号
* Firebase CLI (`npm install -g firebase-tools`) 
* Perplexity API key 和 OpenAI API key

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/iamaayushijain/perplexity-lens.git
cd perplexity_lens

# 安装依赖
npm install

# 构建浏览器扩展
npm run build
```

<div id="configuration">
  ## 配置
</div>

编辑 `src/config.ts`：

```typescript theme={null}
export const PERPLEXITY_API_KEY = 'your-perplexity-key';
export const EMBEDDING_API_KEY = 'your-openai-key';
export const FIREBASE_HOSTING_URL = 'https://your-project-id.web.app';
```

<div id="usage">
  ## 使用方式
</div>

1. **加载浏览器扩展**：访问 `chrome://extensions/`，启用开发者模式，点击“加载已解压的浏览器扩展”，然后选择 `dist/` 目录

2. **登录**：点击浏览器扩展图标，通过 Firebase 完成身份验证

3. **使用功能**：
   * **高亮文本**：在任意网页上选中文本，即可获得 AI 洞察
   * **总结页面**：使用“Summarize”功能获取网页概览
   * **随时提问**：将鼠标悬停或点击词语/短语，查看释义或解释
   * **查看图谱**：切换到 Graph 标签页，查看你的知识图谱
   * **探索**：在交互式图谱中缩放、拖拽节点，或悬停查看详情
   * **分享**：点击“Share Graph”生成公开链接

<div id="code-explanation">
  ## 代码说明
</div>

* **前端**：React + TypeScript + TailwindCSS，打造现代化的响应式界面
* **浏览器扩展**：Chrome 扩展架构，包含弹出页面与内容脚本
* **AI 集成**：借助 Perplexity AI 实现智能文本解释与摘要
* **知识图谱**：使用 D3.js 实现交互式图谱可视化与概念关联
* **存储**：本地 IndexedDB 与云端 Firebase 的双重存储系统
* **身份验证**：使用 Firebase Auth 保障用户访问安全与数据管理
* **RAG 系统**：通过检索增强生成提供上下文洞察与释义
