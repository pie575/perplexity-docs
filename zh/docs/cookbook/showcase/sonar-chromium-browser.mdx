**Sonar Chromium Browser** 是一个 Chromium 浏览器补丁，原生集成 Perplexity 的 Sonar API，直接在浏览器中提供 AI 能力。用户在地址栏输入 `sonar <query>` 即可即时获得 AI 答案，或选中文本后右键选择“使用 Sonar 总结”快速生成摘要，从而简化调研与浏览流程。

<div id="features">
  ## 功能
</div>

* **地址栏 AI 问答**：使用 `sonar <query>` 语法即时获得回答
* **右键菜单摘要**：一键为选中文本生成摘要
* **原生浏览器集成**：基于 Chromium 的地址栏与右键菜单 API
* **双模型支持**：地址栏使用 Sonar Pro,摘要使用 Sonar
* **输入防抖处理**:提升 API 调用效率
* **自定义浏览器构建**:演示 AI 集成模式

<div id="prerequisites">
  ## 前置条件
</div>

* Ubuntu 22.04 (推荐使用 WSL2) 
* 已检出的 Chromium 源代码
* Perplexity API key
* 16GB 及以上内存 (用于构建 Chromium) 
* Git 及标准构建工具

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/KoushikBaagh/perplexity-hackathon-chromium.git
cd perplexity-hackathon-chromium

# 将补丁应用到 Chromium 源代码
# 详细的 Chromium 配置说明请参阅 README
```

<div id="configuration">
  ## 配置
</div>

在修改后的文件中更新 API key：

```cpp theme={null}
// 在 sonar_autocomplete_provider.cc 和 render_view_context_menu.cc 中
const std::string API_KEY = "your_perplexity_api_key_here";
```

<div id="usage">
  ## 使用方法
</div>

1. **构建 Chromium**：按照仓库说明应用补丁并完成构建
2. **启动自定义浏览器**：已集成 AI 功能
3. **使用地址栏 AI**：在地址栏中输入 `sonar what is quantum tunneling?`
4. **使用上下文摘要**：选中文本，右键点击 “使用 Sonar 总结”

<div id="code-explanation">
  ## 代码说明
</div>

* **地址栏集成**：对接 Chromium omnibox API 的自定义自动补全提供程序
* **右键菜单**：改造渲染视图右键菜单，实现文本摘要功能
* **API 集成**：直接调用 Perplexity Sonar API，并对输入做防抖处理
* **模型选择**：地址栏查询使用 Sonar Pro，文本摘要使用 Sonar
* **浏览器架构**：展示 Chromium 中可用于 AI 功能的扩展点
* **构建流程**：打上 AI 补丁后的自定义 Chromium 构建
