**Flow &amp; Focus** 是一款个性化新闻应用，它把阅读新闻变成一种学习体验。其独特之处在于，将垂直新闻信息流 (Flow) 带来的快速浏览发现与深入的互动式学习对话 (Focus) 融为一体，背后由 Perplexity 的 Sonar Pro 与 Sonar Deep Research 模型提供支持。

<div id="features">
  ## 功能特性
</div>

* **双模式界面**：Flow Feed 用于快速浏览新闻，Focus 用于个性化深度阅读
* **垂直新闻信息流**：可滑动浏览的新闻片段，配有 AI 生成的摘要、标签和背景图
* **交互式深度阅读**：点击关键短语即可聚焦相关内容，详情面板支持横向滚动
* **个性化学习**：由 AI 驱动的对话片段，提供 “Oracle”“Explorer” 等角色
* **智能个性化**：追踪阅读习惯，自动定制内容推荐
* **实时内容**：借助 Sonar Pro 获取最新资讯，并使用 Sonar Deep Research 进行深入分析
* **视觉增强**：根据内容关键词，通过 Runware.ai 动态生成背景图

<div id="prerequisites">
  ## 前置条件
</div>

* Node.js 18+ 和 npm
* Perplexity API key
* 用于图像生成的 Runware API key
* Next.js 15 和 React 19 环境

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/michitomo/NewsReel.git
cd NewsReel

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env.local
```

<div id="configuration">
  ## 配置
</div>

创建 `.env.local` 文件：

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key_here
RUNWARE_API_KEY=your_runware_api_key_here
PERPLEXITY_FOCUS_MODEL=sonar-deep-research
```

<div id="usage">
  ## 使用方法
</div>

1. **启动开发服务器**：
   ```bash theme={null}
   npm run dev
   ```

2. **访问应用**：在浏览器中打开 [http://localhost:3000](http://localhost:3000)

3. **Flow Feed**：上下滑动浏览新闻片段，点按关键短语即可深度阅读

4. **Focus Mode**：生成个性化摘要，并支持交互式对话片段

5. **个性化**：你的浏览习惯会自动影响内容的推荐

<div id="code-explanation">
  ## 代码说明
</div>

* **前端**：Next.js 15 搭配 React 19、Typescript、Tailwind CSS，并使用 Framer Motion 实现动画
* **状态管理**：Zustand，通过 localStorage 持久化保存用户偏好设置
* **AI 集成**：使用 Perplexity Sonar Pro 获取实时新闻，使用 Sonar Deep Research 进行深度分析
* **图像生成**：集成 Runware SDK，根据内容关键词动态生成背景图
* **API 路由**：服务端集成，负责处理 Perplexity 与 Runware 的 API 调用
* **移动优先设计**：滑动手势与响应式布局，带来直观的移动端体验
