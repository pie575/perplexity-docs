**FirstPrinciples App** 是一款 AI 驱动的工具，可将你宽泛的学习目标转化为结构化、个性化的学习路线图。在交互式对话中，AI 会与你逐步交流，通过有针对性的提问厘清你的学习需求，进而生成一份详细的学习计划。该应用旨在为你指明清晰的前进路径，帮助你更高效地学习。

<div id="features">
  ## 功能特性
</div>

* **交互式聊天界面**：通过对话定义并细化学习目标
* **AI 驱动的主题收窄**：通过智能且有针对性的提问明确学习目标
* **会话管理**：支持多个学习路线图讨论并跟踪进度
* **可视化进度指示器**：在信息收集充分时给出提示
* **个性化学习计划**：提供结构化的分步学习路线图
* **对话式 AI 流程**：结合 OpenAI 与 Perplexity API 实现智能交互

<div id="prerequisites">
  ## 前置条件
</div>

* Python 3.8+ 和 pip
* Node.js 16+ 和 npm
* OpenAI API key
* Perplexity API key

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/william-Dic/First-Principle.git
cd First-Principle

# 后端设置
cd flask-server
pip install -r requirements.txt

# 前端设置
cd ../client
npm install
```

<div id="configuration">
  ## 配置
</div>

在 `flask-server` 目录下创建 `.env` 文件：

```ini theme={null}
OPENAI_API_KEY=your_openai_api_key
PERPLEXITY_API_KEY=your_perplexity_api_key
PERPLEXITY_API_KEY=your_perplexity_api_key
```

<div id="usage">
  ## 使用方法
</div>

1. **启动后端**：
   ```bash theme={null}
   cd flask-server
   python server.py
   ```
   服务器运行在 [http://localhost:5000](http://localhost:5000)

2. **启动前端**：
   ```bash theme={null}
   cd client
   npm start
   ```
   客户端运行在 [http://localhost:3000](http://localhost:3000)

3. **生成学习路线图**：
   * 在浏览器中打开 [http://localhost:3000](http://localhost:3000)
   * 在聊天界面中描述你想学习的内容
   * 回答 AI 的追问，进一步明确学习目标
   * 获得一份个性化的结构化学习路线图

<div id="code-explanation">
  ## 代码说明
</div>

* **前端**：React 应用，提供对话式聊天界面和进度指示器
* **后端**：Flask 服务器，负责管理 API 调用、会话状态和对话流程
* **AI 集成**：结合 OpenAI API 实现对话流程，并使用 Perplexity API 进行智能主题分析
* **会话管理**：跟踪对话状态和学习目标的细化过程
* **学习路线图生成**：根据用户输入生成结构化、可落地的学习计划
* **对话流程**：采用目标导向的对话方式，逐步明确学习目标
