**Executive Intelligence** 是一款由 Perplexity Sonar 驱动的综合性应用，为高管和董事会成员提供即时、准确且可信的情报，助力战略决策。它基于 Perplexity 的 Sonar API，从实时数据源中提炼出可直接用于董事会的洞察。

<div id="features">
  ## 功能
</div>

* **竞争情报简报**：提供全面、可直接用于董事会的竞争分析，并附可核实的引用来源
* **情景规划 (“What If?” 分析)&#x20;**：基于实时数据动态生成未来情景
* **Board Pack记忆**：保存并整理情报简报、情景分析和基准对比报告
* **即时基准对标与同业比较**：围绕关键指标提供带来源引用的可视化对比
* **实时数据集成**：借助 Perplexity Sonar API 获取最新市场情报
* **专业排版**：结构化报告、执行摘要以及可直接用于董事会的演示材料

<div id="prerequisites">
  ## 前置条件
</div>

* Node.js 18+ 及 npm/yarn
* Git
* Perplexity API key (Sonar Pro)

<div id="installation">
  ## 安装
</div>

```bash theme={null}
# 克隆仓库
git clone https://github.com/raishs/perplexityhackathon.git
cd perplexityhackathon

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env.local
```

<div id="configuration">
  ## 配置
</div>

创建 `.env.local` 文件：

```ini theme={null}
PERPLEXITY_API_KEY=your_perplexity_api_key
```

<div id="usage">
  ## 使用方法
</div>

1. **启动开发服务器**：
   ```bash theme={null}
   npm run dev
   ```

2. **访问应用**：在浏览器中打开 [http://localhost:3000](http://localhost:3000)

3. **生成情报**：
   * 在输入框中输入公司名称
   * 点击“Competitive Analysis”生成完整的竞争分析简报
   * 使用“情景规划”进行“假设情景”分析
   * 打开“基准对标”进行同业对标
   * 将报告保存到“Board Pack”，方便日后查看

4. **Board Pack 管理**：点击“📁 Board Pack”按钮，查看和管理已保存的情报报告

<div id="code-explanation">
  ## 代码说明
</div>

* **前端**：采用 Next.js 搭配 Typescript 和 React，构建现代化的响应式界面
* **后端**：使用 Next.js API 路由处理 Perplexity Sonar API 集成
* **AI 集成**：借助 Perplexity Sonar Pro 实现实时竞争情报与情景分析
* **状态管理**：使用 React Context 实现董事会记忆与持久化数据存储
* **Markdown 处理**：通过自定义工具解析 AI 响应并处理引用
* **错误处理**：针对 API 调用的完善超时与错误管理机制
* **专业输出**：结构化排版，生成可直接用于董事会的内容，并附带来源引用
