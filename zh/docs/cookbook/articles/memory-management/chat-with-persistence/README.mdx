  # 使用 Perplexity Sonar API 实现持久化对话记忆
</div>

<div id="overview">
  ## 概述
</div>

本实现展示如何利用 LlamaIndex 的向量存储与 Perplexity 的 Sonar API 保留长期对话记忆，通过智能检索与摘要在多次 API 调用之间维持上下文。

<div id="key-features">
  ## 核心特性
</div>

* **多轮上下文保持**：记住此前的提问与回复
* **语义检索**：借助向量嵌入查找相关的历史对话
* **Perplexity 集成**：使用 Sonar-pro 模型生成准确回复
* **LanceDB 存储**：基于列式向量数据库持久化保存对话历史

<div id="implementation-details">
  ## 实现细节
</div>

<div id="core-components">
  ### 核心组件
</div>

```python theme={null}
# 初始化记忆
vector_store = LanceDBVectorStore(uri="./lancedb", table_name="chat_history")
storage_context = StorageContext.from_defaults(vector_store=vector_store)
index = VectorStoreIndex([], storage_context=storage_context)
```

<div id="conversation-flow">
  ### 对话流程
</div>

1. 将用户查询存储为向量嵌入
2. 检索最相关的 3 条历史交互
3. 结合上下文历史生成 Sonar API 请求
4. 持久化保存响应，供后续对话使用

<div id="api-integration">
  ### API 集成
</div>

```python theme={null}
# 携带对话上下文的 Sonar API 调用
messages = [
    {"role": "system", "content": f"Context: {context_nodes}"},
    {"role": "user", "content": user_query}
]
response = sonar_client.chat.completions.create(
    model="sonar-pro",
    messages=messages
)
```
