<div id="memory-management-with-llamaindex-and-perplexity-sonar-api">
  # 使用 LlamaIndex 与 Perplexity Sonar API 实现记忆管理
</div>

<div id="overview">
  ## 概述
</div>

本文探讨在大语言模型 (LLM) 驱动的应用中保留对话记忆的进阶方案。目标是通过在多次交互之间延续上下文来实现连贯的多轮对话，即便受限于模型的 token 上限也依然如此。

<div id="problem-statement">
  ## 问题描述
</div>

LLM 的上下文窗口有限，难以维持长期的对话记忆。若缺乏妥善的记忆管理机制，后续追问可能会偏离主题，甚至凭空生成与上下文无关的答案。

<div id="approaches">
  ## 方案
</div>

我们基于 LlamaIndex 实现了两种不同的策略来解决这一问题：

<div id="1-chat-summary-memory-buffer">
  ### 1. **对话摘要记忆缓冲区**
</div>

* **目标**：对较早的消息进行摘要，在保留关键上下文的同时不超出 token 上限。
* **方法**：
  * 使用 LlamaIndex 的 `ChatSummaryMemoryBuffer` 动态截断并摘要对话历史。
  * 确保早期交互中的关键细节以精简形式得以保留。
* **适用场景**：非常适合对记忆效率要求较高的短期对话。
* **实现**：[查看完整指南 →](/zh/docs/cookbook/articles/memory-management/chat-summary-memory-buffer/README)

<div id="2-persistent-memory-with-lancedb">
  ### 2. **基于 LanceDB 的持久化记忆**
</div>

* **目标**：实现跨会话的长期记忆持久化。
* **方法**：
  * 将对话历史以向量嵌入的形式存储在 LanceDB 中。
  * 通过语义搜索和元数据过滤检索相关的历史上下文。
  * 集成 Perplexity 的 Sonar API，基于检索到的上下文生成回复。
* **适用场景**：适合需要长期保留记忆并进行上下文回溯的应用。
* **实现**：[查看完整指南 →](/zh/docs/cookbook/articles/memory-management/chat-with-persistence/README)
