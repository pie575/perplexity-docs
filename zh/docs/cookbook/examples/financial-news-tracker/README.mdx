<div id="financial-news-tracker">
  # 财经新闻追踪器
</div>

一款命令行工具，借助 Perplexity 的 Sonar API 获取并分析实时财经新闻。针对任意金融话题，提供全面的市场洞察、新闻摘要与投资分析。

<div id="features">
  ## 功能特性
</div>

* 多源实时聚合财经新闻
* 市场情绪分析 (看涨/看跌/中性) 
* 新闻影响程度评估 (高/中/低) 
* 行业与公司专项分析
* 投资洞察与建议
* 时间范围可自定义 (24 小时至 1 年) 
* 支持结构化 JSON 输出
* 美观的命令行输出，辅以表情符号增强可读性

<div id="tips-for-best-results">
  ## 获得最佳效果的技巧
</div>

1. **描述具体**：包含公司股票代码、行业名称或特定事件
2. **组合主题**：将公司名称与相关主题搭配 (例如“TSLA 电动汽车”) 
3. **善用时间范围**：让时间范围与你的投资周期相匹配
4. **定期监控**：配置 cron 定时任务，获取每日市场动态

<div id="python-integration">
  ### Python 集成
</div>

```python theme={null}
import subprocess
import json

def get_financial_news(query, time_range="24h"):
    result = subprocess.run(
        ["./financial_news_tracker.py", query, "--time-range", time_range, "--json"],
        capture_output=True,
        text=True
    )
    
    if result.returncode == 0:
        return json.loads(result.stdout)
    else:
        raise Exception(f"Error fetching news: {result.stderr}")

# 使用示例
news = get_financial_news("tech stocks", "1w")
print(f"Market sentiment: {news['market_analysis']['market_sentiment']}")
```
