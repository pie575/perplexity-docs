<div id="equity-research-brief">
  # 股票研究简报
</div>

这是一个命令行工具，可利用 Perplexity 的 [Agent API](https://docs.perplexity.ai/docs/agent-api/quickstart) 和内置的 [`finance_search`](https://docs.perplexity.ai/docs/agent-api/tools/finance-search) 工具，为任意上市公司股票代码生成结构化的股票研究简报。

`finance_search` 会返回结构化的市场数据——行情报价、财务数据、财报电话会议记录、同业对比、分析师预测——让模型能够写出以数据为支撑的报告，而不只是泛泛的文字描述。该工具专为智能体式投研工作流而打造。

<div id="features">
  ## 功能
</div>

* 一条命令即可生成包含 6 个部分的简报：概览、业务综述、财务走势、最新财报、同业对比、风险、结论
* 使用 Agent API 的 `finance_search` 工具获取结构化基本面数据、报价和财报电话会议记录
* 三种预设配置，与官方 `finance_search` 建议保持一致：
  * `quote` — 仅获取实时价格/报价，速度最快、成本最低
  * `single` — 单一公司历史数据查询，附带网页上下文
  * `research` — 完整的多步骤跨公司简报 (默认) 
* 在简报旁输出可直接引用的 Perplexity 财经来源链接
* 报告 `finance_search` 的调用次数和请求总成本
* `--json` 标志会输出 Agent API 的原始响应，供下游流程使用

<div id="prerequisites">
  ## 前提条件
</div>

* Python 3.9+
* 一个具备 Agent API 访问权限的 Perplexity API 密钥。`finance_search` 目前处于 beta 阶段，可用性详见 [金融搜索 文档](https://docs.perplexity.ai/docs/agent-api/tools/finance-search)。

<div id="configuration-reference">

</div>

| 配置         | 模型                          | 工具                                            | 最大步数 | 适用场景         |
| ---------- | --------------------------- | --------------------------------------------- | ---- | ------------ |
| `quote`    | `perplexity/sonar`          | `finance_search`                              | 1    | 实时价格与报价，路径最快 |
| `single`   | `openai/gpt-5.5`            | `web_search` + `finance_search` + `fetch_url` | 5    | 单家公司的历史基本面   |

这些配置直接取自 [`finance_search` 推荐配置](https://docs.perplexity.ai/docs/agent-api/tools/finance-search)。

<div id="code-walkthrough">
  ## 代码详解
</div>

该脚本完成三件事:

**1. 发起一次启用 `finance_search` 的 Agent API 调用。**

```python theme={null}
from perplexity import Perplexity

client = Perplexity()
response = client.responses.create(
    model="anthropic/claude-opus-4-7",
    instructions=SYSTEM_PROMPT,
    input=BRIEF_TEMPLATE.format(ticker="NVDA"),
    tools=[
        {"type": "web_search"},
        {"type": "finance_search"},
        {"type": "fetch_url"},n    ],
    max_output_tokens=4096,
    max_steps=10,
)
```

模型会根据提示词自行决定获取哪些 `finance_search` 类别 (报价、财务数据、财报电话会议记录等) ，无需你手动挑选字段。

**2. 遍历 `response.output`，同时提取助手文本和结构化的 `finance_results` 数据块。**

```python theme={null}
for item in response.output:
    if item.type == "finance_results":
        for r in item.results:
            print(r.category, r.tickers, r.sources)
    elif item.type == "message":
        for block in item.content:
            if block.type == "output_text":
                print(block.text)
```

**3. 在正文旁一并呈现成本与财经来源 URL。** `result.sources` 中返回的 Perplexity 财经页面是稳定、可直接引用的链接——无论该简报是供人阅读，还是交给下游 RAG 流水线处理，都很有价值。

<div id="prompting-guidance">
  ## 提示词指导
</div>

当提示词要求的是业务结论、而非特定的数据格式时，`finance_search` 效果最佳。系统提示词会指示模型：

* 表述要量化，并将数字对应到正确的期间 (例如 `FY2025`、`Q3 FY26`) 
* 绝不臆造数字——如果 `finance_search` 未返回某个字段，要明确说明
* 以整洁的 Markdown 格式输出

该模式详见 [finance&#95;search 提示词指导](https://docs.perplexity.ai/docs/agent-api/tools/finance-search#prompt-guidance)。

<div id="pricing">
  ## 定价
</div>

`finance_search` 按 **每 1,000 次调用 $5** 计费，与模型 token 用量分开计算。各 preset 的成本特征不同：

* `quote`：通常 1 次调用，每份简报约 $0.007
* `single`：1–3 次调用 + GPT-5.5 token
* `research`：3–6 次调用 + Claude Opus token

最新费率请参见 [Perplexity 定价](https://docs.perplexity.ai/docs/getting-started/pricing)。

<div id="limitations">
  ## 限制
</div>

* `finance_search` 目前处于 beta 阶段，可能并未在所有 API 密钥 上启用
* 结果取决于 Perplexity 的金融数据覆盖范围；冷门或非美股代码返回的数据结构化程度可能较低
* 本内容不构成投资建议。“结论”部分明确定位为分析性观点，而非投资推荐
