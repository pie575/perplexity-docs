<div id="disease-information-app">
  # 疾病信息应用
</div>

一个基于浏览器的交互式应用，借助 Perplexity 的 Sonar API 提供结构化的疾病信息。该应用会生成一个独立的 HTML 界面，用户可以就各种疾病提问，并获得条理清晰、附带引用来源的回答。

<div id="features">
  ## 🌟 功能特性
</div>

* **友好的用户界面**：简洁的响应式设计，适配各类设备
* **AI 驱动的回答**：借助 Perplexity 的 Sonar API 提供准确的医学信息
* **结构化知识卡片**：将信息整理为概述、病因和治疗方案三部分
* **引用来源追踪**：列出信息来源，并提供可点击的链接
* **客户端缓存**：避免对已提问过的问题重复调用 API
* **独立部署**：生成单个 HTML 文件，无需服务器即可使用
* **完善的错误处理**：友好的错误提示与稳健的错误管理机制

<div id="requirements">
  ## 📋 环境要求
</div>

* Python 3.6+
* Jupyter Notebook 或 JupyterLab (用于开发/生成) 
* 所需依赖包：
  * requests
  * pandas
  * python-dotenv
  * IPython

<div id="setup-installation">
  ## 🚀 设置与安装
</div>

1. 克隆本仓库或直接下载该 notebook
2. 安装所需的软件包：

```bash theme={null}
# 从 requirements 文件安装（推荐）
pip install -r requirements.txt

# 或手动安装
pip install requests pandas python-dotenv ipython
```

3. 配置你的 Perplexity API key：
   * 在 notebook 所在目录下创建一个 `.env` 文件
   * 添加你的 API key：`PERPLEXITY_API_KEY=your_api_key_here`

<div id="usage">
  ## 🔧 使用方法
</div>

<div id="running-the-notebook">
  ### 运行 Notebook
</div>

1. 在 Jupyter 中打开该 notebook：

```bash theme={null}
jupyter notebook Disease_Information_App.ipynb
```

2. 运行所有单元格，生成并启动基于浏览器的应用
3. 应用会自动在你的默认浏览器中打开

<div id="using-the-generated-html">
  ### 使用生成的 HTML
</div>

你也可以直接使用生成的 `disease_qa.html` 文件：

1. 在任意现代浏览器中打开该文件
2. 输入关于某种疾病的问题 (例如：&quot;What is diabetes?&quot;、&quot;Tell me about Alzheimer&#39;s disease&quot;) 
3. 点击 &quot;Ask&quot;，即可获得该疾病的结构化信息

<div id="deploying-the-app">
  ### 部署应用
</div>

如果是个人或教学用途，直接分享生成的 HTML 文件即可。

如果用于生产环境，请考虑以下几点：

1. 搭建合适的后端，以保护你的 API key
2. 将文件托管到 Web 服务器上
3. 按需添加分析统计和用户管理功能

<div id="how-it-works">
  ## 🔍 工作原理
</div>

本应用会：

1. 使用精心设计的提示词，指示 AI 输出结构化 JSON
2. 解析该 JSON，提取概述、病因、治疗方案和引用来源
3. 以简洁的知识卡片形式呈现信息
4. 在客户端发起 API 调用，并做好错误处理
5. 提供适配桌面端与移动端的响应式设计

<div id="technical-details">
  ## ⚙️ 技术细节
</div>

<div id="api-structure">
  ### API 结构
</div>

该应用期望 AI 返回如下结构的 JSON 对象：

```json theme={null}
{
  "overview": "A brief description of the disease.",
  "causes": "The causes of the disease.",
  "treatments": "Possible treatments for the disease.",
  "citations": ["https://example.com/citation1", "https://example.com/citation2"]
}
```

<div id="files-generated">
  ### 生成的文件
</div>

* `disease_qa.html` - 独立应用程序
* `disease_app.log` - 详细的应用日志 (运行 notebook 时生成)

<div id="customization-options">
  ### 自定义选项
</div>

你可以修改：

* `create_html_ui` 函数中的 HTML/CSS 样式
* 使用的 AI 模型 (默认为 “sonar-pro”) 
* 针对不同信息字段的提示词结构
* 输出文件的位置和命名

<div id="extending-the-app">
  ## 🛠️ 扩展应用
</div>

可能的扩展方向：

* 添加 Flask/Django 后端，以保护 API key
* 实现用户账户与问题收藏功能
* 添加疾病统计数据可视化
* 创建多种疾病的对比视图
* 添加自然语言问题改写功能
* 实现答案质量反馈机制

<div id="important-notes">
  ## ⚠️ 重要提示
</div>

* **API key 安全**：当前实现会将 API key 直接嵌入 HTML 文件，仅适合个人使用，不适合公开部署。
* **非医疗建议**：本应用仅提供一般性信息，不应作为医疗决策依据。如需医疗建议，请务必咨询专业医护人员。
* **API 使用**：请留意你账户的 Perplexity API 速率限制与计费情况。
