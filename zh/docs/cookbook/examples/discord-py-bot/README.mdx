一个简单的 `discord.py` 机器人，可将 [Perplexity 的 Sonar API](https://docs.perplexity.ai/) 集成到你的 Discord 服务器中。通过斜杠命令或 @ 提及该机器人即可提问，获得联网检索支持的 AI 回答。

<img src="https://mintcdn.com/perplexity/y2ljsQXTUHXyDIEa/docs/cookbook/static/img/discord-py-bot-demo.png?fit=max&auto=format&n=y2ljsQXTUHXyDIEa&q=85&s=af7e57165646fd8bff36ad04c0d22635" alt="Discord Bot Demo" />

<div id="features">
  ## ✨ 功能特性
</div>

* **🌐 联网 AI**：使用 Perplexity 的 Sonar API 获取实时信息
* **⚡ 斜杠命令**：使用简单的 `/ask` 命令提问
* **💬 支持 @ 提及**：@ 机器人即可提问
* **🔗 来源引用**：自动格式化并附上来源链接
* **🔒 安全配置**：基于环境变量管理 API key

<div id="prerequisites">
  ## 🛠️ 前置条件
</div>

<Steps>
  <Step title="Python 环境">
    系统中已安装 **Python 3.8+**

    ```bash theme={null}
    python --version  # 应为 3.8 或更高版本
    ```
  </Step>

  <Step title="Perplexity API 访问权限">
    在 [Perplexity API 平台控制台](https://console.perplexity.ai) 获取的**有效 Perplexity API key**

    <Note>访问该 API 需要付费的 Perplexity 账户。最新费率请参见[定价页面](https://www.perplexity.ai/pricing)。</Note>
  </Step>

  <Step title="Discord 机器人应用">
    在 [Discord 开发者门户](https://discord.com/developers/applications) 获取的 **Discord Bot Token**
  </Step>
</Steps>

<div id="quick-start">
  ## 🚀 快速开始
</div>

<div id="1-repository-setup">
  ### 1. 仓库设置
</div>

克隆仓库并进入 bot 目录：

```bash theme={null}
git clone https://github.com/ppl-ai/api-cookbook.git
cd api-cookbook/docs/examples/discord-py-bot/
```

<div id="2-install-dependencies">
  ### 2. 安装依赖
</div>

```bash theme={null}
# 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Windows 上：venv\Scripts\activate

# 安装所需依赖包
pip install -r requirements.txt
```

<div id="3-configure-api-keys">
  ### 3. 配置 API key
</div>

<Steps>
  <Step title="获取 Perplexity API key">
    1. 访问 [Perplexity API 平台控制台](https://console.perplexity.ai)
    2. 生成一个新的 API key
    3. 将该密钥复制到 .env 文件中

    <Warning>请妥善保管你的 API key！切勿将其提交到版本控制或公开分享。</Warning>
  </Step>

  <Step title="创建 Discord 机器人应用">
    1. 前往 [Discord 开发者门户](https://discord.com/developers/applications)
    2. 点击 **“New Application”**，并为其取一个含义明确的名称
    3. 进入 **“Bot”** 板块
    4. 点击 **“Reset Token”** (首次创建则点击 “Add Bot”) 
    5. 复制机器人的 token
  </Step>

  <Step title="配置环境变量">
    复制示例环境文件，并填入你的密钥：

    ```bash theme={null}
    cp env.example .env
    ```

    在 `.env` 中填写你的凭据：

    ```bash title=".env" theme={null}
    DISCORD_TOKEN="your_discord_bot_token_here"
    PERPLEXITY_API_KEY="your_perplexity_api_key_here"
    ```
  </Step>
</Steps>

<div id="usage-guide">
  ## 🎯 使用指南
</div>

<div id="bot-invitation-setup">
  ### 邀请机器人与设置
</div>

<Steps>
  <Step title="生成邀请链接">
    在 Discord 开发者门户 中：

    1. 前往 **OAuth2** → **URL Generator**
    2. 选择作用域：`bot` 和 `applications.commands`
    3. 选择机器人权限：`Send Messages`、`Use Slash Commands`
    4. 复制生成的 URL
  </Step>

  <Step title="邀请至服务器">
    1. 在浏览器中打开该 URL
    2. 选择要添加机器人的 Discord 服务器
    3. 确认权限
  </Step>

  <Step title="启动机器人">
    ```bash theme={null}
    python bot.py
    ```

    此时应能看到输出，提示机器人已上线且命令已同步。
  </Step>
</Steps>

<div id="response-format">
  ## 📊 响应格式
</div>

该机器人提供简洁、易读的响应，包含：

* **AI 回答**：来自 Perplexity Sonar API 的直接回复
* **来源引用**：可点击的来源链接 (如有) 
* **自动截断**：响应会被裁剪，以符合 Discord 的长度限制

<div id="technical-details">
  ## 🔧 技术细节
</div>

该机器人使用：

* **模型**：Perplexity 的 `sonar-pro` 模型
* **响应上限**：API 返回 2000 个 token，并截断以适配 Discord
* **Temperature**：0.2，以获得稳定、准确的回复
* **无权限限制**：服务器中的任何人都可以使用该机器人
