<div id="api-key-setup">
  ## API key 设置
</div>

所有示例都需要 Perplexity API key。请将其设置为环境变量：

```bash theme={null}
export PERPLEXITY_API_KEY="your-api-key-here"
```

<Tip>
  前往 [perplexity.ai/account/api](https://perplexity.ai/account/api) 获取你的 API key。
</Tip>

<div id="common-requirements">
  ## 通用要求
</div>

* **Python 3.9+** 或 **Node.js 18+** (视具体示例而定)
* **Perplexity API key**
* 可用于发起 API 调用的**网络连接**

其他要求因示例而异，详见各项目的文档。
