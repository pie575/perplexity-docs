<div id="daily-knowledge-bot">
  # 每日知识机器人
</div>

一个 Python 应用，借助 Perplexity AI API 每天围绕不同主题推送有趣的知识。非常适合日常学习、简报内容或个人自学。

<div id="features">
  ## 🌟 功能特性
</div>

* **每日主题轮换**：根据当月日期自动选择主题
* **AI 驱动的知识点**：使用 Perplexity 的 Sonar API 生成有趣且准确的知识点
* **主题可自定义**：轻松扩展或修改主题列表
* **持久化存储**：将知识点保存为按日期命名的文本文件，便于日后查阅
* **健全的错误处理**：从容应对 API 故障和意外错误
* **可配置**：通过环境变量安全管理 API key

<div id="requirements">
  ## 📋 环境要求
</div>

* Python 3.6+
* 所需依赖包：
  * requests
  * python-dotenv
  *  (可选) logging

<div id="installation">
  ## 🚀 安装
</div>

1. 克隆本仓库或下载脚本
2. 安装所需依赖包：

```bash theme={null}
# 从 requirements 文件安装（推荐）
pip install -r requirements.txt

# 或手动安装
pip install requests python-dotenv
```

3. 配置你的 Perplexity API key：
   * 在脚本所在目录下创建一个 `.env` 文件
   * 添加你的 API key：`PERPLEXITY_API_KEY=your_api_key_here`

<div id="usage">
  ## 🔧 使用方法
</div>

<div id="running-the-bot">
  ### 运行机器人
</div>

直接执行脚本即可：

```bash theme={null}
python daily_knowledge_bot.py
```

此操作将：

1. 根据当前日期选择一个主题
2. 从 Perplexity AI 获取一条有趣的知识
3. 将该知识保存到当前目录下以日期命名的文本文件中
4. 在控制台中输出该知识

<div id="customizing-topics">
  ### 自定义主题
</div>

编辑 `topics.txt` 文件 (每行一个主题) ，或直接在脚本中修改 `topics` 列表。

示例主题：

```
天文学
历史
生物学
科技
心理学
海洋生物
古代文明
量子物理学
艺术史
烹饪科学
```

<div id="automated-scheduling">
  ### 自动定时调度
</div>

<div id="on-linuxmacos-using-cron">
  #### 在 Linux/macOS 上 (使用 cron) ：
</div>

```bash theme={null}
# 编辑 crontab
crontab -e

# 添加以下这行，使其每天上午 8:00 运行
0 8 * * * /path/to/python3 /path/to/daily_knowledge_bot.py
```

<div id="on-windows-using-task-scheduler">
  #### 在 Windows 上 (使用任务计划程序) ：
</div>

1. 打开任务计划程序
2. 新建一个基本任务
3. 将其设置为每天运行
4. 添加操作：启动程序
5. 程序/脚本：`C:\path\to\python.exe`
6. 参数：`C:\path\to\daily_knowledge_bot.py`

<div id="configuration-options">
  ## 🔍 配置选项
</div>

可在 `.env` 文件中设置以下环境变量：

* `PERPLEXITY_API_KEY` (必填) ：你的 Perplexity API key
* `OUTPUT_DIR` (可选) ：保存知识文件的目录 (默认为当前目录) 
* `TOPICS_FILE` (可选) ：自定义主题文件的路径

<div id="extending-the-bot">
  ## 🛠️ 扩展机器人
</div>

扩展这个机器人的一些思路：

* 添加邮件或短信推送能力
* 创建查看历史知识的 Web 界面
* 集成社交媒体自动发布
* 为知识内容配上多媒体素材
* 实现高级调度，在特定日期推送特定主题

<div id="limitations">
  ## ⚠️ 限制
</div>

* 视你的 Perplexity 账户情况,可能会受到 API 速率限制
* 事实内容的准确性取决于所使用的 AI model
* 免费版 Sonar API 存在 token 上限,可能会截断较长的响应
