<div id="quick-start">
  ## 快速开始
</div>

<Steps>
  <Step title="获取 API 访问权限">
    使用 Perplexity API 平台需要一个 API key。如果你还没有：

    <Card title="获取你的 Perplexity API Key" icon="key" arrow="True" horizontal="True" iconType="solid" cta="点击这里" href="https://perplexity.ai/account/api">
      在 API 门户中打开 **API Keys** 标签页，生成一个新的 key。
    </Card>
  </Step>

  <Step title="安装 SDK">
    Perplexity API SDK 提供 Python 和 TypeScript 两个版本，请安装你所用语言对应的包：

    <CodeGroup>
      ```bash Python theme={null}
      pip install perplexityai
      ```

      ```bash TypeScript theme={null}
      npm install @perplexity-ai/perplexity_ai
      ```
    </CodeGroup>
  </Step>

  <Step title="选择起点">
    Perplexity API 平台通过多个 API 支持各种各样的使用场景。以下是针对不同目标推荐的几个起点：

    * 初次接触该平台？请参阅 <u>[快速开始指南](/zh/docs/getting-started/quickstart)</u>
    * 想动手构建点什么？不妨看看我们的 <u>[示例](/zh/docs/cookbook/examples/README)</u>
  </Step>
</Steps>
