<div id="data-privacy-retention">
  ## 数据隐私与留存
</div>

<div id="zero-data-retention-policy">
  ### 零数据留存政策
</div>

Perplexity 对 Chat Completions API 实行严格的**零数据留存政策**。我们不会保留通过 Chat Completions API 发送的数据，也不会将客户数据用于训练模型，或用于处理当前请求之外的任何其他用途。

<div id="data-we-collect">
  ### 我们收集的数据
</div>

我们通过 Chat Completions API 收集的数据仅限于服务运行所必需的计费指标：

* 处理的 token 数量
* 每个请求使用的 model
* 请求时间戳和耗时
* API key 标识 (用于计费) 

这些计费元数据不包含您的提示词、响应内容或其他任何用户数据。
