<Update label="August 2026" tags={["Agent API", "Presets"]}>
  **preset 的提示缓存**

  Agent API 的 preset 现在会自动使用稳定的提示缓存键，使用同一 preset 的各个独立请求可以复用共享的提示前缀 (system prompt 和工具定义) 。无需修改请求；若显式指定 `prompt_cache_key`，仍会覆盖 preset 的默认值。对于频繁使用 preset 的应用，这可将成本降低约 5%，具体取决于缓存利用率。[当前 preset 取值](/zh/docs/agent-api/presets#current-preset-values)中列出了各冻结配置对应的键。
</Update>

<Update label="July 2026" tags={["Agent API", "Presets"]}>
  **研究类 preset 支持行内引用**

  Agent API 的搜索支撑型 preset 均包含行内引用：`fast` 对源自搜索结果的论断使用编号引用 (如 `[1]`) ，而 `low`、`medium` 和 `high` 现在会对源自工具结果或所提供来源材料的论断使用带来源类型的引用 (如 `[web:1]`) 。工具调用成功后，`low`、`medium` 和 `high` preset 会在最终回答中至少包含一条引用。[当前 preset 取值](/zh/docs/agent-api/presets#current-preset-values)中列出了冻结配置所用的 system prompt。
</Update>

<Update label="July 2026" tags={["MCP", "Agent API"]}>
  **MCP 服务器 1.0：现由 Agent API 提供支持**

  [Perplexity MCP 服务器](/zh/docs/getting-started/integrations/mcp-server) v1.0.0 将其依赖模型的工具从旧版 Sonar 模型迁移到 [Agent API preset](/zh/docs/agent-api/presets)：`perplexity_ask` 使用 `fast` preset，`perplexity_reason` 使用 `medium`，`perplexity_research` 使用 `high`。工具名称与响应结构保持不变，三个工具的平均速度较此前的 Sonar 版本更快、成本更低。长时间运行的研究任务现在会向主动请求进度的 MCP 客户端流式推送进度，取消 MCP 请求也会一并取消底层运行。

  工具 schema 中已移除 `strip_thinking` 与 `reasoning_effort` 参数 (Agent API 不输出 think 标签，推理强度由 preset 管理) ；对仍在发送这些参数的客户端会做兼容处理，直接忽略。
</Update>

  **新功能：智能视觉内容的媒体分类器**

  我们很高兴推出 **媒体分类器**——它能自动识别哪些查询可从视觉内容中受益，并在响应中附上相关图片或视频。

  **核心能力：**

  * **自动识别**：分析查询，判断何时加入视觉内容更有价值
  * **智能媒体选择**：根据查询类型智能选择图片、视频或两者兼有
  * **上下文感知**：非常适合教育类内容、地理类查询、流程说明与演示场景
  * **可配置控制**：可按需启用/禁用并覆盖媒体类型

  媒体分类器仅在 `sonar-pro` 上可用，能为视觉概念、地点、分步流程和教育类内容带来更佳的响应效果。[了解更多 →](/zh/docs/sonar/media)

  **Search API 增强**

  我们对 Search API 做了多项改进：

  * **新增 `max_tokens` 参数**：控制搜索结果中每个页面提取的最大 token 数，让你更精细地掌控响应体积与成本。[了解更多 →](/zh/docs/search/quickstart)
  * **支持 `last_updated_filter`**：除发布日期外，还可按内容最后更新时间筛选搜索结果，非常适合查找最新信息。[了解更多 →](/zh/docs/search/filters/date-time-filters)
  * **支持 Vercel AI SDK**：Search API 现已兼容 Vercel AI SDK，让你能以框架无关的方式基于 Perplexity 进行构建。[了解更多 →](https://ai-sdk.dev/tools-registry/perplexity-search)
