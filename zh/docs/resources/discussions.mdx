<div id="developer-resources">
  ## 开发者资源
</div>

<Steps>
  <Step title="报告问题">
    发现 Bug？欢迎提交详细的 Bug 报告，帮助我们改进。

    在[社区论坛](https://community.perplexity.ai/)发布新帖，并添加 `Bug Reports` 标签。
  </Step>

  <Step title="分享你的成果">
    用 Perplexity API 做出了有意思的东西？我们很乐意展示你的作品。

    * 为我们的 [API Cookbook](https://github.com/perplexityai/api-cookbook) 贡献内容
    * 在 X/Twitter 上分享并 @ [@perplexitydevs](https://twitter.com/perplexitydevs)
    * 在我们的月度开发者展示活动中进行演示
  </Step>

  <Step title="获得推荐展示">
    出色的项目有机会登上我们的新闻通讯、博客、社交媒体渠道以及 [Cookbook 社区展示](/zh/docs/cookbook/showcase/briefo)。

    <Tip>
      分享你的项目详情和应用场景，可以提高获得推荐展示的机会。
    </Tip>
  </Step>
</Steps>
