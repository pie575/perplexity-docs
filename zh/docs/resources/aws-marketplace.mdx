Perplexity API 平台已作为 SaaS 商品页在 AWS Marketplace 上架。你可以通过 AWS 账户购买 API 额度——额度会计入你的 Perplexity API 余额，并适用于所有 API (Router、Agent、Search、Sonar 和 Embeddings) 。

<Note>
  该商品面向 **API 平台** (Router API、Agent API、Search API、Sonar 和 Embeddings) ，与 **Enterprise Pro** 属于不同产品，后者不包含 API 访问权限。
</Note>

<div id="why-subscribe-through-aws-marketplace">
  ## 为什么通过 AWS Marketplace 订阅？
</div>

与直接计费相比，通过 AWS Marketplace 购买有以下几项优势：

* **AWS 账单合并** —— 费用与其他 AWS 服务一并计入现有的 AWS 账单，简化财务与会计流程
* **企业采购** —— 满足强制要求通过 AWS Marketplace 采购的组织的采购规范，无需另建供应商关系
* **符合 EDP 资格** —— 采购金额可计入您的 AWS 企业折扣计划 (EDP) 承诺额度
* **简化供应商管理** —— 无需另行维护合同或支付方式，发票由 AWS 统一开具

<div id="pricing">
  ## 价格
</div>

AWS Marketplace 上的 Perplexity API 平台以 **1 个月合约**形式提供，并附带 API 平台额度：

| 方案           |     额度    |  合约期 |
| ------------ | :-------: | :--: |
| **API 平台额度** | 起价 $1,000 | 1 个月 |

额度与美元按 1:1 计价——1 额度 = $1。额度会计入你的账户余额，并随着你发起 API 请求逐步扣减。

<Note>
  所有 Perplexity API 产品——Router API、Agent API、Search API、Sonar 和 Embeddings——都从同一个共享额度池中扣减，无需为每个产品单独设置预算。

  有关按请求和按 token 计费的详细信息，请参阅<u>[价格页面](/zh/docs/getting-started/pricing)</u>。
</Note>

<div id="how-to-subscribe">
  ## 如何订阅
</div>

<Tip>
  额度不会过期——**1 个月合约**指的是计费周期，而非使用期限，因此未用完的额度会继续保留在你的余额中。
</Tip>

1. 访问 AWS Marketplace 上的 <u>[Perplexity API 平台商品页](https://aws.amazon.com/marketplace/pp/prodview-fslss6gnscauq)</u>
2. 点击 **View purchase options**
3. 选择额度金额，然后点击 **Create contract**
4. 确认购买——AWS 会处理该订阅，并通过电子邮件通知你

<div id="getting-started-after-subscribing">
  ## 订阅后的入门步骤
</div>

AWS Marketplace 订阅确认后：

1. **登录或创建账户** — 前往 <u>[console.perplexity.ai](https://console.perplexity.ai)</u>，使用 Perplexity 账户登录 (若尚无账户，请先创建)
2. **关联订阅** — 按照控制台中的提示，将你在 AWS Marketplace 的购买关联到 Perplexity 账户；此操作会把已购额度与你的项目绑定
3. **设置项目** — 额度绑定在某个项目上 (即你的组织在 API Portal 中的工作区) 。完成设置的人将成为 Admin，拥有账单、API key 和成员邀请的完整权限。其他成员可以 Admin (完整权限) 或 Member (仅查看) 身份加入。参见 <u>[项目与账单](/zh/docs/getting-started/projects)</u>。
4. **生成 API key** — 在控制台中进入 API Keys，为项目创建密钥。参见 <u>[API Key 管理](/zh/docs/admin/api-key-management)</u>。
5. **开始发起请求** — 额度会计入项目余额，并在所有产品间共享 (Router API、Agent API、Search API、Sonar、Embeddings) 。你可以随时在控制台中查看剩余余额和使用情况。

<div id="refund-policy">
  ## 退款政策
</div>

如需取消订阅，可在**购买后 14 天内**且**未使用任何额度**的前提下申请退款。申请退款请发送邮件至 <u>[aws-api@perplexity.ai](mailto:aws-api@perplexity.ai)</u>，并附上您的 AWS Marketplace 订单 ID。

<Warning>
  一旦消耗了任何额度，或已超过 14 天期限，将无法退款。
</Warning>
