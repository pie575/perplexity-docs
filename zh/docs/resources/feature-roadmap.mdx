</Info>

<div id="upcoming-and-in-progress">
  ## 即将推出与进行中
</div>

<AccordionGroup>
  <Accordion title="Sandbox API" description="隔离式 Python 和 Bash 执行环境">
    我们即将推出 Sandbox API，提供用于执行 Python 和 Bash 代码的隔离环境。每个 sandbox 均运行在独立容器中，拥有专属资源，支持文件操作、后台进程，并可通过暂停/恢复实现状态持久化。

    * **每个 sandbox 独享容器**，隔离性更强
    * **支持 Python 和 Bash 执行**，并支持文件与进程操作
    * **暂停/恢复状态持久化**，适用于迭代式工作流
  </Accordion>

  <Accordion title="Chat Completions 性能优化" description="降低现有端点的延迟">
    我们正在逐步推出性能改进，同时保持兼容性。

    * **端点契约不变**，向后兼容
    * 针对常见请求模式的**延迟优化**
    * **自动生效**，大多数用户无需迁移
  </Accordion>

  <Accordion title="视频上传功能" description="多模态视频处理">
    我们正在扩展多模态支持，以支持直接上传视频。

    * 对上传文件进行**视频内容分析**
    * **帧级推理**，获取特定时间点的洞察
    * 面向长视频等媒体的**视觉场景理解**
    * 跨文本、图像和视频上下文的**多模态检索**
  </Accordion>

  <Accordion title="文件搜索和连接器" description="扩展数据访问范围">
    我们正在为 API 组织打造更深层的文件与数据源访问能力。

    * **代码库与连接器搜索**：覆盖组织内的各类数据
    * **多格式支持**：支持常见文档类型
    * **外部数据源集成**：面向企业工作流
  </Accordion>

  <Accordion title="异步 API 的 Webhook 支持" description="事件驱动的完成通知">
    我们计划为异步工作流添加 webhook 回调，让长时间运行的任务能够自动通知你的系统。

    * 面向异步请求的**任务完成 webhook**
    * 具备重试安全投递语义的**失败 webhook**
    * 用于安全处理回调的**签名验证**
  </Accordion>

  <Accordion title="模型和 SDK 扩展" description="新的模型功能与 SDK 易用性">
    我们将持续扩展模型覆盖范围，并优化 SDK 的使用体验。

    * **发布更多模型**，并明确生命周期规划
    * 面向 Python 和 TypeScript 的 **SDK 易用性改进**
    * 针对常见集成模式提供**更多生产可用的示例**
  </Accordion>

  <Accordion title="上下文管理与记忆" description="改进跨调用的上下文处理能力">
    我们正在通过改进面向记忆的工作流来解决上下文持久化方面的限制。

    * **会话感知的状态管理**
    * **减少跨请求的手动上下文拼接**
    * **更好地掌控长时间运行的对话式工作流**
  </Accordion>

  <Accordion title="改进错误处理" description="更清晰的故障排查与恢复流程">
    我们正在改进各 API 的错误上报与诊断方式。

    * **更具可操作性的错误信息**
    * **文档中更完善的修复指引**
    * **更清晰的重试与退避建议**
  </Accordion>

  <Accordion title="语音到语音 API" description="实时音频交互">
    我们正在构建面向实时体验的原生语音交互能力。

    * **直接语音输入与流式音频输出**
    * **多语言支持**
    * **低延迟对话循环**
  </Accordion>

  <Accordion title="专属 API 控制台" description="独立的开发者控制台，与 Perplexity 应用相互独立">
    我们正在打造一个专用的 API 控制台——一个独立于 Perplexity 网站的开发者界面。它将成为 API key 管理、用量查看和团队管控的核心入口。

    * **独立于 Perplexity 应用** —— 专为 API 开发者打造
    * **API key 管理**，支持细粒度权限与密钥轮换
    * **用量与成本透视**，可细化到单个 key 和团队层级
    * **组织管控**，用于团队访问与协作
  </Accordion>

  <Accordion title="开发者分析仪表板" description="运营使用情况洞察">
    我们正在为 API 团队提供更全面的分析视图。

    * **查询与延迟分析**
    * **错误趋势监控**
    * **成本与用量预测**
  </Accordion>

  <Accordion title="金融工具集成" description="金融数据与分析">
    我们正在通过更丰富的结构化访问方式扩展金融研究能力。

    * **市场行情与财报文件工作流**
    * **针对金融场景检索的更精细控制**
    * **更多面向分析师场景的端到端示例**
  </Accordion>

  <Accordion title="文档全面更新" description="更高质量的文档与指南">
    文档改进仍在持续进行中。

    * **更清晰的 API 选型指南**
    * **给出明确推荐做法的实现指南**
    * **更贴近真实场景、面向生产环境的示例**
  </Accordion>

  <Accordion title="通过 API 使用 Labs 功能" description="实验性功能">
    我们计划将部分实验性功能开放至开发者预览。

    * **抢先体验功能通道**
    * **用于收集反馈的原型集成**
    * **更快的开发者反馈闭环，助力路线图规划**
  </Accordion>
</AccordionGroup>
