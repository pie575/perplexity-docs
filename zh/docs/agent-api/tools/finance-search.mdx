<div id="overview">
  ## 概览
</div>

`finance_search` 让 model 能够获取上市公司、ETF 及相关金融工具的结构化金融与市场数据。model 会根据你的提示词决定获取哪些字段。

当单次回答需要多种类型的财务数据时 (例如同一家公司或同一批公司的估值、财报和背景信息) ，就可以使用该工具。

<div id="capabilities">
  ### 能力
</div>

| 数据领域       | 涵盖内容                                  |
| ---------- | ------------------------------------- |
| 公司基本信息     | 报价、公司概况、同业公司及市场元数据                    |
| 财务数据       | 利润表、资产负债表、现金流量表 (季度与年度) 、关键财务比率       |
| 估值与价格      | 当前/准实时价格、1 分钟至 1 个月的 OHLCV 区间、盘前与盘后数据 |
| 财报         | 最近一次财报电话会议纪要、监管文件、超预期/不及预期历史、业绩指引讨论   |
| 分部与 KPI 跟踪 | 按分部和地区划分的收入/利润、ARPU、订阅用户数、GMV 及其他经营指标 |
| 分析师覆盖      | 未来收入与每股收益预测、覆盖分析师数量、历史预测调整            |
| 市场动态       | 涨幅榜、跌幅榜及成交最活跃标的                       |
| 持股与公司行动    | 内部人交易、标的层面元数据、拆股及相关市场事件               |
| ETF 与指数详情  | 主要成分股、持股数量、权重及市值                      |

<div id="coverage">
  ## 覆盖范围
</div>

`finance_search` 的覆盖范围取决于代码、交易所、资产类别、地区以及源数据的可用性。

| 覆盖领域          | 当前说明                            |
| ------------- | ------------------------------- |
| **股票代码与符号覆盖** | 可解析出受支持的代码时，涵盖上市公司、ETF 及相关金融工具。 |
| **资产类别**      | 公开市场股票与 ETF。                    |

<Warning>
  部分代码的市场数据可能存在延迟、不完整或无法获取的情况。`finance_search` 仅供信息参考，不构成投资、法律、税务或财务建议。
</Warning>

<div id="quickstart">
  ## 快速开始
</div>

将 `finance_search` 添加到 `tools` 数组中。在不使用 preset、直接指定 `model` 或 `models` 时，请将 `max_steps` 至少设置为 3。若省略该参数，直连模型的默认值为 1 步，不足以初始化并运行 `finance_search`。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      model="openai/gpt-5.6-sol",
      input="What's NVIDIA trading at right now, and what is its current P/E?",
      tools=[
          {"type": "web_search"},
          {"type": "finance_search"}
      ],
      max_steps=3
  )

  for item in response.output:
      if item.type == "message":
          print(item.content[0].text)
  ```

  ```bash cURL theme={null}
  curl -X POST "https://api.perplexity.ai/v1/agent" \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.6-sol",
      "input": "What is NVIDIA trading at right now, and what is its current P/E?",
      "tools": [
        {"type": "web_search"},
        {"type": "finance_search"}
      ],
      "max_steps": 3
    }'
  ```
</CodeGroup>

<div id="example-prompts">
  ## 示例提示词
</div>

* **完整的公司简报：**“给我一份完整的 NVIDIA 概览：估值、最新季度的各业务板块收入，以及管理层对利润率指引的最新表态。”
* **一次请求对比多家公司：**“对比 Apple、Microsoft 和 Alphabet 在最近一个财年的收入增速、营业利润率和预期市盈率。”
* **财报 + 市场反应：**“总结 Tesla 最近一次财报电话会议，包含实际值与市场一致预期的对比，并说明财报发布后股价和分析师目标价的变化情况。”

<div id="prompt-guidance">
  ## 提示词指引
</div>

提示词说明想要的结果、而非数据结构时，`finance_search` 的效果最佳。

* 先提出业务问题，再给出公司名称或股票代码。
* 必要时补充时间范围 (`latest quarter`、`fiscal year to date`、`last 30 days`) 。
* 让工具自行决定检索哪些具体的报表字段。

<div id="recommended-configurations">
  ## 推荐配置
</div>

请根据金融问题的类型选择相应的配置作为起点。

| 配置         | 适用场景               | 延迟 | 质量 | 成本 |
| ---------- | ------------------ | -- | -- | -- |
| 实时行情与报价    | 实时价格、报价和最新数据       | 快  | 良好 | 低  |
| 单一公司历史数据查询 | 单个公司或股票代码的基础历史财务数据 | 均衡 | 高  | 中  |
| 多步骤金融研究    | 跨公司对比与复杂金融分析       | 深入 | 最高 | 高  |

<div id="limits-quotas">
  ## 限制 / 配额
</div>

`finance_search` 使用与其他工具相同的 Agent API 请求流程。具体限制取决于你的账户等级、请求配置以及回答该提示所需的工具调用次数。基于等级的请求限制请参阅[速率限制与使用等级](/zh/docs/admin/rate-limits-usage-tiers#agent-api-rate-limits)。

| 限制方面         | 预期情况                                                                                                           |
| ------------ | -------------------------------------------------------------------------------------------------------------- |
| **API 速率限制** | Agent API 速率限制适用于使用 `finance_search` 的请求。                                                                      |
| **工具调用**     | 模型每调用一次 `finance_search`，即计为一次可计费的工具调用。涉及多家公司或多步骤的提示可能需要多次调用。                                                  |
| **步骤限制**     | 使用直连模型时，请将 `max_steps` 至少设为 3，以便 `finance_search` 完成初始化并运行。若将其与 `web_search`、`fetch_url` 等工具组合用于多步骤请求，请设置更大的值。 |
| **输出限制**     | 大规模对比、长篇文字记录以及跨多年的财务表格可能触及 `max_output_tokens` 或响应截断设置。                                                        |
| **覆盖范围限制**   | 视数据源覆盖范围和数据新鲜度而定，部分代码、交易所、地区、资产类别或字段可能不可用。                                                                     |
