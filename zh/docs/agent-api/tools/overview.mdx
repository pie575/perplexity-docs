工具是把 模型 变成智能体的关键。

仅凭自身，模型 只能依据已有知识作答；有了工具，它就能搜索实时网络、抓取网页、运行代码，或调用你自己的系统。

只需在 `tools` 数组中列出工具即可启用它们。在单次请求内，模型 会运行一个智能体循环：推理、调用工具、观察结果，如此反复，直到能够给出答案。

<div id="three-kinds-of-tools">
  ## 三类工具
</div>

| 类型                                              | 是什么                               | 模型在哪里运行它                     |
| ----------------------------------------------- | --------------------------------- | ---------------------------- |
| 内置工具                                            | Perplexity 托管的能力，通过 `type` 启用。    | 在循环内；由 Perplexity 运行并内联返回结果。 |
| [MCP 服务器](/zh/docs/agent-api/tools/mcp)            | 你自己的远程 MCP 服务器，通过 `type: mcp` 连接。 | 在循环内；模型自动调用其中的工具。            |
| [自定义函数](/zh/docs/agent-api/tools/custom-functions) | 由你控制的函数，使用 JSON Schema 声明。        | 暂停并交回给你；由你执行调用并返回结果。         |

<div id="built-in-tools">
  ## 内置工具
</div>

通过各工具的 `type` 启用。每个工具都有独立的参考页面，其中包含完整的配置项、响应结构和定价信息。

| 工具                                                           | `type`           | 用途                  |
| ------------------------------------------------------------ | ---------------- | ------------------- |
| [Web Search](/zh/docs/agent-api/tools/web-search)               | `web_search`     | 搜索实时网页，支持域名/日期/地区筛选 |
| [Sandbox](/zh/docs/agent-api/tools/sandbox)                     | `sandbox`        | 在隔离容器中运行代码          |
| [Fetch URL Content](/zh/docs/agent-api/tools/fetch-url-content) | `fetch_url`      | 抓取并提取指定 URL 的内容     |
| [Finance Search](/zh/docs/agent-api/tools/finance-search)       | `finance_search` | 获取结构化的金融与市场数据       |
| [People Search](/zh/docs/agent-api/tools/people-search)         | `people_search`  | 查找专业人士与人物信息         |
