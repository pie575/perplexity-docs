<div id="overview">
  ## 概述
</div>

`wide-research` 是用于构建大规模、有证据支撑的资料集合的 preset。只需给它一个类似&quot;找出所有符合 X 条件的公司，并为每一家标注来源&quot;的任务，它就会找出符合条件的实体，为每个实体收集支撑证据，并把结果写入文件供你下载。

这正是 Perplexity 的 [WANDR 基准](https://research.perplexity.ai/articles/wandr-benchmark-evaluating-research-agents-that-must-search-wide-and-deep) (Wide ANd Deep Research) 所衡量的任务形态：既要发现范围广泛的一组条目 (广度) ，又要对每一条深挖到足以为每项论断找到来源 (深度) 。这类研究正是 Agent API 的用武之地——Perplexity 的搜索编排系统在 WANDR 基准中位列第一，而 `wide-research` 把同样的配置封装进了单个 preset。

<div id="quickstart">
  ## 快速开始
</div>

Wide research 运行通常需要运行数分钟，因此请以 `background=true` 提交，再按 id 轮询响应直至其完成，最后下载 agent 生成的文件。

<CodeGroup>
  ```python Python theme={null}
  import time
  from perplexity import Perplexity

  client = Perplexity()

  # 1. 在后台提交
  response = client.responses.create(
      preset="wide-research",
      background=True,
      input=(
          "Find at least 70 US-based companies with a CEO or CFO appointment first "
          "announced between March 1 and April 30, 2026. For each, cite an authoritative "
          "page that names the company and appointee and gives the role and date. Write "
          "the results to results.jsonl, one JSON record per line with fields: "
          "company, appointee, role, announcement_date, url."
      ),
  )

  # 2. 轮询直到运行进入终止状态
  while response.status not in ("completed", "failed", "cancelled", "incomplete"):
      time.sleep(5)
      response = client.responses.retrieve(response.id)

  # 3. 下载本次运行生成的所有文件
  for file in client.responses.files.list(response.id).data:
      client.responses.files.content(
          file_id=file.id, response_id=response.id
      ).write_to_file(file.filename)
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  // 1. 在后台提交
  let response = await client.responses.create({
    preset: 'wide-research',
    background: true,
    input:
      'Find at least 70 US-based companies with a CEO or CFO appointment first ' +
      'announced between March 1 and April 30, 2026. For each, cite an authoritative ' +
      'page that names the company and appointee and gives the role and date. Write ' +
      'the results to results.jsonl, one JSON record per line with fields: ' +
      'company, appointee, role, announcement_date, url.',
  });

  // 2. 轮询直到运行进入终止状态
  while (!['completed', 'failed', 'cancelled', 'incomplete'].includes(response.status)) {
    await new Promise((r) => setTimeout(r, 5000));
    response = await client.responses.retrieve(response.id);
  }

  // 3. 列出本次运行生成的文件，然后按 id 逐个下载
  const files = await client.responses.files.list(response.id);
  for (const file of files.data) {
    console.log(file.id, file.filename, file.bytes);
  }
  ```

  ```bash cURL theme={null}
  # 1. 在后台提交 —— 记录 response id
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "preset": "wide-research",
      "background": true,
      "input": "Find at least 70 US-based companies with a CEO or CFO appointment first announced between March 1 and April 30, 2026. For each, cite an authoritative page that names the company and appointee and gives the role and date. Write the results to results.jsonl, one JSON record per line with fields: company, appointee, role, announcement_date, url."
    }'

  # 2. 按 id 轮询，直到状态为 completed、failed、cancelled 或 incomplete
  curl https://api.perplexity.ai/v1/agent/$RESPONSE_ID \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY"

  # 3. 列出并下载本次运行生成的文件
  curl https://api.perplexity.ai/v1/agent/$RESPONSE_ID/files \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY"

  curl https://api.perplexity.ai/v1/agent/$RESPONSE_ID/files/$FILE_ID/content \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -o results.jsonl
  ```

<div id="how-it-works">
  ## 工作原理
</div>

一次 wide-research 运行包含三个环节，每个环节都有对应的功能页面：

<Steps>
  <Step title="以后台方式提交">
    设置 `preset="wide-research"` 和 `background=true`，并将任务作为 `input` 传入。提交调用会立即返回响应 `id` 和 `queued` 状态；即使客户端断开连接，运行仍会在服务端继续。参见[后台模式](/zh/docs/agent-api/background-mode)。
  </Step>

  <Step title="轮询直至完成">
    通过 `id` 获取响应，直到其 `status` 进入终止状态：`completed`、`failed`、`cancelled` 或 `incomplete`。你也可以实时流式获取运行过程，并在连接中断后重新接入，参见[后台模式](/zh/docs/agent-api/background-mode#stream-and-reconnect)。
  </Step>

  <Step title="下载结果">
    agent 会将资料集合写入 sandbox 中的文件并投递出来，因此它会作为 `share_file` 项出现在响应的 `output` 中。通过响应 `id` 即可列出并下载该文件。参见[文件处理](/zh/docs/agent-api/working-with-files)。
  </Step>
</Steps>

<Tip>
  wide-research 的效果取决于任务描述的精确程度。请给出具体目标 (“至少 70 家公司”) 、明确的筛选规则 (日期、地域、阈值) 、每条记录必须附带的来源，以及清晰的输出形式——指定文件名，并列出每行包含的确切字段。结构化且带引用的输出更易于校验，也更便于下游使用。
</Tip>
