在我们运行的基准测试中，Agent API preset 的单位成本质量优于 Sonar：preset 曲线始终位于所有 Sonar model 之上。
在 BrowseComp、WideSearch 这类高难度的多步骤任务上，领先幅度最为明显——最强的 preset 得分是 Sonar 最佳成绩的两倍以上。

<div id="what-we-measured">
  ## 我们评测了什么
</div>

我们在相同的工作负载下，通过三项基准测试对 Agent API preset 与 Sonar model 进行了评测：

* **[BrowseComp](https://arxiv.org/abs/2504.12516)**：衡量在需要串联多次搜索的高难度问题上的智能体浏览能力。
* **[DSQA (DeepSearchQA) ](https://arxiv.org/abs/2601.20975)**：衡量深度搜索类问题的回答质量。
* **[WideSearch](https://arxiv.org/abs/2508.07999)**：衡量单次运行收集并填充结构化结果的完整程度，以行级 F1 计分。

Agent API preset 甚至能以极低的成本媲美 Sonar 最强的 model——Deep Research。

<div id="which-preset-should-you-use">
  ## 应该使用哪个 preset？
</div>

效果因使用场景而异，但每个 preset 在质量曲线上都高于与之对应的 Sonar 方案——而在深度研究这一档，成本还更低。
可以先参照下表的对应关系，再结合自己的实际流量加以验证。

| Sonar Chat Completions | Agent API preset | 最适合的场景                   | 提升之处                                                   |
| ---------------------- | ---------------- | ------------------------ | ------------------------------------------------------ |
| Sonar                  | `fast`           | 单一事实查询、定义、快速摘要。          | 比 Sonar 更准确，在研究型的多步骤问题上提升最为明显。                         |
| Sonar Pro              | `low`            | 日常研究问题，以及需要最新信息的轻量多步骤查询。 | 准确度大幅提升，并解锁 Sonar Pro 无法企及的真正多步骤智能体式研究。                |
| Sonar Reasoning Pro    | `medium`         | 多跳浏览以及跨大量来源的广泛聚合。        | 在逐步推理以及跨多轮搜索串联证据方面表现强得多。                               |
| Sonar Deep Research    | `high`           | 专家级推理与详尽的来源覆盖。           | 在高难度的专家级与深度研究任务上准确度最高，且单次请求成本通常低于 Sonar Deep Research。 |

<Tip>
  若需业界领先的深度研究能力，请使用 `xhigh` preset——它是整个系列中质量最高的，在我们运行的各项基准测试中均处于领先。
</Tip>
