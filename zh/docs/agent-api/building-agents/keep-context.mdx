---
title: "保留上下文"
description: "在 input 数组中重放对话，实现跨轮次延续会话，让后续提问能够理解先前的内容。"
---

当你需要精确控制发送哪些上下文时，可自行在 `input` 数组中重放对话，例如在发起后续提问前，对之前的轮次进行摘要、脱敏、重排或省略。相关模式与代码示例参见[自行重放对话轮次](/zh/docs/agent-api/conversation-state#replay-conversation-turns-yourself)。

<div id="storage-backed-continuity">
  ## 基于存储的对话延续
</div>

在大多数多轮对话场景中，可使用 `previous_response_id` 从已完成的上一条响应继续，无需自行重新发送整个对话内容。完整指南请参阅[对话状态](/zh/docs/agent-api/conversation-state)。
