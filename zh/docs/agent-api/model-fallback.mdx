---
title: "模型回退"
description: "在回退链中指定多个模型，以提升可用性并实现自动故障转移。"
---

<div id="overview">
  ## 概述
</div>

模型回退 (fallback) 支持在 `models` 数组中指定多个模型。API 会按顺序逐个尝试，直到其中一个成功，从而在某个模型不可用时实现自动故障转移。

<div id="how-it-works">
  ## 工作原理
</div>

提供一个最多包含 5 个 模型 的 `models` 数组：

1. API 首先尝试数组中的第一个 模型
2. 如果该 模型 调用失败或不可用，则尝试下一个
3. 依此类推，直到某个 模型 成功，或所有 模型 均已尝试完毕

同时提供 `models` 数组和单个 `模型` 字段时，以 `models` 数组为准。

<Info>
  **优势：**

  * **更高的可用性**：主 模型 不可用时自动故障转移
  * **提供方冗余**：使用来自不同提供方的 模型，最大限度提升可靠性
  * **无缝运行**：无需重构代码，回退由 API 自动完成
</Info>

<div id="basic-example">
  ## 基础示例
</div>

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.responses.create(
      models=["openai/gpt-5.6-sol", "anthropic/claude-sonnet-4-6", "google/gemini-3-flash-preview"],
      input="Explain the original Transformer architecture from 'Attention Is All You Need' (Vaswani et al. 2017): encoder-decoder structure, multi-head self-attention, and positional encodings.",
      instructions="You have access to a web_search tool. Use it for questions about current events.",
      max_output_tokens=8192,
  )

  print(f"Model used: {response.model}")
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.responses.create({

      input: "Explain the original Transformer architecture from 'Attention Is All You Need' (Vaswani et al. 2017): encoder-decoder structure, multi-head self-attention, and positional encodings.",
      instructions: "You have access to a web_search tool. Use it for questions about current events.",
      max_output_tokens: 8192,
  });

  console.log(`Model used: ${response.model}`);
  ```

  ```bash cURL theme={null}
  curl https://api.perplexity.ai/v1/agent \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "models": ["openai/gpt-5.6-sol", "anthropic/claude-sonnet-4-6", "google/gemini-3-flash-preview"],

      "instructions": "You have access to a web_search tool. Use it for questions about current events.",
      "max_output_tokens": 8192
    }'
  ```

<div id="pricing">
  ## 定价
</div>

<Warning>
  计费依据是实际处理请求的 模型，而非回退链中的所有 模型。
</Warning>

响应中的 `模型` 字段表示实际使用的 模型，`usage` 字段则显示该 模型 的 token 用量。

<Accordion title="示例">
  **请求：**

  ```json theme={null}
  {
    "models": ["openai/gpt-5.6-sol", "openai/gpt-5.4"],
    "input": "..."
  }
  ```

  **响应** (若第一个 模型 调用失败) ：

  ```json theme={null}
  {
    "model": "openai/gpt-5.6-sol",
    "usage": {
      "input_tokens": 150,
      "output_tokens": 320,
      "total_tokens": 470
    }
  }
  ```

  在这种情况下，将按 `gpt-5.1` 的价格对 470 个 token 计费。
</Accordion>

<Tip>
  将首选 模型 放在数组的最前面。排列回退链顺序时，请一并考虑价格差异。
</Tip>
