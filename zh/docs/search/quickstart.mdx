<div id="overview">
  ## 概览
</div>

Perplexity 的 Search API 以结构化数据的形式返回实时、经过排序的网页结果，并支持按域名、语言、地区以及提取内容进行控制。

如果你需要获取原始结果并自行处理，请使用 Search API；如果需要由 LLM 生成、带引用的答案，请使用 [Agent API](/zh/docs/agent-api/quickstart)。

<div id="add-perplexity-search-to-your-agent">
  ## 为你的智能体添加 Perplexity Search
</div>

让你的智能体安装 Perplexity Search 技能：

```text wrap theme={null}
阅读 https://github.com/perplexityai/api-platform-developers/blob/main/skills/pplx-cli/SKILL.md 并安装该技能。
```

你也可以[在交互式 Playground 中试用 Perplexity Search](https://console.perplexity.ai/project/playground/search)，无需 API key。

<Tip>
  现在你可以直接在终端中运行 Perplexity Search。
  [Perplexity CLI](/zh/docs/cli/overview) 会以 JSON 形式返回同样的排序结果，可直接用于 shell 管道和智能体工具调用，无需编写任何代码。
</Tip>

<div id="basic-usage">
  ## 基本用法
</div>

先从一个简单的搜索查询开始，获取相关的网页结果。`max_results` 的取值范围为 1 到 20，默认值为 10。完整参数请参阅 [API 参考](/zh/api-reference/search-post)，搜索费用请参阅[价格](/zh/docs/getting-started/pricing)。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  search = client.search.create(
      query="GPT-5.5 release announcement details",
      max_results=5,
      search_context_size="high"
  )

  for result in search.results:
      print(f"{result.title}: {result.url}")
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const search = await client.search.create({
      query: "GPT-5.5 release announcement details",
      max_results: 5,
      search_context_size: "high"
  });

  for (const result of search.results) {
      console.log(`${result.title}: ${result.url}`);
  }
  ```

  ```javascript JavaScript theme={null}
  const Perplexity = require('@perplexity-ai/perplexity_ai');

  const client = new Perplexity();

  async function main() {
      const search = await client.search.create({
          query: "GPT-5.5 release announcement details",
          max_results: 5,
          search_context_size: "high"
      });

      for (const result of search.results) {
          console.log(`${result.title}: ${result.url}`);
      }
  }

  main();
  ```

  ```bash cURL theme={null}
  curl -X POST 'https://api.perplexity.ai/search' \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H 'Content-Type: application/json' \
    -d '{
      "query": "GPT-5.5 release announcement details",
      "max_results": 5,
      "search_context_size": "high"
    }' | jq
  ```
</CodeGroup>

<div id="regional-web-search">
  ## 按地区进行网络搜索
</div>

将 `country` 设置为 ISO 3166-1 alpha-2 代码 (例如 `US`、`GB`、`DE` 或 `JP`) ，即可获得地域相关性更强的结果。这对本地新闻、法规等特定地区的查询尤其有用：

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  # 搜索来自特定国家/地区的结果
  search = client.search.create(
      query="government policies on renewable energy",
      country="US",  # ISO 国家/地区代码
      max_results=5
  )

  for result in search.results:
      print(f"{result.title}: {result.url}")
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  // 搜索来自特定国家/地区的结果
  const search = await client.search.create({
      query: "government policies on renewable energy",
      country: "US", // ISO 国家/地区代码
      max_results: 5
  });

  for (const result of search.results) {
      console.log(`${result.title}: ${result.url}`);
  }
  ```

  ```bash cURL theme={null}
  curl -X POST 'https://api.perplexity.ai/search' \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H 'Content-Type: application/json' \
    -d '{
      "query": "government policies on renewable energy",
      "country": "US",
      "max_results": 5
    }' | jq
  ```
</CodeGroup>

<div id="domain-filtering-for-search-results">
  ## 搜索结果的域名过滤
</div>

`search_domain_filter` 参数可将搜索结果限定在特定域名 (允许列表) ，或排除某些域名 (拒绝列表) ，从而聚焦研究范围。该过滤器支持两种模式：

* **允许列表模式**：仅包含指定域名 (不加 `-` 前缀)
* **拒绝列表模式**：排除指定域名 (加 `-` 前缀)

你还可以在域名后附加路径，将结果限定在站点的某个板块 (例如 `"nature.com/articles"`) 。有关路径过滤和高级用法，请参阅[域名过滤器指南](/zh/docs/search/filters/domain-filter)。

**注意**：允许列表模式和拒绝列表模式只能二选一，不能在同一个请求中同时使用。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  search = client.search.create(
      query="IPCC AR6 synthesis report key findings",
      search_domain_filter=[
          "science.org",
          "pnas.org",
          "cell.com"
      ],
      max_results=10
  )

  for result in search.results:
      print(f"{result.title}: {result.url}")
      print(f"Published: {result.date}")
      print("---")
  ```

<div id="manual-token-budgets">
  ### 手动 token 预算
</div>

当你需要手动精确控制内容上限，以满足响应大小、返回的 token 总量、评估，或下游上下文窗口与成本管理方面的要求时，可使用 `max_tokens` 和 `max_tokens_per_page`。

* `max_tokens` 限制所有结果中返回的网页内容总量，最多可达 1,000,000 个 token。
* `max_tokens_per_page` 限制从每个结果页面中提取的内容量。

取值越高，返回的提取内容越多；取值越低，返回的内容越短，便于控制响应大小、下游上下文窗口或 token 成本预算。

`search_context_size` 与显式预算的相互作用如下：

* 若 `search_context_size` 和预算参数均未指定，则采用默认的 `search_context_size`。
* 若同时指定了 `max_tokens` 和 `max_tokens_per_page` 但未指定 `search_context_size`，则以这两个预算为准。
* 若只指定了 `max_tokens` 或 `max_tokens_per_page` 其中之一，且未指定 `search_context_size`，则另一个取默认 `search_context_size` 对应的值。
* 同一请求中，`search_context_size` 不能与 `max_tokens` 或 `max_tokens_per_page` 同时使用。
