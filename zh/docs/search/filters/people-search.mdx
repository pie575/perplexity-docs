<Note>
  `search_type` 参数用于在通用网页搜索和专用搜索模式之间切换 Search API 的行为。设置 `search_type="people"` 即可调用 People Search，获取个人的职业信息，如姓名、职位和所属公司。
</Note>

<div id="overview">
  ## 概览
</div>

People Search 让你可以在 Perplexity 的索引中查询专业人士、企业员工和公众人物。适用于应用需要实现以下场景时：

* 查询某个特定人物的职业背景
* 按职能或职位查找某家公司的员工
* 发现特定领域或地区的专业人士
* 调研领导团队或组织架构

在标准的 Search API 请求中传入 `search_type="people"`，即可将查询路由到 People Search 后端。Search API 的其他所有参数 (例如 `max_results`、`max_tokens_per_page`) 依然适用。

<div id="request-example">
  ## 请求示例
</div>

以下示例用于查找特定公司的工程管理层。

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  client = Perplexity()

  response = client.search.create(
      query="Stripe VP of Engineering",
      search_type="people",
      max_results=10
  )

  for result in response.results:
      print(f"{result.title}: {result.url}")
  ```

  ```typescript Typescript theme={null}
  import Perplexity from '@perplexity-ai/perplexity_ai';

  const client = new Perplexity();

  const response = await client.search.create({
      query: "Stripe VP of Engineering",
      search_type: "people",
      max_results: 10
  });

  for (const result of response.results) {
      console.log(`${result.title}: ${result.url}`);
  }
  ```

  ```bash cURL theme={null}
  curl -X POST 'https://api.perplexity.ai/search' \
    -H "Authorization: Bearer $PERPLEXITY_API_KEY" \
    -H 'Content-Type: application/json' \
    -d '{
      "query": "Stripe VP of Engineering",
      "search_type": "people",
      "max_results": 10
    }' | jq
  ```
</CodeGroup>

<div id="query-tips">
  ## 查询技巧
</div>

为获得最佳效果，请在查询中包含可用于识别身份的细节：

| 方式          | 示例查询                                       |
| ----------- | ------------------------------------------ |
| **姓名 + 公司** | “Find John Smith who works at Google”      |
| **职位 + 公司** | “Head of Design at Figma”                  |
| **职位 + 地点** | “Marketing directors in San Francisco”     |
| **职位 + 领域** | “Machine learning researchers at Stanford” |

<Tip>
  如果智能体工作流需要由 model 自主判断何时查找人员，请改用 Agent API 的 [`people_search` 工具](/zh/docs/agent-api/tools/people-search)。若要将 People Search 接入第三方智能体 SDK，请参阅下文的[作为智能体工具使用](#use-as-an-agent-tool)。
</Tip>

<div id="use-as-an-agent-tool">
  ## 作为智能体工具使用
</div>

可以将 People Search 以 `people_search` 函数工具的形式暴露给第三方智能体 SDK——当你希望模型自主决定何时查找人物信息时，这一做法非常有用。下面的接入方式与 [`web_search` 智能体 SDK 集成](/zh/docs/search/agent-sdks/anthropic)一致；把 `people_search` 接入同一个工具调用循环即可，可与 `web_search` 并用，也可完全替代它。

<div id="tool-description">
  ### 工具描述
</div>

请原样保留该描述——正是这样的措辞才能生成高质量、聚焦的查询，并避免 model 在处理常识类问题时误选 People Search。

<CodeGroup>
  ```python Python theme={null}
  PEOPLE_SEARCH_TOOL_DESCRIPTION = """\
  Searches a dedicated index for individual profiles and employee data. Returns information including names, job titles, companies, and profile URLs. Use this tool ONLY when the user specifically wants individual employee lookups, career history, or people who match work-related criteria (e.g., listing employees at a company by location). For general questions about executives, leadership teams, or public figures, prefer search_web instead as it returns richer curated results.

  Best practices:
  - Include the person's name and/or company for targeted results.
  - Add job title or role keywords to narrow results.
  - Use both abbreviations AND full titles for better coverage (e.g., query for both "CTO" and "Chief Technology Officer").
  - Use multiple distinct query variations for broader coverage, varying by role, department, company name, or location.
  - Use up to five queries for complex requests.

  Examples:
    - ["John Smith software engineer Google"]
    - ["CTO Stripe", "Chief Technology Officer Stripe"]
    - ["Perplexity AI engineer SF", "Perplexity product manager", "Perplexity AI designer San Francisco"]
    - ["machine learning researcher Stanford"]"""

  PEOPLE_QUERIES_PARAM_DESCRIPTION = (
      "An array of keyword-based people search queries. Each query should "
      "include names, titles, or companies."
  )
  ```

<div id="handler">
  ### 处理函数
</div>

各 SDK 中的处理函数完全相同——使用 `search_type="people"` 调用 Search API：

<CodeGroup>
  ```python Python theme={null}
  from perplexity import Perplexity

  perplexity = Perplexity()

  def run_people_search(queries: list[str]) -> str:
      """调用 Perplexity People Search，并将结果格式化后交给 model。"""
      response = perplexity.search.create(
          query=queries, search_type="people", max_results=10
      )

      lines = []
      for result in response.results:
          snippet = (result.snippet or "").strip().replace("\n", " ")
          if len(snippet) > 400:
              snippet = snippet[:400] + "…"
          lines.append(f"- {result.title}\n  {result.url}\n  {snippet}")
      return "\n\n".join(lines) if lines else "No results."
  ```

  ```typescript Typescript theme={null}
  import Perplexity from "@perplexity-ai/perplexity_ai";

  const perplexity = new Perplexity();

  async function runPeopleSearch(queries: string[]): Promise<string> {
    const response = await perplexity.search.create({
      query: queries,
      search_type: "people",
      max_results: 10,
    });

    const lines = response.results.map((r) => {
      const snippet = (r.snippet ?? "").trim().replace(/\n/g, " ");
      const trimmed = snippet.length > 400 ? `${snippet.slice(0, 400)}…` : snippet;
      return `- ${r.title}\n  ${r.url}\n  ${trimmed}`;
    });
    return lines.length ? lines.join("\n\n") : "No results.";
  }
  ```
</CodeGroup>
