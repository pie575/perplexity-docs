<div id="overview">
  ## 概述
</div>

<u>[OpenClaw](https://openclaw.ai)</u> 是一款运行在终端中的开源 AI 智能体，可连接多个 LLM 提供方，并支持将 Perplexity 作为网页搜索提供方来实时检索信息。

你可以将 OpenClaw 配置为使用 Perplexity 的 Agent API 模型作为智能体，并使用 Perplexity Search API 处理网络搜索工具调用，从而在 OpenClaw 的智能体框架中直接用上 Perplexity 强大的模型和最新的搜索结果。

<Card title="获取 Perplexity API 密钥" icon="key" arrow="True" horizontal="True" iconType="solid" cta="获取密钥" href="https://console.perplexity.ai/project/keys">
  前往 API 控制台，生成一个新密钥，用于搭配 OpenClaw 使用。
</Card>

***

<div id="search-api-setup-use-perplexity-as-your-web-search-provider">
  ## Search API 配置 (将 Perplexity 用作网页搜索提供方)
</div>

将 Perplexity Search API 用作 OpenClaw 的网页搜索后端，实现实时信息检索。

<Steps>
  <Step title="安装 Perplexity 插件">
    Perplexity 搜索提供方以独立的 OpenClaw 插件形式提供。请先安装该插件，再配置密钥：

    ```bash theme={null}
    openclaw plugins install @openclaw/perplexity-plugin
    openclaw gateway restart
    ```
  </Step>

  <Step title="配置搜索提供方">
    <Tabs>
      <Tab title="交互式 CLI（推荐）">
        最快捷的方式，无需编辑文件：

        ```bash theme={null}
        openclaw configure --section web
        ```

        在提示选择搜索提供方时选择 **Perplexity**，然后粘贴你的 API 密钥。
      </Tab>

      <Tab title="配置文件（JSON）">
        编辑 `openclaw.json` (运行 `openclaw config file` 可定位该文件) ：

        ```json theme={null}
        {
          "plugins": {
            "entries": {
              "perplexity": {
                "config": {
                  "webSearch": {
                    "apiKey": "pplx-..."
                  }
                }
              }
            }
          },
          "tools": {
            "web": {
              "search": {
                "provider": "perplexity"
              }
            }
          }
        }
        ```
      </Tab>

      <Tab title="环境变量">
        设置环境变量，OpenClaw 会自动检测：

        <Tabs>
          <Tab title="macOS / Linux">
            ```bash theme={null}
            export PERPLEXITY_API_KEY="pplx-..."
            ```
          </Tab>

          <Tab title="Windows（PowerShell）">
            ```powershell theme={null}
            setx PERPLEXITY_API_KEY="pplx-..."
            ```
          </Tab>
        </Tabs>

        若以守护进程方式安装，也可在 `~/.openclaw/.env` 中设置 `PERPLEXITY_API_KEY`。
      </Tab>
    </Tabs>
  </Step>

  <Step title="搭配 Perplexity Search 使用 OpenClaw">
    启动 OpenClaw，提出任何需要网页搜索的问题：

    ```
    openclaw
    > What are the latest developments in quantum computing?
    ```

    OpenClaw 会调用 Perplexity Search API 获取结构化结果，并将其融入回答中。
  </Step>
</Steps>

<div id="search-tool-parameters">
  ### 搜索工具参数
</div>

当 OpenClaw 以 Perplexity 作为搜索提供方调用 `web_search` 时，可使用以下参数：

| 参数                    | 说明                                      |
| --------------------- | --------------------------------------- |
| `query`               | 搜索查询 (必填)                               |
| `count`               | 结果数量 (1–10，默认值：5)                       |
| `country`             | ISO 3166-1 alpha-2 国家代码 (例如 `US`、`DE`)  |
| `language`            | ISO 639-1 语言代码 (例如 `en`、`fr`)           |
| `freshness`           | 时间筛选：`day`、`week`、`month` 或 `year`      |
| `date_after`          | 在此日期之后发布的结果 (`YYYY-MM-DD`)              |
| `date_before`         | 在此日期之前发布的结果 (`YYYY-MM-DD`)              |
| `domain_filter`       | 域名允许列表或屏蔽列表 (最多 20 条)                   |
| `max_tokens`          | 内容总预算 (默认值：25,000，最大值：1,000,000)        |
| `max_tokens_per_page` | 单页 token 上限 (默认值：2,048)                 |

<Tip>
  域名过滤器支持允许列表 (`["nature.com", "science.org"]`) 和屏蔽列表 (`["-reddit.com", "-pinterest.com"]`) ，但不能在同一请求中混用两者。详见[域名过滤器指南](/zh/docs/search/filters/domain-filter)。
</Tip>

<div id="agent-api-setup-use-perplexity-as-your-llm-provider">
  ## Agent API 配置 (将 Perplexity 用作 LLM 提供方)
</div>

使用 Perplexity 的 Agent API，只需一个 API 密钥，即可调用 Anthropic、OpenAI、Google 等厂商的前沿模型。

<Steps>
  <Step title="获取您的 API 密钥">
    <Card title="生成 API key" icon="key" arrow="True" horizontal="True" iconType="solid" cta="获取密钥" href="https://console.perplexity.ai/project/keys">
      前往 API 控制台，生成一个新密钥。
    </Card>
  </Step>

  <Step title="安装 OpenClaw">
    如果你尚未安装 OpenClaw：

    <Tabs>
      <Tab title="macOS / Linux">
        ```bash theme={null}
        curl -fsSL https://openclaw.ai/install.sh | bash
        ```
      </Tab>

      <Tab title="Windows (PowerShell)">
        ```powershell theme={null}
        iwr -useb https://openclaw.ai/install.ps1 | iex
        ```
      </Tab>
    </Tabs>

    如需使用 Docker、Podman、Nix 或其他安装方式，请参阅 [OpenClaw 安装文档](https://docs.openclaw.ai/install)。
  </Step>

  <Step title="应用所需配置">
    Perplexity 的 Agent API 会在服务端运行自己的内置工具。若要将其用作 OpenClaw 的模型提供方，请在 `openclaw.json` 中禁用 OpenClaw 自带的 `web_search`，让模型改用 Perplexity 的内置搜索：

    ```json theme={null}
    {
      "tools": {
        "web": {
          "search": { "enabled": false }
        }
      }
    }
    ```

    Perplexity Agent API 为其服务端工具保留的完整名称列表，请参阅下方的[保留工具名称](#reserved-tool-names)。
  </Step>

  <Step title="将 Perplexity 配置为 LLM 提供方">
    <Tabs>
      <Tab title="引导式 CLI（推荐）">
        最快捷的方式，无需编辑任何文件：

        ```bash theme={null}
        openclaw onboard \
          --auth-choice custom-api-key \
          --custom-base-url "https://api.perplexity.ai/v1" \
          --custom-api-key "pplx-YOUR_KEY_HERE" \
          --custom-model-id "anthropic/claude-sonnet-4-6" \
          --custom-compatibility openai-responses \
          --custom-provider-id perplexity \
          --install-daemon
        ```

        这会将 Perplexity 注册为提供方，并附带一个 model。若要添加更多 model，可换用不同的 `--custom-model-id` 重新运行命令，或改用配置文件方式。

        你可以把 `anthropic/claude-sonnet-4-6` 替换为 [Agent API 模型列表](/zh/docs/agent-api/models)中的任意 model ID，以更改默认 model。
      </Tab>

      <Tab title="配置文件">
        编辑 `openclaw.json` (运行 `openclaw config file` 可定位该文件) 。以下配置声明了 Perplexity 及一个初始 model，并启用实时 model 发现，让 OpenClaw 通过 `GET /v1/models` 自动获取 Agent API 目录中的其余 model：

        ```json theme={null}
        {
        "agents": {
          "defaults": {
            "model": { "primary": "perplexity/anthropic/claude-sonnet-4-6" },
            "models": { "perplexity/*": {} }
          }
        },
        "tools": {
          "web": { "search": { "enabled": false } }
        },
        "models": {
          "mode": "merge",
          "providers": {
            "perplexity": {
              "baseUrl": "https://api.perplexity.ai/v1",
              "apiKey": "${PERPLEXITY_API_KEY}",
              "api": "openai-responses",
              "models": [
                {
                  "id": "anthropic/claude-sonnet-4-6",
                  "name": "Claude Sonnet 4.6 (Perplexity)",
                  "api": "openai-responses",
                  "reasoning": false,
                  "input": ["text"],
                  "cost": { "input": 3.00, "output": 15.00, "cacheRead": 0.30, "cacheWrite": 0 },
                  "contextWindow": 200000,
                  "maxTokens": 16384
                }
              ]
            }
          }
        }
        }
        ```

        请在 shell 中设置 `PERPLEXITY_API_KEY`，或使用 OpenClaw 的密钥存储功能，不要把密钥直接写入配置文件。

        `agents.defaults.models` 下的 `"perplexity/*": {}` 条目用于启用实时发现。重启后，运行 `openclaw models list --provider perplexity` 即可查看 `GET /v1/models` 返回的所有 model，然后以 `perplexity/<model-id>` 的形式引用其中任意一个 (例如 `perplexity/openai/gpt-5.4` 或 `perplexity/anthropic/claude-opus-4-7`) 。若要为某个 model 固定上下文窗口、成本或能力，只需将该 model 添加到 `models` 数组中；未固定的部分会沿用实时发现的结果。
      </Tab>
    </Tabs>
  </Step>

  <Step title="开始使用 OpenClaw">
    启动 OpenClaw，你的智能体就会使用 Perplexity：

    ```bash theme={null}
    openclaw
    ```
  </Step>
</Steps>

<div id="reserved-tool-names">
  ### 保留的工具名称
</div>

Perplexity 的 Agent API 将以下函数名保留给其服务端内置工具使用；请勿使用这些名称定义自定义函数：

* `web_search`
* `fetch_url`
* `people_search`
* `finance_search`

上述设置步骤中要求的配置会禁用 OpenClaw 托管的 `web_search`，使模型改用 Perplexity 的服务端搜索。Perplexity 的 `web_search` 在模型生成响应的过程中运行，由模型自动调用，每次调用 $0.0025，并返回带引用来源的可溯源结果。若要在某个请求中强制启用它，请将 `{"type": "web_search"}` 作为内置工具 (而非函数) 添加到请求的 `tools` 数组中。

若要将其他占用保留名称的工具从对外的工具目录中移除，可通过其各自的配置开关禁用，或使用 OpenClaw 的通用工具策略：

```json theme={null}
{
  "tools": {
    "deny": ["web_search"]
  }
}
```

<div id="mcp-server-setup-use-perplexity-as-a-tool-provider">
  ## MCP 服务器设置 (将 Perplexity 用作工具提供方)
</div>

OpenClaw 也可以通过 [Model Context Protocol](https://docs.perplexity.ai/docs/getting-started/integrations/mcp-server) 访问 Perplexity，该协议将 `perplexity_search`、`perplexity_ask`、`perplexity_research` 和 `perplexity_reason` 暴露为 MCP 工具，供你的智能体调用。它与上文的 Agent API 设置互为补充：Agent API 负责驱动模型，MCP 则让模型能够使用 Perplexity 的搜索与研究能力。

<Tabs>
  <Tab title="远程 MCP（推荐）">
    在 `openclaw.json` 中添加托管的 MCP 服务器：

    ```json theme={null}
    {
      "mcp": {
        "servers": {
          "perplexity": {
            "url": "https://api.perplexity.ai/mcp",
            "transport": "streamable-http",
            "headers": {
              "Authorization": "Bearer ${PERPLEXITY_API_KEY}"
            }
          }
        }
      }
    }
    ```

    或使用 CLI：

    ```bash theme={null}
    openclaw mcp add perplexity \
      --url https://api.perplexity.ai/mcp \
      --transport streamable-http \
      --header "Authorization=Bearer $PERPLEXITY_API_KEY"
    openclaw mcp doctor perplexity --probe
    ```

    OpenClaw 会在发起请求时从环境变量中解析 `${PERPLEXITY_API_KEY}`。请勿将明文密钥直接写入配置文件。
  </Tab>

  <Tab title="本地 MCP（stdio）">
    通过 `npx` 在本地运行 MCP 服务器，并由 OpenClaw 管理该子进程：

    ```json theme={null}
    {
      "mcp": {
        "servers": {
          "perplexity": {
            "command": "npx",
            "args": ["-y", "@perplexity-ai/mcp-server"],
            "transport": "stdio",
            "env": {
              "PERPLEXITY_API_KEY": "${PERPLEXITY_API_KEY}"
            }
          }
        }
      }
    }
    ```

    或使用 CLI：

    ```bash theme={null}
    openclaw mcp add perplexity \
      --command npx \
      --arg "-y" \
      --arg "@perplexity-ai/mcp-server" \
      --env "PERPLEXITY_API_KEY=$PERPLEXITY_API_KEY"
    openclaw mcp doctor perplexity --probe
    ```

    本地 stdio 方式要求运行 OpenClaw 的机器上已安装 Node.js。除非确实需要完全脱离 Perplexity 边缘节点离线运行，否则建议优先使用远程 MCP 服务器。
  </Tab>
</Tabs>

<Note>
  MCP 工具的名称形如 `perplexity_search`，因此不会与 Perplexity Agent API 的保留名称冲突。如果同时使用 Agent API 设置和 MCP 设置，请保留 Agent API 一节中的 `tools.web.search.enabled: false` 配置项。
</Note>

<Tip>
  MCP 工具同样遵循 OpenClaw 的工具配置档案以及允许/拒绝策略。可通过 `mcp.servers.perplexity.toolFilter.include` 限定智能体可调用哪些 Perplexity 工具。完整字段列表参见 [OpenClaw MCP 指南](https://docs.openclaw.ai/tools/mcp)。
</Tip>

<div id="agent-api-configuration-tips">
  ### Agent API 配置提示
</div>

<AccordionGroup>
  <Accordion title="API 传输方式必须为 openai-responses">
    Perplexity 的 Agent API 主端点是 `POST https://api.perplexity.ai/v1/agent`。它同时也接受发往 `POST https://api.perplexity.ai/v1/responses` 的请求，该地址是[兼容 OpenAI Responses 的别名](/zh/docs/agent-api/openai-compatibility)，也正是 OpenClaw 在 `api` 为 `"openai-responses"` 时所使用的端点。

    在 `openclaw.json` 中，需要在提供方层级和每个 model 条目上都设置 `api: "openai-responses"`。设为 `"openai-completions"` 无法正常工作，因为 Agent API 并未实现 `/v1/chat/completions`。
  </Accordion>

  <Accordion title="基础 URL 必须严格为 https://api.perplexity.ai/v1">
    Perplexity 的 Agent API 主端点是 `POST /v1/agent`，而 `POST /v1/responses` 是其兼容 OpenAI Responses 的别名。OpenClaw 的 `openai-responses` 客户端会在你提供的基础 URL 后追加 `/responses` 再发送请求，因此基础 URL 必须是 `https://api.perplexity.ai/v1`，OpenClaw 才能命中 `/v1/responses` 这个别名。

    | 正确的基础 URL                      | 不要用作基础 URL                                                                                             |
    | ------------------------------ | ------------------------------------------------------------------------------------------------------ |
    | `https://api.perplexity.ai/v1` | `https://api.perplexity.ai/v1/agent` (OpenClaw 会调用 `/v1/agent/responses`，返回 `405 Method Not Allowed`)  |
    |                                | `https://api.perplexity.ai/v1/responses` (OpenClaw 会调用 `/v1/responses/responses`，返回 `404`)             |
    |                                | `https://api.perplexity.ai` (缺少 `/v1`；请求会打到 `/responses`，返回 `404`)                                     |
  </Accordion>

  <Accordion title="模型 ID 格式">
    在配置中，提供方块下的模型 ID 省略提供方前缀，而完整的模型引用会带上前缀：

    * 配置中的模型 ID：`anthropic/claude-sonnet-4-6`
    * 完整模型引用：`perplexity/anthropic/claude-sonnet-4-6`
  </Accordion>

  <Accordion title="使用 `perplexity/*` 通配符发现模型">
    在 `agents.defaults.models` 中添加 `"perplexity/*": {}`，OpenClaw 就会调用 `GET https://api.perplexity.ai/v1/models`，并自动注册返回的每一个模型。你只需为想要固定的模型在 `models.providers.perplexity.models` 下保留详细条目，其余的交由实时发现处理即可。可通过 `openclaw models list --provider perplexity` 进行验证。
  </Accordion>
</AccordionGroup>

<Tip>
  如需获取最新的模型列表与价格，请参阅 [Agent API 模型页面](/zh/docs/agent-api/models)和[价格页面](/zh/docs/getting-started/pricing)。
</Tip>
