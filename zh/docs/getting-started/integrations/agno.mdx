<div id="overview">
  ## 概述
</div>

[Agno](https://docs.agno.com) 是一个用于构建智能体、团队和工作流的开源 Python 框架。借助 Agno 中兼容 OpenAI Responses 的模型类，可以将其接入 Perplexity 的 [Agent API](/zh/docs/agent-api/quickstart)。

<div id="installation">
  ## 安装
</div>

```bash theme={null}
pip install agno openai
```

<div id="api-key-setup">
  ## API key 设置
</div>

将你的 Perplexity API key 设置为环境变量：

```bash theme={null}
export PERPLEXITY_API_KEY="your_api_key_here"
```

<Card title="获取 API key" icon="key" href="https://console.perplexity.ai/project/keys">
  在 API 门户中生成你的 Perplexity API key。
</Card>

<div id="quick-start">
  ## 快速开始
</div>

搭配 Agent API 的基础 URL 和任意受支持的 Agent API 模型使用 `OpenAIResponses`。通过 `extra_body` 传入 research [预设](/zh/docs/agent-api/presets)，让回答基于实时的网络搜索结果：

```python theme={null}
import os

from agno.agent import Agent
from agno.models.openai import OpenAIResponses

agent = Agent(
    model=OpenAIResponses(
        id="openai/gpt-5.6-luna",
        base_url="https://api.perplexity.ai/v1",
        api_key=os.environ["PERPLEXITY_API_KEY"],
        extra_body={"preset": "medium"},
    ),
    markdown=True,
)

agent.print_response(
    "What are the latest breakthroughs in fusion energy this year?",
    stream=True,
)
```

将 `id` 替换为任意 [Agent API 模型](/zh/docs/agent-api/models)，即可通过 Perplexity 路由第三方模型。Agent API 还提供有研究支撑的[预设](/zh/docs/agent-api/presets)以及更多内置[工具](/zh/docs/agent-api/tools)。
