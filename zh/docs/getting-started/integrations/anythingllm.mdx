<div id="overview">
  ## 概述
</div>

[AnythingLLM](https://anythingllm.com) 是一款一体化 AI 生产力应用，可将任意文档、资源或内容转化为 LLM 对话所用的上下文。它同时支持桌面端和自托管部署，并可对接数十家 LLM 提供商——其中 Perplexity 作为一等公民级云端提供商，让每个工作区都能获得带引用来源的联网答案。

<Info>
  **AnythingLLM** 由 Mintplex Labs 开发和维护。它支持按工作区分别配置 LLM，因此你可以在一个工作区使用 Perplexity，在另一个工作区使用其他提供商。详见 [anythingllm.com](https://anythingllm.com)。
</Info>

<div id="setup">
  ## 设置
</div>

<Steps>
  <Step title="获取 API key">
    在 [API 门户](https://console.perplexity.ai/project/keys)中生成 Perplexity API key。

    <Card title="获取 API Key" icon="key" href="https://console.perplexity.ai/project/keys">
      生成你的 Perplexity API key。
    </Card>
  </Step>

  <Step title="打开 LLM 设置">
    在 AnythingLLM 中，前往 **Settings → LLM Preference**。
  </Step>

  <Step title="选择 Perplexity AI">
    从提供商列表中选择 **Perplexity AI**，然后粘贴你的 API key。
  </Step>

  <Step title="选择模型">
    输入 key 后，**Chat Model Selection** 下拉列表会自动列出可用的 Perplexity 模型。选择所需的模型 (例如 `sonar-pro`) 并保存。
  </Step>
</Steps>

<div id="system-vs-workspace-models">
  ## 系统级与工作区级模型
</div>

AnythingLLM 支持在两个层级上设置 LLM 的选择范围：

* **系统 LLM** —— 所有工作区和智能体默认使用的提供商。
* **工作区 LLM** —— 针对单个工作区的覆盖设置，在该工作区内对话时优先生效。

你可以自由搭配不同的提供商。例如，将 Anthropic 设为系统默认，而在某个需要实时网络信息支撑的研究型对话工作区中使用 Perplexity。

按工作区覆盖设置的方法：打开该工作区，依次进入 **Workspace Settings → Chat Settings → Workspace LLM Provider**，选择 **Perplexity AI** 及所需的模型。

<div id="available-models">
  ## 可用模型
</div>

AnythingLLM 用户可使用 API 支持的所有 Perplexity 模型——API key 验证通过后，模型下拉列表会自动填充。推荐模型：

* `sonar` — 快速、经济高效的联网对话
* `sonar-pro` — 高级推理，引用来源更丰富
* `sonar-reasoning-pro` — 结合搜索的多步推理

完整列表请参阅 [Perplexity 模型与能力](/zh/docs/sonar/models)。

<div id="use-cases">
  ## 使用场景
</div>

将 Perplexity 与 AnythingLLM 搭配使用，可以获得：

* **文档工作流中的实时网络答案** —— 工作区可在同一个对话中，既回答已上传 PDF 的相关问题，也回答来自公开网络的问题。
* **带引用来源的检索** —— Perplexity 会返回来源 URL，你可以结合检索增强的上下文逐一核查。
* **面向时事的无 RAG 回退** —— 当文档中找不到答案时，模型可自动获取实时网络上下文。

<div id="agent-configuration">
  ## Agent 配置
</div>

使用 AnythingLLM 的 [AI 智能体](https://docs.anythingllm.com/agent/setup) 时，你可以在工作区的 **Agent Configuration** 菜单中将 Perplexity 设置为智能体所用的 LLM。如果智能体需要把网络调研与网页浏览、文档问答、外部 API 调用等技能串联起来，这一配置尤其有用。
