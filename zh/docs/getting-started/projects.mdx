<div id="what-is-a-project">
  ## 什么是 Project？
</div>

**Project** 是你的组织在 Perplexity API Portal 中的工作空间。你可以在其中：

* **管理账单**及 API 使用的支付方式
* **创建并管理 API key**，用于访问 Perplexity API
* **邀请团队成员**并设置其权限 (可选) 
* **监控**所有 API key 的**用量与费用**

<div id="prerequisites">
  ## 前提条件
</div>

开始之前，请确保你已具备：

* 一个 Perplexity 账户 (可在 [perplexity.ai](https://perplexity.ai) 注册) 
* 管理账单和 API key 所需的**管理员权限**
* 一张用于设置付款方式的**信用卡** (初始不会产生扣费) 

<Note>
  如果你要加入已有团队，需要管理员向你发送邀请。请联系团队负责人获取访问权限。
</Note>

<div id="accessing-the-api-portal">
  ## 访问 Perplexity API Portal
</div>

前往 [console.perplexity.ai](https://console.perplexity.ai) 打开你的项目。左侧边栏分为两个部分：

* **Project**：Settings、Members、Billing、API keys、Files
* **API Playground**：Search API、Agent API

<div id="billing-and-payment-methods">
  ## 账单与支付方式
</div>

<div id="how-billing-works">
  ### 计费方式
</div>

Perplexity API 采用**基于额度的计费系统**：

* **额度**需提前购买，用于支付 API 调用
* **不同 model** 每次请求消耗的额度各不相同
* **费用**按处理的 token 数量和发起的搜索查询次数计算
* 可开启**自动充值**，避免服务中断

<Info>
  各 model 及使用类型的详细费用信息，请参阅我们的[定价页面](./pricing)。
</Info>

<div id="setting-up-payment">
  ### 设置付款方式
</div>

<Card title="访问账单面板" icon="credit-card" arrow="True" horizontal="True" iconType="solid" cta="前往账单页面" href="https://console.perplexity.ai/project/billing">
  直接前往 API 账单面板，管理支付方式、查看用量并配置账单设置。
</Card>

<Steps>
  <Step title="进入账单页面">
    点击左侧边栏中的 **Billing**。该页面会显示你的信用额度余额、付款方式、用量图表以及账单明细。

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_billing.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=6d6e71d28dcf4d39faa4fc8b14c6ad48" alt="API Billing Dashboard" />
    </Frame>
  </Step>

  <Step title="添加付款方式">
    点击 **Add payment method** 并填写信用卡信息。付款由 Stripe 管理，你也可以点击 **Manage ↗** 直接进入 Stripe 门户。

    <Note>
      添加付款方式不会对信用卡扣款，只会保存付款信息，供后续 API 使用时结算。
    </Note>
  </Step>

  <Step title="配置自动充值（推荐）">
    点击 **Auto reload** 旁边的 **Change preferences**，启用额度自动充值。

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_topup.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=3aa16c75b424292781b61005b1ab32df" alt="API Billing Dashboard" />
    </Frame>

    <Warning>
      如果额度用尽，你的 API key 会被停用，直到补充额度余额为止。启用自动充值后，余额低于设定阈值时系统会自动补充额度，从而避免这种情况。
    </Warning>
  </Step>
</Steps>

<div id="credit-balance">
  ### 信用额度余额
</div>

计费页面会在顶部醒目位置显示你的**剩余信用额度余额**。你可以随时通过 **Buy more credits** 链接购买更多额度。

此处还会显示你当前的**用量层级** —— 点击 **Learn more ↗** 可了解各层级的门槛与权益详情。

<div id="managing-api-keys">
  ## 管理 API key
</div>

<div id="what-are-api-keys">
  ### 什么是 API key？
</div>

API key 是你访问 Perplexity API 的凭据。每个 key 都会：

* **验证你发往 Perplexity API 的请求**
* **跟踪用量**，用于使用归属
* **可随时吊销**，以保障安全
* **应妥善保管**，切勿公开分享

<Info>
  你需要在每个 API 请求的 Authorization 请求头中携带 API key：`Authorization: Bearer $PERPLEXITY_API_KEY`
</Info>

<div id="creating-an-api-key">
  ### 创建 API key
</div>

<Steps>
  <Step title="进入 API keys 页面">
    点击左侧边栏中的 **API keys**。

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_api_keys.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=d72bcb05e281c05a5a7a2f7b3a469f50" alt="API Keys" />
    </Frame>
  </Step>

  <Step title="生成新的 key">
    点击 **+ Generate API Key** 创建新的 API key。

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_api_keys_new.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=ca3c652417faa90238d299ddc72b0249" alt="API Keys" />
    </Frame>
  </Step>
</Steps>

<Warning>
  API key 属于敏感凭据。切勿将其写入客户端代码，也不要在公开代码仓库中分享。
</Warning>

<div id="adding-and-managing-members">
  ## 添加和管理成员
</div>

管理员可以邀请团队成员加入组织，并为其指定特定角色：**Admin** (管理员) 或 **Member** (成员) 。

<div id="adding-a-member">
  ### 添加成员
</div>

<Steps>
  <Step title="进入成员页面">
    点击左侧边栏中的 **Members**。该页面会显示当前的团队成员及其角色。
  </Step>

  <Frame>
    <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_members.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=78f439f1a1567dc49c7ff06c4033b3af" alt="Members" />
  </Frame>

  <Step title="发起成员邀请">
    点击 **+ Add Member**，输入该用户的邮箱地址，然后点击 **Invite**。

    <Frame>
      <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_add_member.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=c4fab8e720fb1db15206846289399a3a" alt="Add Member" />
    </Frame>
  </Step>

  <Step title="成员收到邀请">
    受邀用户会收到一封邮件，其中包含加入你的项目的链接。

    <Check>
      对方接受邀请后，即会出现在成员列表中，并显示其所分配的角色。
    </Check>
  </Step>
</Steps>

<div id="filtering-members-by-role">
  ### 按角色筛选成员
</div>

使用下拉菜单可按角色筛选团队成员列表。

<div id="roles">
  ### 角色
</div>

* **管理员**：拥有完整权限，可邀请/移除成员、管理账单并查看用量数据。
* **成员**：可查看用量和账户限额，但不能修改设置。

<Warning>
  只有管理员才能更改账单和成员权限。
</Warning>

<div id="viewing-usage-metrics">
  ## 查看用量指标
</div>

所有成员都可以直接在控制台的 **Billing** 页面查看 API 用量。

<Frame>
  <img src="https://mintcdn.com/perplexity/DPUduAo6hpcohwv5/docs/assets/images/api_portal/console_usage_metrics.png?fit=max&auto=format&n=DPUduAo6hpcohwv5&q=85&s=80e6246097068cf8854370c98a9de338" alt="Usage Metrics" />
</Frame>

**Usage** 图表支持按以下条件筛选，跟踪一段时间内的使用情况：

* **指标选择器**：可选择 Chat Completions API Requests、Input Tokens、Output Tokens、Citation Tokens、Reasoning Tokens、Deep Research Requests Count、Search API Requests Count 或 Pro Search API Requests Count
* **时间范围**：可按最近 7 天、最近 30 天或自定义范围筛选

图表下方的 **Billing breakdown** 表格会按 model 列出用量、费率和费用明细，让你清楚掌握各产品的支出情况。

<Check>
  用量指标可帮助你监控 API 活动，并针对成本或性能进行优化。
</Check>

在 **Billing** 页面的用量图表和账单明细下方，可以看到 **Invoice history**——其中记录了所有历史发票的日期、状态和金额。
